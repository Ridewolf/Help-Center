# Ridewolf support

This repository is the public knowledge base and support entry point for the Ridewolf Dashboard.

## Find an answer

Choose a language from the [Help Center home page](README.md), then browse the contents or use GitHub search. Search for the page name, dashboard route, or the action you want to complete.

## Ask for help

If the documentation does not answer your question, [open a support request](https://github.com/Ridewolf/Help-Center/issues/new?template=support.yml). Describe your goal, the page you used, the steps you took, and the exact error message.

This is a public repository. Never post:

- passwords, tokens, API keys, or cookies;
- customer names, email addresses, phone numbers, or payment information;
- private company data, internal URLs, or unredacted screenshots.

For a documentation correction, use the [documentation issue form](https://github.com/Ridewolf/Help-Center/issues/new?template=documentation.yml). Report suspected security vulnerabilities through [GitHub's private security advisory form](https://github.com/Ridewolf/Help-Center/security/advisories/new).

## Response expectations

Issues are triaged by the Ridewolf team. Public GitHub support is not an emergency channel and does not guarantee a response time. If your organization has a separate support agreement, use the contact channel specified there for urgent incidents.
