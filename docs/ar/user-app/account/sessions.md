# الجلسات — الأجهزة المسجلة الدخول إلى الحساب

شاشة **الجلسات** (`/settings/sessions`) تعرض كل مكان تم تسجيل دخول حساب الراكب فيه حاليًا، وتتيح له تسجيل الخروج من تلك الأماكن. هذه هي الشاشة التي يجب الوصول إليها كلما اشتبه الراكب في أن شخصًا آخر لديه وصول إلى حسابه.

نقطتا دخول، كلاهما يؤدي إلى هنا:

- **الملف الشخصي → إدارة الجلسات**
- **الإعدادات → بطاقة الخصوصية → إدارة الجلسات**

## كيف يتم تنظيم القائمة

الجلسات **مجمعة حسب الجهاز** — المتصفح وإصداره، نظام التشغيل وإصداره، نوع الجهاز، الشركة المصنعة والطراز — بحيث يظهر نفس الهاتف مرة واحدة بدلاً من عدة مرات.

يتم ترتيب المجموعات عمدًا كالتالي:

1. جهاز الراكب الحالي أولاً
2. ثم حسب الحالة: **نشط**، ثم **غير نشط**، ثم **قديم**
3. ثم حسب آخر نشاط، الأحدث أولاً

كل مجموعة قابلة للطي. توسيعها يكشف عن كل جلسة فردية تنتمي لذلك الجهاز.

## قراءة مجموعة جهاز

| ما تراه                            | المعنى                                                                    |
| --------------------------------- | ------------------------------------------------------------------------- |
| **تسمية الجهاز**                  | الشركة المصنعة والطراز عند المعرفة، وإلا نظام التشغيل وإصداره            |
| أيقونة نوع الجهاز                | هاتف، جهاز لوحي أو شاشة                                                  |
| **تسمية المتصفح**                 | المتصفح وإصداره وراء الجلسة                                               |
| شارة **حالة الجلسة**             | انظر الجدول أدناه                                                        |
| **آخر نشاط**                     | الوقت النسبي — "الآن فقط"، قبل N دقائق / ساعات / أيام، وتاريخ مطلق إذا مضى أكثر من أسبوع |
| **عدد الجلسات**                  | عدد الجلسات التي يمتلكها ذلك الجهاز                                     |
| **الموقع**                      | المدينة، البلد وعنوان IP                                                 |
| **تاريخ الإنشاء**                | متى بدأت تلك الجلسة                                                      |
| **الجهاز الحالي** / **الجلسة الحالية** | شارة مميزة على الجهاز والجلسة التي يستخدمها الراكب الآن                 |

### شارات الحالة

| الشارة       | المعنى                              |
| ------------ | ---------------------------------- |
| **نشط**     | آخر نشاط قبل أقل من ساعة            |
| **غير نشط** | آخر نشاط قبل أقل من 24 ساعة         |
| **قديم**    | آخر نشاط قبل 24 ساعة أو أكثر         |

الشارة تقيس **الحداثة فقط** — لا تعني ما إذا كانت الجلسة لا تزال صالحة. شارة "قديم" لا تعني أن الجلسة انتهت صلاحيتها.

## تسجيل الخروج من جلسة واحدة

الجلسة الحالية لا تحتوي على زر حذف — حسب التصميم، لا يمكن إزالتها من هذه القائمة. يمكن حذف أي جلسة أخرى:

1. قم بتوسيع مجموعة الجهاز
2. اضغط على أيقونة **سلة المهملات** على الجلسة
3. أكد في مربع الحوار

تُعاد تحميل القائمة وتختفي الجلسة.

## الإجراءات الجماعية

| الإجراء                     | ما يقوم به                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **تسجيل خروج الجلسات الأخرى**  | يسجل خروج كل الجلسات ما عدا الجلسة على الجهاز الذي يستخدمه الراكب. هذا هو الإجراء الصحيح عندما يشتبه الراكب في أن شخصًا آخر لديه وصول |
| **تسجيل خروج كل الجلسات**    | يسجل خروج كل شيء **بما في ذلك الجهاز الحالي**، فيُعاد الراكب إلى شاشة تسجيل الدخول ويجب عليه تسجيل الدخول مرة أخرى. مصمم كإجراء مدمر لهذا السبب |
| **إلغاء الجهاز**          | يُعرض على مجموعة جهاز موسعة ليست الجهاز الحالي — يسجل خروج كل الجلسات على ذلك الجهاز      |

أثناء تنفيذ طلب تسجيل الخروج تُعطل الأزرار. في حالة الفشل يظهر رسالة خطأ قصيرة؛ في حالة النجاح يظهر تأكيد ويُعاد تحميل القائمة.

## سير العمل النموذجي

- **يعتقد الراكب أن شخصًا آخر في حسابه** — استخدم **تسجيل خروج الجلسات الأخرى**، ثم غيّر كلمة المرور من **الملف الشخصي**. لاحظ أن تغيير كلمة المرور الناجح يسجل خروج الراكب أيضًا، لذا سيقوم بتسجيل الدخول مرة أخرى بعد ذلك ([الملف الشخصي](profile.md))
- **تسجيل دخول منسي على هاتف مستعار** — قم بتوسيع مجموعة ذلك الجهاز، ثم **إلغاء الجهاز**
- **بدء نظيف في كل مكان** — استخدم **تسجيل خروج كل الجلسات**، ثم سجل الدخول مرة أخرى ([تسجيل الدخول](registration-login.md))

## الأسئلة الشائعة

- **لماذا لا يمكن للراكب حذف جلسته الحالية؟** لا يظهر زر حذف لها. لإنهاء الجلسة الحالية، استخدم **تسجيل خروج كل الجلسات**، أو زر **تسجيل الخروج** العادي في الملف الشخصي.
- **ماذا يعني "نشط" فعليًا؟** نشاط خلال الساعة الماضية — لا أكثر.
- **لماذا يظهر هاتف واحد عدة جلسات؟** تُنشأ الجلسات لكل تسجيل دخول. الشاشة تجمعها تحت جهاز واحد وتعرض العدد.
- **زر إدارة الجلسات معطل.** الحساب لديه حذف معلق، مما يعطل إدارة الجلسات مع تحرير الملف الشخصي — انظر [الملف الشخصي](profile.md).
