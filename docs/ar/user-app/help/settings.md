# تطبيق الراكب — الإعدادات

الإعدادات (`/settings`) تحتوي على كل تفضيلات التطبيق التي يراها الراكب: الإشعارات، ما يعرضه الخريطة، مفاتيح الخصوصية، اللغة، السمة والأداء.

**لا يوجد زر حفظ.** تعرض الشاشة الإعدادات المخزنة مؤقتًا على الفور، وتُحدّثها في الخلفية، وترسل كل تغيير تلقائيًا بعد لحظة من إجرائه. الراكب الذي غيّر شيئًا وأغلق الشاشة فورًا قد حفظه بالتأكيد — هذا هو الجواب على "هل تم تطبيق تغييري؟".

تغير عدة مفاتيح من هذه ما يعرضه [الخريطة](../riding/map.md)، لذا هذه هي الشاشة الأولى التي يجب زيارتها عند "الخريطة بطيئة" و"لا أستطيع رؤية مستويات البطارية".

## الإشعارات

خمسة مفاتيح مستقلة:

- **إشعارات الرحلات**
- **إشعارات الترويج**
- **تحديثات التطبيق**
- **إشعارات الدفع**
- **إشعارات البريد الإلكتروني** — مفتاح واحد فقط؛ لا توجد خيارات فرعية لكل نوع تحتها

في نفس المنطقة:

| التحكم            | الملاحظات                                                                    |
| ------------------ | ---------------------------------------------------------------------------- |
| **الصوت**          | مفتاح تبديل                                                                  |
| **مستوى الصوت**    | شريط تمرير — يظهر فقط أثناء تشغيل **الصوت**                                  |
| **الاهتزاز**       | مفتاح تبديل                                                                  |
| **إعدادات الرادار**| بطاقة تظهر فقط في إصدارات التطبيق التي تم تفعيل إعدادات الرادار فيها         |

## الخريطة والعرض

مفاتيح التبديل:

- **عرض مستوى البطارية**
- **عرض المركبات الترويجية**
- **عرض التسعير**
- **التكبير التلقائي**
- **الخريطة ثلاثية الأبعاد** — يؤثر على الخريطة فورًا
- **تقليل الرسوم المتحركة**

بالإضافة إلى **وضع البيانات**، وهو اختيار بين **متوازن**، **منخفض** و**مرتفع**. يتحكم في جودة بلاطات الخريطة وكمية التفاصيل التي تعرضها الخريطة، وهو **أول شيء يجب تجربته عندما يبلغ الراكب عن خريطة بطيئة أو ثقيلة** — خفضه إلى _منخفض_، وتشغيل **تقليل الرسوم المتحركة** أيضًا.

**الخرائط دون اتصال** غير متوفرة حاليًا في التطبيق.

## ضوابط الخصوصية

- مفتاح **مشاركة الموقع الجغرافي**
- مفتاح **مشاركة البيانات**
- **سياسة الخصوصية** — يفتح عنوان URL خارجي قمت بتكوينه في [شركتي](../../settings/administration/my-company.md)؛ يظهر الرابط فقط عند تعيين عنوان URL
- **إدارة الجلسات** — يفتح شاشة الأجهزة المسجلة الدخول (`/settings/sessions`)، نفس الشاشة التي يمكن الوصول إليها من الملف الشخصي

شاشة إرشادات الخصوصية والسلامة الكاملة هي مسار خاص بها (`/privacy`). **حذف الحساب غير موجود هنا** — تدفق الحذف الفعلي موجود في شاشة الملف الشخصي.

## المنطقة والمظهر

| التحكم        | الخيارات                          | الملاحظات                                                                                               |
| -------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **اللغة**     | **en**، **ru**، **ro**           | يُطبق فورًا، بدون إعادة تحميل. هذه الثلاث فقط متاحة في هذه الشاشة                                     |
| **الوحدات**   | —                                | محدد وحدات غير متوفر حاليًا في التطبيق                                                                |
| **السمة**     | فاتح، داكن، النظام                | يُطبق فورًا                                                                                            |
| **نمط الخريطة**| تلقائي، فاتح، داكن               | **معطل ومجبر على التلقائي كلما كانت السمة على النظام.** غيّر السمة إلى فاتح أو داكن لتمكينه             |

تظهر هنا فقط اللغات الثلاثة للتطبيق أعلاه، رغم وجود لغات أخرى في أجزاء أخرى من المنتج — انظر [Localization](../../settings/administration/localization.md) لجهة لوحة التحكم.

## وضع الركوب

**وضع الركوب غير متوفر حاليًا في التطبيق.** الراكب الذي يسأل عن مكان تحكم وضع الركوب لم يفقد إذنًا — القسم غير موجود في التطبيق، ولا يوجد إعداد في لوحة التحكم يضيفه.

## الأسئلة الشائعة

| يسأل الراكب…                        | الجواب                                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| "أين زر الحفظ؟"                     | لا يوجد — التغييرات تحفظ تلقائيًا                                                            |
| "أين وضع الركوب؟"                   | غير متوفر حاليًا في التطبيق                                                                  |
| "لماذا نمط الخريطة معتم؟"           | السمة مضبوطة على **النظام**. غيّرها إلى فاتح أو داكن أولًا                                  |
| "لماذا لغتي غير مدرجة؟"             | هذه الشاشة تقدم فقط **en**، **ru** و**ro**                                                  |
| "أين إعداد الوحدات؟"                 | غير متوفر حاليًا في التطبيق                                                                  |
| "أين مفتاح الخرائط دون اتصال؟"      | غير متوفر حاليًا في التطبيق                                                                  |
| "كيف أحذف حسابي؟"                   | من شاشة الملف الشخصي، وليس من الإعدادات                                                    |
| "كيف أرى أجهزتي المسجلة الدخول؟"    | **إدارة الجلسات** — هنا، أو نفس الزر في الملف الشخصي                                       |
| "الخريطة بطيئة"                     | **وضع البيانات → منخفض**، ثم تشغيل **تقليل الرسوم المتحركة**. انظر [الخريطة](../riding/map.md#استكشاف-الأخطاء-وإصلاحها) |

## نصائح

- **وضع البيانات هو مفتاح أدائك.** قبل أن تلوم هاتف الراكب أو بلاطاتك، اجعلهم يجربون _منخفض_.
- **"لم يتم الحفظ" نادراً ما تكون صحيحة.** اطلب منهم إعادة فتح الشاشة — ستكون القيمة موجودة.
- **شكاوى الخريطة غالباً ما تكون هنا، وليس على الخريطة.** نسب البطارية المفقودة، الأسعار المفقودة والمركبات الترويجية المفقودة كلها تبديلات في هذه الشاشة.
- **السمة تقفل نمط الخريطة.** احفظ هذا الزوج؛ وإلا سيكون تذكرة أسبوعية.
