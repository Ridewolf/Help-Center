# مراجعة التذاكر التلقائية

صفحة مراجعة التذاكر التلقائية (`/support/tickets/auto-review`) هي **واجهة قائمة مبسطة** للعمل على التذاكر المعلقة واحدة تلو الأخرى، دون العودة إلى القائمة بين القرارات.

تمامًا مثل [مراجعة إثبات الوقوف التلقائية](park-proof-auto-review.md)، تعني كلمة "تلقائي" هنا **التقدم التلقائي**: بعد كل إجراء، تقوم الصفحة بتحميل التذكرة المعلقة التالية حتى تتمكن من الاستمرار في المراجعة دون انقطاع.

يمكن الوصول إليها من خلال زر **المراجعة التلقائية** في [قائمة التذاكر](tickets.md).

الصلاحية المطلوبة: **التذاكر** (`a8b9c1`).

## كيف تعمل

1. تقوم الصفحة بتحميل **قائمة التذاكر المعلقة الحالية** عند فتحها
2. ترى أول تذكرة — صورة الدليل، معلومات التذكرة، وأزرار الإجراءات
3. اختر إجراءً (حل / قيد العمل / بانتظار المعلومات / رفض / مكرر) أو تخطى
4. تقوم الصفحة **بالتقدم تلقائيًا** إلى التذكرة المعلقة التالية
5. كرر حتى تفرغ القائمة
6. عند الفراغ، تتحول الصفحة إلى **حالة انتظار** مع عد تنازلي يستطلع التذاكر الجديدة

مكانك هو قائمة التذاكر المعلقة نفسها — إغلاق التبويب وإعادة فتحه لا يفقد التقدم، فقط تتابع من التذكرة المعلقة التالية عند تحميلها.

## التخطيط

ثلاثة أعمدة على الشاشات العريضة، تتكدس على الشاشات الضيقة:

| العمود      | العرض | المحتويات                                                              |
| ----------- | ----- | ---------------------------------------------------------------------- |
| **الصورة**  | 5/12  | صورة الدليل القابلة للتكبير + الطابع الزمني                            |
| **الإجراءات** | 4/12  | خمسة أزرار لتغيير الحالة + تخطى + تعليق                               |
| **المعلومات** | 3/12  | بطاقة معلومات التذكرة مع الحالة، نوع الشكوى، المركبة، المبلغ، التواريخ |

شريط تقدم عبر الأعلى يظهر مدى التقدم.

## الرأس

- **العنوان** "مراجعة التذاكر التلقائية"
- **العنوان الفرعي** مع التقدم: `مراجعة X من Y · T-12345`
- زر **تخطي** (أعلى اليمين) — يتخطى التذكرة الحالية دون اتخاذ قرار (التذكرة تبقى _معلقة_)
- **سهم العودة** — يعود إلى [قائمة التذاكر](tickets.md)

## أزرار الإجراءات

خمسة انتقالات حالة، بالإضافة إلى تخطى وتعليق اختياري:

| الزر             | الحالة الجديدة  | متى تستخدمه                                                                |
| ---------------- | --------------- | --------------------------------------------------------------------------- |
| **حل**           | _محلول_         | تم إصلاح المشكلة (أو لم تكن حقيقية) — يغلق التذكرة                         |
| **قيد العمل**    | _قيد التقدم_    | المشكلة حقيقية، وبدأت في إصلاحها (مهمة صيانة، متابعة)                      |
| **بانتظار المعلومات** | _بانتظار المعلومات_ | تحتاج إلى مزيد من المعلومات من الراكب قبل اتخاذ القرار — يتم إرسال تنبيه للراكب |
| **رفض**          | _مرفوض_         | ليست مشكلة حقيقية (تقرير منخفض الجودة، هدف خاطئ، بريد مزعج)               |
| **مكرر**          | _مكرر_          | توجد تذكرة أخرى لنفس المركبة / المشكلة                                    |
| **تخطي**          | (لم يتغير)      | لا تتخذ قرارًا؛ انتقل إلى التذكرة التالية                                  |
| **تعليق**         | (أي إجراء)      | ملاحظة اختيارية مرفقة بالإجراء الذي تنقر عليه                              |

كل نقرة تُنفذ فورًا وتتقدم إلى التذكرة التالية. اكتب **التعليق أولاً** إذا أردت إرفاقه.

### متى تستخدم كل حالة إغلاق

- **حل** — تم إصلاح العطل (أو كان التقرير سوء فهم تم حله بفحص المركبة)
- **رفض** — كان التقرير سيئًا / مزيفًا / غير ذي صلة؛ يرى الراكب الرفض في تطبيقه
- **مكرر** — رابط إلى التذكرة الأصلية؛ النظام الخلفي يدير السلسلة بحيث إغلاق واحدة يغلق الكل

_حل_، _رفض_ و_مكرر_ تغلق التذكرة. _قيد العمل_ و_بانتظار المعلومات_ تبقيها مفتوحة في قائمة مختلفة.

## عمود المعلومات

بطاقة **معلومات التذكرة** على اليمين تعرض البيانات المنظمة خلف الصورة:

- **الحالة** — علامة الحالة الحالية
- **نوع الشكوى** — علامة ملونة (ضرر ميكانيكي، كهربائي، بطارية، إلخ)
- **المركبة** — تسمية ورابط
- **المبلغ** — اسم (راكب) أو تسمية (نظام / مشغل)
- **الموقع** — العنوان / الإحداثيات
- **تاريخ الإنشاء / التحديث** — الطوابع الزمنية
- **اتفاقية مستوى الخدمة (SLA)** — الوقت المتبقي (أو شارة "متأخر")

اقرأ هذه البطاقة قبل اتخاذ القرار — تخبرك بالقصة كاملة دون مغادرة الصفحة.

## حالة الانتظار

عندما تفرغ القائمة، تعرض الصفحة نفس شاشة الانتظار المستخدمة في إثباتات الوقوف:

- رسالة "تم مراجعة كل التذاكر"
- **مؤقت عد تنازلي** حتى الاستطلاع التلقائي التالي
- زر **التحقق الآن** للاستطلاع الفوري
- زر **الخروج** للعودة إلى القائمة

إذا وصلت تذكرة جديدة أثناء الانتظار، تقوم الصفحة بتحميلها تلقائيًا.

## متى تستخدم المراجعة التلقائية مقابل القائمة

| استخدم القائمة عندما…                                      | استخدم المراجعة التلقائية عندما…                      |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| تحتاج إلى التصفية حسب الحالة، نوع الشكوى، أو المركبة     | تقوم بمعالجة قائمة التذاكر المعلقة غير المصفاة         |
| تحقق في مركبة معينة أو تاريخ راكب محدد                     | تركز على تذكرة واحدة في كل مرة، ملء الشاشة             |
| تقوم بتدقيق القرارات السابقة (محلول / مرفوض / إلخ)       | تريد السرعة: قراءة → قرار → التالي                      |
| تحتاج إلى التصعيد لفريق الصيانة                          | تعمل في وضع الوردية، تعالج القائمة من البداية للنهاية |

## سير العمل النموذجي

- **بدء الوردية** — افتح المراجعة التلقائية → عالج كل تذكرة معلقة → انتهِ على شاشة الانتظار
- **الفرز السريع** — اقرأ الصورة + نوع الشكوى + المبلغ → إذا كان واضحًا، _حل_ / _رفض_ مع تعليق من سطر واحد؛ إذا لم يكن، _قيد العمل_ وعلّم فريق الصيانة في التعليق
- **بانتظار الراكب** — عندما يكون التقرير غير واضح، _بانتظار المعلومات_ مع سؤال في التعليق؛ يتم تنبيه الراكب
- **تكرار** — عندما يكشف البحث عن تذكرة مفتوحة لنفس المركبة، _مكرر_ لربط السلسلة
- **حالة غامضة** — _تخطي_ وافتح من القائمة مع السياق الكامل (تاريخ المركبة، الرحلات ذات الصلة، تنبيهات إنترنت الأشياء)

## نصائح

- **اكتب التعليق أولاً** — نفس قاعدة إثباتات الوقوف: يتم تنفيذ الإجراء قبل حفظ التعليقات المتأخرة
- **التخطي ≠ قرار** — التخطي لا يغلق أي شيء؛ تبقى التذكرة في الطابور للمشغل التالي
- **الفرق بين حل ورفض** — _حل_ تعني "لقد أصلحنا المشكلة"؛ _رفض_ تعني "لم تكن مشكلة حقيقية"؛ يرى الراكب الفرق في تطبيقه
- **معالجة التكرار** — ابحث في القائمة حسب تسمية المركبة أولاً؛ إذا وجدت تذكرة أصل، انقر مكرر، وإلا حل الأكثر معلومات وكرر الباقي
- **مؤقت اتفاقية مستوى الخدمة لا يزال يعمل** أثناء الانتظار — إذا كان الطابور فارغًا لكن القائمة تحتوي على صفوف متأخرة، يتم تصفية تلك الصفوف من المراجعة التلقائية (ربما بسبب الأذونات أو الحالة)؛ عد إلى القائمة لرؤيتها
- **المراجعة التلقائية تحترم ترتيب التذاكر من الخادم** — تختلف أحدث التذاكر المعلقة حسب النشر؛ اعتبر ترتيب الطابور هو المعتمد
