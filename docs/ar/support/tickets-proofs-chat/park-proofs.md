# إثباتات الوقوف — القائمة

قائمة إثباتات الوقوف (`/support/park-proofs`) هي قائمة المراجعة للصور التي يلتقطها الركاب لمركباتهم في لحظات رئيسية من الرحلة. تثبت هذه الصور أن الراكب ركن المركبة بشكل صحيح (أو لم يفعل)، ومهمة فريقك هنا هي **الموافقة على الصور الجيدة، وتحذير أو معاقبة الصور السيئة**.

لمراجعة الصور بشكل فردي (شاشة المراجعة الكبيرة)، راجع [مراجعة إثبات الوقوف](park-proof-review.md). لقواعد الأتمتة التي تتعامل مع الحالات الواضحة بدون تدخل منك، راجع [المراجعة التلقائية](park-proof-auto-review.md).

الصلاحية المطلوبة: **إثباتات الوقوف** (`d5e6f7`). بعض إجراءات الصف تحتاج إلى صلاحيات فرعية إضافية.

## كيف تصل الإثباتات إلى هنا

يطلب تطبيق الراكب على الهاتف المحمول من المستخدم التقاط صورة في ثلاث نقاط:

1. **البداية** — عند فتح قفل المركبة (يثبت أن الوحدة كانت بحالة جيدة عند استلامها)
2. **الوقوف** — أثناء توقف مؤقت في منتصف الرحلة (يثبت أنهم ركنوا بشكل قانوني أثناء التوقف)
3. **النهاية** — عند إنهاء الرحلة (الصورة **الرئيسية** — تثبت أنهم تركوا المركبة مركونة بشكل صحيح)

يتم رفع الصورة مع بيانات تحديد الموقع الجغرافي (GPS) ونشرها في هذه القائمة بحالة **قيد الانتظار**. يمكن للمراجعة التلقائية تحويلها إلى _موافق عليها_ (صورة جيدة) بدون تدخل المشغل؛ وأي شيء غير مؤكد من المراجعة التلقائية يُرسل هنا للمراجعة البشرية.

## الفلاتر

| الفلتر     | النوع     | الملاحظات                                                               |
| ---------- | -------- | ------------------------------------------------------------------- |
| بحث        | نص       | يبحث حسب اسم العميل، تسمية المركبة، معرف الرحلة                     |
| نطاق التاريخ | تقويم  | اختيار من / إلى؛ الافتراضي "كل الوقت"                            |
| الحالة    | قائمة منسدلة | `قيد الانتظار` / `موافق عليها` / `تحذير` / `مغرم` / `محظور` (أو `الكل`) |
| النوع     | قائمة منسدلة | `البداية` / `الوقوف` / `النهاية` (أو `الكل`)                                 |

استخدم `الحالة = قيد الانتظار` كفلتر المراقبة اليومية — فهي قائمة المراجعة.

## الأعمدة

| العمود      | قابل للفرز؟ | المحتوى                                                   |
| ----------- | --------- | --------------------------------------------------------- |
| **الصورة**   | —         | صورة مصغرة للصورة (انقر لفتح صفحة المراجعة)    |
| **المستخدم**    | —         | اسم العميل وصورة الملف الشخصي؛ انقر لفتح ملف العميل  |
| **المركبة** | —         | تسمية المركبة والطراز؛ انقر لفتح تفاصيل المركبة |
| **الرحلة**    | —         | معرف الرحلة؛ انقر لفتح تفاصيل الرحلة                    |
| **النوع**    | ✓         | مرحلة الرحلة (`البداية` / `الوقوف` / `النهاية`)              |
| **الحالة**  | ✓         | شريط الحالة (انظر المرجع أدناه)                         |
| **التاريخ**    | ✓         | وقت التقاط الصورة؛ الفرز الافتراضي = الأحدث أولاً     |

## مرجع الحالة

| الحالة       | اللون  | المعنى                                                                       |
| ------------ | ------ | ----------------------------------------------------------------------------- |
| **قيد الانتظار**  | أصفر | في انتظار المراجعة (من قبلك أو من المراجعة التلقائية)                                  |
| **موافق عليها** | أخضر  | الصورة جيدة — الراكب ركن المركبة بشكل صحيح                                        |
| **تحذير**  | برتقالي | الصورة ليست جيدة — الراكب يتلقى تحذيرًا لكن بدون غرامة حتى الآن                      |
| **مغرم**    | أحمر    | الصورة سيئة — تم تغريم الراكب (أو النظام وضع علامة كمرشح للغرامة) |
| **محظور**  | رمادي   | تم حظر الراكب بسبب هذا الإثبات (انتهاك شديد / متكرر)     |

يتم تسجيل الحالات التي يتم تعيينها من خلال إجراءات الصف وعلى صفحة المراجعة في سجل الإثبات وسجل [نشاط العميل](../../operations/customers/client-detail.md#لسان-النشاط).

## إجراءات الصف

كل صف يحتوي على **قائمة ثلاث نقاط** على اليمين. تعتمد الإجراءات المتاحة على الصلاحيات:

| الإجراء        | الصلاحية    | ما يقوم به                                                                                                |
| ------------- | ------------- | ----------------------------------------------------------------------------------------------------------- |
| **عرض**      | `view-detail` | فتح [صفحة المراجعة](park-proof-review.md) مع الصورة الكاملة والسياق |
| **الموافقة**   | `review`      | تعيين الإثبات كـ _موافق عليه_ (بدون غرامة، بدون تحذير) — النموذجي للصور الجيدة                                |
| **تحذير**      | `review`      | تعيين كـ _تحذير_ — يتم إعلام الراكب لكنه لا يُغرم                                                |
| **فتح الرحلة** | —             | الانتقال إلى صفحة تفاصيل الرحلة ذات الصلة (خريطة المسار، الجدول الزمني، إلخ)                                          |

الإجراءات التي لا تملك صلاحية لها مخفية.

مجموعة الإجراءات الكاملة (الغرامة، حظر المستخدم، إنشاء مهمة صيانة، طلب إعادة الركن) موجودة في **صفحة المراجعة** — اذهب هناك لأي شيء يتجاوز الموافقة أو التحذير السريع.

## إجراءات الصفحة (أعلى اليمين)

- **المراجعة التلقائية** — تفتح [صفحة إعدادات المراجعة التلقائية](park-proof-auto-review.md) لتكوين القواعد التي توافق تلقائيًا على الصور الجيدة الواضحة وتعلم تلقائيًا على الصور السيئة الواضحة (هذا يفرغ قائمة قيد الانتظار حتى تراجع فقط الحالات الحدية)

## سير العمل النموذجي

- **قائمة المراجعة اليومية** — `الحالة = قيد الانتظار` → فرز حسب التاريخ من الأقدم → استعراض كل صورة، _عرض_ للسياق، _موافقة_ / _تحذير_ حسب ما تراه
- **التحقيق في شكوى** — البحث بمعرف الرحلة أو العميل → إيجاد الإثبات → _عرض_ → التحقق من الصورة مقابل ادعاء الراكب
- **البحث عن المخالفين المتكررين** — البحث باسم العميل → مراجعة عدة إثباتات لرؤية نمط (سجل نشاط ملف المستخدم سيخبر نفس القصة)
- **صور نهاية الرحلة فقط** — `النوع = النهاية` → مراجعة صور نهاية الرحلة فقط (الأهم؛ صور الوقوف في منتصف الرحلة عادةً ما تكون جيدة)
- **تدقيق المراجعة التلقائية** — فلترة `الحالة = موافق عليها` لليوم السابق → فحص عينة للتأكد من أن القواعد تعمل بشكل صحيح

## نصائح

- **الصورة المصغرة تكفي لمعظم المكالمات** — واضحة داخل المنطقة، مؤطرة بشكل مستقيم، بدون عوائق — _الموافقة_ دون فتح. احفظ _عرض_ للصور الغامضة
- **الرحلة المفتوحة** هي اختصارك للسياق — إذا ادعى الراكب أنه ركن بشكل قانوني، تخبرك خريطة الرحلة بالمكان الذي انتهى فيه فعليًا
- **الحالات ثابتة** — بمجرد تعيين _موافق عليه_، يتوقف الراكب عن تلقي التذكيرات بهذا الإثبات. لا توافق على صورة سيئة لـ"تفريغ الطابور" وإلا ستفقد القدرة على المتابعة
- **التحذير هو "الحالة الوسيطة"** — استخدمه عندما تكون الصورة سيئة ولكن ليست خبيثة (الراكب كان مستعجلاً، الطقس كان سيئًا، إلخ). التحذيرات المتكررة تصعد إلى غرامات عبر قواعد المراجعة التلقائية
- **استخدم المراجعة التلقائية بشكل مكثف** — الطابور ينمو بسرعة؛ كلما وافقت المراجعة التلقائية على الصور الجيدة الواضحة بنفسها، زادت طاقتك للصور الغامضة حقًا
- **الرابط قابل للمشاركة** — انسخ عرضًا مفلترًا (مثل _إثباتات الغرامات ليوم أمس_) وأرسله لزميل لفحص عشوائي
