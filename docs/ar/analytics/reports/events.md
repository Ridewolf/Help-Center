# التحليلات — الأحداث الأخيرة

صفحة تحليلات الأحداث (`/analytics/events`) هي **لوحة تحكم الحوادث** الخاصة بك: كل حدث ملحوظ في النظام، المركبة، المستخدم، والمنطقة خلال فترة مختارة، مع عدادات مؤشرات الأداء الرئيسية، أنماط عبر الزمن، وتغذية قابلة للبحث في الأسفل.

مختلفة عن [لوحة الإشعارات](../../features/ux/notifications.md) (في الوقت الحقيقي، لكل حدث) — هذه الصفحة **مجمعة وتاريخية**، مفيدة لرصد الاتجاهات وإجراء مراجعة بعد الحوادث.

الصلاحية المطلوبة: **عرض الأحداث الأخيرة** (`s1t2u3`).

## الإطار الزمني والفلاتر

شريط **نطاق التاريخ** موجود في الأعلى — كل مقياس ورسم بياني يحترمه. أربعة فلاتر إضافية تضيق العرض:

| الفلتر          | الخيارات                                                                 |
| --------------- | ----------------------------------------------------------------------- |
| **الشدة**       | `critical` / `warning` / `info` (اختيار متعدد)                          |
| **النوع**       | `error` / `offline` / `battery` / `payment` / `support` / `maintenance` |
| **نوع المصدر**  | `vehicle` / `user` / `zone` / `system`                                  |
| **الحالة**      | `open` / `resolved` / `dismissed`                                       |

تتجمع كل الفلاتر باستخدام AND. يعكس عنوان URL كل إعداد — شارك رابطًا ويرى زميلك نفس الجزء بالضبط.

## الأقسام

الصفحة تحتوي على **خمسة أقسام**:

### 1. الملخص

أربع بطاقات مؤشرات تلخص عدد الأحداث:

| مؤشر الأداء الرئيسي | ما يعرضه                                               |
| -------------------- | ----------------------------------------------------- |
| **الإجمالي**         | إجمالي الأحداث في النطاق                              |
| **حرج**              | عدد الأحداث مع `severity = critical` — الرقم الذي يجب الانتباه إليه  |
| **تحذير**            | عدد الأحداث مع `severity = warning`                   |
| **معلومات**          | عدد الأحداث مع `severity = info` — عادة ضوضاء إلا إذا كان هناك ارتفاع |

كل بطاقة تحمل شارة مقارنة "مقابل الفترة السابقة".

### 2. حسب النوع

رسم بياني يكسر الأحداث حسب **النوع**:

- **خطأ** — فشل النظام / التكامل
- **غير متصل** — أجهزة إنترنت الأشياء التي تنقطع
- **البطارية** — إنذارات انخفاض / نفاد / شذوذ البطارية
- **الدفع** — الرفض، مشاكل بوابة الدفع
- **الدعم** — ارتفاع التذاكر / المحادثات
- **الصيانة** — أحداث متعلقة بالخدمة

عادة ما تكون الارتفاعات في نوع واحد هي نقطة البداية للتحقيق.

### 3. الأنماط

رسمان بيانيان زمنيّان:

- **حسب اليوم** — الأحداث يوميًا عبر النطاق (يعرض دورات أسبوعية)
- **حسب الساعة** — الأحداث في كل ساعة من اليوم عبر النطاق الكامل (يعرض ذروات يومية)

### 4. المصادر الأعلى

قائمة بأعلى **المصادر** التي تولد الأحداث — عادة مركبات أو مناطق فردية بها عدد غير متناسب من الأحداث.

كل إدخال يشمل المصدر (مرتبط بصفحة التفاصيل الخاصة به)، عدد الأحداث، والشدة / النوع السائد.

هنا تجد **المركبة التي كانت تصدر إنذارات طوال الأسبوع** أو **المنطقة التي بها مشاكل في البطارية**.

### 5. التغذية

تغذية قابلة للتمرير للأحداث الفردية التي تطابق الفلاتر الحالية. كل صف يعرض:

- أيقونة الشدة (ملونة)
- نوع الحدث + تسمية المصدر
- وصف قصير
- الطابع الزمني
- علامة الحالة

انقر على عنصر في التغذية للانتقال إلى الكيان المرتبط (مركبة، عميل، رحلة، تذكرة) حيثما ينطبق.

## سير العمل النموذجي

- **مراجعة صباحية يومية** — إعداد مسبق _آخر 24 ساعة_ → الشدة = حرج → مسح؛ كل شيء باللون الأحمر يحصل على اهتمام قبل فتح بقية لوحة التحكم
- **فرز المصادر الأعلى** — قسم المصادر الأعلى → انقر على مركبة تظهر باستمرار → إصلاح أو تصعيد عند المصدر
- **كشف الأنماط** — رسوم الأنماط؛ يوم أو ساعة غير عادية تظهر تغيرًا (نشر، طقس، انقطاع)
- **مراجعة بعد الحادث** — اختر اليوم → الشدة = حرج → قارن التغذية مع تبويب التنبيهات في [المركبة](../../operations/fleet/vehicle-detail.md) أو قسم الجودة في [تحليلات المدفوعات](payments.md) حسب النوع
- **جولة تنظيف** — الحالة = مفتوح → حل جماعي للعناصر القديمة (تفعل هذا من صفحات المصدر، ليس هنا، لكن تجدها هنا)

## نصائح

- **الحرج أولاً** — ابدأ بـ `severity = critical`; التحذيرات والمعلومات غالبًا ما تحل نفسها
- **النوع هو محققك** — بمجرد وجود ارتفاع، صفِّ حسب النوع السائد لتضييق الضوضاء
- **المصادر الأعلى هي الذهب** — مركبة واحدة في أعلى قائمة المصادر تفسر عادة 30-50% من كل الأحداث
- **التجميع مقابل الخام** — هذه الصفحة تجمع؛ للمعاملات / التنبيهات الفعلية اذهب إلى صفحة مجال المصدر
- **الفلاتر الثابتة** — إعداداتك تبقى عند التنقل؛ امسحها عند تسليم الرابط لشخص آخر
- **الحالة `open` ≠ إنذار إنترنت الأشياء غير محلول** — الحالة هنا هي حالة _سجل الحدث_؛ قد يكون الإنذار الأساسي قد تم مسحه على الجهاز بينما الحدث لا يزال مفتوحًا في النظام
