# التحليلات — المركبات

صفحة تحليلات المركبات (`/analytics/vehicles`) هي **لوحة صحة الأسطول**: عدد المركبات التي لديك، أداؤها، حالة البطارية، المشاكل، والأعطال حسب النوع والمنطقة.

مختلفة عن [قائمة المركبات](../../operations/fleet/vehicles.md) — التي تعرض نظرة تشغيلية لكل وحدة؛ هذه هي **مقاييس الأسطول المجمعة** خلال فترة مختارة.

## الإطار الزمني

شريط **نطاق التاريخ** موجود في الأعلى. تستخدم مخططات الاتجاه النطاق الكامل؛ تعكس نظرة عامة / عدادات الحالة **الحالة الحالية** (نهاية النطاق).

## الأقسام

سبعة أقسام، من الأعلى إلى الأسفل:

### 1. نظرة عامة

تركيب الأسطول على المستوى الأعلى.

| المؤشر الرئيسي للأداء | ما يعرضه                                                        |
| --------------------- | ---------------------------------------------------------------- |
| **الإجمالي**          | جميع المركبات المسجلة                                          |
| **نشط**               | المتاحة للركاب لاستئجارها الآن                                 |
| **خامل**              | غير مستخدمة حالياً (قد تكون متاحة أو منخفضة الاستخدام)         |
| **خارج الخدمة**       | في الصيانة / التخزين / غير جاهزة — لا تحقق إيرادات             |
| **مفقودة / مسروقة**   | الحالة = مسروقة، أو غير متصلة لفترة أطول من الحد المسموح      |

استخدم هذا القسم كنظرة سريعة رئيسية على الأسطول.

### 2. الأداء

مدى كفاءة أسطولك في **تحقيق الأرباح** لك.

| المؤشر الرئيسي للأداء       | ما يعرضه                                              |
| --------------------------- | ---------------------------------------------------- |
| **المركبات المربحة**        | المركبات التي أكملت رحلة واحدة على الأقل خلال الفترة |
| **المركبات الخاملة**        | المركبات النشطة بدون رحلات (هدر)                      |
| **الرحلات لكل مركبة**       | متوسط الرحلات لكل مركبة خلال النطاق                   |
| **نسبة الاستخدام**          | ساعات الإيجار / ساعات التوفر (المعيار الصناعي: 5-15%) |

الخمول ضمن المركبات النشطة هو الأسوأ — يكلفك نفقات تشغيلية دون إنتاج.

### 3. البطارية

صحة البطارية عبر الأسطول.

| المؤشر / المخطط       | ما يعرضه                                                                   |
| --------------------- | ------------------------------------------------------------------------- |
| **المستوى المتوسط**   | متوسط نسبة البطارية عبر جميع المركبات حالياً                              |
| **حرج**              | عدد المركبات تحت العتبة الحرجة (10-20%)                                  |
| **اتجاه المتوسط**     | متوسط البطارية خلال النطاق — الانخفاض = تبديلات البطارية غير كافية       |
| **التوزيع**           | مخطط تكراري للمركبات حسب فئة البطارية (0-20 / 20-40 / 40-60 / 60-80 / 80-100) |
| **التبديلات**          | عدد عمليات تبديل البطارية خلال النطاق                                     |

إذا كان المتوسط ينخفض والحرج يرتفع، فإن فريق الميدان يتأخر — جدولة المزيد من التبديلات.

### 4. المشاكل

التنبيهات والمشاكل التشغيلية التي تم الإبلاغ عنها ضد الأسطول.

| المؤشر الرئيسي للأداء | ما يعرضه                                                  |
| --------------------- | ---------------------------------------------------------- |
| **التنبيهات**         | إجمالي التنبيهات خلال النطاق                               |
| **أنواع التنبيهات**   | تفصيل حسب النوع (بطارية / اتصال / ميكانيكي / إلخ)        |
| **حرجة**              | التنبيهات ذات الخطورة الحرجة                               |
| **الصيانة**           | المركبات في حالة الصيانة حالياً                             |
| **غير متصل**          | المركبات التي لم يبلغ جهاز إنترنت الأشياء الخاص بها لفترة أطول من الحد |

اقترن هذا القسم مع تحليلات [الأحداث الأخيرة](events.md) لعرض كل حدث على حدة.

### 5. الاتجاهات

مخطط زمني يظهر كيف تغير عدد المركبات **النشطة** خلال النطاق. الانخفاض عادة يعني تغيير حالة جماعي (نقل إلى الصيانة، الطقس، استدعاء).

### 6. حسب النوع

تفصيل حسب **نوع المركبة** (سكوتر / دراجة / دراجة كهربائية / إلخ). لكل نوع: العدد، نسبة الأرباح، نسبة الاستخدام، معدل التنبيهات.

إذا كان نوع واحد يهيمن على معدل التنبيهات، فالمشكلة في **النموذج** — وليس في فريق العمليات.

### 7. حسب المنطقة

تفصيل حسب **المنطقة**. لكل منطقة: عدد المركبات، نسبة الاستخدام، معدل المشاكل.

المناطق ذات الاستخدام المنخفض والمخزون العالي = **فرصة لإعادة التوازن** (انظر أيضاً [تحليلات إعادة التوازن](../../operations/rebalance/runs.md)).

## سير العمل النموذجي

- **مراجعة أسبوعية للأسطول** — نظرة عامة → الأداء (اتجاه الاستخدام) → البطارية (هل هناك زيادة في الحالات الحرجة؟) → المشاكل (ارتفاع التنبيهات) → الاتجاهات (هل هناك انخفاض غير مفسر في النشط؟)
- **تنظيف المركبات الخاملة** — الأداء → عدد الخاملين → إذا كان العدد يتزايد، حدد المركبات المخالفة عبر [قائمة المركبات](../../operations/fleet/vehicles.md) وتحقق من الحالة / الموقع
- **حالة طوارئ البطارية** — قسم البطارية → ارتفاع الحالات الحرجة + انخفاض المتوسط → دفع فريق الميدان للعمل
- **كشف النموذج السيئ** — قسم حسب النوع → أي نوع لديه أسوأ معدل تنبيهات → النظر في إيقافه أو التفاوض مع الشركة المصنعة
- **إعادة التوازن** — قسم حسب المنطقة → مناطق منخفضة الاستخدام + مخزون عالي → جدولة إعادة توزيع
- **التخطيط قبل الوردية** — الاتجاهات + الأنماط من [الأحداث](events.md) → أي الأيام / الساعات تحتاج إلى مزيد من الموظفين في الميدان؟

## نصائح

- **نشط + خامل + خارج الخدمة + مفقود/مسروق = الإجمالي** — عندما لا تتطابق الحسابات، تكون الحالات في مرحلة انتقالية؛ قم بالتحديث أو اختر تاريخًا مستقرًا
- **نشط ≠ يحقق أرباحًا** — المركبة "نشطة" إذا كان يمكن تأجيرها؛ "يحقق أرباحًا" تعني أنها كانت مؤجرة فعليًا. قارن بين هذين
- **الاستخدام فوق 25% غير صحي** — لا يستطيع الركاب العثور على المركبات عند حاجتهم لها؛ فكر في زيادة المخزون في تلك المنطقة
- **الاستخدام تحت 5% هو وزن ميت** — تكلفة إبقاء تلك المركبة في الخدمة تتجاوز أرباحها؛ أعد التوازن أو اسحبها
- **بطارية حرجة + الاتجاه المتوسط** — كلاهما معًا هو نظام الإنذار المبكر الخاص بك؛ واحد فقط هو ضوضاء
- **المفقود / المسروق حالة ثابتة** — يتطلب تغيير الحالة يدويًا للتصحيح؛ استرجع "مسروق" قبل الاحتفال بإعادته
- **حسب النوع وحسب المنطقة معًا** — أحيانًا يفشل نوع ما في منطقة واحدة فقط (عدم توافق التضاريس)؛ التقاطع يكشف ذلك
