# السمات

لوحة التحكم تحتوي على ثلاث إعدادات مظهر مستقلة:

- **الوضع** — فاتح، داكن، أو متابعة نظام التشغيل
- **اللون** — لون التمييز المستخدم للأزرار، الروابط، الشارات، والحالات النشطة
- **نمط الخريطة** — بلاطات الخريطة الأساسية (اختيار منفصل للوضع الفاتح والداكن)

كل الثلاثة موجودة في **ورقة الملف الشخصي** في الأسفل — انقر على صورتك الرمزية في الشريط العلوي لفتحها.

## الوضع (فاتح / داكن / النظام)

التبديل بين ثلاثة أوضاع:

| الأيقونة    | الوضع   | السلوك                                                        |
| ---------- | ------ | ------------------------------------------------------------- |
| 🖥️ شاشة    | النظام | يتبع تفضيل نظام التشغيل؛ يتغير تلقائيًا عند تغيير النظام |
| ☀️ شمس     | فاتح   | دائمًا فاتح، يتجاهل نظام التشغيل                            |
| 🌙 قمر     | داكن   | دائمًا داكن، يتجاهل نظام التشغيل                            |

الوضع **النظام** هو الافتراضي. إذا قمت بتغيير سمة نظام التشغيل (مثل الوضع الداكن المجدول في macOS عند الغروب)، تتبع لوحة التحكم ذلك فورًا — بدون إعادة تحميل.

## نمط الخريطة

الصفحات التي تعرض خرائط (الخريطة الحية، تفاصيل المركبة، محرر المنطقة، مسار الرحلة، إلخ) تستخدم نمط خريطة أساسي يمكنك اختياره بشكل مستقل. تحتفظ لوحة التحكم بـ **تفضيلين منفصلين لنمط الخريطة** — واحد للوضع الفاتح، وآخر للوضع الداكن — بحيث تتطابق الخريطة مع بقية واجهة المستخدم عند تبديل الأوضاع.

- التبديل بين الوضع (فاتح ↔ داكن) يغير تلقائيًا إلى نمط الخريطة الذي اخترته لذلك الوضع
- الأنماط المتاحة تعتمد على مزود الخريطة الخاص بك (MapTiler أو بديل)؛ عادة: الشوارع، القمر الصناعي، الفاتح، الداكن، الخارجي

## مكان تخزين التفضيلات

كل الإعدادات الثلاثة مخزنة في **localStorage** لمتصفحك تحت هذه المفاتيح:

| الإعداد           | مفتاح التخزين         |
| ----------------- | --------------------- |
| الوضع             | `app-dark-mode`       |
| اللون             | `app-theme`           |
| نمط الخريطة (فاتح) | `app-map-style-light` |
| نمط الخريطة (داكن)  | `app-map-style-dark`  |

وهذا يعني:

- **لكل جهاز، لكل متصفح** — جهاز مختلف = تفضيلات مختلفة
- **غير متزامنة** مع حسابك — الزملاء الذين يستخدمون نفس الحساب يرون سماتهم الخاصة
- **تمسح عند "مسح بيانات التصفح"** لهذا الموقع
- **نوافذ التصفح الخفي** تبدأ بالإعدادات الافتراضية

## نصائح

- **ابدأ بوضع النظام** — دع جدول نظام التشغيل يقرر؛ انتقل إلى الفاتح/الداكن فقط إذا كان لديك تفضيل مختلف عن النظام
- **طابق نمط الخريطة مع الوضع** — القمر الصناعي صعب القراءة في الوضع الداكن؛ اختر نمط "داكن" أو "شوارع داكنة" بدلاً منه
- **اللون يؤثر على التباين** — الأصفر أو السماوي على خلفية فاتحة قد يكون صعب القراءة؛ إذا بدت الأزرار "رقيقة"، جرب لون تمييز أغمق (أحمر، أزرق، نيلي)
- **السمة ليست إذنًا** — يمكن لكل مشغل اختيار سمة خاصة به؛ الزملاء لن يروا تغييراتك
