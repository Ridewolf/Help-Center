# العملاء — القائمة

قائمة العملاء (`/clients`) هي قاعدة بيانات عملائك: كل شخص قام بتسجيل حساب مع خدمتك، مع رصيده، العلامات، ملخص تاريخ الرحلات، وقنوات الاتصال.

للعمل على كل عميل على حدة (التاريخ الكامل، إجراءات الرصيد، الأجهزة، التعليقات) افتح [صفحة تفاصيل العميل](client-detail.md).

الصلاحية المطلوبة: **العملاء** (`e4f5h6`). صلاحيات فرعية إضافية تتحكم في إجراءات الصفوف والإجراءات الجماعية المحددة.

## كيف يظهر العملاء هنا

عادةً لا تقوم بإنشاء العملاء في لوحة التحكم — بل يقومون بالتسجيل عبر تطبيق الراكب على الهاتف المحمول:

1. يقوم الشخص بتثبيت **تطبيق رايدوولف للراكب** ويسجل (هاتف أو بريد إلكتروني)
2. يقوم النظام الخلفي بإنشاء سجل عميل؛ يظهر الصف هنا بحالة **جارٍ التسجيل** أثناء التحقق (رسالة نصية، هوية، طريقة دفع)
3. بعد اكتمال التحقق تتحول الحالة إلى **نشط** — يمكن للعميل القيام بالرحلات
4. يمكن للمشغلين إنشاء العملاء يدويًا (مثلاً للحسابات المميزة أو التجريبية) عبر `+ إنشاء` — مغطى في مقال _إنشاء_

تتجدد القائمة عند إعادة التحميل أو تغيير الفلاتر.

## الفلاتر

| الفلتر     | النوع         | الملاحظات                                                      |
| ---------- | ------------ | -------------------------------------------------------------- |
| بحث        | نص           | يبحث في الاسم، الهاتف، البريد الإلكتروني، معرف العميل         |
| نطاق التاريخ | تقويم       | يفلتر حسب **تاريخ التسجيل**؛ من / إلى                          |
| الحالة     | قائمة منسدلة | `نشط` / `محظور` / `مجمّد` / `جارٍ التسجيل` (أو `الكل`)         |
| العلامات   | اختيار متعدد | يفلتر حسب العلامات المطبقة على العميل                           |

جميع الفلاتر تعمل معًا باستخدام AND. تظهر رقائق الفلترة فوق الجدول؛ وتعكس عنوان URL الحالة الحالية.

## الأعمدة

| العمود        | قابل للفرز؟ | المحتوى                                                                       |
| ------------- | --------- | ----------------------------------------------------------------------------- |
| **العميل**    | ✓         | صورة رمزية + الاسم الأول/الأخير + الهاتف أو البريد الإلكتروني؛ رابط لصفحة تفاصيل العميل |
| **القنوات**   | —         | أيقونات لقنوات الاتصال التي تحقق منها العميل (هاتف، بريد إلكتروني، اجتماعي) |
| **الرصيد**    | ✓         | رصيد المحفظة بعملة الشركة، يظهر باللون الأحمر عند السالب                      |
| **العلامات**  | —         | العلامات المطبقة على هذا العميل                                               |
| **الحالة**    | ✓         | شريط الحالة (انظر المرجع أدناه)                                               |
| **التقييم**   | ✓         | متوسط التقييم الذي تركه الركاب لهذا العميل (تقييم السائق)                     |
| **الرحلات**   | ✓         | عدد الرحلات طوال العمر                                                        |
| **آخر رحلة**  | ✓         | آخر مرة قام العميل برحلة                                                      |
| **الدفع**    | —         | أيقونة طريقة الدفع الافتراضية (بطاقة، محفظة، إلخ)                            |

يمكن الفرز بالنقر على رأس عمود قابل للفرز. الفرز جزء من عنوان URL.

## مرجع الحالة

| الحالة          | المعنى                                                                              |
| --------------- | ------------------------------------------------------------------------------------ |
| **نشط**         | تم التحقق منه بالكامل، يمكنه القيام بالرحلات، يمكن تحصيل رسوم منه                   |
| **محظور**       | لا يمكنه القيام بالرحلات؛ حظر من المشغل (احتيال، إساءة، دين) أو من النظام           |
| **مجمّد**       | الحساب متوقف مؤقتًا (مثلاً أثناء التحقيق في نزاع، أو بناءً على طلب العميل)          |
| **جارٍ التسجيل**| التسجيل قيد التنفيذ — الهاتف / البريد الإلكتروني / الهوية / طريقة الدفع لم تُتحقق بعد |

## إجراءات الصف

لكل صف **قائمة ثلاث نقاط** على اليمين. تعتمد الإجراءات المتاحة على صلاحياتك:

| الإجراء             | الصلاحية           | ما يقوم به                                                                        |
| ------------------- | ------------------ | --------------------------------------------------------------------------------- |
| **عرض الملف الشخصي** | —                  | فتح [صفحة تفاصيل العميل](client-detail.md)                                     |
| **تاريخ الرحلات**   | —                  | فتح عرض رحلات العميل (جزء مركز من قائمة الرحلات العامة)                         |
| **إرسال رسالة نصية**| —                  | فتح مربع حوار لإرسال رسالة نصية إلى هاتف العميل الذي تم التحقق منه               |
| **إرسال بريد إلكتروني** | —              | فتح مربع حوار لإرسال بريد إلكتروني إلى عنوان العميل الذي تم التحقق منه           |
| **إرسال إشعار**     | —                  | فتح مربع حوار لإرسال إشعار دفع إلى تطبيق العميل                                 |
| **شحن الرصيد**      | `topup-manual`                | فتح مربع حوار الرصيد — إضافة أموال إلى محفظة العميل                              |
| **فرض غرامة**       | `fine`                | فتح مربع حوار الغرامة — خصم أموال من المحفظة (لأضرار، وقوف، إلخ)                |
| **حظر / إلغاء الحظر**| `block` / `unblock`         | فتح مربع حوار الحظر — تبديل حالة الحظر للعميل مع سبب اختياري                      |
| **تحرير**           | `edit`                | فتح [نموذج التحرير](client-create-edit.md)                                      |
| **حذف**             | `delete`                | حذف العميل بشكل ناعم (مع تأكيد؛ عنصر مدمر باللون الأحمر)                         |

الإجراءات التي لا تملك صلاحياتها مخفية من القائمة.

## الإجراءات الجماعية

اختر عميلًا واحدًا أو أكثر باستخدام مربعات الاختيار على اليسار. تظهر **شريط الإجراءات الجماعية** في الأعلى مع عدد المحددين والإجراءات:

| الإجراء الجماعي       | الإذن               | ما يقوم به                                                             |
| ----------------- | ------------------- | ------------------------------------------------------------------------ |
| **إضافة رصيد**   | `topup-manual`      | إضافة مبلغ واحد إلى كل محفظة مختارة (مع تأكيد)      |
| **خصم مبلغ** | `fine`              | خصم مبلغ واحد من كل محفظة مختارة (مثلاً غرامة عامة للحدث)  |
| **تغيير الحالة** | `block` / `unblock` | تعيين نفس الحالة لكل عميل مختار (نشط / محظور / مجمد) |
| **إرسال إشعار**     | —                   | إرسال إشعار دفع لكل عميل مختار دفعة واحدة                |

توجهك نوافذ الحوار الجماعية خلال تحديد المبلغ / الرسالة / الحالة، ثم تطبقها على كل الصفوف المختارة في عملية واحدة مع تأكيد نهائي.

## إجراءات الصفحة (أعلى اليمين)

- **+ إنشاء** — يفتح [نموذج إنشاء العميل](client-create-edit.md) (مقال منفصل)

## سير العمل النموذجي

- **التحقيق في شكوى دفع** — البحث بالهاتف أو البريد الإلكتروني → فتح التفاصيل → التحقق من الرصيد وتاريخ الرحلات
- **شحن المحفظة بناءً على طلب المشغل** — إيجاد العميل، _شحن الرصيد_ من قائمة الصف، إدخال المبلغ، تأكيد
- **حظر محتال** — البحث عن العميل → _حظر / إلغاء الحظر_ → تعيين محظور مع السبب؛ تتغير الحالة إلى _محظور_، لا يمكنه القيام برحلات
- **إرسال رسالة انقطاع الخدمة** — تصفية حسب علامة المنطقة → _تحديد الكل_ → _إرسال إشعار_ (أو استخدام التسويق → الرسائل النصية للبث غير العاجل)
- **تدقيق حاملي علامة** — تصفية حسب علامة، فحص الرصيد وعدد الرحلات للبحث عن الحالات الشاذة

## نصائح

- **الحالة هي الحارس الصامت** — العملاء في _تسجيل_ / _مجمد_ / _محظور_ لا يمكنهم القيام برحلات؛ لا تتوقع رؤيتهم في قائمة الرحلات
- **أيقونات القنوات تخبرك بما تم التحقق منه** — غياب أيقونة البريد الإلكتروني يعني أن الرسائل النصية هي القناة الوحيدة للخروج لذلك العميل
- **التقييم هو تقييم الراكب للعميل** (ليس الرحلة) — التقييمات المنخفضة غالباً ما تعني مشاكل في الوقوف أو سلوك غير لائق؛ تحقق من إثباتات الوقوف والتذاكر
- **تحول الرصيد إلى الأحمر** = المحفظة سالبة. لا يمكن للعميل بدء رحلات جديدة حتى يتم شحن الرصيد أو استرداده
- **الأذونات متعددة الطبقات** — قد تتمكن من _إرسال رسالة نصية_ لكن لا يمكنك _شحن_ نفس العميل؛ القائمة تظهر ما يمكنك فعله
- **الرابط قابل للمشاركة** — انسخ عرضاً مفلترًا (مثلاً _العملاء المحظورون مع رحلات > 0_) وأرسله لزميل
