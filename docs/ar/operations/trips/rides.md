# الرحلات — القائمة

**الرحلة** هي رحلة واحدة يقوم بها العميل على إحدى مركباتك. قائمة الرحلات (`/rides`) هي السجل الرئيسي لكل رحلة — الماضية، الحالية، والقادمة — عبر الأسطول بأكمله.

افتح صفًا لرؤية [صفحة تفاصيل الرحلة](ride-detail.md) مع المسار، الجدول الزمني، وجميع الإجراءات.

الصلاحية المطلوبة: **الرحلات** (`i1j2k3`).

## كيف تظهر الرحلات هنا

لا تقوم بإنشاء الرحلات في لوحة التحكم — فهي تنشأ من جانب العميل:

1. يقوم العميل **بفتح قفل المركبة** في تطبيق الهاتف المحمول (تطبيق Ridewolf rider)
2. يقوم النظام الخلفي بفتح سجل رحلة جديد مرتبط بتلك المركبة والعميل
3. تظهر الرحلة في هذه القائمة فورًا بحالة **نشط**
4. عندما يقوم العميل **بقفل / ركن** المركبة، يغلق النظام الخلفي الرحلة؛ تتغير الحالة إلى **مكتمل** ويتم حساب التفاصيل النهائية (المسافة، المدة، السعر)
5. الحالات النهائية الأخرى (`ملغى`، إلخ) تأتي من قواعد النظام أو إجراءات المشغل

قم بتحديث الصفحة أو إعادة زيارتها لسحب أحدث لقطة — يتم تحديث الرحلات النشطة مع تحرك العميل.

## الترتيب الافتراضي

بشكل افتراضي، يعرض النظام الخلفي **الرحلات النشطة أولاً**، ثم الرحلات المكتملة بترتيب زمني عكسي (الأحدث أولاً). طبق فرز عمود لتجاوز هذا الترتيب الافتراضي.

## الفلاتر

| الفلتر    | النوع        | ملاحظات                                                              |
| ---------- | ------------ | -------------------------------------------------------------------- |
| بحث       | نص           | يبحث في اسم العميل، تسمية المركبة، معرف الرحلة                      |
| نطاق التاريخ | تقويم      | اختيار من / إلى؛ الافتراضي "كل الوقت"                              |
| الحالة    | قائمة منسدلة | `نشط`، `مكتمل`، `ملغى`، إلخ                                         |
| التقييم   | قائمة منسدلة | فلترة حسب تقييم النجوم الذي يتركه الراكب (1–5، _بدون تقييم_)         |
| العلامات  | اختيار متعدد | فلترة حسب علامات الرحلة (موروثة من المركبة — انظر الأعمدة أدناه)    |

تُدمج كل الفلاتر باستخدام AND. تظهر شرائح الفلتر فوق الجدول؛ وتعكس URL حالة الفلتر الحالية.

## الأعمدة

| العمود   | قابل للفرز؟ | المحتوى                                                            |
| -------- | ----------- | ------------------------------------------------------------------ |
| العميل  | —           | صورة رمزية، الاسم، رابط إلى ملف العميل                            |
| المركبة | —           | التسمية، الطراز، رابط إلى المركبة                                 |
| التعريفة | —          | اسم التعريفة المطبقة على الرحلة                                  |
| الإحصائيات | —         | شارات سريعة: المسافة، المدة، التكلفة الإجمالية                    |
| العلامات | —          | علامات موروثة من **المركبة** عند بدء الرحلة                       |
| الحالة  | ✓           | حبة الحالة (نشط، مكتمل، ملغى، إلخ)                               |
| التقييم | ✓           | تقييم النجوم الذي يتركه الراكب (أو "–" إذا لم يوجد)              |
| الإنشاء | ✓           | تاريخ ووقت بدء الرحلة؛ الفرز الافتراضي = الأحدث أولاً            |

قم بالفرز بالنقر على رأس عمود قابل للفرز. الفرز المختار جزء من URL و**يتجاوز** الترتيب الافتراضي الموضح أعلاه — لا يوجد نقرة ثالثة لـ"استعادة الافتراضي"، لكن يمكنك مسح الفرز بتحرير URL أو التحديث بدون معامل فرز.

> **العلامات موروثة من المركبة.** لا تمتلك الرحلات محرر علامات خاص بها — علامات الرحلة هي لقطة من العلامات التي كانت على المركبة عند بدء الرحلة. عدّل علامات المركبة لاحقًا وستحتفظ الرحلات الحالية بلقطتها الأصلية؛ فقط الرحلات الجديدة تلتقط العلامات الجديدة.

## إجراءات الصف

كل صف يحتوي على **قائمة ثلاث نقاط** على اليمين. تعتمد الإجراءات المتاحة على حالة الرحلة وصلاحياتك:

| الإجراء       | الصلاحية       | متى يكون مُمكّنًا                                              |
| ------------ | -------------- | ------------------------------------------------------------- |
| **إيقاف مؤقت** | `pause-unpause` | الرحلة **نشطة** (ليست موقوفة مسبقًا، مكتملة، ملغاة)           |
| **استئناف**   | `pause-unpause` | الرحلة **موقوفة مؤقتًا**                                       |
| **إنهاء الرحلة** | `end-ride`  | الرحلة **ليست** مكتملة أو ملغاة                               |

الإجراءات التي لا تملك صلاحية لها مخفية. تظهر الإجراءات المعطلة (مثل إنهاء رحلة مكتملة مسبقًا) باللون الرمادي حتى تتمكن من رؤية ما هو ممكن في الحالة الصحيحة.

مجموعة الإجراءات الكاملة — استرداد، عرض المسار على الخريطة، إرسال إشعار، أرشفة — موجودة في **صفحة تفاصيل الرحلة**. انقر على الصف للوصول إليها.

## إجراءات الصفحة

في أعلى يمين صفحة القائمة:

- **تصدير** — تحميل القائمة المفلترة حاليًا كملف (يتم احترام الفلاتر والفرز)

## سير العمل النموذجي في القائمة

- **مراقبة النشاط المباشر** — افتح الصفحة وابقَ عليها؛ يعرض أعلى القائمة الرحلات النشطة
- **البحث عن رحلات في منطقة أو نافذة زمنية** — اجمع بين نطاق التاريخ + الحالة + العلامات
- **رصد الشذوذات** — فلتر حسب `الحالة = ملغى` أو `التقييم ≤ 2` وابحث عن أنماط (نفس المركبة؟ نفس وقت اليوم؟)
- **إيقاف رحلة عالقة بسرعة** — دون مغادرة القائمة، افتح قائمة الصف واختر _إنهاء الرحلة_ (يتطلب صلاحية)

## نصائح

- **الرابط قابل للمشاركة** — فلتر القائمة، انسخ الرابط، أرسله لزميل — يحصل على نفس العرض
- **شارات الإحصائيات في القائمة** طريقة سريعة لرصد الرحلات القصيرة أو الطويلة بشكل غير عادي قبل النقر
- **لا تثق بالتقييم وحده** — افتح صفحة التفاصيل للرحلات منخفضة التقييم؛ التقييم هو إشارة واحدة من عدة إشارات
- **الصلاحيات تختلف حسب الشركة** — بعض المشغلين يرون فقط الرحلات للمركبات التي يديرونها؛ إذا كانت رحلة مفقودة لديك، تحقق مع المسؤول
