# إعادة التوازن — المناطق الميتة

صفحة المناطق الميتة (`/rebalance/dead-zones`) هي **لوحة استهداف عمليات الميدان**: حيث يجلس مخزونك خاملاً، كم من الإيرادات يخسرها ذلك، وأي المناطق يجب إرسال شاحنة إعادة التوازن إليها بعد ذلك.

على عكس صفحة [Analytics — Rebalance](runs.md) التي تلخص نشاط فريق الميدان مع مرور الوقت، هذه الصفحة تتطلع إلى الأمام: تجيب على سؤال _إلى أين نذهب الآن؟_

الصلاحية المطلوبة: مشغل مسجل الدخول (المسار يفرض فقط _requiresAuth_، بدون معرف صلاحية محدد).

## ماذا يعني "المنطقة الميتة"

**المنطقة الميتة** هي منطقة في المدينة تقضي فيها المركبات وقتًا طويلاً متوقفة دون أن يتم استئجارها. تحدد الصفحة هذه المناطق وترتبها حتى يعرف فريق الميدان أي التجمعات يجب تفكيكها أولاً.

يدعم النظام طريقتين لتقسيم الخريطة:

- **مناطق المالك** — مضلعاتك المكونة من [الإعدادات — المناطق](../../settings/infrastructure/zones.md)
- **شبكة H3** — تقسيم سداسي من Uber، يستخدم لتحليل أدق أو مستقل عن المناطق

المفتاح موجود في كتلة الفلاتر؛ الجدول يعرض نفس الأعمدة في كلتا الحالتين.

## صف مؤشرات الأداء الرئيسية (أعلى)

صف من خمس بطاقات مؤشرات أداء تلخص وضع المناطق الميتة عبر ما قمت بتصفية عرضه.

| مؤشر الأداء الرئيسي | ما يعرضه                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------ |
| **المناطق الميتة**  | عدد المناطق / الخلايا المصنفة حالياً كمناطق ميتة                                         |
| **الخسارة / يوم**   | الإيرادات المفقودة المقدرة يومياً — مجموع `lostRevenuePerDay` عبر المناطق المصفاة                        |
| **الأجهزة المحاصرة**| إجمالي الأجهزة الخاملة المحاصرة داخل المناطق الميتة — هدف الاستلام المادي الخاص بك       |
| **متوسط البقاء**    | متوسط وقت البقاء (بالدقائق) عبر المناطق الميتة — مدة جلوس المركبة قبل التحرك             |
| **التقدم الأسبوعي**| نسبة التغير مقارنة بالأسبوع الماضي — السالب = تدهور الوضع؛ الموجب = تحسن              |

تتحدث كل مؤشرات الأداء مع الفلاتر؛ استخدمها كفحص سريع برقم واحد قبل التعمق في القائمة.

## أوضاع العرض — الخريطة مقابل الجدول

مفتاح في الأعلى يمين يبدل بين عرضين لنفس البيانات:

- **الخريطة** — عرض جغرافي للمناطق الميتة مغطى على المدينة (حالياً عنصر نائب _قريباً_)
- **الجدول** — شبكة البيانات أدناه، مع كل الأعمدة وسياق كل صف

تطبق الفلاتر على كلا العرضين. _الجدول_ هو الافتراضي؛ _الخريطة_ مفعلة لكن العرض الجغرافي لا يزال قيد الإنشاء.

مفتاح _التحديث التلقائي_ بجانب مفتاح العرض — فعّله لإعادة استدعاء البيانات على فترات (مفيد للعمليات الحية).

## الفلاتر

كتلة الفلاتر بها أربعة عناصر تحكم؛ جميعها تعمل معًا باستخدام AND:

| الفلتر        | النوع    | ملاحظات                                                                                 |
| ------------- | -------- | --------------------------------------------------------------------------------------- |
| **المدينة**   | قائمة منسدلة | _كل المدن_ / _موسكو_ / _سانت بطرسبرغ_ — تضييق إلى مدينة تشغيل واحدة                  |
| **الشدة**     | قائمة منسدلة | _الكل_ / _منخفض_ / _متوسط_ / _مرتفع_ / _حرج_ — بناءً على درجة شدة المنطقة             |
| **نوع المنطقة**| قائمة منسدلة | _مناطق المالك_ / _شبكة H3_ — أي تقسيم تستخدم                                      |
| **بحث**      | نص       | نص حر — يطابق اسم المنطقة / الحي                                                      |

زر _مسح الكل_ على يمين بطاقة الفلاتر يعيد تعيين كل عناصر التحكم بنقرة واحدة.

## الأعمدة

عرض الجدول يحتوي على تسعة أعمدة. انقر على صف لفتح درج معلومات المنطقة (يعرض حالياً إشعارًا باسم المنطقة كعنصر نائب).

| العمود               | المحتوى                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **المنطقة / الخلية** | اسم المنطقة بالإضافة إلى المدينة والحي تحتها؛ في وضع H3 هذا هو معرف السداسي                   |
| **نسبة الخمول**      | نسبة الوقت الذي كانت فيه الأجهزة خاملة في المنطقة، ملونة: أخضر `< 25%`، كهرماني `25–40%`، أحمر `≥ 40%` |
| **مدة البقاء**       | متوسط مدة البقاء بالدقائق، مع _p90_ تحتها                                                     |
| **متوسط الأجهزة الخاملة** | متوسط عدد المركبات الخاملة في المنطقة، مع _الهدف_ للمقارنة                                   |
| **البدايات**         | بدايات الرحلات في المنطقة خلال _آخر 24 ساعة_ / _آخر 7 أيام_ / _آخر 30 يومًا_                  |
| **التحويل**          | البدايات لكل جهاز خامد في الساعة — أخضر `≥ 0.30`، كهرماني `0.15–0.30`، أحمر `< 0.15`                 |
| **الإمداد الزائد**    | الأجهزة فوق الهدف — إيجابي = كثير جدًا، سلبي = قليل جدًا؛ الإيجابي يظهر بالأحمر                 |
| **الخسارة / يوم**    | الإيرادات المفقودة المقدرة لهذه المنطقة فقط                                                    |
| **آخر مرة شوهدت فيها خاملة** | متى كانت المنطقة تحتوي آخر مرة على أجهزة خاملة — منسقة حسب لغتك المحلية                      |

الصفوف قابلة للنقر؛ فرز الأعمدة غير مفعّل بعد في هذه النسخة.

## إجراءات الصف

لكل صف معالج نقر يعرض حالياً إشعارًا باسم المنطقة. قائمة **الإجراءات (لكل صف)** كاملة مطبقة في الكود لكنها معطلة حالياً بانتظار API. الإجراءات المخططة مدرجة أدناه للرجوع إليها — ستظهر في قائمة ثلاث نقاط على أقصى يمين كل صف عند تفعيلها:

| الإجراء المخطط           | ما الذي سيفعله                                                          |
| ------------------------ | ------------------------------------------------------------------------ |
| **إنشاء تشغيل**          | فتح منشئ تشغيل إعادة التوازن مع تعبئة هذه المنطقة مسبقًا                 |
| **تعيين حد وقت الوقوف**  | تضييق الحد الأقصى لوقت الوقوف داخل المنطقة                             |
| **التسعير الديناميكي**   | تطبيق رافعات السعر لجذب / تثبيط الرحلات التي تبدأ أو تنتهي هنا          |
| **تعديل المنطقة**        | تحرير حدود المنطقة (تقسيم، دمج، إعادة تشكيل)                            |
| **تعيين عدم الوقوف**     | تحويل المنطقة إلى منطقة عدم وقوف لدفع المركبات للخروج                   |
| **خفض هدف العرض**        | خفض هدف الأجهزة حتى يتوقف النظام عن إرسال المركبات إلى هنا             |
| **تجربة A/B**            | إعداد تجربة محكمة على استراتيجية المعالجة                              |

حتى يتم إطلاق نقطة النهاية، اعتبر الجدول كـ **سطح رؤية للبيانات للقراءة فقط** — استخدمه مع قائمة المركبات لتنفيذ الإجراءات على المركبات بشكل فردي.

## حالات الفراغ / التحميل

- **جارٍ التحميل** — مؤشر دوران مع "جارٍ تحميل المناطق الميتة…" أثناء استعلام الخلفية
- **خطأ** — لافتة _تنبيه_ مع زر _حاول مرة أخرى_ إذا فشل الطلب
- **فارغ** — أيقونة _مثلث تنبيه_ في الوسط مع نص "لا توجد مناطق ميتة"؛ هذه هي **الحالة المتوقعة اليوم** لأن نقطة النهاية لا تعيد بيانات

## سير العمل النموذجي

- **التخطيط الصباحي** — فرز الجدول حسب _المفقود / يوم_ (مرئيًا، اليوم؛ أعمدة قابلة للفرز قادمة): اختر أفضل 3 مناطق لتعيينها لتشغيل اليوم
- **فرز حسب الشدة** — تصفية _الشدة = حرج_ لرؤية أسوأ المخالفين فقط، ثم فتح كل منطقة للسياق
- **العمليات حسب المدينة** — تصفية حسب _المدينة_ عند تشغيل عمليات متعددة المدن؛ مراجعة العدد والإيرادات المفقودة بشكل منفصل
- **المقارنة مع الأسطول** — استخدم رقم _الأجهزة المحاصرة_ من صف مؤشرات الأداء الرئيسية، ثم انتقل إلى [قائمة المركبات](../fleet/vehicles.md) مصفاة حسب المنطقة لرؤية المركبات الفعلية
- **الاقتران مع التحليلات** — قارن العدد المباشر هنا مع أقسام المناطق الميتة / الأجهزة الخاملة في [التحليلات — إعادة التوازن](runs.md) و[تحليلات المركبات](../../analytics/reports/vehicles.md) لتأكيد الاتجاه

## نصائح

- **التحويل هو العمود الأكثر عملية** — تحويل منخفض (أحمر) مع فائض عرض مرتفع يعني أن إعادة توازن المنطقة _لن تساعد_؛ لديك العرض الصحيح لكن الطلب غير موجود
- **نسبة الخمول مقابل متوسط الأجهزة الخاملة** — _نسبة الخمول_ محسوبة بالوزن الزمني (كم مرة تكون المنطقة خاملة)، _متوسط الأجهزة الخاملة_ محسوب بالعدد (كم عدد الأجهزة الموجودة هناك). وجود كلاهما باللون الأحمر = أقوى إشارة لمنطقة ميتة
- **الـ _الهدف_ تحت _متوسط الأجهزة الخاملة_ يأتي من تكوين المنطقة** — إذا تم تعيينه بشكل خاطئ، ستبدو كل منطقة ميتة؛ تحقق من [الإعدادات — المناطق](../../settings/infrastructure/zones.md)
- **شبكة H3 مفيدة للمدن غير المحددة مناطقها** — عندما لم تحدد مناطق المشغل بعد، توفر H3 دلوًا جغرافيًا افتراضيًا
- **التقدم الأسبوعي هو مؤشر "هل ننجح" في الصفحة** — إذا زاد عدد المناطق الميتة لكن الإيرادات المفقودة انخفضت، فهذا يعني أن فريق الميدان يعمل على المناطق ذات القيمة الأعلى أولاً (علامة جيدة)
- **معالجات الإجراءات هي نماذج أولية** — النقر على صف يشغل فقط إشعار معلومات الآن؛ ستصل الأدراج / الحوارات الفعلية عندما يكون الخلفية جاهزة
