# إعادة التوازن — الرحلات

صفحة رحلات إعادة التوازن (`/rebalance/runs`) هي **سجل العمليات لكل رحلة إعادة توازن**: من قاد أي شاحنة، من أي مستودع انطلقت، عدد السكوترات والبطاريات على متنها، ما إذا كانت في الوقت المحدد، وأين حدثت المشاكل.

**الرحلة** هي عمل ميداني لوردية واحدة — سائق، شاحنة، مستودع الأصل، قائمة مرتبة من التوقفات، ونافذة ETA مخططة. تتيح الصفحة للمشغلين مراقبة الرحلات النشطة ومراجعة المكتملة.

تعرض هذه الصفحة تفاصيل كل رحلة على حدة، مكملةً ملخص [Analytics — Rebalance](runs.md) على مستوى أعلى ولوحة [Rebalance — Dead Zones](dead-zones.md) المعتمدة على الموقع.

الصلاحية المطلوبة: مشغل مسجل دخول (المسار يفرض فقط _requiresAuth_، بدون معرف صلاحية محدد).

> ملاحظة — في وقت كتابة هذا، نقاط نهاية CRUD الخاصة بـ `/rebalance/runs` غير مفعلة بعد. تعرض الصفحة كتلة الفلترة، صف مؤشرات الأداء الرئيسية وتخطيط الجدول مقابل مؤشرات أداء وهمية وقائمة فارغة. _إنشاء رحلة_، _بحث_، _تحديث تلقائي_، وقائمة الإجراءات لكل صف (_إرسال_، _إعادة تعيين_، _إعادة تحسين_، _طباعة ورقة_، _تصدير_، _تحرير_، _إلغاء_) مفعلة في الكود لكنها معلقة بانتظار الخلفية. النقر على صف ينقل إلى `/rebalance/runs/:id` لكن صفحة التفاصيل ليست جزءًا من هذا البناء.

## صف مؤشرات الأداء الرئيسية (أعلى)

صف من خمس بطاقات مؤشرات أداء تلخص رحلات اليوم.

| مؤشر الأداء       | ما يعرضه                                                                                      |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **الرحلات النشطة** | الرحلات الحالية في حالة _مرسلة_ / _قيد التقدم_ / _موقوفة مؤقتًا_                            |
| **نسبة الالتزام بالوقت** | نسبة الرحلات التي وصلت ضمن نافذة ETA المخططة؛ اتجاه صعودي أخضر ≥ 90%، واتجاه هبوطي أحمر أقل |
| **الرحلات المتأخرة** | عدد الرحلات الموسومة بـ _متأخرة_ ضمن اتفاقية مستوى الخدمة — مؤشر "ما يحتاج مساعدة" للمشغل |
| **إجمالي الكيلومترات اليوم** | المسافة التراكمية التي قطعتها جميع شاحنات إعادة التوازن اليوم                              |
| **تبديلات البطاريات** | إجمالي تبديلات البطاريات التي نفذها الفريق الميداني اليوم                                  |

تعطي هذه الخمسة معًا صورة سريعة عن كيفية سير العمليات الميدانية اليوم مقارنة بالخطة.

## الفلاتر

أربعة فلاتر موجودة في بطاقة _الفلاتر_؛ جميعها مرتبطة بـ AND. زر _مسح الكل_ على اليمين يعيد تعيين الكتلة.

| فلتر              | النوع    | الخيارات                                                                                  |
| ----------------- | -------- | ---------------------------------------------------------------------------------------- |
| **الحالة**        | قائمة منسدلة | _الكل_ / _مخطط_ / _مرسل_ / _قيد التقدم_ / _موقوف مؤقتًا_ / _مكتمل_ / _ملغى_           |
| **مخاطر اتفاقية مستوى الخدمة** | قائمة منسدلة | _الكل_ / _على المسار_ / _في خطر_ / _متأخر_ — علامة تأخر الرحلة                        |
| **المدينة**       | قائمة منسدلة | _كل المدن_ / _موسكو_ / _سانت بطرسبرغ_                                               |
| **هل توجد حوادث** | قائمة منسدلة | _الكل_ / _نعم_ / _لا_ — الحوادث المسجلة ضد الرحلة                                    |

تم تنفيذ تحكم _بحث_ نصي حر (برقم الرحلة، السائق أو الشاحنة) لكنه مخفي حاليًا مع _التحديث التلقائي_ و_إنشاء رحلة_ حتى يتم تفعيل نقطة النهاية.

## الأعمدة

الجدول يحتوي على تسعة أعمدة مرئية. الصفوف قابلة للنقر — تنقل إلى `/rebalance/runs/:id` (عرض التفاصيل غير موجود في هذا البناء).

| العمود               | المحتوى                                                                                                               |
| -------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **رقم الرحلة**       | معرف الرحلة قابل للقراءة من قبل الإنسان (مثلاً `RUN-2026-0517-001`)                                                  |
| **السائق / الشاحنة** | صورة السائق + الاسم + الهاتف؛ طراز الشاحنة + رقم اللوحة تحتها                                                      |
| **المستودع / المدينة** | اسم مستودع الأصل واسم المدينة                                                                                         |
| **الحالة**           | علامة الحالة — رمادي _مخطط_، أزرق _مرسل_، أخضر _قيد التقدم_، أصفر _موقوف مؤقتًا_، أزرق مخضر _مكتمل_، أحمر _ملغى_ |
| **التوقفات**         | التقدم كـ `تم / الكلي`، مع _فشل: N_ باللون الأحمر تحتها عند فشل أي توقف                                         |
| **الحمولة**          | السكوترات المحملة (`🛴 في / السعة`) والبطاريات المحملة (`🔋 مشحونة + مفرغة / السعة`)                                |
| **المخطط**           | وقت بدء-انتهاء ETA + المسافة المخططة (كم) والمدة (دقائق)                                                             |
| **مخاطر اتفاقية مستوى الخدمة** | علامة المخاطر — أخضر _على المسار_، كهرماني _في خطر_، أحمر _متأخر_                                                   |
| **تاريخ الإنشاء / التحديث** | تاريخ الإنشاء في الأعلى، وتاريخ آخر تحديث تحته                                                                            |

عمود الإجراءات (قائمة النقاط الثلاث) مفعّل لكنه معلق بانتظار نقاط نهاية CRUD؛ انظر _إجراءات الصف_ أدناه للمجموعة المخططة.

## مرجع الحالة

الرحلة تكون في حالة واحدة بالضبط؛ الحالة تحدد إجراءات الإرسال المتاحة:

| الحالة          | المعنى                                               |
| --------------- | ---------------------------------------------------- |
| **مخطط**       | تم إنشاؤها وجدولتها لكنها لم تُرسل للسائق بعد         |
| **مرسل**       | أُرسلت للسائق / الشاحنة — في انتظار المغادرة          |
| **قيد التقدم** | الشاحنة تتحرك و/أو تقوم بالتوقفات                     |
| **موقوف مؤقتًا** | أوقف السائق الرحلة (استراحة، حادث، إلخ)              |
| **مكتمل**      | تم محاولة جميع التوقفات، الرحلة مغلقة                 |
| **ملغى**       | أُلغيت قبل الإكمال                                   |

## مرجع مخاطر اتفاقية مستوى الخدمة (SLA)

علامة في الوقت الحقيقي تشير إلى ما إذا كانت الرحلة ستصل ضمن النافذة المخططة لها:

| المخاطرة       | المعنى                                               |
| -------------- | ---------------------------------------------------- |
| **على المسار** | الوتيرة الحالية تتطابق مع الوقت المتوقع المخطط له    |
| **في خطر**     | الاتجاه متأخر، لكنه لا يزال ضمن مسافة يمكن التعافي منها |
| **متأخر**      | الخطة قد فُقدت بالفعل — يحتاج إلى انتباه المرسل      |

استخدم _مخاطر SLA = متأخر_ كأول فلتر للمرسل في الصباح.

## إجراءات الصف (مخطط لها)

كل صف سيحصل على قائمة ثلاث نقاط على اليمين مع الإجراءات أدناه؛ اليوم العمود مخفي بانتظار واجهة برمجة التطبيقات.

| الإجراء          | ما الذي سيفعله                                            |
| ---------------- | -------------------------------------------------------- |
| **عرض**          | فتح صفحة تفاصيل الرحلة عند `/rebalance/runs/:id`                            |
| **إرسال**        | نقل رحلة _مخطط لها_ إلى _مرسلة_، مع إشعار السائق         |
| **إعادة تعيين**  | تغيير السائق و/أو السيارة في الرحلة                       |
| **إعادة تحسين**  | إعادة تشغيل محسن المسار على المحطات المتبقية              |
| **طباعة الورقة** | إنشاء ورقة رحلة قابلة للطباعة (ملخص موجه للسائق)          |
| **تصدير**        | تصدير بيانات الرحلة كملف (مع احترام الفلاتر / الفرز)     |
| **تحرير**        | فتح محرر الرحلة                                          |
| **إلغاء**        | إلغاء الرحلة — يفتح مربع تأكيد                            |

## حالات الفراغ / التحميل

- **جارٍ التحميل** — مؤشر دوران مع "جارٍ تحميل الرحلات…" أثناء استعلام الخلفية
- **خطأ** — لافتة _تنبيه_ مع زر _حاول مرة أخرى_ إذا فشل الطلب
- **فارغ** — أيقونة _شاحنة_ في الوسط مع "لم يتم العثور على رحلات"؛ هذه هي **الحالة المتوقعة اليوم** لأن نقطة النهاية لا تعيد عناصر

## سير العمل النموذجي

- **جولة الإرسال الصباحية** — تصفية _الحالة = مخطط لها_، فرز حسب تاريخ الإنشاء، إرسال كل رحلة بالترتيب
- **المراقبة الحية** — تصفية _الحالة = قيد التقدم_، ثم _مخاطر SLA = متأخر_ لإظهار السائقين الذين يحتاجون مساعدة؛ عند التمكين، _التحديث التلقائي_ يحافظ على عرض محدث
- **مراجعة نهاية اليوم** — تصفية _الحالة = مكتمل_، مسح عمود _المحطات_ للرحلات التي بها محطات فشلت، النقر على كل واحدة لمراجعة الحوادث
- **مدينة بمدينة** — تصفية _المدينة_ عند تشغيل عمليات متعددة المدن؛ التحقق من الأعداد مقابل صفحة [Analytics — Rebalance](runs.md)
- **فرز الحوادث** — تصفية _هل توجد حوادث = نعم_ لإظهار كل رحلة حدث بها خطأ اليوم
- **فحص السعة** — النظر إلى عمود _الحمولة_ في الصفوف _قيد التقدم_؛ قد تحتاج السيارات القريبة من السعة إلى العودة إلى المستودع قريبًا

## نصائح

- **أرقام الرحلات هي معرفات ثابتة** — شاركها مع فريق الميدان لتنسيق واضح ("انظر إلى RUN-2026-0517-003")
- **عمود المحطات يعكس الحقيقة بنظرة سريعة** — `4/7` تعني أربعة مكتملة، وثلاث متبقية؛ _فشل: N_ باللون الأحمر تحتها = يحتاج متابعة
- **نفاد الحمولة مهم** — عدد البطاريات المفرغة العالي يعني أن السيارة مليئة بالبطاريات الميتة ويجب أن تمر على شاحن
- **الإنشاء مقابل التحديث** — _التحديث_ يحدث في كل مرة يتصرف فيها السائق على الرحلة؛ _تحديث_ قديم في صف _قيد التقدم_ = السائق لم يسجل دخوله منذ فترة
- **الحالة _موقوف_ ليست خطأ** — السائقون يتوقفون للاستراحات، الحوادث، وتفاعل الركاب؛ الرحلات الموقوفة لفترة طويلة تستحق مكالمة هاتفية
- **حتى يتم إطلاق نقطة النهاية، اعتبر هذه الصفحة معاينة للتصميم / تجربة المستخدم** — الهيكل، الفلاتر واللغة البصرية نهائية؛ البيانات خلفها ليست كذلك
