# قواعد المركبة

صفحة قواعد المركبة (`/settings/vehicle-rules`) هي **كتالوج نماذج المركبات** التي يعرف Ridewolf كيفية تشغيلها — _Xiaomi M365_، _Ninebot Max G30_، _Segway F40_، وهكذا. كل صف هنا هو **قالب نموذج**: حزمة قابلة لإعادة الاستخدام من التسعير، والحدود التقنية، وقواعد إثبات الصور، والعلامات التي تُرفق بالمركبات الفيزيائية الفردية عبر [نموذج المركبة](../../operations/fleet/vehicle-create-edit.md) من خلال [المركبات](../../operations/fleet/vehicles.md).

الصلاحية المطلوبة: **قواعد المركبة** (`e7f8g9`). صلاحيات فرعية تحكم `create` / `edit` / `delete`.

## النموذج مقابل وحدة المركبة

هذا هو التمييز الأهم في هذه الصفحة:

- **نموذج المركبة** (هذه الصفحة) — تعريف. _"كل Xiaomi M365 في أسطولنا يتصرف بهذه الطريقة"_. صف واحد لكل طراز/تكوين.
- **المركبة** (قائمة [المركبات](../../operations/fleet/vehicles.md)) — وحدة فيزيائية تحمل ملصقًا مثل `RW-007`، مرتبطة بجهاز إنترنت الأشياء واحد، متوقفة في مكان ما. مئات منها تشير إلى نموذج واحد.

عند تغيير نموذج هنا، ترث كل مركبة تشير إليه الإعدادات الافتراضية الجديدة — تصبح التعريفات مفعلة، تتحدث حدود السرعة، تدخل متطلبات إثبات الصور حيز التنفيذ. اعتبر هذه الصفحة كـ **طبقة سياسة** تتفرع إلى العديد من الوحدات دفعة واحدة.

## الفلاتر

شريط الفلاتر العلوي يحتوي على ثلاثة عناصر تحكم:

| الفلتر      | النوع     | ملاحظات                                                                            |
| ---------- | -------- | -------------------------------------------------------------------------------- |
| **بحث**    | نص       | يبحث في تسمية النموذج                                                             |
| **الحالة** | قائمة منسدلة | `الكل` / `نشط` / `غير نشط` / `مؤرشف`                                           |
| **النوع**  | قائمة منسدلة | `الكل` / `سكوتر كهربائي` / `دراجة كهربائية` / `دراجة شحن كهربائية` / `موبيد كهربائي` / `سيارة كهربائية` / `قارب كهربائي` |

تغيير أي فلتر يعيد تعيين الترقيم إلى الصفحة 1 ويعيد التحميل من الخادم.

## الأعمدة

| العمود          | قابل للفرز؟ | المحتوى                                                                                     |
| --------------- | --------- | ------------------------------------------------------------------------------------------- |
| **صورة**       | —         | صورة مصغرة 64×64؛ تعود لأيقونة سيارة عامة إذا لم تُحمّل صورة                               |
| **الاسم**      | ✓         | تسمية النموذج (مثلاً _Xiaomi M365 Pro_)                                                    |
| **النوع**      | ✓         | شريحة نوع المركبة (سكوتر كهربائي، دراجة كهربائية، …)                                    |
| **الوصف**      | ✓         | أول 36 حرفًا من وصف الماركداون، بدون تنسيق                                                |
| **العلامات**   | —         | حتى علامتين + شريحة `+N` للزيادة — **انقر للتحرير السريع** في مربع حوار                   |
| **الحالة**    | ✓         | شريحة ملونة: نشط (أخضر) / غير نشط (رمادي) / مؤرشف (أزرق) — **انقر للتحرير السريع**       |
| **تاريخ الإنشاء** | ✓         | تاريخ إنشاء النموذج                                                                        |
| **تاريخ التحديث** | ✓         | تاريخ آخر تعديل                                                                           |

النقر على التحرير السريع يفتح مربع حوار صغير يحتوي فقط على اختيار متعدد للعلامات أو قائمة الحالة المنسدلة — مفيد لتغيير الحالة دفعة واحدة دون مغادرة القائمة.

## إجراءات شريط الأدوات

أزرار أعلى اليمين (الظهور يعتمد على الصلاحيات):

| الزر             | الصلاحية  | الوظيفة                                                                                                                    |
| ---------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **التحديث التلقائي** | —          | يستطلع القائمة بفاصل زمني ثابت؛ تبديل تشغيل/إيقاف؛ الأيقونة تدور أثناء التحميل                                              |
| **استيراد**       | `create`   | اختر ملف JSON (صيغة التصدير). كل عنصر يصبح مكالمة `create`؛ تُزال العلامات والتعريفات — أعد إرفاقها يدويًا بعد ذلك |
| **تصدير**        | —          | يفتح مربع حوار لتصدير الصفحة الحالية / كل الفلاتر / صفحات محددة كـ `vehicle-models-export.json`                         |
| **+ إنشاء**      | `create`   | يذهب إلى `/settings/vehicle-rules/create`                                                                                      |

## إجراءات الصف

قائمة ثلاث نقاط لكل صف:

| الإجراء          | الصلاحية  | الوظيفة                                                                                                                 |
| ---------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **عرض التفاصيل** | —          | يفتح تفاصيل النموذج في `/settings/vehicle-rules/:id` (علامات التبويب عام / تقني / التاريخ)                                 |
| **تحرير**        | `edit`     | يفتح نموذج التحرير (`/settings/vehicle-rules/:id/edit`) مع مجموعة الحقول الكاملة                                             |
| **حذف**          | `delete`   | مربع حوار تأكيد مدمر مع تأخير 3 ثوانٍ قبل تفعيل زر التأكيد. يختفي صف النموذج من القائمة |

النقر على الصف نفسه (في أي مكان خارج شرائح التحرير السريع) يذهب إلى **عرض التفاصيل**.

## نموذج الإنشاء / التحرير

`+ إنشاء` (`/settings/vehicle-rules/create`) و_تحرير_ (`/settings/vehicle-rules/:id/edit`) يشتركان في نفس التخطيط: بطاقة نموذج على اليسار، وشريط جانبي **دليل الحقول** سياقي على اليمين مع معاينة حية للنموذج.

النموذج مقسم إلى أقسام — يعرض الإنشاء فقط الحقول الأساسية السبعة؛ يضيف التحرير ثلاثة أقسام فرعية إضافية (المواصفات التقنية، السياسات التلقائية، متطلبات الوثائق) للإعدادات المتقدمة.

### الحقول الأساسية

| الحقل           | مطلوب | ملاحظات                                                                                                                               |
| ---------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **التسمية**      | ✓      | اسم بشري يظهر في كل مكان (مثلاً _Xiaomi M365 Pro_). نص حر                                                                           |
| **الوصف**        | —      | محرر ماركداون؛ يُستخدم في تفاصيل النموذج وفي نصائح المشغل                                                                            |
| **نوع المركبة**  | ✓      | واحد من: سكوتر كهربائي / دراجة كهربائية / دراجة شحن كهربائية / موبايد كهربائي / سيارة كهربائية / قارب كهربائي. يتحكم في أيقونة القيادة ومنطق الفئة |
| **الحالة**       | ✓      | نشط / غير نشط / مؤرشف. غير النشط يزيل النموذج من قائمة اختيار إنشاء المركبة                                                           |
| **الصورة**       | —      | سحب وإفلات أو النقر للتحميل. PNG/JPEG/JPG، الحد الأقصى 10 ميغابايت. تظهر في صورة مصغرة للقائمة وعلى تفاصيل المركبة                      |
| **التعريفات**    | ✓      | اختيار متعدد من [تعريفات المركبات](vehicle-tariffs.md). كل الرحلات على هذا النموذج تُسعر وفق هذه التعريفات                            |
| **العلامات**     | ✓      | اختيار متعدد لعلامات على مستوى النموذج. تُورث لكل مركبة من هذا النموذج                                                               |

### المواصفات التقنية (وضع التحرير فقط)

| الحقل                             | ملاحظات                                                                                  |
| --------------------------------- | ---------------------------------------------------------------------------------------- |
| **الحد الأقصى للسرعة الأساسية (كم/س)** | حد صارم يفرضه برنامج إنترنت الأشياء على كل رحلة                                            |
| **احتياطي البطارية (%)**           | مستوى الشحن الذي تحته تُعتبر البطارية منخفضة                                            |
| **احتياطي المدى (كم)**              | المدى المتبقي المقدر الذي تحته تُعلم الوحدة بضرورة الاستبدال                            |
| **الجهد الأدنى / الأقصى للبطارية (فولت)** | حدود لقراءات البطارية الرئيسية الصالحة — أي قراءة خارجها تُعلم _يحتاج إلى تحقيق_          |
| **الجهد الأدنى / الأقصى لإنترنت الأشياء (فولت)** | نفس الشيء، لبطارية وحدة تتبع إنترنت الأشياء                                            |

### السياسات التلقائية (وضع التحرير فقط)

تبديل الحزمة: **إيقاف عند انخفاض البطارية**، **إيقاف عند انخفاض الرصيد**، **رحلات متعددة**، **قفل تلقائي**، بالإضافة إلى **استرداد تلقائي** و**خصم تلقائي** مع عتبات خاصة بها (مسافة / وقت / مبلغ).

### متطلبات الوثائق (وضع التحرير فقط)

يحدد الصور / الوثائق التي يجب على الراكب تقديمها:

- **إثباتات البداية** — صور المركبة عند بدء الرحلة (تبديل + مطلوب + عدد) وصورة شخصية للراكب
- **إثباتات الوقوف** — صور الوقوف عند نهاية الرحلة (تبديل + مطلوب + عدد)
- **وثائق إضافية** — رخصة القيادة / جواز السفر / بطاقة الهوية / صورة شخصية / أخرى

تقرأ تطبيق الراكب هذه القواعد عند بدء / إنهاء رحلة على مركبة مرتبطة بهذا النموذج.

## العلاقة بالكيانات الأخرى

- **[تعريفات المركبات](vehicle-tariffs.md)** — صفوف التسعير التي تختارها في حقل **التعريفات**. النموذج بدون تعريفات لا يمكنه تسعير الرحلة
- **[المركبات](../../operations/fleet/vehicles.md)** — وحدات مادية تشير إلى هذا النموذج عبر حقل _نموذج المركبة_ في [نموذج المركبة](../../operations/fleet/vehicle-create-edit.md). النموذج يحدد السياسة؛ والمركبة تملك إنترنت الأشياء، التسمية، والموقع
- **العلامات** — علامات على مستوى النموذج تُورث لكل مركبة من هذا النموذج، بالإضافة إلى علامات على مستوى المركبة تُطبق مباشرة على الوحدة. ترث الرحلات كلاهما عند بدء الرحلة

## سير العمل النموذجي

- **إضافة نموذج جديد** — `+ إنشاء` → املأ التسمية / النوع / الحالة / الصورة → اختر التعريفات التي تنطبق → حفظ → افتح النموذج الجديد من القائمة وانقر _تحرير_ لضبط المواصفات التقنية والسياسات
- **إيقاف نموذج** — افتح النموذج → _تحرير_ → اضبط الحالة = _مؤرشف_ → حفظ. المركبات الحالية تستمر بالعمل؛ النموذج فقط لا يظهر في قائمة إنشاء المركبة
- **تغيير التعريفات عبر الأسطول** — حرر النموذج → استبدل التعريفات → حفظ. كل مركبات هذا النموذج تبدأ التسعير بالتعريفات الجديدة من الرحلة التالية
- **استيراد جماعي بعد الترحيل** — تصدير من بيئة الاختبار → استيراد ملف JSON هنا → إعادة ربط التعريفات والعلامات يدوياً على كل نموذج جديد (الاستيراد يزيل هذه المراجع عمداً)
- **تعديل متطلبات الصور** — تحرير → متطلبات الوثائق → تبديل إثباتات البداية / الوقوف → حفظ. تطبيق الراكب يلتقط القواعد الجديدة عند بدء الرحلة التالية

## نصائح

- **حدد التعريفات قبل تفعيل النموذج** — النموذج بدون تعريفات سيرفض طلبات تسعير الرحلات
- **استخدم غير نشط، لا تحذف، لإيقاف النموذج** — غير النشط يخفي النموذج من إنشاء المركبات الجديدة لكنه يحافظ على السجل. الحذف لا يمكن التراجع عنه ومحظور بسبب تأخير التأكيد 3 ثوانٍ لسبب
- **الصورة مهمة** — الصورة المصغرة في القائمة وقوائم اختيار المركبات للمشغلين كلها تستخدم هذه الصورة. قصها إلى مربع بخلفية شفافة لأفضل مظهر
- **العلامات هنا على مستوى النموذج، ليست على مستوى المركبة** — تطبيق علامة هنا يضعها على كل مركبة من هذا النموذج. للعلامات الخاصة بوحدة معينة، حرر المركبة الفردية بدلاً من ذلك
- **تنبيهات المواصفات التقنية** — احتياطي البطارية وحدود الجهد تغذي مشغل _يحتاج إلى تحقيق_؛ ضبطها ضيقاً جداً يفيض قائمة التنبيهات
- **شريط دليل الحقل يتحدث أثناء تركيزك على حقل** — اقرأه أول مرة تنشئ فيها نموذجاً، فهو أكثر حداثة من هذه المقالة
