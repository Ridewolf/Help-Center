# المناطق

صفحة المناطق (`/zones`) هي المكان الذي ترسم فيه **القواعد غير المرئية لمنطقة خدمتك** — مثل مواقف السيارات، المناطق الممنوعة، السرعة المنخفضة، الشحن وغيرها من المضلع التي تغير سلوك المركبات والعملاء عند عبور الحدود. كل منطقة هي مضلع واحد على الخريطة بالإضافة إلى نوع، حالة، معلمات اختيارية (السرعة، السعر، سعة المركبة) وعلامات.

المناطق تتحكم في سلوك التشغيل لـ [المركبات](../../operations/fleet/vehicles.md) — عند دخول مضلع ممنوع الركوب يتم قطع المركبة؛ وعند الوقوف داخل مضلع موقف مدفوع يبدأ احتساب السعر.

الصلاحية المطلوبة: **المناطق** (`u7v8w9`). الصلاحيات الفرعية `create` / `edit` / `delete` تتحكم في الإجراءات المقابلة.

## ما هي المنطقة

المنطقة تتكون من أربعة أجزاء أساسية:

1. **النوع** — يحدد اللون والقواعد المطبقة أثناء التشغيل (انظر الجدول أدناه)
2. **المضلع** — مضلع واحد بالضبط، مرسوم على الخريطة؛ الأشكال المقعرة مقبولة، الثقوب غير مقبولة
3. **المعلمات** — تعتمد على النوع: السرعة (السرعة المنخفضة)، السعر (موقف مدفوع)، المبلغ (الشحن)، المركبات المسموح بها (موقف، موقف مدفوع، إعادة توازن)
4. **الحالة** — `نشط` (مطبق)، `غير نشط` (محفوظ لكن مهمل)، `مؤرشف` (مخفي من معظم القوائم)

### أنواع المناطق

| النوع            | اللون       | ما يفعله                                                           |
| ---------------- | ----------- | ------------------------------------------------------------------ |
| **ممنوع الدخول** | أسود        | لا يمكن للمركبات الدخول أو العمل هنا                              |
| **ممنوع الوقوف** | أحمر        | لا يمكن للركاب إنهاء الرحلة هنا                                   |
| **ممنوع الركوب** | بنفسجي      | يتم قطع المركبات / ترفض البدء داخل هذا المضلع                     |
| **سرعة منخفضة**  | أزرق        | الحد الأقصى للسرعة مضبوط على القيمة `speed` (كم/س)                   |
| **موقف**         | أخضر        | موقف مخصص؛ سعة المركبة اختيارية                                   |
| **موقف مدفوع**   | برتقالي     | موقف مع سعر وسعة اختيارية                                         |
| **شحن**          | أخضر داكن   | منطقة مكافأة — يتم تطبيق `amount` عند إنهاء الركاب هنا                |
| **صيانة**        | أحمر داكن   | علامة داخلية للعمليات؛ المركبات داخلها مستبعدة من تدفق الركاب    |
| **إعادة توازن**  | أزرق داكن   | منطقة هدف لإعادة توازن الأسطول؛ سعة المركبة اختيارية             |

## أوضاع العرض

مجموعة تبديل في رأس الصفحة تسمح بالتبديل بين ثلاثة عروض — نفس البيانات، عدسات مختلفة.

| الوضع     | الأفضل لـ                                                        |
| --------- | ---------------------------------------------------------------- |
| **جدول**  | التعديلات الجماعية، الفرز حسب الاسم/النوع/الحالة، التصفح المرقّم |
| **بطاقات**| المسح البصري مع خريطة مصغرة لكل منطقة؛ تمرير لا نهائي             |
| **خريطة** | رؤية كل منطقة مغطاة على الخريطة الحقيقية — مفيد لتدقيق التغطية    |

## الفلاتر

| فلتر    | النوع     | ملاحظات                              |
| ------- | --------- | ------------------------------------ |
| بحث     | نص        | يبحث في اسم المنطقة والوصف          |
| الحالة  | قائمة منسدلة | `نشط` / `غير نشط` (أو `الكل`)      |
| النوع   | قائمة منسدلة | واحد من 9 أنواع (أو `الكل`)          |

تطبق الفلاتر عبر أوضاع العرض الثلاثة كلها. عرض الخريطة يجلب **كل** المناطق المطابقة (بدون ترقيم)؛ الجدول والبطاقات ترقّم.

## الأعمدة (عرض الجدول)

| العمود          | قابل للفرز؟ | المحتوى                                                    |
| --------------- | --------- | ---------------------------------------------------------- |
| **اسم المنطقة** | ✓         | تسمية + لون النوع؛ روابط لصفحة تفاصيل المنطقة             |
| **الوصف**       | —         | وصف نصي اختياري                                            |
| **النوع**       | ✓         | علامة نوع ملونة (انظر جدول الأنواع أعلاه)                 |
| **الحالة**      | ✓         | `نشط` / `غير نشط` / `مؤرشف`                              |
| **العلامات**    | —         | العلامات المطبقة على المنطقة                               |

## إجراءات الصف

قائمة ثلاثية النقاط لكل صف. الإجراءات المتاحة تعتمد على الصلاحيات:

| الإجراء          | الصلاحية  | ما يفعله                                                  |
| ---------------- | --------- | --------------------------------------------------------- |
| **عرض التفاصيل** | —         | فتح صفحة تفاصيل المنطقة (الخريطة + البيانات الوصفية)     |
| **تحرير**        | `edit`    | فتح نموذج التحرير على الهندسة/الخصائص                     |
| **حذف**          | `delete`  | إزالة دائمة — يتطلب الضغط لمدة 3 ثوانٍ للتأكيد            |

## الإجراءات الجماعية

حدد الصفوف في عرض الجدول لإظهار شريط الإجراءات الجماعية. كل الإجراءات الجماعية التي تغير البيانات تتطلب صلاحية `edit`:

- **تغيير النوع** — إعادة تلوين عدة مناطق إلى نوع جديد دفعة واحدة (يتم إعادة تعيين المعلمات وفقًا لذلك)
- **تغيير حد المركبات** — تعيين `allowedVehicles` عبر التحديد (ذو صلة بالمواقف / المواقف المدفوعة / إعادة التوازن)
- **تغيير القيمة** — تعيين القيمة الرقمية الخاصة بالنوع (السرعة / السعر / المبلغ)
- **تغيير الحالة** — تبديل نشط ↔ غير نشط بشكل جماعي
- **تغيير العلامات** — إضافة أو استبدال العلامات عبر التحديد
- **تصدير المحدد** — تحميل المناطق المميزة فقط كملف JSON (لا تحتاج صلاحية؛ على جانب العميل)

## الإنشاء — معالج من 5 خطوات

`+ إنشاء` يفتح نموذجًا موجهًا. يمكنك الرجوع بحرية؛ القفز للأمام متاح فقط عندما تكون الخطوة الحالية صالحة.

1. **الاسم والوصف** — `التسمية` (مطلوب) و`الوصف` اختياري
2. **التصنيف** — `النوع` (مطلوب، يحدد اللون وشكل المعامل)، `الحالة` (نشط / غير نشط / مؤرشف)، `العلامات`
3. **المعاملات** — مدخلات رقمية خاصة بالنوع مع شريط تمرير من 0 إلى 100 للإدخال السريع: السرعة (كم/س)، السعر، الكمية، أو المركبات المسموح بها. الأنواع التي لا تحتوي على معاملات تعرض إشعار "لا توجد معاملات" وتسمح لك بالتقدم
4. **الهندسة** — ارسم **مضلعًا واحدًا** بالضبط على الخريطة. يمكن تفعيل المناطق الموجودة كطبقة متقطعة حتى لا تتداخل. أدوات الخريطة: رسم، تحرير، إضافة نقاط، التراجع (حتى 20 خطوة)، حذف، تكبير، ملاءمة الحدود، تحديد موقعي، ملء الشاشة
5. **المراجعة** — ملخص نهائي للقراءة فقط لكل حقل بالإضافة إلى عدد نقاط المضلع

الحفظ ينشئ المنطقة ويوجهك إلى صفحة التفاصيل الخاصة بها.

## نموذج التحرير

`تحرير` يعيد استخدام نفس الإطار ولكن في نموذج صفحة واحدة (بدون خطوات) — غيّر التسمية، النوع، الحالة، المعاملات، العلامات أو أعد رسم المضلع، ثم احفظ. يظهر تحذير التغييرات غير المحفوظة قبل مغادرة الصفحة.

## الاستيراد / التصدير

زرّان خارجيان بجانب **+ إنشاء**:

- **استيراد** — اختر ملف `.json` تم تصديره سابقًا؛ تتحقق لوحة التحكم من صحة المحتوى وتنشئ المناطق على الخادم. يتطلب صلاحية `create`
- **تصدير** — يفتح حوارًا تختار فيه ما تريد تنزيله: الصفحة الحالية، كل الصفحات مع الفلاتر الحالية، أو الكل. شريط الإجراءات الجماعية يقدم أيضًا "تصدير المحدد" للصفوف المميزة

## صفحة التفاصيل

النقر على صف (أو _عرض التفاصيل_) يفتح صفحة تفاصيل المنطقة مع:

- معاينة خريطة حية للمضلع
- بطاقة معلومات أساسية (التسمية، الوصف، النوع، الحالة، اللون)
- بطاقة المعاملات (السرعة / السعر / الكمية / المركبات المسموح بها، عند الاقتضاء)
- العلامات
- طوابع زمن الإنشاء / التحديث
- أزرار التحرير والحذف في العنوان (مقيدة بالصلاحيات)

## سير العمل النموذجي

- **إطلاق مدينة جديدة** — استيراد حزمة JSON من المناطق إذا كانت متوفرة، وإلا ارسم أولاً حلقة عدم الدخول، ثم مضلعات مواقف السيارات داخلها
- **تعديل منطقة سرعة منخفضة** — تحرير → الخطوة 3 → زيادة قيمة السرعة → حفظ. سارية المفعول فورًا
- **إغلاق موقف سيارات ليوم واحد** — تحرير → الحالة = غير نشط → حفظ. أعد التفعيل عند إعادة فتح الموقف
- **إعادة تقسيم المناطق بعد تغيير في المدينة** — تحديد جماعي للمناطق المتأثرة → تغيير النوع → تأكيد. يتم مسح المعاملات الخاصة بالنوع القديم تلقائيًا
- **تدقيق التغطية** — التبديل إلى عرض الخريطة، تصفية حسب الحالة = نشط، فحص الفجوات والتداخلات

## نصائح

- **النوع يحدد كل شيء** — اللون، شكل المعامل، قاعدة وقت التشغيل. اختيار النوع الخطأ هو السبب الأكثر شيوعًا لإعادة العمل
- **مضلع واحد لكل منطقة** — قسم المناطق المعقدة إلى مناطق متعددة؛ المحرر يفرض وجود مضلع واحد
- **المناطق المتداخلة مسموح بها** — القاعدة الأكثر تقييدًا هي التي تسود (عدم الدخول > عدم الركوب > سرعة منخفضة)، فلا تخف من تكديس منطقة سرعة منخفضة داخل مضلع موقف سيارات
- **استخدم الطبقة المتقطعة** — فعّل "عرض المناطق الموجودة على الخريطة" في المحرر لتجنب التداخل العرضي مع الجيران
- **غير نشط ≠ محذوف** — غيّر الحالة عندما تريد إيقاف المنطقة مؤقتًا؛ الحذف دائم (تأكيد بالضغط لمدة 3 ثوانٍ هو شبكة الأمان)
- **علّم مناطقك** — العلامات هي الفلتر الوحيد متعدد الاختيارات الذي يبقى عبر أوضاع العرض. استخدمها للتجميع حسب الحي، الحملة، أو الملكية
- **صدّر قبل التعديلات الجماعية** — نقرة واحدة في حوار التصدير تحفظ النسخة الكاملة، لذا فإن التغيير الجماعي الفاشل يمكن التراجع عنه بالاستيراد
