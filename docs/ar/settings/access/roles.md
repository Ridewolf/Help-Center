# الأدوار

صفحة الأدوار (`/settings/roles`) هي المكان الذي تحدد فيه **ما يمكن للمشغلين القيام به** في لوحة التحكم. الدور هو مجموعة مسماة من الأذونات؛ كل مشغل لديه دور واحد بالضبط؛ تحدد الأذونات الصفحات التي يمكنهم رؤيتها والإجراءات التي يمكنهم اتخاذها.

اقترن هذه الصفحة مع [Operators](operators.md) — حيث يخصص المشغلون الأدوار للأشخاص، وتحدد الأدوار ما يمكن لكل دور فعله بالفعل.

الأذن المطلوب: **الأدوار** (`d4e5f6`).

## كيف تعمل الأذونات

كل صفحة وإجراء في لوحة التحكم محمي بواسطة **معرف إذن** (مثلاً `k7m8n9` للمركبات، `e4f5h6` للعملاء). الدور هو في الأساس قائمة تحقق من هذه المعرفات:

- يمكن للمشغل رؤية صفحة فقط إذا كان لدوره إذن الصفحة
- يتم إخفاء إجراء صف (تحرير، حذف، إلخ) عندما يفتقر الدور إلى الإذن الفرعي المطابق
- يتم تقييم الأذونات **لكل طلب** — غيّر دورًا ويرى المشغل التغيير عند تحميل الصفحة التالية (أو قبل ذلك)

لا يوجد **وراثة** بين الأدوار — كل دور مستقل. الأدوار ذات الثقة الأعلى ببساطة لديها قائمة أذونات أطول.

## الأدوار الافتراضية مقابل المخصصة

تأتي الأدوار بنوعين:

| النوع        | قابل للتحرير | الغرض                                                                 |
| ----------- | -------- | ----------------------------------------------------------------------- |
| **افتراضي** | لا       | يأتي مع المنصة (مثل المالك، المسؤول). يضمن قاعدة آمنة |
| **مخصص**  | نعم      | تم إنشاؤه من قبلك — يتناسب مع هيكل فريقك                               |

لا يمكن تحرير أو حذف أدوار **المالك / المسؤول** الافتراضية — فهي شبكة الأمان. الأدوار المخصصة هي حيث تضبط الأذونات لتتناسب مع المسؤوليات الواقعية.

## الفلاتر

| فلتر | النوع     | ملاحظات                              |
| ------ | -------- | ---------------------------------- |
| بحث | نص     | يبحث في اسم الدور والوصف |
| الحالة | قائمة منسدلة | `نشط` / `غير نشط` (أو `الكل`)   |

## الأعمدة

| العمود          | قابل للفرز؟ | المحتوى                                                                    |
| --------------- | --------- | -------------------------------------------------------------------------- |
| **اسم الدور**   | ✓         | تسمية الدور                                                           |
| **الوصف** | —         | نص قصير يشرح الغرض من الدور                                 |
| **النوع**        | —         | علامة افتراضية / مخصصة                                                       |
| **الأذونات** | —         | عدد الأذونات الممنوحة (مثلاً "23 / 84")                              |
| **درجة الثقة** | ✓         | درجة رقمية تشير إلى مدى قوة الدور (الأعلى = أكثر قوة) |
| **تاريخ الإنشاء**     | ✓         | متى تم إنشاء الدور                                                  |

### درجة الثقة

درجة الثقة هي مقياس رقمي تقريبي لـ"مدى خطورة مجموعة أذونات هذا الدور" — تُستخدم للفرز والإشارات البصرية. الدور الذي يملك حذف + تحديث جماعي + إدارة الأذونات له درجة ثقة أعلى من دور للعرض فقط. لا توجد مقياس ثابت؛ اعتبرها مقياسًا نسبيًا ضمن قائمة أدوارك.

## إجراءات الصف

قائمة ثلاثية النقاط لكل صف.

| الإجراء           | الإذن | ما يفعله                                                                                      |
| ---------------- | ---------- | ------------------------------------------------------------------------------------------------- |
| **عرض التفاصيل** | —          | فتح صفحة تفاصيل الدور مع تفصيل كامل للأذونات                                      |
| **تحرير**         | `edit`     | فتح نموذج التحرير (معطل مع رسالة منبثقة للأدوار الافتراضية)                                      |
| **حذف**       | `delete`   | حذف الدور بشكل ناعم (مع تأكيد؛ فقط للأدوار المخصصة؛ فقط إذا لم يكن لدى أي مشغل الدور) |

إذا كان الدور قيد الاستخدام، سيرفض النظام الحذف ويخبرك بعدد المشغلين الذين لا يزال لديهم الدور — قم بإعادة تعيينهم أولاً.

## نموذج الإنشاء / التحرير

يعرض نموذج الدور كل إذن مجمّع حسب المجال (العمليات، الدعم، التحليلات، الإعدادات، إلخ) مع مربعات اختيار.

الحقول الرئيسية:

- **الاسم** (مطلوب، فريد)
- **الوصف** (اختياري لكن موصى به)
- **الحالة** (نشط / غير نشط)
- **شجرة الأذونات** — أذونات على مستوى الصفحة والأذونات الفرعية، مجمعة حسب المجال

عند إيقاف تشغيل إذن صفحة على المستوى الأعلى، تُجبر كل الأذونات الفرعية على الإيقاف (يفقد المشغل الصفحة بالكامل). تشغيل إذن صفحة يمنح عرض فقط بشكل افتراضي — ثم تختار _إنشاء_، _تحرير_، _حذف_، إلخ. للأذونات الفرعية بشكل فردي.

مؤشر صغير لـ **درجة الثقة** يتحدث أثناء تحديد المربعات — مفيد للمقارنة مع أدوار مماثلة.

## صفحة تفاصيل الدور

فتح صف يفتح صفحة تفاصيل الدور التي تعرض:

- الاسم، الوصف، النوع، الحالة
- درجة الثقة
- قائمة الأذونات الكاملة (للقراءة فقط، مجمعة حسب المجال)
- سجل النشاط: متى تم إنشاء الدور، آخر تعديل، ومن قام به
- قائمة المشغلين المعينين حاليًا (مع روابط لملفاتهم الشخصية)

## سير العمل النموذجي

- **تعريف فريق جديد** — `+ إنشاء` → الاسم (مثلاً "قائد فريق ميداني") → تحديد الأذونات التي يحتاجونها → حفظ → تعيين الدور للمشغلين المعنيين [operators](operators.md)
- **تشديد دور موجود** — ابحث عن الدور في القائمة → تحرير → إلغاء تحديد الأذونات التي لم تعد تريدها → حفظ (يفقد المشغلون الذين لديهم هذا الدور الوصول عند طلبهم التالي)
- **ترقية عضو فريق** — اذهب إلى [Operators](operators.md) → تحرير → تغيير الدور → حفظ (لا يتم من هذه الصفحة)
- **تدقيق من يمكنه حذف المركبات** — افتح هذه القائمة → فرز حسب درجة الثقة → استعرض أذونات التحرير / الحذف الفرعية لكل دور على المركبات
- **إيقاف دور** — تأكد من عدم وجود مشغل لديه الدور ([Operators](operators.md) فلتر حسب الدور) → حذف

## نصائح

- **الأقل هو الأكثر** — ابدأ بعرض فقط وأضف إجراءات محددة؛ قاوم الرغبة في نسخ دور أعلى وتقليصه
- **اختبر بالتقمص** (حيثما يدعم) — قبل نشر دور، سجّل الدخول كمشغل اختبار بالدور وجرب سير العمل
- **الأدوار الافتراضية هي خط الدفاع الأخير** — المالك / المسؤول موجودان دائمًا؛ إذا قفلت نفسك عن دور مخصص عن طريق الخطأ، يمكن للمسؤول استعادة الوصول
- **درجة الثقة تلميح وليست قاعدة** — دوران بنفس درجة الثقة يمكن أن يقومان بأشياء مختلفة جدًا؛ تحقق دائمًا من شجرة الأذونات الفعلية
- **يتم تقييم الأذونات على الخادم** — إيقاف تشغيلها في الدور لا يزيل جلسة المشغل الحالية، لكن الطلب التالي يُرفض
- **وثّق كل دور مخصص** في حقل الوصف — بعد ستة أشهر، "مدير الأسطول (قراءة + تحرير، بدون حذف)" يكون منقذًا للحياة
