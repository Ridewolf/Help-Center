# المشغلون

صفحة المشغلين (`/settings/operators`) هي **دليل الموظفين** — كل موظف لديه وصول إلى لوحة التحكم. لكل مشغل دور (انظر [الأدوار](roles.md))، وبيانات اختيارية للقسم / المنصب، وعلامات للتصفية، وحالة (نشط / غير نشط).

مختلف عن [العملاء](../../operations/customers/clients.md) (عملاؤك) — المشغلون هم **الفريق الداخلي** الذي يدير المنصة.

الصلاحية المطلوبة: **المشغلون** (`t4u5v6`). الصلاحيات الفرعية تتحكم في إجراءات التحرير.

## كيف يصل المشغلون إلى هنا

يتم إنشاء المشغلين من قبلك (كمدير) عبر زر **+ إنشاء** — لا يوجد تسجيل ذاتي:

1. يفتح زر **+ إنشاء** نموذج المشغل — الاسم، البريد الإلكتروني، الدور، بيانات اختيارية للقسم / المنصب / العلامات
2. يتلقى المشغل الجديد بريدًا إلكترونيًا بتعليمات تسجيل الدخول وكلمة مرور مؤقتة
3. يقوم بتسجيل الدخول، ويكمل ملفه الشخصي (`/profile`)، ويمكنه البدء بالعمل بناءً على صلاحيات دوره
4. لا يمكن للمشغلين غير النشطين تسجيل الدخول — قم بتغيير حالة الحساب إلى غير نشط عند مغادرة الموظف

## عوامل التصفية

| عامل التصفية | النوع         | ملاحظات                                                    |
| ------------- | ------------ | ---------------------------------------------------------- |
| بحث           | نص           | يبحث في الاسم، البريد الإلكتروني، المنصب، القسم           |
| الحالة       | قائمة منسدلة | `نشط` / `غير نشط` (أو `الكل`)                             |
| العلامات     | اختيار متعدد | التصفية حسب العلامات المطبقة على المشغلين (مثلاً "الوردية الليلية") |

## الأعمدة

| العمود         | قابل للفرز؟ | المحتوى                                                                 |
| -------------- | --------- | ----------------------------------------------------------------------- |
| **المستخدم**   | ✓         | الصورة الرمزية + الاسم الأول/الأخير + البريد الإلكتروني؛ رابط لصفحة تفاصيل المشغل |
| **الدور**      | —         | دور المشغل (رابط إلى [الأدوار](roles.md))                      |
| **القسم**      | —         | تسمية القسم الاختيارية                                               |
| **المنصب**     | —         | تسمية المنصب الاختيارية                                             |
| **العلامات**   | —         | العلامات المطبقة على المشغل                                         |
| **الحالة**     | ✓         | `نشط` (أخضر) / `غير نشط` (رمادي)                                  |

## إجراءات الصف

قائمة ثلاثية النقاط لكل صف. تعتمد الإجراءات المتاحة على الصلاحيات:

| الإجراء           | الصلاحية | الوصف                                               |
| ----------------- | -------- | -------------------------------------------------- |
| **عرض التفاصيل** | —        | فتح صفحة تفاصيل المشغل                              |
| **تحرير**         | `edit`   | فتح نموذج التحرير (الاسم، الدور، القسم، إلخ)       |

لا يوجد **إجراء حذف** — تُحتفظ سجلات المشغل لأغراض التدقيق. لمنع تسجيل الدخول، قم بتغيير حالة المشغل إلى _غير نشط_ عبر التحرير.

## صفحة التفاصيل

النقر على صف (أو _عرض التفاصيل_) يفتح صفحة تفاصيل المشغل التي تحتوي على:

- المعلومات الشخصية (الاسم، البريد الإلكتروني، الهاتف، الصورة)
- لمحة عن الدور والصلاحيات
- القسم / المنصب / العلامات
- الحالة
- سجل النشاط (أحداث تسجيل الدخول، تغييرات الدور)

يمكن التحرير من هناك أو من قائمة الصف — كلاهما يفتح نفس النموذج.

## نموذج الإنشاء / التحرير

نموذج **المشغل** (`+ إنشاء` أو _تحرير_) بسيط:

- **الاسم الأول / الاسم الأخير** (مطلوب)
- **البريد الإلكتروني** (مطلوب، فريد بين المشغلين)
- **الدور** (مطلوب، قائمة منسدلة بالأدوار المتاحة — انظر [الأدوار](roles.md))
- **القسم / المنصب** (اختياري)
- **العلامات** (اختيار متعدد اختياري)
- **الحالة** (نشط / غير نشط)
- عند الإنشاء فقط: حقل **كلمة المرور الأولية** أو كلمة مرور مولدة تلقائيًا تُرسل إلى المشغل عبر البريد الإلكتروني

الحفظ يتحقق من صحة البيانات ويسجلها في سجل التدقيق. يتلقى المشغلون الجدد بريد ترحيبي تلقائيًا.

## سير العمل النموذجي

- **تعيين موظف جديد** — `+ إنشاء` → ملء الاسم/البريد الإلكتروني/الدور → حفظ → تأكيد استلام البريد الترحيبي → طلب تسجيل الدخول وإكمال الملف الشخصي
- **تغيير الدور بعد الترقية** — تحرير → تغيير الدور → حفظ (تُطبق الصلاحيات الجديدة عند الطلب التالي للمشغل، وليس بأثر رجعي)
- **المغادرة** — تحرير → تعيين الحالة = غير نشط → حفظ (يبقى السجل لأغراض التدقيق؛ يتم حظر تسجيل الدخول)
- **تخطيط الورديات بناءً على العلامات** — تطبيق علامات مثل "الوردية الليلية" → تصفية القائمة حسب العلامة لرؤية من هو مجدول

## نصائح

- **الدور هو الحقل القوي** — كن حذرًا عند تغييره. إنقاص الدور من مدير إلى دعم يسحب صلاحيات الكتابة فورًا
- **غير نشط ≠ محذوف** — يتم الاحتفاظ بتاريخ المشغل؛ يمكن إعادة التفعيل لاستعادة الوصول
- **القائمة مرتبة حسب الاسم افتراضيًا** — إذا كان لديك العديد من المشغلين، ابحث بالبريد الإلكتروني أو القسم بدلاً من التمرير
- **العلامات هنا مختلفة عن علامات العملاء** — فهي خاصة بالمشغلين (مثلاً "الوردية الليلية"، "مدرب") ولا تشترك في نفس مساحة الأسماء
- **قيود التعديل الذاتي** — لا يمكنك تغيير دورك من قائمة الصف؛ استخدم الملف الشخصي للتغييرات الشخصية
