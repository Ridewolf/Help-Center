# أدلة سريعة

تحتوي صفحة الأدلة السريعة (`/settings/quick-guides`) على **الإرشادات خطوة بخطوة** التي يعرضها تطبيق رايد وولف للراكب على الهاتف المحمول لأشياء مثل "كيفية استئجار سكوتر" أو "قائمة التحقق من السلامة". كل دليل هو قائمة مرتبة من العناصر مع أيقونة، لون، عنوان، ونص أساسي — يتم نشره حسب الجمهور (تطبيق الراكب، تطبيق العميل، الميكانيكي، المسؤول، عام).

إلى جانب [مجموعات الأسئلة الشائعة](faq-sets.md) (كتل الأسئلة/الأجوبة) و[مجموعات الأيقونات](icon-sets.md) (فن الخريطة)، تعد الأدلة السريعة الركيزة الثالثة لطبقة المحتوى. حرر دليلاً هنا، يلتقط تطبيق الراكب التغيير عند الجلب التالي — لا حاجة لإصدار جديد للتطبيق.

الصلاحية المطلوبة: **الأدلة السريعة** (تحقق مع المسؤول).

## أين تظهر هذه للراكب

في تطبيق الراكب على الهاتف المحمول، تغذي الأدلة السريعة دروس التهيئة وشاشات النصائح أثناء الرحلة. يتم تحميل كل دليل من نوع **تطبيق الراكب** وحالته `active`؛ تظهر العناصر المعلمة `visible` في `order`، مع `icon` و`color` المكونين على اليسار، ويتم توسيع نص `body` إذا كانت `expandByDefault` صحيحة.

الدلائل من النوع `client-app`، `mechanic`، `admin`، `general` مرتبطة بواجهاتها الخاصة.

## عوامل التصفية

| عامل التصفية | النوع         | الملاحظات                                                               |
| ------------- | ------------ | ----------------------------------------------------------------------- |
| بحث           | نص           | مربع البحث في العنوان — يبحث في العنوان / الوصف / السبيكة              |
| العلامات      | اختيار متعدد | التصفية حسب العلامات (التهيئة، الأساسيات، التقنية، المدفوعات، …)      |
| الحالة        | قائمة منسدلة | `نشط` / `مسودة` / `مؤرشف` (أو `الكل`)                                |
| النوع         | قائمة منسدلة | `تطبيق العميل` / `تطبيق الراكب` / `الميكانيكي` / `المسؤول` / `عام` (أو `الكل`) |

**مسح الكل** يعيد تعيين كل عوامل التصفية.

## الأعمدة

| العمود      | المحتوى                                                             |
| ----------- | ------------------------------------------------------------------- |
| **المجموعة** | أيقونة كتاب + العنوان؛ السطر الثانوي يعرض الوصف أو السبيكة          |
| **النوع**    | شريحة الجمهور — تطبيق العميل / تطبيق الراكب / الميكانيكي / المسؤول / عام |
| **العلامات** | أول 3 شرائح علامات، مع تجاوز `+N`                                 |
| **العناصر**  | عدد الخطوات في الدليل                                            |
| **الحالة**  | `نشط` (أخضر) / `مسودة` (رمادي) / `مؤرشف` (باهت)                  |
| **تم التحديث** | تاريخ نسبي؛ مرر فوقه لرؤية الطابع الزمني الكامل + المؤلف            |

انقر على صف لفتح مربع حوار **عرض** (معاينة لكل خطوة). انقر على قائمة النقاط الثلاث للإجراءات.

## إجراءات الصف

| الإجراء           | ما يفعله                                                           |
| ---------------- | ------------------------------------------------------------------ |
| **عرض التفاصيل** | معاينة مع عرض كل عنصر كما يراه الراكب                             |
| **تحرير**         | فتح نموذج الحوار (نفس إنشاء، مع تعبئة مسبقة)                    |
| **تكرار**         | استنساخ الدليل مع لاحقة السبيكة `-copy` وإعادة تعيين الحالة إلى `مسودة` |
| **تصدير**         | التنزيل كملف ZIP أو JSON                                          |
| **أرشفة**         | النقل إلى `مؤرشف` — مخفي من تطبيق الراكب، محفوظ للتاريخ          |
| **حذف**           | الإزالة بشكل دائم                                                 |

شريط الأدوات العلوي **استيراد** (ZIP / JSON) و**تصدير** (ZIP / JSON) يعملان بالجملة.

## نموذج الإنشاء / التحرير

النموذج يحتوي على نفس محددات المستوى الأعلى مثل مجموعات الأسئلة الشائعة، بالإضافة إلى محرر أغنى لكل عنصر:

- **النوع** — مطلوب، يحدد من يرى الدليل
- **الحالة** — `مسودة` / `نشط` / `مؤرشف`
- **العلامات** — اختيار متعدد
- **العنوان / الوصف** — العنوان مطلوب، الوصف اختياري
- **العناصر** — قائمة الخطوات. كل عنصر يحتوي على:
  - **العنوان** — عنوان الخطوة
  - **النص** — محتوى الخطوة (نص طويل، نص عادي)
  - **الأيقونة** — اسم أيقونة Lucide (مثلاً `MapPin`، `QrCode`، `Shield`)
  - **اللون** — لون سداسي عشري مع إعدادات مسبقة للعلامة التجارية (أساسي `#6366f1`، نجاح `#22c55e`، تحذير `#eab308`، خطر `#ef4444`، إلخ)
  - **التوسيع افتراضياً** — إذا كان مفعلاً، يفتح العنصر موسعاً في التطبيق
  - **مرئي** — تبديل لإخفاء عنصر دون حذفه
  - **الترتيب** — السحب لإعادة الترتيب

السبيكة مشتقة من العنوان وتستخدم في عنوان واجهة برمجة التطبيقات.

## سير العمل النموذجي

- **كتابة دليل تهيئة جديد** — `+ إنشاء دليل` → النوع = تطبيق الراكب، الحالة = مسودة → أضف 5–7 عناصر مرتبة مع أيقونات + ألوان → معاينة عبر عرض التفاصيل → تحويل إلى نشط → يظهر في تطبيق الراكب عند الجلب التالي
- **جعل خطوة اختيارية / إخفاؤها** — تحرير → إيقاف تشغيل `مرئي` على العنصر → حفظ (يبقى العنصر في البيانات، فقط لا يعرض)
- **اختبار A/B لإرشاد جديد** — تكرار الدليل النشط → تحرير النسخة → أرشفة القديم وتفعيل الجديد معاً
- **استيراد مسودة مصمم بالجملة** — أعلى اليمين _استيراد_ → ZIP/JSON → تأكيد الهيكل المحلل → استيراد كمسودة → مراجعة وتفعيل

## نصائح

- **الأيقونات هي أسماء Lucide** — اختر من [lucide.dev](https://lucide.dev) ليتم عرضها في التطبيق؛ أسماء الأيقونات المكتوبة خطأ تعود إلى عنصر نائب
- **لون الخطوات لسهولة المسح البصري** — يقرأ الراكب الأدلة بسرعة. استخدم تحذير لخطوات "الحذر" ونجاح لحالات "تم" 
- **`expandByDefault` للخطوة الأولى فقط عادةً** — فتح كل عنصر افتراضياً يهدم فكرة الأكورديون. اترك الباقي مطوي
- **نص المحتوى هو نثر عادي، ليس ماركداون** — اجعل الفقرات قصيرة؛ يحدد التطبيق على الهاتف الطباعة
- **الأرشفة بدلاً من الحذف** عند تقاعد دليل — يمكنك دائماً إعادة التفعيل أو التكرار لاحقاً
- **استخدم العلامات بشكل متسق مع [مجموعات الأسئلة الشائعة](faq-sets.md)** — `onboarding`، `troubleshooting`، إلخ هي مفردات مشتركة عبر طبقة المحتوى
