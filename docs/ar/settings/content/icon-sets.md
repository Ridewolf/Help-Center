# مجموعات الأيقونات

صفحة مجموعات الأيقونات (`/settings/icon-sets`) هي **مكتبة أيقونات الخريطة** التي يستخدمها تطبيق Ridewolf للراكب على الهاتف المحمول لعرض المركبات. كل مجموعة مرتبطة بنوع مركبة واحد (سكوتر كهربائي، دراجة كهربائية، دراجة شحن كهربائية، دراجة نارية كهربائية، سيارة كهربائية، قارب كهربائي) وتوفر ثلاث فئات من أيقونات SVG: **مُختارة**، **غير مختارة**، و**خصم**.

هذه بنية تحتية للمحتوى — يقوم المشغلون بتحميل ملفات SVG هنا، ويختار تطبيق الراكب الأيقونة المناسبة بناءً على نوع المركبة، مستوى البطارية، وما إذا كان الراكب قد نقر على المركبة على الخريطة. لا حاجة لإصدار جديد من التطبيق لتبديل الرسومات.

مع [FAQ Sets](faq-sets.md) و[Quick Guides](quick-guides.md)، هذه هي طبقة المحتوى في لوحة التحكم.

الصلاحية المطلوبة: **مجموعات الأيقونات** (تحقق مع المسؤول).

## أين تظهر هذه للراكب

على خريطة تطبيق الراكب، يستخدم كل دبوس مركبة أيقونة من المجموعة النشطة لنوع مركبته:

- تُستخدم أيقونات **غير المختارة** للدبابيس التي لم ينقر عليها الراكب — ستة مستويات بطارية (`bat10`، `bat25`، `bat40`، `bat55`، `bat90`، `bat100`) بحيث يعكس الدبوس الشحن الحالي
- تحل أيقونات **المُختارة** محل الدبوس بمجرد نقر الراكب عليه — نفس مستويات البطارية الستة، بأسلوب مختلف
- تُضاف أيقونات **الخصم** (5%، 15%، 25%، 35%، 45%، 55% افتراضيًا) فوق الدبوس عندما تكون للمركبة سعر ترويجي

يمكن تعيين مجموعة واحدة لكل نوع مركبة كـ **افتراضية** — هذه هي التي يحملها التطبيق عندما لا يتم تكوين شيء آخر.

## عوامل التصفية

| عامل التصفية    | النوع     | ملاحظات                                                                                                         |
| -------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| بحث            | نص       | مربع البحث في العنوان — يبحث في العنوان / المعرف                                                                 |
| نوع المركبة    | قائمة منسدلة | `سكوتر كهربائي` / `دراجة كهربائية` / `دراجة شحن كهربائية` / `دراجة نارية كهربائية` / `سيارة كهربائية` / `قارب كهربائي` (أو `الكل`) |
| تغطية الحالة  | قائمة منسدلة | التصفية حسب ما هو مملوء: `المُختارة فقط` / `غير المختارة فقط` / `الخصم فقط` / `تغطية كاملة` (أو `الكل`) |
| الحالة        | قائمة منسدلة | `نشط` / `مسودة` / `غير مكتمل` / `مؤرشف` (أو `الكل`)                                                        |
| العلامات      | صندوق اختيار | تصفية العلامات الحرة (مربع الإدخال ظاهر لكنه معطل حاليًا — قادم قريبًا)                                          |

**مسح الكل** يعيد تعيين كل عوامل التصفية.

## الأعمدة

| العمود                 | المحتوى                                                                   |
| ---------------------- | ------------------------------------------------------------------------- |
| **المجموعة**           | أيقونة الحزمة + العنوان؛ السطر الثانوي يعرض المعرف                           |
| **نوع المركبة**        | علامة (سكوتر كهربائي، دراجة كهربائية، إلخ)                                |
| **أيقونات المُختارة**  | التغطية مثل `6/6` (عدد مستويات البطارية المحملة)                            |
| **أيقونات غير المختارة** | نفس تغطية `n/6` للأنواع غير المختارة                                     |
| **أيقونات الخصم**      | أول 3 نسب خصم كشرائح (`5%`، `15%`، `25%`)، `+N` للزيادة                       |
| **العلامات**           | أول شريحتين للعلامات مع `+N` للزيادة                                      |
| **تم التحديث**         | تاريخ آخر تحديث                                                           |
| **الحالة**             | `نشط` / `مسودة` / `غير مكتمل` / `مؤرشف`                                  |

`غير مكتمل` يعني أن المجموعة تفتقد أيقونات لإحدى الفئات الثلاث — يتراجع تطبيق الراكب إلى الافتراضي لنوع المركبة هذا حتى تكمل التحميل.

انقر على صف لفتح **مربع التفاصيل** — معاينة بصرية لكل أيقونة في المجموعة. انقر على قائمة النقاط الثلاث للإجراءات.

## إجراءات الصف

| الإجراء             | ما يفعله                                                                      |
| ------------------ | --------------------------------------------------------------------------------- |
| **عرض التفاصيل**   | فتح مربع التفاصيل مع معاينات لكل SVG محمل                                   |
| **تحرير**          | فتح نموذج متعدد الألسنة (التفاصيل / المُختارة / غير المختارة / الخصومات / المعاينة) |
| **تكرار**          | استنساخ المجموعة كمسودة                                                      |
| **تعيين كافتراضي** | تعيين هذه المجموعة كافتراضية لنوع مركبتها — سيحملها تطبيق الراكب          |
| **تنزيل**          | تنزيل المجموعة كملف ZIP يحتوي على كل ملفات SVG                            |
| **أرشفة**          | نقل إلى `مؤرشف` — محفوظ للسجل، لا يستخدمه التطبيق                          |
| **حذف**            | إزالة نهائي                                                                |

شريط الأدوات العلوي **استيراد** (ZIP / JSON) و**تصدير** (ZIP / JSON) يعملان بالجملة.

## نموذج الإنشاء / التحرير

النموذج هو مربع حوار بخمسة ألسنة:

1. **التفاصيل** — العنوان (مطلوب)، المعرف (مشتق تلقائيًا)، نوع المركبة (مطلوب)، العلامات، الحالة
2. **المُختارة** — تحميل 6 ملفات SVG، واحدة لكل مستوى بطارية (`bat10` → `bat100`)
3. **غير المختارة** — نفس 6 خانات، لحالة الخريطة غير المختارة
4. **الخصومات** — ملف SVG واحد لكل نسبة خصم. الإعدادات الافتراضية هي `5, 15, 25, 35, 45, 55` لكن يمكنك إضافة/حذف صفوف
5. **المعاينة** — فحص بصري شامل للمجموعة قبل الحفظ

يتم حفظ المجموعة التي تحتوي على خانات فارغة في أي لسان كـ `غير مكتملة`.

## سير العمل النموذجي

- **تحديث دبابيس السكوتر الإلكتروني لإعادة العلامة التجارية** — نسخ النسخة الافتراضية الحالية → تحميل ملفات SVG جديدة في الثلاث علامات → حفظ كمسودة → معاينة → تعيين كافتراضي → يلتقط تطبيق الراكب التحديث عند التحديث التالي
- **إجراء اختبار A/B على الأيقونات** — إبقاء المجموعة القديمة نشطة وليست افتراضية، إنشاء مجموعة جديدة نشطة + افتراضية لنوع مركبة → التراجع بتعيين القديمة كافتراضية إذا لزم الأمر
- **فن خصم العطلات** — فتح المجموعة النشطة → تحرير → علامة الخصومات → تحميل ملفات SVG ذات الطابع الخاص بالنسبة المئوية المستخدمة حالياً → حفظ
- **استيراد مجمع لملف ZIP لمصمم** — أعلى اليمين _استيراد_ → ZIP → تأكيد تعيين الملفات → مراجعة في المعاينة → تفعيل

## نصائح

- **افتراضي واحد لكل نوع مركبة** — تعيين افتراضي جديد يلغي السابق تلقائياً. شارة الحالة لا يجب أن تكون `نشط` لتكون المجموعة افتراضية، لكنها يجب أن تكون كذلك
- **مستويات البطارية ثابتة** — `bat10/25/40/55/90/100` هي الفئات الوحيدة التي يفهمها التطبيق؛ يختار التطبيق الأقرب بناءً على شحن المركبة الحالي
- **ملفات SVG فقط** — التحميلات تتوقع ملفات SVG؛ ملفات PNG لن تظهر بوضوح على شاشات الريتنا
- **`غير مكتمل` هو حاجز أمان مفيد** — يخبرك أن تطبيق الراكب يعود إلى الافتراضي، لذا لن ترسل مجموعة نصف محملة عن طريق الخطأ
- **الأرشفة قبل الحذف** — تبقى المجموعات المؤرشفة قابلة للبحث في حال أردت التراجع
