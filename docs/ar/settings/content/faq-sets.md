# مجموعات الأسئلة الشائعة

صفحة مجموعات الأسئلة الشائعة (`/settings/faq-sets`) هي **مكتبة الأسئلة والأجوبة** المعروضة داخل تطبيقات Ridewolf — بشكل أساسي تطبيق الركاب على الهاتف المحمول، ولكن أيضًا على واجهات المشغلين. كل مجموعة هي حزمة من إدخالات الأسئلة/الأجوبة موجهة لجمهور محدد (تطبيق الركاب، تطبيق العميل، الميكانيكي، المسؤول، أو عام).

معًا مع [أدلة سريعة](quick-guides.md) و[مجموعات الأيقونات](icon-sets.md)، تشكل هذه الصفحة جزءًا من طبقة المحتوى — ما يغيره المشغل هنا هو ما يراه الراكب على هاتفه، دون الحاجة لإصدار جديد للتطبيق.

الصلاحية المطلوبة: **مجموعات الأسئلة الشائعة** (تحقق مع المسؤول).

## أين تظهر هذه للراكب

في تطبيق الركاب على الهاتف المحمول، تدعم مجموعات الأسئلة الشائعة قسم المساعدة / الأسئلة الشائعة داخل التطبيق. يتم تحميل كل مجموعة من النوع **تطبيق الركاب** والحالة `active` في التطبيق؛ تظهر الإدخالات المعلمة `visible`، مرتبة حسب حقل `order`. المجموعات من النوع `client-app`، `mechanic`، `admin`، `general` تذهب إلى تلك التطبيقات / الواجهات المعنية.

لا يتم عرض مجموعة من النوع `draft` أو `archived` أبدًا — مفيد لتجهيز التغييرات قبل النشر.

## عوامل التصفية

| عامل التصفية | النوع         | ملاحظات                                                                |
| ------------ | ------------ | ---------------------------------------------------------------------- |
| بحث          | نص           | مربع البحث في الرأس — يبحث في العنوان / الوصف / السبيكة               |
| العلامات     | اختيار متعدد | التصفية حسب العلامات المطبقة على المجموعة (التوجيه، المدفوعات، التقنية، …) |
| الحالة      | قائمة منسدلة | `نشط` / `مسودة` / `مؤرشف` (أو `الكل`)                                |
| النوع       | قائمة منسدلة | `تطبيق العميل` / `تطبيق الركاب` / `الميكانيكي` / `المسؤول` / `عام` (أو `الكل`) |

**مسح الكل** يعيد تعيين كل عوامل التصفية دفعة واحدة.

## الأعمدة

| العمود      | المحتوى                                                             |
| ----------- | ------------------------------------------------------------------- |
| **المجموعة** | أيقونة + العنوان؛ السطر الثانوي يعرض الوصف أو السبيكة              |
| **النوع**    | شريحة الجمهور — تطبيق العميل / تطبيق الركاب / الميكانيكي / المسؤول / عام |
| **العلامات** | أول 3 شرائح علامات، مع `+N` للزيادة                               |
| **العناصر**  | عدد حقول الأسئلة/الأجوبة في المجموعة                              |
| **الحالة**   | `نشط` (أخضر) / `مسودة` (رمادي) / `مؤرشف` (باهت)                  |
| **تم التحديث**| تاريخ نسبي؛ تحويم لعرض الطابع الزمني الكامل + المؤلف                |

انقر على صف لفتح مربع حوار **عرض** (معاينة للقراءة فقط). انقر على قائمة النقاط الثلاث للإجراءات.

## إجراءات الصف

| الإجراء           | ما يفعله                                                          |
| ---------------- | ----------------------------------------------------------------- |
| **عرض التفاصيل** | معاينة للقراءة فقط مع عرض كل عنصر سؤال/جواب                      |
| **تحرير**        | فتح مربع الحوار للنموذج (نفس إنشاء، مع تعبئة مسبقة)             |
| **تكرار**        | استنساخ المجموعة مع لاحقة السبيكة `-copy` وإعادة تعيين الحالة إلى `مسودة` |
| **تصدير**        | تنزيل المجموعة كملف ZIP أو JSON                                 |
| **أرشفة**        | نقل إلى `مؤرشف` — مخفي عن تطبيق الركاب، محفوظ للتاريخ           |
| **حذف**          | إزالة نهائية (إجراء مدمر — فقط إذا كنت متأكدًا من عدم الحاجة إليه) |

شريط الأدوات العلوي يحتوي أيضًا على استيراد جماعي **استيراد** (ZIP / JSON) و**تصدير** (ZIP / JSON للقائمة الظاهرة).

## نموذج الإنشاء / التحرير

مربع الحوار للنموذج يحتوي على ثلاثة محددات على المستوى الأعلى وقائمة من حقول الأسئلة/الأجوبة:

- **النوع** — مطلوب، يحدد من يرى المجموعة (تطبيق العميل / تطبيق الركاب / الميكانيكي / المسؤول / عام)
- **الحالة** — `مسودة` (افتراضي للجديد) / `نشط` / `مؤرشف`
- **العلامات** — اختيار متعدد، يستخدم للتصفية والتجميع
- **العنوان** — مطلوب، يظهر كاسم المجموعة
- **الوصف** — اختياري، السطر الثانوي في القائمة
- **الحقول** — إدخالات الأسئلة/الأجوبة. كل حقل يحتوي على:
  - **التسمية** (السؤال)
  - **القيمة** (الإجابة)
  - **النوع** — `text` / `markdown` / `link` / `list`
  - مفتاح تبديل **مرئي** (إخفاء عناصر فردية دون حذف)
  - **الترتيب** (اسحب لإعادة الترتيب)

السبيكة مشتقة من العنوان وتستخدم في عنوان URL لواجهة برمجة التطبيقات — يمكن تغييرها عبر التحرير إذا لزم الأمر.

## سير العمل النموذجي

- **نشر أسئلة شائعة جديدة للراكب** — `+ إنشاء مجموعة` → النوع = تطبيق الركاب، الحالة = مسودة → املأ العنوان + الوصف → أضف حقول الأسئلة/الأجوبة → حفظ → معاينة عبر عرض التفاصيل → تحرير، غيّر الحالة إلى نشط → تظهر في تطبيق الركاب عند التحديث التالي
- **تجهيز نسخة موسمية** — تكرار مجموعة موجودة → تحرير النسخة كمسودة → جدولة التبديل بأرشفة المجموعة القديمة وتفعيل الجديدة دفعة واحدة
- **التراجع عن إجابة خاطئة** — افتح المجموعة المخالفة → تحرير → أصلح الحقل (أو أوقف التبديل إلى مرئي) → حفظ؛ أو أرشف المجموعة كاملة وارجع إلى نسخة مكررة سابقة
- **استيراد جماعي من تفريغ JSON** — أعلى اليمين _استيراد_ → اختر الملف → أكد الهيكل المحلل → استيراد كمسودة، ثم راجع وفعّل

## نصائح

- **النوع يحدد من يرى المحتوى** — لا تضع نصًا موجهًا للراكب في مجموعة `mechanic`، فلن تصل أبدًا إلى تطبيق الركاب
- **المسودة صديقك** — المجموعات الجديدة افتراضيًا مسودة حتى لا يعرض تطبيق الركاب محتوى نصف مكتمل. غيّر إلى نشط فقط بعد مراجعة كل شيء
- **حقول ماركداون تعرض التنسيق** — استخدمها للإجابات التي تحتاج إلى قوائم نقطية أو عناوين بارزة؛ اختر `text` عندما تريد نصًا عاديًا فقط
- **العلامات مشتركة مع الفلتر** — استخدم مفردات علامات متسقة (مثل `onboarding`، `payments`، `troubleshooting`) ليظل التصفية المستقبلية مفيدًا
- **الأرشفة بدل الحذف** متى أمكن — المجموعات المحذوفة تختفي نهائيًا، المجموعات المؤرشفة يمكن إعادة تفعيلها وتستخدم كأرشيف
