# Rider App — Estatísticas do Rider

**Estatísticas para o rider não estão disponíveis atualmente no app.** Não há tela de gráficos, totais ou resumo de gastos para o rider acessar.

Envie os riders para [History](history.md) — é o único lugar com seus próprios dados.

## O que o rider vê

- **Não há ponto de entrada.** O menu lateral lista Carteira, Histórico, Suporte, Privacidade, Configurações e Perfil — e nada mais. Um rider que diz não encontrar uma tela de análises está certo; não diga para procurar no menu, nem envie um link para isso.
- Se a tela `/analytics` for aberta diretamente, ela mostra apenas um título e espaço vazio. **Nada está errado** com a conta do rider, seu dispositivo ou a instalação do app — reinstalar não muda nada.

## Onde os números do rider realmente estão

[History](history.md) tem dados reais por rider:

- A aba **Corridas** lista todas as corridas passadas com distância, duração e custo
- A aba **Pagamentos** lista recargas, reembolsos, débitos e bônus com valores e status
- Tocar em uma corrida abre seus detalhes com o [detalhamento completo do custo](../riding/rides.md#detalhamento-de-custos), a linha do tempo da atividade e a rota desenhada no mapa

Não há **banner de totais agregados em lugar algum** no app do rider — nem em telas de estatísticas, nem no topo do Histórico. Totais acumulados precisam ser somados pela lista de corridas ou extraídos do seu próprio relatório.

## Respondendo às perguntas de números do dashboard

Quando um rider realmente precisa dos totais, produza-os no lado do operador:

| Rider quer                     | Onde você obtém                                                                  |
| ------------------------------- | --------------------------------------------------------------------------------- |
| Total gasto em um período       | [Análises — Pagamentos](../../analytics/reports/payments.md)                        |
| Sua própria lista de corridas, exportada   | [Corridas — Lista](../../operations/trips/rides.md), filtrada para esse cliente           |
| Seus registros de pagamento           | [Pagamentos — Histórico](../../operations/payments/payments.md)                        |
| Um resumo rápido por cliente      | [Detalhe do Cliente](../../operations/customers/client-detail.md) — total de corridas, saldo, avaliação |

## FAQ

| Rider pergunta…                     | Resposta                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------- |
| "Onde estão minhas estatísticas?"           | Não disponível atualmente no app. Use [History](history.md)                    |
| "Não encontro Análises no menu" | Não há entrada de menu para isso                                               |
| "A página de Análises está em branco"   | Esperado — a tela não está disponível no momento. Nada está quebrado              |
| "Posso exportar meus dados de corrida?"    | Não pelo app. Exporte pelo dashboard em nome do rider             |
| "Quanto eu gastei no total?" | Não existe total no app do rider. Veja no Histórico ou extraia do dashboard |

## Dicas

- **Não envie links de análises para os riders.** Não há tela útil para acessar, e uma página em branco parece um app quebrado.
- **Responda as perguntas de totais você mesmo.** Puxar o número do dashboard leva um minuto e encerra a conversa.
- **O Histórico é a resposta honesta**, e é realmente completo por corrida e pagamento — apresente assim em vez de pedir desculpas pela falta de tela.
