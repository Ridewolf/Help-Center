# Bem-vindo ao Painel Ridewolf

O Painel Ridewolf é o centro de controle para gerenciar uma frota de mobilidade compartilhada. Seja para operar scooters, bicicletas ou qualquer outro tipo de veículo, aqui você monitora a atividade em tempo real, gerencia clientes, lida com suporte e analisa o desempenho.

## Para quem é este painel

O painel foi criado para **operadores** — funcionários que trabalham no dia a dia com a frota:

- **Gerentes de frota** — veículos, zonas, tarifas
- **Agentes de suporte** — bilhetes, conversas, comprovantes de estacionamento
- **Analistas** — métricas, relatórios, desempenho
- **Administradores** — operadores, funções, configurações do sistema

O que cada operador vê depende da sua **função e permissões**. Sua visão pode ser mais restrita que as capturas de tela deste guia se alguns módulos forem limitados para sua função.

## Conceitos principais

O painel é organizado em torno de alguns conceitos que você encontrará em toda parte:

| Conceito      | O que significa                                                               |
| -------------- | ----------------------------------------------------------------------------- |
| **Veículo**    | Uma unidade física na frota (scooter, bicicleta, etc.) — possui GPS, bateria, status |
| **Corrida**    | Uma viagem feita por um cliente em um veículo — possui horário de início/fim, rota, custo |
| **Cliente**    | Um cliente registrado que pode alugar veículos                                |
| **Pagamento**  | Transações financeiras vinculadas a corridas, recargas ou reembolsos         |
| **Zona**       | Uma área geográfica onde os veículos operam (ou são restritos)                |
| **Tarifa**     | Regras de precificação que determinam quanto as corridas custam               |
| **Etiqueta**   | Um rótulo anexado a clientes ou veículos para agrupamento e filtragem        |
| **Bilhete**    | Um pedido de suporte ao cliente                                               |
| **Comprovante de Estacionamento** | Uma foto enviada por um cliente para confirmar o estacionamento correto |

## Navegação básica

### Barra lateral (esquerda)

A barra lateral é a navegação principal. Os grupos se expandem para revelar subpáginas — por exemplo, **Suporte** se expande em Bilhetes, Comprovantes de Estacionamento e Conversas.

### Barra superior

A barra superior aparece em todas as páginas e contém:

- **Breadcrumb** — o caminho de volta pela hierarquia (ex: Início → Veículos → RW-001)
- **Chat de IA** (ícone de brilho) — um assistente que pode responder perguntas sobre o painel
- **Ajuda** (ícone de interrogação) — abre esta base de conhecimento, contextualizada para a página atual
- **Notificações** (ícone de sino) — eventos e alertas recentes do sistema
- **Perfil** (avatar) — configurações, alteração de senha, sair, controles de tema

### Tabelas

A maioria das páginas de lista (veículos, corridas, clientes, etc.) segue o mesmo layout:

1. **Barra de pesquisa** no topo para busca por texto completo
2. **Filtros em pílulas** abaixo para restringir por status, tipo, etc.
3. **Colunas ordenáveis** — clique no cabeçalho da coluna para ordenar
4. **Paginação** na parte inferior
5. **Ações na linha** — um menu de três pontos em cada linha para ações rápidas

## O que fazer primeiro

Se esta é sua primeira vez no painel, recomendamos:

1. **Atualize seu perfil** — avatar → Perfil, preencha nome, foto, detalhes de contato
2. **Explore a frota** — abra **Veículos** para ver o que está ativo no momento
3. **Confira as corridas de hoje** — abra **Corridas** filtrado para hoje para acompanhar a atividade em tempo real
4. **Abra o painel inicial** — a página principal `/dashboard` resume os KPIs diários
5. **Leia esta base de conhecimento** — abra a seção relevante antes de realizar sua primeira ação em cada módulo

## Como obter ajuda

Existem três formas de obter ajuda dentro do painel:

- **Ícone de Ajuda (?)** na barra superior — abre uma gaveta lateral com documentação relevante para a página onde você está
- **Ajuda** na barra lateral (ícone de livro) — a base de conhecimento completa e pesquisável
- **Formulários de Feedback / Sugestão** na página inicial da Ajuda — escreva diretamente para a equipe
