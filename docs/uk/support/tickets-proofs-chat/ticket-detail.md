# Деталі квитка

Сторінка деталей квитка (`/support/tickets/:id`) — це місце, де ви розслідуєте один запит у службу підтримки. Вона відкривається як велике модальне вікно поверх [списку квитків](tickets.md) — URL змінюється, щоб квиток можна було поділитися або відкрити за прямим посиланням.

Зазвичай ви потрапляєте сюди, клацнувши рядок у списку або вставивши пряме посилання у браузер.

Необхідний дозвіл: **Квитки** (`a8b9c1`). Для деяких дій потрібні додаткові піддозволи (`edit`, `delete`).

## Як це пов’язано з іншими переглядами квитків

| Перегляд                                                                   | Призначення                                                                    |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [Список квитків](tickets.md)                  | Повна черга — пошук, фільтрація, сортування                                   |
| [Автоматичний перегляд квитка](ticket-auto-review.md) | Спрощений режим — один очікуючий квиток за раз, швидке сортування з клавіатури |
| **Деталі квитка (ця сторінка)**                                              | Детальний перегляд одного квитка — повне зображення, повний опис, контекст, редагування / видалення |

## Макет

Модальне вікно розташоване зверху вниз:

1. **Заголовок** — назва (мітка квитка), рядок опису ("Квиток №ID"), кнопка закриття (X)
2. **Розділ зображення** — фото доказу від користувача (велике, кліком відкривається)
3. **Картка деталей квитка** — статус, тип скарги, опис, коментар
4. **Картка транспортного засобу та місцезнаходження** — транспортний засіб, IMEI, координати, зона, повідомник
5. **Підвал** — кнопки _Закрити_ та _Редагувати_

## Заголовок

Верхня смуга ідентифікує квиток:

- **Іконка alert-circle** поруч із міткою квитка (наприклад, мітка транспортного засобу або згенерована назва квитка)
- **Рядок опису** з ID квитка
- Кнопка закриття діалогу (×) у верхньому правому куті — також закривається клавішею Esc або кліком поза вікном

Закриття діалогу видаляє `/:id` з URL, щоб історія переходів назад / вперед відповідала відображеному.

## Розділ зображення

Повне фото доказу, надане користувачем, достатньо велике для швидкого перегляду:

- **Клікніть на зображення** (або на кнопку _Переглянути у повному розмірі_, що з’являється при наведенні) — відкриває фото оригінальної роздільної здатності в новій вкладці
- **Наведіть курсор** — з’являється затемнена накладка + кнопка _Переглянути у повному розмірі_
- Якщо зображення не завантажується, на його місці з’являється заповнювач
- Якщо у квитка немає зображення (рідко, наприклад, квитки, створені оператором), розділ приховано

Мініатюра у списку — це маленька версія; тут показано повне зображення, готове для модерації.

## Картка деталей квитка

Ліва картка з двокарткового сітки. Поля:

| Поле               | Що показує                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Статус**         | Пігулка статусу (Очікується, В процесі, Вирішено, Відхилено, Дубль тощо) — та сама палітра кольорів, що й у списку                   |
| **Тип скарги**     | Пігулка типу скарги — та ж кольорова схема, що й у списку (червоний Механічне пошкодження, жовтий Чистота тощо)                      |
| **Опис**           | Вільний текст опису від користувача, відображений як markdown (переноси рядків зберігаються, посилання автоматично активні) — порожнє, якщо користувач не залишив опис |
| **Коментар**       | Внутрішній коментар / нотатки оператора щодо квитка — порожнє, доки оператор не додасть

Див. [Список квитків → Посилання на статуси / Типи скарг](tickets.md) для повного значення кожного кольору пігулки.

## Картка транспортного засобу та місцезнаходження

Права картка сітки. Поля:

| Поле          | Що показує                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------- |
| **Транспортний засіб**  | Мітка транспортного засобу (з іконкою автомобіля) та пов’язаний IMEI його IoT-пристрою       |
| **Місцезнаходження**    | Широта / довгота, де було зафіксовано проблему (6 знаків після коми, з іконкою шпильки)       |
| **Зона**       | [Зона](../../settings/infrastructure/zones.md), у якій знаходиться місцезнаходження, якщо є    |
| **Повідомник** | Користувач / система / оператор, який створив квиток, з їхньою електронною поштою             |

Використовуйте ці перехресні посилання для переходу в контекст: клацніть транспортний засіб, щоб відкрити [деталі транспортного засобу](../../operations/fleet/vehicle-detail.md), клацніть повідомника, щоб відкрити його [профіль клієнта](../../operations/customers/client-detail.md), або скопіюйте координати у карту для підтвердження місцезнаходження.

## Дії (підвал)

Сторінка деталей пропонує **навмисно обмежений** набір дій — більшість робочих процесів із квитками відбувається у списку або пов’язаних сутностях (транспортний засіб, клієнт). Що тут є:

| Кнопка    | Що робить                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Закрити** | Закриває модальне вікно (видаляє `/:id` з URL)                                                                                                               |
| **Редагувати**  | Відкриває квиток у режимі редагування. Примітка: у поточній версії обробник Редагування показує повідомлення "Редагування не реалізовано" — він підключений, але форма ще не готова |

### Що є у списку, але немає тут

Меню рядка у списку має дві додаткові дії, яких немає на сторінці деталей:

| Дія        | Де знаходиться   | Чому                                                                                                                             |
| ---------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Редагувати** | Рядок списку + деталі | Те саме Редагувати (поки що заповнювач)                                                                                         |
| **Видалити** | Меню рядка списку | Видалення — це дія лише для рядка (з діалогом підтвердження). Щоб видалити з деталей, спочатку закрийте модальне вікно, потім використайте меню рядка |

### Що на сторінці списку

Заголовок сторінки списку має _Автоматичний перегляд_, який переходить до черги оптимізації — еквівалентної кнопки в деталях немає, бо ви вже зосереджені на одному квитку.

## Дії з увімкненим feature-flag (не в поточній збірці)

У кодовій базі є заповнювачі для розширеного набору дій з квитками, які **закоментовані** у цій збірці:

- **Призначити** — призначити квиток оператору
- **Заблокувати транспортний засіб** — вивести транспортний засіб з експлуатації одним кліком
- **Створити завдання з техобслуговування** — відкрити завдання з техобслуговування, заповнене даними цього квитка
- **Нарахувати користувачу** — видати кредит на гаманець повідомнику
- **Відповісти** — надіслати шаблонну відповідь користувачу
- **Об’єднати дублікати** — пов’язати цей квиток з головним квитком

Якщо у вашому розгортанні ці функції увімкнені, вони з’являються в меню рядка / у випадаючому списку _Дії_ у заголовку — не в тілі модального вікна. Зверніться до адміністратора, якщо очікуєте їх і не бачите.

## Типові робочі процеси

- **Сортування за фото** — відкрити квиток → подивитися зображення → якщо пошкодження реальне, скопіювати маркування транспортного засобу → закрити модальне вікно → відкрити деталі транспортного засобу, щоб заблокувати його / створити завдання з техобслуговування
- **Вирішити скаргу низької якості** — відкрити квиток → підтвердити, що фото неякісне → закрити → використати меню рядка списку для видалення (з підтвердженням)
- **Розслідувати історію транспортного засобу** — відкрити квиток → клікнути на транспортний засіб → побачити повну історію тривог і поїздок транспортного засобу → повернутися до квитка, щоб додати коментар
- **Перевірити скаргу користувача щодо поїздки** — відкрити квиток → скопіювати повідомника → відкрити деталі його клієнта → перевірити його останні поїздки для контексту
- **Поділитися квитком з колегою** — URL містить id квитка (`/support/tickets/:id`), тож ви можете вставити його в чат, і отримувач відкриє те саме модальне вікно

## Поради

- **URL — це ваша закладка** — копіювання URL з `:id` і вставка пізніше повертає безпосередньо до того самого квитка, навіть з іншої сесії
- **Esc для закриття** — модальне вікно підтримує Esc, клік поза вікном і X — усі три видаляють id з URL
- **Клікніть на зображення один раз, щоб переглянути оригінал** — мініатюра стиснута; оригінал — це те, що насправді надіслав користувач
- **Перевірте IMEI** — якщо транспортний засіб часто отримує квитки, це часто проблема IoT, а не шасі. IMEI — ваш зв’язок із записом [налаштувань IoT](../../settings/infrastructure/iot.md)
- **Коментар — лише для внутрішнього користування** — користувачі його не бачать; використовуйте для нотаток між операторами щодо квитка
- **Редагування ще не реалізоване** — клік по _Редагувати_ зараз показує повідомлення. Якщо потрібно змінити статус, робіть це через дії на рівні списку або Автоматичний перегляд
