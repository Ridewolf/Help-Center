# Розмови

Сторінка Розмов (`/support/conversations`) — це **месенджер оператора** — інтерфейс чату в реальному часі між вашою службою підтримки та вашими користувачами. Кожна розмова належить одному клієнту і містить повну історію повідомлень, дії вашої команди та зміни статусу.

Потрібен дозвіл: **Розмови** (`x2y3z4`).

## Як розмови відображаються тут

Розмови надходять із кількох потоків:

1. **Користувач відкриває чат** у мобільному додатку — створює _Нову_ розмову, потрапляє в чергу _Очікується_
2. **Оператор ініціює** — _+ Нове_ у бічній панелі дозволяє почати чат із конкретним клієнтом (наприклад, для подальшого розгляду штрафу або перевірки шахрайства)
3. **Відкрито повторно** — закриті розмови можна відкрити знову (користувачем або оператором), і вони повертаються на початок списку

Список є **живим** — нові розмови та вхідні повідомлення надходять через WebSocket без оновлення сторінки.

## Макет

Сторінка має дві основні області. Макет адаптується до розміру екрану:

- **Десктоп** — розділений вигляд, бічна панель зліва (30%) і вміст чату справа (70%) з можливістю перетягування
- **Мобільний** — по одній області за раз: список у бічній панелі або відкритий чат (стрілка назад повертає до списку)

## Бічна панель (зліва)

Черга розмов і фільтри:

- **+ Нове** — відкриває діалог для пошуку клієнта і початку нової розмови (статус _Очікується_)
- **Пошук** — текстовий пошук за ім’ям клієнта, ID, останнім повідомленням
- **Фільтри за статусом** — кнопки з лічильниками: `Всі` / `Нові` / `Очікується` / `Активні` / `Відкладені` / `Закриті`
- **Картки розмов** — кожна показує: аватар, ім’я клієнта, прев’ю останнього повідомлення, статус, часову позначку, бейдж непрочитаних. Клік для відкриття
- **Завантажити ще** — пагінація при прокручуванні

За замовчуванням сортування ставить відповіді, що очікують (Очікується / Активні з непрочитаними), на початок — найтерміновіші чати завжди на виду.

### Довідка по статусах

| Статус      | Значення                                                    |
| ----------- | ----------------------------------------------------------- |
| **Новий**   | Щойно відкритий, ніхто ще не прочитав                      |
| **Очікується** | Не призначений, у черзі для будь-якого оператора           |
| **Активний**| Призначений оператору, розмова в процесі                   |
| **Відкладений** | Оператор поставив на паузу (очікування інформації, подальші дії) |
| **Закритий**| Вирішено і закрито                                         |

## Вміст чату (праворуч)

Коли ви вибираєте розмову, у правій колонці відображається:

### Заголовок чату

- **Стрілка назад** (тільки мобільний) — повернення до списку в бічній панелі
- **Заголовок** — ім’я клієнта зі статусом розмови
- **Відкрити інформацію** — відкриває [бічну панель інформації про користувача](#інформаційні-панелі) з повним контекстом клієнта
- Кнопки **Відкласти / Передати / Закрити** залежно від статусу

### Вікно чату

- **Повідомлення у бульбашках** — повідомлення оператора справа (акцентний колір), повідомлення користувача зліва; з часовими позначками та індикаторами прочитання
- **Індикатор набору тексту** — показує, коли користувач друкує
- Кнопка **Завантажити старіші** вгорі — завантажує попередні повідомлення за запитом
- Кнопка **До нових повідомлень** — швидкий перехід до низу, якщо ви прокрутили вгору
- **Дії з повідомленнями** при наведенні — Редагувати / Видалити для власних повідомлень

### Шаблони відповідей

Рядок над полем введення показує шаблони швидких відповідей, згруповані за категоріями. Клік по шаблону вставляє текст у поле введення — ви можете відредагувати перед відправкою.

### Нижня панель чату

Що відображається внизу, залежить від **статусу** розмови та призначення:

- **Активна + призначена вам** → **Поле введення повідомлення** з меню вкладень (текст + зображення / файл)
- **Інші випадки** → панель **Дій з розмовою** з кнопками, релевантними поточному стану

## Дії з розмовою (за статусом)

Внизу відображаються потрібні кнопки для поточного статусу. Загальні дії:

| Дія           | Доступна коли…                      | Що робить                                            |
| ------------- | ---------------------------------- | ---------------------------------------------------- |
| **Прийняти**  | Очікується / Новий (ви ще не власник) | Призначає розмову вам і переводить у _Активний_      |
| **Перехопити**| Активна (належить іншому оператору) | Перепризначає вам                                   |
| **Повернути** | Активна (призначена вам)            | Звільняє розмову назад у _Очікується_                |
| **Відкласти** | Активна                            | Ставить розмову на паузу → _Відкладена_              |
| **Відкрити знову** | Закрита                          | Повертає розмову у _Активний_                         |
| **Закрити**   | Активна                            | Позначає розмову як вирішену → _Закрита_             |
| **Видалити**  | За наявності дозволу               | М’яке видалення розмови (адмінський рівень)          |
| **Нове**      | Завжди                            | Почати нову розмову з тим самим клієнтом             |

Ви захищені від дій у чаті, який вам не належить — замість поля введення з’явиться кнопка _Перехопити_, якщо чат призначений іншому оператору.

## Інформаційні панелі

Дві панелі, що висуваються, відкриваються з дій у вікні чату:

- **Бічна панель інформації про користувача** — швидкий контекст для призначеного оператора (вас) і недавня активність користувача в цьому чаті
- **Повний профіль клієнта** — повний знімок профілю клієнта (баланс, статус, теги, останні поїздки) без виходу з чату — зручно для швидких рішень

## Порожній стан (десктоп)

Коли на десктопі чат не вибрано, у правій панелі показується ілюстрація порожнього стану з підказкою вибрати розмову. На мобільному правої панелі немає, доки ви не виберете чат — список у бічній панелі займає весь екран.

## Типові робочі процеси

- **Підхопити чат у черзі** — `Status = Waiting` → натисніть на верхню картку → _Прийняти_ → почніть спілкування
- **Взяти розмову у колеги** — відкрийте чат (ви побачите, що він належить іншому) → _Взяти на себе_ (використовуйте обережно; це порушує безперервність для користувача)
- **Охолодити повільну розмову** — коли користувач перестає відповідати, _Відкладіть_, щоб перемістити її з активної черги; вона повернеться у вашу папку вхідних, коли користувач відповість
- **Закрити розмову** — питання вирішено → _Закрити_ з швидкою шаблонною відповіддю ("Все вирішено, гарної поїздки!")
- **Швидко отримати контекст користувача** — _Відкрити інформацію_ у заголовку → перегляньте баланс / останні поїздки / теги перед відповіддю на питання про оплату
- **Використовуйте шаблонні відповіді** — для повторюваних відповідей (політика повернення коштів, процес пошуку загублених речей) виберіть шаблон і персоналізуйте його

## Поради

- **За замовчуванням у режимі реального часу** — нові повідомлення надходять без оновлення сторінки; лічильник значка оновлюється автоматично
- **Спочатку без відповіді** — сортування тримає термінові чати зверху; довіряйте порядку списку
- **Шаблонні відповіді — це шаблони, а не сценарії** — завжди персоналізуйте привітання і заключну фразу; користувачі помічають, коли отримують стандартні відповіді
- **Обережно беріть розмову на себе** — користувач не бачить стан оператора. Перемикання посеред розмови може бути різким; беріть на себе лише коли поточний оператор явно недоступний (офлайн, поза зміною)
- **Відкладіть > Закрийте у сумнівних випадках** — якщо ви думаєте, що питання може повернутися, _Відкладіть_ зберігає зв’язок у темі; _Закрити_ змушує користувача відкрити нову розмову, якщо хоче продовжити
- **Редагуйте лише свої повідомлення** — і лише для виправлення дрібних помилок; переписування старого повідомлення після того, як користувач його прочитав, може підірвати довіру
- **URL містить ID розмови** — вставте його у квиток або запис про ескалацію, щоб наступний оператор міг одразу перейти до неї
