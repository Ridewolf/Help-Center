# Перегляд доказів паркування

Сторінка перегляду (`/support/park-proofs/:id/review`) — це місце, де ви детально модеруватимете одне фото доказу паркування. Тут розміщено повне зображення, весь пов’язаний контекст (клієнт / поїздка / транспортний засіб) та повне меню дій.

Зазвичай ви потрапляєте сюди, натискаючи на мініатюру (або _Переглянути_ у меню рядка) у [списку доказів паркування](park-proofs.md).

Необхідний дозвіл: **Park Proofs** (`d5e6f7`) + піддозвіл `review` для дій модерування.

## Макет

Сторінка розділена на три колонки на широких екранах, на вузьких — стекаються:

| Колонка        | Ширина | Вміст                                               |
| -------------- | ------ | -------------------------------------------------- |
| **Зображення** | 5/12   | Фото у повному розмірі з можливістю масштабування і панорамування |
| **Дії**        | 4/12   | Кнопки модерування, необов’язковий коментар, адміністраторське Видалення |
| **Інформаційні картки** | 3/12   | Деталі клієнта, поїздки, транспортного засобу, доказу |


## Зображення (ліва колонка)

**Переглядач зображень із масштабуванням** з фото у повній роздільній здатності:

- **Клік + перетягування** для панорамування при збільшенні
- **Колесо прокрутки** (або стиснення пальцями на мобільному) для масштабування
- **Подвійний клік** для скидання масштабу

Звертайте увагу на:

- Повністю транспортний засіб у кадрі (не лише колесо)
- Законне місце для паркування (не заважає пішоходам, не в зоні заборони паркування)
- Підніжка опущена, транспортний засіб стоїть вертикально
- Будь-що, що суперечить історії користувача у разі спору

## Дії (середня колонка)

Чотири кнопки модерування розташовані вертикально за ступенем суворості:

| Кнопка               | Вплив на статус | Використовуйте, коли                                                    |
| -------------------- | --------------- | --------------------------------------------------------------------- |
| **Затвердити**       | _Затверджено_   | Фото хороше — користувач припаркувався правильно                     |
| **Попередити**       | _Попередження_  | Фото неідеальне, але недостатньо погане для штрафу — користувач отримує сповіщення |
| **Відхилити зі штрафом** | _Штраф_         | Фото погане — застосовується штраф на суму, введену нижче кнопки      |
| **Заблокувати**      | _Заблоковано_   | Серйозне / повторне порушення — блокує користувача від майбутніх поїздок |

Кожна дія вимагає піддозвіл `review`. Дії, які ви не можете виконати, приховані або вимкнені.

### Сума штрафу

Кнопка **Відхилити зі штрафом** має поле введення числа безпосередньо під нею для **суми штрафу** в валюті компанії. Штраф списується з гаманця клієнта (або з його стандартного способу оплати, залежно від налаштувань). Сума є обов’язковою при натисканні _Відхилити зі штрафом_ — інакше кнопка вимкнена.

### Коментар

Під кнопками дій розташоване текстове поле **Коментар**. Все, що ви введете, додається до дії і зберігається у:

- Записі доказу (для майбутніх аудитів)
- [Журналі активності клієнта](../../operations/customers/client-detail.md#вкладка-активність) (щоб будь-хто, хто пізніше розслідує клієнта, бачив вашу нотатку)
- Сповіщенні в додатку користувача (залежно від дії — вони бачать контекст, чому їх попередили / оштрафували)

Пишіть коментар **перед** натисканням дії — він надсилається разом із дією, а не після. Будьте конкретні: "самокат блокує тротуар, фото зроблено о 22:14" краще, ніж "погане паркування".

### Видалити (адміністратор)

Кнопка **Видалити** внизу (видима лише з правами адміністратора) повністю видаляє запис доказу. Використовуйте для:

- Тестових фото / спам-завантажень
- Дубльованих завантажень (одна поїздка, кілька однакових фото)
- Фото, завантажених для неправильної поїздки (помилка даних)

Не використовуйте Видалити замість Затвердити / Відхилити — Видалити призначено для _видалення запису з системи_, а не для рішень модерування.

## Інформаційні картки (права колонка)

Три картки "пов’язаних сутностей" плюс картка деталей розташовані вертикально:

- **Клієнт** — ім’я, телефон, електронна пошта, статус, посилання на [сторінку клієнта](../../operations/customers/client-detail.md)
- **Поїздка** — ID поїздки, час початку/закінчення, відстань, вартість; посилання на [сторінку поїздки](../../operations/trips/ride-detail.md)
- **Транспортний засіб** — позначка, модель, статус; посилання на [сторінку транспортного засобу](../../operations/fleet/vehicle-detail.md)
- **Деталі доказу паркування** — тип (початок/паркування/кінець), дата створення, GPS-координати, будь-який уже застосований автоматичний вердикт

Використовуйте ці картки, щоб **швидко сформувати контекст**:

- Чи є цей клієнт порушником уперше чи повторно? — відкрийте Клієнт → Активність
- Чи завершив він поїздку у місці на фото? — відкрийте Поїздка → карта маршруту
- Чи часто цей транспортний засіб паркується неправильно? — відкрийте Транспортний засіб → останні докази

## Типові робочі процеси

- **Швидке затвердження** — фото явно хороше → залиште коментар порожнім → _Затвердити_ → назад до черги
- **Попередження з контекстом** — фото погане, але легке → напишіть одне речення → _Попередити_ → користувач отримує м’яке нагадування
- **Штраф після розгляду** — фото явно погане → перевірте картку Клієнта на повторні порушення → напишіть пояснювальну нотатку → введіть суму → _Відхилити зі штрафом_
- **Ескалація до блокування** — фото третє порушення → перевірте Клієнт → Активність на попередні попередження → напишіть нотатку → _Заблокувати_
- **Аудит попереднього рішення** — відкрийте доказ → прочитайте поле Коментар у журналі активності, щоб побачити, що писав попередній оператор

## Поради

- **Збільшуйте масштаб перед прийняттям рішення** — підпірки, знаки паркування та пішохідні доріжки легко пропустити на мініатюрі
- **Спочатку введіть коментар** — після натискання дії вона відразу застосовується; якщо коментар вводити після, ви вже відреагували без контексту
- **Затвердити > Попередити > Штрафувати > Заблокувати** — це одностороння ескалація, не переходьте одразу до Заблокувати при першому порушенні
- **Коментар є публічним** (для вашої команди та користувача) — тримайте його фактичним; без внутрішнього жаргону, без оцінок клієнта
- **Видалення незворотне** — після видалення доказу його не можна відновити; використовуйте _Відхилити_, якщо потрібен запис про погане фото
- **Зображення — це правда** — коли користувач оскаржує штраф, оригінальне фото + ваш коментар + хронологія є справою
