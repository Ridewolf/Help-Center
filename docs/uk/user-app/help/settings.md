# Rider App — Налаштування

Налаштування (`/settings`) містять усі переваги для додатка, орієнтованого на користувача: сповіщення, що відображає карта, перемикачі конфіденційності, мова, тема та продуктивність.

**Кнопки Зберегти немає.** Екран миттєво показує кешовані налаштування, оновлює їх у фоновому режимі та автоматично застосовує кожну зміну через мить після її внесення. Користувач, який щось змінив і одразу закрив екран, майже напевно зберіг зміни — це відповідь на питання «чи застосовано мою зміну?».

Декілька цих перемикачів змінюють те, що відображає [Карта](../riding/map.md), тому це перший екран для відвідування при проблемах «карта повільна» або «я не бачу рівень заряду батареї».

## Сповіщення

П’ять незалежних перемикачів:

- **Сповіщення про поїздки**
- **Сповіщення про акції**
- **Оновлення додатка**
- **Push-сповіщення**
- **Email-сповіщення** — один перемикач; під ним немає підпунктів за типами

У тій самій області:

| Елемент керування | Примітки                                                                    |
| ------------------ | -------------------------------------------------------------------------- |
| **Звук**           | Перемикач                                                                  |
| **Гучність звуку** | Повзунок — з’являється лише коли **Звук** увімкнено                        |
| **Вібрація**       | Перемикач                                                                  |
| **Налаштування радара** | Картка, що з’являється лише у збірках додатка, де увімкнено налаштування радара |

## Карта та відображення

Перемикачі:

- **Показувати рівень заряду батареї**
- **Показувати рекламні транспортні засоби**
- **Показувати ціни**
- **Автоматичне масштабування**
- **3D-карта** — застосовується до карти одразу
- **Зменшена анімація**

Плюс **Режим даних**, селектор із варіантами **збалансований**, **низький** та **високий**. Він керує якістю тайлів карти та деталізацією, і це **перше, що варто спробувати, коли користувач скаржиться на повільну або важку карту** — встановіть на _низький_ і також увімкніть **Зменшену анімацію**.

**Офлайн-карти** наразі недоступні в додатку.

## Контролі конфіденційності

- Перемикач **Обмін геолокацією**
- Перемикач **Обмін даними**
- **Політика конфіденційності** — відкриває зовнішнє посилання, яке ви налаштували в [Моя компанія](../../settings/administration/my-company.md); посилання з’являється лише якщо URL задано
- **Керування сесіями** — відкриває екран пристроїв, де виконано вхід (`/settings/sessions`), той самий, що доступний із Профілю

Повний екран із правилами конфіденційності та безпеки — це окремий маршрут (`/privacy`). **Видалення облікового запису тут немає** — робочий процес видалення знаходиться на екрані Профілю.

## Регіон і зовнішній вигляд

| Елемент керування | Варіанти                         | Примітки                                                                                                  |
| ----------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Мова**          | **en**, **ru**, **ro**           | Застосовується одразу, без перезавантаження. Тут доступні лише ці три мови                                 |
| **Одиниці виміру** | —                               | В додатку наразі немає селектора одиниць виміру                                                           |
| **Тема**          | Світла, Темна, Системна          | Застосовується одразу                                                                                      |
| **Стиль карти**   | Авто, Світла, Темна              | **Вимкнено і примусово встановлено Авто, коли Тема встановлена на Системна.** Перемкніть Тему на Світлу або Темну, щоб розблокувати |

Тут відображаються лише три мови додатка, хоча інші локалі існують в інших частинах продукту — див. [Localization](../../settings/administration/localization.md) для панелі керування.

## Режим поїздки

**Режим поїздки наразі недоступний у додатку.** Користувач, який питає, де керування режимом поїздки, не втратив доступ — цього розділу немає в додатку, і немає налаштування в панелі керування, яке б його додавало.

## FAQ

| Користувач питає…                     | Відповідь                                                                                     |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| «Де кнопка Зберегти?»                 | Її немає — зміни зберігаються автоматично                                                    |
| «Де Режим поїздки?»                   | Наразі недоступний у додатку                                                                 |
| «Чому Стиль карти сірий?»              | **Тема** встановлена на **Системна**. Спочатку змініть її на Світлу або Темну                 |
| «Чому моєї мови немає у списку?»       | Цей екран пропонує лише **en**, **ru** та **ro**                                            |
| «Де налаштування Одиниць?»             | Наразі недоступне у додатку                                                                  |
| «Де перемикач Офлайн-карт?»            | Наразі недоступний у додатку                                                                  |
| «Як видалити обліковий запис?»         | З екрана Профілю, а не з Налаштувань                                                        |
| «Як побачити мої пристрої з входом?»  | **Керування сесіями** — тут або та сама кнопка в Профілі                                     |
| «Карта повільна»                      | **Режим даних → низький**, потім увімкніть **Зменшену анімацію**. Див. [Map](../riding/map.md#усунення-несправностей) |

## Поради

- **Режим даних — це ваш регулятор продуктивності.** Перш ніж звинувачувати телефон користувача або ваші тайли, запропонуйте їм спробувати _низький_.
- **"Не збереглося" майже ніколи не відповідає дійсності.** Попросіть їх знову відкрити екран — значення там буде.
- **Скарги на карту часто знаходяться тут, а не на самій карті.** Відсутні відсотки заряду, відсутні ціни та відсутні промоційні транспортні засоби — це всі перемикачі на цьому екрані.
- **Тема блокує стиль карти.** Запам’ятайте цю пару; інакше це щотижневий квиток.
