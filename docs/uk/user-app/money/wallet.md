# Rider App — Гаманець і Поповнення

Гаманець (`/wallet`) — це екран грошей користувача, який відкривається з рядка балансу гаманця в бічному меню. Він містить поточний баланс, бонуси, точку входу для поповнення, перемикач автоматичного поповнення та доступ до збережених карток.

Усе, що стосується карток — додавання, видалення, вибір за замовчуванням і три способи завершення поповнення — знаходиться в [Способах оплати](payment-methods.md). Минулі поповнення, повернення, списання та бонуси знаходяться в [Історії](history.md).

## Що на екрані

| Елемент                      | Що це означає                                                                                                    |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Реальний баланс**           | Доступний для витрат баланс користувача. Іконка оновлення поруч з ним перечитує баланс із сервера                |
| **Бонуси**                   | Окремий бонусний баланс, показується лише там, де бонуси увімкнені                                              |
| **Попередньо встановлені суми поповнення** | Чотири кнопки: **50**, **100**, **200**, **400**. На цьому екрані немає поля для введення власної суми           |
| **Автоматичне поповнення**   | Один перемикач із описом власного порогу та суми                                                                |
| **Керування способами оплати** | Відкриває [Способи оплати](payment-methods.md) (`/wallet/payment-methods`)                                      |

Якщо користувач наполягає, що його баланс неправильний або застарілий, **спочатку попросіть його натиснути іконку оновлення** — це очищує кешоване значення і зчитує актуальне. Це вирішує більшість скарг "моє поповнення не відображається".

## Як користувач поповнює баланс

1. Відкрити Гаманець.
2. Вибрати одну з попередньо встановлених сум — 50, 100, 200 або 400.
3. Підтвердити поповнення.

Що станеться далі, повністю залежить від платіжного провайдера, і існує рівно **три** варіанти:

| Потік провайдера                 | Що бачить користувач                                                                    | Вихід з додатка? |
| -------------------------------- | --------------------------------------------------------------------------------------- | ---------------- |
| **Підтвердження в додатку** (Stripe) | Оплата підтверджується всередині додатка за збереженою карткою                          | Ні               |
| **Перенаправлення** (MAIB та подібні) | Відкривається зовнішній браузер, користувач оплачує на сторінці банку, додаток чекає підтвердження | Так              |
| **Оплата через QR** (MIA та подібні) | Оплата через QR / банківський додаток з відліком часу, додаток чекає підтвердження       | Так              |

**Лише потік підтвердження в додатку завершується без виходу з додатка.** Для перенаправлення та оплати через QR ніколи не кажіть користувачу, що гроші надходять миттєво — спочатку потрібно завершити оплату зовні. Покрокові інструкції для всіх трьох варіантів є в [Способах оплати](payment-methods.md#поповнення--три-варіанти-процесу).

## Що відбувається одразу після поповнення

Баланс оновлюється миттєво в додатку, потім додаток підтверджує його з сервером, повторюючи кілька разів із збільшенням затримок (приблизно півсекунди, потім 1, 2, 4 і 8 секунд). Якщо підтвердження так і не надійшло, відображений баланс **відкочується** до початкового значення.

Отже, баланс, який коротко з’явився, а потім зник, означає одне: **оплата так і не була підтверджена.** Перевірте список очікуваних поповнень на екрані [Способів оплати](payment-methods.md#поповнення-в-очікуванні).

## Автоматичне поповнення

- Один перемикач із діалогом підтвердження при увімкненні користувачем.
- Воно **вимкнене** там, де поточний провайдер не може підтверджувати платежі всередині додатка. Саме тому користувач із провайдером, що підтримує лише перенаправлення або QR, не може його увімкнути.
- Поріг і сума описані безпосередньо на екрані. Читайте їх із екрана — не цитуйте цифри з пам’яті і не вказуйте обмеження, яких на екрані немає.

## Де зберігається історія платежів

Не тут. Поповнення, повернення, списання та бонуси всі перераховані на вкладці **Платежі** в [Історії](history.md#вкладка-платежі) з кольоровим кодуванням суми та статусу. Ваш власний журнал оператора — [Платежі — Історія](../../operations/payments/payments.md).

## Усунення несправностей

| Користувач каже…                        | Що перевірити                                                                                                                             |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| «Мій баланс неправильний / застарілий»  | Натисніть на іконку оновлення поруч із **Реальним балансом**                                                                              |
| «Платіж відхилено»                      | Відмова з боку картки або банку. Код помилки знаходиться у записі платежу в [Історія → Платежі](history.md#вкладка-платежі)                   |
| «Недостатньо коштів»                     | Баланс нижчий за необхідний для дії. Спочатку поповніть баланс — зверніть увагу, що для початку поїздки існує власний [мінімальний стартовий баланс](../riding/rides.md#чому-користувач-не-може-почати-поїздку) для користувачів без картки |
| «Я не можу увімкнути авто-поповнення»  | Активний провайдер не може підтвердити платежі всередині додатка                                                                            |
| «Моє поповнення не дійшло»              | Перевірте список очікуваних поповнень у розділі [Платіжні методи](payment-methods.md#поповнення-в-очікуванні). Перенаправлення або оплата через QR, які не були завершені, залишаються там і можуть бути скасовані |
| «Коли надійде моє повернення коштів?»   | Не обіцяйте конкретні терміни — у додатку не визначено час повернення коштів. Повернені платежі відображаються на вкладці Платежі зі статусом повернено |

## Поради

- **Оновіть перед розслідуванням.** Половина звернень «гроші зникли» пов’язана з кешованим балансом.
- **Знайте процес вашого провайдера перед відповіддю.** «Миттєвий» означає підтвердження лише в додатку; інші два варіанти потребують завершення користувачем на боці банку.
- **Зниклий баланс — це непідтверджений платіж, а не втрачений.** Перейдіть безпосередньо до очікуваних поповнень.
- **Прив’язка картки повністю знімає обмеження на баланс для поїздок** — для користувачів, які постійно поповнюють невеликими сумами, це краща порада.
