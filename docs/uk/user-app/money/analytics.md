# Rider App — Статистика користувача

**Статистика для користувачів наразі недоступна в додатку.** Немає екрану з графіками, підсумків чи огляду витрат, які користувач міг би відкрити.

Натомість направляйте користувачів до [History](history.md) — це єдине місце з їхніми власними даними.

## Що бачить користувач

- **Відсутня точка входу.** Бічне меню містить Wallet, History, Support, Privacy, Settings та Profile — і нічого більше. Користувач, який каже, що не може знайти екран аналітики, правий; не кажіть їм шукати в меню і не надсилайте посилання на нього.
- Якщо відкрити екран `/analytics` безпосередньо, він показує лише заголовок і порожній простір. **З обліковим записом користувача, пристроєм чи встановленням додатка нічого не не так** — перевстановлення нічого не змінить.

## Де насправді знаходяться дані користувача

[History](history.md) містить реальні дані по кожному користувачу:

- Вкладка **Rides** перераховує всі минулі поїздки з відстанню, тривалістю та вартістю
- Вкладка **Payments** перераховує поповнення, повернення, списання та бонуси з сумами та статусами
- Торкання поїздки відкриває її деталі з повним [розподілом вартості](../riding/rides.md#розбивка-вартості), хронологією активності та маршрутом на карті

У додатку для користувача **немає банера з підсумками** — ні на жодному екрані статистики, ні вгорі History. Загальні підсумки за весь час потрібно підраховувати з переліку поїздок або отримувати зі звітів.

## Відповіді на питання про цифри з панелі керування

Коли користувачу справді потрібні підсумки, формуйте їх на стороні оператора:

| Користувач хоче                  | Де це отримати                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------- |
| Загальні витрати за період      | [Analytics — Payments](../../analytics/reports/payments.md)                      |
| Власний список поїздок, експорт | [Rides — List](../../operations/trips/rides.md), відфільтрований за клієнтом     |
| Записи про платежі              | [Payments — History](../../operations/payments/payments.md)                      |
| Короткий підсумок по клієнту   | [Client Detail](../../operations/customers/client-detail.md) — загальна кількість поїздок, баланс, рейтинг |

## FAQ

| Користувач запитує…             | Відповідь                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------- |
| «Де моя статистика?»             | Наразі недоступна в додатку. Використовуйте [History](history.md)                |
| «Я не можу знайти Analytics у меню» | У меню немає такого пункту                                                    |
| «Сторінка Analytics порожня»    | Очікувано — цей екран наразі недоступний. Нічого не зламано                      |
| «Чи можу я експортувати дані поїздок?» | Ні, не з додатка. Експортуйте з панелі керування від імені користувача         |
| «Скільки я витратив загалом?»   | Загального підсумку в додатку немає. Дивіться History або отримуйте з панелі керування |

## Поради

- **Не надсилайте користувачам посилання на аналітику.** Немає сенсу потрапляти на порожній екран, це виглядає як зламаний додаток.
- **Відповідайте на питання про підсумки самі.** Отримання цифр з панелі керування займає хвилину і завершує розмову.
- **History — це чесна відповідь**, і вона справді повна по кожній поїздці та платежу — подавайте це саме так, замість вибачень за відсутність екрану.
