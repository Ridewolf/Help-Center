# Профіль — Деталі облікового запису, пароль та видалення

Екран **Профіль** (`/profile`) — це власний екран облікового запису користувача: що оператор знає про нього, а також усі дії на рівні облікового запису — фото, ім'я, пароль, сесії, вихід і видалення.

Саме тут відбувається фактичне видалення облікового запису. Кнопка на екрані Конфіденційність не призначена для цього — див. [Privacy](privacy.md).

## Що показує екран

| Поле               | Редагується? | Примітки                                            |
| ------------------ | ----------- | -------------------------------------------------- |
| **Фото**           | Так         | Аватар 96 × 96 з накладкою камери для зміни         |
| **Повне ім'я**     | Так         | Відображається тут, редагується у формі редагування |
| Значок статусу     | Ні          | Читайте напис так, як він показаний                 |
| **Електронна пошта** | Ні          | Тільки для перегляду                                |
| **Телефон**        | Ні          | Тільки для перегляду                                |
| **Статус облікового запису** | Ні          | Тільки для перегляду                                |
| **Член з**         | Ні          | Дата створення облікового запису                    |

Дата народження **не** відображається на цьому екрані. Вона збирається під час реєстрації, але тут не показується і не редагується, тому не направляйте користувача сюди для її зміни.

## Редагування імені

1. Натисніть на іконку **олівець**
2. Відкривається форма редагування з полями **Ім'я** та **Прізвище** — і нічим іншим. Обидва поля обов’язкові
3. Зберегти

Електронна пошта та телефон тут не редагуються, і в додатку немає процесу для їх зміни. Якщо користувачу потрібна інша електронна пошта або телефон, ваша команда має це зробити через панель керування — див. [Client — Create & Edit](../../operations/customers/client-create-edit.md).

Одна зручність: користувача, який увійшов через Apple або Google, можуть попросити ввести справжнє ім'я, оскільки ім'я, яке повертають ці сервіси, не завжди придатне для використання.

## Зміна фото

Натискання на аватар відкриває форму вибору фото з трьома джерелами:

- **Зробити фото** — камера телефону
- **Вибрати з галереї**
- **Вибрати файл**

Обмеження: **JPEG, JPG, PNG або WEBP, не більше 10 МБ**. Кадрування відсутнє — фото використовується як є, тому скажіть користувачам заздалегідь правильно його сфотографувати. Після завантаження нове фото замінює старе у всьому додатку.

## Зміна пароля

Форма **Змінити пароль** запитує три поля:

| Поле                 | Правило                                  |
| --------------------- | ---------------------------------------- |
| **Поточний пароль**   | Обов’язкове                             |
| **Новий пароль**      | Має відповідати показаним правилам     |
| **Підтвердження пароля** | Має співпадати з новим паролем           |

Попередьте користувача перед початком: **успішна зміна пароля призводить до виходу з облікового запису** і повертає його на екран входу з повідомленням про підтвердження. Це передбачена поведінка, а не помилка — користувач просто входить знову з новим паролем.

Неправильний поточний пароль показує помилку безпосередньо у цьому полі. Будь-яка інша помилка відображається коротким повідомленням у верхній частині екрана.

## Керування сесіями

**Керування сесіями** відкриває `/settings/sessions`, список усіх пристроїв, увійшлих в обліковий запис. Див. [Sessions](sessions.md) для списку пристроїв і дій виходу з усіх сесій.

## Вихід з облікового запису

Кнопка **Вийти** завершує сесію на цьому пристрої і повертає користувача на початок додатку. Це не впливає на інші пристрої — для них використовуйте [Sessions](sessions.md).

## Видалення облікового запису — робочий процес

1. Кнопка **Видалити обліковий запис** з’являється лише якщо видалення ще не заплановане
2. Натискання відкриває діалог підтвердження
3. Після підтвердження видалення планується
4. Кнопка замінюється на індикатор очікування: іконка годинника, **Заплановано на {date}**, і кнопка **Скасувати**, якщо скасування ще дозволене

Щоб скасувати, користувач натискає **Скасувати**, підтверджує у діалозі, і звичайна кнопка **Видалити обліковий запис** повертається.

Для цього процесу не потрібен нульовий баланс — користувач із залишком у гаманці все одно може запланувати видалення, тому нагадайте йому спочатку витратити або повернути кошти, якщо це важливо. Див. [Wallet](../money/wallet.md).

## Поки видалення очікується

Редагування профілю, зміна пароля, завантаження фото та керування сесіями **усі вимкнені**, поки видалення заплановане.

Це відповідь, коли користувач скаржиться, що кнопки на екрані Профілю сірі: у нього заплановане видалення. Скасування відновлює всі функції.

## FAQ

- **Чому користувач не може редагувати тут електронну пошту або телефон?** Форма редагування містить лише ім'я та прізвище; обидва контактні поля лише для перегляду, і немає внутрішнього процесу зміни.
- **Чому всі кнопки вимкнені?** Заплановане видалення облікового запису. Скасуйте його.
- **Користувач вийшов одразу після зміни пароля.** Це очікувано — успішна зміна пароля вимагає повторного входу.
- **Що означають значення статусу?** Читайте напис **Статус облікового запису** так, як він показаний; не зіставляйте з фіксованим списком значень.
- **Користувач питає про видалення облікового запису з екрана Конфіденційність.** На екрані Конфіденційність немає кнопки видалення — він лише інформативний. Використовуйте **Профіль → Видалити обліковий запис** — див. [Privacy](privacy.md).
