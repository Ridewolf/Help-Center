# Сесії — Пристрої, увійшли в обліковий запис

Екран **Сесії** (`/settings/sessions`) показує всі місця, де наразі увійшов обліковий запис користувача, і дозволяє вийти з цих місць. Це екран, до якого слід звертатися, якщо користувач підозрює, що хтось інший має доступ до його облікового запису.

Два входи, які ведуть сюди:

- **Профіль → Керувати сесіями**
- **Налаштування → Картка Конфіденційність → Керувати сесіями**

## Як організовано список

Сесії **групуються за пристроєм** — браузер і версія, операційна система і версія, тип пристрою, виробник і модель — тому один і той же телефон показується один раз, а не десятки разів.

Групи сортуються навмисно:

1. Спочатку поточний пристрій користувача
2. Потім за статусом: **активні**, потім **неактивні**, потім **старі**
3. Потім за останньою активністю, спочатку найновіші

Кожна група згортана. Розгортання показує всі окремі сесії, що належать цьому пристрою.

## Як читати групу пристроїв

| Що ви бачите                      | Значення                                                                                  |
| --------------------------------- | ---------------------------------------------------------------------------------------- |
| **Назва пристрою**                | Виробник і модель, якщо відомі, інакше операційна система та її версія                    |
| Іконка типу пристрою             | Телефон, планшет або монітор                                                            |
| **Назва браузера**                | Браузер і версія, що стоять за сесією                                                   |
| Значок **статусу сесії**         | Див. таблицю нижче                                                                       |
| **Остання активність**            | Відносний час — «щойно», N хвилин / годин / днів тому, і абсолютна дата, якщо минуло більше тижня |
| **Кількість сесій**               | Скільки сесій має цей пристрій                                                          |
| **Місцезнаходження**              | Місто, країна та IP-адреса                                                              |
| **Створено**                     | Коли ця сесія почалася                                                                  |
| **Поточний пристрій** / **Поточна сесія** | Виділений значок на пристрої та сесії, якими користується користувач зараз               |

### Значки статусу

| Значок       | Значення                              |
| ------------ | ------------------------------------ |
| **активний** | Остання активність була менше години тому  |
| **неактивний** | Остання активність була менше 24 годин тому |
| **старий**   | Остання активність була 24 години або більше тому   |

Значок показує **лише свіжість** — він не означає, що сесія все ще дійсна. Значок «старий» не означає, що сесія закінчилася.

## Вихід з однієї сесії

Поточна сесія не має кнопки видалення — це зроблено навмисно, її не можна видалити зі списку. Будь-яку іншу сесію можна:

1. Розгорнути групу пристрою
2. Натиснути іконку **кошика** на сесії
3. Підтвердити у діалоговому вікні

Список оновиться, і сесія зникне.

## Масові дії

| Дія                         | Що робить                                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Вийти з інших сесій**     | Виходить з усіх сесій, крім тієї, що на пристрої користувача. Це правильна дія, якщо користувач підозрює, що хтось інший має доступ |
| **Вийти з усіх сесій**      | Виходить з усіх сесій, **включно з поточним пристроєм**, тому користувач повертається на екран входу і має увійти знову. Через це оформлено як руйнівну дію |
| **Відкликати пристрій**     | Доступно на розгорнутій групі пристроїв, що не є поточним — виходить з усіх сесій на цьому пристрої          |

Поки виконується запит на вихід, кнопки вимкнені. У разі помилки показується коротке повідомлення; у разі успіху — підтвердження і оновлення списку.

## Типові сценарії

- **Користувач думає, що хтось інший увійшов у його обліковий запис** — **Вийти з інших сесій**, потім змінити пароль у **Профілі**. Зверніть увагу, що успішна зміна пароля також виходить із системи, тому користувач увійде знову ([Профіль](profile.md))
- **Забутий вхід на позиченому телефоні** — розгорнути групу пристроїв, **Відкликати пристрій**
- **Почати все з чистого аркуша** — **Вийти з усіх сесій**, потім увійти знову ([Вхід](registration-login.md))

## Поширені запитання

- **Чому користувач не може видалити поточну сесію?** Для неї не показується кнопка видалення. Щоб завершити поточну сесію, використовуйте **Вийти з усіх сесій** або звичайну кнопку **Вийти** у Профілі.
- **Що означає «активний»?** Активність протягом останньої години — нічого більше.
- **Чому один телефон показує кілька сесій?** Сесії створюються при кожному вході. Екран групує їх під одним пристроєм і показує кількість.
- **Кнопка Керувати сесіями сірого кольору.** Обліковий запис очікує на видалення, що вимикає керування сесіями разом із редагуванням профілю — див. [Профіль](profile.md).
