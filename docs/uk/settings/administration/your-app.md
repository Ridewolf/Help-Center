# Ваш додаток (White-Label)

Сторінка Ваш додаток (`/settings/your-app`) — це **майстер, який збирає все необхідне для створення та публікації брендованого додатка для користувачів під вашим ім'ям** — назва додатка, домен, брендовані матеріали, текст для магазину, скріншоти та юридичні посилання. Живий перегляд на пристрої поруч із формою показує ваші вибори на макетах iPhone та Android у міру введення.

Знайдіть її в бічному меню під **Налаштування → Ваш додаток**.

Майстер має вісім кроків: **Ідентичність → Домен → Матеріали → Опис → Скріншоти → Юридичне → Видавець → Перевірка**. Ця стаття охоплює перші шість; Видавець і Перевірка описані в [Your App: Publisher & Submission](your-app-publisher.md).

## Життєвий цикл статусу

Картка статусу вгорі показує, на якому етапі ваш додаток, з версією та часовими позначками:

**чернетка → підготовка → на перевірці → у виробництві**, або **відхилено**.

- Майстер **редагується**, поки статус `draft` або `rejected` — відхилення відкриває форму знову, щоб ви могли виправити зауваження магазину.
- Він **тільки для читання**, поки додатком керує конвеєр: `provisioning`, `in-review` та `production`. У цих станах сторінка є підсумком, а посилання на магазини — **TestFlight, Play internal testing, App Store, Play Store** — з’являються по мірі їх доступності.

## Крок Ідентичність

- **Назва додатка** (обов’язково) — вона **автоматично формує iOS bundle id, Android bundle id та субдомен**, тому обирайте уважно.
- **Перевизначення bundle** — перемикач, що дозволяє вручну ввести iOS та Android bundle id, якщо автоматично згенеровані не підходять.
- **Колір іконки** — шістнадцяткове значення, що використовується для оболонки іконки додатка та фону заставки.

## Крок Домен

- **Тип домену** — радіокнопка між **субдоменом** (виводиться з назви додатка) та **кастомним**.
- **Кастомний домен** — текстове поле, що з’являється лише при виборі типу `custom`.

## Крок Матеріали

- Перемикач **Монохромний** — визначає, чи одна версія графіки підходить для обох тем.
- **Символ** та **логотип** — завжди обов’язкові.
- **Символ / логотип для темної теми** — показується лише коли Монохромний вимкнено, тобто коли ви надаєте окремі світлу та темну версії.

Зону завантаження можна використовувати для перетягування файлів або вставки URL. Пряме завантаження бінарних файлів наразі недоступне — на практиці поки що подавайте кожен матеріал як URL.

## Крок Опис

Текст для магазину з обмеженнями на кількість символів, які контролюють поля вводу:

| Поле                 | Обмеження                                  |
| --------------------- | ------------------------------------------- |
| **Підзаголовок**      | 30 символів                                |
| **Короткий опис**     | 80 символів                                |
| **Промо-текст**       | 170 символів (промо-текст App Store)      |
| **Ключові слова**     | 100 символів, через кому                    |
| **Повний опис**       | 4000 символів                              |

- **Категорія** — подорожі, навігація, спорт, стиль життя, здоров’я та фітнес, або бізнес.
- **Мови магазину** — оберіть із підтримуваного набору локалей. **Перша обрана мова є базовою**; кожна додаткова мова отримує власну вкладку з можливістю локальних замін для підзаголовка, описів, промо-тексту та ключових слів. Порожні поля в замінах автоматично перекладаються з базової мови.

## Крок Скріншоти

Шість фіксованих варіантів скріншотів, кожен потребує **заголовка** та **підзаголовка**: `map`, `reserve`, `timer`, `ride`, `group`, `wallet`. Живий перегляд пристрою в правій колонці відображає їх з вашими брендованими матеріалами, оновлюючись у міру введення.

## Крок Юридичне

Політика конфіденційності, умови обслуговування, URL підтримки, електронна пошта підтримки, телефон підтримки та маркетинговий URL. Ці поля **автоматично заповнюються з профілю [Моя компанія](my-company.md)**, якщо там є відповідні значення — спочатку заповніть Моя компанія, щоб зекономити час.

## Поширені питання

- **Bundle id виглядають неправильно.** Вони формуються з назви додатка — увімкніть перевизначення bundle, щоб задати їх вручну.
- **Поля для темної версії відсутні.** Вони з’являються лише коли Монохромний вимкнено.
- **Я більше не можу нічого редагувати.** Статус `provisioning`, `in-review` або `production` — додатком керує конвеєр. Редагування відкривається автоматично, якщо подання відхилено.
- **Текст підзаголовка обрізається.** Ліміт — 30 символів, менше, ніж ви могли очікувати.
- **Поле кастомного домену не видно.** Спочатку виберіть тип домену `custom`.
- **Сторінка показує повідомлення про "локальну чернетку".** Ваші зміни зберігаються лише в цьому браузері і ще не синхронізовані — не припускайте, що вони збережуться автоматично; перевірте форму знову, коли повідомлення зникне.
