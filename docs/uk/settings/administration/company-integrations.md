# Платежі та інтеграції

Вкладки **Платежі** та **Інтеграції** на сторінці [Моя компанія](my-company.md) (`/settings/my-company`, **Розширений режим**) містять облікові дані сторонніх сервісів: платіжні шлюзи, які стягують оплату з ваших користувачів, та інтеграції сервісів, що забезпечують вхід, обмін повідомленнями та AI-асистента.

У Розширеному режимі в Моїй компанії є чотири вкладки — Профіль, Конфігурація додатка, **Платежі**, **Інтеграції**. Ця стаття охоплює останні дві.

## Вкладка Платежі

1. **Виберіть валюту компанії** — тут редагується валюта (та її символ), **не на вкладці Профіль**. У випадаючому списку 16 кодів: USD, EUR, GBP, CHF, RON, MDL, GEL, UAH, RUB, TRY, PLN, CZK, HUF, BGN, ILS, AED.
2. **Налаштуйте по одній картці на кожного платіжного провайдера** — **maib**, **mia**, **Stripe**.
3. Кожна картка має перемикач **увімкнено**, власні поля облікових даних і прапорець **за замовчуванням**.

Рівно **один провайдер виступає за замовчуванням** для нових платежів, і він має бути серед увімкнених/підтримуваних провайдерів.

## Вкладка Інтеграції

П’ять карток, кожна з власним перемикачем увімкнення та обліковими даними:

| Картка       | Облікові дані                                      | Забезпечує                  |
| ------------ | -------------------------------------------------- | ---------------------------- |
| **Telegram** | токен бота, ім’я користувача бота                  | Вхід / обмін повідомленнями Telegram |
| **WhatsApp** | ID бізнес-акаунта, ID номера телефону, токен доступу | Вхід / обмін повідомленнями WhatsApp |
| **Google**   | client ID, client secret                           | Вхід через Google для користувачів |
| **Apple**    | client ID, team ID, key ID, приватний ключ          | Вхід через Apple для користувачів |
| **OpenAI**   | API key                                            | AI-асистент на Панелі керування |

## Кожна картка зберігається окремо

Кожна картка платіжного провайдера та інтеграції **зберігається індивідуально** — вони не входять до загального збереження сторінки. Збереження вкладок Профіль або Конфігурація додатка не зберігає ці картки, і навпаки. **Зберігайте кожну змінену картку.**

## Відношення до методів входу користувачів

Методи автентифікації на вкладці Конфігурація додатка для Google, Apple, Telegram і WhatsApp працюють лише після того, як **відповідна картка Інтеграції увімкнена та налаштована**. Спочатку налаштуйте інтеграцію, потім увімкніть метод входу.

## Секрети

- Поля секретів **візуально приховані** так, щоб браузерні менеджери паролів не намагалися їх зберегти або автозаповнити.
- **При оновленні секрету свідомо введіть повне значення заново**, не покладайтеся на прихований заповнювач.

## Telegram: два різні налаштування

Окремо від картки Інтеграції Telegram існує процес **виявлення OTP-бота Telegram**: введіть токен бота, натисніть **Перевірити чати** і виберіть чат зі списку. Цей процес призначений для доставки одноразових паролів і є **іншим налаштуванням**, ніж картка Інтеграції Telegram — налаштування одного не налаштовує інше.

## Поширені питання

- **Я змінив облікові дані, але нічого не змінилося.** Кожна картка зберігається окремо — переконайтеся, що ви зберегли саме цю картку, а не лише сторінку.
- **Соціальний вхід недоступний користувачам.** Картка провайдера має бути увімкнена та налаштована тут, перш ніж відповідний метод входу в Конфігурації додатка запрацює.
- **Я не можу вибрати провайдера за замовчуванням.** За замовчуванням можна вибрати лише серед провайдерів, які фактично налаштовані як підтримувані.
- **Де поле валюти?** На цій вкладці Платежі — не на вкладці Профіль.
- **"Перевірка чатів" не вдається з дійсним токеном.** Спочатку розглядайте це як проблему середовища/підключення, а не як помилку токена.
