# Загальні

Сторінка Загальні (`/settings/general`) — це **системна панель керування** — одне місце для встановлення значень за замовчуванням, які керують додатком для користувачів, флотом, ціноутворенням, поїздками, сповіщеннями та перемикачами для розробників. Все тут застосовується глобально для всієї компанії; індивідуальні налаштування для транспортних засобів або тарифів знаходяться в [Налаштуваннях транспортних засобів](../infrastructure/vehicle-settings.md) та [Тарифи на транспортні засоби](../infrastructure/vehicle-tariffs.md).

> _Примітка_: ця сторінка наразі є **екраном лише фронтенду** — кожне значення зберігається у локальному стані, а кнопка **Зберегти** лише показує підтвердження у вигляді тосту. Дані поки що не надсилаються на бекенд. Розглядайте це як специфікацію / тестовий інтерфейс для майбутнього API.

Маршрут `/settings/general-settings` — це окремий, майже порожній **заповнювач** з однією ілюстрацією та заголовком. Справжній екран конфігурації — `/settings/general` (ця стаття) — саме там розташовані всі шість вкладок.

Потрібні права: у маршрутизаторі не встановлено конкретних `requiredPermissions` — будь-який авторизований оператор може відкрити цю сторінку.

## Вкладки

Сторінка має шість вкладок у верхній частині (на десктопі). На мобільних пристроях ті ж вкладки згортаються в акордеон із повідомленням _Використовуйте десктоп для повної конфігурації_ — ці налаштування призначені лише для адміністраторів.

| Вкладка       | Іконка      | Що охоплює                                                                                              |
| ------------- | ----------- | ------------------------------------------------------------------------------------------------------ |
| App           | sliders     | Блокування оновлення додатка, видимість модулів за замовчуванням, прапорці функцій, обмеження швидкості API, налаштування транспортних засобів за замовчуванням             |
| Locale        | globe       | Мова за замовчуванням, часовий пояс, увімкнені мови, формати дати / часу / одиниць, провайдер карти + стилізація зон |
| Pricing       | dollar sign | Значення ціноутворення за замовчуванням, шаблони тарифів, політика знижок/промо, налаштування підписок                      |
| Rides         | car         | Правила бронювання та поїздок, авто-пауза/авто-стоп, штрафи, обробка платежів                          |
| Notifications | bell        | Перемикачі каналів (push / email / SMS) та шаблони повідомлень для подій користувача                            |
| Advanced      | code        | Інтеграції, безпека, збереження приватності, юридичні сторінки, прапорці розробника, технічне обслуговування системи            |

Прикріплений футер із кнопками **Відхилити** та **Зберегти зміни** з’являється внизу лише після того, як ви фактично змінили поле — сторінка використовує `useFormState` для порівняння зі збереженим знімком.

## Розділи на вкладках

### App

Два картки, розташовані одна над одною.

**Налаштування додатка за замовчуванням**

- _Вимагати оновлення додатка_ — перемикач + текстове поле для мінімальної версії (неактивне, поки перемикач вимкнено). Якщо увімкнено, додаток Rider App блокуватиме користувачів із версією нижче вказаної.
- _Видимість модулів за замовчуванням_ — чотири перемикачі (Маркетинг, Ребаланс, Підтримка, Аналітика), які попередньо встановлюють, які модулі бачать нові оператори.
- _Прапорці функцій_ — чотири перемикачі (Живе відстеження, Розширена статистика, Мультивалюта, Білий лейбл).
- _Обмеження швидкості API_ / _Обмеження швидкості UI_ — числові поля (за замовчуванням 1000 / 100 запитів на хвилину).

**Налаштування транспортних засобів за замовчуванням**

- _Набір іконок за замовчуванням_ — пошуковий випадаючий список назв наборів іконок (поки що чотири жорстко закодовані макети: Default Icons / Modern Set / Minimalist / Color Bold; справжній список буде з [Наборів іконок](../content/icon-sets.md)).
- _Пороги заряду батареї_ — два числові поля (Низький %, Критичний %). Перевірка виконується при збереженні: критичний повинен бути меншим за низький, інакше з’явиться повідомлення про помилку.
- _Ваги показника здоров’я_ — три поля відсотків (сигнал / помилки / батарея). Перевіряється, що сума дорівнює 100 при збереженні.
- _Автоматичні теги_ — рядок тегів, розділених комами, які автоматично застосовуються до нових транспортних засобів.

### Locale

- _Мова за замовчуванням_ / _Часовий пояс_ — вибір.
- _Увімкнені мови_ — мультивибір; X для видалення.
- _Початок тижня_ — понеділок / неділя.
- _Формат дати_ — DD/MM/YYYY, MM/DD/YYYY, ISO тощо.
- _Формат часу_ — 12-годинний / 24-годинний.
- _Одиниця температури_ — Цельсій / Фаренгейт.
- _Одиниця відстані_ — км / милі.
- _Валюта відображення_ — за замовчуванням EUR (TODO у коді: завантажити з API компанії).
- _Округлення цін_ — без округлення / до найближчих 0.05 / тощо.

**Карти** (окрема картка на тій же вкладці)

- _Провайдер_ (за замовчуванням MapTiler) та _Стиль_ (світлий / темний / супутниковий).
- _API ключ_ — текстове поле для ключа провайдера.
- _Масштаб за замовчуванням_ + _Центр за замовчуванням_ — використовуються, коли немає GPS-контексту.
- _Стилізація зон_ — колір + ширина обводки для полігонів Паркування / Заборонено / Низька швидкість / Платне паркування. Вибір кольорів із палітри з 12 кольорів.
- _Обмеження швидкості_ — числове (км/год).

### Pricing

Чотири картки: _Значення ціноутворення за замовчуванням_, _Шаблони тарифів_, _Знижки та промо_, _Підписки_. Вони встановлюють **значення за замовчуванням** — фактичне ціноутворення поїздок перевизначається для кожного транспортного засобу через [Тарифи на транспортні засоби](../infrastructure/vehicle-tariffs.md).

- Значення ціноутворення за замовчуванням: плата за розблокування, ціна за хвилину, ціна за кілометр, платне очікування, безкоштовні хвилини бронювання, двоступенева знижка залежно від кількості поїздок.
- Шаблони тарифів: за період (хвилина / година / день / тиждень / місяць / рік) — ціна, максимальна тривалість, перемикач безкоштовного паркування, перемикач увімкнення. Плюс _дозволити накладання_.
- Знижки та промо: максимальний відсоток знижки, префікс промо (за замовчуванням `WOLF`), стандартна кількість днів дії, правила накладання.
- Підписки: стандартний відсоток знижки, пробні дні, автоматичне поновлення, дозвіл на промокоди.

### Rides

- Правила бронювання та поїздок: безкоштовні хвилини бронювання, максимальна кількість активних бронювань на клієнта, мінімальний баланс для початку, авто-пауза + авто-стоп (кожен із увімкненням + порогом).
- Штрафи: два типи штрафів (поза зоною, неправильне паркування) — кожен із сумою штрафу та рядком попереджувального повідомлення.
- _Швидкий посібник за замовчуванням_ — випадаючий список із заповнювача; буде взято з [Швидких посібників](../content/quick-guides.md).
- _Набір FAQ за замовчуванням_ — випадаючий список із [Наборів запитань і відповідей](../content/faq-sets.md).
- Картка платежів: 3-D Secure, режим захоплення (негайний / попередня авторизація), сума попередньої авторизації, тривалість утримання (години), політика повернення, максимальний термін повернення (дні).

### Сповіщення

- _Канали_ — три перемикачі (Push / Email / SMS) — контролюють, які канали доступні в додатку для райдера.
- _Шаблони_ — заголовок + текст тіла для трьох основних подій: Поїздка почалася, Поїздка завершена, Накладено штраф. Змінні, як-от `{{amount}}` / `{{reason}}`, підставляються бекендом.
- Кнопка **Тестове сповіщення** показує інформаційне повідомлення (реального відправлення поки немає).

Для **операторської** системи сповіщень дивіться [Alerts & Notifications](alerts-notifications.md) — ця вкладка тут для сторони додатка райдера.

### Розширені налаштування

П’ять карток.

- _Інтеграції_ — webhook endpoint + секрет, Google Analytics ID, Sentry DSN, рядки для ботів Telegram і Slack. Кнопка **Тест webhook** показує повідомлення.
- _Безпека_ — перемикач вимоги 2FA, таймаут сесії (хв), політика паролів (мінімальна довжина + великі літери/цифри/спецсимволи), ключі reCAPTCHA, білый список IP, випадаюче меню обмежень експорту.
- _Конфіденційність_ — зберігання даних у днях (телеметрія / медіа / логи), перемикач анонімізації GPS, SLA експорту та видалення у днях.
- _Юридичне_ — Умови обслуговування + Політика конфіденційності у вигляді Markdown-текстових полів, а також рядок версії та дата публікації.
- _Розробник / Розширені_ — режим пісочниці, рівень логування, URL-адреси продакшн і стейджинг, перемикачі експериментів (AI маршрутизація, прогнозне обслуговування, динамічне ціноутворення).
- _Система / Технічне обслуговування_ — перемикач режиму обслуговування + текст банера + перемикач режиму лише для читання.
- _Аудит і резервні копії_ — кнопки _Створити резервну копію_ та _Видалити всі дані_ (обидві показують повідомлення; кнопка видалення каже, що _потрібне підтвердження адміністратора_ — поки не підключено).

## Робочі процеси

- **Заблокувати новий реліз** — вкладка App → увімкнути _Вимагати оновлення додатка_ → встановити мінімальну версію → Зберегти. Райдери зі старими версіями отримають запит на оновлення.
- **Додати мову** — вкладка Locale → _Увімкнені мови_ → вибрати мітку локалі → Зберегти. Рядки ще потрібно перекласти через [Localization](localization.md).
- **Налаштувати UX штрафів для райдера** — вкладка Rides → відрегулювати плату за виїзд за межі зони + текст попередження → Зберегти.
- **Поставити платформу на паузу для обслуговування** — вкладка Advanced → _Система / Технічне обслуговування_ → переключити перемикач, відредагувати текст банера, за бажанням увімкнути режим лише для читання → Зберегти.
- **Впровадити новий стиль карти** — вкладка Locale → картка _Maps_ → вибрати стиль → налаштувати кольори зон → Зберегти (зміни застосуються глобально після підключення API).

## Поради

- **Поки що лише фронтенд.** Збереження робить локальний знімок, але не надсилає дані на бекенд — не покладайтеся на цю сторінку для збереження, доки API не буде підключено.
- **Валідація відбувається при Збереженні.** Пороги батареї (критичний < низький) і ваги оцінки стану (сума 100) перевіряються при натисканні Зберегти, а не під час введення — виправте помилку в повідомленні і спробуйте знову.
- **Не плутайте з `/settings/general-settings`.** Цей маршрут існує, але показує лише порожню картку-заповнювач — відкривайте `/settings/general` для справжнього екрану.
- **Відхилити — ваша страховка** — футер з’являється лише при наявності незбережених змін; натисніть _Відхилити_, щоб повернутися до завантаженого знімка без виходу зі сторінки.
- **Мобільна версія навмисно обмежена.** Підключено лише акордеон App; решта просто перенаправляє на десктопну сесію.
- **Перевага за транспортним засобом.** Все, що ви налаштовуєте в Pricing / Rides, є за замовчуванням; фактичний тариф, який платить райдер, береться з Vehicle Tariff, прив’язаного до моделі — дивіться [Vehicle Tariffs](../infrastructure/vehicle-tariffs.md).
