# Локалізація

Сторінка Локалізації (`/settings/localization`) — це **робоче місце перекладача** — бібліотека _Колекцій_ (груп пов’язаних ключів перекладу), які ви редагуєте, імпортуєте, експортуєте та публікуєте. Кожна колекція має простір імен (наприклад, `ui`, `auth`, `rides`), базову мову (завжди `en`), набір цільових мов і список ключів із значеннями для кожної мови.

> _Примітка_: ця сторінка наразі є **прототипом лише фронтенду** — колекції завантажуються з `mockData.ts` і зберігаються у локальному стані. _Збереження_ та _Публікація_ показують підтвердження, але бекенд-ендпоінт ще не реалізований. Сторінка безпечна для використання як специфікація API; нічого тут не зберігається постійно.

Необхідні права: на маршруті не встановлено конкретних `requiredPermissions` — будь-який авторизований оператор може її відкрити.

## Макет сторінки

Один заголовок із назвою сторінки, поле пошуку, випадаюче меню _Імпорт / Експорт_ та кнопка _+ Створити колекцію_ — далі картка Фільтрів і таблиця Колекцій.

Довідкові дані (поки що жорстко закодовані у `Localization.vue`):

- Мови: `en`, `ro`, `ru`, `de`, `fr`, `es` (базова + 5 цільових)
- Прості імен: `ui`, `auth`, `rides`, `payments`, `marketing`
- Теги: `core`, `beta`, `promo`, `legacy`

## Фільтри

Картка Фільтрів розташована над таблицею.

| Фільтр    | Тип            | Примітки                                                                      |
| --------- | -------------- | ---------------------------------------------------------------------------- |
| Мова      | Випадаюче меню | Фільтрує колекції, що містять цю мову. За замовчуванням `ro`                  |
| Простір імен | Випадаюче меню | Один із списку просторів імен (або порожнє для всіх)                         |
| Статус    | Випадаюче меню | `all`, `active`, `draft`, `archived`                                         |
| Теги      | Перемикачі     | Мультивибір тегів — колекція має містити _кожен_ вибраний тег, щоб пройти фільтр |
| Пошук     | Текст (панель) | З затримкою 300 мс — шукає за ім’ям, описом, простором імен                   |

Кнопка _Очистити_ на картці Фільтрів скидає всі чотири фільтри.

## Створення / Редагування / Перегляд — діалог Колекції

Відкривається з + Створити або будь-якої дії рядка. У діалозі чотири вкладки.

### Вкладка Огляд

Редагуйте метадані колекції.

- _Ім’я_ (обов’язкове) — відображуване ім’я (наприклад, "UI Labels").
- _Простір імен_ — вибір із пошуком.
- _Опис_ — короткий опис.
- _Базова мова_ — лише для читання, завжди `en`.
- _Цільові мови_ — перемикачі з п’яти неанглійських варіантів. Базова + цільові разом формують набір мовних стовпців на вкладці Ключі.
- _Статус_ — `active` / `draft` / `archived`.
- _Теги_ — перемикачі з переліку тегів.

### Вкладка Ключі

Фактична сітка перекладів.

- Панель інструментів: поле пошуку (збігається з ім’ям ключа та будь-яким значенням), фільтр за статусом (наприклад, _Тільки відсутні_), вибір мови (який цільовий стовпець підсвічено як фокус редагування).
- Масові дії при виборі ключів: _Встановити статус_, _Очистити значення_, _Експортувати вибране_, _Видалити_.
- Дії для кожного рядка: дублювати ключ, видалити ключ, копіювати з англійської (заповнює поточний цільовий стовпець значенням EN), перевірка заповнювачів (перевіряє, що такі елементи як `{{name}}` в EN збережені в цільовій мові).
- Кожен рядок має необов’язкові прапорці, що відображаються бейджами:

| Позначка   | Значення                                                      |
| ---------- | -------------------------------------------------------------- |
| `new`      | Ключ додано нещодавно — потребує перевірки людиною            |
| `changed`  | Значення EN змінено з моменту останнього перекладу — цільові можуть бути застарілими |
| `missing`  | Порожнє значення принаймні в одній цільовій мові              |
| `obsolete` | Ключ більше не використовується в коді — можна безпечно видалити |

- _Додати ключ_ та _Знайти й замінити_ відкривають окремі міні-діалоги.
- Перемикач _Автозбереження_ — при ввімкненні зміни значення одразу фіксуються в локальному стані.

### Вкладка Імпорт / Експорт

Імпорт:

- _Формат_ — JSON / CSV / XLSX.
- _Режим_ — замінити існуючі значення / об’єднати / додати.
- Перемикач _Зберігати невідомі ключі_ — якщо вимкнено, ключі, яких немає у файлі імпорту, позначаються як `obsolete`.
- _Симуляція_ — пробний запуск, що показує, що зміниться (без запису).
- _Застосувати_ — підтвердити імпорт. Під час виконання відображається індикатор прогресу.

Експорт:

- _Формат_ — JSON / CSV / XLSX.
- _Область_ — усі ключі / відфільтровані ключі / вибрані ключі.
- _Завантажити_ — тимчасова дія (поки що повідомлення).

### Вкладка Публікація

- Блок з підсумком: _Всього ключів N / Змінено M / Відсутні K_.
- Список змінених ключів з попередніми та новими значеннями.
- Список попереджень (наприклад, невідповідність заповнювачів, відсутність у цільовій мові).
- _Зберегти чернетку_ — зберігає робочу копію як чернетку (`status = draft`).
- _Опублікувати_ — переводить чернетку в `active` і показує повідомлення.

## Верхня панель — меню Імпорт / Експорт

Два глобальні ярлики в заголовку сторінки (окремо від дій для кожної колекції):

- _Імпортувати колекції_ — відкриває діалог імпорту на рівні сторінки (масовий імпорт кількох колекцій одночасно).
- _Експортувати все_ — ярлик для експорту всіх колекцій одним пакетом (поки що повідомлення).

## Незбережені зміни та захист навігації

Існує глобальний прапорець "незбережені зміни" (`hasUnsavedGlobal`) — коли він увімкнений, з’являється закріплений футер з кнопками _Відхилити_ / _Зберегти_. Також встановлено захист `router.beforeEach`: спроба покинути сторінку з незбереженими змінами викликає вбудований браузерний діалог підтвердження.

## Робочі процеси

- **Перекласти новий ключ румунською** — Вибрати колекцію в таблиці → Редагувати → Вкладка Ключі → встановити мову `ro` → знайти ключ (або _Додати ключ_) → заповнити значення → _Зберегти_ (або увімкнути Автозбереження).
- **Перевірити відсутні переклади французькою** — Редагувати колекцію → Вкладка Ключі → фільтр статусу _Тільки відсутні_ → мова _fr_. Використати _Копіювати з англійської_ як швидкий запасний варіант або _Перевірити заповнювачі_ перед публікацією.
- **Масове оновлення з XLSX** — Редагувати колекцію → Вкладка Імпорт / Експорт → вибрати XLSX, режим _Об’єднати_, спочатку _Симуляція_ → переглянути різницю → _Застосувати_.
- **Перевести чернетку в продуктив** — Редагувати колекцію → Вкладка Публікація → підтвердити список змінених ключів, виправити попередження → _Опублікувати_.
- **Створити варіант для нового ринку** — Дублювати колекцію → перейменувати → додати нову мову в _Цільові мови_ → перекласти.
- **Архівувати застарілий набір** — Меню рядка → Архівувати. Колекція залишається в таблиці, але переходить у статус `archived`; пізніше можна знайти за фільтром Статус.

## Поради

- **Поки що лише фронтенд.** Нічого тут не надсилається на бекенд — `Зберегти`, `Опублікувати`, `Експортувати`, `Видалити`, `Архівувати` — це лише зміни локального стану + повідомлення. Не покладайтеся на це для реальних продуктивних рядків, поки не з’явиться API.
- **Базова мова заблокована.** `en` завжди базова — колекції неанглійською створюються як цільові мови колекції з англійською базою, а не окремо.
- **Теги використовують логіку AND.** Фільтрація за двома тегами означає, що колекція має містити _обидва_ теги. Щоб шукати за будь-яким, очистіть один із тегів.
- **Захист навігації глобальний.** Навіть якщо забруднено лише діалог, при спробі покинути сторінку з’явиться запит на підтвердження — збережіть або відхиліть зміни, щоб пропустити запит.
- **Перевірка заповнювачів — ваш друг** — запуск перед публікацією виявляє помилки типу "втраченого `{{name}}` у перекладі", які ламають рядок під час виконання.
- **Не плутайте з вкладкою Locale у [General](general.md)** — та вкладка встановлює налаштування за замовчуванням (які мови _увімкнені_, формати дати / часу / одиниць). Ця сторінка містить фактичні перекладені рядки.
- **Дані для довідки — макетні.** Мови, простори імен і теги наразі жорстко закодовані — коли з’явиться бекенд, очікуйте, що вони надходитимуть з API і, можливо, будуть редаговані.
