# Ролі

Сторінка Ролі (`/settings/roles`) — це місце, де ви визначаєте, **що оператори можуть робити** у Панелі керування. Роль — це іменований набір дозволів; кожен оператор має рівно одну роль; дозволи визначають, які сторінки вони бачать і які дії можуть виконувати.

Поєднуйте цю сторінку з [Operators](operators.md) — Operators призначає ролі людям, Roles визначає, що кожна роль фактично може робити.

Необхідний дозвіл: **Ролі** (`d4e5f6`).

## Як працюють дозволи

Кожна сторінка та дія в Панелі керування захищені **ID дозволу** (наприклад, `k7m8n9` для Транспортних засобів, `e4f5h6` для Клієнтів). Роль — це по суті контрольний список цих ID дозволів:

- Оператор бачить сторінку лише якщо його роль має дозвіл на цю сторінку
- Дія в рядку (Редагувати, Видалити тощо) прихована, якщо роль не має відповідного піддозволу
- Дозволи оцінюються **для кожного запиту** — зміна ролі відображається оператору при наступному завантаженні сторінки (або раніше)

Між ролями **немає спадкування** — кожна роль незалежна. Ролі з вищим рівнем довіри просто мають довший список дозволів.

## Стандартні та користувацькі ролі

Ролі бувають двох типів:

| Тип          | Редагується | Призначення                                                            |
| ------------ | ---------- | --------------------------------------------------------------------- |
| **Стандартна** | Ні         | Постачається з платформою (наприклад, Власник, Адмін). Гарантує безпечну базу |
| **Користувацька** | Так        | Створена вами — відповідає структурі вашої команди                    |

Стандартні ролі **Власник / Адмін** не можна редагувати або видаляти — це ваша страховка. Користувацькі ролі дозволяють налаштовувати дозволи відповідно до реальних обов’язків.

## Фільтри

| Фільтр  | Тип       | Примітки                              |
| ------- | --------- | ------------------------------------ |
| Пошук   | Текст     | Шукає за ім’ям ролі та описом        |
| Статус  | Випадаючий список | `Активний` / `Неактивний` (або `Всі`) |

## Колонки

| Колонка          | Сортується? | Вміст                                                                    |
| ---------------- | ---------- | ------------------------------------------------------------------------ |
| **Ім'я ролі**    | ✓          | Позначка ролі                                                           |
| **Опис**         | —          | Короткий текст, що пояснює призначення ролі                            |
| **Тип**          | —          | Позначка Стандартна / Користувацька                                    |
| **Дозволи**      | —          | Кількість наданих дозволів (наприклад, "23 / 84")                     |
| **Рівень довіри**| ✓          | Числовий показник, що вказує, наскільки роль потужна (більше = потужніша) |
| **Створено**     | ✓          | Дата створення ролі                                                     |

### Рівень довіри

Рівень довіри — це приблизний числовий показник «наскільки небезпечний набір дозволів цієї ролі» — використовується для сортування та візуальних підказок. Роль із дозволами на видалення, масове оновлення та керування дозволами має вищий рівень довіри, ніж роль лише для перегляду. Фіксованої шкали немає; розглядайте це як відносний показник у вашому списку ролей.

## Дії в рядку

Меню з трьома крапками для кожного рядка.

| Дія              | Дозвіл     | Що робить                                                                                      |
| ---------------- | ---------- | --------------------------------------------------------------------------------------------- |
| **Переглянути деталі** | —          | Відкриває сторінку деталей ролі з повним розбором дозволів                                    |
| **Редагувати**    | `edit`     | Відкриває форму редагування (вимкнено з повідомленням для Стандартних ролей)                   |
| **Видалити**     | `delete`   | М’яке видалення ролі (з підтвердженням; лише для Користувацьких ролей; лише якщо жоден оператор її не має) |

Якщо роль використовується, система відмовить у видаленні і повідомить, скільки операторів її ще мають — спочатку переназначте їх.

## Форма створення / редагування

Форма ролі відображає всі дозволи, згруповані за доменами (Операції, Підтримка, Аналітика, Налаштування тощо) з прапорцями.

Ключові поля:

- **Ім'я** (обов’язкове, унікальне)
- **Опис** (необов’язковий, але рекомендований)
- **Статус** (Активний / Неактивний)
- **Дерево дозволів** — дозволи на рівні сторінок і піддозволи, згруповані за доменами

Коли ви вимикаєте дозвіл на верхньому рівні сторінки, усі її піддозволи автоматично вимикаються (оператор повністю втрачає доступ до сторінки). Увімкнення дозволу на сторінку за замовчуванням дає лише дозвіл на перегляд — далі ви окремо вибираєте піддозволи на _створення_, _редагування_, _видалення_ тощо.

Невеликий індикатор **Рівня довіри** оновлюється під час вибору прапорців — корисно для порівняння з подібними ролями.

## Сторінка деталей ролі

Клік по рядку відкриває сторінку деталей ролі, де показано:

- Ім'я, опис, тип, статус
- Рівень довіри
- Повний список дозволів (тільки для читання, згрупований за доменами)
- Журнал активності: коли роль створена, востаннє редагована, ким
- Список операторів, які наразі мають цю роль (з посиланнями на їхні профілі)

## Типові робочі процеси

- **Визначити нову команду** — `+ Створити` → ім’я (наприклад, "Керівник польової команди") → вибрати потрібні дозволи → Зберегти → призначити роль відповідним [операторам](operators.md)
- **Уточнити існуючу роль** — знайти роль у списку → Редагувати → зняти прапорці з непотрібних дозволів → Зберегти (оператори з цією роллю втратять доступ при наступному запиті)
- **Підвищити члена команди** — перейти до [Operators](operators.md) → Редагувати → змінити Роль → Зберегти (не робиться на цій сторінці)
- **Аудит, хто може видаляти транспортні засоби** — відкрити цей список → відсортувати за Рівнем довіри → перевірити піддозволи Редагування / Видалення для Транспортних засобів у кожній ролі
- **Вивести роль з використання** — переконатися, що жоден оператор її не має ([Operators](operators.md) фільтр за роллю) → Видалити

## Поради

- **Менше — краще** — починайте з режиму лише для перегляду та додавайте конкретні дії; утримуйтеся від копіювання ролі з вищими правами та її обрізання
- **Тестуйте через імітацію** (де підтримується) — перед впровадженням ролі увійдіть як тестовий оператор з цією роллю та перевірте робочі процеси
- **Ролі за замовчуванням — ваш запасний варіант** — Власник / Адміністратор завжди існують; якщо випадково заблокуєте себе в Користувацькій ролі, Адміністратор може відновити доступ
- **Рівень довіри — це підказка, а не правило** — дві ролі з однаковим рівнем довіри можуть мати дуже різні можливості; завжди перевіряйте фактичне дерево дозволів
- **Дозволи оцінюються на сервері** — вимкнення їх у ролі не припиняє поточну сесію оператора, але наступний запит буде відхилено
- **Документуйте кожну Користувацьку роль** у полі Опис — через шість місяців «Менеджер флоту (читання + редагування, без видалення)» стане порятунком
