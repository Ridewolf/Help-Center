# Зони

Сторінка Зон (`/zones`) — це місце, де ви малюєте **невидимі правила вашої зони обслуговування** — паркувальні, заборонені, з обмеженням швидкості, зарядки та інші полігони, які змінюють поведінку транспортних засобів і клієнтів при перетині межі. Кожна зона — це один полігон на карті плюс тип, статус, необов’язкові параметри (швидкість, ціна, місткість транспортних засобів) та теги.

Зони визначають поведінку під час роботи для [Транспортних засобів](../../operations/fleet/vehicles.md) — в’їзд у полігон без поїздок призводить до відключення транспортного засобу; паркування в зоні з платним паркуванням активує тариф.

Необхідний дозвіл: **Зони** (`u7v8w9`). Піддозволи `create` / `edit` / `delete` контролюють відповідні дії.

## Що таке зона

Зона має чотири основні складові:

1. **Тип** — визначає колір і правило, що застосовується під час роботи (див. таблицю нижче)
2. **Полігон** — рівно один полігон, намальований на карті; опуклі форми дозволені, дірки — ні
3. **Параметри** — залежать від типу: швидкість (низькошвидкісна), ціна (платне паркування), сума (зарядка), дозволені транспортні засоби (паркування, платне паркування, ребалансування)
4. **Статус** — `Активний` (застосовується), `Неактивний` (збережений, але ігнорується), `Архівовано` (прихований у більшості списків)

### Типи зон

| Тип             | Колір      | Що робить                                                           |
| ---------------- | ---------- | ------------------------------------------------------------------- |
| **Заборонена**   | Чорний     | Транспортні засоби не можуть в’їжджати або працювати тут           |
| **Заборона паркування** | Червоний   | Користувачі не можуть завершити поїздку тут                        |
| **Заборона поїздок** | Фіолетовий | Транспортні засоби відключаються / відмовляються стартувати всередині цього полігону |
| **Низька швидкість** | Синій      | Максимальна швидкість обмежена налаштованим значенням `speed` (км/год) |
| **Паркування**   | Зелений    | Відведене паркувальне місце; необов’язкова місткість транспортних засобів |
| **Платне паркування** | Помаранчевий | Паркування з ціною та необов’язковою місткістю                     |
| **Зарядка**      | Темно-зелений | Зона винагороди — застосовується `amount`, коли користувач завершує тут поїздку |
| **Техобслуговування** | Темно-червоний | Внутрішній маркер для операцій; транспортні засоби всередині виключені з потоку користувачів |
| **Ребалансування** | Темно-синій | Цільова зона для ребалансування флоту; необов’язкова місткість транспортних засобів |

## Режими перегляду

Група перемикачів у заголовку сторінки змінює між трьома видами — ті ж дані, різний вигляд.

| Режим     | Найкраще підходить для                                               |
| --------- | ------------------------------------------------------------------- |
| **Таблиця** | Масові редагування, сортування за ім’ям/типом/статусом, посторінковий перегляд |
| **Картки** | Візуальний огляд з міні-картою для кожної зони; нескінченне прокручування |
| **Карта**  | Перегляд усіх зон, накладених на реальну карту — корисно для аудиту покриття |

## Фільтри

| Фільтр  | Тип       | Примітки                              |
| ------- | --------- | ------------------------------------ |
| Пошук   | Текст     | Пошук за назвою та описом зони       |
| Статус  | Випадаючий список | `Активний` / `Неактивний` (або `Всі`) |
| Тип     | Випадаючий список | Один із 9 типів (або `Всі`)          |

Фільтри застосовуються у всіх трьох режимах перегляду. Режим Карти завантажує **всі** відповідні зони (без пагінації); Таблиця та Картки — з пагінацією.

## Колонки (режим Таблиця)

| Колонка         | Сортується? | Вміст                                                      |
| --------------- | ---------- | ---------------------------------------------------------- |
| **Назва зони**  | ✓          | Назва + кольоровий маркер типу; посилання на сторінку деталей зони |
| **Опис**        | —          | Необов’язковий текстовий опис                              |
| **Тип**         | ✓          | Кольорова позначка типу (див. таблицю типів вище)         |
| **Статус**      | ✓          | `Активний` / `Неактивний` / `Архівовано`                   |
| **Теги**        | —          | Теги, застосовані до зони                                  |

## Дії над рядком

Меню з трьома крапками для кожного рядка. Доступні дії залежать від дозволів:

| Дія              | Дозвіл    | Що робить                                               |
| ---------------- | --------- | ------------------------------------------------------- |
| **Переглянути деталі** | —         | Відкрити сторінку деталей зони (карта + метадані)       |
| **Редагувати**    | `edit`    | Відкрити форму редагування геометрії/властивостей       |
| **Видалити**      | `delete`  | Постійне видалення — потребує утримання 3 секунди для підтвердження |

## Масові дії

Виберіть рядки в режимі Таблиця, щоб відкрити панель масових дій. Всі масові дії, що змінюють дані, вимагають дозволу `edit`:

- **Змінити тип** — одночасно змінити тип багатьох зон (параметри скидаються відповідно)
- **Змінити ліміт транспортних засобів** — встановити `allowedVehicles` для вибраних зон (актуально для паркування / платного паркування / ребалансування)
- **Змінити значення** — встановити числове значення, специфічне для типу (швидкість / ціна / сума)
- **Змінити статус** — масово переключити Активний ↔ Неактивний
- **Змінити теги** — додати або замінити теги у вибраних зонах
- **Експортувати вибране** — завантажити лише виділені зони у форматі JSON (дозвіл не потрібен; клієнтська операція)

## Створення — покроковий майстер з 5 кроків

`+ Створити` відкриває покрокову форму. Ви можете вільно повертатися назад; перехід вперед доступний лише при валідності поточного кроку.

1. **Ім'я та опис** — `Label` (обов’язково) та необов’язковий `Description`
2. **Класифікація** — `Type` (обов’язково, визначає колір і форму параметра), `Status` (Активний / Неактивний / Архівовано), `Tags`
3. **Параметри** — числові поля, специфічні для типу, з повзунком 0–100 для швидкого введення: швидкість (км/год), ціна, кількість або дозволені транспортні засоби. Типи без параметрів показують повідомлення «немає параметрів» і дозволяють перейти далі
4. **Геометрія** — намалюйте рівно **1 полігон** на карті. Існуючі зони можна увімкнути як пунктирний накладний шар, щоб не перекривати. Керування картою: малювати, редагувати, додавати точки, скасувати (до 20 кроків), видалити, масштабувати, підлаштувати межі, знайти мене, повноекранний режим
5. **Перевірка** — остаточне зведення для читання кожного поля плюс кількість точок полігону

Збереження створює зону і перенаправляє вас на її сторінку деталей.

## Форма редагування

`Edit` використовує той самий інтерфейс, але у вигляді односторінкової форми (без покрокового майстра) — змініть мітку, тип, статус, параметри, теги або перемалюйте полігон, потім натисніть Зберегти. Попередження про незбережені зміни з’являється перед виходом зі сторінки.

## Імпорт / Експорт

Дві контурні кнопки поруч із **+ Створити**:

- **Імпорт** — виберіть файл `.json`, експортований раніше; Панель керування перевіряє дані та створює зони на сервері. Потрібна можливість `create`
- **Експорт** — відкриває діалог, де ви обираєте, що завантажити: поточну сторінку, усі сторінки з поточними фільтрами або все. Панель масових дій також пропонує «Експортувати вибране» для виділених рядків

## Сторінка деталей

Клік по рядку (або _Переглянути деталі_) відкриває сторінку деталей зони з:

- Живою картою з переглядом полігону
- Карткою базової інформації (мітка, опис, тип, статус, колір)
- Карткою параметрів (швидкість / ціна / кількість / дозволені транспортні засоби, якщо актуально)
- Тегами
- Часом створення / оновлення
- Кнопками Редагувати та Видалити у заголовку (залежно від прав)

## Типові робочі процеси

- **Запуск нового міста** — імпортуйте JSON-пак зон, якщо він у вас є, інакше спочатку намалюйте заборонене кільце, потім полігони паркування всередині нього
- **Коригування зони з низькою швидкістю** — Редагувати → крок 3 → збільшити значення швидкості → Зберегти. Активується одразу
- **Закриття паркінгу на день** — Редагувати → Статус = Неактивний → Зберегти. Поверніть назад, коли паркінг відкриється
- **Перезонування після змін у місті** — масово виберіть уражені зони → Змінити тип → підтвердити. Старі параметри типу очищуються автоматично
- **Аудит покриття** — переключіться на вигляд Карти, відфільтруйте за Статусом = Активний, перевірте на прогалини та перекриття

## Поради

- **Тип визначає все** — колір, форму параметра, правило виконання. Вибір неправильного типу — найпоширеніша причина переробок
- **Один полігон на зону** — розділяйте складні області на кілька зон; редактор дозволяє лише один полігон
- **Перекриття зон дозволені** — виграє найсуворіше правило (заборонено > заборонено їздити > низька швидкість), тому не бійтеся накладати низькошвидкісну зону всередині паркувальної
- **Використовуйте пунктирний накладний шар** — увімкніть «Показувати існуючі зони на карті» в редакторі, щоб уникнути випадкових перекриттів із сусідами
- **Неактивний ≠ Видалений** — змінюйте Статус, щоб тимчасово призупинити зону; Видалення — назавжди (підтвердження утриманням 3 секунди — захист)
- **Позначайте зони тегами** — теги — єдиний мультивибірковий фільтр, що зберігається між режимами перегляду. Використовуйте для групування за районом, кампанією або власністю
- **Експортуйте перед масовими змінами** — один клік у діалозі експорту створює резервну копію всього набору, тож помилкову масову зміну можна скасувати імпортом
