# Набори іконок

Сторінка Набори іконок (`/settings/icon-sets`) — це **бібліотека іконок на карті**, яку мобільний додаток Ridewolf Rider використовує для відображення транспортних засобів. Кожен набір прив’язаний до одного типу транспортного засобу (електросамокат, електровелосипед, вантажний електровелосипед, електроскутер, електромобіль, електричний човен) і містить три категорії SVG-іконок: **Вибрані**, **Не вибрані** та **Знижка**.

Це інфраструктура контенту — оператори завантажують SVG-іконки сюди, додаток Rider вибирає правильну іконку залежно від типу транспортного засобу, рівня заряду батареї та того, чи торкнувся користувач транспортного засобу на карті. Для заміни іконок не потрібне оновлення мобільного додатка.

Разом із [FAQ Sets](faq-sets.md) та [Quick Guides](quick-guides.md) це шар контенту в Панелі керування.

Потрібен дозвіл: **Набори іконок** (зверніться до адміністратора).

## Де це відображається для користувача

На карті в додатку Rider кожна позначка транспортного засобу використовує іконку з активного набору для свого типу:

- Іконки **Не вибрані** використовуються для позначок, які користувач не торкався — шість рівнів заряду батареї (`bat10`, `bat25`, `bat40`, `bat55`, `bat90`, `bat100`), щоб позначка відображала поточний заряд
- Іконки **Вибрані** замінюють позначку, коли користувач торкається її — ті ж шість рівнів заряду, але інший стиль
- Іконки **Знижка** (за замовчуванням 5%, 15%, 25%, 35%, 45%, 55%) накладаються на позначку, коли на транспортний засіб діє промо-ціна

Один набір на тип транспортного засобу може бути позначений як **за замовчуванням** — саме його додаток завантажує, якщо інше не налаштовано.

## Фільтри

| Фільтр           | Тип       | Примітки                                                                                                         |
| ---------------- | --------- | ---------------------------------------------------------------------------------------------------------------- |
| Пошук            | Текст     | Поле пошуку в заголовку — шукає за назвою / ідентифікатором                                                     |
| Тип транспортного засобу | Випадаючий список | `Електросамокат` / `Електровелосипед` / `Вантажний електровелосипед` / `Електроскутер` / `Електромобіль` / `Електричний човен` (або `Всі`) |
| Покриття станів  | Випадаючий список | Фільтр за заповненістю: `Тільки вибрані` / `Тільки не вибрані` / `Тільки зі знижкою` / `Повне покриття` (або `Всі`) |
| Статус           | Випадаючий список | `Активний` / `Чернетка` / `Неповний` / `Архівовано` (або `Всі`)                                                |
| Теги             | Комбобокс | Фільтр за тегами у вільній формі (поле вводу показано, але наразі вимкнено — скоро з’явиться)                    |

**Очистити все** скидає всі фільтри.

## Колонки

| Колонка                | Вміст                                                                    |
| ---------------------- | ------------------------------------------------------------------------ |
| **Набір**              | Іконка пакету + назва; другий рядок показує ідентифікатор                  |
| **Тип транспортного засобу** | Пігулка (Електросамокат, Електровелосипед тощо)                         |
| **Вибрані іконки**     | Покриття, наприклад `6/6` (скільки рівнів заряду завантажено)             |
| **Не вибрані іконки**  | Аналогічне покриття `n/6` для не вибраних варіантів                       |
| **Іконки зі знижкою**  | Перші 3 відсотки знижки у вигляді чіпів (`5%`, `15%`, `25%`), `+N` надлишок |
| **Теги**               | Перші 2 теги у вигляді чіпів з `+N` надлишком                             |
| **Оновлено**           | Дата останнього оновлення                                                |
| **Статус**             | `Активний` / `Чернетка` / `Неповний` / `Архівовано`                      |

`Неповний` означає, що в наборі бракує іконок для однієї з трьох категорій — додаток Rider використовує набір за замовчуванням для цього типу транспортного засобу, доки ви не завершите завантаження.

Клацніть рядок, щоб відкрити **Діалог деталей** — візуальний перегляд усіх іконок у наборі. Клацніть меню з трьома крапками для дій.

## Дії з рядком

| Дія                 | Що робить                                                                       |
| ------------------- | -------------------------------------------------------------------------------- |
| **Переглянути деталі** | Відкриває діалог деталей з прев’ю кожного завантаженого SVG                     |
| **Редагувати**       | Відкриває багатовкладкову форму (Деталі / Вибрані / Не вибрані / Знижки / Перегляд) |
| **Дублювати**        | Клонує набір як Чернетку                                                        |
| **Встановити за замовчуванням** | Позначає цей набір як набір за замовчуванням для його типу транспортного засобу — додаток Rider завантажить його |
| **Завантажити**      | Завантажує набір у ZIP-архіві з усіма SVG                                      |
| **Архівувати**       | Переміщує в `Архівовано` — зберігається для історії, не використовується додатком |
| **Видалити**         | Видаляє назавжди                                                              |

Кнопки **Імпорт** (ZIP / JSON) та **Експорт** (ZIP / JSON) у верхній панелі працюють пакетно.

## Форма створення / редагування

Форма — це діалог із п’ятьма вкладками:

1. **Деталі** — назва (обов’язково), ідентифікатор (генерується автоматично), тип транспортного засобу (обов’язково), теги, статус
2. **Вибрані** — завантажте 6 SVG, по одному на кожен рівень заряду (`bat10` → `bat100`)
3. **Не вибрані** — ті ж 6 слотів для стану на карті, коли не вибрано
4. **Знижки** — по одному SVG на кожен відсоток знижки. За замовчуванням `5, 15, 25, 35, 45, 55`, але можна додавати/видаляти рядки
5. **Перегляд** — візуальна перевірка всього набору перед збереженням

Набір із порожніми слотами на будь-якій вкладці зберігається як `Неповний`.

## Типові робочі процеси

- **Оновіть піни електросамокатів для ребрендингу** — Скопіюйте поточний набір за замовчуванням → завантажте нові SVG у всіх трьох вкладках → збережіть як Чернетку → перегляньте → Встановіть за замовчуванням → Rider App оновить їх при наступному оновленні
- **Проведіть A/B тест іконок** — залиште старий набір Активним і не за замовчуванням, створіть новий набір як Активний + за замовчуванням для типу транспортного засобу → за потреби поверніть старий, встановивши його за замовчуванням
- **Святкове оформлення знижок** — відкрийте активний набір → Редагувати → вкладка Знижки → завантажте тематичні SVG для відсотків, які зараз використовуються → збережіть
- **Масовий імпорт ZIP від дизайнера** — у верхньому правому куті _Імпорт_ → ZIP → підтвердіть відповідність файлів → перегляньте у Попередньому перегляді → Активуйте

## Поради

- **Один набір за замовчуванням на тип транспортного засобу** — встановлення нового набору за замовчуванням автоматично скасовує попередній. Значок Статусу не обов’язково має бути `Активний`, щоб набір був за замовчуванням, але бажано
- **Рівні заряду батареї фіксовані** — `bat10/25/40/55/90/100` — єдині категорії, які розуміє додаток; він вибирає найближчу на основі поточного заряду транспортного засобу
- **Тільки SVG** — для завантаження потрібні SVG-файли; PNG не масштабуються чітко на екранах Retina
- **`Incomplete` — корисний захист** — він показує, що Rider App повертається до набору за замовчуванням, тож ви ніколи випадково не опублікуєте неповний набір
- **Архівуйте перед видаленням** — архівовані набори залишаються доступними для пошуку, якщо знадобиться повернутися
