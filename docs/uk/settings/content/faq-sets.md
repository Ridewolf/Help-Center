# Набори запитань і відповідей

Сторінка Наборів запитань і відповідей (`/settings/faq-sets`) — це **бібліотека запитань і відповідей**, що відображається у додатках Ridewolf — переважно у мобільному додатку для користувачів, а також на інтерфейсах для операторів. Кожен набір — це пакет записів запитань/відповідей, орієнтований на певну аудиторію (додаток для користувачів, клієнтський додаток, механік, адміністратор або загальний).

Разом із [Quick Guides](quick-guides.md) та [Icon Sets](icon-sets.md) ця сторінка є частиною контентного шару — те, що оператор змінює тут, бачить користувач у своєму телефоні без оновлення мобільного додатка.

Потрібний дозвіл: **FAQ Sets** (зверніться до адміністратора).

## Де це відображається користувачу

У мобільному додатку для користувачів Набори запитань і відповідей підтримують розділ Допомога / FAQ у додатку. Кожен набір типу **rider-app** зі статусом `active` завантажується в додаток; записи, позначені як `visible`, відображаються у порядку поля `order`. Набори типів `client-app`, `mechanic`, `admin`, `general` відображаються у відповідних додатках / інтерфейсах.

Набір зі статусом `draft` або `archived` ніколи не показується — це корисно для підготовки змін перед публікацією.

## Фільтри

| Фільтр  | Тип          | Примітки                                                                 |
| ------- | ------------ | ----------------------------------------------------------------------- |
| Пошук   | Текст        | Поле пошуку у заголовку — шукає за назвою / описом / slug               |
| Теги    | Мультивибір  | Фільтр за тегами, застосованими до набору (onboarding, payments, technical, …) |
| Статус  | Випадаючий   | `Активний` / `Чернетка` / `Архівовано` (або `Всі`)                      |
| Тип     | Випадаючий   | `Клієнтський додаток` / `Додаток користувача` / `Механік` / `Адмін` / `Загальний` (або `Всі`) |

**Очистити все** скидає всі фільтри одночасно.

## Колонки

| Колонка     | Вміст                                                               |
| ----------- | ----------------------------------------------------------------- |
| **Набір**   | Іконка + назва; другорядний рядок показує опис або slug           |
| **Тип**     | Піктограма аудиторії — Клієнтський додаток / Додаток користувача / Механік / Адмін / Загальний |
| **Теги**    | Перші 3 теги, з позначкою `+N` для зайвих                         |
| **Записи**  | Кількість полів запитань/відповідей у наборі                      |
| **Статус**  | `Активний` (зелений) / `Чернетка` (сірий) / `Архівовано` (приглушений) |
| **Оновлено**| Відносна дата; при наведенні показує повний час і автора          |

Клацніть рядок, щоб відкрити діалог **Переглянути** (тільки для читання). Клацніть меню з трьома крапками для дій.

## Дії з рядком

| Дія              | Що робить                                                           |
| ---------------- | ------------------------------------------------------------------ |
| **Переглянути деталі** | Перегляд у режимі тільки для читання з усіма записами запитань/відповідей |
| **Редагувати**        | Відкрити форму (таку ж, як Створити, з попереднім заповненням)   |
| **Дублювати**         | Клонувати набір із суфіксом slug `-copy` і статусом `Draft`      |
| **Експортувати**      | Завантажити набір у форматі ZIP або JSON                         |
| **Архівувати**        | Перемістити в `Архівовано` — приховано від додатка користувача, збережено для історії |
| **Видалити**          | Видалити назавжди (руйнівна дія — лише якщо дійсно не потрібен)  |

У верхній панелі також є масовий імпорт **Імпортувати** (ZIP / JSON) та експорт **Експортувати** (ZIP / JSON видимого списку).

## Форма створення / редагування

Діалог форми має три основні селектори та список полів запитань/відповідей:

- **Тип** — обов’язковий, визначає, хто бачить набір (Клієнтський додаток / Додаток користувача / Механік / Адмін / Загальний)
- **Статус** — `Чернетка` (за замовчуванням для нових) / `Активний` / `Архівовано`
- **Теги** — мультивибір, використовується для фільтрації та групування
- **Назва** — обов’язкова, відображається як ім’я набору
- **Опис** — необов’язковий, другорядний рядок у списку
- **Поля** — записи запитань/відповідей. Кожне поле має:
  - **Підпис** (запитання)
  - **Значення** (відповідь)
  - **Тип** — `text` / `markdown` / `link` / `list`
  - Перемикач **Видимість** (ховає окремі записи без видалення)
  - **Порядок** (перетягування для зміни порядку)

Slug утворюється з назви і використовується в URL API — змінюйте через Редагувати за потреби.

## Типові робочі процеси

- **Опублікувати новий FAQ для користувачів** — `+ Створити набір` → Тип = Додаток користувача, Статус = Чернетка → заповнити назву + опис → додати поля запитань/відповідей → зберегти → переглянути через Переглянути деталі → Редагувати, змінити Статус на Активний → він з’явиться у додатку користувача при наступному оновленні
- **Підготувати сезонний текст** — дублювати існуючий набір → редагувати копію як Чернетку → запланувати заміну, архівувавши старий набір і активувавши новий одночасно
- **Відкотити неправильну відповідь** — відкрити проблемний набір → Редагувати → виправити поле (або вимкнути Видимість) → зберегти; або Архівувати весь набір і повернутися до раніше дубльованої версії
- **Масовий імпорт із JSON-дампу** — у верхньому правому куті _Імпортувати_ → вибрати файл → підтвердити структуру → імпортувати як Чернетку, потім переглянути і Активувати

## Поради

- **Тип визначає, хто бачить контент** — не розміщуйте тексти для користувачів у наборі `mechanic`, вони ніколи не потраплять у додаток користувача
- **Чернетка — ваш друг** — нові набори за замовчуванням у статусі Чернетка, щоб додаток користувача не показував недороблений контент. Перемикайте на Активний лише після повного перегляду
- **Поля markdown підтримують форматування** — використовуйте їх для відповідей із маркованими списками або жирним шрифтом; обирайте `text`, якщо потрібен лише простий текст
- **Теги спільні з фільтром** — використовуйте послідовну систему тегів (наприклад, `onboarding`, `payments`, `troubleshooting`), щоб фільтрація залишалась корисною
- **Архівуйте замість видалення**, коли можливо — видалені набори зникають назавжди, архівовані можна реактивувати і вони служать історією
