# Аналітика — Теплові карти

Сторінка Теплові карти (`/analytics/heatmaps`) — це **географічний візуалізатор щільності**: виберіть джерело даних, діапазон дат і режим візуалізації — карта покаже, де зосереджена активність у вашій зоні роботи.

Використовуйте її для **виявлення попиту** (де користувачі хочуть почати? де вони закінчують?) та **планування покриття** (де користувачі шукають, але у нас немає транспортних засобів?).

## Джерела даних

Три джерела сигналів, по одному за раз:

| Джерело        | Що показує                                                              |
| -------------- | ---------------------------------------------------------------------- |
| **Сканування** | Де користувачі **відкривали додаток і шукали транспортні засоби** — намір попиту |
| **Початки поїздок** | Де поїздки **фактично починалися** — конвертований попит              |
| **Закінчення поїздок** | Де поїздки **закінчувалися** — природні місця висадки                  |

Порівняйте _Сканування_ та _Початки поїздок_, щоб знайти **незадоволений попит**: місця, де користувачі шукали, але не могли знайти транспортний засіб.

## Режими візуалізації

Чотири способи відобразити ті ж дані:

| Режим        | Що відображає                                                                |
| ------------ | ---------------------------------------------------------------------------- |
| **Теплокарта**  | Класичне плавне розмивання — найкраще для **швидкого виявлення піків**       |
| **Гексагони**   | Гексагональні бінування — найкраще для **порівняння зон** з однаковою геометрією |
| **Кластери**   | Кластери точок, що розширюються при збільшенні масштабу — найкраще для **детального аналізу окремих точок** |
| **Сітка**      | Регулярна квадратна сітка — найкраще для **вирівнювання з планувальними зонами** |

Ті ж вихідні дані можуть розповідати різні історії в різних режимах — перемикайтеся під час дослідження.

## Кольорові схеми

Рядок маленьких зразків дозволяє вибрати кольорову схему — корисно для операторів з порушеннями кольоросприйняття або для відповідності бренд-палітрі. Назва схеми з’являється у підказці при наведенні.

## Повзунок точок

Повзунок на панелі інструментів дозволяє контролювати, скільки точок даних вибирати (наприклад, 1 тис. / 10 тис. / 100 тис.). Більше точок = точніша картина щільності, але повільніше відображення. Починайте з малої кількості під час дослідження, збільшуйте, коли звузите область / діапазон.

## Діапазон дат

Стандартна панель вибору діапазону дат зверху. Чим ширший діапазон, тим більш агрегована картина; для «що сталося цього ранку» вибирайте кілька годин.

## Карта

Карта заповнює сторінку. Стандартні елементи керування картою (панорамування, масштабування, перемикання шарів). Накладення теплової карти розташоване поверх базової карти.

**Легенда** у кутку пояснює кольорову шкалу активного режиму — від низької до високої щільності.

## Типові робочі процеси

- **Знайти незадоволений попит** — Джерело = Сканування, Режим = Теплокарта → знайти гарячу зону → переключити Джерело на Початки поїздок → якщо ця ж зона холодна = незадоволений попит → розглянути балансування або розширення в цю зону
- **Планувати нову зону** — Джерело = Закінчення поїздок, Режим = Гексагони → шукати концентрації природних місць висадки поза поточними зонами → запропонувати операціям
- **Детально вивчити гарячу точку** — Режим = Кластери → збільшити масштаб гарячої зони → окремі точки показують точні широту/довготу; зіставити з [Пошук транспортних засобів](vehicles.md) для деталей поїздок
- **Порівняти часові вікна** — завантажити ранкові Сканування → зробити скріншот → переключити на вечірні Сканування → порівняти скріншоти поруч (Панель керування поки не підтримує подвійну періодичність; потрібен ручний експорт)
- **Аудит покриття** — Джерело = Сканування за останній тиждень → шукати гарячі точки далеко від будь-яких планованих зон → розглянути можливість перерозподілу меж зон

## Поради

- **Сканування ≠ поїздки** — багато сканувань не конвертуються (користувач не бачить транспортний засіб, бачить ціну, відмовляється). Різниця між Скануваннями та Початками поїздок — ваш найцінніший сигнал
- **Режим теплової карти приховує масштаб** — кольори відносні в межах видимої карти; масштабування змінює картину. Режим Гексагони чесніший при фіксованому масштабі
- **Починайте з малої кількості точок, закінчуйте великою** — дослідження з 1 тис. точок швидке; збільшуйте до 100 тис., коли знаєте, що шукаєте
- **Режим сітки для планування** — якщо ваші зони приблизно прямокутні, Сітка вирівнюється з ними і спрощує обчислення; інакше краще Гексагони
- **Проблеми з кольорами?** — спробуйте альтернативні схеми; вихідні дані однакові
- **Карта не оновлюється автоматично при зміні дати** — залежно від налаштувань, можливо, потрібно повторно натиснути _Застосувати_ / _Оновити_ після зміни діапазону дат
- **Легенда важлива** — те, що виглядає «червоним і драматичним», може бути невеликим абсолютним числом; завжди дивіться на легенду перед інтерпретацією
