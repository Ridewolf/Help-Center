# Аналітика — Транспортні засоби

Сторінка аналітики Транспортних засобів (`/analytics/vehicles`) — це **панель керування станом флоту**: скільки у вас транспортних засобів, як вони працюють, стан батареї, проблеми та поломки за типом і зоною.

Відрізняється від [Списку транспортних засобів](../../operations/fleet/vehicles.md) — там операційний огляд по одиницях; тут — **агреговані метрики флоту** за обраний період.

## Період часу

Угорі розташована **панель вибору діапазону дат**. Графіки трендів використовують весь діапазон; огляд / підрахунки статусів відображають **поточний стан** (кінець діапазону).

## Розділи

Сім розділів зверху вниз:

### 1. Огляд

Загальний склад флоту.

| KPI               | Що показує                                                      |
| ----------------- | ------------------------------------------------------------------ |
| **Всього**        | Всі зареєстровані транспортні засоби                              |
| **Активні**       | Доступні для оренди користувачами прямо зараз                     |
| **Проста**        | Не використовуються (можуть бути Доступні або з низьким використанням) |
| **Не в роботі**   | У техобслуговуванні / зберіганні / не готові — не приносять дохід |
| **Втрачено / Вкрадено** | Статус = Вкрадено або відсутні в мережі довше за поріг            |

Використовуйте цей розділ як загальний знімок стану флоту.

### 2. Продуктивність

Наскільки добре ваш флот **заробляє** для вас.

| KPI                   | Що показує                                              |
| --------------------- | ---------------------------------------------------------- |
| **Заробляючі транспортні засоби**  | Транспортні засоби, які виконали принаймні одну поїздку за період    |
| **Неактивні транспортні засоби**  | Активні транспортні засоби без поїздок (марнотратство)                    |
| **Поїздок на транспортний засіб** | Середня кількість поїздок на транспортний засіб за період                     |
| **Використання**       | Години оренди / години доступності (галузевий орієнтир: 5-15%) |

Неактивні серед Активних — найгірший варіант, що коштує вам операційних витрат без прибутку.

### 3. Батарея

Стан батареї по всьому флоту.

| KPI / Графік      | Що показує                                                                   |
| ---------------- | ------------------------------------------------------------------------------- |
| **Середній рівень**    | Середній % заряду батареї по всіх транспортних засобах прямо зараз                                    |
| **Критичний**     | Кількість нижче критичного порогу (10-20%)                                     |
| **Тренд середнього**    | Середній заряд батареї за період — падіння = заміни не встигають                 |
| **Розподіл** | Гістограма транспортних засобів за діапазонами заряду (0-20 / 20-40 / 40-60 / 60-80 / 80-100) |
| **Заміни**        | Кількість операцій заміни батарей за період                                   |

Якщо середній рівень падає, а критичний зростає, польова команда відстає — заплануйте більше замін.

### 4. Проблеми

Сповіщення та операційні проблеми, зафіксовані по флоту.

| KPI             | Що показує                                                  |
| --------------- | -------------------------------------------------------------- |
| **Сповіщення**      | Загальна кількість сповіщень за період                               |
| **Типи сповіщень** | Розподіл за типами (батарея / зв’язок / механіка / тощо) |
| **Критичні**    | Сповіщення критичної важкості                                       |
| **Техобслуговування** | Транспортні засоби, що зараз у статусі Техобслуговування                       |
| **Офлайн**     | Транспортні засоби, які не передавали дані IoT довше за поріг   |

Поєднуйте цей розділ з аналітикою [Останніх подій](events.md) для детального перегляду по подіях.

### 5. Тренди

Графік часових рядів, що показує, як змінювалась кількість **Активних** транспортних засобів за період. Зниження зазвичай означає масову зміну статусу (перехід у техобслуговування, погода, відкликання).

### 6. За типом

Розподіл за **типом транспортного засобу** (скутер / велосипед / електровелосипед / тощо). Для кожного: кількість, коефіцієнт заробітку, використання, рівень сповіщень.

Якщо один тип домінує за рівнем сповіщень, проблема у **моделі**, а не в операційній команді.

### 7. За зоною

Розподіл за **зоною**. Для кожної: кількість транспортних засобів, використання, рівень проблем.

Зони з низьким використанням і високим запасом = **можливість ребалансування** (див. також [Аналітику ребалансування](../../operations/rebalance/runs.md)).

## Типові робочі процеси

- **Щотижневий огляд флоту** — Огляд → Продуктивність (тренд використання) → Батарея (чи зростає кількість критичних?) → Проблеми (сплески сповіщень) → Тренди (чи є незрозуміле падіння Активних?)
- **Прибирання неактивних** — Продуктивність → Кількість неактивних → якщо зростає, знайдіть проблемні транспортні засоби через [Список транспортних засобів](../../operations/fleet/vehicles.md) і перевірте статус / місцезнаходження
- **Аварійна ситуація з батареєю** — Розділ Батарея → Критичні зростають + Середній падає → підштовхніть польову команду
- **Виявлення проблемної моделі** — Розділ За типом → який тип має найгірший рівень сповіщень → розгляньте виведення з експлуатації / переговори з виробником
- **Ребалансування** — Розділ За зоною → зони з низьким використанням + високим запасом → заплануйте перерозподіл
- **Планування перед зміною** — Тренди + Шаблони з [Подій](events.md) → які дні / години потребують більше польового персоналу?

## Поради

- **Активні + Бездіяльні + Позаслужбові + Втрачені/Вкрадені = Всього** — коли сума не сходиться, статуси перебувають у проміжному стані; оновіть або виберіть стабільну дату
- **Активні ≠ заробіток** — транспортний засіб вважається «Активним», якщо його можна було орендувати; «Заробіток» означає, що він дійсно був орендований. Порівняйте ці два показники
- **Використання понад 25% є небажаним** — користувачі не можуть знайти транспортні засоби, коли їм потрібно; розгляньте можливість збільшення інвентарю в цій зоні
- **Використання нижче 5% — це баласт** — вартість утримання цього транспортного засобу перевищує його заробіток; перерозподіліть або заберіть
- **Критичний рівень батареї + середня тенденція** — разом це ваша система раннього попередження; поодинці — це шум
- **Втрачені / Вкрадені залишаються в статусі** — для очищення потрібна ручна зміна статусу; відновіть «Вкрадений» перед тим, як святкувати повернення
- **За типом і за зоною разом** — іноді тип не працює лише в одній зоні (невідповідність місцевості); перетин цих даних це виявляє
