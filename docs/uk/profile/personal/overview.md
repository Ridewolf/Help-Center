# Ваш профіль

**Профіль** — це _ваш_ обліковий запис у Ridewolf — оператор, який зараз увійшов у систему. Тут ви можете змінити своє ім'я, фото, пароль, тему, звуки сповіщень і переглянути, де ви увійшли. Якщо ваш операторський обліковий запис також пов’язаний з клієнтським обліковим записом у Rider App, ви можете переключитися на клієнтський вигляд того самого облікового запису.

Чотири маршрути охоплюють цю статтю, усі доступні з аватара у верхній панелі:

| Маршрут             | Що це таке                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| `/profile`          | Хаб — автоматично перенаправляє вас до вигляду оператора або клієнта залежно від вашого облікового запису |
| `/profile/operator` | Вигляд оператора (за замовчуванням для співробітників)                                           |
| `/profile/customer` | Вигляд клієнта (тільки якщо ваш обліковий запис також пов’язаний з клієнтом у Rider App)          |
| `/profile/legacy`   | Спадковий односторінковий вигляд — ті самі дані у вигляді однієї довгої форми (резервний варіант для оновлених виглядів) |

Це **самообслуговування**. Щоб керувати _іншими_ операторами (вашими колегами), використовуйте [Operators](../../settings/access/operators.md).

Без обмежень доступу — кожен увійшовший користувач може відкрити свій профіль.

## Як `/profile` вирішує, куди вас направити

При безпосередньому переході на `/profile` сторінка не завантажується — відбувається миттєве перенаправлення:

1. Зчитує `lastPersona` з localStorage браузера (встановлено останній раз, коли ви використовували перемикач особи у верхньому заголовку)
2. Якщо `lastPersona = customer` і ваш обліковий запис має пов’язаний клієнт → `/profile/customer`
3. Якщо `lastPersona = operator` → `/profile/operator`
4. Інакше: оператор, якщо у вас є операторський обліковий запис, клієнт — якщо ні
5. За замовчуванням: `/profile/operator`

Ви бачите індикатор завантаження з написом «Перенаправлення...» на короткий момент між завантаженням і перенаправленням.

## Верхній заголовок (спільний для виглядів оператора і клієнта)

Фіксований заголовок розташований у верхній частині `/profile/operator` і `/profile/customer`. Він показує:

- **Аватар** з накладкою камери при наведенні — натисніть, щоб відкрити діалог **Завантаження аватара**
- **Ім'я** (натисніть, щоб скопіювати) і **електронну пошту** (натисніть, щоб скопіювати) — обидва мають підказки для копіювання
- **Значки** — ваш статус (`Активний` / `Неактивний`), `Підтверджено` та `Клієнт`, якщо ви у вигляді клієнта
- **Швидкі KPI** — чотири маленькі плитки, вміст залежить від особи (див. нижче)
- **Перемикач особи** — дві кнопки (`Оператор` / `Клієнт`). Кнопка Клієнт вимкнена з підказкою, якщо у вашого облікового запису немає пов’язаного клієнта
- **Дії** — кнопка `Редагувати`, плюс меню з трьома крапками з _Копіювати ID користувача_, _Копіювати електронну пошту_, _Відкрити як JSON_ (вивантажує ваш запис користувача у новій вкладці) і _Вийти_

Перемикання особи через ці кнопки зберігає ваш вибір у `lastPersona` в localStorage, щоб наступного разу `/profile` знав, куди вас направити.

## `/profile/operator` — три вкладки

Вигляд оператора організовано у три вкладки. Хеш URL (`#overview`, `#security`, `#preferences`) відображає активну вкладку, тож можна створювати глибокі посилання на вкладку.

### Вкладка Огляд

Дві картки поруч: **Організація та роль** (зліва) і **Активність** (справа).

Картка **Організація та роль** показує у режимі лише для читання:

| Поле           | Джерело                                                               |
| -------------- | --------------------------------------------------------------------- |
| **ID користувача** | Ваш операторський ID — скорочений до 8 символів з іконкою копіювання |
| **Команди**    | Теги, призначені вам (отримані з кешу тегів)                          |
| **Електронна пошта** | Електронна пошта вашого облікового запису                          |
| **Статус**     | Значок `Активний` / `Неактивний`                                     |
| **Роль**       | Назва ролі з кількістю дозволів у дужках                              |
| **Відділ**     | З профілю вашої організації                                          |
| **Посада**     | З профілю вашої організації                                          |
| **Місцезнаходження** | Місто та часовий пояс, якщо встановлено                            |
| **2FA**        | `Увімкнено` (зелений) або `Вимкнено` (сірий) — показується лише, якщо відомо |

Ця картка є **лише для читання** у вигляді оператора. Щоб змінити будь-яке з цих полів (роль, відділ, посада, теги), адміністратор має відредагувати ваш запис у [Operators](../../settings/access/operators.md) — ви не можете підвищити себе самостійно.

Картка **Активність** показує ваші останні п’ять дій, отриманих із `/activity/operator/{id}`:

- Кольорова крапка (зелена = Створено, синя = Оновлено, помаранчева = Видалено, основна = інше)
- Значок категорії ("Створено" / "Оновлено" / "Видалено" / "Безпека")
- Опис ("Оновлено транспортний засіб #ABC" тощо)
- Відносний час ("2 години тому")
- Виконавець — зазвичай "ви самі", "Система" для автоматичних змін

Якщо стрічка активності порожня, картка показує ваші **останні сесії входу** як події безпеки. Кнопка "Переглянути всі" внизу перемикає на вкладку Безпека, де є повний список сесій.

KPI над картками показують `{n} actions · {m} changes in 30d`.

### Вкладка Безпека

Дві картки одна над одною: **Керування паролем** та **Активні сесії**.

**Керування паролем** дозволяє змінити власний пароль через діалог. Відкрийте його кнопкою _Змінити_ поруч із "Поточний пароль".

Діалог має три поля:

| Поле                 | Валідація                                           |
| --------------------- | --------------------------------------------------- |
| Поточний пароль       | Обов’язкове; мінімум 8 символів                     |
| Новий пароль          | Обов’язкове; мінімум 8 символів; має відрізнятися від поточного |
| Підтвердження нового пароля | Обов’язкове; мінімум 8 символів; має співпадати з новим паролем |

Кнопка підтвердження залишається вимкненою, доки всі три поля не пройдуть перевірку. Помилки відображаються червоним під кожним полем під час введення. У разі успіху з’являється повідомлення, діалог закривається, форма очищується.

Під розділом пароля розташована невелика таблиця **історії паролів**, яка містить останні три події зміни з датою, дією та причиною. (Наразі це статичний заповнювач — бекенд ще не надає кінцеву точку для історії паролів).

**Активні сесії** відображаються спільним менеджером сесій. Сесії **групуються за відбитком пристрою** (браузер + ОС + тип пристрою + виробник + модель), тому кілька вкладок на одному ноутбуці згортаються в одну групу.

Заголовок кожної групи показує:

- Іконку пристрою (Монітор / Смартфон / Ноутбук залежно від `deviceType`)
- Позначку пристрою — виробник + модель, або ОС + версія, або тип пристрою
- Позначку браузера
- Значок статусу: `active` (остання активність менше 1 години, зелений), `inactive` (менше 24 годин, сірий), `old` (понад 24 години, приглушений), або `Цей пристрій` (поточна сесія, синя обводка)
- Час останньої активності (відносний)
- Кількість сесій у групі

Клацніть заголовок групи, щоб розгорнути її та побачити кожну окрему сесію всередині, кожна з країною та IP з пошуку місцезнаходження, датою входу та іконкою кошика для відкликання цієї сесії. Групу також можна відкликати цілком за допомогою кнопки «Вийти з цього пристрою» внизу розгорнутого списку (поточна сесія завжди зберігається).

Кнопка **Вийти з інших сесій** у верхній частині відкликає _усі_ інші сесії одночасно. Поточний пристрій ніколи не зачіпається. Кількість включає всі неактивні сесії на всіх пристроях.

### Вкладка Параметри

Дві картки: **Тема та стиль карти** і **Звуки сповіщень**.

Перша картка містить спільний селектор теми та селектор стилю карти — ті ж віджети, що й у плаваючому профілі. Детальний опис режимів, акцентних кольорів і стилів карти дивіться в [Themes](../../features/ux/themes.md).

Друга картка містить налаштування звуків сповіщень — звуки для кожного типу тостів, звуки для кожного сповіщення та незалежні повзунки гучності для тостів і сповіщень. Повний вибір дивіться в [Notifications](../../features/ux/notifications.md).

Усі налаштування цієї вкладки зберігаються у **localStorage** вашого браузера, а не на сервері. Це означає, що налаштування є для кожного пристрою та браузера окремо — вони не переносяться при вході з іншого пристрою.

## `/profile/customer` — вигляд зі сторони клієнта

Якщо ваш обліковий запис оператора **також** пов’язаний з обліковим записом користувача (клієнта) у тій самій інсталяції Ridewolf, ви можете переключитися між ролями, щоб побачити, як ви виглядаєте зі сторони клієнта. Кнопка ролі у верхньому заголовку веде сюди.

### Коли у вас немає облікового запису клієнта

Ви бачите пунктирну картку порожнього стану з:

- Іконкою та заголовком «Пов’язати ваш профіль клієнта»
- Описом
- Двома кнопками — **Створити обліковий запис клієнта** та **Пов’язати існуючий** (обидві наразі показують тости «Скоро буде»; бекенд ще не готовий)
- Сповіщенням про перевірку
- Посиланням «Продовжити як оператор» назад до `/profile/operator`

### Коли у вас є обліковий запис клієнта

Дві вкладки: **Огляд** та **Поїздки**.

Основні показники вгорі змінюються на релевантні для клієнта: **Баланс** (відформатована валюта), **Загальна кількість поїздок**, **Рейтинг** (1 десяткове), **Бонус** (бали).

Вкладка **Огляд** показує:

- Картку **Гаманець** — поточний баланс, необов’язкові бонусні бали (тільки якщо > 0) та пов’язаний спосіб оплати (бренд + останні 4 цифри + місяць/рік закінчення + тип провайдера), якщо він існує
- Картку **Статистика поїздок** — три плитки: Загальна кількість поїздок, Рейтинг зі зіркою (і підписом "{n} оцінили"), Бонусні бали
- Бічну панель **Інформація про акаунт** — ID клієнта (моноширинний, усічений), Провайдер, Створено (відносно), Остання активність (відносно, якщо є), Остання поїздка (відносно, якщо є)
- Картку **Пристрої** — ваші зареєстровані клієнтські пристрої (iOS / Android / Web), відображені спільним `ClientDevicesList`
- Швидкі посилання **Безпека та підтримка** — FAQ, Зв’язок з підтримкою, Повідомити про проблему (кнопки-заповнювачі)

Вкладка **Поїздки** показує ваші останні 20 поїздок (спочатку найновіші) з:

- ID поїздки (моноширинний) та час створення (відносний)
- Значок статусу (`completed` суцільний, `active` вторинний, інші — контур)
- Відстань (км), тривалість (хвилини або `Hh Mm`), позначка транспортного засобу
- Ціна (відформатована валюта)
- Рядок зі зірками для рейтингу, якщо він є

Використовується прокручуваний контейнер з фіксованою висотою 500px і станом завантаження з 4 скелетонами. Порожній стан показує іконку карти та напис «Поїздок ще немає».

Тут **немає форми редагування** — це лише режим читання, дзеркало того, що показується у вашому Rider App. Кнопка Редагувати у верхньому заголовку наразі показує тост «Скоро буде».

## `/profile/legacy` — односторінковий запасний варіант

`/profile/legacy` — це **старий односторінковий профіль**, який зберігається для запасного варіанту та прямого посилання. Він містить майже все на одній прокручуваній сторінці замість вкладок:

- Картка заголовка профілю з аватаром, ім’ям, електронною поштою, значком статусу та кнопками Редагувати / Зберегти / Скасувати
- Картка **Особиста інформація** — редаговані Ім’я, Прізвище (текстові поля під час редагування); лише для читання Електронна пошта та редагований Телефон
- Картка **Інформація про акаунт** — лише для читання ID користувача (усічений + копіювання), Електронна пошта, Статус (сирий код)
- Картка **Зовнішній вигляд** — селектор теми та селектор стилю карти (ті ж віджети, що й у вкладці Параметри)
- Картка **Сповіщення та звуки**
- Картка **Безпека** — рядок пароля з кнопкою Змінити (поки не відкриває діалог)
- Нижній колонтитул із версією додатка (перші 7 символів `CF_PAGES_COMMIT_SHA` або локально `DEVELOPMENT_KIT`)

Два важливі застереження:

- Дія **Зберегти** наразі показує тост «Функція ще недоступна» — бекенд не має кінцевої точки `PATCH /operators/me`, тому зміни Імені, Прізвища та Телефону фактично не зберігаються
- Завантаження фото було видалено з цього вигляду; використовуйте оновлений `/profile/operator` і клацніть свій аватар, щоб відкрити діалог завантаження

Віддавайте перевагу `/profile/operator` для щоденного використання. Зберігайте це посилання в закладках лише якщо майбутнє виправлення оновленого вигляду вимагатиме повернення сюди.

## Діалог завантаження аватара

Відкривається з верхнього заголовка (клацніть свій аватар) в оновлених виглядах.

Підтримує:

- Типи файлів: лише `image/png`, `image/jpeg`, `image/jpg` — будь-який інший тип викликає помилку «Тип файлу»
- Максимальний розмір файлу: **10 МБ** — більші файли викликають помилку «Розмір файлу»
- Перетягніть файл або натисніть, щоб вибрати

Діалогове вікно показує попередній перегляд, ім'я файлу та індикатор прогресу під час завантаження. Послідовність завантаження:

1. `POST` файл → повертає `avatarUrl`
2. `PATCH /me` з `{ photo: avatarUrl }` → повертає оновлений запис користувача
3. Сховище користувача оновлюється новим полем `photo`; новий аватар одразу з'являється у всіх посиланнях на нього

Сповіщення підтверджують успіх або помилку. У разі успіху діалогове вікно закривається автоматично.

| Телефон                      | Спадщина (не працює — без бекенду) | На стороні клієнта не перевіряється                                |
| Поточний пароль             | Оператор → Безпека            | Обов’язково, ≥ 8 символів                                         |

| Підтвердження пароля        | Оператор → Безпека            | Обов’язково, має співпадати з новим паролем                        |
| Режим теми                  | Оператор → Переваги, Спадщина | Лише localStorage                                                 |

## Типові робочі процеси

- **Скинути власний пароль** — `/profile/operator` → вкладка Безпека → Змінити → заповнити всі три поля → Надіслати. Діалогове вікно закривається, ви залишаєтесь увійшли
- **Вийти з публічного комп’ютера, про який забули** — вкладка Безпека → розгорнути групу пристроїв → іконка кошика для цієї сесії або «Вийти з цього пристрою» для всіх сесій на ньому. Поточна сесія завжди захищена
- **Підозріла активність** — вкладка Безпека → «Вийти з інших сесій» зверху відкликає всі сесії, крім поточної, одним кліком
- **Змінити аватар** — натиснути на аватар у верхньому заголовку → перетягнути PNG/JPG до 10 МБ → Завантажити
- **Переключити панель керування в темний режим** — вкладка Переваги → Режим теми = Темний (або встановити Системний і дати ОС вирішувати)
- **Закріпити вкладку** — у кожної вкладки є хеш (`#overview`, `#security`, `#preferences`); скопіюйте URL з хешем і використовуйте як пряме посилання
- **Подивитися себе як клієнта** — якщо ваш акаунт пов’язаний, натисніть кнопку Клієнт у верхньому заголовку → побачите свій вигляд у rider-app (баланс, поїздки, пристрої). Повернутися можна так само

## Поради

- **Те, що ви можете редагувати тут, обмежено** — ваша роль, відділ, посада, теги та електронна пошта керуються адміністратором на сторінці [Операторів](../../settings/access/operators.md). Профіль — лише для вашого аватара, пароля, сесій і переваг
- **Переваги локальні** — теми та звуки сповіщень зберігаються в localStorage, а не на сервері. Якщо очистити дані браузера, вони скинуться; при переході на інший пристрій не збережуться
- **Хеш визначає вкладку** — `/profile/operator#security` відкривається безпосередньо на Безпеці. Використовуйте це в посиланнях у чаті, щоб колега бачив той самий вигляд, що й ви
- **Кнопка Зберегти у спадщині наразі не працює** — поки не з’явиться `PATCH /operators/me`, використовуйте оновлений вигляд оператора для всього; для зміни імені звертайтеся до адміністратора
- **Сесії згруповані за пристроями** — якщо бачите один запис, що охоплює кілька вкладок, це нормально. Розгорніть, щоб побачити окремі сесії
- **Персона клієнта залежить від даних** — навіть якщо кнопка видима, вона нічого не робить, якщо у вашому акаунті немає запису `client`. Якщо його немає, ігноруйте кнопку Клієнт і залишайтеся на `/profile/operator`
