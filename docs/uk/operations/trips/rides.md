# Поїздки — Список

**Поїздка** — це одна поїздка, здійснена клієнтом на одному з ваших транспортних засобів. Список поїздок (`/rides`) є основним записом кожної поїздки — минулої, поточної та майбутньої — усього флоту.

Відкрийте рядок, щоб побачити [сторінку деталей поїздки](ride-detail.md) з маршрутом, хронологією та повним набором дій.

Потрібен дозвіл: **Поїздки** (`i1j2k3`).

## Як поїздки відображаються тут

Ви не створюєте поїздки в Панелі керування — вони виникають зі сторони клієнта:

1. Клієнт **розблоковує транспортний засіб** у мобільному додатку (Ridewolf Rider App)
2. Сервер створює новий запис поїздки, пов’язаний із цим транспортним засобом і клієнтом
3. Поїздка одразу з’являється в цьому списку зі статусом **Активний**
4. Коли клієнт **блокує / паркує** транспортний засіб, сервер закриває поїздку; статус змінюється на **Завершено**, і розраховуються підсумкові дані (відстань, тривалість, ціна)
5. Інші кінцеві стани (`Скасовано` тощо) виникають через системні правила або дії оператора

Оновіть або перезавантажте сторінку, щоб отримати останній знімок — активні поїздки оновлюються в міру руху клієнта.

## Порядок за замовчуванням

За замовчуванням сервер повертає **спочатку активні поїздки**, потім завершені у зворотному хронологічному порядку (новіші першими). Щоб змінити цей порядок, застосуйте сортування за стовпцем.

## Фільтри

| Фільтр    | Тип          | Примітки                                                            |
| --------- | ------------ | ------------------------------------------------------------------ |
| Пошук     | Текст        | Пошук за ім’ям клієнта, позначкою транспортного засобу, ID поїздки |
| Діапазон дат | Календар    | Вибір від/до; за замовчуванням — «весь час»                        |
| Статус    | Випадаючий список | `Активний`, `Завершено`, `Скасовано` тощо                          |
| Рейтинг   | Випадаючий список | Фільтр за кількістю зірок, залишених клієнтом (1–5, _Без рейтингу_) |
| Теги      | Мультивибір | Фільтр за тегами поїздки (успадковані від транспортного засобу — див. нижче) |

Усі фільтри комбінуються через AND. Фільтри відображаються над таблицею; URL відображає поточний стан фільтрів.

## Стовпці

| Стовпець  | Сортується? | Вміст                                                              |
| --------- | ----------- | ----------------------------------------------------------------- |
| Клієнт   | —           | Аватар, ім’я, посилання на профіль клієнта                        |
| Транспортний засіб | —   | Позначка, модель, посилання на транспортний засіб                 |
| Тариф    | —           | Назва тарифу, застосованого до поїздки                            |
| Статистика | —          | Швидкі бейджі: відстань, тривалість, загальна вартість            |
| Теги     | —           | Теги, успадковані від **транспортного засобу** на момент початку поїздки |
| Статус   | ✓           | Піктограма статусу (Активний, Завершено, Скасовано тощо)          |
| Рейтинг  | ✓           | Рейтинг у зірках, залишений клієнтом (або «–», якщо відсутній)    |
| Створено | ✓           | Дата і час початку поїздки; сортування за замовчуванням — новіші першими |

Сортуйте, натискаючи на заголовок стовпця, що сортується. Обране сортування є частиною URL і **перевизначає** порядок за замовчуванням, описаний вище — немає третього кліку для «відновлення за замовчуванням», але ви можете очистити сортування, редагуючи URL або оновивши сторінку без параметра сортування.

> **Теги успадковуються від транспортного засобу.** Поїздки не мають власного редактора тегів — теги поїздки є знімком тегів транспортного засобу на момент початку поїздки. Змініть теги транспортного засобу пізніше, і існуючі поїздки збережуть свій оригінальний знімок; лише нові поїздки отримають нові теги.

## Дії з рядком

Кожен рядок має **меню з трьома крапками** праворуч. Доступні дії залежать від статусу поїздки та ваших дозволів:

| Дія          | Дозвіл          | Коли доступна                                                  |
| ------------ | --------------- | -------------------------------------------------------------- |
| **Пауза**    | `pause-unpause` | Поїздка **Активна** (ще не на паузі, не завершена, не скасована) |
| **Відновити**| `pause-unpause` | Поїздка **на паузі**                                           |
| **Завершити поїздку** | `end-ride` | Поїздка **не** Завершена або Скасована                         |

Дії, на які у вас немає дозволу, приховані. Вимкнені дії (наприклад, Завершити для вже завершеної поїздки) відображаються сірими, щоб ви бачили, що можливо у відповідному стані.

Повний набір дій — повернення коштів, перегляд маршруту на карті, надсилання повідомлення, архівація — доступний на **сторінці деталей поїздки**. Клікніть на рядок, щоб отримати до них доступ.

## Дії на сторінці

У верхньому правому куті сторінки списку:

- **Експортувати** — завантажити поточний відфільтрований список у файл (фільтри та сортування зберігаються)

## Типові робочі процеси зі списком

- **Слідкувати за активністю в реальному часі** — відкрийте сторінку і залишайтеся на ній; зверху списку показані активні поїздки
- **Знаходити поїздки в зоні або часовому проміжку** — комбінуйте діапазон дат + статус + теги
- **Виявляти аномалії** — фільтруйте за `Статус = Скасовано` або `Рейтинг ≤ 2` і шукайте закономірності (той самий транспортний засіб? той самий час доби?)
- **Швидко зупинити завислу поїздку** — не виходячи зі списку, відкрийте меню рядка і _Завершити поїздку_ (потрібен дозвіл)

## Поради

- **URL можна поділитися** — відфільтруйте список, скопіюйте URL, надішліть колезі — він побачить те саме
- **Бейджі статистики у списку** — швидкий спосіб помітити надто короткі або довгі поїздки перед відкриттям деталей
- **Не довіряйте лише рейтингу** — відкривайте сторінку деталей для поїздок з низьким рейтингом; рейтинг — лише один із багатьох сигналів
- **Дозволи залежать від компанії** — деякі оператори бачать лише поїздки на транспортних засобах, якими вони керують; якщо поїздка відсутня, зверніться до адміністратора
