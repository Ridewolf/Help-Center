# Деталі поїздки

Сторінка деталей поїздки (`/rides/:id`) — це робоче місце для однієї поїздки. Використовуйте її для розслідування скарг, аудиту нарахувань, виконання дій оператора (пауза, повернення коштів, архівація) та перегляду повного журналу подій.

Зазвичай ви потрапляєте сюди, натискаючи рядок у [списку Поїздок](rides.md) або з профілю клієнта.

Необхідний дозвіл: **Rides** (`i1j2k3`).

## Макет

Зверху вниз:

1. **Заголовок** — ключові факти + кнопка _Дії_
2. **Оглядові картки** — тривалість, відстань, вартість, статус
3. **Інформаційні картки** — інформація про поїздку, розбивка, знімок тарифу
4. **Вкладки** — Деталі (карта маршруту + хронологія) та Активність (повний журнал подій)

## Заголовок

Верхня смуга ідентифікує поїздку з першого погляду:

- **Кнопка Назад** (`←`) повертає до списку
- **ID поїздки** з іконкою _Копіювати_
- **Статус у вигляді пігулки** (Активний, Завершено, Скасовано тощо)
- Посилання на **Клієнта** та **транспортний засіб**
- **Час початку → закінчення** та **загальна вартість**
- Кнопка **Дії** праворуч — відкриває діалог дій (описано нижче)

## Дії

Натисніть **Дії** у заголовку, щоб відкрити діалог з усіма доступними діями оператора для цієї поїздки. Дії вимикаються залежно від статусу поїздки та ваших дозволів, з підказкою, чому вони недоступні:

| Дія                   | Коли доступна                         | Дозвіл          |
| --------------------- | ------------------------------------ | --------------- |
| **Пауза / Відновлення** | Поїздка має бути активною для паузи або відновлення | `pause-unpause` |
| **Завершити поїздку**  | Поїздка має бути активною для завершення | `end-ride`      |
| **Переглянути маршрут на карті** | Завжди (переходить на вкладку карти) | —               |
| **Повернути кошти**    | Поїздка має бути завершеною для повернення | refund-related  |
| **Надіслати сповіщення** | Завжди (надсилає push-повідомлення користувачу) | notification    |
| **Архівувати поїздку** | Завжди                               | archive         |

Наведіть курсор на вимкнену дію, щоб побачити, чому вона недоступна (наприклад, «Поїздка має бути завершеною для повернення»).

Діалог _Дії_ у заголовку є **надмножиною** доступних дій; меню рядка на сторінці списку містить лише три найпоширеніші (Пауза / Відновлення / Завершити). Для повернень, перегляду маршруту, push-сповіщень і архівації — використовуйте цей діалог.

## Оглядові картки

Ряд із чотирьох невеликих карток під заголовком дає швидку інформацію:

- **Тривалість** — загальний час поїздки
- **Відстань** — загальна пройдена відстань
- **Вартість** — загальна нарахована вартість
- **Статус** — поточний статус поїздки (відображається як у пігулці в заголовку, але більший і помітніший)

## Інформаційні картки

Сітка з трьох карток розташована під оглядовими, показуючи основні дані поїздки:

- **Інформація про поїздку** — транспортний засіб, клієнт, тариф, ID, часові позначки
- **Розбивка** — покроковий розрахунок вартості по хвилинах (стартовий збір, час, відстань, модифікатори, знижки)
- **Деталі тарифу** — знімок тарифу, застосованого для цієї поїздки (щоб бачити, за що саме клієнту нарахували, навіть якщо тариф змінився пізніше)

## Вкладки

Під картками деталі перемикаються між двома вкладками:

| Вкладка       | Що всередині                                                                                                                                               |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Деталі**    | Карта маршруту, хронологія значущих подій, повні інформаційні картки                                                                                       |
| **Активність** | Хронологічний журнал подій — кожна зміна стану, сигнал і системна дія, пов’язана з цією поїздкою — ширше за хронологію Деталей (корисно для налагодження IoT) |

### Карта маршруту

У вкладці Деталі карта маршруту показує GPS-трек поїздки:

- **Маркування початку / кінця** з їхніми адресами
- **Полілінія**, пофарбована за швидкістю (повільні та швидкі сегменти)
- **Накладки зон**, якщо поїздка заходила у заборонені зони
- **Легенда**, що пояснює кольорову шкалу
- **Масштабування / панорамування** мишею або жестами двома пальцями

### Хронологія

Під картою вертикальна хронологія перераховує всі значущі події поїздки:

- **Початок поїздки** (з розблокуванням транспортного засобу)
- **Пауза / відновлення** (якщо були)
- **Входи / виходи з зон**
- **Попередження про швидкість**
- **Завершення поїздки** (з блокуванням / доказом паркування, якщо є)
- **Події оплати**

Використовуйте хронологію для розслідування спорів («користувач каже, що з нього зняли кошти після завершення поїздки») — кожна подія має часову позначку.

### Вкладка Активність

Вкладка Активність показує повний журнал подій, включно з системними діями — ширше за хронологію Деталей. Використовуйте її, коли простої хронології недостатньо (наприклад, для технічного налагодження проблеми IoT).

## Типові робочі процеси

- **Розслідування скарги клієнта** — перегляньте розбивку, потім карту маршруту та хронологію; хронологія рідко помиляється
- **Аудит рішення про повернення коштів** — відкрийте картку розбивки; рядки показують, за що саме клієнт заплатив, потім натисніть _Дії → Повернути кошти_
- **Пауза і дзвінок клієнту** — _Дії → Пауза_ зупиняє поїздку; _Дії → Надіслати сповіщення_ нагадує клієнту; _Відновити_, коли він повернеться
- **Завершення завислої поїздки** — для поїздок, які ніколи не закриваються (втрата зв’язку, клієнт залишив транспортний засіб увімкненим), використовуйте _Дії → Завершити поїздку_ для примусового закриття — система використає останню відому позицію для доказу паркування

## Поради

- **Прочитайте підказку вимкненої дії** — вимкнені кнопки не зламані; підказка пояснює, в якому стані має бути поїздка
- **Скопіюйте ID поїздки** з заголовка, щоб вставити у розмову з підтримкою або запит до бекенда
- **Деталі тарифу показують тариф _таким, яким він був_** — навіть якщо тариф було змінено пізніше, знімок зберігається для аудиту
- **Діалог дій — це повне меню** — не шукайте повернення коштів/архівування у списку; вони знаходяться тут
