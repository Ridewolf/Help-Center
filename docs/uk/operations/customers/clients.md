# Клієнти — Список

Список Клієнтів (`/clients`) — це ваша база даних клієнтів: кожна особа, яка зареєструвала обліковий запис у вашому сервісі, з їхнім балансом, тегами, підсумком історії поїздок та каналами зв’язку.

Для роботи з окремим клієнтом (повна історія, дії з балансом, пристрої, коментарі) відкрийте [сторінку деталей клієнта](client-detail.md).

Потрібен дозвіл: **Клієнти** (`e4f5h6`). Додаткові піддозволи контролюють конкретні дії над рядками та масові дії.

## Як клієнти з’являються тут

Зазвичай ви не створюєте клієнтів у Панелі керування — вони реєструються через мобільний додаток для пасажирів:

1. Особа встановлює **Ridewolf rider app** і реєструється (телефон або електронна пошта)
2. Бекенд створює запис клієнта; рядок з’являється тут зі статусом **Реєстрація** під час проходження верифікації (SMS, ID, спосіб оплати)
3. Після завершення верифікації статус змінюється на **Активний** — клієнт може користуватися поїздками
4. Оператори можуть вручну створювати клієнтів (наприклад, для VIP або тестових акаунтів) через `+ Створити` — описано в статті _Створення_

Список оновлюється при перезавантаженні або зміні фільтрів.

## Фільтри

| Фільтр     | Тип          | Примітки                                                    |
| ---------- | ------------ | ----------------------------------------------------------- |
| Пошук      | Текст        | Пошук за ім’ям, телефоном, електронною поштою, ID клієнта  |
| Діапазон дат | Календар    | Фільтр за **датою реєстрації**; від / до                   |
| Статус     | Випадаючий список | `Активний` / `Заблоковано` / `Заморожено` / `Реєстрація` (або `Всі`) |
| Теги       | Мультивибір  | Фільтр за тегами, застосованими до клієнта                  |

Всі фільтри застосовуються через І (AND). Фільтри відображаються над таблицею; URL відображає поточний стан.

## Колонки

| Колонка       | Сортується? | Вміст                                                                          |
| ------------- | ----------- | ------------------------------------------------------------------------------ |
| **Клієнт**   | ✓           | Аватар + ім’я/прізвище + телефон або електронна пошта; посилання на деталі клієнта |
| **Канали**   | —           | Іконки каналів зв’язку, які клієнт підтвердив (телефон, електронна пошта, соцмережі) |
| **Баланс**   | ✓           | Баланс гаманця в валюті компанії, червоним при від’ємному значенні              |
| **Теги**     | —           | Теги, застосовані до цього клієнта                                            |
| **Статус**   | ✓           | Пігулка статусу (див. довідку нижче)                                          |
| **Рейтинг**  | ✓           | Середній рейтинг, який пасажири залишили цьому клієнту (рейтинг водія)         |
| **Поїздки**  | ✓           | Загальна кількість поїздок                                                    |
| **Остання поїздка** | ✓     | Коли клієнт востаннє користувався поїздкою                                    |
| **Оплата**   | —           | Іконка способу оплати за замовчуванням (картка, гаманець тощо)                 |

Сортування за допомогою кліку на заголовок колонки, що сортується. Сортування відображається в URL.

## Довідка по статусах

| Статус          | Значення                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------- |
| **Активний**    | Повністю верифікований, може користуватися поїздками, може бути списаний платіж            |
| **Заблоковано** | Не може користуватися поїздками; блокування ініційоване оператором (шахрайство, зловживання, борг) або системою |
| **Заморожено**  | Обліковий запис призупинено (наприклад, під час розслідування спору або за запитом клієнта) |
| **Реєстрація**  | Процес реєстрації — телефон / електронна пошта / ID / спосіб оплати ще не підтверджено    |

## Дії над рядком

У кожного рядка справа є **меню з трьома крапками**. Доступні дії залежать від ваших дозволів:

| Дія                 | Дозвіл              | Що робить                                                                         |
| ------------------- | ------------------- | --------------------------------------------------------------------------------- |
| **Переглянути профіль** | —               | Відкриває [сторінку деталей клієнта](client-detail.md)                           |
| **Історія поїздок**  | —                   | Відкриває перегляд поїздок клієнта (фокусований зріз глобального списку поїздок) |
| **Надіслати SMS**    | —                   | Відкриває діалог для надсилання SMS на підтверджений телефон клієнта              |
| **Надіслати email**  | —                   | Відкриває діалог для надсилання електронного листа на підтверджену адресу клієнта |
| **Надіслати push**   | —                   | Відкриває діалог для надсилання push-повідомлення в додаток клієнта               |
| **Поповнити баланс** | `topup-manual`      | Відкриває діалог балансу — зарахування грошей на гаманець клієнта                 |
| **Виписати штраф**   | `fine`              | Відкриває діалог штрафу — списання грошей з гаманця (за пошкодження, паркування тощо) |
| **Заблокувати / Розблокувати** | `block` / `unblock` | Відкриває діалог блокування — перемикає статус блокування клієнта з опціональною причиною |
| **Редагувати**       | `edit`              | Відкриває [форму редагування](client-create-edit.md)                             |
| **Видалити**         | `delete`            | М’яке видалення запису клієнта (з підтвердженням; червона деструктивна дія)      |

Дії, на які у вас немає дозволів, приховані в меню.

## Масові дії

Виберіть одного або кількох клієнтів за допомогою чекбоксів зліва. Зверху з’являється **панель масових дій** з кількістю вибраних і доступними діями:

| Масова дія       | Дозвіл              | Що вона робить                                                          |
| ----------------- | ------------------- | ----------------------------------------------------------------------- |
| **Додати баланс** | `topup-manual`      | Зарахувати одну суму на кожен вибраний гаманець (з підтвердженням)      |
| **Списати суму**  | `fine`              | Списати одну суму з кожного вибраного гаманця (наприклад, штраф за подію) |
| **Змінити статус**| `block` / `unblock` | Встановити однаковий статус для всіх вибраних клієнтів (Активний / Заблокований / Заморожений) |
| **Надіслати push**| —                   | Надіслати push-повідомлення всім вибраним клієнтам одночасно            |

Масові діалоги проведуть вас через введення суми / повідомлення / статусу, а потім застосують їх до всіх вибраних рядків за одну операцію з остаточним підтвердженням.

## Дії на сторінці (угорі справа)

- **+ Створити** — відкриває [форму створення клієнта](client-create-edit.md) (окрема стаття)

## Типові робочі процеси

- **Розслідувати скаргу на платіж** — пошук за телефоном або електронною поштою → відкрити деталі → перевірити баланс і історію поїздок
- **Поповнити гаманець за запитом оператора** — знайти клієнта, _Поповнити баланс_ у меню рядка, ввести суму, підтвердити
- **Заблокувати шахрая** — знайти клієнта → _Блокувати / Розблокувати_ → встановити Заблоковано з причиною; статус зміниться на _Заблоковано_, поїздки заборонені
- **Надіслати SMS про відключення** — відфільтрувати за тегом зони → _Вибрати все_ → _Надіслати push_ (або використати Маркетинг → SMS для не термінових розсилок)
- **Перевірити власників тегу** — відфільтрувати за тегом, перевірити баланс і кількість поїздок на наявність аномалій

## Поради

- **Статус — це мовчазний охоронець** — клієнти в станах _Реєстрація_ / _Заморожено_ / _Заблоковано_ не можуть починати поїздки; не очікуйте побачити їх у списку Поїздок
- **Іконки каналів показують, що підтверджено** — відсутність іконки електронної пошти означає, що єдиний канал зв’язку з клієнтом — SMS
- **Рейтинг — це оцінка клієнта від райдера** (не поїздки) — низькі рейтинги часто свідчать про проблеми з паркуванням або грубу поведінку; перевіряйте разом із доказами паркування та квитками
- **Баланс, що стає червоним** = від’ємний гаманець. Клієнт не може почати нові поїздки, доки не поповнить баланс або не отримає повернення
- **Дозволи мають шарувату структуру** — ви можете мати дозвіл _Надіслати SMS_, але не _Поповнити_ того самого клієнта; меню показує, що доступно
- **URL можна поширювати** — скопіюйте відфільтрований вигляд (наприклад, _Заблоковані клієнти з поїздками > 0_) і надішліть колезі
