# Транспортні засоби — Список

Список транспортних засобів (`/vehicles`) — це інвентар вашого усього флоту — кожен самокат, велосипед або інший пристрій із поточним станом, місцезнаходженням, зарядом батареї, підключенням IoT, тегами та зоною. Це найчастіше використовувана сторінка в **Панелі керування**: майже будь-яку операцію з флотом ви починаєте тут.

Для роботи з окремим транспортним засобом (повний статус, історія, команди IoT, відтворення маршруту) відкрийте [сторінку деталей транспортного засобу](vehicle-detail.md).

Потрібен дозвіл: **Vehicles** (`k7m8n9`).

## Як транспортні засоби потрапляють сюди

Транспортні засоби не з’являються самі по собі — їх створюєте і підтримуєте ви:

1. Оператор **створює транспортний засіб** через кнопку _Створити_ (вказує мітку, модель, IoT-пристрій, початковий стан)
2. Транспортний засіб реєструється на IoT-пристрій; цей пристрій починає безперервно надсилати **заряд батареї, стан замка, останній сигнал, GPS-координати**
3. Як тільки IoT-пристрій надсилає перший сигнал, рядок у цьому списку заповнюється живими даними — відсоток заряду, час сигналу, індикатор замка
4. Оператори (та масові дії) **оновлюють статус, теги, зону, налаштування** протягом усього життєвого циклу транспортного засобу
5. Коли транспортний засіб виводять з експлуатації, ви змінюєте його статус на _Зберігання_ / _Технічне обслуговування_ / тощо, або видаляєте його

Список оновлюється при перезавантаженні або зміні фільтрів; живі оновлення IoT, що надходять із бекенду, також можуть оновлювати рядки на місці.

## Режими перегляду — Таблиця проти Карти

Сторінка має два режими перегляду, між якими можна переключатися за допомогою керування вгорі:

- **Таблиця** — повна сітка даних з усіма фільтрами, сортуванням і можливістю масового вибору
- **Карта** — той самий флот, відображений на карті вашої операційної зони; транспортні засоби позначені кольоровими пінами за статусом із бейджами заряду батареї

Фільтри застосовуються до обох режимів. Режим Карти зручний для виявлення скупчень, прогалин і можливостей ребалансування; Таблиця — для роботи з даними.

## Фільтри

| Фільтр   | Тип             | Примітки                                                                    |
| -------- | --------------- | --------------------------------------------------------------------------- |
| Пошук    | Текст на всю ширину | Пошук за міткою транспортного засобу, ID, серійним номером IoT — введення **затримується ~300мс** |
| Одометр  | Випадаючий список | Діапазони загальної дистанції: `<1k`, `1k–10k`, `10k–50k`, `50k–100k`, `>100k` км |
| Статус   | Випадаючий список | Фільтр за статусом транспортного засобу (див. довідку нижче)                 |
| Теги     | Мультивибір     | Фільтр за тегами, застосованими до транспортного засобу                     |

Всі фільтри застосовуються через логічне І. Фільтри відображаються над таблицею; URL оновлюється під час роботи.

## Колонки

| Колонка         | Сортується? | Вміст                                                                                   |
| --------------- | ---------- | --------------------------------------------------------------------------------------- |
| **Стан**        | —          | Компактні індикатори стану IoT (периферія) — маленькі іконки, що підсумовують статус підсистем IoT |
| **Код**         | ✓          | Мітка транспортного засобу (людинозрозумілий код на наклейці) з посиланням на деталі транспортного засобу |
| **Статус**      | ✓          | Пігулка статусу (Доступний, У використанні, Заряджається тощо — див. довідку нижче)     |
| **Модель**      | —          | Назва моделі та мініатюра (наприклад, Xiaomi M365)                                     |
| **Замок**       | —          | Іконка замка — закритий (заблоковано) / відкритий (розблоковано) за останнім звітом IoT |
| **Батарея**     | ✓          | Відсоток заряду батареї з кольоровою смугою (зелений ≥ 60%, жовтий 30–60%, червоний < 30%) |
| **Теги**        | —          | Теги, застосовані до цього транспортного засобу (оператори можуть редагувати)           |
| **Зона**        | —          | Зона, в якій наразі знаходиться транспортний засіб, або «Поза зоною»                    |
| **Остання поїздка** | ✓       | Дата/час останнього розблокування транспортного засобу для поїздки                    |
| **Останній сигнал** | ✓       | Коли IoT-пристрій востаннє надіслав звіт (старий сигнал = пристрій, ймовірно, офлайн)  |

Колонки, що сортуються, позначені ✓ — натисніть на заголовок. Сортування відображається в URL.

## Довідка по статусах

Кожен транспортний засіб має рівно один статус. Статус визначає поведінку (чи можуть користувачі орендувати, чи спрацьовують сповіщення IoT тощо):

| Статус                  | Значення                                               |
| ----------------------- | ----------------------------------------------------- |
| **Доступний**           | Вільний, доступний для оренди, правильно припаркований |
| **У використанні**      | Зараз у поїздці                                     |
| **Заряджається**        | На зарядній станції                                  |
| **Розряджений**         | Заряд батареї занизький для оренди                   |
| **Потребує розслідування** | Позначений системою або оператором — потребує ручної перевірки |
| **Технічне обслуговування** | У майстерні / поза флотом для ремонту               |
| **Не готовий**          | Створений, але ще не випущений для користувачів       |
| **Зарезервовано**       | Заброньований для конкретного користувача/замовлення  |
| **Транспортування**     | Переміщується (ребалансування, збір з поля)           |
| **Зберігання**          | У довгостроковому зберіганні, поза операціями          |
| **Вкрадено**            | Повідомлено про крадіжку / відсутній                   |
| **Тривога**             | Критична тривога від IoT або системи                   |

## Дії з рядком

Кожен рядок має **меню з трьома крапками** праворуч. Доступні дії залежать від ваших дозволів:

| Дія                     | Дозвіл               | Що робить                                                           |
| ----------------------- | -------------------- | ------------------------------------------------------------------- |
| **Переглянути деталі**  | —                    | Відкрити [сторінку деталей транспортного засобу](vehicle-detail.md) |
| **Переглянути історію маршруту** | `coordinates-history` | Відкрити карту з відтворенням останнього GPS-шляху транспортного засобу |
| **Відкрити в Google Maps** | —                    | Відкрити останні відомі координати транспортного засобу в Google Maps (новій вкладці) |
| **Редагувати**          | `edit`               | Відкрити форму редагування                                         |
| **Змінити статус**      | `edit`               | Відкрити невелике діалогове вікно для зміни статусу без виходу зі списку |
| **Видалити**            | `delete`             | М'яке видалення транспортного засобу (з підтвердженням)            |

Дії, для яких у вас немає дозволів, приховані.

## Масові дії

Виберіть один або кілька транспортних засобів за допомогою прапорців ліворуч від кожного рядка. Зверху з’явиться **панель масових дій** з кількістю вибраних та доступними діями:

| Масова дія            | Дозвіл         | Що робить                                                        |
| --------------------- | -------------- | ---------------------------------------------------------------- |
| **Змінити статус**    | `bulk-update`  | Відкрити діалог і застосувати один статус до всіх вибраних транспортних засобів |
| **Змінити теги**      | `bulk-update`  | Додати або видалити теги у вибраних                              |
| **Змінити налаштування** | `bulk-update`  | Застосувати налаштування транспортних засобів (наприклад, макс. швидкість, тривоги) до всіх вибраних |
| **Надіслати команду** | `iot-command`  | Надіслати IoT-команду (заблокувати, розблокувати, увімкнути/вимкнути тривогу, перезавантажити) усім вибраним |
| **Пакетний QR**       | —              | Згенерувати друкований лист із QR-кодами для вибраних транспортних засобів |
| **Видалити вибране**  | `delete`       | М'яке видалення кожного вибраного транспортного засобу (з підтвердженням) |

## Дії сторінки (угорі праворуч)

- **+ Створити** — відкриває [форму створення транспортного засобу](vehicle-create-edit.md) (окрема стаття)
- **Експортувати** — завантажити поточний відфільтрований список у файл (фільтри та сортування збережено)
- **Пакетний QR** (також доступно як масова дія) — відкриває майстер створення QR-кодів для друку

## Перегляд карти

Коли ви переключаєтеся на перегляд карти:

- Транспортні засоби відображаються як **піни**, пофарбовані за статусом (зелений = Доступний, синій = У використанні тощо)
- Біля кожного піна є невеликий **значок батареї**
- Клік на пін відкриває спливаюче вікно з назвою транспортного засобу, статусом, зарядом батареї та посиланням _Переглянути деталі_
- **Фільтри залишаються активними** — звужуйте за статусом, тегами тощо, карта оновлюється
- Панорамування / масштабування мишею або жестами двома пальцями

Карта отримує дані з того ж джерела, що й таблиця — це інший спосіб перегляду, а не інший набір даних.

## Типові робочі процеси

- **Масове балансування** — відфільтруйте за `Статус = Розряджений` + зона, виберіть усі, _Надіслати команду → Заблокувати_ (або _Змінити статус → Транспортування_) перед підбором
- **Знайти застряглий транспортний засіб** — відсортуйте за _Останній сигнал_ за зростанням, щоб побачити найстаріші сигнали зверху
- **Виявити низький заряд батареї до проблеми** — відсортуйте за _Батарея_ за зростанням; низ флоту — це ваша майбутня черга техобслуговування
- **Аудит тегу** — відфільтруйте за тегом і перегляньте рядки
- **Підготовка польового персоналу** — відфільтруйте цілі на день, _Пакетний QR_ для друку етикеток на нові одиниці

## Поради

- **Пошук з затримкою** — зробіть паузу у введенні, щоб сервер відповів один раз
- **URL = вигляд** — копіюйте та діліться посиланнями з фільтрами з колегами
- **Колонка стану здоров’я на перший погляд** — маленькі іконки узагальнюють підсистеми IoT; наведіть курсор на будь-яку іконку, щоб побачити, що вона означає (наприклад, сигнал мобільного зв’язку, стан замка, показання сенсора)
- **Колір батареї — ваш скорочений код** — червона смуга у списку = потребує зарядки або швидкого підбору
- **Індикатор замка — останній звіт IoT** — може бути застарілим на кілька секунд; використовуйте _Надіслати команду → Заблокувати_, якщо потрібно гарантувати стан на пристрої
