# Деталі транспортного засобу

Сторінка деталей транспортного засобу (`/vehicles/:id`) — це робоче місце для окремого одиниці. Використовуйте її, щоб переглядати живі дані IoT, надсилати команди, переглядати історію поїздок, розслідувати сповіщення та виконувати дії оператора (редагувати, змінювати місцезнаходження, позначати для технічного обслуговування, генерувати QR, видаляти).

Зазвичай ви потрапляєте сюди, натискаючи рядок у [Списку транспортних засобів](vehicles.md).

Потрібен дозвіл: **Транспортні засоби** (`k7m8n9`). Деякі вкладки та дії потребують додаткових дозволів (зазначено нижче).

## Макет

Зверху вниз:

1. **Заголовок** — назад, мітка, статус, кнопка _Дії_
2. **Оглядові картки** — батарея, останній сигнал, зведення стану IoT, модель тощо
3. **Картка місцезнаходження** — маленька карта з поточним GPS-маркером
4. **Вкладки** — Деталі / Поїздки / Активність / Сповіщення / Команди

## Заголовок

Верхня смуга ідентифікує транспортний засіб:

- **Кнопка назад** (`←`) повертає до списку
- **Мітка транспортного засобу** (наприклад, _RW-001_) та **статусна пігулка** (Доступний, У використанні тощо)
- Кнопка **Дії** праворуч — відкриває діалог дій

## Дії

Натискання **Дій** відкриває модальне вікно з усіма доступними діями оператора для цього транспортного засобу. Деякі дії обмежені дозволами:

| Дія                      | Дозвіл     | Що робить                                                                                                                             |
| ------------------------ | ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Редагувати транспортний засіб** | `edit`     | Відкриває [форму редагування](vehicle-create-edit.md)                                                                                  |
| **Переглянути історію маршруту** | —          | Відкриває діалог координат з останнім GPS-маршрутом                                                                                     |
| **Позначити для техобслуговування** | —          | Швидко встановлює статус _Технічне обслуговування_                                                                                      |
| **Змінити місцезнаходження** | —          | Відкриває карту для ручного оновлення GPS-координат (використовується, коли IoT-пристрій мовчить, а оператор знає, де транспортний засіб) |
| **Згенерувати QR-код**    | —          | Відкриває генератор QR для цього транспортного засобу (друкована мітка)                                                                |
| **Видалити транспортний засіб** | `delete`   | М’яке видалення з підтвердженням                                                                                                       |

Дії, на які у вас немає дозволу, приховані в діалозі.

## Оглядові картки

Сітка маленьких карток під заголовком дає короткий огляд транспортного засобу:

- **Батарея** — відсоток заряду батареї самоката (і батареї IoT-плати, якщо вона окремо повідомляється)
- **Останній сигнал** — коли IoT-пристрій востаннє передавав дані, зі статусною пігулкою (Онлайн / Офлайн / Застарілий)
- **Замок** — заблоковано / розблоковано
- **Модель** — назва моделі, статус, зображення
- **GSM / GPS** — статус дійсності мобільного зв’язку та GPS
- **Режим швидкості** — поточний режим їзди (еко, нормальний, спорт тощо, якщо модель підтримує)
- **Напруга** — напруга IoT-плати (інженерне поле)

## Картка місцезнаходження

Маленька карта показує транспортний засіб як один маркер на останній відомій GPS-координаті з масштабом за замовчуванням, що підлаштовується під маркер. Використовуйте для швидкого запитання «де він зараз?» без відкриття історії маршруту.

## Вкладки

Деталі перемикаються між п’ятьма вкладками (деякі обмежені дозволами):

| Вкладка       | Дозвіл       | Що всередині                                                                       |
| ------------ | ------------ | --------------------------------------------------------------------------------- |
| **Деталі**   | —            | Повні дані транспортного засобу — поля IoT, модель + тарифи, теги, зони, GSM/GPS, режим швидкості |
| **Поїздки**  | view-rides   | Останні поїздки на цьому транспортному засобі (фокусований зріз глобального списку Поїздок) |
| **Активність** | —            | Журнал активності, обмежений цим транспортним засобом (дії оператора та системи)  |
| **Сповіщення** | —            | Груповані помилки та тривоги IoT з пагінацією (історія «що пішло не так»)
| **Команди**  | `iot-command` | Надсилання команд IoT безпосередньо на пристрій (замок, розблокування, сигналізація, перезавантаження тощо) |

### Вкладка Деталі

Вкладка за замовчуванням і найглибший огляд стану транспортного засобу:

- **Панель IoT** — батарея, напруга, замок, сигнал GSM, дійсність GPS, останній сигнал, режим швидкості
- **Панель моделі** — назва моделі та зображення, статус, теги, успадковані від моделі
- **Панель тарифів** — тарифи, призначені моделі транспортного засобу (вони регулюють ціноутворення поїздок)
- **Панель тегів** — теги, застосовані до цього конкретного транспортного засобу (оператор може редагувати через _Редагувати_)
- **Панель зон** — зони, до яких транспортний засіб наразі належить

Якщо дані IoT не завантажуються, у цій вкладці з’являється банер помилки; решта сторінки працює як і раніше.

### Вкладка Поїздки

Перелік останніх поїздок на цьому транспортному засобі — той самий формат рядка, що й у глобальному списку Поїздок, відфільтрований лише за цим транспортним засобом. Натисніть будь-який рядок, щоб відкрити деталі поїздки.

Ця вкладка прихована, якщо у вас немає дозволу `view-rides` на цей транспортний засіб.

### Вкладка Активність

Хронологічний **журнал активності** для цього транспортного засобу: кожна дія оператора (редагування, зміна статусу, видалення, оновлення тегів) і кожна системна подія (зміни статусу за тригерами IoT, запуск автоматизації).

Корисно для відповідності, підзвітності та налагодження несподіваних змін стану.

### Вкладка Сповіщення

Груповані **сповіщення та помилки IoT**, створені пристроєм, з пагінацією. Кожен запис містить:

- Код і зрозумілу людині назву
- Час першого / останнього виявлення
- Частоту (як часто цей код з’являвся)
- Статус (активний / вирішений)

Кнопка _Очистити_ (де підтримується) дозволяє позначити групу як вирішену. Пагінація дає змогу переглядати історичні сповіщення.

### Вкладка Команди

Прямі **IoT-команди** для пристрою, згруповані за категоріями (наприклад, _Заблокувати та розблокувати_, _Тривога_, _Світло_, _Система_). Доступ за дозволом `iot-command`.

- Виберіть команду та натисніть _Відправити_
- Команда надсилається на IoT-пристрій; час відповіді залежить від якості мобільного сигналу
- Історія останніх команд відображається нижче зі статусом (надіслано / доставлено / помилка)

Використовуйте це, коли потрібно виконати те, що не охоплює масова команда _Відправити команду_ — діагностика, одноразові перезавантаження, ручне розблокування для випадків підтримки.

## Типові робочі процеси

- **Розслідувати скаргу** — відкрийте Активність, щоб побачити, які оператори / системи працювали з цим транспортним засобом сьогодні; потім Сповіщення для помилок IoT; потім Поїздки для відповідної поїздки
- **Примусово заблокувати або розблокувати** — вкладка Команди → _Відправити блокування_ або _Відправити розблокування_ (потрібен `iot-command`)
- **Взяти пристрій на сервіс** — _Дії → Позначити для техобслуговування_ (встановлює статус); відправте польову команду
- **Вручну виправити GPS** — _Дії → Змінити місцезнаходження_ (коли IoT-пристрій не відповідає і ви знаєте, де він знаходиться)
- **Друкувати нову наклейку** — _Дії → Згенерувати QR-код_

## Поради

- **Слідкуйте за вкладкою Сповіщення** — часті коди є ранніми попередженнями про проблеми з обладнанням; усувайте їх до того, як вони стануть інцидентами
- **Активність — ваш аудиторський слід** — кожна зміна оператором тут фіксується з ім’ям і часом
- **Команди — це односторонні fire-and-forget через мобільний зв’язок** — якщо відповідь не з’являється протягом хвилини, пристрій може бути офлайн; перевірте Останній сигнал в огляді перед повторною спробою
- **Теги та тарифи надходять з двох джерел** — теги на рівні транспортного засобу (панель Теги, редагується в Редагуванні) переважають / доповнюють теги на рівні моделі (тільки для читання тут, налаштовуються в Налаштуваннях транспортного засобу)
- **Карта показує лише останню позначку** — для перегляду маршруту використовуйте _Дії → Переглянути історію маршруту_
