# Теми

Панель керування має три незалежні налаштування зовнішнього вигляду:

- **Режим** — світлий, темний або слідувати за операційною системою
- **Колір** — акцентний колір для кнопок, посилань, бейджів та активних станів
- **Стиль карти** — базові плитки карти (окремий вибір для світлого та темного режимів)

Всі три налаштування знаходяться у **Профілі** внизу — натисніть на свій аватар у верхній панелі, щоб відкрити його.

## Режим (світлий / темний / система)

Перемикайте між трьома режимами:

| Іконка    | Режим   | Поведінка                                                        |
| ---------- | ------ | --------------------------------------------------------------- |
| 🖥️ Монітор | Система | Слідує за налаштуваннями ОС; автоматично змінюється при зміні ОС |
| ☀️ Сонце   | Світлий | Завжди світлий, ігнорує ОС                                      |
| 🌙 Місяць  | Темний  | Завжди темний, ігнорує ОС                                       |

Режим **Система** є за замовчуванням. Якщо ви зміните тему ОС (наприклад, у macOS темний режим за розкладом на заході сонця), панель керування зміниться одразу — без перезавантаження.

## Колір

Акцентний колір використовується для кнопок, посилань, бейджів, обводок фокусу та активного елемента бічної панелі. Доступно дванадцять готових палітр:

| Колір  | Попередній перегляд |
| ------ | ------------------- |
| Чорний | ⚫                  |
| Червоний | 🔴                |
| Рожевий | 🌹                  |
| Рожевий світлий | 🩷           |
| Помаранчевий | 🟠              |
| Жовтий | 🟡                  |
| Зелений | 🟢                  |
| Бірюзовий | 🟢                 |
| Ціан | 🔵                    |
| Синій | 🔵                   |
| Індиго | 🟣                  |
| Фіолетовий | 🟣               |

Виберіть той, який найкраще читається на вашому вибраному режимі (деякі кольори краще виглядають на світлому, інші — на темному).

## Стиль карти

Сторінки з картами (Жива карта, Деталі транспортного засобу, Редактор зон, Маршрут поїздки тощо) використовують базовий стиль карти, який можна вибрати окремо. Панель керування зберігає **дві окремі налаштування стилю карти** — для світлого та темного режимів — щоб карта відповідала інтерфейсу при перемиканні режимів.

- Перемикання режиму (світлий ↔ темний) автоматично змінює стиль карти на вибраний для цього режиму
- Доступні стилі залежать від вашого провайдера карт (MapTiler або альтернативи); зазвичай: Streets, Satellite, Light, Dark, Outdoors

## Де зберігаються налаштування

Всі три налаштування зберігаються у **localStorage** вашого браузера під такими ключами:

| Налаштування      | Ключ у сховищі       |
| ----------------- | --------------------- |
| Режим             | `app-dark-mode`       |
| Колір             | `app-theme`           |
| Стиль карти (світлий) | `app-map-style-light` |
| Стиль карти (темний)  | `app-map-style-dark`  |

Це означає:

- **Для кожного пристрою та браузера окремо** — інший комп’ютер = інші налаштування
- **Не синхронізується** з вашим обліковим записом — колеги, що використовують той самий обліковий запис, бачать свої теми
- **Очищається при "Очистити дані перегляду"** для цього сайту
- **Інкогніто** вікна починаються з налаштувань за замовчуванням

## Поради

- **Починайте з режиму Система** — дозвольте ОС керувати темою; перемикайте на Світлий/Темний лише якщо маєте власні уподобання
- **Підбирайте стиль карти під режим** — Satellite важко читати в темному режимі; краще обрати "Dark" або "Streets Dark"
- **Колір впливає на контрастність** — Жовтий або Ціан на світлому фоні можуть бути важкими для читання; якщо кнопки здаються "тонкими", спробуйте темніший акцент (Червоний, Синій, Індиго)
- **Тема — це не дозвіл** — кожен оператор може обирати свою; колеги не побачать ваших змін
