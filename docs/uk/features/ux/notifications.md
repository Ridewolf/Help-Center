# Сповіщення

Сповіщення відображають події в реальному часі з усієї Панелі керування — нові квитки, IoT-тривоги, активність платежів, проблеми з транспортними засобами, системні повідомлення. Вони надходять через WebSocket-з'єднання, тому оновлення відбуваються миттєво без перезавантаження сторінки.

## Дзвіночок у верхній панелі

**Іконка дзвіночка** у верхній панелі — це ваша точка входу. Червона позначка показує кількість непрочитаних сповіщень.

- Немає позначки → немає непрочитаних
- Числова позначка → стільки непрочитаних
- `99+` → більше 99 непрочитаних

Натисніть на дзвіночок, щоб відкрити **панель Сповіщень** у вигляді бічної панелі справа.

## Всередині панелі

### Заголовок

- **Заголовок** «Сповіщення»
- **Кількість непрочитаних** показується як «N непрочитаних» або «Всі переглянуті», якщо їх немає
- **Швидкий доступ до налаштувань** (іконка шестерні) відкриває глобальну сторінку налаштувань сповіщень

### Перемикач браузерних сповіщень

Якщо ваш браузер підтримує системні сповіщення, під заголовком з’являється перемикач:

- **Вимкнено** → сповіщення відображаються лише всередині Панелі керування
- **Увімкнено** → браузер показує системне сповіщення, коли надходить нове, навіть якщо вкладка у фоновому режимі
- При першому увімкненні браузер запитує дозвіл

Якщо ви раніше відмовили у дозволі, перемикач вимкнено, і з’являється жовте повідомлення з інструкціями, як знову увімкнути його в налаштуваннях сайту браузера.

### Список

Сповіщення відображаються від найновіших до найстаріших. Кожен елемент показує:

- **Іконка категорії** — маленька іконка, пофарбована кольором пріоритету (див. нижче)
- **Заголовок** — короткий заголовок
- **Текст** — опис події
- **Час минув** — наприклад, «2 хв тому»
- **Клікніть** на елемент, щоб перейти на відповідну сторінку (відповідний квиток, транспортний засіб, платіж тощо)

### Порожній стан

Коли немає сповіщень, панель показує дружнє повідомлення та кнопку для відкриття сторінки налаштувань.

## Категорії та пріоритет

Кожне сповіщення має **категорію** (визначає іконку) та **пріоритет** (визначає колір).

### Категорії

| Категорія   | Іконка          | Типові події                                |
| ----------- | --------------- | ------------------------------------------- |
| Підтримка   | 🔔 Дзвіночок    | Нові квитки, відповіді на квитки           |
| Техобслуговування | 🔧 Гаечний ключ | Призначені завдання, тригери автоматизації |
| Транспортний засіб | ✨ Іскри       | Зміни статусу, аномалії                     |
| Клієнт      | 👥 Користувачі  | Нові реєстрації, позначки акаунтів          |
| Платежі     | 💳 Картка       | Транзакції, повернення, події вебхуків      |
| IoT         | 🖥️ Процесор     | Відключення пристрою, низький заряд, тривоги датчиків |
| Система     | 🛎️ Дзвінок      | Системні повідомлення, розгортання          |
| Безпека     | 🛡️ Щит         | Події автентифікації, підозріла активність  |

### Кольори пріоритету

| Пріоритет | Колір  | Використання                                      |
| --------- | ------ | ------------------------------------------------ |
| Критичний | Червоний | Потребує негайних дій (відмова транспортного засобу, тривога безпеки) |
| Високий   | Помаранчевий | Важливо, але не блокує                          |
| Середній  | Янтарний | Рутинна увага                                   |
| Низький   | Синій   | Інформаційний                                   |

## Налаштування (глибша конфігурація)

Панель дзвіночка охоплює базові функції. Для повної конфігурації відкрийте **Налаштування → Сповіщення та тривоги** (або натисніть шестерню в заголовку панелі):

- **Звуки** — виберіть звук для кожного пріоритету або вимкніть звуки
- **Провайдери** — пересилання сповіщень у зовнішні канали (Telegram тощо), налаштовується для кожного чату/отримувача
- **Фільтрування** — які категорії ви хочете отримувати
- **Розклад тиші** — години без звуків (де підтримується)

## Як працює дозвіл

Браузерні сповіщення потребують одноразового дозволу від браузера. Перемикач у панелі викликає запит браузера при першому увімкненні.

- **Дозвіл надано** → перемикач працює; ви отримуєте системні сповіщення, поки Панель керування відкрита в будь-якій вкладці
- **Дозвіл відхилено** → перемикач заблоковано; потрібно змінити дозвіл у налаштуваннях сайту браузера, потім повернутися і увімкнути
- **Не підтримується** → деякі вбудовані браузери та старі версії не можуть показувати системні сповіщення; перемикач приховано

Надання дозволу браузеру не змінює нічого всередині Панелі керування — вбудована панель працює незалежно.

## Поради

- **Використовуйте браузерні сповіщення в одній вкладці** — відкриття Панелі керування в кількох вкладках може множити системні сповіщення
- **Звуки локальні** — вони відтворюються лише у вкладці, де ви підключені; вимикайте їх на спільних комп’ютерах
- **Клік — найшвидший спосіб роботи** — клік на сповіщення миттєво переносить вас на сторінку, що його викликала; швидше за ручну навігацію
- **Відключена Панель керування** — якщо WebSocket-з’єднання переривається, маленька точка статусу на аватарі стає червоною. Сповіщення відновлюються одразу після повернення з’єднання; ви нічого не втрачаєте в цей час
- **Спочатку критичні** — коли надходить багато сповіщень одночасно, спочатку переглядайте кольори: червоні іконки піднімаються вгору вашої черги
