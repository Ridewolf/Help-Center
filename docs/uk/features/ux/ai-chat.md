# AI-чат

Панель керування оснащена **штучним інтелектом**, який розуміє продукт, може читати живі дані з екранів, на яких ви перебуваєте, і — з вашого дозволу — може виконувати дії від вашого імені. Сприймайте його як колегу поруч: задавайте питання, просіть щось зробити або пояснити, що ви бачите.

## Відкриття панелі

Натисніть **іконку іскри** (✨) у верхній панелі. Чат відкриється у бічній панелі праворуч.

- Якщо на іконці світиться маленький значок `*` у вигляді зірочки, ШІ створив нову відповідь з моменту вашого останнього перегляду панелі.
- Панель також відкривається за допомогою `⌘ + K` / `Ctrl + K` на більшості сторінок (де налаштовано цей ярлик).

## Що він може робити

П’ять категорій можливостей, у порядку зростання потужності:

| Можливість       | Приклади                                                                    |
| ---------------- | -------------------------------------------------------------------------- |
| **Пояснювати**   | «Що означає цей статус?», «Як створити тариф?»                            |
| **Шукати інформацію** | «Скільки активних транспортних засобів у зоні A?», «Покажи вчорашні невдалі платежі» |
| **Навігація**    | «Відкрий сторінку поїздок, відфільтровану на сьогодні», «Перейди до транспортного засобу RW-001» |
| **Заповнювати форми** | «Створи новий тег з назвою 'VIP', кольору червоного, і застосуй його до клієнта X» |
| **Змінювати дані** | «Заблокувати транспортний засіб RW-001», «Повернути платіж #12345», «Надіслати пуш всім у зоні A» |

ШІ використовує **ті ж API та ті ж дозволи**, що й ви. Якщо ви не можете виконати дію вручну, ШІ не зможе зробити це від вашого імені. Це межа безпеки — немає режиму «суперкористувача ШІ».

## Всередині панелі

### Заголовок

- **Іскра + заголовок** «AI Chat»
- **Значок імені агента** праворуч (зелена таблетка з блиском) показує, який агент зараз активний — натисніть, щоб відкрити налаштування та переключити агента
- **Значок контексту** з’являється під описом, коли в розмові є повідомлення — показує, наскільки заповнене вікно пам’яті ШІ (наприклад, «12 повідомлень · 35% контексту»)

### Бульбашка живого виконання

Коли ШІ виконує багатокрокову дію (шукає дані, відкриває сторінки, викликає інструменти), з’являється **бульбашка статусу в реальному часі**, що показує кожен крок:

- _Пошук транспортних засобів…_
- _Відкриття /vehicles…_
- _Заповнення форми: Статус = Активний…_
- _Надсилання…_

Ви можете читати, що відбувається в реальному часі, і зупинити процес раніше, якщо він іде не так.

### Розмова

Розмова відбувається як чат: повідомлення користувача праворуч, відповіді ШІ ліворуч, відображаються в markdown (підтримуються списки, таблиці, код, посилання). Запуски інструментів можна розгорнути, щоб побачити точні аргументи та відповіді — корисно для перевірки виконаних дій.

### Введення

- **Введіть повідомлення** і натисніть `Enter` для відправлення; `Shift + Enter` для нового рядка
- Поле введення розширюється під час набору
- Файли / вставлені зображення наразі не підтримуються в чаті

## Підтвердження змін

Для потенційно руйнівних дій (видалення, повернення коштів, зміна статусу, масові операції) ШІ показує **вбудоване підтвердження** замість негайного виконання:

- Короткий опис того, що станеться ("Повернення платежу #12345 — $42.50 Джону Доу")
- Кнопки **Підтвердити** / **Скасувати**
- Нічого не відбувається, доки ви не підтвердите

Уважно читайте опис — це єдина перевірка безпеки між розумінням ШІ та вашими даними.

## Налаштування

Натисніть **значок імені агента** в заголовку, щоб відкрити діалог налаштувань:

- **Вибір агента** — оберіть персоналію агента (різні агенти налаштовані для різних завдань: флот, підтримка, аналітика)
- **Модель** — оберіть базову LLM (якщо доступно кілька)
- **Дозволені інструменти** — вибірково вимикайте інструменти (наприклад, блокувати зміни, якщо потрібен лише Q&A)
- **Історія розмов** — очистити, експортувати

## Вікно контексту

ШІ має обмежену пам’ять поточної розмови. Під час чату контекст заповнюється; ви бачите це у відсотках у значку заголовка.

- **Менше 70%** — достатньо місця
- **70–90%** — майже заповнено; розгляньте початок нової розмови для іншої теми
- **Понад 90%** — старі повідомлення можуть бути узагальнені, щоб звільнити місце; ШІ може забути ранні деталі

Початок нової розмови для нового завдання недорогий і допомагає ШІ залишатися ефективним.

## Поради

- **Будьте конкретні** — «Заблокувати RW-001» краще, ніж «заблокувати той самокат, про який ми говорили»
- **Перевіряйте перед підтвердженням змін** — читайте опис на картці підтвердження. ШІ іноді припускає сутність, яку ви не мали на увазі
- **Запитуйте «що ти можеш тут зробити?»** на будь-якій сторінці — ШІ знає, які інструменти актуальні для поточного екрану
- **Використовуйте для пояснення незнайомих даних** — вставте код статусу або напис на екрані і запитайте «що це означає?»
- **Дозволи все ще діють** — якщо ШІ каже «я не можу цього зробити», це майже завжди проблема з дозволами, а не відсутність функції
- **Чутливі дані** — ставтеся до чату як до екрану колеги. Не вставляйте паролі, номери платіжних карток або будь-які дані, які не хочете бачити в логах
- **Відключення** — якщо ШІ зупиняється посеред виконання, прокрутіть вгору, щоб знайти останню бульбашку живого виконання; вона точно покаже, де зупинилося
