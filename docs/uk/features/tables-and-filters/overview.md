# Таблиці та фільтри

Майже на кожній сторінці списку в Панелі керування (Транспортні засоби, Поїздки, Клієнти, Платежі, Квитки підтримки, Докази паркування, Розмови, Аналітика, Оператори тощо) використовується одна й та сама структура. Коли ви зрозумієте цей шаблон, кожна сторінка списку працюватиме однаково.

## Структура сторінки списку

Зверху вниз:

1. **Заголовок сторінки** — назва, дії на рівні сторінки (наприклад, _Створити_, _Експортувати_)
2. **Панель пошуку** — повнотекстовий пошук за кількома полями
3. **Рядок фільтрів** — випадаючі списки та кнопки для звуження результатів
4. **Активні фільтри у вигляді чіпів** — знімні чіпи, що показують застосовані фільтри
5. **Панель масових дій** — з’являється, коли вибрано один або кілька рядків
6. **Таблиця** — сортувані стовпці, дії для рядків праворуч
7. **Пагінація** — внизу праворуч

## Пошук

Панель пошуку здійснює пошук за найбільш релевантними полями для цієї сторінки (наприклад, мітка, ID, ім'я власника).

- **Введіть текст для пошуку** — результати фільтруються під час введення, з короткою затримкою, щоб не перевантажувати сервер
- **Очистити** — натисніть × у полі вводу або клавішу `Esc`
- Пошук виконується **на стороні сервера** по всьому набору даних, а не лише на поточній сторінці

## Фільтри

Фільтри звужують набір результатів без текстового пошуку. Кожен фільтр — це випадаючий список (одиночний або множинний вибір залежно від поля).

- **Застосування при зміні** — фільтри застосовуються миттєво, без кнопки Застосувати
- **Кілька фільтрів комбінуються через AND** — чим більше додаєте, тим суворіше
- **Активні фільтри у вигляді чіпів** з’являються над таблицею; натисніть × на чіпі, щоб видалити лише цей фільтр
- **Очистити все** — при багатьох застосованих фільтрах поруч із чіпами з’являється кнопка _Очистити все_

Поширені типи фільтрів:

| Тип          | Поведінка                                                      |
| ------------ | -------------------------------------------------------------- |
| Статус       | Випадаючий список з одиночним вибором                         |
| Тип / Модель | Випадаючий список з одиночним вибором                         |
| Теги         | Множинний вибір із чіпами всередині випадаючого списку        |
| Діапазон дат | Календарний віджет (з / по)                                   |
| Діапазон чисел | Поля введення від / до (наприклад, батарея 0–30%)             |
| Пошук за ID  | Вільний текст у вигляді чіпа фільтра (окремо від основного пошуку) |

## Сортування

- **Клік по заголовку стовпця** — сортування за зростанням
- **Повторний клік** — сортування за спаданням
- **Третій клік** — скидання сортування (повернення до стандартного порядку)
- Поруч із назвою стовпця з’являється **стрілка** (↑ / ↓), коли це активне сортування

Не всі стовпці можна сортувати. Сортувальні стовпці мають легкий ефект при наведенні на заголовок; несортувальні — ні.

## Пагінація

Внизу праворуч таблиці:

- **Номери сторінок** — клікніть номер, щоб перейти
- **Стрілки Назад / Вперед** по боках
- **Вибір розміру сторінки** — випадаючий список (зазвичай 10 / 20 / 50 / 100 рядків на сторінку)

Пагінація виконується на стороні сервера. Ваші фільтри та пошук застосовуються до **всього набору даних**, а не лише до поточної сторінки — сторінка 3 відфільтрованих результатів все одно відфільтрована.

## Дії з рядками

У кожного рядка праворуч є **меню з трьома крапками**. Меню відкриває випадаючий список із діями для рядка:

- **Переглянути** — відкрити сторінку деталей
- **Редагувати** — відкрити форму редагування
- **Видалити** — видалити запис (з підтвердженням)
- **Дії, специфічні для сторінки** — наприклад, _Надіслати push_ для клієнтів, _Розблокувати_ для транспортних засобів, _Повернути_ для платежів, _Призначити_ для квитків

Дії, які ви бачите, залежать від ваших **дозволів** — дії, на які у вас немає дозволу, приховані.

## Множинний вибір і масові дії

На сторінках, де це підтримується (Клієнти, Транспортні засоби тощо):

1. **Вибрати рядки** — натисніть чекбокс ліворуч від кожного рядка
2. **Вибрати всі на цій сторінці** — натисніть чекбокс у заголовку стовпця
3. З’являється **панель масових дій** зверху, що показує кількість вибраних і доступні масові дії
4. **Вибрати дію** — вона застосовується до всіх вибраних рядків
5. **Очистити вибір** — × на панелі масових дій або зняти позначку в чекбоксі заголовка

Поширені масові дії:

- Додати або видалити теги
- Надіслати push-повідомлення
- Накласти штраф або поповнити баланс (для клієнтів)
- Змінити статус

## Порожні та стан завантаження

- **Завантаження** — короткочасне відображення скелетонів рядків під час завантаження даних
- **Немає результатів** — дружнє повідомлення ("Немає відповідних результатів") з кнопкою _Очистити фільтри_, якщо фільтри активні
- **Помилка мережі** — стан помилки з кнопкою _Спробувати знову_ (найчастіше при нестабільному з’єднанні)

## Поради

- **Чекайте на затримку** — після введення в пошук зачекайте частку секунди перед кліком — сервер виконує запит один раз, коли ви припиняєте вводити
- **Діліться відфільтрованими видами** — пошук, фільтри, сортування та сторінка відображаються в URL. Скопіюйте URL і надішліть колезі; він побачить точно такий самий вигляд
- **Кнопки назад/вперед браузера** працюють як очікується — вони проходять через ваші зміни фільтрів
- **Комбінуйте пошук і фільтри** — пошук — це вільний текст поверх фільтрів. Використовуйте фільтри для звуження за статусом/типом, а потім шукайте за ім’ям у цій підмножині
- **Збільшуйте розмір сторінки** до 100, коли хочете швидко переглянути багато записів замість переходу між сторінками
- **Дозволи — це тихий фільтр** — якщо колега бачить рядки, яких ви не бачите, це майже завжди різниця в дозволах, а не помилка
