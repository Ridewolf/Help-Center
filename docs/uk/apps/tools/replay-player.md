# Відтворювач Replay

Відтворювач Replay (`/apps/replay-player`) — це судово-технічний інструмент, який анімує GPS-трек транспортного засобу протягом дня або повний маршрут однієї поїздки на карті. Використовуйте його для розслідування інцидентів, перевірки претензій пасажирів, аудиту незвичних маршрутів або просто для спостереження за рухом флоту.

Це не карта в реальному часі (для цього дивіться Панель керування Realtime) — вона відтворює **історичні** координати з бекенду з повним контролем часової шкали.

Необхідний дозвіл: **Replay Player** (`k7m8n9`).

## Макет

Сторінка розділена на ліву бічну панель (селектори + інформаційні панелі) та велику область карти з панеллю керування внизу:

| Регіон       | Ширина | Вміст                                                                 |  
| ------------ | ------ | -------------------------------------------------------------------- |
| **Бічна панель**  | 320 px | Вкладки селекторів (За транспортним засобом / За поїздкою), інформаційна панель для кожного транспортного засобу |
| **Карта**      | flex   | Карта MapLibre з полілінією маршруту, маркерами початку / кінця, курсором у реальному часі |
| **Керування** | низ    | Відтворення / пауза, випадаючий список швидкості, повзунок часової шкали, відображення пройденого / загального часу |

## Керування (бічна панель)

Бічна панель визначає, **що** відтворюється. Вона має дві вкладки, які переключають модель вибору.

### Вкладка За транспортним засобом

Відтворення повного треку одного або кількох транспортних засобів за день (або будь-яку обрану дату):

- **Транспортні засоби** — мультивибір до **5** транспортних засобів. Введіть для пошуку, фільтруйте список за тегами з випадаючого меню нижче.
- **Дата** — календар; за замовчуванням сьогодні. Відтворення охоплює весь день у локальному часі для обраної дати.
- **Теги** — обмежує список транспортних засобів тими, що мають будь-який із вибраних тегів. Корисно при великому флоті.
- **Завантажити** — завантажує координати дня для всіх вибраних транспортних засобів паралельно та відображає їх.

При завантаженні кількох транспортних засобів кожен отримує власну полілінію (фарбовану за швидкістю) і власний рухомий маркер на карті, а також окрему інформаційну картку в бічній панелі.

### Вкладка За поїздкою

Відтворення координат однієї поїздки замість повного дня:

- **Транспортний засіб** (необов’язково) — одиночний вибір; звужує список поїздок нижче
- **Дата** (необов’язково) — календар; фільтрує поїздки за одним днем. Очистіть, щоб побачити всі дати.
- **Теги** (необов’язково) — фільтрує список поїздок за тегами транспортних засобів
- **Список поїздок** — прокручуваний, пагінований список поїздок, що відповідають фільтрам. Кожна картка показує час початку, статус, тривалість і відстань.

Клік по картці поїздки автоматично завантажує її координати — окрема кнопка Завантажити не потрібна.

## Часова шкала (нижня панель)

Панель керування розташована внизу карти:

| Керування          | Що робить                                                                                 |
| ------------------ | ----------------------------------------------------------------------------------------- |
| **Відтворити / Пауза** | Запустити або призупинити анімацію                                                      |
| **Випадаючий список швидкості** | Вибрати множник швидкості відтворення (див. нижче)                                |
| **Повзунок часової шкали** | Перемотати до будь-якої точки відтворення; карта оновлюється миттєво                   |
| **Пройдено / Загалом** | `мм:сс` (або `г:мм:сс`, якщо довше за годину) — пройдений час відтворення і загальна тривалість |

При завантаженні кількох транспортних засобів повзунок охоплює **глобальний** інтервал від початку до кінця об’єднання всіх треків. Треки, які ще не почалися на поточний час, просто не мають маркера на карті.

## Карта

Карта використовує стиль карти вашої поточної теми (див. [Themes](../../features/ux/themes.md)). Для кожного завантаженого треку:

- Малюється **полілінія**, пофарбована за швидкістю — зелена для повільної, помаранчева для середньої, червона для швидкої
- На першій точці ставиться **зелений маркер початку**
- На останній точці ставиться **червоний маркер кінця**
- **Маркери транспортних засобів** рухаються вздовж лінії під час відтворення часової шкали

Керування картою розташоване у верхньому правому куті (вертикальний стек):

| Кнопка            | Що робить                                                                                 |
| ----------------- | ----------------------------------------------------------------------------------------- |
| **Збільшити / Зменшити** | Стандартне масштабування карти                                                        |
| **Скинути орієнтацію** | Повертає карту до півночі вгору, якщо ви її нахиляли або обертали                         |
| **Підігнати межі**    | Масштабує / панорамувує, щоб повністю показати маршрут(и) — корисно, якщо камера від’їхала під час довгого відтворення |
| **Повноекранний режим** | Розгортає карту на весь екран; панель керування залишається внизу                       |

## Швидкість відтворення

Випадаючий список швидкості пропонує вісім пресетів: **1x, 2x, 4x, 8x, 16x, 32x, 64x, 128x**.

- **1x** відтворює Replay у реальному часі — 20-хвилинна поїздка відтворюється 20 хвилин
- **128x** стискає 8-годинний день приблизно до 4 хвилин
- Швидкість можна змінювати під час відтворення; анімація плавно продовжується з поточного місця

Використовуйте вищі швидкості (32x / 64x / 128x) для відтворення повноденних треків транспортних засобів, нижчі швидкості (1x / 2x / 4x) — для судово-технічного аналізу поїздок, коли потрібно бачити точне місцезнаходження пасажира в кожну секунду.

## Інформаційна панель для кожного транспортного засобу

Кожен завантажений транспортний засіб отримує невелику картку в бічній панелі, яка оновлюється в реальному часі під час відтворення:

| Поле            | Що показує                                                                |
| --------------- | ------------------------------------------------------------------------- |
| **Швидкість**   | Поточна інтерпольована швидкість у км/год (кольорове кодування: зелений / жовтий / червоний) |
| **Координати**  | Поточні широта / довгота з точністю до 6 знаків після коми                |
| **Відстань**    | Накопичена пройдена відстань у км (за формулою гаверсин, обчислюється на клієнті) |
| **Точка**       | Поточний індекс точки / загальна кількість точок (наскільки пройдено через набір даних) |

Коли відтворення не почалося або дані не завантажені, на картці показуються тире.

## Порожні / стан завантаження

- **Немає вибору** — у зоні карти показується іконка відтворення та підказка «Виберіть транспортний засіб і дату або поїздку, щоб почати повтор»
- **Завантаження** — по центру карти накладається спінер із написом «Завантаження координат...»
- **Немає даних** — якщо обрана дата / поїздка не має координат, з’являється тост-попередження «Дані координат для цього вибору не знайдено», а карта залишається порожньою
- **Помилка завантаження частини карти** — карта завантажується частинами (~1 МБ); якщо завантаження не вдалось (застаріле розгортання, офлайн), з’явиться тост з помилкою і пропозицією оновити сторінку

## Типові сценарії

- **Розслідувати скаргу** — переключіться на За поїздкою, знайдіть поїздку користувача, клацніть її → перегляньте маршрут у 4 рази швидше, щоб побачити, куди він фактично їхав, а не куди заявляв
- **Аудит «зниклого» транспортного засобу** — За транспортним засобом, виберіть одиницю, встановіть сьогоднішню дату → відтворюйте у 128 разів швидше, щоб побачити весь день за секунди; остання позиція маркера — де він зараз знаходиться
- **Порівняти два транспортні засоби** — За транспортним засобом, виберіть дві одиниці, які рухалися схожими маршрутами в той самий день → обидві лінії та маркери відображаються разом для візуального порівняння
- **Визначити час події** — завантажте поїздку → перетягніть повзунок до позначки часу з квитка / журналу → прочитайте координати з інформаційної панелі
- **Виявити перевищення швидкості** — завантажте день транспортного засобу → шукайте **червоні** сегменти лінії → перетягніть повзунок до цієї ділянки для підтвердження

## Поради

- **Максимум 5 транспортних засобів** одночасно — інтерфейс обмежує мультивибір, щоб зберегти продуктивність карти. Для більшої кількості робіть окремі сесії.
- **Використовуйте Fit Bounds після тривалого відтворення** — відтворення слідує за маркером, що зсуває камеру; один клік на **Fit Bounds** перефокусовує весь маршрут.
- **Кольори швидкості не залежать від тарифу** — це лише візуальні підказки на основі зафіксованої GPS-швидкості (>15 км/год жовтий, >30 км/год червоний). Порівнюйте з _режимом швидкості_ транспортного засобу на сторінці деталей для контексту.
- **Повзунок працює в обох напрямках** — перетягуйте назад для перемотування. Поєднуйте з низькою швидкістю, щоб крокувати складними сегментами.
- **Стан у URL не зберігається** — вибори не зберігаються в URL, тому неможливо поділитися глибоким посиланням. Зберігайте скріншоти, якщо потрібно закріпити момент.
- **Поєднуйте з [Ride Detail](../../operations/trips/ride-detail.md)** — деталі поїздки мають статичну карту маршруту з подіями на часовій шкалі; плеєр повтору додає часовий вимір зверху.
