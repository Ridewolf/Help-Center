# Пакетний режим — Черга кількох транспортних засобів

Пакетний режим (`/batch`) збирає кілька транспортних засобів в одну чергу, щоб ви могли бачити їх поруч і працювати з ними без повторного пошуку кожного. Доступний з головного екрану або за посиланням сканування в порожньому стані [карти флоту](../fleet/fleet-map.md).

**Прочитайте це спочатку:** пакетний режим — це список завдань, а не інструмент масових команд. Кнопки групових дій внизу екрана **наразі недоступні в додатку**. Ви дієте з кожним транспортним засобом на його власній [сторінці транспортного засобу](../fleet/vehicle-controls.md).

## Додавання транспортних засобів

1. Відкрийте пакетний режим.
2. Відскануйте QR-код транспортного засобу — сканер той самий, що й на карті флоту, тому застосовуються ті ж правила пошуку (мітка, VIN або IMEI).
3. Кожне успішне сканування додає транспортний засіб у чергу в стані **очікування**.
4. Повторіть для кожного транспортного засобу, який хочете додати до списку.

Довгі черги залишаються чуйними, тому немає практичної причини тримати список коротким, окрім вашого власного плану зміни.

## Читання черги

Кожен рядок показує:

| Елемент              | Як читати                                                                              |
| -------------------- | -------------------------------------------------------------------------------------- |
| **Мітка**            | Код транспортного засобу                                                               |
| **Індикатор батареї**| Червоний при 10% або менше, оранжевий при 20% або менше, янтарний при 40% або менше, зелений понад 40% |
| **Батарея трекера**  | Заряд трекера                                                                           |
| **Іконка підключення**| Чи трекер онлайн чи офлайн                                                             |
| **Статус**           | Поточний статус транспортного засобу                                                  |
| **Стан рядка**       | очікування, в роботі, ок, або помилка                                                  |

Рядок з помилкою показує повідомлення про помилку замість телеметрії, щоб ви могли побачити, що пішло не так, не виходячи з черги.

**Натискання на будь-який рядок відкриває сторінку цього транспортного засобу** — саме так ви фактично дієте з транспортним засобом: додаєте їх у чергу, а потім працюєте з ними по одному.

## Видалення транспортних засобів

- **Іконка кошика на рядку** видаляє цей транспортний засіб з черги. Нічого не надсилає транспортному засобу — видалення впливає лише на ваш список.
- **Іконка кошика в заголовку** очищує всю чергу після підтвердження. Вимкнена, поки пакет позначений як в роботі.

## Групові дії

П’ять кнопок розташовані внизу екрана: шестерня налаштувань, розблокування, дзвінок, блискавка та шари. **Ці групові дії наразі недоступні в додатку.** Натискання не надсилає нічого жодному транспортному засобу.

Щоб розблокувати, подати сигнал, замінити батарею або надіслати команду трекеру, відкрийте транспортний засіб із черги та використовуйте елементи керування на [сторінці транспортного засобу](../fleet/vehicle-controls.md):

- Блокування та розблокування — **Режим поїздки**
- Звук локатора — **Сигнал**
- [Заміна батареї](battery-swap.md) — послідовність заміни з таймером
- Команди постачальника — аркуш **Команди**

## Поширені проблеми

| Симптом                                        | Що це означає                                                                       |
| ---------------------------------------------- | ----------------------------------------------------------------------------------- |
| Натискання групової дії ніби нічого не робить  | Вірно — групові дії наразі недоступні. Працюйте з кожним транспортним засобом на його сторінці |
| Кнопка очистити все сірого кольору             | Пакет позначений як в роботі                                                        |
| Рядок не показує батарею або підключення       | Ці значення невідомі для цього транспортного засобу — не нуль                      |
| Відсканований транспортний засіб не з’явився  | Код не розпізнано. Правила ті ж, що й на карті флоту: мітка, VIN або IMEI          |

## Поради

- **Створюйте чергу на початку маршруту.** Одне сканування десяти транспортних засобів у дворі краще, ніж пошук їх по одному пізніше.
- **Використовуйте кольори батареї для впорядкування роботи** — спочатку червоні, це ті, про які наступними повідомить користувач.
- **Черга належить лише вам**, тому видалення рядка ніколи нічого не змінює для колег або транспортного засобу.
- **Для операцій на рівні всього флоту використовуйте Панель керування.** Масові зміни статусу, масові теги та масові команди доступні в [списку транспортних засобів Панелі керування](../../operations/fleet/vehicles.md#масові-дії).
