# Ласкаво просимо до Панелі керування Ridewolf

Панель керування Ridewolf — це центр управління флотом спільного користування. Незалежно від того, чи керуєте ви самокатами, велосипедами чи будь-яким іншим типом транспортних засобів, тут ви можете відстежувати активність у реальному часі, керувати клієнтами, обробляти підтримку та аналізувати продуктивність.

## Для кого ця панель керування

Панель керування створена для **операторів** — співробітників, які працюють з флотом щодня:

- **Менеджери флоту** — транспортні засоби, зони, тарифи
- **Агенти підтримки** — квитки, розмови, докази паркування
- **Аналітики** — метрики, звіти, продуктивність
- **Адміністратори** — оператори, ролі, системні налаштування

Те, що бачить кожен оператор, залежить від його **ролі та дозволів**. Ваш вигляд може бути обмежений порівняно з скріншотами в цьому посібнику, якщо деякі модулі заборонені для вашої ролі.

## Основні поняття

Панель керування організована навколо кількох понять, з якими ви зустрінетесь повсюдно:

| Поняття       | Що це означає                                                                 |
| -------------- | ----------------------------------------------------------------------------- |
| **Транспортний засіб** | Фізичний одиниця у флоті (самокат, велосипед тощо) — має GPS, батарею, статус |
| **Поїздка**    | Поїздка клієнта на транспортному засобі — має час початку/закінчення, маршрут, вартість |
| **Клієнт**    | Зареєстрований користувач, який може орендувати транспортні засоби             |
| **Платіж**    | Грошові операції, пов’язані з поїздками, поповненнями або поверненнями         |
| **Зона**      | Географічна область, де працюють транспортні засоби (або де їх обмежено)      |
| **Тариф**    | Правила ціноутворення, що визначають вартість поїздок                          |
| **Тег**       | Позначка, прикріплена до клієнтів або транспортних засобів для групування та фільтрації |
| **Квиток**   | Запит у службу підтримки клієнтів                                              |
| **Доказ паркування** | Фото, яке клієнт надсилає для підтвердження правильного паркування           |

## Основна навігація

### Бічна панель (зліва)

Бічна панель — це основна навігація. Групи розгортаються, щоб показати підсторінки — наприклад, **Підтримка** розгортається у Квитки, Докази паркування та Розмови.

### Верхня панель

Верхня панель відображається на кожній сторінці і містить:

- **Хлібні крихти** — шлях назад через ієрархію (наприклад, Головна → Транспортні засоби → RW-001)
- **AI Chat** (іконка іскри) — помічник, який може відповідати на питання про панель керування
- **Допомога** (іконка знаку питання) — відкриває цю базу знань, контекстно до поточної сторінки
- **Сповіщення** (іконка дзвінка) — останні системні події та тривоги
- **Профіль** (аватар) — налаштування, зміна пароля, вихід, керування темою

### Таблиці

Більшість сторінок зі списками (транспортні засоби, поїздки, клієнти тощо) мають однаковий макет:

1. **Панель пошуку** зверху для повнотекстового пошуку
2. **Фільтри у вигляді кнопок** нижче для звуження за статусом, типом тощо
3. **Стовпці з можливістю сортування** — натисніть на заголовок стовпця для сортування
4. **Пагінація** внизу
5. **Дії рядка** — меню з трьома крапками в кожному рядку для швидких дій

## З чого почати

Якщо ви вперше у панелі керування, рекомендуємо:

1. **Оновити свій профіль** — аватар → Профіль, заповнити ім'я, фото, контактні дані
2. **Оглянути флот** — відкрити **Транспортні засоби**, щоб побачити, що зараз активне
3. **Перевірити сьогоднішні поїздки** — відкрити **Поїздки** з фільтром на сьогодні, щоб спостерігати активність у реальному часі
4. **Відкрити головну панель керування** — головна сторінка `/dashboard` підсумовує щоденні ключові показники
5. **Прочитати цю базу знань** — відкрийте відповідний розділ перед виконанням першої дії в кожному модулі

## Отримання допомоги

Існує три способи отримати допомогу всередині панелі керування:

- **Іконка допомоги (?)** у верхній панелі — відкриває бічну панель з документацією, що стосується поточної сторінки
- **Допомога** у бічній панелі (іконка книги) — повна, пошукова база знань
- **Форми зворотного зв’язку / пропозицій** на головній сторінці Допомоги — пишіть безпосередньо команді

## Наступні кроки

Коли ви освоїте основи:

- Перегляньте **Функції Панелі керування**, щоб дізнатися про гарячі клавіші, хитрощі фільтрів і теми
- Перегляньте **Операції** для практичних посібників з транспортних засобів, поїздок і клієнтів
- Перегляньте **Налаштування**, якщо потрібно налаштувати операторів, зони або тарифи
