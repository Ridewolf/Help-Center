# Welkom bij het Ridewolf Dashboard

Het Ridewolf Dashboard is het controlecentrum voor het beheren van een gedeelde mobiliteitsvloot. Of u nu scooters, fietsen of een ander type voertuig beheert, hier houdt u de realtime activiteit in de gaten, beheert u klanten, behandelt u ondersteuning en analyseert u de prestaties.

## Voor wie is dit dashboard bedoeld

Het dashboard is gebouwd voor **operators** — medewerkers die dagelijks met de vloot werken:

- **Vlootmanagers** — voertuigen, zones, tarieven
- **Supportmedewerkers** — tickets, gesprekken, parkeerbewijzen
- **Analisten** — statistieken, rapporten, prestaties
- **Beheerders** — operators, rollen, systeeminstellingen

Wat elke operator ziet, hangt af van hun **rol en rechten**. Uw weergave kan beperkter zijn dan de schermafbeeldingen in deze gids als sommige modules voor uw rol beperkt zijn.

## Kernconcepten

Het dashboard is georganiseerd rond een paar concepten die u overal tegenkomt:

| Concept        | Wat het betekent                                                              |
| -------------- | ----------------------------------------------------------------------------- |
| **Voertuig**   | Een fysiek onderdeel van de vloot (scooter, fiets, enz.) — heeft GPS, batterij, status |
| **Rit**        | Een rit gemaakt door een klant op een voertuig — heeft start/eindtijd, route, kosten |
| **Klant**      | Een geregistreerde klant die voertuigen kan huren                            |
| **Betaling**   | Geldtransacties gekoppeld aan ritten, opwaarderingen of terugbetalingen      |
| **Zone**       | Een geografisch gebied waar voertuigen opereren (of waar ze beperkt zijn)    |
| **Tarief**     | Prijsregels die bepalen hoeveel ritten kosten                               |
| **Label**      | Een label gekoppeld aan klanten of voertuigen voor groepering en filtering  |
| **Ticket**     | Een klantenondersteuningsverzoek                                            |
| **Parkeerbewijs** | Een foto die een klant indient om correct parkeren te bevestigen           |

## Basisnavigatie

### Zijbalk (links)

De zijbalk is de primaire navigatie. Groepen klappen uit om subpagina's te tonen — bijvoorbeeld, **Ondersteuning** klapt uit naar Tickets, Parkeerbewijzen en Gesprekken.

### Bovenbalk

De bovenbalk verschijnt op elke pagina en bevat:

- **Broodkruimel** — het pad terug door de hiërarchie (bijv. Start → Voertuigen → RW-001)
- **AI Chat** (sprankel-icoon) — een assistent die vragen over het dashboard kan beantwoorden
- **Help** (vraagteken-icoon) — opent deze kennisbank, contextueel voor de huidige pagina
- **Meldingen** (bel-icoon) — recente systeemgebeurtenissen en meldingen
- **Profiel** (avatar) — instellingen, wachtwoord wijzigen, afmelden, thema-instellingen

### Tabellen

De meeste lijstpagina's (voertuigen, ritten, klanten, enz.) volgen dezelfde indeling:

1. **Zoekbalk** bovenaan voor volledige tekstzoekopdrachten
2. **Filterknoppen** eronder om te verfijnen op status, type, enz.
3. **Sorteerbare kolommen** — klik op een kolomkop om te sorteren
4. **Paginering** onderaan
5. **Rijacties** — een menu met drie puntjes op elke rij voor snelle acties

## Wat eerst te doen

Als dit uw eerste keer in het dashboard is, raden we aan:

1. **Werk uw profiel bij** — avatar → Profiel, vul naam, foto, contactgegevens in
2. **Bekijk de vloot** — open **Voertuigen** om te zien wat er momenteel actief is
3. **Controleer de ritten van vandaag** — open **Ritten** gefilterd op vandaag om realtime activiteit te volgen
4. **Open het startdashboard** — de hoofdpagina `/dashboard` geeft een overzicht van dagelijkse KPI's
5. **Lees deze kennisbank** — open de relevante sectie voordat u uw eerste actie in elke module uitvoert

## Hulp krijgen

Er zijn drie manieren om hulp te krijgen vanuit het dashboard:

- **Help-icoon (?)** in de bovenbalk — opent een zijpaneel met documentatie relevant voor de pagina waar u bent
- **Help** in de zijbalk (boek-icoon) — de volledige, doorzoekbare kennisbank
- **Feedback-/suggestieformulieren** op de Help-startpagina — schrijf direct naar het team
