# הפרופיל שלך

**פרופיל** הוא _החשבון_ שלך בתוך Ridewolf — המפעיל שנכנס כרגע. כאן תוכל לשנות את שמך, תמונתך, סיסמתך, ערכת הנושא, צלילי ההתראות, ולסקור היכן אתה מחובר. אם חשבון המפעיל שלך מקושר גם לחשבון לקוח באפליקציות הרוכבים, תוכל לעבור לתצוגת לקוח של אותו חשבון.

ארבעה מסלולים חולקים מאמר זה, כולם נגישים מהאווטאר בסרגל העליון:

| מסלול               | מה זה                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| `/profile`          | מרכז — מפנה אותך אוטומטית לתצוגת מפעיל או לקוח בהתאם למה שיש בחשבונך              |
| `/profile/operator` | תצוגת מפעיל של עצמך (ברירת מחדל לעובדים)                                                |
| `/profile/customer` | תצוגת לקוח (רק אם חשבונך מקושר גם ללקוח רוכב)                        |
| `/profile/legacy`   | תצוגת עמוד יחיד ישנה — אותם נתונים מוצגים כטופס ארוך אחד (גיבוי לתצוגות המעוצבות מחדש) |

זו תצוגת **שירות עצמי**. לניהול _מפעילים אחרים_ (חברי הצוות שלך), השתמש ב-[Operators](../../settings/access/operators.md) במקום זאת.

אין שער הרשאות — כל משתמש מחובר יכול לפתוח את הפרופיל שלו.

## איך `/profile` מחליט לאן להפנות אותך

לחיצה על `/profile` ישירות לא תוביל לדף — היא מפנה מיד:

1. קורא את `lastPersona` מ-localStorage בדפדפן שלך (הוגדר בפעם האחרונה שהשתמשת במתג הפרסונה בכותרת הראשית)
2. אם `lastPersona = customer` וחשבון שלך מקושר ללקוח → `/profile/customer`
3. אם `lastPersona = operator` → `/profile/operator`
4. אחרת: מפעיל אם יש לך חשבון מפעיל, לקוח רק אם אין
5. ברירת מחדל: `/profile/operator`

אתה רואה סמל סיבוב עם "מופנה..." לרגע הקצר בין הנחיתה להפניה.

## הכותרת הראשית (משותפת לתצוגות מפעיל + לקוח)

כותרת דביקה יושבת בראש `/profile/operator` ו-`/profile/customer`. היא מציגה:

- **אווטאר** עם שכבת מצלמה בהעברה — לחץ לפתיחת דו-שיח **העלאת אווטאר**
- **שם** (לחץ להעתקה) ו-**אימייל** (לחץ להעתקה) — לשניהם יש טיפים להעתקה ללוח
- **תגים** — הסטטוס שלך (`פעיל` / `לא פעיל`), `מאומת`, ו-`לקוח` אם אתה בתצוגת לקוח
- **מדדי KPI מהירים** — ארבע אריחים קטנים, התוכן תלוי בפרסונה (ראה למטה)
- **מתג פרסונה** — שני כפתורים (`מפעיל` / `לקוח`). כפתור הלקוח מושבת עם טיפים כאשר לחשבון שלך אין לקוח מקושר
- **פעולות** — כפתור `ערוך`, בתפריט שלוש נקודות עם _העתק מזהה משתמש_, _העתק אימייל_, _פתח כ-JSON_ (מייצא את רשומת המשתמש שלך בכרטיסייה חדשה), ו- _התנתק_

החלפת פרסונה דרך כפתורים אלה שומרת את הבחירה שלך ב-`lastPersona` ב-localStorage כך שבפעם הבאה `/profile` ידע לאן להפנות אותך.

## `/profile/operator` — שלוש לשוניות

תצוגת המפעיל מארגנת הכל לשלוש לשוניות. ה-hash ב-URL (`#overview`, `#security`, `#preferences`) משקף את הלשונית הפעילה, כך שתוכל לקשר ישירות ללשונית.

### לשונית סקירה כללית

שתי כרטיסיות זו לצד זו: **ארגון ותפקיד** (משמאל) ו-**פעילות** (מימין).

כרטיסיית **ארגון ותפקיד** מציגה, בטופס לקריאה בלבד:

| שדה          | מקור                                                                |
| -------------- | --------------------------------------------------------------------- |
| **מזהה משתמש**    | מזהה המפעיל שלך — מקוצר ל-8 תווים עם אייקון העתקה ללוח |
| **צוותים**      | תגיות שהוקצו לך (מופיעות מהמטמון של התגיות)             |
| **אימייל**      | אימייל החשבון שלך                                                    |
| **סטטוס**     | תג `פעיל` / `לא פעיל`                                           |
| **תפקיד**       | תג תפקיד, עם ספירת הרשאות בסוגריים                     |
| **מחלקה** | מפרופיל הארגון שלך                                        |
| **משרה**   | מפרופיל הארגון שלך                                        |
| **מיקום**   | עיר ואזור זמן, אם הוגדר                                           |
| **2FA**        | `מופעל` (ירוק) או `מנוטרל` (אפור) — מוצג רק כשהוא ידוע        |

כרטיס זה הוא **לקריאה בלבד** בתצוגת מפעיל. לשינוי כל אחד מהשדות האלה (תפקיד, מחלקה, משרה, תגיות), מנהל צריך לערוך את הרשומה שלך מ-[Operators](../../settings/access/operators.md) — אינך יכול לקדם את עצמך.

כרטיסיית **פעילות** מציגה את חמש הפעולות האחרונות שלך, שנמשכו מ-`/activity/operator/{id}`:

- נקודה צבעונית (ירוק = נוצר, כחול = עודכן, כתום = נמחק, ראשי = אחר)
- תג קטגוריה ("נוצר" / "עודכן" / "נמחק" / "אבטחה")
- תיאור ("עודכן רכב #ABC", וכו')
- זמן יחסי ("לפני שעתיים")
- מבצע — בדרך כלל "על ידך", "על ידי המערכת" לשינויים אוטומטיים

אם פיד הפעילות ריק, הכרטיס מציג את **מפגשי ההתחברות האחרונים** שלך כאירועי אבטחה. כפתור "הצג הכל" בתחתית עובר ללשונית אבטחה שבה רשימת המפגשים המלאה.

מדדי ה-KPI מעל הכרטיסיות מציגים את `{n} actions · {m} changes in 30d`.

### לשונית אבטחה

שתי כרטיסיות מונחות: **ניהול סיסמה** ו-**מפגשים פעילים**.

**ניהול סיסמה** מאפשר לך לשנות את הסיסמה שלך דרך דו-שיח. פתח אותו דרך כפתור _שנה_ ליד "סיסמה נוכחית".

לדו-שיח שלושה שדות:

| שדה                | אימות                                          |
| -------------------- | --------------------------------------------------- |
| סיסמה נוכחית     | חובה; מינימום 8 תווים                           |
| סיסמה חדשה         | חובה; מינימום 8 תווים; חייבת להיות שונה מהנוכחית |
| אשר סיסמה חדשה | חובה; מינימום 8 תווים; חייבת להיות זהה לסיסמה החדשה  |

כפתור השליחה נשאר מושבת עד שכל שלושת השדות תקינים. שגיאות שדה מופיעות באדום מתחת לכל שדה בזמן ההקלדה. בהצלחה, תראה הודעת טוסט והדו-שיח ייסגר; הטופס ינוקה.

מתחת למדור הסיסמה, טבלת **היסטוריית סיסמאות** קטנה מציגה את שלושת אירועי השינוי האחרונים עם תאריך, פעולה וסיבה. (זהו כרגע מציין מקום סטטי — השרת עדיין לא מספק נקודת קצה להיסטוריית סיסמאות.)

**הפעלות פעילות** מוצגות על ידי מנהל ההפעלות המשותף. ההפעלות **מקובצות לפי טביעת אצבע של המכשיר** (דפדפן + מערכת הפעלה + סוג מכשיר + יצרן + דגם), כך שכמה לשוניות באותו מחשב נייד מתמזגות לקבוצה אחת.

כותרת כל קבוצה מציגה:

- אייקון מכשיר (מסך / סמארטפון / מחשב נייד בהתאם ל-`deviceType`)
- תווית מכשיר — יצרן + דגם, או מערכת הפעלה + גרסה, או סוג מכשיר
- תווית דפדפן
- תג סטטוס: `active` (פעילות אחרונה מתחת לשעה, ירוק), `inactive` (מתחת ל-24 שעות, אפור), `old` (מעל 24 שעות, עמום), או `מכשיר זה` (הפעלה נוכחית, מסגרת כחולה)
- זמן הפעילות האחרון (יחסי)
- ספירת הפעלות בקבוצה

לחץ על כותרת קבוצה כדי להרחיב אותה ולראות כל הפעלה בנפרד, כל אחת עם מדינה וכתובת IP לפי מיקום, תאריך כניסה, ואייקון פח אשפה לביטול ההפעלה. ניתן גם לבטל את כל הקבוצה באמצעות כפתור "התנתק מהמכשיר הזה" בתחתית הרשימה המורחבת (ההפעלה הנוכחית נשמרת תמיד).

כפתור **התנתק מהפעלות אחרות** בראש העמוד מבטל _את כל_ ההפעלות האחרות בבת אחת. המכשיר הנוכחי לעולם לא נוגע בו. הספירה כוללת את כל ההפעלות שאינן נוכחיות בכל המכשירים.

### לשונית העדפות

שתי כרטיסיות: **ערכת נושא וסגנון מפה** ו-**צלילי התראות**.

הכרטיס הראשון משלב את בורר ערכת הנושא והסגנון המשותף — אותם ווידג'טים כמו בגליון הפרופיל הצף. ראה [Themes](../../features/ux/themes.md) לפירוט מלא של מצבים, צבעי הדגשה וסגנונות מפה.

הכרטיס השני משלב את הגדרות צלילי ההתראות — צלילים לפי סוג התראה, צליל לכל התראה, ומחווני עוצמה נפרדים להודעות ולתראות. ראה [Notifications](../../features/ux/notifications.md) לבורר המלא.

כל מה שבכרטיסיה זו נכתב ל-**localStorage** של הדפדפן שלך, לא לשרת. משמעות הדבר שהעדפות הן למכשיר ולדפדפן ספציפיים — הן לא עוקבות אחריך כשאתה נכנס ממכשיר אחר.

## `/profile/customer` — תצוגת צד לקוח

אם חשבון המפעיל שלך **גם** מקושר לחשבון רוכב (לקוח) באותו התקנת Ridewolf, תוכל להחליף פרסונה ולראות איך אתה נראה מצד הלקוח. כפתור הפרסונה בכותרת הראשית מוביל לכאן.

### כשאין לך חשבון לקוח

אתה רואה כרטיס מצב ריק מקווקו עם:

- אייקון וכותרת "קשר את פרופיל הלקוח שלך"
- תיאור
- שני כפתורים — **צור חשבון לקוח** ו-**קשר קיים** (שניהם מציגים כרגע הודעות "בקרוב"; אין שרת עדיין)
- התראת אימות
- קישור "המשך כמפעיל" חזרה ל-`/profile/operator`

### כשיש לך חשבון לקוח

שתי לשוניות: **סקירה כללית** ו-**נסיעות**.

מדדי מפתח בכותרת הראשית משתנים למספרים רלוונטיים ללקוח: **יתרה** (מטבע מעוצב), **סה"כ נסיעות**, **דירוג** (ספרה עשרונית אחת), **בונוס** (נקודות).

לשונית **סקירה כללית** מציגה:

- כרטיס **ארנק** — יתרה נוכחית, נקודות בונוס אופציונליות (רק אם > 0), ושיטת תשלום מקושרת (מותג + 4 ספרות אחרונות + חודש/שנה לפקיעה + סוג ספק) אם קיימת
- כרטיס **סטטיסטיקות נסיעות** — שלושה אריחים: סה"כ נסיעות, דירוג עם כוכב (ותווית משנה "{n} דירגו"), נקודות בונוס
- סרגל צד **מידע על החשבון** — מזהה לקוח (מונוספייס, מקוצר), ספק, נוצר (יחסי), פעיל לאחרונה (יחסי, אם קיים), נסיעה אחרונה (יחסי, אם קיים)
- כרטיס **מכשירים** — מכשירי הלקוח הרשומים שלך (iOS / Android / Web) מוצגים על ידי `ClientDevicesList` המשותף
- קישורים מהירים ל-**בטיחות ותמיכה** — שאלות נפוצות, צור קשר עם התמיכה, דווח על בעיה (כפתורי מציין מקום)

לשונית **נסיעות** מציגה את 20 הנסיעות האחרונות שלך (החדשות ביותר ראשונות), עם:

- מזהה נסיעה (מונוספייס) וזמן יצירה (יחסי)
- תג סטטוס (`completed` מלא, `active` משני, אחרים מסגרת)
- מרחק (ק"מ), משך (דקות או `Hh Mm`), תווית רכב
- מחיר (מטבע מעוצב)
- שורת כוכבים לדירוג, אם קיים

היא משתמשת במיכל גלילה עם גובה קבוע של 500 פיקסלים ומצב טעינה עם 4 שלדים. מצב ריק מציג אייקון מפה ו"אין נסיעות עדיין".

**אין כאן טופס עריכה** — זהו מראה לקריאה בלבד של מה שמוצג באפליקציית Rider שלך. כפתור העריכה בכותרת הראשית מציג כרגע הודעת "בקרוב".

## `/profile/legacy` — דף יחיד חלופי

`/profile/legacy` הוא **פרופיל דף יחיד ישן יותר**, שמור כגיבוי וקישור ישיר. הוא מכיל כמעט הכל בדף גלילה אחד במקום לשוניות:

- כרטיס כותרת פרופיל עם אווטאר, שם, אימייל, תג סטטוס, וכפתורי ערוך / שמור / בטל
- כרטיס **מידע אישי** — שם פרטי, שם משפחה ניתנים לעריכה (שדות טקסט בעת עריכה); אימייל לקריאה בלבד וטלפון ניתן לעריכה
- כרטיס **מידע על החשבון** — מזהה משתמש לקריאה בלבד (מקוצר + העתקה), אימייל, סטטוס (ערך גולמי)
- כרטיס **מראה** — בורר ערכת נושא ובורר סגנון מפה (אותם ווידג'טים כמו בלשונית העדפות)
- כרטיס **התראות וצלילים**
- כרטיס **אבטחה** — שורת סיסמה עם כפתור שינוי (כרגע לא פותח את הדיאלוג)
- תחתית המציגה את גרסת האפליקציה (7 התווים הראשונים של `CF_PAGES_COMMIT_SHA`, או `DEVELOPMENT_KIT` מקומית)

שני אזהרות חשובות:

- פעולה **שמור** מציגה כרגע הודעת "הפונקציה עדיין לא זמינה" — לשרת אין נקודת קצה `PATCH /operators/me`, לכן שינויים בשם פרטי, שם משפחה וטלפון אינם נשמרים בפועל
- העלאת תמונה הוסרה מתצוגה זו; השתמש ב-`/profile/operator` המעוצב מחדש ולחץ על האווטאר שלך לפתיחת דיאלוג ההעלאה

מומלץ להשתמש ב-`/profile/operator` לשימוש יומיומי. שמור את כתובת ה-URL הזו רק אם תיקון עתידי לתצוגה המעוצבת מחדש ידרוש גיבוי לכאן.

## דיאלוג העלאת אווטאר

נפתח מכותרת הראשית (לחץ על האווטאר שלך) בתצוגות המעוצבות מחדש.

מקבל:

- סוגי קבצים: רק `image/png`, `image/jpeg`, `image/jpg` — כל דבר אחר יגרום לשגיאת "סוג קובץ"
- גודל קובץ מקסימלי: **10 מגה-בייט** — קבצים גדולים יותר יגרמו לשגיאת "גודל קובץ"
- גרור ושחרר או לחץ לבחירה

הדיאלוג מציג תצוגה מקדימה, שם הקובץ, וסרגל התקדמות במהלך ההעלאה. רצף ההעלאה הוא:

1. `POST` את הקובץ → מחזיר `avatarUrl`
2. `PATCH /me` עם `{ photo: avatarUrl }` → מחזיר את רשומת המשתמש המעודכנת
3. חנות המשתמש מתעדכנת עם השדה החדש `photo`; האווטאר החדש מופיע מיד בכל מקום שמוזכר

הודעות Toast מאשרות הצלחה או כישלון. בהצלחה, הדיאלוג נסגר אוטומטית.

## הפניה לשדות (בכל המסלולים)

רשימה מאוחדת של מה שניתן לעריכה, היכן, ואיך הוא מאומת:

| שדה                          | ניתן לעריכה ב-               | אימות                                                              |
| ----------------------------- | ------------------------------ | ------------------------------------------------------------------- |
| אווטאר / תמונה               | מפעיל                         | PNG/JPG/JPEG, עד 10 מגה-בייט                                       |
| שם פרטי                      | Legacy (שבור — ללא backend)   | לא נאכף בצד הלקוח                                                |
| שם משפחה                    | Legacy (שבור — ללא backend)   | לא נאכף בצד הלקוח                                                |
| טלפון                       | Legacy (שבור — ללא backend)   | לא נאכף בצד הלקוח                                                |
| סיסמה נוכחית                | מפעיל → אבטחה                | חובה, ≥ 8 תווים                                                   |
| סיסמה חדשה                 | מפעיל → אבטחה                | חובה, ≥ 8 תווים, חייבת להיות שונה מהנוכחית                        |
| אשר סיסמה                  | מפעיל → אבטחה                | חובה, חייבת להתאים לסיסמה החדשה                                  |
| מצב ערכת נושא              | מפעיל → העדפות, Legacy       | localStorage בלבד                                                |
| צבע ערכת נושא              | מפעיל → העדפות, Legacy       | localStorage בלבד                                                |
| סגנון מפה                  | מפעיל → העדפות, Legacy       | localStorage בלבד                                                |
| הגדרת צליל התראה          | מפעיל → העדפות, Legacy       | localStorage בלבד                                                |
| תפקיד / מחלקה / משרה / תגיות | _לא כאן_                     | נערך על ידי מנהל דרך [Operators](../../settings/access/operators.md) |

## תהליכי עבודה טיפוסיים

- **אפס את הסיסמה שלך** — `/profile/operator` → לשונית אבטחה → שנה → מלא את שלושת השדות → שלח. הדיאלוג נסגר ואתה נשאר מחובר
- **התנתק ממחשב ציבורי ששכחת ממנו** — לשונית אבטחה → הרחב את קבוצת המכשירים → סמל פח האשפה על אותה סשן, או "התנתק מהמכשיר הזה" לכל הסשנים בו. הסשן הנוכחי שלך תמיד מוגן
- **פעילות חשודה** — לשונית אבטחה → "התנתק מסשנים אחרים" למעלה מבטל כל סשן שאינו נוכחי בלחיצה אחת
- **שנה את האווטאר שלך** — לחץ על האווטאר בכותרת הראשית → גרור PNG/JPG עד 10 מגה-בייט → העלה
- **החלף את לוח המחוונים למצב כהה** — לשונית העדפות → מצב ערכת נושא = כהה (או הגדר למערכת ותן למערכת ההפעלה להחליט)
- **סמן לשונית כמועדפת** — לכל לשונית יש האש (`#overview`, `#security`, `#preferences`); העתק את כתובת ה-URL עם ההאש והשתמש בה כקישור ישיר
- **ראה את עצמך כלקוח** — אם החשבון שלך מקושר, לחץ על כפתור הלקוח בכותרת הראשית → ראה את תצוגת Rider App שלך (יתרה, נסיעות, מכשירים). חזור באותו אופן

## טיפים

- **מה שניתן לערוך כאן מוגבל** — התפקיד, המחלקה, המשרה, התגיות והאימייל מנוהלים כולם בדף [Operators](../../settings/access/operators.md) על ידי מנהל. הפרופיל מיועד רק לאווטאר, סיסמה, סשנים והעדפות שלך
- **העדפות הן מקומיות** — ערכות נושא וצלילי התראה נשמרים ב-localStorage, לא בשרת. מחיקת נתוני הדפדפן מאפסת אותם; החלפת מכשירים לא מעבירה אותם
- **ההאש קובע את הלשונית** — `/profile/operator#security` פותח ישירות ללשונית אבטחה. השתמש בזה בקישורי צ'אט כדי שחבר צוות יראה את אותה תצוגה כמוך
- **כפתור השמירה בתצוגת Legacy כרגע לא פעיל** — עד ש-`PATCH /operators/me` יושק, השתמש בתצוגת המפעיל המעודכנת לכל דבר; לשינוי שמות בקש ממנהל
- **סשנים מקובצים לפי מכשיר** — אם אתה רואה רשומה אחת שמכסה כמה לשוניות, זה צפוי. הרחב כדי לראות סשנים בודדים
- **פרסונת הלקוח מוגבלת על ידי נתונים** — גם אם הכפתור נראה, הוא לא עושה דבר שימושי אלא אם לחשבון שלך יש רשומת `client` מצורפת. אם אין לך, התעלם מכפתור הלקוח והישאר על `/profile/operator`
