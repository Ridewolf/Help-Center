# ניתוחים — מפות חום

דף מפות החום (`/analytics/heatmaps`) הוא **ממחיש צפיפות גאוגרפית**: בחר מקור נתונים, טווח תאריכים, ומצב תצוגה — המפה מציגה היכן מרוכזת הפעילות באזור התפעול שלך.

השתמש בו ל**גילוי ביקוש** (מאיפה הרוכבים רוצים להתחיל? איפה הם מסיימים?) ו**תכנון כיסוי** (איפה הרוכבים מחפשים, אבל אין לנו רכבים?).

## מקורות נתונים

שלושה מקורות אות, אחד בכל פעם:

| מקור           | מה הוא מציג                                                             |
| --------------- | ------------------------------------------------------------------------ |
| **סריקות**      | איפה שהרוכבים **פתחו את האפליקציה וסרקו רכבים** — כוונת ביקוש          |
| **התחלות נסיעה** | איפה שהנסיעות **החלו בפועל** — ביקוש מומש                             |
| **סיום נסיעה**  | איפה שהנסיעות **הסתיימו** — מיקומי ירידה טבעיים                       |

השווה בין _סריקות_ ל_התחלות נסיעה_ כדי למצוא **ביקוש לא ממומש**: מקומות שבהם הרוכבים חיפשו אך לא מצאו רכב.

## מצבי תצוגה

ארבע דרכים להציג את אותם הנתונים:

| מצב          | מה הוא מצייר                                                                |
| ------------ | --------------------------------------------------------------------------- |
| **מפת חום**  | טשטוש חום קלאסי וחלק — הטוב ביותר ל**זיהוי שיאים** במבט חטוף              |
| **משושים**  | תאים משושים — הטוב ביותר ל**השוואת אזורים** עם גאומטריה עקבית            |
| **אשכולות** | אשכולות נקודות שמתפשטים בהגדלה — הטוב ביותר ל**חקירת נקודות בודדות**     |
| **רשת**     | רשת ריבועית רגילה — הטוב ביותר ל**יישור עם אזורי תכנון**                   |

אותם נתוני מקור יכולים לספר סיפורים שונים במצבים שונים — החלף מצב תוך כדי חקירה.

## סכמות צבע

שורת דגימות קטנות מאפשרת לבחור סכמת צבע — שימושי למפעילים עם עיוורון צבעים או להתאמת פלטת צבעים למותג. שם הסכמה מופיע כטיפ בעת ריחוף.

## מחוון נקודות

מחוון בסרגל הכלים מאפשר לשלוט בכמות נקודות הנתונים לדגימה (למשל 1k / 10k / 100k). יותר נקודות = תמונת צפיפות מדויקת יותר אך עיבוד איטי יותר. התחל נמוך בזמן חקירה, הגדל כשממקדים אזור / טווח.

## טווח תאריכים

סרגל טווח תאריכים סטנדרטי למעלה. ככל שהטווח רחב יותר, התמונה מתאגדת יותר; ל"מה קרה הבוקר" בחר כמה שעות.

## המפה

המפה ממלאת את הדף. בקרות מפה סטנדרטיות (הזזה, זום, החלפת שכבות). שכבת מפת החום יושבת מעל בסיס המפה.

**מקרא** בפינה מסביר את סולם הצבעים של המצב הפעיל — מצפיפות נמוכה לגבוהה.

## תרחישי עבודה טיפוסיים

- **מצא ביקוש לא ממומש** — מקור = סריקות, מצב = מפת חום → איתור אזור חם → החלף מקור ל'התחלות נסיעה' → אם אותו אזור קר = ביקוש לא ממומש → שקול איזון מחדש או הרחבה לאזור זה
- **תכנן אזור חדש** — מקור = סיום נסיעה, מצב = משושים → חפש ריכוזי ירידה טבעיים מחוץ לאזורים הקיימים → הצע לתפעול
- **חקור נקודה חמה** — מצב = אשכולות → התקרב לאזור החם → נקודות בודדות מציגות קואורדינטות מדויקות; השווה עם [Vehicle Search](vehicles.md) לפרטי נסיעה
- **השווה חלונות זמן** — טען סריקות בוקר → צלם מסך → החלף לסריקות ערב → השווה בין הצילומי מסך (הלוח עדיין לא תומך בתצוגת שתי תקופות; נדרש ייצוא ידני)
- **בדיקת כיסוי** — מקור = סריקות בשבוע האחרון → חפש נקודות חמות רחוקות מאזור מתוכנן → שקול שרטוט מחדש של גבולות האזור

## טיפים

- **סריקות ≠ נסיעות** — סריקות רבות לא מתממשות (הרוכב לא מוצא רכב, רואה מחיר, מוותר). הפער בין סריקות להתחלת נסיעה הוא האות הפעיל ביותר שלך
- **מצב מפת חום מסתיר סולם** — הצבעים יחסיים למפה הנראית; הזום משנה את התמונה. מצב משושים יותר אמין בזומי קבועים
- **התחל עם מעט נקודות, סיים עם רבות** — חקירה עם 1k נקודות מהירה; הגדל ל-100k רק כשברור מה מחפשים
- **מצב רשת לתכנון** — אם האזורים שלך מלבניים, רשת מתיישרת איתם ומקלה על החישובים; אחרת העדף משושים
- **עיוורון צבעים?** — נסה סכמות חלופיות; הנתונים הבסיסיים זהים
- **המפה לא מתעדכנת אוטומטית בשינוי תאריך** — בהתאם להגדרות ייתכן שתצטרך ללחוץ שוב על _החל_ / _רענן_ לאחר שינוי טווח התאריכים
- **מקרא חשוב** — מה שנראה "אדום ודרמטי" יכול להיות ספירה מוחלטת קטנה; תמיד הבט במקרא לפני פרשנות
