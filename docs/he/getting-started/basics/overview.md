# ברוכים הבאים ללוח המחוונים של Ridewolf

לוח המחוונים של Ridewolf הוא מרכז הבקרה לניהול צי שיתוף תחבורה. בין אם אתם מפעילים קורקינטים, אופניים או כל סוג רכב אחר, כאן תוכלו לעקוב אחרי פעילות בזמן אמת, לנהל לקוחות, לטפל בתמיכה ולנתח ביצועים.

## למי מיועד לוח המחוונים הזה

לוח המחוונים מיועד ל**מפעילים** — צוות העובד יום-יום עם הצי:

- **מנהלי צי** — רכבים, אזורים, תעריפים
- **סוכני תמיכה** — כרטיסים, שיחות, הוכחות חניה
- **אנליסטים** — מדדים, דוחות, ביצועים
- **מנהל מערכת** — מפעילים, תפקידים, הגדרות מערכת

מה שכל מפעיל רואה תלוי ב**תפקיד ובהרשאות** שלו. התצוגה שלכם עשויה להיות מצומצמת יותר מהצילום מסך במדריך זה אם חלק מהמודולים מוגבלים לתפקידכם.

## מושגים מרכזיים

לוח המחוונים מאורגן סביב כמה מושגים שתפגשו בכל מקום:

| מושג          | משמעותו                                                                    |
| -------------- | --------------------------------------------------------------------------- |
| **רכב**        | יחידה פיזית בצי (קורקינט, אופניים וכו') — כוללת GPS, סוללה, סטטוס       |
| **נסיעה**      | נסיעה שביצע לקוח ברכב — כוללת זמן התחלה/סיום, מסלול, עלות                 |
| **לקוח**       | לקוח רשום שיכול לשכור רכבים                                               |
| **תשלום**      | עסקאות כספיות הקשורות לנסיעות, טעינות או החזרים                          |
| **אזור**       | אזור גאוגרפי שבו פועלים רכבים (או שמוגבלים בו)                            |
| **תעריף**      | כללי תמחור שקובעים כמה עולה נסיעה                                         |
| **תג**         | תווית שמצורפת ללקוחות או רכבים לצורך קיבוץ וסינון                         |
| **כרטיס**      | בקשת תמיכה מלקוח                                                          |
| **הוכחת חניה** | תמונה ששלח לקוח לאישור חניה נכונה                                        |

## ניווט בסיסי

### סרגל צד (משמאל)

סרגל הצד הוא הניווט הראשי. קבוצות נפתחות כדי לחשוף דפים משניים — לדוגמה, **תמיכה** נפתחת לכרטיסים, הוכחות חניה ושיחות.

### סרגל עליון

הסרגל העליון מופיע בכל דף וכולל:

- **נתיב ניווט** — הנתיב חזרה בהיררכיה (למשל בית → רכבים → RW-001)
- **צ׳אט בינה מלאכותית** (אייקון ניצוץ) — עוזר שיכול לענות על שאלות לגבי לוח המחוונים
- **עזרה** (אייקון סימן שאלה) — פותח את בסיס הידע הזה, בהקשר לדף הנוכחי
- **התראות** (אייקון פעמון) — אירועים והתראות מערכת אחרונים
- **פרופיל** (אוואטר) — הגדרות, שינוי סיסמה, יציאה, בקרות נושא

### טבלאות

רוב דפי הרשימות (רכבים, נסיעות, לקוחות וכו') משתמשים במבנה זהה:

1. **סרגל חיפוש** למעלה לחיפוש טקסט מלא
2. **פילטרים** מתחת לצמצום לפי סטטוס, סוג וכו'
3. **עמודות למיון** — לחצו על כותרת עמודה למיון
4. **פגינציה** בתחתית
5. **פעולות שורה** — תפריט שלוש נקודות בכל שורה לפעולות מהירות

## מה לעשות קודם

אם זו הפעם הראשונה שלכם בלוח המחוונים, מומלץ:

1. **עדכון הפרופיל** — אוואטר → פרופיל, מלאו שם, תמונה, פרטי קשר
2. **עיון בצי** — פתחו את **רכבים** כדי לראות מה פעיל כרגע
3. **בדיקת נסיעות היום** — פתחו את **נסיעות** עם סינון ליום זה לצפייה בפעילות בזמן אמת
4. **פתיחת לוח המחוונים הראשי** — דף `/dashboard` מסכם מדדי מפתח יומיים
5. **קריאת בסיס הידע הזה** — פתחו את הסעיף הרלוונטי לפני ביצוע פעולה ראשונה בכל מודול

## קבלת עזרה

יש שלוש דרכים לקבל עזרה מתוך לוח המחוונים:

- **אייקון עזרה (?)** בסרגל העליון — פותח מגירה צדדית עם תיעוד רלוונטי לדף הנוכחי
- **עזרה** בסרגל הצד (אייקון ספר) — בסיס ידע מלא וחיפוש
- **טפסי משוב / הצעות** בדף הבית של העזרה — כתבו ישירות לצוות

## צעדים הבאים

כשתרגישו בנוח עם הבסיס:

- ראו **תכונות לוח המחוונים** ללמוד קיצורי מקלדת, טריקים לסינון ונושאים
- ראו **תפעול** למדריכים מעשיים על רכבים, נסיעות ולקוחות
- ראו **הגדרות** אם אתם צריכים להגדיר מפעילים, אזורים או תעריפים
