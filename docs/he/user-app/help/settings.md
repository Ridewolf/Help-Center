# אפליקציית Rider — הגדרות

הגדרות (`/settings`) מכילות את כל ההעדפות של האפליקציה הפונה לרוכב: התראות, מה שהמפה מציגה, מתגי פרטיות, שפה, נושא וביצועים.

**אין כפתור שמירה.** המסך מציג מיידית את ההגדרות מהמטמון, מרענן אותן ברקע, ודוחף כל שינוי אוטומטית רגע לאחר ביצועו. רוכב ששינה משהו וסגר את המסך מיד כמעט בוודאות שמר את השינוי — זו התשובה ל"האם השינוי שלי הוחל?".

כמה מהמתגים האלה משנים את מה שה[מפה](../riding/map.md) מציגה, לכן זה המסך הראשון לביקור כשיש תלונות כמו "המפה איטית" ו"אני לא רואה את רמות הסוללה".

## התראות

חמישה מתגים עצמאיים:

- **התראות נסיעה**
- **התראות קידום**
- **עדכוני אפליקציה**
- **התראות פוש**
- **התראות אימייל** — מתג יחיד; אין תת-אפשרויות לפי סוג תחתיו

באותו אזור:

| בקרה              | הערות                                                                        |
| ------------------ | ---------------------------------------------------------------------------- |
| **צליל**          | מתג                                                                          |
| **עוצמת צליל**    | מחוון — מופיע רק כשה**צליל** מופעל                                            |
| **רטט**           | מתג                                                                          |
| **הגדרות רדאר**   | כרטיס שמופיע רק בבניית האפליקציה שבה הגדרות רדאר מופעלות                      |

## מפה ותצוגה

מתגים:

- **הצג רמת סוללה**
- **הצג רכבים מקודמים**
- **הצג תמחור**
- **זום אוטומטי**
- **מפה תלת-ממדית** — נכנס לתוקף מיד על המפה
- **הפחתת אנימציות**

בנוסף **מצב נתונים**, בחירה בין **מאוזן**, **נמוך** ו**גבוה**. הוא שולט באיכות אריחי המפה וכמה פרטים המפה מציגה, ו**זו הפעולה הראשונה שכדאי לנסות כשרוכב מדווח על מפה איטית או כבדה** — הורידו ל_נמוך_, והפעילו גם את **הפחתת אנימציות**.

**מפות לא מקוונות** אינן זמינות כרגע באפליקציה.

## בקרות פרטיות

- מתג **שיתוף מיקום גאוגרפי**
- מתג **שיתוף נתונים**
- **מדיניות פרטיות** — פותח את כתובת ה-URL החיצונית שהגדרת ב[החברה שלי](../../settings/administration/my-company.md); הקישור מופיע רק כשכתובת הוגדרה
- **ניהול מושבים** — פותח את מסך המכשירים המחוברים (`/settings/sessions`), אותו מסך שניתן להגיע אליו גם מפרופיל

מסך ההנחיות המלא לפרטיות ובטיחות הוא מסלול נפרד (`/privacy`). **מחיקת חשבון אינה כאן** — תהליך המחיקה עובד במסך הפרופיל.

## אזור ומראה

| בקרה          | אפשרויות                          | הערות                                                                                                   |
| -------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **שפה**       | **en**, **ru**, **ro**           | נכנס לתוקף מיד, ללא טעינה מחדש. רק שלוש אלה מוצעות במסך זה                                         |
| **יחידות**    | —                                | בורר יחידות אינו זמין כרגע באפליקציה                                                                  |
| **נושא**      | בהיר, כהה, מערכת                 | נכנס לתוקף מיד                                                                                        |
| **סגנון מפה** | אוטומטי, בהיר, כהה              | **מנוטרל ומאולץ לאוטומטי כשנושא מוגדר למערכת.** החלף נושא לבהיר או כהה כדי לשחרר אותו                 |

רק שלוש שפות האפליקציה הנ״ל מופיעות כאן, אף על פי שקיימות לוקליזציות נוספות במוצר — ראו [Localization](../../settings/administration/localization.md) בצד לוח המחוונים.

## מצב רכיבה

**מצב רכיבה אינו זמין כרגע באפליקציה.** רוכב ששואל היכן בקרת מצב הרכיבה לא איבד הרשאה — הסעיף אינו באפליקציה, ואין הגדרה בלוח המחוונים שמוסיפה אותו.

| רוכב שואל…                          | תשובה                                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| "איפה כפתור השמירה?"               | אין כזה — השינויים נשמרים אוטומטית                                                    |
| "איפה מצב הרכיבה?"                 | אינו זמין כרגע באפליקציה                                                            |
| "למה סגנון המפה באפור?"             | **הנושא** מוגדר ל**מערכת**. החלף ל־בהיר או כהה קודם                                   |
| "למה השפה שלי לא מופיעה?"          | מסך זה מציע רק **en**, **ru** ו־**ro**                                              |
| "איפה הגדרת היחידות?"              | אינה זמינה כרגע באפליקציה                                                             |
| "איפה מתג מפות לא מקוונות?"         | אינו זמין כרגע באפליקציה                                                             |
| "איך מוחקים את החשבון שלי?"        | ממסך הפרופיל, לא מהגדרות                                                           |
| "איך רואים את המכשירים המחוברים שלי?" | **ניהול מושבים** — כאן, או אותו כפתור בפרופיל                                      |
| "המפה איטית"                       | **מצב נתונים → נמוך**, ואז **הפחתת אנימציות** מופעל. ראו [Map](../riding/map.md#פתרון-בעיות) |

## טיפים

- **מצב נתונים הוא כפתור הביצועים שלך.** לפני שאתה מאשים את הטלפון של הרוכב או את האריחים שלך, תבקש מהם לנסות _נמוך_.
- **"זה לא נשמר" כמעט אף פעם לא נכון.** בקש מהם לפתוח מחדש את המסך — הערך יהיה שם.
- **תלונות על המפה לרוב נמצאות כאן, לא על המפה.** אחוזי סוללה חסרים, מחירים חסרים ורכבים פרומושנליים חסרים הם כולם מתגים במסך זה.
- **הנושא קובע את סגנון המפה.** זכור את הזוג הזה; אחרת זו כרטיס שבועי.
