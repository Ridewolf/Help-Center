# אפליקציית Rider — תמיכה, שאלות נפוצות וצ'אט חי

תמיכה (`/support`) היא המקום שאליו רוכב פונה לקבלת עזרה. יש לה שני לשוניות — **שאלות נפוצות** ו-**צור קשר** — והצ'אט החי נפתח במסך נפרד (`/support/messenger`).

שתי נקודות שכדאי לדעת לפני שתענה על כל שאלה בנושא תמיכה:

- **כל ערוץ תקשורת הוא שלך להגדרה.** אין אימייל תמיכה גלובלי של Ridewolf, מספר טלפון או שעות פתיחה באפליקציה — אל תצטט אף אחד מהם.
- **לאפליקציה יש צ'אט, לא טופס כרטיס.** לרוכבים אין מספרי כרטיסים. התצוגה של הצוות שלך לאותן שיחות היא ב-[שיחות](../../support/tickets-proofs-chat/conversations.md); [כרטיסים](../../support/tickets-proofs-chat/tickets.md) הוא מושג בצד המפעיל.

## לשונית שאלות נפוצות

קטעי אקורדיון שנבנו מתוכן שאלות ותשובות שפרסמת, בנוסף לפריטי **מדריך הרכיבה** המחולקים לקבוצות **לפני התחלה** ו-**לפני סיום**.

אתה שולט בכל זה ללא צורך בשחרור גרסה חדשה של האפליקציה:

- שאלות ותשובות — [סטים של שאלות נפוצות](../../settings/content/faq-sets.md)
- מדריכי רכיבה — [מדריכים מהירים](../../settings/content/quick-guides.md)

פריטי שאלות נפוצות בודדים הם **ניתנים לקישור עמוק**: קישור לפריט מסוים פותח את התמיכה כשהפריט כבר מורחב וממוקם בתצוגה. זו הדרך הנכונה לשלוח רוכב ישירות לתשובה אחת במקום "לחפש בשאלות נפוצות".

## לשונית צור קשר

כל ערוץ כאן מוצג רק אם הפעלת אותו ב-[החברה שלי → אפליקציה → ערוצי תמיכה](../../settings/administration/my-company.md).

| ערוץ          | מה הוא עושה                                                        |
| ------------- | ------------------------------------------------------------------- |
| **צ'אט חי**   | פותח את המסנג'ר (`/support/messenger`)                          |
| **אימייל**    | פותח את אפליקציית המייל של הרוכב עם הכתובת שלך                   |
| **אתר אינטרנט** | פותח את כתובת ה-URL שהגדרת בדפדפן בתוך האפליקציה                 |
| **טלגרם**    | פותח את איש הקשר שלך בטלגרם מחוץ לאפליקציה                        |
| **וואטסאפ**  | פותח את איש הקשר שלך בוואטסאפ מחוץ לאפליקציה                      |
| **טלפון**    | מתחיל שיחה למספר שהגדרת                                         |

אם **אף אחד** מהם לא מופעל, הלשונית מציגה איור של אין ערוצים. רוכב המדווח "אין דרך ליצור קשר עם התמיכה" כמעט תמיד נמצא בחברה שכל הערוצים בה כבויים — בדוק את ההגדרות שלך לפני שתבדוק במקום אחר.

## צ'אט חי

המסנג'ר מבוסס שיחות:

- הרוכב רואה את **רשימת השיחות שלו**, כל שיחה עם סטטוס, המפעיל שהוקצה, ההודעה האחרונה וזמנה, ומספר הודעות שלא נקראו.
- **צ'אט חדש** מוצע **רק אם לרוכב אין שיחה פתוחה.** רוכב עם שיחה פתוחה לא רואה אפשרות לפתוח שיחה שנייה — זה מתוכנן כך. הם ממשיכים את השיחה הקיימת.
- פתיחת שיחה טוענת את היסטוריית ההודעות שלה, 50 הודעות בכל פעם, ומביאה הודעות ישנות יותר כשהרוכב גולל למעלה.

| סטטוס שיחה       | משמעות                              |
| ----------------- | ------------------------------------ |
| **חדש**           | נפתחה זה עתה, עדיין לא טופלה         |
| **ממתין**         | ממתין לצוות שלך                     |
| **פעיל**          | בטיפול                              |
| **מושהה**         | נדחה                               |
| **סגור**          | נסגר על ידי מפעיל                   |

**סוגי הודעות שהאפליקציה מציגה:** טקסט, תמונה, קובץ, מיקום, איש קשר, נסיעה, קישור לאפליקציה והודעות מערכת.

**אייקוני סטטוס הודעה:** נשלח, נשלח בהצלחה, נמסר, נקרא ונכשל.

### שליחת הודעה

רוכב יכול לצרף:

- עד **5 תמונות בהודעה אחת**
- **סמן מיקום** (קו רוחב, קו אורך ותווית)
- **קובץ**

הודעה שנשלחה מופיעה מיד כ_נשלחת_, ואז מתעדכנת לסטטוס האמיתי כשהשרת מאשר. החיבור החי הזה גם מעדכן הודעות חדשות, קריאות, הודעות שיחה נסגרה והקצאה, ומציג את הסמן "_{name} מקליד…_".

לאחר אובדן חיבור האפליקציה טוענת מחדש את רשימת השיחות ואת הצ'אט הפתוח, ומונעת כפילויות של הודעות — כך שרוכב שיצא לא מקוון לא יראה את אותה הודעה פעמיים.

כשמפעיל **סוגר** את השיחה, הקלט של הרוכב מושבת והודעת "השיחה נסגרה" מחליפה את שדה הקלט.

## פתרון בעיות

| הרוכב אומר…                            | מה הבעיה                                                                                                    |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| "אין אפשרויות יצירת קשר"              | אין ערוצים מופעלים בחברה שלך — תקן זאת ב-[החברה שלי](../../settings/administration/my-company.md)          |
| "אין כפתור צ'אט חדש"                   | לרוכב כבר יש שיחה פתוחה; עליו להמשיך את השיחה הזו                                                        |
| "אני לא יכול להקליד יותר"             | מפעיל סגר את השיחה. ניתן להתחיל שיחה חדשה רק כשאין שיחה פתוחה                                         |
| "ההודעה שלי מופיעה כנכשלת"             | ההודעה לא יצאה מהמכשיר — נסה לשלוח שוב                                                                     |
| "ההודעות שלי הוכפלו אחרי חיבור מחדש"  | הן לא הוכפלו; הטעינה מחדש מונעת כפילויות. בקש צילום מסך אם הם מתעקשים                                  |
| "כמה מהר תענו?"                        | אין זמן תגובה מוגדר באפליקציה. **אל תבטיח זמן תגובה** — צטט את התחייבות השירות שפרסמת בעצמך              |
| "איפה מדווחים על מקרה חירום?"         | דרך כל הערוצים שהפעלת. האפליקציה לא מגדירה מוקד חירום, ואין לצטט מספר חירום ממנה                          |

## טיפים

- **בצע ביקורת על לשונית הקשר שלך.** פתח את אפליקציית Rider בעצמך לאחר כל שינוי ב-My Company — לשונית קשר ריקה לגמרי בלתי נראית עבורך ומכעיסה את הרוכבים.
- **קשר ישיר לתשובות ב-FAQ** בתגובות לשיחות במקום להקליד אותן מחדש. זה מלמד את הרוכבים היכן התשובה נמצאת.
- **שיחה פתוחה אחת בכל פעם** היא הכלל. כאשר רוכב צריך להעלות נושא לא קשור, סגור קודם את השרשור הישן.
- **שמור על סטים של שאלות נפוצות ומדריכים מהירים מעודכנים** — כל שאלה שהם עונים עליה היא שיחה שאתה לעולם לא תצטרך.
- **סגירת שיחה מסיימת את יכולת התגובה של הרוכב.** ודא שהתשובה שלמה לפני הסגירה.
