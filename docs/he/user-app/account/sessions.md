# מושבים — מכשירים מחוברים לחשבון

מסך **מושבים** (`/settings/sessions`) מציג כל מקום שבו חשבון הרוכב מחובר כרגע, ומאפשר לו להתנתק מהמקומות האלה. זה המסך אליו פונים בכל פעם שרוכב חושד שמישהו אחר ניגש לחשבונו.

שני דרכי כניסה, שתיהן מובילות לכאן:

- **פרופיל → ניהול מושבים**
- **הגדרות → כרטיס פרטיות → ניהול מושבים**

## כיצד הרשימה מאורגנת

המושבים **מקובצים לפי מכשיר** — דפדפן וגרסה, מערכת הפעלה וגרסה, סוג מכשיר, יצרן ודגם — כך שהטלפון עצמו מופיע פעם אחת במקום עשרות פעמים.

הקבוצות ממוינות בכוונה:

1. המכשיר הנוכחי של הרוכב ראשון
2. אחר כך לפי סטטוס: **פעיל**, אחר כך **לא פעיל**, אחר כך **ישן**
3. אחר כך לפי פעילות אחרונה, החדשים ביותר ראשונים

כל קבוצה ניתנת לכיווץ. פתיחתה חושפת כל מושב בודד השייך למכשיר זה.

## קריאת קבוצת מכשירים

| מה שאתה רואה                      | משמעות                                                                    |
| --------------------------------- | -------------------------------------------------------------------------- |
| **תווית מכשיר**                   | יצרן ודגם כשידועים, אחרת מערכת ההפעלה וגרסתה                            |
| אייקון סוג מכשיר                  | טלפון, טאבלט או מסך                                                      |
| **תווית דפדפן**                   | הדפדפן וגרסתו מאחורי המושב                                              |
| **סמל סטטוס מושב**               | ראה את הטבלה למטה                                                        |
| **פעילות אחרונה**                 | זמן יחסי — "הרגע עכשיו", N דקות / שעות / ימים לפני כן, ותאריך מוחלט כשהוא מעל שבוע |
| **מספר מושבים**                  | כמה מושבים יש למכשיר זה                                                  |
| **מיקום**                        | עיר, מדינה וכתובת IP                                                    |
| **נוצר**                        | מתי התחיל מושב זה                                                        |
| **מכשיר נוכחי** / **מושב נוכחי** | סמל מודגש על המכשיר והמושב שהרוכב משתמש בהם כרגע                      |

### סמלוני סטטוס

| סמלון       | משמעות                              |
| ------------ | ------------------------------------ |
| **פעיל**    | פעילות אחרונה פחות משעה אחת לפני כן |
| **לא פעיל** | פעילות אחרונה פחות מ-24 שעות לפני כן |
| **ישן**     | פעילות אחרונה לפני 24 שעות או יותר   |

הסמלון מודד **רק עדכניות** — הוא לא מציין אם מושב עדיין תקף. סמלון "ישן" לא אומר שהמושב פג תוקף.

## התנתקות ממושב אחד

למושב הנוכחי אין אפשרות מחיקה — במתכונת, לא ניתן להסירו מהרשימה הזו. כל מושב אחר ניתן להסרה:

1. פתח את קבוצת המכשיר
2. הקש על אייקון **פח אשפה** במושב
3. אשר בתיבת הדו-שיח

הרשימה נטענת מחדש והמושב נעלם.

## פעולות מרובות

| פעולה                      | מה היא עושה                                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **התנתק ממושבים אחרים**  | מתנתק מכל המושבים פרט לזה שבמכשיר שביד הרוכב. זו הפעולה הנכונה כשרוכב חושד שמישהו אחר ניגש לחשבונו          |
| **התנתק מכל המושבים**     | מתנתק מכל המושבים **כולל המכשיר הנוכחי**, כך שהרוכב חוזר למסך ההתחברות וצריך להתחבר שוב. מעוצב כהרסני מסיבה זו |
| **בטל מכשיר**              | מוצע בקבוצת מכשיר מורחבת שאינה המכשיר הנוכחי — מתנתק מכל המושבים במכשיר זה                                    |

בעת ביצוע בקשת התנתקות הכפתורים מנוטרלים. כישלון מציג הודעת שגיאה קצרה; הצלחה מציגה אישור ונטענת מחדש הרשימה.

## תרחישי עבודה טיפוסיים

- **הרוכב חושב שמישהו אחר מחובר לחשבונו** — **התנתק ממושבים אחרים**, ואז שנה את הסיסמה מ**פרופיל**. שים לב ששינוי סיסמה מוצלח מתנתק גם הוא, כך שהרוכב יתחבר שוב לאחר מכן ([פרופיל](profile.md))
- **כניסה שנשכחה בטלפון מושאל** — פתח את קבוצת המכשיר, **בטל מכשיר**
- **התחלה נקייה בכל מקום** — **התנתק מכל המושבים**, ואז התחבר שוב ([התחברות](registration-login.md))

## שאלות נפוצות

- **למה הרוכב לא יכול למחוק את המושב הנוכחי שלו?** אין אפשרות מחיקה מוצגת עבורו. כדי לסיים את המושב הנוכחי, השתמש ב**התנתק מכל המושבים**, או בכפתור **התנתק** הרגיל בפרופיל.
- **מה המשמעות של "פעיל" בפועל?** פעילות בשעה האחרונה — לא יותר מזה.
- **למה טלפון אחד מציג כמה מושבים?** מושבים נוצרים בכל כניסה. המסך מקבץ אותם תחת מכשיר אחד ומציג את המספר.
- **כפתור ניהול מושבים אפור.** לחשבון יש מחיקה ממתינה, שמנטרלת ניהול מושבים יחד עם עריכת פרופיל — ראה [פרופיל](profile.md).
