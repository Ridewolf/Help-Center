# אפליקציית Rider — סטטיסטיקות רוכב

**סטטיסטיקות המיועדות לרוכב אינן זמינות כרגע באפליקציה.** אין מסך גרפים, אין סיכומים ואין סיכום הוצאות שהרוכב יכול לפתוח.

שלח את הרוכבים ל-[History](history.md) במקום — זה המקום היחיד עם הנתונים שלהם עצמם.

## מה שהרוכב רואה

- **אין נקודת כניסה.** תפריט הצד מציג ארנק, היסטוריה, תמיכה, פרטיות, הגדרות ופרופיל — ולא משהו נוסף. רוכב שאומר שהוא לא מוצא מסך ניתוחים צודק; אל תגיד לו לחפש בתפריט, ואל תשלח לו קישור למסך כזה.
- אם מסך `/analytics` נפתח ישירות, הוא מציג רק כותרת ורווח ריק. **אין שום תקלה** בחשבון הרוכב, במכשיר שלו או בהתקנת האפליקציה — התקנה מחדש לא תשנה דבר.

## איפה המספרים של הרוכב באמת נמצאים

[History](history.md) מכיל נתונים אמיתיים לכל רוכב:

- לשונית **Rides** מציגה כל נסיעה קודמת עם המרחק, משך הזמן והעלות
- לשונית **Payments** מציגה טעינות, החזרים, חיובים ובונוסים עם סכומים וסטטוסים
- הקשה על נסיעה פותחת את פרטיה עם [פירוט העלות](../riding/rides.md#פירוט-עלות), ציר הזמן של הפעילות והמסלול שמצויר על מפה

אין **שלט סיכומים מצטברים בשום מקום** באפליקציית הרוכב — לא במסכי סטטיסטיקות, ולא בראש היסטוריה. סיכומים מצטברים לכל החיים צריכים להיספר מרשימת הנסיעות, או להישאב מהדוחות שלך.

## מענה לשאלות המספרים מלוח המחוונים

כשרוכב באמת צריך סיכומים, הפק אותם בצד המפעיל:

| הרוכב רוצה                     | איפה אתה מקבל את זה                                                              |
| ------------------------------- | --------------------------------------------------------------------------------- |
| סך ההוצאות לתקופה              | [Analytics — Payments](../../analytics/reports/payments.md)                        |
| רשימת הנסיעות שלו, מיוצאת      | [Rides — List](../../operations/trips/rides.md), מסוננת ללקוח הזה                   |
| רשומות התשלומים שלו            | [Payments — History](../../operations/payments/payments.md)                        |
| סיכום מהיר ללקוח               | [Client Detail](../../operations/customers/client-detail.md) — ספירת נסיעות לכל החיים, יתרה, דירוג |

## שאלות נפוצות

| הרוכב שואל…                   | תשובה                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------- |
| "איפה הסטטיסטיקות שלי?"       | כרגע לא זמינות באפליקציה. השתמש ב-[History](history.md)                        |
| "אני לא מוצא את Analytics בתפריט" | אין כניסה בתפריט לזה                                                        |
| "דף ה-Analytics ריק"           | צפוי — המסך כרגע לא זמין. אין תקלה                                         |
| "האם אני יכול לייצא את נתוני הנסיעות שלי?" | לא מהאפליקציה. ייצא את זה מלוח המחוונים בשם הרוכב                        |
| "כמה הוצאתי בסך הכל?"          | אין סיכום כולל באפליקציית הרוכב. קרא את זה מההיסטוריה, או משוך את זה מלוח המחוונים |

## טיפים

- **אל תשלח קישורי ניתוחים לרוכבים.** אין מסך שכדאי להגיע אליו, ודף ריק נתפס כאפליקציה שבורה.
- **ענה על שאלות סיכומים בעצמך.** משיכת המספר מלוח המחוונים לוקחת דקה ומסיימת את השיחה.
- **ההיסטוריה היא התשובה הכנה**, והיא באמת מלאה לכל נסיעה ולכל תשלום — הצג אותה כך במקום להתנצל על מסך חסר.
