# אפליקציית Rider — ארנק וטעינות

הארנק (`/wallet`) הוא מסך הכסף של הרוכב, נפתח משורת יתרת הארנק בתפריט הצדדי. הוא מכיל את היתרה הנוכחית, בונוסים, נקודת הכניסה לטעינה, מתג הטעינה האוטומטית, והדרך לכרטיסים השמורים.

כל מה שקשור לכרטיסים עצמם — הוספה, הסרה, בחירת ברירת מחדל, ושלוש הדרכים בהן טעינה יכולה להסתיים — נמצא ב-[שיטות תשלום](payment-methods.md). טעינות קודמות, החזרים, חיובים ובונוסים נמצאים ב-[היסטוריה](history.md).

## מה יש על המסך

| אלמנט                        | מה זה                                                                                                            |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **יתרה אמיתית**              | היתרה הזמינה להוצאה של הרוכב. אייקון הרענון לצידה קורא מחדש את היתרה מהשרת                                      |
| **בונוסים**                  | יתרת בונוס נפרדת, מוצגת רק כאשר הבונוסים מופעלים                                                               |
| **סכומי טעינה מראש**         | ארבעה כפתורים: **50**, **100**, **200**, **400**. אין שדה סכום מותאם אישית במסך זה                               |
| **טעינה אוטומטית**           | מתג יחיד, עם תיאור של סף וכמות משלו                                                                              |
| **ניהול שיטות תשלום**        | פותח את [שיטות תשלום](payment-methods.md) (`/wallet/payment-methods`)                                                                  |

אם רוכב מתעקש שהיתרה שלו שגויה או מיושנת, **תבקש ממנו ללחוץ קודם על אייקון הרענון** — זה מנקה את הערך המאוחסן ומקבל את הערך העדכני. זה פותר את רוב הדיווחים "הטעינה שלי לא מופיעה".

## איך רוכב טוען את הארנק

1. פתח את הארנק.
2. בחר אחד מהסכומים המוגדרים מראש — 50, 100, 200 או 400.
3. אשר את הטעינה.

מה שקורה אחר כך תלוי לחלוטין בספק התשלום בשימוש, ויש בדיוק **שלוש** אפשרויות:

| זרימת ספק                      | מה הרוכב חווה                                                                          | יוצא מהאפליקציה? |
| -------------------------------- | --------------------------------------------------------------------------------------- | ----------------- |
| **אישור בתוך האפליקציה** (Stripe) | התשלום מאושר בתוך האפליקציה כנגד כרטיס שמור                                         | לא                |
| **הפניה מחדש** (MAIB ודומיהם)    | דפדפן חיצוני נפתח, הרוכב משלם בדף הבנק, האפליקציה מחכה לאישור                       | כן                |
| **תשלום ב-QR** (MIA ודומיהם)      | תשלום ב-QR / אפליקציית בנק עם ספירה לאחור, האפליקציה מחכה לאישור                    | כן                |

**רק זרימת האישור בתוך האפליקציה מסתיימת מבלי לצאת מהאפליקציה.** בזרימות ההפניה מחדש ו-QR, לעולם אל תגיד לרוכב שהכסף מגיע מיידית — עליו לסיים את התשלום מחוץ לאפליקציה קודם. הוראות שלב אחר שלב לכל השלוש נמצאות ב-[שיטות תשלום](payment-methods.md#טעינה--שלוש-הזרימות).

## מה קורה מיד אחרי טעינה

היתרה מתעדכנת מיידית באפליקציה, ואז האפליקציה מאשרת זאת מול השרת, מנסה שוב מספר פעמים עם השהיות הולכות וגדלות (כחצי שנייה, ואז 1, 2, 4 ו-8 שניות). אם לא מגיע אישור, היתרה המוצגת **מוחזרת** לערכה המקורי.

אז יתרה שהופיעה לרגע ואז נעלמה אומרת דבר אחד: **התשלום מעולם לא אושר.** בדוק את רשימת הטעינות הממתינות במסך [שיטות תשלום](payment-methods.md#טעינות-ממתינות).

## טעינה אוטומטית

- מתג יחיד, עם תיבת אישור כשהרוכב מפעיל אותו.
- הוא **מנוטרל** כאשר הספק הנוכחי אינו יכול לאשר תשלומים בתוך האפליקציה. לכן רוכב עם ספק הפניה מחדש בלבד או QR בלבד לא יכול להפעיל אותו כלל.
- הסף והכמות מתוארים על המסך עצמו. קרא אותם מהמסך — אל תצטט מספרים מהזיכרון, ואל תציין מגבלות שהמסך אינו מציין.

## איפה נמצאת היסטוריית התשלומים

לא כאן. טעינות, החזרים, חיובים ובונוסים כולם מופיעים בכרטיסייה **תשלומים** ב-[היסטוריה](history.md#לשונית-תשלומים), עם סכום וקידוד צבע למצב. היומן שלך בצד המפעיל הוא [תשלומים — היסטוריה](../../operations/payments/payments.md).

## פתרון בעיות

| הרוכב אומר…                             | מה לבדוק                                                                                                                             |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| "היתרה שלי שגויה / מיושנת"           | הקש על סמל הרענון ליד **יתרה אמיתית**                                                                                             |
| "התשלום נדחה"                      | סירוב מצד הכרטיס או הבנק. קוד הכישלון מופיע ברשומת התשלום ב-[היסטוריה → תשלומים](history.md#לשונית-תשלומים)                    |
| "אין מספיק כספים"                    | היתרה נמוכה מהנדרש לפעולה. טען כסף קודם — ושים לב שלתחילת נסיעה יש [יתרת התחלה מינימלית](../riding/rides.md#למה-רוכב-לא-יכול-להתחיל-נסיעה) לרוכבים ללא כרטיס |
| "אני לא יכול להפעיל טעינה אוטומטית"         | הספק הפעיל אינו יכול לאשר תשלומים בתוך האפליקציה                                                                                 |
| "הטעינה שלי לא התבצעה"                | בדוק את רשימת הטעינות הממתינות ב-[שיטות תשלום](payment-methods.md#טעינות-ממתינות). תשלום בהפניה או ב-QR שלא הושלם נמצא שם וניתן לביטול |
| "מתי יגיע ההחזר שלי?"           | אל תבטיח מספר ימים — אין הגדרת זמן להחזר באפליקציה. תשלומים שהוחזרו מופיעים בלשונית תשלומים עם סטטוס הוחזר |

## טיפים

- **רענן לפני חקירה.** חצי מהכרטיסים של "הכסף נעלם" הם תוצאה של יתרה במטמון.
- **הכר את תהליך הספק שלך לפני שאתה עונה.** "מיידי" נכון רק לאישור בתוך האפליקציה; השניים האחרים דורשים שהרוכב יסיים בצד הבנק.
- **יתרה שנעלמה היא תשלום לא מאושר**, לא אבודה. עבור ישירות לטעינות הממתינות.
- **קישור כרטיס מסיר לחלוטין את מגבלת יתרת הנסיעה** — לרוכבים הטוענים סכומים קטנים בתדירות גבוהה, זו העצה הטובה יותר.
