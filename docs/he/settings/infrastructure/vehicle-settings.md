# חוקי רכב

דף חוקי הרכב (`/settings/vehicle-rules`) הוא **קטלוג דגמי הרכב** ש-Ridewolf יודעת להפעיל — _Xiaomi M365_, _Ninebot Max G30_, _Segway F40_ וכן הלאה. כל שורה כאן היא **תבנית דגם**: חבילה לשימוש חוזר של תמחור, מגבלות טכניות, חוקי הוכחות בתמונות ותגיות שמצורפות ל[רכבים](../../operations/fleet/vehicles.md) פיזיים בודדים דרך [טופס הרכב](../../operations/fleet/vehicle-create-edit.md).

הרשאה נדרשת: **חוקי רכב** (`e7f8g9`). תת-ההרשאות מגינות על `create` / `edit` / `delete`.

## דגם לעומת מופע רכב

זו ההבחנה החשובה ביותר בדף זה:

- **דגם רכב** (בדף זה) — הגדרה. _"כל Xiaomi M365 בצי שלנו מתנהג כך"_. שורה אחת לכל יצרן/תצורה.
- **רכב** (ברשימת [רכבים](../../operations/fleet/vehicles.md)) — יחידה פיזית עם תווית מדבקה כמו `RW-007`, קשורה למכשיר IoT אחד, חונה במקום כלשהו. מאות כאלה מצביעים על דגם יחיד.

כשאתה משנה דגם כאן, כל רכב שמצביע עליו יורש את ברירות המחדל החדשות — התעריפים הופכים לפעילים, מגבלות המהירות מתעדכנות, דרישות הוכחות בתמונות נכנסות לתוקף. התייחס לדף זה כשכבת מדיניות שמתפשטת למספר יחידות בבת אחת.

## מסננים

סרגל המסננים העליון כולל שלושה בקרים:

| מסנן       | סוג       | הערות                                                                              |
| ---------- | --------- | ---------------------------------------------------------------------------------- |
| **חיפוש**  | טקסט      | מחפש בתווית הדגם                                                                  |
| **סטטוס**  | תפריט נפתח | `הכל` / `פעיל` / `לא פעיל` / `בארכיון`                                           |
| **סוג**    | תפריט נפתח | `הכל` / `קורקינט חשמלי` / `אופניים חשמליים` / `אופניים חשמליים למטען` / `אפנוע חשמלי` / `רכב חשמלי` / `סירה חשמלית` |

שינוי כל מסנן מאפס את הדף לדף 1 וטוען מחדש מהשרת.

## פעולות בשורה

תפריט שלוש נקודות לכל שורה:

| פעולה           | הרשאה     | מה היא עושה                                                                                                                 |
| ---------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **הצג פרטים**  | —          | פותח את פרטי הדגם ב-`/settings/vehicle-rules/:id` (כרטיסיות כללי / טכני / היסטוריה)                                 |
| **ערוך**         | `edit`     | פותח את טופס העריכה (`/settings/vehicle-rules/:id/edit`) עם כל השדות המלאים                                             |
| **מחק**          | `delete`   | דיאלוג אישור הרסני עם השהייה של 3 שניות לפני הפעלת כפתור האישור. שורת הדגם נעלמת מהרשימה |

לחיצה על השורה עצמה (בכל מקום מחוץ לשבבי העריכה המהירה) מובילה ל-**הצג פרטים**.

## טופס יצירה / עריכה

`+ צור` (`/settings/vehicle-rules/create`) ו_ערוך_ (`/settings/vehicle-rules/:id/edit`) חולקים את אותה תצורה: כרטיס טופס משמאל, סרגל צד **מדריך שדות** הקשרי מימין עם תצוגה מקדימה חיה של הדגם.

הטופס מחולק למדורים — יצירה מציגה רק שבעת השדות המרכזיים; עריכה מוסיפה שלושה תת-מדורים נוספים (מפרט טכני, מדיניות אוטומטית, דרישות מסמכים) להגדרות מתקדמות.

### מדיניות אוטומטית (מצב עריכה בלבד)

החלף חבילה: **עצירת סוללה חלשה**, **עצירת יתרת חיוב נמוכה**, **נסיעות מרובות**, **נעילה אוטומטית**, בנוסף ל-**החזר אוטומטי** ו-**הנחה אוטומטית** עם ספים משלהן (מרחק / זמן / סכום).

### דרישות מסמכים (מצב עריכה בלבד)

מגדיר אילו תמונות / מסמכים על הרוכב להגיש:

- **הוכחות התחלה** — תמונות הרכב בתחילת הנסיעה (הפעלה + חובה + ספירה) ותמונת סלפי של הרוכב
- **הוכחות חניה** — תמונות חניה בסיום הנסיעה (הפעלה + חובה + ספירה)
- **מסמכים נוספים** — רישיון נהיגה / דרכון / תעודת זהות / סלפי / אחרים

כללים אלה נקראים על ידי אפליקציית הרוכב בעת התחלת / סיום נסיעה ברכב השייך לדגם זה.

## קשרים לישויות אחרות

- **[תעריפי רכב](vehicle-tariffs.md)** — שורות התמחור שאתה בוחר בשדה **תעריפים**. דגם ללא תעריפים לא יכול לתמחר נסיעה
- **[רכבים](../../operations/fleet/vehicles.md)** — יחידות פיזיות שמצביעות על דגם זה דרך שדה _דגם רכב_ בטופס [רכב](../../operations/fleet/vehicle-create-edit.md). הדגם מגדיר את המדיניות; הרכב מחזיק את ה-IoT, התווית והמיקום
- **תגיות** — תגיות ברמת הדגם שיורשות לכל רכב מדגם זה, בנוסף לתגיות ברמת הרכב שמוחלות ישירות על היחידה. נסיעות יורשות את שניהם בתחילת הנסיעה

## תהליכים טיפוסיים

- **הוספת דגם חדש** — `+ צור` → מלא תווית / סוג / סטטוס / תמונה → בחר את התעריפים החלים → שמור → פתח את הדגם החדש מהרשימה ולחץ על _ערוך_ כדי להגדיר מפרט טכני ומדיניות
- **הסרת דגם משימוש** — פתח את הדגם → _ערוך_ → הגדר סטטוס = _בארכיון_ → שמור. רכבים קיימים ממשיכים לפעול; הדגם פשוט לא מופיע יותר בבוחר יצירת הרכב
- **שינוי תעריפים בצי כולו** — ערוך את הדגם → החלף תעריפים → שמור. כל רכבי הדגם מתחילים לתמחר לפי התעריפים החדשים מהנסיעה הבאה
- **ייבוא בכמות לאחר הגירה** — ייצא משלב הביניים → ייבא את קובץ ה-JSON כאן → חבר מחדש תעריפים ותגיות ידנית על כל דגם חדש (הייבוא מסיר הפניות אלה בכוונה)
- **שינוי דרישות תמונות** — ערוך → דרישות מסמכים → הפעל / בטל הוכחות התחלה / חניה → שמור. אפליקציית הרוכב תטען את הכללים החדשים בתחילת הנסיעה הבאה

## טיפים

- **הגדר את התעריפים לפני הפיכת הסטטוס לפעיל** — דגם ללא תעריפים ידחה בקשות לתמחור נסיעה
- **השתמש ב'לא פעיל', לא ב'מחק', להסרת דגם** — לא פעיל מסתיר את הדגם מיצירת רכבים חדשים אך שומר היסטוריה שלמה. מחיקה היא בלתי הפיכה וחסומה על ידי עיכוב אישור של 3 שניות מסיבה
- **התמונה חשובה** — התמונה הממוזערת ברשימה ובוחרי הרכב של המפעיל משתמשים בתמונה זו. חתוך לריבוע עם רקע שקוף למראה הנקי ביותר
- **תגיות כאן הן ברמת הדגם, לא ברמת הרכב** — החלת תגית כאן תוסיף אותה לכל רכב מדגם זה. לתגיות ספציפיות ליחידה, ערוך את הרכב בנפרד
- **התראות מפרט טכני** — רזרבת הסוללה וגבולות המתח מזינים את טריגר _דורש בדיקה_; הגדרה צמודה מדי תוצף את תור ההתראות
- **סרגל הצד של מדריך השדות מתעדכן כשאתה מתמקד בשדה** — קרא אותו בפעם הראשונה שאתה יוצר דגם, הוא עדכני יותר מהמאמר הזה
