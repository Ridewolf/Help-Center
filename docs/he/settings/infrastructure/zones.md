# אזורים

דף האזורים (`/zones`) הוא המקום שבו אתה משרטט את **החוקים הבלתי נראים של אזור השירות שלך** — חניות, אזורי איסור, מהירות נמוכה, טעינה ופוליגונים אחרים שמשנים את התנהגות הרכבים והלקוחות כשחוצים גבול. כל אזור הוא פוליגון יחיד במפה בתוספת סוג, סטטוס, פרמטרים אופציונליים (מהירות, מחיר, קיבולת רכב) ותגיות.

האזורים מכתיבים את התנהגות הריצה בזמן אמת עבור [רכבים](../../operations/fleet/vehicles.md) — נכנסים לפוליגון איסור נסיעה והרכב מנותק; חונים בתוך פוליגון חניה בתשלום והתעריף נכנס לפעולה.

הרשאה נדרשת: **אזורים** (`u7v8w9`). תת-ההרשאות `create` / `edit` / `delete` מגבילות את הפעולות המתאימות.

## מהו אזור

לאזור יש ארבעה חלקים עיקריים:

1. **סוג** — קובע את הצבע ואת החוק שמיושם בזמן ריצה (ראה את הטבלה למטה)
2. **פוליגון** — פוליגון אחד מדויק, מצויר על המפה; צורות קעורות תקינות, חורים אינם מותרים
3. **פרמטרים** — תלויים בסוג: מהירות (מהירות נמוכה), מחיר (חניה בתשלום), סכום (טעינה), רכבים מותרים (חניה, חניה בתשלום, איזון מחדש)
4. **סטטוס** — `פעיל` (מופעל), `לא פעיל` (שמורה אך מתעלמים ממנה), `בארכיון` (מוסתר מרוב הרשימות)

### סוגי אזורים

| סוג              | צבע         | מה הוא עושה                                                        |
| ---------------- | ----------- | ------------------------------------------------------------------ |
| **אזור איסור**    | שחור        | רכבים אינם יכולים להיכנס או לפעול כאן                             |
| **איסור חניה**   | אדום        | רוכבים אינם יכולים לסיים נסיעה כאן                               |
| **איסור נסיעה**  | סגול        | רכבים מנותקים / מסרבים להתחיל בתוך הפוליגון הזה                  |
| **מהירות נמוכה** | כחול        | מהירות מקסימלית מוגבלת לערך `speed` המוגדר (קמ"ש)                   |
| **חניה**         | ירוק        | חניה ייעודית; קיבולת רכב אופציונלית                              |
| **חניה בתשלום**  | כתום        | חניה עם מחיר וקיבולת אופציונלית                                  |
| **טעינה**        | ירוק כהה    | אזור תגמול — `amount` מיושם כאשר רוכבים מסיימים כאן                  |
| **תחזוקה**       | אדום כהה    | סימון פנימי לתפעול; רכבים בתוך האזור אינם כלולים בזרימת הרוכבים |
| **איזון מחדש**   | כחול כהה    | אזור יעד לאיזון מחדש של הצי; קיבולת רכב אופציונלית               |

## מצבי תצוגה

קבוצת מתגים בכותרת הדף מחליפה בין שלוש תצוגות — אותם נתונים, עדשה שונה.

| מצב       | מתאים ל־                                                          |
| ---------- | ----------------------------------------------------------------- |
| **טבלה**  | עריכות בכמות גדולה, מיון לפי שם/סוג/סטטוס, גלישה עם דפים       |
| **כרטיסים** | סריקה ויזואלית עם מפת מיני לכל אזור; גלילה אינסופית             |
| **מפה**   | צפייה בכל האזורים משולבים על המפה האמיתית — שימושי לבדיקות כיסוי |

## מסננים

| מסנן    | סוג       | הערות                                  |
| ------- | --------- | -------------------------------------- |
| חיפוש   | טקסט      | מחפש בשם האזור ובתיאור                |
| סטטוס   | תפריט נפתח | `פעיל` / `לא פעיל` (או `הכל`)          |
| סוג     | תפריט נפתח | אחד מתוך 9 הסוגים (או `הכל`)           |

המסננים חלים על כל שלוש תצוגות התצוגה. תצוגת המפה מושכת **את כל** האזורים התואמים (ללא דפים); טבלה וכרטיסים מחולקים לדפים.

## עמודות (תצוגת טבלה)

| עמודה           | ניתן למיין? | תוכן                                                        |
| ---------------- | ----------- | ------------------------------------------------------------ |
| **שם האזור**    | ✓           | תווית + סמל צבעוני של הסוג; קישור לדף פרטי האזור           |
| **תיאור**       | —           | תיאור חופשי אופציונלי                                      |
| **סוג**          | ✓           | סמל צבעוני של הסוג (ראה טבלת הסוגים למעלה)                |
| **סטטוס**        | ✓           | `פעיל` / `לא פעיל` / `בארכיון`                             |
| **תגיות**        | —           | תגיות שהוחלו על האזור                                      |

## פעולות שורה

תפריט שלוש נקודות לכל שורה. הפעולות הזמינות תלויות בהרשאות:

| פעולה           | הרשאה     | מה היא עושה                                               |
| ---------------- | ---------- | ---------------------------------------------------------- |
| **הצג פרטים**  | —          | פותח את דף פרטי האזור (מפה + מטא-נתונים)                 |
| **ערוך**         | `edit`     | פותח את טופס העריכה של הגיאומטריה/המאפיינים              |
| **מחק**          | `delete`   | הסרה קבועה — דורש החזקת לחצן שלוש שניות לאישור          |

## פעולות בכמות גדולה

בחר שורות בתצוגת טבלה כדי להציג את סרגל הפעולות בכמות גדולה. כל פעולות השינוי בכמות גדולה דורשות את היכולת `edit`:

- **שנה סוג** — צובע מחדש אזורים רבים לסוג חדש בבת אחת (הפרמטרים מאופסים בהתאם)
- **שנה מגבלת רכב** — קובע `allowedVehicles` על כל הבחירה (רלוונטי לחניה / חניה בתשלום / איזון מחדש)
- **שנה ערך** — קובע את הערך המספרי הספציפי לסוג (מהירות / מחיר / סכום)
- **שנה סטטוס** — מחליף פעיל ↔ לא פעיל בכמות גדולה
- **שנה תגיות** — מוסיף או מחליף תגיות על כל הבחירה
- **ייצא נבחרים** — מוריד רק את האזורים המסומנים כ־JSON (אין צורך בהרשאה; בצד הלקוח)

## יצירה — אשף חמשת השלבים

`+ צור` פותח טופס מודרך. ניתן לקפוץ אחורה בחופשיות; קפיצות קדימה נפתחות רק כאשר השלב הנוכחי תקין.

1. **שם ותיאור** — `תווית` (נדרש) ו-`תיאור` אופציונלי
2. **סיווג** — `סוג` (נדרש, קובע את הצבע וצורת הפרמטר), `סטטוס` (פעיל / לא פעיל / בארכיון), `תגיות`
3. **פרמטרים** — קלטים מספריים ספציפיים לסוג עם מחוון 0–100 להזנה מהירה: מהירות (קמ"ש), מחיר, כמות, או רכבים מותרים. סוגים ללא פרמטרים מציגים הודעת "אין פרמטרים" ומאפשרים להתקדם
4. **גאומטריה** — צייר בדיוק **פוליגון אחד** על המפה. ניתן להציג אזורים קיימים כשכבת קווים מקווקווים כדי למנוע חפיפה. בקרות המפה: ציור, עריכה, הוספת נקודות, ביטול (עד 20 שלבים), מחיקה, זום, התאמת גבולות, איתור עצמי, מסך מלא
5. **סקירה** — סיכום סופי לקריאה בלבד של כל שדה כולל ספירת נקודות הפוליגון

שמירה יוצרת את האזור ומפנה אותך לדף הפרטים שלו.

## טופס עריכה

`ערוך` משתמש באותו מסגרת אך בטופס דף יחיד (ללא שלבים) — שנה את התווית, הסוג, הסטטוס, הפרמטרים, התגיות או צייר מחדש את הפוליגון, ואז שמור. שמירה מונעת אובדן שינויים לפני עזיבת הדף.

## ייבוא / ייצוא

שני כפתורי קווי מתאר ליד **+ צור**:

- **ייבוא** — בחר קובץ `.json` שיוצא קודם; לוח המחוונים מאמת את התוכן ויוצר אזורים בצד השרת. דורש את היכולת `create`
- **ייצוא** — פותח דיאלוג לבחירת מה להוריד: הדף הנוכחי, כל הדפים עם המסננים הנוכחיים, או הכל. סרגל הפעולות ההמוניות מציע גם "ייצא נבחרים" לשורות המסומנות

## דף פרטים

לחיצה על שורה (או _הצג פרטים_) פותחת את דף הפרטים של האזור עם:

- תצוגת מפה חיה של הפוליגון
- כרטיס מידע בסיסי (תווית, תיאור, סוג, סטטוס, צבע)
- כרטיס פרמטרים (מהירות / מחיר / כמות / רכבים מותרים, כשמתאים)
- תגיות
- תאריכי יצירה ועדכון
- כפתורי עריכה ומחיקה בכותרת (מוגבלים בהרשאות)

## תרחישי עבודה טיפוסיים

- **הקמת עיר חדשה** — ייבא חבילת JSON של אזורים אם יש לך, אחרת צייר תחילה את טבעת האיסור, ואז פוליגוני חניה בתוכה
- **התאמת אזור מהירות נמוכה** — ערוך → שלב 3 → הגדל את ערך המהירות → שמור. פעיל מיידית
- **סגירת חניון ליום אחד** — ערוך → סטטוס = לא פעיל → שמור. החזר לפעולה כשחניון נפתח מחדש
- **שינוי אזורים לאחר שינוי עירוני** — בחר בכמות את האזורים המושפעים → שנה סוג → אשר. פרמטרים ספציפיים ישנים מתאפסים אוטומטית
- **בדיקת כיסוי** — עבור לתצוגת מפה, סנן לפי סטטוס = פעיל, בדוק פערים וחפיפות

## טיפים

- **הסוג קובע הכל** — צבע, צורת פרמטר, חוק ריצה. בחירת סוג שגוי היא הסיבה השכיחה ביותר לתיקונים
- **פוליגון אחד לאזור** — חלק אזורים מורכבים לאזורים מרובים; העורך מחייב פוליגון יחיד
- **מותר חפיפה בין אזורים** — החוק המחמיר ביותר מנצח (איסור > אין נסיעה > מהירות נמוכה), אז אל תחששו להניח מהירות נמוכה בתוך פוליגון חניה
- **השתמשו בשכבת הקווים המקווקווים** — הפעל "הצג אזורים קיימים על המפה" בעורך כדי למנוע חפיפה מקרית עם שכנים
- **לא פעיל ≠ נמחק** — החלף סטטוס כשאתה רוצה להשעות אזור זמנית; מחיקה היא סופית (אישור החזקת 3 שניות הוא רשת בטחון)
- **תייגו את האזורים שלכם** — תגיות הן המסנן היחיד עם בחירה מרובה שנשמר בין מצבי תצוגה. השתמשו בהם לקיבוץ לפי שכונה, קמפיין או בעלות
- **ייצא לפני עריכות המוניות** — לחיצה בדיאלוג הייצוא מגבה את כל הסט, כך ששינוי המוני כושל הוא ייבוא אחד מהפוך ממנו
