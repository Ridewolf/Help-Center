# מכשירי IoT

דף ה-IoT (`/iot`) הוא **מלאי החומרה** — כל יחידת עוקב / מנעול שבבעלות הצי שלך, ללא קשר אם היא מחוברת כרגע לרכב. כל שורה היא מכשיר פיזי אחד המזוהה לפי **IMEI** שלו, עם טלמטריה חיה (מצב מקוון, איתור GPS, אות GSM, סוללה) שמתעדכנת מהפינג האחרון.

זהו המראה בצד המכשיר של [רכבים](../../operations/fleet/vehicles.md): רכב ללא IoT לא ניתן לעקוב או לשלוט עליו; IoT ללא רכב הוא חומרה לא משויכת שמונחת על המדף.

הרשאה נדרשת: **מכשירי IoT** (`n8p9q9`). תת-ההרשאות מגינות על `edit` / `send-command` / `delete` ופעולת ה_צור רכב_ ההמונית שואבת מ`operations.vehicles.create`.

## איך מכשירים מגיעים לכאן

המכשירים אינם מתגלים אוטומטית — אתה רושם אותם כשאתה מקבל משלוחים:

1. **רכש** — אתה קונה יחידות IoT מספק (Omni, Segway, Okai וכו'). לכל יחידה יש **IMEI** ייחודי המודפס על הקופסה / המדבקה
2. **+ צור** כאן — הזן שם, IMEI, ספק, סטטוס. המכשיר כעת במלאי אך לא משויך
3. **שייך לרכב** — נעשה מ[יצירה / עריכת רכב](../../operations/fleet/vehicle-create-edit.md) על ידי בחירת ה-IoT הזה בבורר המכשירים. IoT אחד לכל רכב, רכב אחד לכל IoT
4. **הטלמטריה מתחילה לזרום** ברגע שהמכשיר נדלק עם סים ומתחבר ל-broker של Ridewolf ב-MQTT. הרשימה מציגה את התמונה העדכנית ביותר — רענן או המתן לרענון אוטומטי

כחלופה, השתמש בפעולת ה_צור רכב_ ההמונית למטה כדי ליצור רכב חדש לכל IoT שנבחר במעבר אחד (למשל לאחר קליטת אצווה של קורקינטים חדשים).

## מסננים

| מסנן  | סוג       | הערות                                      |
| ------ | --------- | ------------------------------------------ |
| חיפוש  | טקסט      | מתאים לשם ו-IMEI                          |
| סטטוס  | תפריט נפתח | `הכל` / `פעיל` / `לא פעיל` / `בארכיון`   |

המסננים מסונכרנים עם כתובת ה-URL (רענון שומר את התצוגה שלך) ומאופסים לברירות המחדל דרך הקישור נקה בסרגל המסננים.

## עמודות

| עמודה           | ניתן למיין? | תוכן                                                                    |
| ---------------- | ----------- | ----------------------------------------------------------------------- |
| **שם**           | כן          | שם המכשיר + מזהה קצר; לחץ על השורה לפתיחת דף הפרטים                   |
| **מנעול**        | —           | סמל מצב המנעול (נעול / פתוח) מהפקודה האחרונה ב-MQTT                   |
| **מחובר**       | —           | נקודה ירוקה אם הפינג האחרון בתוך חלון הרענון; אדומה אם ישנה          |
| **GPS**          | —           | אינדיקטור תיקון תקין / לא תקין                                          |
| **GSM**          | —           | עוצמת אות (סולם 0-32, אדום ≤10, צהוב ≤20, ירוק ≤32)                   |
| **סוללה**       | כן          | אחוז סוללה עם פס צבעוני                                                |
| **סטטוס**       | כן          | סמל `פעיל` / `לא פעיל` / `בארכיון`                                    |
| **אות אחרון**   | כן          | זמן מאז חבילת הטלמטריה האחרונה (יחסי, למשל "לפני 5 דקות")            |

## פעולות שורה

תפריט שלוש נקודות לכל שורה. הפעולות הזמינות תלויות בהרשאות:

| פעולה             | הרשאה     | מה היא עושה                                                                |
| ------------------ | ---------- | --------------------------------------------------------------------------- |
| **הצג פרטים**    | —          | פותח את דף פרטי המכשיר (כרטיסיות פרטים / פעילות / פקודות / היסטוריה)    |
| **הצג מיקום**    | —          | פותח את קואורדינטות ה-GPS האחרונות בגוגל מפות (בלשונית חדשה)              |
| **ערוך**           | `edit`     | פותח את טופס העריכה (שם / IMEI / ספק / סטטוס)                            |
| **מחק**            | `delete`   | מסיר את רשומת המכשיר. האישור כולל השהייה של 3 שניות לפני פתיחת המנעול   |

## פעולות המוניות

בחר שורות מרובות (תיבת סימון בכותרת או בכל שורה) כדי להציג את סרגל ההמוני. הפעולות גם הן מוגבלות בהרשאות — אלה שאינך יכול לבצע מוסתרות, לא מושתקות:

| פעולה                      | הרשאה          | מה היא עושה                                                                                                         |
| --------------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------- |
| **צור רכב**                | `vehicles.create` | יוצר רכב חדש אחד לכל IoT שנבחר, עם שם אוטומטי שמתחיל בקידומת החברה שלך; בחר דגם רכב + תגיות אופציונליות           |
| **שנה סטטוס**             | `edit`            | קבע פעיל / לא פעיל / בארכיון לכל הנבחרים                                                                            |
| **בדוק חיבור (Beep)**      | `send-command`    | שלח פקודת `Beep` לכל מכשיר — שימושי לאיתור פיזי של יחידות במחסן                                                      |
| **שלח פקודה**              | `send-command`    | בחר פקודה מספק הבחירה הראשונה (פרה-סט או תהליך מתקדם רב-שלבי) ושלח לכולם                                         |
| **מחק**                    | `delete`          | מחיקה המונית עם דיאלוג אישור (השהיית אישור של 3 שניות)                                                              |

הפעולות ההמוניות מתבצעות ברצף עם התקדמות (`מעובד / סה"כ`) ולוח פריטים שנכשלו — הצלחה חלקית היא נורמלית, מכשירים שנכשלו נשארים מסומנים כדי שתוכל לנסות שוב או לבדוק.

## דף פרטים

לחיצה על שורה (או _הצג פרטים_) פותחת את דף פרטי המכשיר. ארבע כרטיסיות:

- **פרטים** — IMEI / ספק / סטטוס / קואורדינטות עם תצוגה מקדימה משולבת של Google Maps; בלוק טלמטריה מלא (מצב מהירות, תקינות GPS, ערך GSM גולמי, סוללה, מצב נעילה)
- **פעילות** — יומן פעילות כללי למכשיר זה (`entity-type=iot`)
- **פקודות** — שולח פקודות מודע לספק. אותו מנוע משמש בכרטיסיית הפקודות ב[פרטי רכב](../../operations/fleet/vehicle-detail.md) — ראה את המאמר ההוא לפרוצדורה / זרימה מתקדמת
- **היסטוריה** — היסטוריית טלמטריה / יומן חבילות

הכותרת מציגה את ה-רכב המקושר (אם קיים) כצ'יפ — לחיצה תעביר לדף הפרטים של הרכב. תפריט נפתח **פעולות** בכותרת מציע עריכה / הצגה ב-Google Maps / מחיקה.

## טופס יצירה / עריכה

טופס ה-IoT (`+ צור` או _עריכה_) כולל ארבעה שדות, כולם חובה:

- **שם** — תווית קצרה שתראה ברשימות (למשל `SCOOTER-014`). טקסט חופשי
- **IMEI** — מזהה החומרה הייחודי של המכשיר (משמש לקישור לרכב ולקבלת תעבורת MQTT). לאחר ההגדרה, יש להתייחס אליו כבלתי ניתן לשינוי — שינוי במכשיר פרוס יגרום להפסקת הטלמטריה עד לעדכון הקישור לרכב
- **ספק** — מחרוזת היצרן (למשל `omni`, `segway`). קובעת את מערך הפקודות שהמכשיר מבין — יש להיות מדויקים, חיפוש ספק רגיש לאותיות רישיות
- **סטטוס** — `פעיל` (ברירת מחדל) / `לא פעיל` (מוסתר מהבחירה לקישור לרכב) / `בארכיון` (חומרה מושבתת)

אין טופס מקומי לקישור לרכב כאן — כיוון זה מנוהל בטופס יצירה / עריכה של רכב.

## תהליכי עבודה טיפוסיים

- **הטמעת משלוח של 50 עוקבים** — צור כל אחד (או יבא דרך העלאת CSV, אם יש) → בחר את כולם → _צור רכב_ עם דגם הרכב הנכון → סיום; לכל IoT יש כעת רכב מקושר במצב `needs_investigation` מוכן לבדיקת איכות
- **מצא יחידה חסרה במחסן** — סנן לפי שם/IMEI → פעולה בשורה _בדוק חיבור (צפצוף)_ או צפצוף בכמות → סייר והאזין
- **הוצא מכשיר שבור משימוש** — ערוך → הגדר סטטוס = בארכיון (אל תמחק — יומן הפעילות נשמר). אם רכב היה מקושר, בטל את הקישור בטופס עריכת הרכב קודם
- **פריסת פקודות לכל הספק** (למשל הגדרת קושחה) — סנן לפי תבנית שם או טלמטריה, בחר את כולם → _שלח פקודה_ → בחר את פקודת הספק ותן לה לרוץ ברשימה עם התקדמות
- **חקור רכב "רפאים"** (מחובר אך אבוד) — הצג מיקום → אם GPS לא תקין, נסה צפצוף; אם עדיין שקט, חשוד ב-SIM / סוללה
- **השווה טלמטריה מול אירועים** — פתח את [דוח אירועים](../../analytics/reports/events.md) מסונן לפי רכב ה-IoT הזה כדי לקשר מצב חומרה עם פעילות בפלטפורמה

## טיפים

- **IMEI הוא מפתח הקישור** בכל מקום — קישור לרכב, ניתוב MQTT, כרטיסי תמיכה. הקלד פעם אחת, העתק לנצח
- **שדה הספק הוא מבני, לא קוסמטי** — הוא מכתיב את קטלוג הפקודות בכרטיסיית הפקודות. שגיאת כתיב ב-`omni` כמו `Omni` עלולה להניב רשימת פקודות ריקה
- **מחובר ≠ פעיל** — מחובר הוא אות טלמטריה חי; סטטוס הוא דגל מנהל. מכשיר פעיל יכול להיות מנותק (סוללה מתה, ללא GSM); מכשיר בארכיון עדיין יכול לשלוח פינגים עד שכבוי
- **שליחת פקודה בכמות משתמשת בספק של השורה הראשונה** — אם הבחירה שלך מערבת ספקים שונים, חלק אותם לאצוות חד-ספקיות או שתקבל רשימת פקודות מבלבלת
- **צור רכב מייצר בכוונה `needs_investigation` רכבים** — הם זקוקים לאישור אדם שהקישור נכון לפני הפעלה. תיוג בכמות במהלך היצירה מקל על מעבר בדיקת האיכות הבא
- **אין כפתור "כפה חיבור מחדש"** — אם הטלמטריה מפסיקה לאחר החלפה, בדוק קישור IoT ברכב (עריכת רכב) ואת ה-SIM / הספק של המכשיר, לא בדף זה
- **מכשירים בארכיון נשארים ניתנים לחיפוש לפי IMEI** — שימושי כשיחידה ישנה חוזרת מתיקון ואתה צריך להחזיר אותה לחיים (החזר ל-פעיל)
- **אות אחרון הוא בדיקת בריאות מהירה ביותר** — מיין בסדר יורד כדי למצוא מכשירים מיושנים ראשונים; כל דבר מעל 24 שעות בשורה פעילה שווה בדיקה
