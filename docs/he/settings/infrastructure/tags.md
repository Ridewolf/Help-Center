# תגיות

דף התגיות (`/settings/tags`) הוא **ספריית התוויות המשותפת** של החברה שלך. תגית היא תגית עם שם שניתן לצרף לרכבים, לקוחות, מפעילים, נסיעות ותשלומים כדי לסנן, לקבץ ולדווח עליהם. הרשימה כאן היא המקור האחד לאמת — כשאתה מוסיף תגית, היא זמינה בכל מקום שבו היא נתמכת.

הרשאה נדרשת: **תגיות** (`d1e2f3`). תת-ההרשאות מגבילות יצירה, עריכה ומחיקה.

## היכן משתמשים בתגיות

תגיות הן **מאגר גלובלי יחיד** — אין תחום לכל ישות בנפרד. אותה תגית יכולה להיות מצורפת לסוגי רשומות שונים:

- **[רכבים](../../operations/fleet/vehicles.md)** — לדוגמה "דורש ניקוי", "תחזוקה בעדיפות", "צי ניסוי"
- **[לקוחות](../../operations/customers/clients.md)** — לדוגמה "VIP", "חברה", "רשימת חסימה"
- **[מפעילים](../access/operators.md)** — לדוגמה "משמרת לילה", "מאמן", "זמין"
- **נסיעות** — מתויגות לסקירה, מחלוקת או מעקב קמפיין
- **תשלומים** — מתויגים לאישור או למעקב

כל רשומה יכולה לשאת מספר תגיות; סינון לפי תגית זמין בכל רשימה התומכת בכך.

## מסננים

| מסנן  | סוג   | הערות                                   |
| ------ | ------ | --------------------------------------- |
| חיפוש | טקסט | מחפש בשם התגית (התווית) ובתיאור       |

הרשימה מוגדרת כברירת מחדל ל-50 שורות לעמוד ומנקה את המסננים באמצעות הפעולה **נקה**.

## עמודות

| עמודה          | ניתן למיין? | תוכן                                                          |
| --------------- | --------- | -------------------------------------------------------------- |
| **שם תגית**    | כן        | אייקון תגית + תווית; קישור לדף הפרטים של התגית                |
| **סטטוס**      | כן        | `ציבורי` או `פרטי` (ראה למטה)                                |
| **תיאור**      | לא        | תיאור חופשי; מציין "אין תיאור" כאשר ריק                       |
| **תאריכים**   | כן        | תאריך יצירה למעלה, תאריך עדכון מתחת                           |

כותרת הדף מציגה גם **רענון אוטומטי**, **+ צור**, **ייבוא** (בקרוב) ו-**ייצוא** (הורדת JSON — העמוד הנוכחי, כל המסוננים או עמודים ספציפיים).

## פעולות שורה

תפריט שלוש נקודות לכל שורה. הפעולות הזמינות תלויות בהרשאות:

| פעולה           | הרשאה    | מה היא עושה                                                                                   |
| ---------------- | --------- | --------------------------------------------------------------------------------------------- |
| **הצג פרטים**  | —         | פותח את דף הפרטים של התגית                                                                   |
| **ערוך**         | `edit`    | פותח את טופס העריכה (תווית, סטטוס, תיאור)                                                  |
| **מחק**          | `delete`  | מסיר את התגית מהחברה. **רשומות שתויגו קודם יאבדו את הקישור** — יש להשתמש בזה בזהירות          |

מחיקה דורשת אישור עם החזקת לחצן למשך 3 שניות למניעת טעויות.

## דף פרטים

לחיצה על שורה (או _הצג פרטים_) פותחת את דף הפרטים של התגית עם:

- **מידע על התגית** — תווית, סטטוס, תיאור (מוצג עם תמיכה ב-Markdown)
- **מטא-נתונים** — מזהה פנימי, תאריכי יצירה / עדכון

עריכה ומחיקה זמינים גם מפעולות הכותרת בדף הפרטים.

## טופס יצירה / עריכה

**טופס התגית** (`+ צור` או _ערוך_) כולל שלושה שדות:

- **תווית** (נדרש) — שם התגית הנראה; חייב להיות ייחודי מספיק לזיהוי מהיר
- **סטטוס** (נדרש) — `ציבורי` או `פרטי`
  - **ציבורי** — גלוי וניתן לבחירה על ידי כל המפעילים בחברה
  - **פרטי** — נראות מוגבלת; שימושי לזרימות עבודה פנימיות/מנהליות בלבד
- **תיאור** (אופציונלי) — טקסט חופשי המסביר מתי להשתמש בתגית; מוצג בדף הפרטים

**תצוגה מקדימה** חיה בסרגל הצד מציגה כיצד תיראה התווית והתיאור בזמן ההקלדה. שמירה מאמתת שהתווית אינה ריקה, כותבת למאגר התגיות של החברה, ומרעננת את מטמון התגיות המשותף כך שדפים אחרים יטענו מחדש בפעם הבאה שיטענו.

## זרימות עבודה טיפוסיות

- **הוספת תווית חדשה** — `+ צור` → הקלד תווית → בחר ציבורי/פרטי → תאר מתי להשתמש (אופציונלי) → שמור → התגית זמינה מיד במסננים ובטפסי עריכה של רכבים / לקוחות / מפעילים
- **שינוי שם תגית** — ערוך → שנה תווית → שמור (כל הרשומות שכבר תויגו שומרות על הקישור; השם החדש מופיע בכל מקום)
- **הסרת תגית** — מחיקה מתפריט השורה, או קודם הגדר סטטוס לפרטי כדי להסתיר אותה מתיוג חדש תוך שמירת הקישורים ההיסטוריים (ואז תוכל לצרף מחדש רק בעריכה ישירה)
- **ניקוי כפילויות** — חפש ברשימה כדי לזהות כפילויות קרובות ("vip" לעומת "VIP") → ערוך אחת למיזוג השמות, ואז מחק את השנייה (הערה: רשומות תחת התגית שנמחקה יאבדו את הקישור — תייג אותן מחדש קודם)
- **ייצוא בכמות גדולה** — ייצא → כל המסוננים → הורדת JSON לשיתוף עם הצוות או לגיבוי הטקסונומיה

## טיפים

- **תגיות הן גלובליות** — אין מרחב שמות נפרד ל"תגיות לקוח" לעומת "תגיות רכב". תן להן שמות ברורים כך שתגית כמו "VIP" תהיה הגיונית על כל ישות שהיא מצורפת אליה, או השתמש בקידומות ("לקוח:vip", "רכב:תחזוקה") לשמירה על סדר
- **ברירת המחדל היא ציבורי** — השאר ציבורי אלא אם יש סיבה ספציפית להגביל נראות
- **מחיקה היא הרסנית** — כל רשומה הנושאת את התגית מאבדת את הקישור מיד; אין מחיקה רכה. העדף שינוי שם או מעבר לפרטי אם אינך בטוח
- **התיאור תומך ב-Markdown** בתצוגת הפרטים — השתמש בו לתיעוד מי ומתי צריך להחיל את התגית
- **מטמון משותף מתרענן בכל שמירה / מחיקה** — לשוניות פתוחות אחרות יקבלו את השינויים בניווט הבא שלהן, ללא טעינה מלאה
- **שמות תגיות מופיעים בכל מסנני ההקשר של Ridewolf** — שמור אותם קצרים וידידותיים לאותיות קטנות לחוויית משתמש מיטבית בטבלאות צפופות
