# תעריפי רכב

ספריית חוקי התמחור לצי Ridewolf שלך. **תעריף** הוא סט עצמאי של כללי תשלום — מחיר בסיס, דמי התחלת נסיעה, תעריף לפי מרחק, תעריף השהייה, תעריף הזמנה בתשלום, בנוסף לרמות הנחה ורשת בטיחות להחזר אוטומטי — שהמערכת משתמשת בהם כדי לחשב מה הרוכב משלם עבור נסיעה.

נמצא ב-`/settings/vehicle-tariffs`. הרשאה: **רשימת תעריפים** (`v1w2x3`).

## מהו תעריף

תעריף **אינו** מקושר ישירות לרכב — הוא מקושר ל-**דגם רכב** ב-[הגדרות רכב](vehicle-settings.md). השרשרת היא:

```
תעריף  →  דגם רכב  →  רכב  →  נסיעה
```

רשומת תעריף אחת כוללת:

- **זהות** — `שם`, `תיאור` (Markdown), `סטטוס` (פעיל / לא פעיל / בארכיון), `תגיות`
- **יחידת תמחור** — `סוג`: אחד מ-`per-minute`, `per-hour`, `per-day`, `per-month`. זה שולט ברמת הפירוט של החיוב (תמחור לדקה משתמש בחישוב ברמת השנייה; תמחור ליום/חודש משתמש בחיוב עגול — יחידה מלאה מחויבת מראש)
- **שדות תמחור** (כל הערכים הכספיים הם במטבע החברה שלך):
  - **מחיר בסיס** — עלות יחידת תמחור אחת (למשל דקה אחת, יום אחד)
  - **מחיר התחלת נסיעה** — דמי פתיחה קבועים שנגבים פעם אחת בתחילת הנסיעה
  - **מחיר למרחק** — עלות לכל ק"מ שנוסע
  - **מחיר השהייה** — חיוב לדקה בזמן שהנסיעה בהשהייה
  - **מחיר הזמנה בתשלום** — חיוב לדקה לאחר שפג חלון ההזמנה החינמית
  - **זמן הזמנה** — דקות הזמנה חינמיות לפני שההזמנה בתשלום מתחילה
- **רמות הנחה** — שלוש רמות אופציונליות (ראשונה / שנייה / שלישית). כל רמה היא _"אחרי N יחידות, החל X% הנחה"_, כך שנסיעות ארוכות יותר זולות יותר בהדרגה
- **החזר אוטומטי** — מתג + שני ספים (`distance` במטרים, `time` בשניות). כאשר מופעל, אם הרוכב מפסיק את הנסיעה לפני ששני הספים הושגו, המערכת מבטלת ומחזירה את התשלום — מגן על הרוכבים מחיוב על פתיחה שנכשלה

## היכן התעריף חל

1. מפעיל יוצר / עורך **תעריף** כאן
2. מפעיל מקשר את התעריף ל-**דגם רכב** ב-[הגדרות רכב](vehicle-settings.md)
3. רכבים המשויכים לדגם זה יורשים את התעריף
4. כאשר רוכב מתחיל נסיעה, המערכת **לוכדת צילום מצב של התעריף** ברשומת הנסיעה ומשתמשת בצילום זה לכל חישובי החיוב

> **צילום המצב הוא החלק הקריטי.** עריכה או מחיקה של תעריף לאחר מכן **אינה** משנה רטרואקטיבית נסיעות שהושלמו או בתהליך. הפירוט של הנסיעה שאתה רואה ב-[פרטי נסיעה](../../operations/trips/ride-detail.md) מחושב מערכי התעריף **כפי שהיו בתחילת הנסיעה** — כך Ridewolf שומרת על חיוב שניתן לבדיקה.

## מסננים

סרגל המסננים מעל הטבלה:

| מסנן       | סוג     | אפשרויות                                               |
| ---------- | ------- | ------------------------------------------------------- |
| **חיפוש**  | טקסט    | חופשי — מתאים לשם / תיאור                              |
| **סטטוס**  | בחירה   | כל הסטטוסים · פעיל · לא פעיל · בארכיון                 |
| **סוג**    | בחירה   | כל הסוגים · לדקה · לשעה · ליום · לחודש                 |

המסננים מושהים והטבלה נטענת מחדש מהעמוד הראשון בכל שינוי. מצב ה-URL מסונכרן — הדבק את ה-URL כדי לשתף את אותה תצוגה.

## עמודות

| עמודה          | ניתן למיין | הערות                                                                             |
| -------------- | ---------- | --------------------------------------------------------------------------------- |
| **שם**         | כן         | תווית התעריף                                                                      |
| **תיאור**      | כן         | מקוצר; טקסט מלא בהצבעה (Markdown מוצג במקום אחר)                               |
| **סוג**        | כן         | תגית מסגרת — `per-minute` / `per-hour` / `per-day` / `per-month`              |
| **מחיר**       | כן         | מחיר בסיס, מעוצב במטבע החברה שלך, בגופן חד-רוחבי                                  |
| **תגיות**      | לא         | עד 2 שבבי תגיות + `+N` עודף. לחיצה לפתיחת חלון עריכה מהירה                       |
| **סטטוס**      | כן         | תגית צבעונית (פעיל ירוק / לא פעיל אפור / בארכיון כחול). לחיצה לעריכה מהירה       |
| **נוצר**       | כן         | תאריך יצירה                                                                      |
| **עודכן**      | כן         | תאריך עדכון אחרון                                                                |

המיון הוא **בצד הלקוח** — פועל על העמוד הנוכחי.

## פעולות בכותרת

- **רענון אוטומטי** — מרענן את הרשימה (לחיצה ידנית או בפרק זמן, ראה [רענון אוטומטי](../../features/ux/notifications.md))
- **ייצוא** — פותח את דיאלוג הייצוא (העמוד הנוכחי · כל המסוננים · עמודים ספציפיים). הפלט הוא קובץ `vehicle-tariffs-export.json`
- **+ צור** — פותח את טופס היצירה. נראה רק אם יש לך את תת-ההרשאה **צור תעריף**

## פעולות בשורה

תפריט `⋯` בכל שורה:

- **הצג פרטים** — פותח את `/settings/vehicle-tariffs/:id` (זמין תמיד)
- **ערוך** — פותח את `/settings/vehicle-tariffs/:id/edit` (דורש תת-ההרשאה `edit`)
- **מחק** — פותח אישור עם החזקה של 3 שניות; באישור התעריף נמחק (דורש תת-ההרשאה `delete`)

> **מחק בזהירות.** דגמי רכב שמצביעים לתעריף שנמחק יצטרכו שיוקצו לתעריף אחר לפני שניתן יהיה להתחיל נסיעות חדשות על אותם רכבים. רשומות נסיעה קיימות שומרות על צילום המצב שלהן ללא שינוי.

## עריכה מהירה (תגיות / סטטוס)

לחץ ישירות על שבבי **תגיות** או תגית **סטטוס** בכל שורה → נפתח דיאלוג קטן שמאפשר לשנות רק את השדות האלה בלי להיכנס לטופס העריכה המלא. הודעת אישור מוצגת; הטבלה מתעדכנת.

## טופס יצירה / עריכה

גם `/settings/vehicle-tariffs/create` וגם `/settings/vehicle-tariffs/:id/edit` משתמשים באותו פריסת טופס: כרטיס שמאלי עם שדות הקלט, סרגל צד ימין **מדריך שדות** עם עזרה קונטקסטואלית ו**תצוגה מקדימה חיה** של הערכים שהזנת (שם, סוג, מחיר בסיס, התחלה/מרחק, השהייה, הזמנה, תגיות, רמות הנחה).

### שדות חובה

| שדה           | חובה     | אימות                                    |
| -------------- | -------- | ----------------------------------------- |
| **שם**         | כן       | לא ריק                                  |
| **סוג**        | כן       | אחד מתוך 4 אפשרויות                      |
| **סטטוס**      | כן       | אחד מתוך `active` / `inactive` / `archived` |
| **מחיר בסיס**  | כן       | `>= 0`                                    |

כל שדות הכסף האחרים מוגדרים כברירת מחדל ל-`0` ומקבלים `0` (בעצם "תכונה מנוטרלת").

### חלקים

1. **זהות** — שם, תיאור (Markdown), סוג, סטטוס, תגיות
2. **תמחור** — מחיר בסיס, מחיר התחלת נסיעה, מחיר לפי מרחק, מחיר הפסקה, מחיר הזמנה בתשלום, זמן הזמנה (בדקות)
3. **החזר אוטומטי** — מתג. כשהוא מופעל, מלא `מרחק` (במטרים) ו`זמן` (בשניות). יש לעבור את שני הספים לפני שהנסיעה נחשבת כמתחילה; אחרת היא מתבטלת אוטומטית עם החזר
4. **רמות הנחה** — שלוש רמות. כל אחת: `אחוז הנחה` (0-100) ו`אחרי יחידות` (כמה יחידות תמחור חייבות לעבור לפני שההנחה מופעלת). השאר רמה באפסים כדי לדלג עליה

### התנהגות שמירה

- **צור** → הודעת "נוצר", מפנה לדף הפרטים
- **ערוך** → הודעת "עודכן", מפנה לדף הפרטים
- **שינויים לא שמורים** מתועדים באמצעות השוואת תמונת מצב. יציאה מהדף (ביטול / חזור) פותחת תיבת אישור אם משהו השתנה

> **מיפוי סטטוס בשרת.** ערך `archived` בטופס נשלח לשרת כ-`deleted` — זה השם הפנימי. מפעילים רואים `archived` בכל ממשק המשתמש.

## דף פרטים

`/settings/vehicle-tariffs/:id` מציג כותרת עם תווית התעריף, תג סטטוס, פעולות **ערוך** ו-**מחק**, שלוש כרטיסיות סטטיסטיקה (סטטוס / נוצר / עודכן), ואז כרטיס **פרטים** עם:

- שדות זהות (שם, סוג, סטטוס, מחיר בסיס, תאריכים)
- **תיאור** מוצג מ-Markdown
- **תמחור** — תצוגת רשת של כל 5 התעריפים הכספיים (`TariffPriceGrid`)
- **החזר אוטומטי** — תג מופעל/מנוטרל, ועוד שני הספים אם פעיל
- **רמות הנחה** — פירוט חזותי של שלוש הרמות (`TariffDiscountTiers`)
- **תגיות** — שבבי תגיות מפוענחות (רק אם הוגדרו)
- **מידע מערכת** — מזהה מלא, חותמות זמן יצירה/עדכון

## כיצד תמונת המצב מייצרת את פירוט הנסיעה

כשאתה פותח [פרטי נסיעה](../../operations/trips/ride-detail.md), כרטיס **פירוט** מחושב מ:

- `ride.tariff` — תמונת המצב המוטמעת בנסיעה בזמן ההתחלה
- טלמטריה חיה של הנסיעה (משך, מרחק, זמן הפסקה, זמן הזמנה)

החישוב שהשרת משכפל מקומית:

- **בסיס** — `יחידות × מחיר בסיס`, כאשר `units` = שניות שעברו (לפי דקה) או ימים/חודשים מעוגלים לסוגים מבוססי עיגול
- **דמי פתיחה** — סכום קבוע `מחיר התחלת נסיעה`, מחויב פעם אחת
- **מרחק** — `ק"מ × מחיר מרחק`
- **הפסקה** — `דקות הפסקה × מחיר הפסקה`
- **הזמנה** — הדקות הראשונות של `זמן הזמנה` חינם, אחר כך `דקות בתשלום × מחיר הזמנה בתשלום`
- **רמות הנחה** מוחלות מעל לאחר שעוברים את הספים

אם תתקן טעות בתעריף היום, **נסיעות אתמול לא יושפעו** — הפירוט שלהן עדיין מציג את המספרים הישנים כי תמונת המצב היא המקור האמין.

## זרימות עבודה

- **השקת תעריף חדש** — צור את התעריף (סטטוס `לא פעיל`) → בדוק עם הפיננסים → הפעל ל`פעיל` → קשר לדגם הרכב הרלוונטי ב[הגדרות רכב](vehicle-settings.md)
- **מבצע עונתי** — שכפל תעריף קיים (ידני: צור חדש + העתק שדות), שנה את `מחיר בסיס`, תן שם עם תאריך (למשל `קיץ 2026 — קורקינט`), קשר לדגם לתקופת המבצע, החזר אחורה לאחר מכן
- **כוונון החזר אוטומטי** — התחל בספים שמרניים (מרחק קטן + זמן קצר) כדי שלא יחויבו פתיחות כושלות, ואז הרפה אם רואים החזרים חיוביים שגויים ב[נסיעות](../../operations/trips/rides.md)
- **פרישת תעריף ישן** — הגדר סטטוס ל`בארכיון` (נשלח כ-`deleted` לשרת) ברגע שאין דגם רכב שמפנה אליו. נסיעות ישנות שומרות את תמונות המצב שלהן — אפשר לארכב בבטחה
- **שינוי שם להבהרה** — השם הוא רק תווית. שינויי שם משפיעים על תמונות מצב של נסיעות חדשות מהנקודה הזו; נסיעות שהסתיימו שומרות את השם הישן בפירוט

## טיפים

- **תמונת מצב, תמונת מצב, תמונת מצב** — כשיש ספק לגבי מחיר נסיעה היסטורית, בדוק את `ride.tariff.*` ב[פרטי נסיעה](../../operations/trips/ride-detail.md), לא את התעריף הנוכחי ברשימה זו
- **אל תמחק — ארכב במקום זאת** — תעריפים בארכיון נשארים במסד הנתונים (הם נמחקים רך בצד השרת) ועדיין ניתנים לפיענוח מתמונות מצב ישנות. מחיקה קשה מתאימה לטיוטות שלא שומשו
- **השתמש בתצוגה מקדימה של מדריך השדות** — הסרגל הימני מציג את הסכומים המחושבים תוך כדי הקלדה, זו הדרך המהירה לבדוק תעריף חדש לפני שמירה
- **הסוג חשוב לחישוב** — מעבר מ-`per-minute` ל-`per-hour` לא משנה אוטומטית את `מחיר בסיס`; יש לחשב מחדש ידנית (דקה אחת ב-€0.20 ≠ שעה אחת ב-€0.20)
- **רמות הנחה הן עוקבות** — `אחרי` נמדד באותן יחידות כמו `סוג`. רמה עם `אחרי: 30, הנחה: 10 %` בתעריף `per-minute` פירושה "ממהדקה 30 והלאה, מחייבים 90 % ממחיר הבסיס". שלוש הרמות נערמות לפי הסדר — הגבוהה ביותר החלה
- **תייג את התעריפים שלך** — תגיות עוברות לדגם הרכב ועוזרות לסנן ברשימה זו. תוויות נפוצות: `קורקינט`, `אופניים`, `מבצע`, `ישן`
