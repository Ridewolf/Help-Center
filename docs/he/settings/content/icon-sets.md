# סטים של אייקונים

דף סטים של אייקונים (`/settings/icon-sets`) הוא **ספריית אייקוני המפה** שאפליקציית Rider של Ridewolf משתמשת בה להצגת רכבים. כל סט קשור לסוג רכב אחד (קורקינט חשמלי, אופניים חשמליים, אופניים חשמליים למטען, אופנוע חשמלי, רכב חשמלי, סירה חשמלית) ומספק שלוש קטגוריות של אייקוני SVG: **נבחרים**, **לא נבחרים**, ו-**הנחה**.

זו תשתית תוכן — מפעילים מעלים SVG כאן, אפליקציית הרוכב בוחרת את האייקון המתאים לפי סוג הרכב, רמת הסוללה, והאם הרוכב לחץ על הרכב במפה. אין צורך בשחרור גרסה חדשה של האפליקציה כדי להחליף את האמנות.

יחד עם [FAQ Sets](faq-sets.md) ו-[Quick Guides](quick-guides.md), זו שכבת התוכן של לוח המחוונים.

הרשאה נדרשת: **סטים של אייקונים** (יש לבדוק עם מנהל).

## היכן זה מופיע לרוכב

במפת אפליקציית הרוכב, כל סמן רכב משתמש באייקון מהסט הפעיל לסוג הרכב שלו:

- אייקוני **לא נבחרים** משמשים לסמנים שהרוכב לא לחץ עליהם — שישה רמות סוללה (`bat10`, `bat25`, `bat40`, `bat55`, `bat90`, `bat100`) כך שהסמן משקף את הטעינה הנוכחית
- אייקוני **נבחרים** מחליפים את הסמן ברגע שהרוכב לוחץ עליו — אותן שש רמות סוללה, בסגנון שונה
- אייקוני **הנחה** (5%, 15%, 25%, 35%, 45%, 55% כברירת מחדל) מצטלבים על הסמן כשהרכב במחיר מבצע

ניתן לסמן סט אחד לכל סוג רכב כ-**ברירת מחדל** — זה הסט שהאפליקציה טוענת כשאין הגדרה אחרת.

## מסננים

| מסנן           | סוג       | הערות                                                                                                            |
| -------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| חיפוש          | טקסט     | תיבת חיפוש בכותרת — מחפש בכותרת / מזהה                                                                         |
| סוג רכב        | תפריט נפתח | `קורקינט חשמלי` / `אופניים חשמליים` / `אופניים חשמליים למטען` / `אופנוע חשמלי` / `רכב חשמלי` / `סירה חשמלית` (או `הכל`) |
| כיסוי מצב     | תפריט נפתח | סינון לפי מה שממולא: `רק נבחרים` / `רק לא נבחרים` / `רק הנחות` / `כיסוי מלא` (או `הכל`)                        |
| סטטוס          | תפריט נפתח | `פעיל` / `טיוטה` / `לא שלם` / `בארכיון` (או `הכל`)                                                             |
| תגיות          | תיבת בחירה | סינון תגיות חופשי (שדה קלט מוצג אך כרגע מושבת — בקרוב)                                                        |

**נקה הכל** מאפס את כל המסננים.

## עמודות

| עמודה                 | תוכן                                                                   |
| ---------------------- | ------------------------------------------------------------------------- |
| **סט**                | אייקון חבילה + כותרת; שורה משנית מציגה מזהה                           |
| **סוג רכב**            | תגית (קורקינט חשמלי, אופניים חשמליים וכו')                            |
| **אייקונים נבחרים**   | כיסוי כמו `6/6` (כמה רמות סוללה הועלו)                                |
| **אייקונים לא נבחרים** | אותו כיסוי `n/6` עבור וריאנטים לא נבחרים                           |
| **אייקוני הנחה**       | שלושת אחוזי ההנחה הראשונים כתגיות (`5%`, `15%`, `25%`), `+N` עודף          |
| **תגיות**              | שתי תגיות ראשונות עם `+N` עודף                                       |
| **עודכן לאחרונה**      | תאריך העדכון האחרון                                                   |
| **סטטוס**              | `פעיל` / `טיוטה` / `לא שלם` / `בארכיון`                            |

`לא שלם` פירושו שהסט חסר אייקונים באחת משלוש הקטגוריות — אפליקציית הרוכב תחזור לברירת המחדל לסוג הרכב הזה עד שתסיים את ההעלאה.

לחץ על שורה כדי לפתוח את **תיבת הדו-שיח לפרטים** — תצוגה ויזואלית של כל אייקון בסט. לחץ על תפריט שלוש הנקודות לפעולות.

## פעולות שורה

| פעולה              | מה היא עושה                                                                      |
| ------------------ | --------------------------------------------------------------------------------- |
| **הצג פרטים**     | פותח את תיבת הדו-שיח עם תצוגות מקדימות של כל SVG שהועלה                        |
| **ערוך**            | פותח את הטופס הרב-כרטיסי (פרטים / נבחרים / לא נבחרים / הנחות / תצוגה מקדימה) |
| **שכפל**           | משכפל את הסט כטיוטה                                                            |
| **קבע כברירת מחדל** | מסמן סט זה כברירת מחדל לסוג הרכב שלו — אפליקציית הרוכב תטען אותו              |
| **הורד**            | מוריד את הסט כקובץ ZIP של כל קבצי ה-SVG                                       |
| **ארכיב**           | מעביר ל-`בארכיון` — נשמר להיסטוריה, לא בשימוש על ידי האפליקציה                 |
| **מחק**             | מסיר לצמיתות                                                                  |

כפתורי **ייבא** (ZIP / JSON) ו-**ייצא** (ZIP / JSON) בסרגל העליון עובדים בכמות גדולה.

## טופס יצירה / עריכה

הטופס הוא תיבת דו-שיח עם חמישה כרטיסים:

1. **פרטים** — כותרת (נדרשת), מזהה (נוצר אוטומטית), סוג רכב (נדרש), תגיות, סטטוס
2. **נבחרים** — העלאת 6 קבצי SVG, אחד לכל רמת סוללה (`bat10` → `bat100`)
3. **לא נבחרים** — אותם 6 מקומות, למצב המפה הלא נבחר
4. **הנחות** — קובץ SVG אחד לכל אחוז הנחה. ברירות המחדל הן `5, 15, 25, 35, 45, 55` אך ניתן להוסיף/להסיר שורות
5. **תצוגה מקדימה** — בדיקת תקינות ויזואלית של כל הסט לפני השמירה

סט עם מקומות ריקים בכל כרטיס נשמר כ-`לא שלם`.

## תהליכי עבודה טיפוסיים

- **רענן את הסמלים של הקורקינטים החשמליים עבור מיתוג מחדש** — שכפל את ברירת המחדל הנוכחית → העלה קבצי SVG חדשים בכל שלושת הלשוניות → שמור כטיוטה → תצוגה מקדימה → הגדר כברירת מחדל → אפליקציית הרוכב תטען אותם ברענון הבא
- **הרץ בדיקת A/B על האייקונים** — השאר את הסט הישן פעיל ולא כברירת מחדל, צור סט חדש כפעיל + ברירת מחדל לסוג רכב → חזור אחורה על ידי הגדרת הישן כברירת מחדל במידת הצורך
- **גרפיקה להנחות בחגים** — פתח את הסט הפעיל → ערוך → לשונית הנחות → העלה קבצי SVG עם נושא עבור האחוזים שבשימוש כרגע → שמור
- **ייבוא בכמות גדולה של קובץ ZIP של מעצב** — בפינה הימנית העליונה _ייבא_ → ZIP → אשר את מיפוי הקבצים → סקור בתצוגה מקדימה → הפעל

## טיפים

- **ברירת מחדל אחת לכל סוג רכב** — הגדרת ברירת מחדל חדשה מבטלת אוטומטית את הקודמת. תג הסטטוס לא חייב להיות `פעיל` כדי שהסט יהיה ברירת מחדל, אבל רצוי שיהיה
- **רמות סוללה קבועות** — `bat10/25/40/55/90/100` הן היחידות שהאפליקציה מבינה; האפליקציה בוחרת את הקרובה ביותר לפי טעינת הרכב בזמן אמת
- **רק SVG** — ההעלאות מצפות לקבצי SVG; קבצי PNG לא יותאמו היטב למסכי רטינה
- **`לא שלם` הוא מגבלה שימושית** — הוא מודיע שהאפליקציה חוזרת לברירת המחדל, כך שלא תשלח בטעות סט שהועלה חלקית
- **ארכוב לפני מחיקה** — סטים בארכיון נשארים ניתנים לחיפוש למקרה שתרצה לחזור אחורה
