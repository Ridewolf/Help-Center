# מדריכים מהירים

דף המדריכים המהירים (`/settings/quick-guides`) מכיל את **המדריכים שלב אחר שלב** שאפליקציית הרוכב של Ridewolf מציגה עבור דברים כמו "איך לשכור קורקינט" או "רשימת בדיקת בטיחות". כל מדריך הוא רשימה מסודרת של פריטים עם אייקון, צבע, כותרת וטקסט גוף — מפורסם לפי קהל יעד (אפליקציית רוכב, אפליקציית לקוח, מכונאי, מנהל, כללי).

יחד עם [סטים של שאלות נפוצות](faq-sets.md) (בלוקי שאלות ותשובות) ו-[סטים של אייקונים](icon-sets.md) (אמנות מפה), מדריכים מהירים הם העמוד השלישי בשכבת התוכן. ערוך מדריך כאן, אפליקציית הרוכב תטען את השינוי בפעם הבאה שתמשוך נתונים — אין צורך בשחרור אפליקציה.

הרשאה נדרשת: **מדריכים מהירים** (בדוק עם מנהל).

## היכן זה מופיע לרוכב

באפליקציית הרוכב לנייד, מדריכים מהירים מפעילים את מדריכי ההיכרות ואת מסכי הטיפים במהלך הנסיעה. כל מדריך מסוג **rider-app** ובסטטוס `active` נטען; פריטים המסומנים `visible` מופיעים ב-`order`, עם `icon` ו-`color` המוגדרים משמאל, וטקסט `body` מורחב אם `expandByDefault` הוא אמת.

מדריכים מסוגים `client-app`, `mechanic`, `admin`, `general` מחוברים לממשקים המתאימים להם.

## מסננים

| מסנן   | סוג          | הערות                                                                   |
| ------ | ------------ | ----------------------------------------------------------------------- |
| חיפוש  | טקסט         | תיבת חיפוש בכותרת — מחפש בכותרת / תיאור / סלאג                        |
| תגיות  | בחירה מרובה  | סינון לפי תגיות (היכרות, יסודות, טכני, תשלומים, …)                    |
| סטטוס  | תפריט נפתח  | `פעיל` / `טיוטה` / `בארכיון` (או `הכל`)                               |
| סוג    | תפריט נפתח  | `אפליקציית לקוח` / `אפליקציית רוכב` / `מכונאי` / `מנהל` / `כללי` (או `הכל`) |

**נקה הכל** מאפס את כל המסננים.

## עמודות

| עמודה       | תוכן                                                                |
| ----------- | ------------------------------------------------------------------ |
| **סט**     | אייקון ספר + כותרת; שורה משנית מציגה תיאור או סלאג                 |
| **סוג**    | תגית קהל יעד — אפליקציית לקוח / אפליקציית רוכב / מכונאי / מנהל / כללי |
| **תגיות**  | שלוש תגיות ראשונות, עם `+N` עודף                                |
| **פריטים** | מספר השלבים במדריך                                               |
| **סטטוס** | `פעיל` (ירוק) / `טיוטה` (אפור) / `בארכיון` (מעומעם)              |
| **עודכן** | תאריך יחסי; ריחוף להצגת חותמת זמן מלאה + מחבר                     |

לחץ על שורה כדי לפתוח את תיבת הדו-שיח **הצג** (תצוגה מקדימה של כל שלב). לחץ על תפריט שלוש הנקודות לפעולות.

## פעולות שורה

| פעולה           | מה היא עושה                                                        |
| ---------------- | ------------------------------------------------------------------ |
| **הצג פרטים**  | תצוגה מקדימה עם כל פריט מוצג כפי שהרוכב יראה אותו                 |
| **ערוך**         | פתח את טופס הדו-שיח (כמו יצירה, מלא מראש)                        |
| **שכפל**        | שכפל את המדריך עם סלאג עם סיומת `-copy` ואיפוס סטטוס ל-`טיוטה`  |
| **ייצא**         | הורדה כ-ZIP או JSON                                                |
| **ארכיב**        | העבר ל-`בארכיון` — מוסתר מאפליקציית הרוכב, נשמר להיסטוריה         |
| **מחק**          | הסר לצמיתות                                                     |

בכלי העליון **ייבא** (ZIP / JSON) ו-**ייצא** (ZIP / JSON) פועלים בכמות גדולה.

## טופס יצירה / עריכה

לטופס יש את אותם בוחרים ברמה העליונה כמו בסטים של שאלות נפוצות, בתוספת עורך עשיר יותר לכל פריט:

- **סוג** — חובה, מגדיר מי רואה את המדריך
- **סטטוס** — `טיוטה` / `פעיל` / `בארכיון`
- **תגיות** — בחירה מרובה
- **כותרת / תיאור** — כותרת חובה, תיאור אופציונלי
- **פריטים** — רשימת השלבים. כל פריט כולל:
  - **כותרת** — כותרת השלב
  - **גוף** — תוכן השלב (טקסט רגיל, ארוך)
  - **אייקון** — שם אייקון Lucide (למשל `MapPin`, `QrCode`, `Shield`)
  - **צבע** — צבע הקס עם הגדרות מותג (ראשי `#6366f1`, הצלחה `#22c55e`, אזהרה `#eab308`, סכנה `#ef4444`, וכו')
  - **הרחב כברירת מחדל** — אם מופעל, הפריט נפתח מורחב באפליקציה
  - **נראה** — מתג להסתיר פריט בלי למחוק
  - **סדר** — גרור לשינוי סדר

הסלאג נגזר מהכותרת ומשמש ב-URL של ה-API.

## זרימות עבודה טיפוסיות

- **כתוב מדריך היכרות חדש** — `+ צור מדריך` → סוג = אפליקציית רוכב, סטטוס = טיוטה → הוסף 5–7 פריטים מסודרים עם אייקונים + צבעים → תצוגה מקדימה דרך הצג פרטים → הפוך ל-פעיל → מופיע באפליקציית הרוכב בפעם הבאה שתמשוך נתונים
- **הפוך שלב לאופציונלי / הסתר אותו** — ערוך → כבה את `נראה` על הפריט → שמור (הפריט נשאר בנתונים, פשוט לא מוצג)
- **בצע A/B טסט למדריך חדש** — שכפל את המדריך הפעיל → ערוך את העותק → ארכב את הישן והפעל את החדש יחד
- **ייבא בכמות גדולה טיוטת מעצב** — ייבוא עליון ימני _ייבא_ → ZIP/JSON → אשר מבנה מפוענח → ייבא כטיוטה → סקור והפעל

## טיפים

- **אייקונים הם שמות Lucide** — בחר מ-[lucide.dev](https://lucide.dev) כדי שיוצגו באפליקציה; שמות אייקונים שגויים יחזרו לממלא מקום
- **צבע את השלבים לנוחות סריקה** — רוכבים סורקים מדריכים. השתמש באזהרה עבור שלבי "זהירות" ובהצלחה עבור מצבים "בוצע"
- **`expandByDefault` מיועד בדרך כלל לשלב הראשון בלבד** — פתיחת כל הפריטים כברירת מחדל מבטלת את מטרת האקורדיון. השאר את השאר מקופלים
- **טקסט הגוף הוא פרוזה רגילה, לא Markdown** — שמור על פסקאות קצרות; אפליקציית הנייד מגדירה את הטיפוגרפיה
- **ארכב במקום למחוק** כשפורש מדריך — תמיד תוכל להפעיל מחדש או לשכפל אותו מאוחר יותר
- **השתמש בתגיות בהתמדה עם [סטים של שאלות נפוצות](faq-sets.md)** — `onboarding`, `troubleshooting`, וכו' הן אוצר מילים משותף בשכבת התוכן
