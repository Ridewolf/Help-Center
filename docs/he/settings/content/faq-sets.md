# סטים של שאלות נפוצות

דף סטים של שאלות נפוצות (`/settings/faq-sets`) הוא **ספריית שאלות ותשובות** המוצגת בתוך אפליקציות Ridewolf — בעיקר באפליקציית הנוסע לנייד, אך גם בממשקים הפונים למפעיל. כל סט הוא חבילה של פריטי שאלות/תשובות המיועדים לקהל יעד אחד (אפליקציית נוסע, אפליקציית לקוח, מכונאי, מנהל או כללי).

יחד עם [מדריכים מהירים](quick-guides.md) ו[סטים של אייקונים](icon-sets.md), דף זה הוא חלק משכבת התוכן — מה שמפעיל משנה כאן הוא מה שנוסע רואה בטלפון שלו, ללא צורך בשחרור גרסה חדשה של האפליקציה לנייד.

הרשאה נדרשת: **סטים של שאלות נפוצות** (יש לבדוק עם מנהל).

## היכן זה מופיע לנוסע

באפליקציית הנוסע לנייד, סטים של שאלות נפוצות תומכים בסעיף העזרה / שאלות נפוצות בתוך האפליקציה. כל סט מסוג **rider-app** ובסטטוס `active` נטען באפליקציה; פריטים המסומנים `visible` מופיעים, ממוינים לפי שדה `order`. סטים מסוג `client-app`, `mechanic`, `admin`, `general` מיועדים לאפליקציות / ממשקים המתאימים להם.

סט מסוג `draft` או `archived` לעולם לא מוצג — שימושי לשלב שינויים לפני פרסום.

## מסננים

| מסנן   | סוג          | הערות                                                                    |
| ------ | ------------ | ------------------------------------------------------------------------ |
| חיפוש  | טקסט         | תיבת חיפוש בכותרת — מחפש בכותרת / תיאור / סלאג                         |
| תגיות  | בחירה מרובה  | סינון לפי תגיות שהוחלו על הסט (הכשרה, תשלומים, טכני, …)                |
| סטטוס  | תפריט נפתח   | `פעיל` / `טיוטה` / `בארכיון` (או `הכל`)                                |
| סוג    | תפריט נפתח   | `אפליקציית לקוח` / `אפליקציית נוסע` / `מכונאי` / `מנהל` / `כללי` (או `הכל`) |

**נקה הכל** מאפס את כל המסננים בבת אחת.

## עמודות

| עמודה       | תוכן                                                                |
| ----------- | ------------------------------------------------------------------ |
| **סט**     | אייקון + כותרת; שורה משנית מציגה תיאור או סלאג                    |
| **סוג**    | תגית קהל יעד — אפליקציית לקוח / אפליקציית נוסע / מכונאי / מנהל / כללי |
| **תגיות**  | שלוש תגיות ראשונות, עם `+N` להמשך                              |
| **פריטים** | מספר שדות שאלות/תשובות בסט                                       |
| **סטטוס** | `פעיל` (ירוק) / `טיוטה` (אפור) / `בארכיון` (מעומעם)              |
| **עודכן** | תאריך יחסי; ריחוף מציג חותמת זמן מלאה + מחבר                      |

לחץ על שורה כדי לפתוח את תיבת הדו-שיח **הצג** (תצוגה לקריאה בלבד). לחץ על תפריט שלוש הנקודות לפעולות.

## פעולות שורה

| פעולה           | מה היא עושה                                                        |
| ---------------- | ------------------------------------------------------------------ |
| **הצג פרטים**  | תצוגה לקריאה בלבד עם כל פריטי השאלות/תשובות מוצגים               |
| **ערוך**         | פותח את טופס הדו-שיח (כמו יצירה, עם מילוי מראש)                   |
| **שכפל**        | משכפל את הסט עם סלאג שמסתיים ב-`-copy` ומאפס את הסטטוס ל`טיוטה` |
| **ייצא**         | מוריד את הסט כקובץ ZIP או JSON                                    |
| **ארכיב**        | מעביר ל`בארכיון` — מוסתר מאפליקציית הנוסע, נשמר להיסטוריה          |
| **מחק**          | מסיר לצמיתות (הרסני — רק אם באמת לא צריך)                        |

סרגל הכלים העליון כולל גם **ייבוא** בכמות (ZIP / JSON) ו**ייצוא** (ZIP / JSON של הרשימה הנראית).

## טופס יצירה / עריכה

טופס הדו-שיח כולל שלושה בוחרים ברמה העליונה ורשימת שדות שאלות/תשובות:

- **סוג** — חובה, מגדיר מי רואה את הסט (אפליקציית לקוח / אפליקציית נוסע / מכונאי / מנהל / כללי)
- **סטטוס** — `טיוטה` (ברירת מחדל לחדש) / `פעיל` / `בארכיון`
- **תגיות** — בחירה מרובה, משמש לסינון וקיבוץ
- **כותרת** — חובה, מוצגת כשם הסט
- **תיאור** — אופציונלי, שורה משנית ברשימה
- **שדות** — פריטי שאלות/תשובות. כל שדה כולל:
  - **תווית** (השאלה)
  - **ערך** (התשובה)
  - **סוג** — `text` / `markdown` / `link` / `list`
  - מתג **נראה** (הסתרת פריטים בודדים ללא מחיקה)
  - **סדר** (גרור לשינוי מיקום)

הסלאג נגזר מהכותרת ומשמש ב-URL של ה-API — ניתן לשנותו בעריכה במידת הצורך.

## תזרימי עבודה טיפוסיים

- **פרסם שאלות נפוצות חדשות לנוסע** — `+ צור סט` → סוג = אפליקציית נוסע, סטטוס = טיוטה → מלא כותרת + תיאור → הוסף שדות שאלות/תשובות → שמור → תצוגה מקדימה דרך הצג פרטים → ערוך, הפוך סטטוס ל`פעיל` → מופיע באפליקציית הנוסע בפעם הבאה שנטען
- **הכן עותק עונתי** — שכפל סט קיים → ערוך את העותק כטיוטה → תזמן את המעבר על ידי ארכוב הסט הישן והפעלה של החדש בבת אחת
- **בטל תשובה שגויה** — פתח את הסט הבעייתי → ערוך → תקן את השדה (או כבה את מתג `נראה`) → שמור; או ארכב את כל הסט וחזור לגרסה משוכפלת קודמת
- **ייבא בכמות מייצוא JSON** — ייבוא בפינה הימנית העליונה _ייבא_ → בחר קובץ → אשר את המבנה המנותח → ייבא כטיוטה, ואז סקור והפעל

## טיפים

- **הסוג מגדיר מי רואה את התוכן** — אל תכניס טקסט הפונה לנוסע בסט מסוג `mechanic`, הוא לעולם לא יגיע לאפליקציית הנוסע
- **טיוטה היא חברך** — סטים חדשים מוגדרים כברירת מחדל כטיוטה כדי שהאפליקציה לא תציג תוכן חצי גמור. הפוך ל`פעיל` רק לאחר שבדקת הכל
- **שדות Markdown מציגים עיצוב** — השתמש בהם לתשובות שדורשות רשימות עם תבליטים או הדגשה; בחר `text` כשאתה רוצה טקסט פשוט
- **תגיות משותפות עם המסנן** — השתמש באוצר מילים עקבי לתגיות (למשל `onboarding`, `payments`, `troubleshooting`) כדי שהסינון בעתיד יישאר שימושי
- **ארכב במקום למחוק** כשאפשר — סטים שנמחקים נעלמים לצמיתות, סטים בארכיון ניתנים להחזרה ומשמשים כהיסטוריה
