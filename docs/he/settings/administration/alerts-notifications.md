# התראות והודעות

דף התראות והודעות (`/settings/alerts-notifications`) הוא **קונסולת ההתראות למפעיל** — איך הפלטפורמה מודיעה ל_צוות_ שמשהו דורש תשומת לב. הוא כולל את הערוצים (פוש / בתוך האפליקציה / אימייל / SMS), את ספקי החוץ (SendGrid, Twilio, Telegram, Slack, Discord, וובהוקים), את הכללים שמפעילים התראות, את תבניות ההודעות, את מדיניות ההסלמה, מי מנוי ואת יומן המסירה.

דף זה עוסק ב**התראות לצוות שמפעיל את הפלטפורמה**. עבור העתק ההתראות הפונה לרוכב (נסיעה התחילה, קנס הוטל, וכו'), ראה את לשונית _Notifications_ ב-[General](general.md).

> _הערה_: דף זה הוא כרגע **פרוטוטייפ צד-לקוח בלבד** — הגדרות הערוצים, הכללים, המנויים ויומן המסירה נשמרים במצב מקומי (או נטענים מ-`mockData.ts`). _שמירת שינויים_ מציגה הודעת אישור אך עדיין לא שולחת בקשה לשרת. מבנה הדף תואם את המודל האמיתי וניתן להשתמש בו כמפרט לעבודה על ה-API.

הרשאה נדרשת: לא נקבעו `requiredPermissions` ספציפיים בנתיב — כל מפעיל מחובר יכול לפתוח אותו.

## סרגל כלים עליון

כותרת הדף כוללת ארבעה כפתורים:

| פעולה        | מה היא עושה                                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| רענון אוטומטי | ווידג׳ט `AutoRefresh` משותף — לא מבצע פעולה כאן, קיים לשם אחידות עם דפים אחרים                                          |
| בדוק הכל     | מפעיל הודעת טוסט _"בודק הכל"_ — מייצג "שלח בדיקה לכל ערוץ מופעל"                                     |
| השתקה לשעה  | הודעת טוסט _"הושתק לשעה"_ — מייצג השתקה גלובלית למשך שעה                                                              |
| תחזוקה      | כפתור אדום הרסני — פותח תיבת דו-שיח לאישור; לאחר האישור מציג טוסט שהתחזוקה מופעלת |

## לשוניות

שבע לשוניות בחלק העליון. כל אחת היא רכיב משנה נפרד.

| לשונית        | מטרה                                                                              |
| ------------- | ---------------------------------------------------------------------------------- |
| ערוצים       | ערוצים מובנים (פוש / בתוך האפליקציה / אימייל / SMS) + ניתוב לפי חומרה + סיכומים       |
| ספקים        | אישורי ספק חיצוני (אימייל / SMS / Telegram / Slack / Discord / וובהוק) |
| כללים        | כללי התראה לפי משפחת אירועים                                                       |
| תבניות       | העתק התראה לפי משפחת אירועים × שפה                                      |
| מדיניות      | שרשרת הסלמה, השתקה אוטומטית, בטיחות קהל, הסתרת מידע אישי                        |
| מנויים       | מי (תפקיד או משתמש) מקבל אילו משפחות אירועים באילו ערוצים                     |
| יומנים       | יומן מסירה לקריאה בלבד (נשלח / אושר / נכשל)                             |

### ערוצים

שלוש כרטיסיות מונחות אחת על השנייה.

**ערוצים מובנים**

- _פוש_ — הגדרה מלאה (מתג הפעלה, הגבלת תדירות, ניסיונות חוזרים, שעות שקט מ/עד, כפתור בדיקה).
- _בתוך האפליקציה_ — מופעל, הגבלת תדירות, סגירה אוטומטית בשניות.
- _אימייל_ — תלוי בספק האימייל בלשונית ספקים. מופעל, הגבלת תדירות, ניסיונות חוזרים.
- _SMS_ — תלוי בספק ה-SMS. מופעל, הגבלת תדירות, ניסיונות חוזרים, שעות שקט.

**מיפוי חומרה** — שלושה תפריטים נפתחים שממפים `info` → `inApp` (ברירת מחדל), `warning` → `push`, `critical` → `push+email`. אלה הערוצים שישמשו כאשר כלל עם חומרה זו לא מציין ערוצים ספציפיים.

**סיכום (Digest)** — תדירות (כבוי / כל שעה / יומי / שבועי) + זמן שליחה (בחירת שעה:00).

### ספקים

שישה בלוקים של ספקים, כל אחד עם מתג הפעלה ואישורים.

- _אימייל_ — תפריט סוג ספק (SMTP / SendGrid / Mailgun), מפתח API או אישורי SMTP (קלט מוסתר), דומיין שולח.
- _SMS_ — מזהה חשבון SID, אסימון אימות (מוסתר), מספר שולח — מבנה Twilio.
- _Telegram_ — אסימון בוט (מוסתר) + בורר מזהה צ׳אט (רשימה קשיחה של שלושה צ׳אטים לדמו: `@ridewolf_alerts`, `@support_team`, `@management`; כפתור **בדיקה** הוא מייצג).
- _Slack_ — כתובת וובהוק + ערוץ.
- _Discord_ — כתובת וובהוק.
- _Webhook_ — כתובת וובהוק כללית + סוד חתימה.

כל בלוק ספק מציג תג _מופעל_ ליד הכותרת כאשר המתג דלוק. כפתורי _בדיקה_ מפעילים הודעת טוסט.

### כללים

טבלת כללי התראה. עמודות: שם / משפחת אירועים / חומרה / ערוצים / סטטוס / פעולות (תפריט שלוש נקודות: ערוך / שכפל / הפעל-כבה / מחק). לחץ על **+ צור כלל** לפתיחת תיבת דו-שיח כלל — בחר שם, טווח (גלובלי / אזור / תפקיד), משפחת אירועים אחת או יותר, חומרה (מידע / אזהרה / קריטי), ערוצים ודגל הפעלה.

כללים מובנים: _כשלי תשלום_ (קריטי, משפחת תשלומים, push+email+telegram) ו_רכב מנותק_ (אזהרה, משפחת רכבים, push+email).

### תבניות

בחר משפחת אירועים + שפה + ערוץ, ואז ערוך את הכותרת והגוף. הגוף תומך במשתני מיקום (למשל `{{ride.id}}`, `{{amount}}`) שהבלוק **תצוגה מקדימה** מרחיב עם אירוע לדוגמה. _שלח בדיקה_ מפעיל טוסט שמודיע שנשלחת בדיקה לערוץ הנבחר.

### מדיניות

ארבעה בלוקים:

- _הסלמה קריטית_ — תפריט שרשרת (למשל פוש → אימייל → טלגרם → SMS), זמן המתנה לאישור בדקות, מתג דרישת אישור קריאה.
- _השתקה אוטומטית_ — השתקת חזרות: אם אותו אירוע מתרחש _N_ פעמים ב_ M_ דקות, השתק למשך _K_ דקות (שלושה שדות מספריים). מחרוזת סיכום מתחת מסכמת את הכלל.
- _בטיחות קהל_ — מתג _חסום SMS מחוץ לשעות שקט_ (מתעלם מהגדרות שעות שקט בערוצים אחרים עבור SMS ספציפית).
- _הסתרת מידע אישי_ — מתג _הסתר מידע אישי בהודעות חיצוניות_; רמז מסביר מה מוסתר (טלפון, אימייל, ארבעת הספרות האחרונות של כרטיסים וכו').

### מנויים

טבלה של רשומות מנויים. כל שורה מקשרת יעד (תפקיד או משתמש ספציפי) למשפחות אירועים וערוצים אחדים — לדוגמה _תפקיד: מנהל → מערכת + תשלומים → הודעת דחיפה + אימייל_. כפתור **+ צור** פותח דיאלוג מנוי; בתפריט השורה יש ערוך / מחק.

השתמש במנויים כדי לשלוח התראות לאנשים שאינם תואמים אף ערוץ מוצמד בכלל — הכללים מגדירים _מה_ להתריע, והמנויים מגדירים _מי_ שומע את זה.

### יומנים

טבלה לקריאה בלבד של ניסיונות משלוח. עמודות: זמן / אירוע / מסלול / ערוץ / נמען / סטטוס (נשלח / אושר / נכשל) / השהייה. לחץ על שורה כדי לפתוח התראה מפורטת (ממלא מקום לפאנל מפורט מלא). השתמש בזה כדי לאשר שההתראה אכן יצאה, או כדי לאבחן ספק כושל.

## משפחות אירועים

הכללים, התבניות והמנויים כולם מתבססים על אותה רשימה קבועה של משפחות אירועים (מוגדרת ב־`models/channels.ts`):

`authProfile` · `dashboard` · `vehicles` · `rides` · `payments` · `marketing` · `rebalance` · `support` · `maintenance` · `settings` · `system`

אלה מתאימים בערך לתחומי לוח המחוונים — בחר את המשפחה שמתאימה לסוג האירוע שברצונך להתריע עליו.

## זרימות עבודה

- **חבר התראות אימייל** — לשונית ספקים → הפעל אימייל → בחר סוג ספק → הדבק מפתח API → שמור → חזור ללשונית ערוצים → הפעל ערוץ אימייל → סיום.
- **קבל הודעה כשיש כשל בתשלומים** — לשונית כללים → ערוך _כשלי תשלום_ → ודא שהחומרה היא `critical` ושהערוצים כוללים את אלה שאתה באמת עוקב אחריהם → שמור.
- **עצור ספאם SMS בלילה** — לשונית מדיניות → הפעל _חסום SMS מחוץ לשעות שקטות_ → הגדר את שעות השקט לכל ערוץ בלשונית ערוצים.
- **שלח סיכום יומי במקום פינגים** — לשונית ערוצים → כרטיס תקציר → הגדר תדירות ל_יומי_, זמן למשל 09:00.
- **הוסף תפקיד חדש במשמרת** — לשונית מנויים → + צור → בחר את התפקיד → משפחות אירועים → ערוצים → שמור. הם יקבלו התראות עתידיות שתואמות.
- **אבחן התראה חסרה** — לשונית יומנים → חפש את האירוע לפי מסלול או זמן → אם הסטטוס הוא `failed`, עבור לספקים לבדוק הרשאות; אם `sent` אבל האדם לא ראה את זה, בדוק מנויים / שעות שקטות / מצב השתקה.

## טיפים

- **כרגע רק ממשק קדמי.** שמירה מציגה התראה אך ה־API עדיין לא קיים — התייחס לעמוד זה כמפרט, לא כמקור אמת.
- **כפתורי בדיקה הם דמה.** _בדוק הכל_, _השקט שעה_, _בדוק_ לכל ערוץ ואישור _תחזוקה_ כולם רק מציגים התראה — הם לא שולחים הודעות בדיקה או משתקים משהו באמת.
- **מיפוי חומרה הוא ברירת מחדל.** רשימת _ערוצים_ בכלל מנצחת כשהוגדרה; רק רשימה לא מוגדרת/ריקה מפנה למיפוי החומרה.
- **התקציר נפרד מהתראות לאירועים בודדים.** הפעלת התקציר לא משתקת התראות בודדות — היא רק מוסיפה את הסיכום התקופתי.
- **מנויים יכולים ליעד משתמש**, לא רק תפקיד. השתמש בזה להסלמות חד-פעמיות (למשל _מוביל המשמרת מקבל את כל התראות `rides` בהודעת דחיפה_) בלי ליצור תפקיד.
- **פריסת מובייל היא לקריאה בלבד במתכוון.** כל הלשוניות במובייל מציגות _השתמש בשולחן העבודה להגדרה מלאה_ — התראות הן עבודה אדמיניסטרטיבית שדורשת שולחן עבודה.
- **הסתרת מידע אישי חשובה ל־SMS/אימייל.** כשהיא כבויה, גופי ההתראה עלולים לדלוף מספרי טלפון או סיומות כרטיס לספקים חיצוניים — השאר אותה מופעלת אלא אם יש סיבה ספציפית.
