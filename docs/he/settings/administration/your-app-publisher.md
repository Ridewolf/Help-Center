# האפליקציה שלך: מפרסם והגשה

שני השלבים האחרונים של [אשף התווית הלבנה של האפליקציה שלך](your-app.md) (`/settings/your-app`): בחירת **חשבון המפתחים שמפרסם את האפליקציה**, הזנת אישורי החנות אם הם שלך, והגשה לאישור.

## בחירת מפרסם

בחירת רדיו עם שתי אפשרויות:

- **Ridewolf** (ברירת מחדל) — האפליקציה מתפרסמת דרך חשבונות המפתחים של Ridewolf. **אין צורך באישורי חנות מצדך.**
- **החשבונות שלך** — האפליקציה מתפרסמת דרך חשבונות המפתחים שלך ב-Apple ו-Google, ודורשת את האישורים למטה.

## אישורי גישה לחנות (רק חשבונות אישיים)

**Apple — כל הפרטים נדרשים:**

- Apple ID
- Team ID
- App Store Connect API **מזהה מפתח** ו-**מזהה מוציא**
- App Store Connect API **מפתח פרטי** (תוכן קובץ `.p8`)
- מספר D-U-N-S

**Google:**

- אימייל חשבון שירות
- JSON של חשבון שירות
- אימייל Play Console

אישורים אלה רגישים — הם נשלחים לאישור ואינם נשמרים ב**טיוטה מקומית בדפדפן**.

## אישורים ידניים

שתי תיבות סימון שעליך לסמן כדי לאשר שהגישה אכן ניתנה:

- **גישה ל-App Store Connect אושרה** — ה-Apple ID נוסף ל-App Store Connect
- **גישה ל-Play Console אושרה** — הרשאות Play Console הוגדרו

אלה **הצהרות עצמאיות שאינן מאומתות אוטומטית**. סימון שלהן ללא מתן ההרשאות האמיתיות לא יתפס כאן — זה יתברר מאוחר יותר כשכישלון באישור.

## שלב סקירה

סיכום לקריאה בלבד של כל השלבים הקודמים, עם **תגי אימות לפי חוק** (למשל _נדרשים נכסים_ או _השלמת משפטית_) שמוצגים כהצלחה או ככישלון, ו**קישורי עריכה במקום** חזרה לשלב הספציפי שדורש תשומת לב. כל בדיקה חייבת לעבור לפני ש-**הגש** זמין.

## הגשה

ההגשה מפעילה את צינור האישור ומעבירה את הסטטוס דרך **טיוטה → באישור → בבדיקה → בייצור**, או ל-**נדחה**.

- כל עוד הסטטוס הוא `provisioning`, `in-review` או `production`, הדף הוא **לקריאה בלבד** וקישורי החנות (TestFlight, בדיקות פנימיות ב-Play, App Store, Play Store) מופיעים ככל שהצינור ממלא אותם.
- סטטוס **נדחה** מאפשר לערוך שוב את האשף כדי לתקן ולהגיש מחדש.

## שאלות נפוצות

- **הכפתור הגש אינו זמין.** תגי האימות בשלב הסקירה עדיין נכשלות — השתמש בקישורי העריכה כדי לעבור לשלב הבעייתי.
- **שדות Apple/Google אינם מוצגים.** הם מופיעים רק כאשר המפרסם מוגדר לחשבונות שלך.
- **אני צריך לשנות משהו אחרי ההגשה.** לא ניתן לשנות בזמן שהסטטוס הוא `provisioning`, `in-review` או `production`. אם האפליקציה נדחתה, האשף הופך לעריכה שוב — `draft` ו-`rejected` הם שני המצבים העריכים.
- **האישור נכשל למרות שסימנתי את האישורים.** אלה טענות ידניות — בדוק שוב שה-Apple ID אכן יש לו גישה ל-App Store Connect ושהחשבון שירות אכן יש לו הרשאות Play Console.
