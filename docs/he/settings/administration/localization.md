# לוקליזציה

דף ה-Localization (`/settings/localization`) הוא **משטח העבודה לתרגום** — ספריית _אוספים_ (קבוצות של מפתחות תרגום קשורים) שבהם אתה עורך, מייבא, מייצא ומפרסם. לכל אוסף יש מרחב שמות (למשל `ui`, `auth`, `rides`), שפת בסיס (תמיד `en`), סט שפות יעד ורשימת מפתחות עם ערכים לכל שפה.

> _הערה_: דף זה הוא כרגע **פרוטוטייפ בצד הלקוח בלבד** — האוספים נטענים מ-`mockData.ts` ומאוחסנים במצב מקומי. פעולות _שמור_ ו-_פרסם_ מציגות הודעות אישור אך אין נקודת קצה בשרת. הדף בטוח לשימוש כמפרט ל-API; שום דבר שאתה עושה כאן אינו נשמר.

הרשאה נדרשת: לא הוגדרו `requiredPermissions` ספציפיים בנתיב — כל מפעיל מחובר יכול לפתוח אותו.

## פריסת הדף

שורת כותרת אחת עם כותרת הדף, תיבת חיפוש, תפריט נפתח _ייבוא / ייצוא_ וכפתור _+ צור אוסף_ — אחר כך כרטיס סינון וטבלת האוספים.

נתוני ייחוס (כרגע מקודדים ב-`Localization.vue`):

- שפות: `en`, `ro`, `ru`, `de`, `fr`, `es` (שפת בסיס + 5 שפות יעד)
- מרחבי שמות: `ui`, `auth`, `rides`, `payments`, `marketing`
- תגיות: `core`, `beta`, `promo`, `legacy`

## סינונים

כרטיס סינון ממוקם מעל הטבלה.

| סינון    | סוג            | הערות                                                                        |
| --------- | -------------- | ---------------------------------------------------------------------------- |
| שפה      | תפריט נפתח    | מסנן אוספים הכוללים שפה זו. ברירת מחדל `ro`                                 |
| מרחב שמות | תפריט נפתח    | אחד מרשימת מרחבי השמות (או ריק לכולם)                                     |
| סטטוס    | תפריט נפתח    | `all`, `active`, `draft`, `archived`                                         |
| תגיות    | שבבי בחירה    | בחירת תגיות מרובה — האוסף חייב להכיל _כל_ תגית מסומנת כדי לעבור סינון       |
| חיפוש    | טקסט (סרגל כלים) | השהייה של 300 מ"ש — מתאים לשם, תיאור, מרחב שמות                          |

כפתור _נקה_ בכרטיס הסינון מאפס את כל ארבעת הסינונים.

### פעולות שורה

| פעולה    | מה היא עושה                                                                    |
| --------- | ------------------------------------------------------------------------------- |
| הצג      | פותח את דו-שיח האוסף במצב _הצגה_ לקריאה בלבד                            |
| ערוך      | פותח את דו-שיח האוסף במצב _עריכה_                                      |
| שכפל     | משכפל את האוסף עם הסיומת " (העתק)" בראש הרשימה              |
| ייבא      | פותח את דו-שיח האוסף ממוקד בלשונית _ייבוא / ייצוא_ במצב ייבוא |
| ייצא      | הודעת טוסט — מייצג הורדת האוסף בפורמט הנבחר         |
| ארכיב     | משנה סטטוס ל-`archived` (השורה נשארת — סנן לפי סטטוס כדי לראות ארכיון) |
| מחק      | מסיר את השורה מהרשימה המקומית                                             |

## צור / ערוך / הצג — דו-שיח האוסף

נפתח מ-+ צור או מכל אחת מפעולות השורה. ארבע לשוניות בתוך הדו-שיח.

### לשונית סקירה כללית

ערוך את המטא-דאטה של האוסף.

- _שם_ (נדרש) — שם תצוגה (למשל "תוויות ממשק משתמש").
- _מרחב שמות_ — בורר עם שדה חיפוש.
- _תיאור_ — תיאור קצר.
- _שפת בסיס_ — לקריאה בלבד, תמיד `en`.
- _שפות יעד_ — שבבים ניתנים להפעלה מתוך חמש אפשרויות שאינן אנגלית. הבסיס + היעדים יחד יוצרים את עמודות השפה בלשונית המפתחות.
- _סטטוס_ — `active` / `draft` / `archived`.
- _תגיות_ — שבבים ניתנים להפעלה מתוך רשימת התגיות.

### לשונית מפתחות

רשת התרגום בפועל.

- סרגל כלים: תיבת חיפוש (מתאים לשם המפתח ולכל ערך), מסנן סטטוס (למשל _רק חסרים_), בורר שפה (איזו עמודת יעד מודגשת כמוקד העריכה).
- פעולות בכמות גדולה כשמפתחות נבחרים: _קבע סטטוס_, _נקה ערכים_, _ייצא נבחרים_, _מחק_.
- פעולות לכל שורה: שכפל מפתח, מחק מפתח, העתק מאנגלית (ממלא את היעד הנוכחי בערך באנגלית), אימות מחוונים (בודק שפריטים כמו `{{name}}` באנגלית נשמרים ביעד).
- כל שורה נושאת דגלים אופציונליים המוצגים כתגים:

| דגל       | משמעות                                                        |
| ---------- | -------------------------------------------------------------- |
| `new`      | מפתח נוסף לאחרונה — דורש סקירה אנושית                        |
| `changed`  | ערך באנגלית השתנה מאז התרגום האחרון — היעדים עלולים להיות מיושנים |
| `missing`  | ערך ריק לפחות בשפה יעד אחת                                   |
| `obsolete` | מפתח שאינו בשימוש בקוד יותר — בטוח למחיקה                    |

- _הוסף מפתח_ ו_מצא והחלף_ פותחים דיאלוגים קטנים ייעודיים.
- מתג _שמירה אוטומטית_ — כשהוא פעיל, עריכות לערך נשמרות מידית במצב המקומי.

### לשונית ייבוא / ייצוא

ייבוא:

- _פורמט_ — JSON / CSV / XLSX.
- _מצב_ — החלף ערכים קיימים / מיזוג / הוספה.
- מתג _שמור מפתחות לא מוכרים_ — כשהוא כבוי, מפתחות שאינם בקובץ הייבוא מסומנים ב-`obsolete`.
- _סימולציה_ — הרצה יבשה שמדווחת מה ישתנה (ללא כתיבה).
- _החל_ — מבצע את הייבוא. פס התקדמות מוצג במהלך ההרצה.

ייצוא:

- _פורמט_ — JSON / CSV / XLSX.
- _טווח_ — כל המפתחות / מפתחות מסוננים / מפתחות נבחרים.
- _הורדה_ — פעולה זמנית (כרגע מציג התראה).

### לשונית פרסום

- בלוק סיכום: _N מפתחות בסך הכל / M שונו / K חסרים_.
- רשימת מפתחות ששונו עם ערכים לפני / אחרי.
- רשימת אזהרות (למשל חוסר התאמת מחוון, יעד חסר).
- _שמור טיוטה_ — שומר את העותק כטיוטה (`status = draft`).
- _פרסם_ — מקדם את הטיוטה ל-`active` ומציג התראה.

## סרגל כלים עליון — תפריט ייבוא / ייצוא

שני קיצורי דרך גלובליים בכותרת הדף (נפרדים מפעולות לכל אוסף):

- _ייבא אוספים_ — פותח את דיאלוג הייבוא ברמת הדף (ייבוא בכמות גדולה של אוספים בבת אחת).
- _ייצא הכל_ — קיצור לייצוא כל האוספים בחבילה אחת (כרגע מציג התראה).

## שינויים לא שמורים ושמירה מפני ניווט

קיים דגל גלובלי "שינויים לא שמורים" (`hasUnsavedGlobal`) — כשהוא פעיל, מופיע תחתית דביקה עם _בטל שינויים_ / _שמור_. הדף גם מתקין שמירה `router.beforeEach`: ניסיון לעזוב עם שינויים לא שמורים מפעיל דיאלוג _אישור_ מקורי של הדפדפן.

## זרימות עבודה

- **תרגם מפתח חדש ברומנית** — בחר את האוסף מהטבלה → ערוך → לשונית מפתחות → הגדר את בורר השפה ל-`ro` → מצא את המפתח (או _הוסף מפתח_) → מלא את הערך → _שמור_ (או הפעל שמירה אוטומטית).
- **בדוק מה חסר בצרפתית** — ערוך אוסף → לשונית מפתחות → סנן סטטוס _רק חסרים_ → שפה _fr_. השתמש ב_העתק מאנגלית_ כפיתרון מהיר, או ב_אמת מחוונים_ לפני פרסום.
- **עדכון בכמות גדולה מ-XLSX** — ערוך אוסף → לשונית ייבוא / ייצוא → בחר XLSX, מצב _מיזוג_, _סימולציה_ תחילה → סקור את ההבדלים → _החל_.
- **קדם מחרוזות טיוטה לייצור** — ערוך אוסף → לשונית פרסום → אשר את רשימת המפתחות ששונו, תקן אזהרות → _פרסם_.
- **צור גרסה חדשה לשוק חדש** — שכפל את האוסף → שנה שם → הוסף את השפה החדשה ל_שפות יעד_ → תרגם.
- **ארכב סט מיושן** — תפריט שורה → ארכב. האוסף נשאר בטבלה אך עובר לסטטוס `archived`; סנן לפי סטטוס כדי למצוא אותו מאוחר יותר.

## טיפים

- **כרגע רק צד לקוח.** שום דבר כאן לא מגיע לשרת — `שמור`, `פרסם`, `ייצא`, `מחק`, `ארכב` הם שינויים במצב המקומי + התראות. אל תסתמך על זה למחרוזות ייצור אמיתיות עד שה-API יושק.
- **שפת הבסיס נעולה.** `en` היא תמיד הבסיס — אוספים שאינם באנגלית חייבים להיווצר כשפות יעד של אוסף בסיס באנגלית, לא כעצמאיים.
- **תגיות משתמשות בלוגיקת AND.** סינון לפי שתי תגיות פירושו שהאוסף חייב להכיל _שתי_ התגיות. לחיפוש לפי אחת מהן, נקה אחת מהתגיות.
- **שמירת הניווט היא גלובלית.** גם כשדיאלוג בלבד מלוכלך, יציאה מהדף מבקשת אישור — שמור או בטל במפורש כדי לדלג על ההודעה.
- **אימות מחוונים הוא חבר שלך** — הרצה לפני פרסום תופסת טעויות כמו "איבדנו את `{{name}}` בתרגום" שמפריעות להצגת המחרוזת בזמן ריצה.
- **אל תבלבל עם לשונית Locale ב-[General](general.md)** — לשונית זו מגדירה ברירות מחדל (אילו שפות _מופעלות_, פורמטים של תאריך / שעה / יחידות). בדף זה נמצאות המחרוזות המתורגמות בפועל.
- **נתוני הייחוס הם דמה.** שפות, שמות מרחבים ותגיות מוצמדים כרגע בקוד — כששרת ה-API יושק, צפוי שיגיעו ממנו ואולי יהיו ניתנים לעריכה.
