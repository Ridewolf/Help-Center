# מפעילים

דף המפעילים (`/settings/operators`) הוא **ספר העובדים** — כל עובד שיש לו גישה ללוח המחוונים. לכל מפעיל יש תפקיד (ראה [Roles](roles.md)), מטא-נתונים אופציונליים למחלקה / משרה, תגיות לסינון, וסטטוס (פעיל / לא פעיל).

שונה מ-[Clients](../../operations/customers/clients.md) (הלקוחות שלך) — מפעילים הם **הצוות הפנימי** שמפעיל את הפלטפורמה.

הרשאה נדרשת: **Operators** (`t4u5v6`). תת-ההרשאות מגבילות פעולות עריכה.

## איך מפעילים מגיעים לכאן

מפעילים נוצרים על ידך (מנהל) דרך כפתור **+ צור** — אין הרשמה עצמית:

1. **+ צור** פותח את טופס המפעיל — שם, אימייל, תפקיד, מטא-נתונים אופציונליים למחלקה / משרה / תגיות
2. המפעיל החדש מקבל אימייל עם הוראות התחברות וסיסמה זמנית
3. הוא נכנס, משלים את הפרופיל שלו (`/profile`), ויכול להתחיל לעבוד בהתאם להרשאות התפקיד שלו
4. מפעילים לא פעילים לא יכולים להתחבר — הפוך חשבון ללא פעיל כשעובד עוזב

## מסננים

| מסנן  | סוג          | הערות                                                    |
| ------ | ------------ | -------------------------------------------------------- |
| חיפוש | טקסט         | מחפש בשם, אימייל, משרה, מחלקה                           |
| סטטוס | תפריט נפתח   | `פעיל` / `לא פעיל` (או `הכל`)                           |
| תגיות | בחירה מרובה | סינון לפי תגיות שהוחלו על מפעילים (למשל "משמרת לילה") |

## עמודות

| עמודה          | ניתן למיין? | תוכן                                                                   |
| -------------- | --------- | ----------------------------------------------------------------------- |
| **משתמש**     | ✓         | אווטאר + שם פרטי/משפחה + אימייל; קישור לדף פרטי המפעיל                 |
| **תפקיד**     | —         | תווית התפקיד של המפעיל (קישור ל-[Roles](roles.md))                      |
| **מחלקה**     | —         | תווית מחלקה אופציונלית                                                  |
| **משרה**      | —         | תווית משרה אופציונלית                                                  |
| **תגיות**     | —         | תגיות שהוחלו על המפעיל                                                 |
| **סטטוס**     | ✓         | `פעיל` (ירוק) / `לא פעיל` (אפור)                                      |

## פעולות שורה

תפריט שלוש נקודות לכל שורה. הפעולות הזמינות תלויות בהרשאות:

| פעולה           | הרשאה     | מה היא עושה                                      |
| ---------------- | ---------- | ------------------------------------------------- |
| **הצג פרטים**  | —          | פותח את דף הפרטים של המפעיל                      |
| **ערוך**         | `edit`     | פותח את טופס העריכה (שם, תפקיד, מחלקה וכו')       |

אין **פעולת מחיקה** — רשומות המפעילים נשמרות לצורכי ביקורת. כדי למנוע התחברות, הפוך את הסטטוס של המפעיל ל_לא פעיל_ דרך עריכה.

## דף פרטים

לחיצה על שורה (או _הצג פרטים_) פותחת את דף הפרטים של המפעיל עם:

- מידע אישי (שם, אימייל, טלפון, תמונה)
- תפקיד + תמונת מצב הרשאות
- מחלקה / משרה / תגיות
- סטטוס
- יומן פעילות (אירועי התחברות, שינויים בתפקיד)

ערוך משם או מתפריט השורה — שניהם מובילים לאותו טופס.

## טופס יצירה / עריכה

**טופס המפעיל** (`+ צור` או _ערוך_) פשוט לשימוש:

- **שם פרטי / שם משפחה** (נדרש)
- **אימייל** (נדרש, ייחודי בין המפעילים)
- **תפקיד** (נדרש, תפריט נפתח של תפקידים זמינים — ראה [Roles](roles.md))
- **מחלקה / משרה** (אופציונלי)
- **תגיות** (בחירה מרובה אופציונלית)
- **סטטוס** (פעיל / לא פעיל)
- ביצירה בלבד: שדה **סיסמה ראשונית** או סיסמה שנוצרה אוטומטית שנשלחת במייל למפעיל

שמירה מאמתת וכותבת ליומן הביקורת. מפעילים שנוצרו חדשים מקבלים מייל קבלת פנים אוטומטית.

## תרחישי עבודה טיפוסיים

- **קליטת עובד חדש** — `+ צור` → מלא שם/אימייל/תפקיד → שמור → אשר שקיבל מייל קבלת פנים → בקש ממנו להתחבר ולהשלים את הפרופיל
- **שינוי תפקיד לאחר קידום** — ערוך → שנה תפקיד → שמור (ההרשאות החדשות ייכנסו לתוקף בבקשה הבאה של המפעיל, לא רטרואקטיבית)
- **עזיבה** — ערוך → הגדר סטטוס = לא פעיל → שמור (הרשומה נשמרת לביקורת; ההתחברות נחסמת)
- **תכנון משמרות לפי תגיות** — החל תגיות כמו "משמרת לילה" → סנן את הרשימה לפי תגית כדי לראות מי מתוכנן

## טיפים

- **התפקיד הוא השדה החזק** — היה זהיר כשאתה משנה אותו. הורדה מתפקיד מנהל לתמיכה מסירה מיידית את גישת הכתיבה
- **לא פעיל ≠ נמחק** — ההיסטוריה של המפעיל נשמרת; הפוך חזרה ל"פעיל" כדי לשחזר גישה
- **הרשימה ממוינת כברירת מחדל לפי שם** — אם יש לך מפעילים רבים, חפש לפי אימייל או מחלקה במקום לגלול
- **תגיות כאן שונות מתגיות לקוחות** — הן ספציפיות למפעילים (למשל "משמרת לילה", "מדריך") ואינן חולקות את אותו מרחב השמות
- **הגבלות עריכה עצמית** — אינך יכול לשנות את התפקיד שלך מתפריט השורה; השתמש בפרופיל לשינויים אישיים
