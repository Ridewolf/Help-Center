# רכבים — רשימה

רשימת הרכבים (`/vehicles`) היא המלאי של כל הצי שלך — כל קורקינט, אופניים או יחידה אחרת, עם המצב הנוכחי, מיקום, סוללה, חיבור IoT, תגיות ואזור. זו הדף הנפוץ ביותר בלוח המחוונים: כאן אתה מתחיל כמעט כל פעולה בצי.

לעבודה לפי רכב (סטטוס מלא, היסטוריה, פקודות IoT, ניגון מסלול) פתח את [דף פרטי הרכב](vehicle-detail.md).

הרשאה נדרשת: **רכבים** (`k7m8n9`).

## איך רכבים מגיעים לכאן

רכבים לא מופיעים מעצמם — הם נוצרים ומנוהלים על ידך:

1. מפעיל **יוצר רכב** דרך כפתור _צור_ (מגדיר תווית, דגם, מכשיר IoT, מצב התחלתי)
2. הרכב נרשם למכשיר IoT; המכשיר מתחיל לדווח על **סוללה, מצב מנעול, אות אחרון, קואורדינטות GPS** ברציפות
3. ברגע שמכשיר ה-IoT שולח את פעימת הלב הראשונה שלו, השורה ברשימה מתמלאת בנתונים חיים — אחוז סוללה, זמן אות, אינדיקטור מנעול
4. מפעילים (ופעולות בכמות) **מעדכנים סטטוס, תגיות, אזור, הגדרות** לאורך חיי הרכב
5. כשהרכב יוצא משימוש, משנים את הסטטוס ל_אחסון_ / _תחזוקה_ / וכו', או מוחקים אותו

הרשימה מתעדכנת כשאתה טוען מחדש או משנה מסננים; עדכוני IoT חיים שנשלחים מהשרת יכולים גם לעדכן שורות במקום.

## מצבי תצוגה — טבלה מול מפה

לעמוד יש שתי תצוגות, שניתן להחליף ביניהן באמצעות בקרה בראש העמוד:

- **טבלה** — רשת נתונים מלאה עם כל המסננים, מיון ותכונות בחירה בכמות
- **מפה** — אותו צי מוצג על מפה של אזור הפעילות שלך; הרכבים הם סיכות בצבע לפי סטטוס עם סמלוני סוללה

המסננים חלים על שתי התצוגות. תצוגת המפה מצוינת לזיהוי אשכולות, פערים והזדמנויות לאיזון מחדש; הטבלה היא מה שאתה משתמש בו לעבודה עם נתונים.

## מסננים

| מסנן    | סוג             | הערות                                                                        |
| -------- | --------------- | --------------------------------------------------------------------------- |
| חיפוש   | טקסט רוחב מלא  | מחפש בתווית הרכב, מזהה, סידורי IoT — קלט טקסט הוא **מושהה כ-300ms**       |
| מד אוץ  | תפריט נפתח     | דליי מרחק מצטבר: `<1k`, `1k–10k`, `10k–50k`, `50k–100k`, `>100k` ק"מ                        |
| סטטוס   | תפריט נפתח     | סינון לפי סטטוס רכב (ראה הפניה לסטטוסים למטה)                              |
| תגיות   | בחירה מרובה    | סינון לפי תגיות שהוחלו על הרכב                                            |

כל המסננים מחוברים ב-AND. שבבי המסנן מופיעים מעל הטבלה; כתובת ה-URL מתעדכנת תוך כדי תנועה.

## הפניה לסטטוס

כל רכב נמצא בדיוק בסטטוס אחד. הסטטוס מכתיב התנהגות (האם ניתן להשכיר אותו, האם מופעלות התראות IoT וכו'):

| סטטוס                  | משמעות                                               |
| ----------------------- | ----------------------------------------------------- |
| **זמין**               | פנוי, להשכרה, חונה כראוי                           |
| **בשימוש**             | נמצא בנסיעה כרגע                                   |
| **בטעינה**             | בתחנת טעינה                                        |
| **פרוק**               | סוללה נמוכה מדי להשכרה                             |
| **דורש בדיקה**         | סומן על ידי המערכת או מפעיל — דורש בדיקה ידנית    |
| **תחזוקה**             | במוסך / מחוץ לצי לתיקון                            |
| **לא מוכן**            | נוצר אך לא שוחרר לרוכבים                           |
| **שמורה**              | שמור לרוכב/הזמנה ספציפית                          |
| **בהעברה**             | בהעברה (איזון מחדש, איסוף מהשטח)                  |
| **באחסון**             | באחסון לטווח ארוך, מחוץ לתפעול                     |
| **גנוב**                | דווח כגנוב / לא נמצא                              |
| **התראה**              | התראה קריטית מ-IoT או מהמערכת                      |

## פעולות שורה

לכל שורה יש **תפריט שלוש נקודות** בצד ימין. הפעולות הזמינות תלויות בהרשאות שלך:

| פעולה                   | הרשאה                | מה היא עושה                                                          |
| ----------------------- | --------------------- | --------------------------------------------------------------------- |
| **הצג פרטים**          | —                     | פתח את [דף פרטי הרכב](vehicle-detail.md) |
| **הצג היסטוריית מסלול** | `coordinates-history` | פתח תצוגת מפה המשחזרת את מסלול ה-GPS האחרון של הרכב              |
| **פתח ב-Google Maps**   | —                     | פתח את הקואורדינטות האחרונות הידועות של הרכב ב-Google Maps (בלשונית חדשה)    |
| **ערוך**                | `edit`                | פתח את טופס העריכה                                                    |
| **שנה סטטוס**          | `edit`                | פתח דיאלוג קטן לשינוי הסטטוס מבלי לעזוב את הרשימה           |
| **מחק**                 | `delete`              | מחיקה רכה של הרכב (עם דיאלוג אישור)                  |

פעולות שאין לך הרשאה אליהן מוסתרות.

## פעולות בכמות גדולה

בחר רכב אחד או יותר באמצעות תיבות הסימון משמאל לכל שורה. **סרגל פעולות בכמות גדולה** יופיע בראש עם מספר הפריטים שנבחרו והפעולות הזמינות:

| פעולה בכמות גדולה    | הרשאה        | מה היא עושה                                                     |
| --------------------- | ------------- | ---------------------------------------------------------------- |
| **שנה סטטוס**        | `bulk-update` | פתח דיאלוג והחל סטטוס אחד על כל הרכבים שנבחרו |
| **שנה תגיות**        | `bulk-update` | הוסף או הסר תגיות על כל הבחירה                          |
| **שנה הגדרות**       | `bulk-update` | החל הגדרות רכב (למשל מהירות מקסימלית, אזעקות) על כולם  |
| **שלח פקודה**        | `iot-command` | שלח פקודת IoT (נעילה, פתיחה, הפעלת אזעקה/כיבוי, אתחול) לכולם  |
| **קוד QR בכמות**     | —             | צור גיליון קודי QR להדפסה עבור הרכבים שנבחרו     |
| **מחק נבחרים**       | `delete`      | מחיקה רכה של כל הרכבים שנבחרו (עם דיאלוג אישור)  |

## פעולות בדף (למעלה מימין)

- **+ צור** — פותח את [טופס יצירת רכב](vehicle-create-edit.md) (מאמר נפרד)
- **ייצא** — הורד את הרשימה המסוננת הנוכחית כקובץ (מסננים ומיון נשמרים)
- **קוד QR בכמות** (זמין גם כפעולה בכמות גדולה) — פותח את אשף יצירת קודי QR להדפסה

## תצוגת מפה

כאשר עוברים לתצוגת מפה:

- רכבים מופיעים כ**סמני פין** בצבעים לפי הסטטוס (ירוק = זמין, כחול = בשימוש, וכו')
- **סמל סוללה קטן** מופיע ליד כל פין
- לחץ על פין לפתיחת חלונית עם תווית הרכב, סטטוס, סוללה וקישור _הצג פרטים_
- **המסננים עדיין בתוקף** — צמצם לפי סטטוס, תגיות וכו' והמפה תתעדכן
- גלול/התקרב עם העכבר או מחוות שתי אצבעות

המפה מוזנת מאותו מקור נתונים כמו הטבלה — זו עדשה שונה, לא מערך נתונים שונה.

## תרחישי עבודה טיפוסיים

- **איזון מחדש בכמות גדולה** — סנן לפי `סטטוס = פרוק` + אזור, בחר הכל, _שלח פקודה → נעילה_ (או _שנה סטטוס → בהעברה_) לפני האיסוף
- **מצא רכב תקוע** — מיין לפי _אות אחרון_ בסדר עולה כדי לראות את האותות הוותיקים ביותר בראש
- **גלה סוללות חלשות לפני שהן בעיה** — מיין לפי _סוללה_ בסדר עולה; התחתית של הצי היא תור התחזוקה העתידי שלך
- **בדוק תגית** — סנן לפי תגית ועבור על השורות
- **הכנת צוות שטח** — סנן ליעדי היום, _קוד QR בכמות_ להדפסת תוויות ליחידות חדשות

## טיפים

- **החיפוש מושהה** — עצור להקליד כדי שהשרת יגיב פעם אחת
- **כתובת URL = התצוגה** — העתק ושתף קישורים מסוננים עם עמיתים
- **עמודת בריאות במבט חטוף** — האייקונים הקטנים מסכמים תת-מערכות IoT; העבר את העכבר מעל כל אייקון כדי לראות מה הוא מייצג (למשל אות סלולרי, מצב נעילה, קריאת חיישן)
- **צבע הסוללה הוא הקיצור שלך** — פס אדום ברשימה = צריך מטען או איסוף בקרוב
- **מדד הנעילה הוא הדיווח האחרון מ-IoT** — ייתכן שיהיה מאוחר בכמה שניות; השתמש ב_שלח פקודה → נעילה_ אם אתה צריך לוודא את המצב במכשיר
