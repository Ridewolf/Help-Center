# פרטי נסיעה

דף פרטי הנסיעה (`/rides/:id`) הוא שולחן העבודה לנסיעה בודדת. השתמש בו כדי לחקור תלונות, לבדוק חיובים, לבצע פעולות מפעיל (השהיה, החזר, ארכוב) ולסקור את יומן האירועים המלא.

בדרך כלל מגיעים לכאן על ידי לחיצה על שורה ב-[רשימת נסיעות](rides.md) או מפרופיל הלקוח.

הרשאה נדרשת: **נסיעות** (`i1j2k3`).

## פריסה

מלמעלה למטה:

1. **כותרת** — עובדות מפתח + כפתור _פעולות_
2. **כרטיסי סקירה** — משך, מרחק, עלות, סטטוס
3. **כרטיסי מידע** — מידע על הנסיעה, פירוט, תמונת מצב תעריף
4. **כרטיסיות** — פרטים (מפת מסלול + ציר זמן) ופעילות (יומן אירועים מלא)

## כותרת

הרצועה העליונה מזהה את הנסיעה במבט חטוף:

- **כפתור חזור** (`←`) מחזיר לרשימה
- **מזהה נסיעה** עם אייקון _העתק_
- **כפתור סטטוס** (פעיל, הושלם, בוטל וכו')
- קישורים ל**לקוח** ו**רכב**
- **חותמות זמן התחלה → סיום** ו**עלות שורת עליונה**
- כפתור **פעולות** מימין — פותח את תיבת הדו-שיח של הפעולות (מתואר בהמשך)

## פעולות

לחץ על **פעולות** בכותרת כדי לפתוח תיבת דו-שיח עם כל פעולות המפעיל הזמינות לנסיעה זו. פעולות מתבטלות בהתאם לסטטוס הנסיעה ולהרשאות שלך, עם תיאור כללי שמסביר מדוע:

| פעולה                 | מתי מופעלת                           | שער הרשאה      |
| --------------------- | ---------------------------------- | -------------- |
| **השהה / המשך**       | הנסיעה חייבת להיות פעילה כדי להשהות או להמשיך | `pause-unpause`           |
| **סיום נסיעה**        | הנסיעה חייבת להיות פעילה כדי לסיים | `end-ride`           |
| **הצג מסלול במפה**    | תמיד (קופץ לכרטיסיית המפה)          | —              |
| **החזר נסיעה**        | הנסיעה חייבת להיות הושלמה כדי להחזיר | refund-related |
| **שלח התראה**         | תמיד (שולח הודעת פוש לרוכב)          | notification   |
| **ארכוב נסיעה**       | תמיד                               | archive        |

העבר את העכבר מעל פעולה מנוטרלת כדי לראות מדוע היא לא זמינה (למשל "הנסיעה חייבת להיות הושלמה כדי להחזיר").

תיבת הדו-שיח של _פעולות_ בכותרת היא **הקבוצה המלאה** של הזמינות; תפריט השורה בדף הרשימה כולל רק את שלוש הנפוצות ביותר (השהה / המשך / סיום). להחזרים, צפייה במסלול, התראות פוש וארכוב — היכנס לכאן.

## כרטיסי סקירה

שורה של ארבעה כרטיסים קטנים מתחת לכותרת מציגה עובדות במבט חטוף:

- **משך** — זמן כולל של הנסיעה
- **מרחק** — מרחק כולל שנעשה
- **עלות** — עלות כוללת שחויבה
- **סטטוס** — סטטוס הנסיעה הנוכחי (משקף את כפתור הסטטוס בכותרת, גדול ובולט יותר)

## כרטיסי מידע

רשת של שלושה כרטיסים מתחת לסקירה מציגה את הנתונים המרכזיים של הנסיעה:

- **מידע על הנסיעה** — רכב, לקוח, תעריף, מזהים, חותמות זמן
- **פירוט** — הרכב עלות דקה-דקה (דמי פתיחה, זמן, מרחק, תוספות, הנחות)
- **פרטי תעריף** — תמונת מצב התעריף ששימשה לנסיעה זו (כדי שתוכל לראות מה הלקוח שולם בפועל, גם אם התעריף שונה מאוחר יותר)

## כרטיסיות

מתחת לכרטיסים, הפרטים מתחלפים בין שתי כרטיסיות:

| כרטיסיה       | מה יש בפנים                                                                                                                                               |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **פרטים**     | מפת מסלול, ציר זמן של אירועים משמעותיים, כרטיסי מידע מלאים                                                                                              |
| **פעילות**    | יומן אירועים כרונולוגי — כל שינוי מצב, אות ופעולה מערכתית הקשורים לנסיעה זו — רחב יותר מציר הזמן בפרטים (שימושי לאיתור תקלות IoT)                   |

### מפת מסלול

בתוך כרטיסיית הפרטים, מפת המסלול מציגה את עקבות ה-GPS של הנסיעה:

- **סימני התחלה / סיום** עם הכתובות שלהם
- **קו רב-נקודות** בצבע לפי מהירות (קטעים איטיים לעומת מהירים)
- **שכבות אזור** אם הנסיעה נכנסה לאזורים מוגבלים
- **מקרא** שמסביר את סולם הצבעים
- **זום / הזזה** עם עכבר או מחוות שתי אצבעות

### ציר זמן

מתחת למפה, ציר זמן אנכי מפרט כל אירוע משמעותי של הנסיעה:

- **התחלת נסיעה** (עם פתיחת נעילת הרכב)
- **הפסקות / המשכים** (אם יש)
- **כניסות / יציאות מאזור**
- **אזהרות מהירות**
- **סיום נסיעה** (עם נעילה / הוכחת חניה, אם יש)
- **אירועי תשלום**

השתמש בציר הזמן כדי לחקור מחלוקות ("הרוכב טוען שחויב לאחר סיום הנסיעה") — כל אירוע מתועד עם חותמת זמן.

### כרטיסיית פעילות

כרטיסיית הפעילות מציגה את יומן האירועים המלא כולל פעולות ברמת המערכת — רחב יותר מציר הזמן בפרטים. השתמש בה כאשר ציר הזמן הפשוט לא מספק פרטים מספיקים (למשל לאיתור תקלות טכניות ב-IoT).

## תהליכי עבודה טיפוסיים

- **חקור תלונת לקוח** — קרא את הפירוט, לאחר מכן את מפת המסלול וציר הזמן; ציר הזמן כמעט אף פעם לא משקר
- **בדוק החלטת החזר** — פתח את כרטיס הפירוט; שורות הפרטים מראות בדיוק על מה הלקוח שילם, ואז לחץ _פעולות → החזר נסיעה_
- **השהה ותקשר עם הלקוח** — _פעולות → השהה_ מקפיא את הנסיעה; _פעולות → שלח התראה_ מזכיר ללקוח; _המשך_ כשחזר
- **סיים נסיעה תקועה** — לנסיעות שלא נסגרות (איבוד חיבור, הלקוח השאיר את הרכב פתוח), השתמש ב_פעולות → סיום נסיעה_ כדי לאלץ סגירה — המערכת תשתמש במיקום האחרון הידוע להוכחת החניה

## טיפים

- **קרא את תיאור הכלי של פעולה מנוטרלת** — כפתורים מנוטרלים אינם שבורים; תיאור הכלי מסביר באיזה מצב הנסיעה צריכה להיות
- **העתק את מזהה הנסיעה** מהכותרת כדי להדביק בשיחת תמיכה או בשאילתא במערכת
- **פרטי התעריף מציגים את התעריף _כפי שהיה_** — גם אם התעריף נערך מאוחר יותר, תמונת המצב נשמרת לצורכי ביקורת
- **תיבת הדו-שיח של פעולות היא התפריט המלא** — אל תחפש החזר/ארכוב ברשימה; הם נמצאים כאן
