# נסיעות — רשימה

**נסיעה** היא טיול יחיד שנלקח על ידי לקוח באחד מהרכבים שלך. רשימת הנסיעות (`/rides`) היא הרשומה הראשית של כל טיול — עבר, נוכחי ועתידי — בכל הצי.

פתח שורה כדי לראות את [דף פרטי הנסיעה](ride-detail.md) עם המסלול, ציר הזמן וכל הפעולות.

הרשאה נדרשת: **נסיעות** (`i1j2k3`).

## כיצד נסיעות מופיעות כאן

אתה לא יוצר נסיעות בלוח המחוונים — הן נוצרות בצד הלקוח:

1. לקוח **פותח את נעילת הרכב** באפליקציה לנייד (Ridewolf rider app)
2. המערכת מאחור יוצרת רשומת נסיעה חדשה הקשורה לרכב וללקוח
3. הנסיעה מופיעה ברשימה זו מיד עם הסטטוס **פעיל**
4. כאשר הלקוח **נועל / מחנה** את הרכב, המערכת סוגרת את הנסיעה; הסטטוס משתנה ל-**הושלם** והחישוב הסופי (מרחק, משך, מחיר) מתבצע
5. מצבים סופיים אחרים (`מבוטל`, וכו') נובעים מחוקי המערכת או פעולות מפעיל

רענן או חזור לדף כדי למשוך את התמונה העדכנית ביותר — נסיעות פעילות מתעדכנות כאשר הלקוח נע.

## סדר ברירת מחדל

ברירת המחדל היא שהמערכת מחזירה **נסיעות פעילות ראשונות**, ואז נסיעות שהושלמו בסדר כרונולוגי הפוך (החדשות ביותר ראשונות). החל מיון עמודות כדי לעקוף את ברירת המחדל הזו.

## מסננים

| מסנן      | סוג          | הערות                                                                |
| ---------- | ------------ | -------------------------------------------------------------------- |
| חיפוש     | טקסט         | מחפש שם לקוח, תווית רכב, מזהה נסיעה                                |
| טווח תאריכים | לוח שנה     | בורר מ/עד; ברירת מחדל היא "כל הזמנים"                            |
| סטטוס     | תפריט נפתח  | `פעיל`, `הושלם`, `מבוטל`, וכו'                                    |
| דירוג     | תפריט נפתח  | סינון לפי דירוג כוכבים שהשאיר הרוכב (1–5, _ללא דירוג_)             |
| תגיות     | בחירה מרובה | סינון לפי תגיות נסיעה (יורשות מהרכב — ראה עמודות למטה)             |

כל המסננים משולבים עם AND. צ'יפים של מסננים מופיעים מעל הטבלה; כתובת ה-URL משקפת את מצב המסנן הנוכחי.

## עמודות

| עמודה   | ניתן למיין? | תוכן                                                               |
| -------- | ----------- | ----------------------------------------------------------------- |
| לקוח    | —           | אווטאר, שם, קישור לפרופיל הלקוח                                  |
| רכב     | —           | תווית, דגם, קישור לרכב                                            |
| תעריף   | —           | שם התעריף שהוחל על הנסיעה                                        |
| סטטיסטיקות | —         | תגיות מהירות: מרחק, משך, עלות ראשית                            |
| תגיות   | —           | תגיות שיורשות מה**רכב** ברגע שהנסיעה התחילה                      |
| סטטוס   | ✓           | כדור סטטוס (פעיל, הושלם, מבוטל, וכו')                           |
| דירוג   | ✓           | דירוג כוכבים שהשאיר הרוכב (או "–" אם אין)                      |
| נוצר    | ✓           | תאריך ושעת תחילת הנסיעה; מיון ברירת מחדל = החדשים ביותר ראשונים |

מיין על ידי לחיצה על כותרת שניתנת למיון. המיון שנבחר הוא חלק מכתובת ה-URL ו**מחליף** את סדר ברירת המחדל המתואר למעלה — אין לחיצה שלישית ל"שחזר ברירת מחדל", אבל אפשר לנקות את המיון על ידי עריכת ה-URL או רענון ללא פרמטר מיון.

> **תגיות יורשות מהרכב.** לנסיעות אין עורך תגיות משלהן — תגיות הנסיעה הן תמונת מצב של התגיות שהיו על הרכב כשהנסיעה התחילה. ערוך את תגיות הרכב מאוחר יותר והנסיעות הקיימות שומרות על תמונת המצב המקורית; רק נסיעות חדשות יקבלו את התגיות החדשות.

## פעולות שורה

לכל שורה יש **תפריט שלוש נקודות** בצד ימין. הפעולות הזמינות תלויות בסטטוס הנסיעה ובהרשאות שלך:

| פעולה        | הרשאה         | מתי מופעלת                                                   |
| ------------ | -------------- | ------------------------------------------------------------ |
| **השהה**     | `pause-unpause` | הנסיעה **פעילה** (לא כבר בהשהיה, הושלמה, בוטלה)            |
| **המשך**    | `pause-unpause` | הנסיעה **בהשהיה**                                           |
| **סיים נסיעה** | `end-ride`      | הנסיעה **לא** הושלמה או בוטלה                               |

פעולות שאין לך הרשאה אליהן מוסתרות. פעולות מנוטרלות (למשל סיום על נסיעה שכבר הושלמה) מופיעות באפור כדי שתוכל עדיין לראות מה אפשרי במצב הנכון.

מערך הפעולות המלא — החזר, הצגת מסלול במפה, שליחת התראה, ארכיון — נמצא ב**דף פרטי הנסיעה**. לחץ על השורה כדי לגשת אליהן.

## פעולות בדף

בפינה הימנית העליונה של דף הרשימה:

- **ייצא** — הורד את הרשימה המסוננת הנוכחית כקובץ (המסננים והמיון נשמרים)

## תרחישי עבודה טיפוסיים ברשימה

- **צפה בפעילות חיה** — פתח את הדף והישאר עליו; בראש הרשימה מוצגות נסיעות פעילות
- **מצא נסיעות באזור או חלון זמן** — שלב טווח תאריכים + סטטוס + תגיות
- **גלה חריגות** — סנן לפי `סטטוס = מבוטל` או `דירוג ≤ 2` וסרוק דפוסים (אותו רכב? אותה שעה ביום?)
- **עצור נסיעה תקועה במהירות** — בלי לעזוב את הרשימה, פתח את תפריט השורה ו_סיים נסיעה_ (דורש הרשאה)

## טיפים

- **כתובת ה-URL ניתנת לשיתוף** — סנן את הרשימה, העתק את הכתובת, שלח לעמית — הוא יקבל את אותה תצוגה
- **תגי סטטיסטיקות ברשימה** הם דרך מהירה לזהות נסיעות קצרות או ארוכות באופן חריג לפני לחיצה
- **אל תסמוך רק על הדירוג** — פתח את דף הפרטים לנסיעות עם דירוג נמוך; הדירוג הוא אחד ממספר אותות
- **הרשאות משתנות לפי חברה** — חלק מהמפעילים רואים רק נסיעות לרכבים שהם מנהלים; אם נסיעה חסרה לך, בדוק עם מנהל
