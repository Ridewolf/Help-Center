# איזון מחדש — נסיעות

דף נסיעות האיזון מחדש (`/rebalance/runs`) הוא **יומן תפעולי של כל נסיעת האיזון מחדש**: מי נהג באיזו ון, מאיזה מחסן יצא, כמה קורקינטים וסוללות נמצאים על הסיפון, האם הם בזמן, והיכן התרחשה תקלה.

**נסיעה** היא משמרת עבודה אחת בשטח — נהג, ון, מחסן מוצא, רשימת עצירות מסודרת, וחלון זמן משוער להגעה. הדף מאפשר למפעילים לעקוב אחרי נסיעות פעילות ולסקור נסיעות שהושלמו.

דף זה הוא תצוגת פרטי נסיעה שמ ergänzt את הסיכום ברמה גבוהה יותר [Analytics — Rebalance](runs.md) ואת לוח ה[Rebalance — Dead Zones](dead-zones.md) המונחה מיקום.

הרשאה נדרשת: מפעיל מחובר (הנתיב דורש רק _requiresAuth_, ללא מזהה הרשאה ספציפי).

> הערה — בזמן כתיבת שורות אלו, נקודות הקצה של `/rebalance/runs` ל-CRUD עדיין לא פעילות. הדף מציג את בלוק המסננים, שורת KPI ופריסת הטבלה מול KPI מדומים ורשימה ריקה. _צור נסיעה_, _חפש_, _רענון אוטומטי_, ותפריט הפעולות לכל שורה (_שלח_, _הקצה מחדש_, _אופטימיזציה מחדש_, _הדפס גיליון_, _ייצא_, _ערוך_, _בטל_) מחוברים בקוד אך מוגדרים כהערה עד שהשרת יהיה מוכן. לחיצה על שורה מפנה ל-`/rebalance/runs/:id` אך דף הפרטים אינו חלק מבנייה זו.

## שורת KPI (למעלה)

שורה של חמישה כרטיסי KPI מסכמת את נסיעות היום.

| KPI                | מה הוא מציג                                                                                  |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **נסיעות פעילות**  | נסיעות במצב _נשלח_ / _בתהליך_ / _מושהה_                                                  |
| **אחוז בזמן**      | אחוז נסיעות שהגיעו במסגרת חלון ה-ETA המתוכנן; מגמת עלייה ירוקה ≥ 90%, מגמת ירידה אדומה מתחת לכך |
| **נסיעות מאחרות**  | ספירת נסיעות שסומנו כ-_מאחרות_ במסגרת SLA — אינדיקטור "מה זקוק לעזרה" של המפעיל           |
| **סה"כ ק"מ היום** | מרחק מצטבר שנסעו כל הוונים לאיזון מחדש היום                                              |
| **החלפות סוללות**  | סך כל החלפות הסוללות שבוצעו על ידי צוות השטח היום                                        |

חמישיית הכרטיסים יחד מציגה תמונת מצב בבת אחת של התפעול בשטח היום מול התוכנית.

## מסננים

ארבעה מסננים נמצאים בכרטיסיית _מסננים_; כולם מחוברים ב-AND. כפתור _נקה הכל_ מימין מאפס את הבלוק.

| מסנן              | סוג       | אפשרויות                                                                                  |
| ----------------- | --------- | ----------------------------------------------------------------------------------------- |
| **סטטוס**         | תפריט נפתח | _הכל_ / _מתוכנן_ / _נשלח_ / _בתהליך_ / _מושהה_ / _הושלם_ / _בוטל_                      |
| **סיכון SLA**      | תפריט נפתח | _הכל_ / _במסלול_ / _בסיכון_ / _מאחר_ — דגל האיחור של הנסיעה                            |
| **עיר**           | תפריט נפתח | _כל הערים_ / _מוסקבה_ / _סנט פטרסבורג_                                                |
| **יש תקלות**      | תפריט נפתח | _הכל_ / _כן_ / _לא_ — תקלות שנרשמו כנגד הנסיעה                                       |

בקרת _חיפוש_ חופשית (לפי מספר נסיעה, נהג או ון) מיושמת אך כרגע מוסתרת יחד עם _רענון אוטומטי_ ו-_צור נסיעה_ עד שהנקודה תושק.

## עמודות

לטבלה יש תשע עמודות נראות. שורות ניתנות ללחיצה — הן מפנות ל-`/rebalance/runs/:id` (תצוגת פרטים לא כלולה בבנייה זו).

| עמודה                | תוכן                                                                                                                  |
| --------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **מספר נסיעה**        | מזהה נסיעה קריא לבן אדם (למשל `RUN-2026-0517-001`)                                                                 |
| **נהג / ון**          | אווטאר נהג + שם + טלפון; מתחת דגם הוון + מספר לוחית הרישוי                                                    |
| **מחסן / עיר**        | שם מחסן המוצא והעיר שלו                                                                                            |
| **סטטוס**             | סמל סטטוס — אפור _מתוכנן_, כחול _נשלח_, ירוק _בתהליך_, צהוב _מושהה_, טורקיז _הושלם_, אדום _בוטל_              |
| **עצירות**            | התקדמות כ-`בוצע / סה"כ`, עם _נכשל: N_ מתחת באדום כאשר עצירה כלשהי נכשלה                                |
| **מטען**              | קורקינטים טעונים (`🛴 ב / קיבולת`) וסוללות טעונות (`🔋 טעונות + פרוקות / קיבולת`)                              |
| **מתוכנן**            | זמן התחלה–סיום משוער + מרחק מתוכנן (ק"מ) ומשך (דקות)                                                           |
| **סיכון SLA**          | סמל סיכון — ירוק _במסלול_, כתום _בסיכון_, אדום _מאחר_                                                        |
| **נוצר / עודכן**      | תאריך יצירה למעלה, תאריך עדכון אחרון למטה                                                                        |

עמודת הפעולות (תפריט שלוש נקודות) מיושמת אך מוגדרת כהערה עד שהנקודות CRUD יהיו זמינות; ראה _פעולות שורה_ למטה עבור הסט המתוכנן.

## הפניה לסטטוס

נסיעה נמצאת בדיוק בסטטוס אחד; הסטטוס מכתיב אילו פעולות שליחה זמינות:

| סטטוס          | משמעות                                               |
| --------------- | ----------------------------------------------------- |
| **מתוכנן**     | נוצר ותוזמן אך עדיין לא נשלח לנהג                      |
| **נשלח**       | נשלח לנהג / ון — ממתין ליציאה                        |
| **בתהליך**     | הוון בתנועה ו/או מבצע עצירות                          |
| **מושהה**      | הנהג השהה את הנסיעה (הפסקה, תקלה, וכו')              |
| **הושלם**      | כל העצירות בוצעו, הנסיעה נסגרה                         |
| **בוטל**       | בוטל לפני סיום                                       |

## התראה על סיכון SLA

דגל בזמן אמת האם הריצה תעמוד במסגרת הזמן המתוכננת שלה:

| סיכון         | משמעות                                              |
| ------------ | ---------------------------------------------------- |
| **במסלול**   | הקצב הנוכחי תואם את זמן ההגעה המתוכנן (ETA)        |
| **בסיכון**   | מגמה של איחור, אך עדיין בטווח שניתן לתיקון          |
| **מאוחר**   | התוכנית כבר נפגעה — דורש תשומת לב מהמשגר            |

השתמש ב_סיכון SLA = מאוחר_ כמסנן הראשון של המשגר בבוקר.

## פעולות שורה (מתוכננות)

לכל שורה יהיה תפריט שלוש נקודות מימין עם הפעולות הבאות; כיום העמודה מוסתרת עד לקבלת ה-API.

| פעולה           | מה היא תעשה                                               |
| --------------- | ---------------------------------------------------------- |
| **הצג**        | פותח את דף פרטי הריצה בכתובת `/rebalance/runs/:id`                          |
| **שלח**        | מעביר ריצה _מתוכננת_ ל_נשלחה_, ומודיע לנהג                  |
| **הקצה מחדש**  | משנה את הנהג ו/או הרכב בריצה                                |
| **אופטימיזציה מחדש** | מריץ מחדש את אופטימיזציית המסלול על התחנות שנותרו       |
| **הדפס דף**    | מייצר דף ריצה להדפסה (סיכום לנהג)                         |
| **ייצא**       | מייצא את נתוני הריצה כקובץ (מסננים ומיון נשמרים)           |
| **ערוך**        | פותח את עורך הריצה                                         |
| **בטל**        | מבטל את הריצה — פותח תיבת אישור                            |

## מצבי ריק / טעינה

- **טעינה** — סיבובון עם הטקסט "טוען ריצות…" בזמן שאחורי הקלעים נשאל
- **שגיאה** — באנר _התראה_ עם כפתור _נסה שוב_ אם הבקשה נכשלה
- **ריק** — אייקון _משאית_ במרכז עם הטקסט "לא נמצאו ריצות"; זהו המצב **הצפוי כיום** מאחר שהנקודת קצה מחזירה אפס פריטים

## תזרימי עבודה טיפוסיים

- **סינון משגר בבוקר** — סנן לפי _סטטוס = מתוכנן_, מיין לפי תאריך יצירה, ושלח כל ריצה לפי הסדר
- **מעקב חי** — סנן לפי _סטטוס = בתהליך_, ואז _סיכון SLA = מאוחר_ כדי להציג נהגים הזקוקים לעזרה; לאחר הפעלה, _רענון אוטומטי_ שומר על תצוגה מעודכנת
- **סקירת סוף יום** — סנן לפי _סטטוס = הושלם_, סרוק את עמודת _תחנות_ עבור ריצות עם תחנות שנכשלו, לחץ על כל אחת לסיכום האירוע
- **עיר-עיר** — סנן לפי _עיר_ בעת הפעלת תפעול רב-עירוני; השווה ספירות מול דף [Analytics — Rebalance](runs.md)
- **מיון אירועים** — סנן לפי _יש אירועים = כן_ כדי להציג כל ריצה שבה אירע תקלה היום
- **בדיקת קיבולת** — הסתכל על עמודת _משקל_ בשורות _בתהליך_; רכבים קרובים לקיבולת עשויים להזדקק לחזרה למוסך בקרוב

## טיפים

- **מספרי ריצה הם מזהים יציבים** — שתף אותם עם צוות השטח לתיאום ברור ("תסתכל על RUN-2026-0517-003")
- **עמודת תחנות משקפת את המצב במבט חטוף** — `4/7` פירושו ארבע הושלמו, שלוש נשארו; _נכשל: N_ באדום מתחת = דורש מעקב
- **"משקל" מותש חשוב** — ספירת סוללות מותשות גבוהה פירושה שהרכב מלא בסוללות מתות וצריך לעבור טעינה
- **נוצר לעומת עודכן** — _עודכן_ מתעדכן בכל פעם שהנהג פועל בריצה; _עודכן_ ישן בשורה _בתהליך_ = הנהג לא דיווח זמן מה
- **סטטוס _מושהה_ אינו שגיאה** — נהגים עוצרים להפסקות, אירועים ואינטראקציות עם רוכבים; ריצות מושהות זמן רב שוות שיחת טלפון
- **עד שהנקודת קצה תושק, התייחס לעמוד זה כסקיצה / תצוגת UX** — המבנה, המסננים והשפה הוויזואלית סופיים; הנתונים מאחוריהם אינם
