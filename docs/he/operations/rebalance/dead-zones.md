# איזורי דומם — Rebalance

דף איזורי הדומם (`/rebalance/dead-zones`) הוא **לוח היעדים לתפעול בשטח**: איפה המלאי שלך עומד ללא שימוש, כמה הכנסות זה עולה לך, ואילו אזורים לשלוח אליהם את רכב ה-Rebalance הבא.

בניגוד לדף [Analytics — Rebalance](runs.md), המסכם פעילות צוות השטח לאורך זמן, דף זה מביט קדימה: הוא עונה על השאלה _לאן אנחנו הולכים עכשיו?_

הרשאה נדרשת: מפעיל מחובר (הנתיב דורש _requiresAuth_ בלבד, ללא מזהה הרשאה ספציפי).

## מה משמעות "אזור דומם"

**אזור דומם** הוא אזור בעיר שבו רכבים מבלים זמן רב מדי בחניה ללא השכרה. הדף מזהה אותם ומדרג אותם כדי שהצוות בשטח ידע באילו אשכולות לפרק קודם.

המערכת תומכת בשתי דרכים לחלוקת המפה:

- **אזורים בבעלותך** — הפוליגונים שהגדרת ב-[הגדרות — אזורים](../../settings/infrastructure/zones.md)
- **רשת H3** — רשת משושים של Uber, לשימוש בניתוח מדויק יותר או ללא תלות באזורים

המתג נמצא בבלוק המסננים; הטבלה מציגה את אותן עמודות בכל מקרה.

## שורת KPI (למעלה)

שורה של חמישה כרטיסי KPI מסכמת את מצב אזורי הדומם בהתאם לסינון שבחרת.

| KPI                 | מה הוא מציג                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------ |
| **אזורים דוממים**   | ספירת אזורים / תאים המסומנים כיום כדוממים                                           |
| **הפסד יומי**       | הכנסה מוערכת אבודה ליום — סכום `lostRevenuePerDay` על פני האזורים המסוננים      |
| **מכשירים תקועים**  | סך המכשירים הלא פעילים התקועים באזורים הדוממים — יעד האיסוף הפיזי שלך                   |
| **זמן שהייה ממוצע** | זמן שהייה ממוצע (בדקות) באזורים הדוממים — כמה זמן רכב עומד לפני תנועה |
| **התקדמות שבועית** | שינוי באחוזים לעומת השבוע שעבר — שלילי = מצב מחמיר; חיובי = משתפר         |

כל KPI מתעדכן בהתאם לסינון; השתמש בהם כבדיקת תחושה במספר יחיד לפני חקירה מעמיקה ברשימה.

## מצבי תצוגה — מפה מול טבלה

מתג בפינה הימנית העליונה מחליף בין שתי הצגות של אותם נתונים:

- **מפה** — תצוגה גאוגרפית של אזורי הדומם על גבי העיר (כרגע מציין _בקרוב_)
- **טבלה** — רשת הנתונים למטה, עם כל העמודות והקשר לכל שורה

המסננים חלים על שתי התצוגות. _טבלה_ היא ברירת המחדל; _מפה_ מחוברת אך ההצגה הגאוגרפית עדיין בבנייה.

בקרת _רענון אוטומטי_ נמצאת ליד מתג התצוגה — הפעל אותה כדי לבצע שאילתות מחודשות על בסיס קבוע (שימושי לתפעול חי).

## מסננים

בלוק המסננים כולל ארבעה בקרים; כולם מחוברים ב-AND:

| מסנן          | סוג       | הערות                                                                             |
| ------------- | --------- | --------------------------------------------------------------------------------- |
| **עיר**       | תפריט נפתח | _כל הערים_ / _מוסקבה_ / _סנט פטרסבורג_ — צמצום לעיר תפעול אחת       |
| **חומרה**    | תפריט נפתח | _הכל_ / _נמוך_ / _בינוני_ / _גבוה_ / _קריטי_ — מבוסס על ציון חומרת האזור |
| **סוג אזור** | תפריט נפתח | _אזורים בבעלותך_ / _רשת H3_ — איזו רשת להשתמש                                   |
| **חיפוש**    | טקסט      | טקסט חופשי — מתאים לשם אזור / מחוז                                          |

כפתור _נקה הכל_ בצד ימין של כרטיס המסנן מאפס את כל הבקרים בלחיצה אחת.

## עמודות

תצוגת הטבלה כוללת תשע עמודות. לחץ על שורה כדי לפתוח את מגירת התובנות של האזור (כרגע מציג הודעת טוסט עם שם האזור כממלא מקום).

| עמודה                | תוכן                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **אזור / תא**       | שם האזור עם העיר והמחוז מתחת; במצב H3 זהו מזהה המשושה                   |
| **יחס חניה**        | אחוז הזמן שבו יש מכשירים לא פעילים באזור, בצבעים: ירוק `< 25%`, כתום `25–40%`, אדום `≥ 40%` |
| **זמן שהייה**        | זמן שהייה חציוני בדקות, עם _p90_ מתחתיו                                               |
| **ממוצע מכשירים לא פעילים** | ספירת ממוצע רכבים לא פעילים באזור, עם ה_יעד_ להשוואה               |
| **התחלות**          | התחלת נסיעות באזור ב-_24 השעות האחרונות_ / _7 הימים האחרונים_ / _30 הימים האחרונים_                                  |
| **המרה**            | התחלות לכל רכב לא פעיל לשעה — ירוק `≥ 0.30`, כתום `0.15–0.30`, אדום `< 0.15`                 |
| **עודף אספקה**      | מכשירים מעבר ליעד — חיובי = יותר מדי, שלילי = מעט מדי; חיובי מוצג באדום                 |
| **הפסד יומי**       | הכנסה מוערכת אבודה לאזור זה בלבד                                                        |
| **נראה לאחרונה לא פעיל** | מתי האזור היה עם מכשירים לא פעילים לאחרונה — מעוצב לפי המיקום שלך                                    |

השורות ניתנות ללחיצה; מיון העמודות עדיין לא מחובר בגרסה זו.

## פעולות שורה

לכל שורה יש מטפל בלחיצה שמציג כיום הודעת טוסט עם שם האזור. **תפריט הפעולות (לכל שורה)** מיושם בקוד אך כרגע מושבת עד לקבלת ה-API. הפעולות המתוכננות מפורטות למטה כהפניה — הן יופיעו בתפריט שלוש הנקודות בצד ימין של כל שורה ברגע שיופעלו:

| פעולה מתוכננת           | מה היא תעשה                                                          |
| ------------------------ | ------------------------------------------------------------------------ |
| **צור ריצה**             | פותח את בונה ריצות האיזון מראש עם האזור הזה מלא מראש                  |
| **הגדר מגבלת זמן חניה**  | מהדק את זמן החניה המקסימלי בתוך האזור                                 |
| **תמחור דינמי**          | מיישם מנופים של מחיר כדי למשוך או להרתיע נסיעות שמתחילות או מסתיימות כאן |
| **ניתוח אזור**           | ערוך את גבול האזור (פיצול, מיזוג, שינוי צורה)                         |
| **סמן כאזור ללא חניה**  | המיר את האזור לאזור ללא חניה כדי לדחוף את הרכבים החוצה              |
| **הפחתת יעד אספקה**     | הורד את יעד המכשירים כך שהמערכת תפסיק לשלוח רכבים לכאן                |
| **ניסוי A/B**            | הקם ניסוי מבוקר על אסטרטגיית תיקון                                   |

עד שהנקודת קצה תושק, התייחס לטבלה כאל **משטח תובנות לקריאה בלבד** — שלב אותה עם רשימת הרכבים כדי לפעול על רכבים בנפרד.

## מצבי ריק / טעינה

- **טעינה** — סיבובון עם הטקסט "טוען אזורי מתים…" בזמן שהמערכת שואלת את השרת
- **שגיאה** — באנר _התראה_ עם כפתור _נסה שוב_ אם הבקשה נכשלה
- **ריק** — אייקון _AlertTriangle_ במרכז עם הטקסט "אין אזורי מתים"; זהו ה**מצב הצפוי כיום** כי נקודת הקצה מחזירה אין נתונים

## זרימות עבודה טיפוסיות

- **תכנון בוקר** — מיין את הטבלה לפי _אבוד ליום_ (ויזואלית, היום; עמודות למיון יגיעו): בחר את 3 האזורים העליונים להקצאה לריצות של היום
- **מיון חומרה** — סנן לפי _חומרה = קריטי_ כדי לראות רק את המפרים הגרועים ביותר, ואז פתח כל אזור להקשר
- **תפעול עיר-עיר** — סנן לפי _עיר_ בעת הפעלת תפעול רב-עירוני; סקור את הספירה וההכנסה האבודה הכוללת בנפרד
- **השוואה עם הצי** — השתמש במספר _מכשירים כלואים_ משורת ה-KPI, ואז קפוץ ל[רשימת הרכבים](../fleet/vehicles.md) המסוננת לפי אזור כדי לראות את הרכבים בפועל
- **שילוב עם ניתוחים** — השווה את הספירה החיה כאן מול [ניתוחים — איזון](runs.md) ו[ניתוחי רכבים](../../analytics/reports/vehicles.md) בקטעי אזורי מתים / מכשירים לא פעילים כדי לאשר את המגמה

## טיפים

- **המרה היא העמודה התפעולית החשובה ביותר** — המרה נמוכה (אדום) עם עודף אספקה גבוה אומרת שאיזון האזור _לא יעזור_; יש לך את האספקה הנכונה אבל הביקוש לא שם
- **יחס לא פעיל לעומת ממוצע מכשירים לא פעילים** — _יחס לא פעיל_ הוא משוקלל לפי זמן (כמה זמן האזור לא פעיל), _ממוצע מכשירים לא פעילים_ הוא משוקלל לפי ספירה (כמה יושבים שם). שניהם אדומים = האות החזק ביותר לאזור מת
- **היעד תחת _ממוצע מכשירים לא פעילים_ מגיע מהגדרת האזור** — אם הוא מוגדר לא נכון, כל אזור ייראה מת; בדוק ב[הגדרות — אזורים](../../settings/infrastructure/zones.md)
- **רשת H3 שימושית לערים ללא אזורים מוגדרים** — כשעדיין לא הגדרת אזורי מפעילים, H3 נותנת דלי גאוגרפי ברירת מחדל
- **התקדמות שבועית היא מדד "האם מנצחים" של הדף** — אם ספירת אזורי המתים עולה אבל ההכנסה האבודה יורדת, צוות השטח עובד קודם על האזורים בעלי הערך הגבוה ביותר (סימן טוב)
- **המטפלים בפעולות הם דמויות** — לחיצה על שורה מפעילה כרגע רק התראה מידע; המגירות / דיאלוגים האמיתיים יגיעו כשהשרת יהיה מוכן
