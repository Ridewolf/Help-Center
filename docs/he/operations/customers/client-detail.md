# פרטי לקוח

דף פרטי הלקוח (`/clients/:id`) הוא שולחן העבודה עבור לקוח יחיד. השתמש בו כדי לסקור מידע אישי, לבצע פעולות על היתרה (הפקדה, קנס), לחסום / להסיר חסימה, לשלוח הודעות, ולבדוק את היסטוריית הנסיעות ופעילות החשבון של הלקוח.

בדרך כלל מגיעים לכאן על ידי לחיצה על שורה ב[רשימת הלקוחות](clients.md) או מדף פרטי נסיעה (הקישור ללקוח בכותרת).

הרשאה נדרשת: **לקוחות** (`e4f5h6`). פעולות ספציפיות דורשות הרשאות משנה (מצוינות להלן).

## פריסה

מלמעלה למטה:

1. **כותרת** — חזור, שם, סטטוס, כפתור _פעולות_
2. **כרטיסי סקירה** — יתרה, נסיעות, דירוג, סטטוס (4 אריחי KPI)
3. **כרטיסיות** — פרטים / פעילות / היסטוריה

## כותרת

הרצועה העליונה מזהה את הלקוח:

- **כפתור חזור** (`←`) מחזיר לרשימה
- **שם** (פרטי + משפחה) ו**כפתור סטטוס** (פעיל / חסום / מוקפא / ברישום)
- כפתור **פעולות** מימין — פותח את תיבת הדו-שיח של הפעולות

## פעולות

לחיצה על **פעולות** פותחת תיבת דו-שיח עם כל פעולת מפעיל זמינה עבור לקוח זה. כל פעולה מוגנת בהרשאה:

| פעולה               | הרשאה              | מה היא עושה                                                               |
| ------------------- | ------------------- | -------------------------------------------------------------------------- |
| **הפקדת יתרה**      | `topup-manual`      | פותח את תיבת הדו-שיח להפקדת כסף לארנק של הלקוח                            |
| **הטלת קנס**        | `fine`              | פותח את תיבת הדו-שיח להורדת כסף מהארנק (נזק, חניה, וכו')                 |
| **שליחת הודעת פוש** | —                   | פותח תיבת דו-שיח לשליחת התראה באפליקציה של הלקוח                         |
| **חסימה / הסרת חסימה** | `block` / `unblock` | משנה את סטטוס החסימה של הלקוח עם סיבה אופציונלית                        |
| **עריכת לקוח**      | `edit`              | פותח את [טופס העריכה](client-create-edit.md)                              |
| **מחיקת לקוח**      | `delete`            | מחיקה רכה עם תיבת אישור (פריט הרסני אדום)                                |

פעולות שאין לך הרשאה אליהן מוסתרות.

## כרטיסי סקירה

שורה של ארבעה כרטיסים מתחת לכותרת מסכמת את הלקוח במבט חטוף:

| כרטיס       | מה הוא מציג                                                                       |
| ----------- | ----------------------------------------------------------------------------------- |
| **יתרה**    | יתרת הארנק במטבע החברה (אדום אם שלילי)                                           |
| **נסיעות**  | ספירת נסיעות מצטברת                                                              |
| **דירוג**   | דירוג ממוצע שהרוכבים נתנו ללקוח זה                                              |
| **סטטוס**   | הסטטוס הנוכחי עם כותרת משנה בשורה אחת ("פעיל / חסום / מוקפא / ברישום")       |

## כרטיסיות

שלוש כרטיסיות:

| כרטיס       | מה יש בפנים                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| **פרטים**   | מידע אישי (שם, אימייל, טלפון, סטטוס, יתרה, תגיות) ולוח **התקנים** (התקנים מחוברים)                   |
| **פעילות**  | פעולות מפעיל ומערכת בחשבון הלקוח (שינויים בסטטוס, עריכות יתרה, וכו')                                   |
| **היסטוריה**| היסטוריית הנסיעות של הלקוח — חתך ממוקד של רשימת הנסיעות העולמית, ממוקד ללקוח זה                          |

### כרטיסיית פרטים

הצפייה העמוקה ביותר במצב חשבון הלקוח. שני אזורים:

**מידע אישי (רשת):**

- שם פרטי
- שם משפחה
- אימייל (מדד אימות)
- טלפון (מדד אימות)
- סטטוס (עם כפתור הסטטוס)
- יתרה (מעוצבת במטבע החברה)
- תגיות (השבבים שהוחלו על לקוח זה)

**לוח התקנים:**

רשימה של כל התקן שנכנס לאפליקציית Rider תחת חשבון זה, עם חותמות זמן של הפעם האחרונה שנצפה והאפשרות לשלוח פוש (כשמותר) או להתנתק מההתקן. שימושי לחקירות אבטחה ומקרי תמיכה של "אני לא מצליח להתחבר".

### כרטיסיית פעילות

**יומן הפעילות** הכרונולוגי עבור לקוח זה: כל פעולה של מפעיל (הפקדה, קנס, שינוי סטטוס, עריכה, שליחת SMS/אימייל/פוש) וכל אירוע מערכת (אבני דרך ברישום, שינויים במצב אימות, התאמות יתרה מהחזרים).

שימושי לציות, פתרון סכסוכים ואחריות.

### כרטיסיית היסטוריה

**היסטוריית הנסיעות** של הלקוח בטבלה — פורמט שורה זהה לרשימת הנסיעות העולמית, מסוננת מראש ללקוח זה. לחץ על כל שורה כדי לפתוח את פרטי הנסיעה.

כרטיסיה זו היא נקודת ההתחלה שלך למקרי "הלקוח טוען שהנסיעה X הייתה שגויה".

## תרחישי עבודה טיפוסיים

- **הלקוח טוען שהארנק שגוי** — פתח פרטים (יתרה נוכחית), אחר כך פעילות (חפש את שינוי היתרה האחרון), ואז היסטוריה (אמת את הנסיעה שגרמה לניכוי). אם משהו היה שגוי, _פעולות → הפקדת יתרה_ עם סיבה
- **הלקוח מדווח על טלפון אבוד** — פרטים → התקנים → התנתק מההתקן האבוד (כשנתמך); אופציונלי לנעול את הארנק דרך _פעולות → חסימת לקוח_ עד שיקבלו גישה מחדש
- **הונאה או שימוש לרעה** — פעילות לציר הזמן, היסטוריה לנסיעות החשודות; ואז _פעולות → חסימת לקוח_ עם סיבה; הסיבה נשמרת ביומן הפעילות
- **החזר מתוך רצון טוב** — _פעולות → הפקדת יתרה_ עם תיאור כמו "החזר מתוך רצון טוב — כרטיס #12345"; התיאור נראה בפעילות למעקב
- **פנייה לקבלת פנים / הטמעה** — _פעולות → שליחת פוש_ עם הודעת קבלת פנים; בדוק קודם התקנים לוודא שיש סשן פעיל

## טיפים

- **עקבו אחרי כרטיס הסטטוס** — גם אם הכל נראה תקין, סטטוס _חסום_ או _קפוא_ מסביר מדוע הלקוח לא יכול לנסוע
- **לוח המכשירים הוא נקודת ההתחלה לאיתור תקלות** — רוב המקרים של "אני לא יכול להתחבר" נובעים מישיבת מכשיר מיושנת
- **תיאורי טעינה וקנסות מופיעים בפעילות** — כתבו משהו שמפעילים יוכלו לחפש אחריו מאוחר יותר ("כרטיס #X", "החזר עבור נסיעה Y") במקום רק מספר
- **עריכה מיועדת למטא-דאטה** — שם, אימייל, טלפון — לא ליתרה. השתמשו בדיאלוגים הייעודיים ליתרה (עם מעקב ביקורת) לפעולות כספיות
- **הדירוג הוא דירוג ה_נהג_ של הלקוח** — דירוג נמוך בשילוב עם עליות בהוכחות חניה / כרטיסים בדרך כלל מצביע על רוכב בעייתי
- **כתובת ה-URL מכילה את מזהה הלקוח** — הדביקו אותה בשיחת תמיכה כדי לשתף את הפרופיל המדויק
