# לקוחות — רשימה

רשימת הלקוחות (`/clients`) היא מאגר הלקוחות שלך: כל אדם שנרשם לשירות שלך, עם היתרה שלו, תגיות, סיכום היסטוריית נסיעות וערוצי התקשרות.

לעבודה פרטנית עם לקוח (היסטוריה מלאה, פעולות יתרה, מכשירים, הערות) פתח את [דף פרטי הלקוח](client-detail.md).

הרשאה נדרשת: **לקוחות** (`e4f5h6`). הרשאות משנה נוספות מגבילות פעולות שורה ופעולות מרובות ספציפיות.

## כיצד לקוחות מופיעים כאן

בדרך כלל אינך יוצר לקוחות בלוח המחוונים — הם נרשמים דרך אפליקציית הנוסע לנייד:

1. אדם מתקין את **אפליקציית Ridewolf rider** ונרשם (טלפון או אימייל)
2. המערכת יוצרת רשומת לקוח; השורה מופיעה כאן במצב **בתהליך רישום** בזמן שהאימות (SMS, תעודה, אמצעי תשלום) מתבצע
3. לאחר השלמת האימות, הסטטוס משתנה ל-**פעיל** — הלקוח יכול לבצע נסיעות
4. מפעילים יכולים ליצור לקוחות ידנית (למשל עבור חשבונות VIP או בדיקה) דרך `+ צור` — מוסבר במאמר _יצירה_

הרשימה מתעדכנת כאשר אתה טוען מחדש או משנה מסננים.

## מסננים

| מסנן       | סוג          | הערות                                                      |
| ---------- | ------------ | ---------------------------------------------------------- |
| חיפוש      | טקסט         | מחפש בשם, טלפון, אימייל, מזהה לקוח                        |
| טווח תאריכים | לוח שנה     | מסנן לפי **תאריך רישום**; מ־ / עד                          |
| סטטוס      | תפריט נפתח  | `פעיל` / `חסום` / `קפוא` / `בתהליך רישום` (או `הכל`)      |
| תגיות      | בחירה מרובה | מסנן לפי תגיות שהוחלו על הלקוח                            |

כל המסננים מחוברים ב-AND. צ'יפים של מסננים מופיעים מעל הטבלה; כתובת ה-URL משקפת את המצב הנוכחי.

## עמודות

| עמודה         | ניתן למיין? | תוכן                                                                          |
| ------------- | --------- | ----------------------------------------------------------------------------- |
| **לקוח**      | ✓         | אווטאר + שם פרטי/משפחה + טלפון או אימייל; קישור לפרטי הלקוח                 |
| **ערוצים**   | —         | אייקונים של ערוצי התקשרות שהלקוח אימת (טלפון, אימייל, רשתות חברתיות)       |
| **יתרה**     | ✓         | יתרת הארנק במטבע החברה, בצבע אדום כאשר שלילי                              |
| **תגיות**    | —         | תגיות שהוחלו על לקוח זה                                                    |
| **סטטוס**    | ✓         | סמן סטטוס (ראה הפניה למטה)                                                 |
| **דירוג**    | ✓         | דירוג ממוצע שנוסעים השאירו ללקוח זה (דירוג נהג)                            |
| **נסיעות**   | ✓         | סך כל נסיעות בחיים                                                        |
| **נסיעה אחרונה** | ✓      | מתי הלקוח ערך את נסיעתו האחרונה                                          |
| **תשלום**    | —         | אייקון אמצעי התשלום המוגדר כברירת מחדל (כרטיס, ארנק וכו')                   |

מיין על ידי לחיצה על כותרת שניתנת למיון. המיון הוא חלק מכתובת ה-URL.

## הפניה לסטטוס

| סטטוס          | משמעות                                                                              |
| --------------- | ------------------------------------------------------------------------------------ |
| **פעיל**       | מאומת במלואו, יכול לבצע נסיעות, ניתן לחייב אותו                                   |
| **חסום**       | לא יכול לבצע נסיעות; חסימה ביוזמת מפעיל (הונאה, שימוש לרעה, חוב) או מערכתית       |
| **קפוא**       | החשבון מוקפא (למשל בזמן בדיקת מחלוקת, או לפי בקשת הלקוח)                        |
| **בתהליך רישום** | תהליך ההרשמה בעיצומו — טלפון / אימייל / תעודה / אמצעי תשלום עדיין לא אומתו       |

## פעולות שורה

לכל שורה יש **תפריט שלוש נקודות** מימין. הפעולות הזמינות תלויות בהרשאות שלך:

| פעולה               | הרשאה              | מה היא עושה                                                                       |
| ------------------- | ------------------- | ---------------------------------------------------------------------------------- |
| **הצג פרופיל**     | —                   | פתח את [דף פרטי הלקוח](client-detail.md)                                        |
| **היסטוריית נסיעות** | —                 | פתח את תצוגת הנסיעות של הלקוח (חתך ממוקד של רשימת הנסיעות הכללית)              |
| **שלח SMS**         | —                   | פתח דיאלוג לשליחת SMS לטלפון המאומת של הלקוח                                    |
| **שלח אימייל**      | —                   | פתח דיאלוג לשליחת אימייל לכתובת המאומתת של הלקוח                                |
| **שלח פוש**         | —                   | פתח דיאלוג לשליחת התראה דחופה לאפליקציה של הלקוח                                |
| **הטען יתרה**       | `topup-manual`      | פתח דיאלוג יתרה — הטען כסף לארנק של הלקוח                                       |
| **הטלת קנס**        | `fine`              | פתח דיאלוג קנס — נכה כסף מהארנק (עבור נזק, חניה וכו')                            |
| **חסום / בטל חסימה** | `block` / `unblock` | פתח דיאלוג חסימה — החלף את סטטוס החסימה של הלקוח עם סיבה אופציונלית              |
| **ערוך**             | `edit`              | פתח את [טופס העריכה](client-create-edit.md)                                     |
| **מחק**              | `delete`            | מחיקה רכה של רשומת הלקוח (עם אישור; פריט הרסני באדום)                           |

פעולות שאין לך הרשאה אליהן מוסתרות מהתפריט.

## פעולות מרובות

בחר לקוח אחד או יותר באמצעות תיבות הסימון משמאל. סרגל **פעולות מרובות** מופיע למעלה עם מספר הנבחרים והפעולות:

| פעולה מרובה       | הרשאה              | מה היא עושה                                                             |
| ----------------- | ------------------- | ------------------------------------------------------------------------ |
| **הוסף יתרה**     | `topup-manual`      | זיכוי סכום יחיד לכל ארנק שנבחר (עם אישור)                              |
| **חיוב סכום**     | `fine`              | חיוב סכום יחיד מכל ארנק שנבחר (למשל קנס אירועי)                        |
| **שנה סטטוס**    | `block` / `unblock` | קביעת אותו סטטוס לכל לקוח שנבחר (פעיל / חסום / מוקפא)                  |
| **שלח הודעת פוש** | —                   | שליחת התראה לכל הלקוחות שנבחרו בבת אחת                                |

תיבות הדו-שיח של הפעולות המרובות מנווטות אותך דרך הסכום / ההודעה / הסטטוס, ואז מיישמות על כל השורות שנבחרו בפעולה אחת עם אישור סופי.

## פעולות בדף (למעלה מימין)

- **+ צור** — פותח את [טופס יצירת לקוח](client-create-edit.md) (מאמר נפרד)

## זרימות עבודה טיפוסיות

- **חקור תלונת תשלום** — חפש לפי טלפון או אימייל → פתח פרטים → בדוק יתרה והיסטוריית נסיעות
- **הוסף כסף לארנק לפי בקשת מפעיל** — מצא את הלקוח, _הוסף יתרה_ בתפריט השורה, מלא את הסכום, אשר
- **חסום רמאי** — חפש את הלקוח → _חסום / בטל חסימה_ → קבע סטטוס חסום עם סיבה; הסטטוס משתנה ל_חסום_, אין נסיעות נוספות
- **שלח SMS על תקלה** — סנן לפי תג אזור → _בחר הכל_ → _שלח פוש_ (או השתמש ב-שיווק → SMS לשידורים לא דחופים)
- **בדוק מחזיקי תג** — סנן לפי תג, סרוק יתרות ומספר נסיעות לחיפוש חריגים

## טיפים

- **הסטטוס הוא השומר השקט** — לקוחות ב_הרשמה_ / _מוקפא_ / _חסום_ לא יכולים לבצע נסיעות; אל תצפה לראותם ברשימת הנסיעות
- **אייקוני ערוצים מראים מה מאומת** — אייקון אימייל חסר אומר ש-SMS הוא הערוץ היחיד ליציאה ללקוח זה
- **הדירוג הוא דירוג הרוכב ללקוח** (לא לנסיעה) — דירוגים נמוכים מצביעים לעיתים על בעיות חניה או התנהגות גסה; בדוק עם הוכחות חניה וכרטיסים
- **היתרה הופכת לאדומה** = ארנק שלילי. הלקוח לא יכול להתחיל נסיעות חדשות עד להוספה או החזר
- **הרשאות הן בשכבות** — ייתכן שתוכל _לשלוח SMS_ אך לא _להוסיף יתרה_ לאותו לקוח; התפריט מראה מה מותר
- **כתובת ה-URL ניתנת לשיתוף** — העתק תצוגה מסוננת (למשל _לקוחות חסומים עם נסיעות > 0_) ושלח לחבר צוות
