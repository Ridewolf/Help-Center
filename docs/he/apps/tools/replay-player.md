# נגן נגן מחדש

נגן הנגן מחדש (`/apps/replay-player`) הוא כלי פורנזי שמנפיש את עקבות ה-GPS של רכב לאורך יום שלם — או את המסלול המלא של נסיעה בודדת — על מפה. השתמש בו כדי לחקור תקריות, לאמת טענות של רוכבים, לבדוק מסלולים חריגים, או פשוט לצפות בתנועת הצי.

זו לא מפה בזמן אמת (לזה ראה את לוח המחוונים בזמן אמת) — הוא משחזר **קואורדינטות היסטוריות** מהשרת עם שליטה מלאה על ציר הזמן.

הרשאה נדרשת: **נגן נגן מחדש** (`k7m8n9`).

## פריסה

הדף מחולק לסרגל צד שמאלי (בחירות + לוחות מידע) ואזור מפה גדול עם סרגל בקרה בתחתית:

| אזור         | רוחב   | תוכן                                                                   |
| ------------ | ------ | ---------------------------------------------------------------------- |
| **סרגל צד**  | 320 פיקסלים | לשוניות בחירה (לפי רכב / לפי נסיעה), לוח מידע לכל רכב                  |
| **מפה**      | גמיש   | מפה MapLibre עם קו מסלול, סימני התחלה / סיום, סמן חי על המפה          |
| **בקרות**   | תחתית | הפעלה / הפסקה, תפריט מהירות, מחוון ציר זמן, תצוגת זמן שעבר / כולל    |

## בקרות (סרגל צד)

סרגל הצד מגדיר **מה** מתנגן. יש לו שתי לשוניות שמחליפות את מודל הבחירה.

### לשונית לפי רכב

השמע מסלול יום מלא של רכב אחד או יותר (או כל תאריך שתבחר):

- **רכבים** — בחירה מרובה עד **5** רכבים. הקלד לחיפוש, סנן את הרשימה לפי תגיות מהתפריט הנפתח למטה.
- **תאריך** — לוח שנה קופץ; ברירת מחדל היום. הנגן משחזר את כל יום הזמן המקומי של התאריך שנבחר.
- **תגיות** — הגבל את תפריט הרכבים לרכבים הנושאים כל אחת מהתגיות שנבחרו. שימושי כשיש לך צי גדול.
- **טען** — מביא את קואורדינטות היום לכל הרכבים שנבחרו במקביל ומציג אותם.

כשאתה טוען מספר רכבים, לכל אחד יש קו משלו (צבוע לפי מהירות) וסמן נע משלו על המפה, בנוסף לכרטיס מידע ייעודי בסרגל הצד.

### לשונית לפי נסיעה

השמע קואורדינטות של נסיעה בודדת במקום יום שלם:

- **רכב** (אופציונלי) — בחירה יחידה; מצמצם את רשימת הנסיעות למטה
- **תאריך** (אופציונלי) — לוח שנה קופץ; מסנן נסיעות ליום אחד. נקה כדי לראות את כל התאריכים.
- **תגיות** (אופציונלי) — סנן את רשימת הנסיעות לפי תגיות רכב
- **רשימת נסיעות** — רשימה גלילה ומדורגת של נסיעות התואמות לסינונים למעלה. כל כרטיס מציג את זמן ההתחלה, סטטוס, משך וזמן.

לחיצה על כרטיס נסיעה טוענת את הקואורדינטות שלה מיד — אין צורך בכפתור טען נפרד.

## ציר זמן (סרגל תחתון)

סרגל הבקרה רץ לאורך תחתית המפה:

| בקרה              | מה היא עושה                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------- |
| **הפעל / הפסק**   | התחל או עצור את האנימציה                                                                |
| **תפריט מהירות**  | בחר מכפיל מהירות השמעה (ראה למטה)                                                      |
| **מחוון ציר זמן**  | גלול לכל נקודה בנגן; המפה מתעדכנת מיידית                                             |
| **זמן שעבר / כולל** | `דק:שנ` (או `ש:דק:שנ` אם ארוך משעה) — זמן השמעה שעבר והמשך מלא                        |

כשמספר רכבים טעונים, המחוון משתרע על תחילת וסיום **כולל** של איחוד כל המסלולים. מסלולים שעדיין לא התחילו בזמן הנוכחי פשוט לא מציגים סמן על המפה.

## מפה

המפה משתמשת בסגנון המפה של הנושא הנוכחי שלך (ראה [Themes](../../features/ux/themes.md)). עבור כל מסלול שטען:

- **קו מסלול** מצויר בצבע לפי מהירות — ירוק לאיטי, כתום לבינוני, אדום למהיר
- **סמן התחלה ירוק** ממוקם בנקודה הראשונה
- **סמן סיום אדום** ממוקם בנקודה האחרונה
- **סמן רכב** נע לאורך הקו בזמן שהנגן מתנגן

בקרות המפה נמצאות בפינה הימנית העליונה (ערימה אנכית):

| כפתור             | מה הוא עושה                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- |
| **התקרב / התרחק** | התקרבות / התרחקות סטנדרטית במפה                                                        |
| **איפוס כיוון**   | מסובב את המפה חזרה לצפון למעלה אם סובבת או הטית אותה                                  |
| **התאמת גבולות** | מתקרב / מזיז כדי להתאים את כל המסלול(ים) בתצוגה — שימושי אחרי נגן ארוך שזז את המצלמה |
| **מסך מלא**      | הפוך את המפה למסך מלא; סרגל הבקרה נשאר בתחתית                                       |

## מהירות השמעה

תפריט המהירות מציע שמונה הגדרות מראש: **1x, 2x, 4x, 8x, 16x, 32x, 64x, 128x**.

- **1x** משמיע את הנגן בזמן אמת — נסיעה של 20 דקות לוקחת 20 דקות לנגן
- **128x** מדחס יום של 8 שעות לכ-4 דקות
- ניתן לשנות את המהירות במהלך ההשמעה; האנימציה ממשיכה בצורה חלקה מהמקום שבו הייתה

השתמש במהירויות גבוהות (32x / 64x / 128x) לנגני יום מלא של רכבים, ומהירויות נמוכות (1x / 2x / 4x) לפורנזיקה של נסיעות כשאתה רוצה לראות בדיוק איפה הרוכב היה בכל שנייה.

## לוח מידע לכל רכב

לכל רכב שטען יש כרטיס קטן בסרגל הצד שמתעדכן בזמן אמת כשהנגן מתנגן:

| שדה            | מה הוא מציג                                                               |
| --------------- | -------------------------------------------------------------------------- |
| **מהירות**     | מהירות נוכחית מחושבת בקמ"ש (מקודדת בצבעים ירוק / צהוב / אדום)          |
| **קואורדינטות** | קו רוחב / אורך נוכחי עד 6 ספרות עשרוניות                                |
| **מרחק**       | מרחק מצטבר שנעשה עד כה בק"מ (חישוב haversine, מבוצע בצד הלקוח)          |
| **נקודה**      | אינדקס נקודה נוכחית / סך כל הנקודות (כמה התקדמנו בנתוני המסלול)          |

כאשר ההפעלה לא התחילה או שאין נתונים טעונים, הכרטיס מציג מקפים ארוכים.

## מצבים ריקים / טעינה

- **אין בחירה** — אזור המפה מציג אייקון הפעלה והודעה "בחר רכב ותאריך או נסיעה כדי להתחיל ניגון מחדש"
- **טוען** — ספינר במרכז עם ההודעה "טוען קואורדינטות..." חופף על המפה
- **אין נתונים** — אם לתאריך / נסיעה שנבחרו אין נקודות קואורדינטות, תופיע התראה "לא נמצאו נתוני קואורדינטות לבחירה זו" והמפה תישאר ריקה
- **כשל בטעינת מקטע מפה** — המפה היא מקטע עצלני (~1 מגה-בייט); אם הטעינה נכשלה (פריסה מיושנת, לא מקוון), תראה התראה עם בקשה לרענן

## תרחישי עבודה טיפוסיים

- **חקירת תלונה** — עבור ל-By Ride, חפש את נסיעת הרוכב, לחץ עליה → צפה במסלול במהירות 4x כדי לראות לאן הם באמת נסעו לעומת מה שטענו
- **בדיקת רכב "אבוד"** — ב-By Vehicle, בחר את היחידה, הגדר את תאריך היום → נגן במהירות 128x כדי לראות את כל היום בשניות; מיקום הסמן האחרון הוא המקום שבו הוא נמצא כעת
- **השוואת שני רכבים** — ב-By Vehicle, בחר שתי יחידות שרצו מסלולים דומים, באותו תאריך → שני הקווים והסמנים מוצגים יחד להשוואה ויזואלית
- **איתור זמן אירוע מדויק** — טען נסיעה → גרור את המחוון לזמן מהכרטיס / יומן → קרא את הקואורדינטות מפאנל המידע
- **זיהוי מהירות מופרזת** — טען יום של רכב → חפש מקטעי קו אדומים → גרור את המחוון לאזור כדי לאשר

## טיפים

- **מקסימום 5 רכבים** בו זמנית — הממשק מגביל את הבחירה המרובה כדי לשמור על ביצועי המפה סבירים. עבור יותר, בצע סשנים נפרדים.
- **השתמש ב-Fit Bounds אחרי ניגון ארוך** — הניגון עוקב אחרי הסמן, שגורם למצלמה לסטות; לחיצה אחת על Fit Bounds ממקדת מחדש את כל המסלול.
- **צבעי המהירות אינם תלויי תעריף** — הם רמזים ויזואליים בלבד המבוססים על מהירות GPS נצפית (>15 קמ"ש צהוב, >30 קמ"ש אדום). השווה למצב המהירות של הרכב בדף פרטי הרכב להקשר.
- **המחוון זז בשתי הכיוונים** — גרור אחורה כדי להחזיר. שלב עם מהירות נמוכה כדי לעבור מקטעים מורכבים.
- **אין מצב URL** — הבחירות אינן נשמרות בכתובת, כך שלא ניתן לשתף קישור עמוק. שמור צילומי מסך אם תרצה לסמן רגע.
- **שלב עם דף [Ride Detail](../../operations/trips/ride-detail.md)** — דף פרטי הנסיעה כולל מפה סטטית עם אירועי ציר זמן; נגן הניגון מחדש מוסיף את מימד הזמן מעליה.
