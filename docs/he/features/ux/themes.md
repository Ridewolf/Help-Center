# ערכות נושא

לוח המחוונים כולל שלוש הגדרות מראה עצמאיות:

- **מצב** — בהיר, כהה, או עקוב אחרי מערכת ההפעלה
- **צבע** — צבע ההדגשה המשמש לכפתורים, קישורים, תגיות ומצבים פעילים
- **סגנון מפה** — אריחי המפה הבסיסיים (בחירה נפרדת למצב בהיר וכהה)

שלוש ההגדרות נמצאות ב**גיליון הפרופיל** בתחתית — לחץ על האווטאר שלך בסרגל העליון כדי לפתוח אותו.

## מצב (בהיר / כהה / מערכת)

החלף בין שלושה מצבים:

| אייקון     | מצב    | התנהגות                                                        |
| ---------- | ------ | --------------------------------------------------------------- |
| 🖥️ מסך    | מערכת  | עוקב אחרי העדפת מערכת ההפעלה שלך; מתחלף אוטומטית כשמערכת ההפעלה משתנה |
| ☀️ שמש    | בהיר   | תמיד בהיר, מתעלם ממערכת ההפעלה                                |
| 🌙 ירח    | כהה    | תמיד כהה, מתעלם ממערכת ההפעלה                                 |

מצב **מערכת** הוא ברירת המחדל. אם תשנה את ערכת הנושא של מערכת ההפעלה שלך (למשל macOS במצב כהה מתוזמן לשקיעה), לוח המחוונים יעקוב מיד — ללא טעינה מחדש.

## צבע

צבע ההדגשה משפיע על כפתורים, קישורים, תגיות, טבעות מיקוד, ופריט סרגל הצד הפעיל. זמינות שתים-עשרה פלטות מוכנות מראש:

| צבע    | תצוגה מקדימה |
| ------ | ------------- |
| שחור   | ⚫            |
| אדום   | 🔴            |
| ורוד אדום | 🌹          |
| ורוד   | 🩷            |
| כתום   | 🟠            |
| צהוב   | 🟡            |
| ירוק   | 🟢            |
| טורקיז | 🟢            |
| תכלת   | 🔵            |
| כחול   | 🔵            |
| אינדיגו | 🟣           |
| סגול   | 🟣            |

בחר את הצבע שהכי נוח לקריאה במצב שבחרת (חלק מהצבעים נראים טוב יותר על בהיר, אחרים על כהה).

## סגנון מפה

דפים המציגים מפות (מפת חי, פרטי רכב, עורך אזורים, מסלול נסיעה וכו') משתמשים בסגנון מפה בסיסי שניתן לבחור בנפרד. לוח המחוונים שומר **שתי העדפות סגנון מפה נפרדות** — אחת למצב בהיר, ואחת למצב כהה — כך שהמפה תתאים לשאר הממשק כשאתה מחליף מצבים.

- החלפת מצב (בהיר ↔ כהה) מחליפה אוטומטית לסגנון המפה שבחרת עבור אותו מצב
- הסגנונות הזמינים תלויים בספק המפות שלך (MapTiler או חלופי); בדרך כלל: רחובות, לוויין, בהיר, כהה, חוץ

## היכן נשמרות ההעדפות

שלוש ההגדרות נשמרות ב**localStorage** של הדפדפן שלך תחת המפתחות הבאים:

| הגדרה            | מפתח אחסון           |
| ----------------- | --------------------- |
| מצב              | `app-dark-mode`       |
| צבע              | `app-theme`           |
| סגנון מפה (בהיר) | `app-map-style-light` |
| סגנון מפה (כהה)  | `app-map-style-dark`  |

משמעות הדבר:

- **לכל מכשיר, לכל דפדפן** — מכונה שונה = העדפות שונות
- **לא מסונכרן** עם החשבון שלך — עמיתים המשתמשים באותו חשבון רואים את הערכות הנושא שלהם
- **נמחק ב"נקה נתוני גלישה"** עבור אתר זה
- חלונות **גלישה בסתר** מתחילים עם ברירות מחדל

## טיפים

- **התחל במצב מערכת** — תן למערכת ההפעלה להחליט עבורך; עבור למצב בהיר/כהה רק אם יש לך העדפה שונה ממערכת ההפעלה
- **התאם את סגנון המפה למצב** — לוויין קשה לקריאה במצב כהה; בחר סגנון "כהה" או "רחובות כהים" במקום
- **הצבע משפיע על הניגודיות** — צהוב או תכלת על רקע בהיר עלולים להיות קשים לקריאה; אם הכפתורים נראים "דקים", נסה צבע הדגשה כהה יותר (אדום, כחול, אינדיגו)
- **ערכת נושא אינה הרשאה** — כל מפעיל יכול לבחור את שלו; חברי צוות לא יראו את השינויים שלך
