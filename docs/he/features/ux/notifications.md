# התראות

התראות מציגות אירועים חיים מכל לוח המחוונים — כרטיסים חדשים, התראות IoT, פעילות תשלום, בעיות ברכב, הודעות מערכת. הן מגיעות דרך חיבור WebSocket, כך שהעדכונים הם בזמן אמת ללא טעינת דף מחדש.

## פעמון בסרגל העליון

**אייקון הפעמון** בסרגל העליון הוא נקודת הכניסה שלך. תג אדום מציג את מספר ההתראות שלא נקראו.

- ללא תג → אין התראות שלא נקראו
- תג מספרי → כמות ההתראות שלא נקראו
- `99+` → יותר מ-99 התראות שלא נקראו

לחץ על הפעמון כדי לפתוח את **לוח ההתראות** כגליון צדדי מימין.

## בתוך הלוח

### כותרת

- **כותרת** "התראות"
- **מספר שלא נקראו** מוצג כ"N שלא נקראו" או "הכל נקרא" כשאין
- **קיצור הגדרות** (אייקון גלגל שיניים) פותח את דף הגדרות ההתראות הגלובלי

### מתג התראות בדפדפן

אם הדפדפן שלך תומך בהתראות מערכת, מתג מופיע מתחת לכותרת:

- **כבוי** → התראות חיות רק בתוך לוח המחוונים
- **פועל** → הדפדפן מציג התראת מערכת כשמגיע משהו חדש, גם כשהכרטיסייה ברקע
- בהפעלה ראשונה, הדפדפן מבקש הרשאה

אם סירבת להרשאה קודם, המתג מנוטרל ומופיעה הודעה צהובה עם הוראות להפעילו מחדש בהגדרות האתר בדפדפן.

### רשימה

התראות מוצגות מהחדשות לישנות. כל פריט מציג:

- **אייקון קטגוריה** — אייקון קטן בצבע עדיפות (ראה למטה)
- **כותרת** — כותרת קצרה
- **גוף** — תיאור האירוע
- **זמן שחלף** — למשל "לפני 2 דקות"
- **לחיצה** על הפריט קופצת לדף הרלוונטי (הכרטיס, הרכב, התשלום וכו')

### מצב ריק

כשאין מה להראות, הלוח מציג הודעה ידידותית וכפתור לפתיחת דף ההגדרות.

## קטגוריות ועדיפות

לכל התראה יש **קטגוריה** (שקובעת את האייקון) ו**עדיפות** (שקובעת את הצבע).

### קטגוריות

| קטגוריה    | אייקון         | אירועים טיפוסיים                            |
| ----------- | -------------- | ------------------------------------------- |
| תמיכה       | 🔔 פעמון       | כרטיסים חדשים, תגובות לכרטיסים            |
| תחזוקה     | 🔧 מפתח ברגים  | משימות שירות שהוקצו, טריגרים של אוטומציה  |
| רכב         | ✨ ניצוצות     | שינויים במצב, חריגות                        |
| לקוח        | 👥 משתמשים    | הרשמות חדשות, דגלים בחשבון                 |
| תשלום       | 💳 כרטיס      | עסקאות, החזרים, אירועי וובהוק              |
| IoT         | 🖥️ מעבד       | מכשיר מנותק, סוללה חלשה, התראות חיישנים    |
| מערכת      | 🛎️ פעמון מערכת| הודעות מערכת, פריסות                        |
| אבטחה      | 🛡️ התראת מגן | אירועי אימות, פעילות חשודה                  |

### צבעי עדיפות

| עדיפות   | צבע    | שימוש                                               |
| -------- | ------ | --------------------------------------------------- |
| קריטי    | אדום   | דורש פעולה מיידית (כשל ברכב, התראת אבטחה)         |
| גבוה     | כתום   | חשוב אך לא חוסם                                    |
| בינוני   | ענבר   | תשומת לב שגרתית                                   |
| נמוך     | כחול   | מידע בלבד                                         |

## הגדרות (תצורה מתקדמת)

לוח הפעמון מכסה את הבסיס. לתצורה מלאה, פתח **הגדרות → התראות והתראות** (או לחץ על גלגל השיניים בכותרת הלוח):

- **צלילים** — בחר צליל לכל עדיפות, או כבה את הצלילים
- **ספקים** — העבר התראות לערוצים חיצוניים (Telegram וכו') המוגדרים לפי שיחה/מקבל
- **סינון** — אילו קטגוריות ברצונך לקבל
- **לוחות שקטים** — שעות שקט (כאשר נתמך)

## איך ההרשאה עובדת

התראות בדפדפן דורשות מתן הרשאה חד-פעמית על ידי הדפדפן. המתג בלוח מפעיל את בקשת ההרשאה בפעם הראשונה שאתה מפעיל אותו.

- **הורשה** → המתג פעיל; אתה מקבל התראות מערכת כל עוד לוח המחוונים פתוח בכל כרטיסייה
- **נדחה** → המתג נעול כבוי; עליך לשנות את ההרשאה בהגדרות האתר בדפדפן, ואז לחזור ולהפעיל את המתג
- **לא נתמך** → דפדפנים משובצים וגרסאות ישנות לא יכולים להציג התראות מערכת; המתג מוסתר

מתן הרשאת דפדפן לא משנה דבר בתוך לוח המחוונים — לוח ההתראות הפנימי עובד בכל מקרה.

## טיפים

- **השתמש בהתראות דפדפן בכרטיסייה אחת בלבד** — פתיחת לוח המחוונים בכמה כרטיסיות יכולה להכפיל את ההתראות המערכת
- **צלילים מקומיים** — הם מתנגנים רק בכרטיסייה שבה אתה מחובר; השתק אותם במחשבים משותפים
- **לחיצה היא זרימת העבודה המהירה ביותר** — לחיצה על התראה קופצת ישר לדף שהפעיל אותה; מהיר יותר מניווט ידני
- **לוח מחוונים מנותק** — אם חיבור ה-WebSocket נופל, נקודת הסטטוס הקטנה באוואטר הופכת לאדומה. ההתראות ממשיכות ברגע שהחיבור חוזר; אינך מאבד דבר בינתיים
- **קריטי קודם** — כשמגיעים רבים בבת אחת, סרוק את הצבעים לפני הכותרות: אייקונים אדומים עולים לראש התור שלך
