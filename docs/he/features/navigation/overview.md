# ניווט

לוח המחוונים מנווט בין שלוש משטחים עיקריים: **סרגל הצד** משמאל, **סרגל העליון** לאורך החלק העליון, ו-**פירורי הלחם** בתוך סרגל העליון. הם מתנהגים בעקביות בכל דף.

## סרגל צד

סרגל הצד הוא הניווט הראשי שלך. כל פריט הוא או דף יחיד (לוח מחוונים, נסיעות, רכבים, לקוחות, תמיכה) או **קבוצה** שנפתחת לפריטים משניים (תשלומים, תמיכה, ניתוחים, הגדרות, אפליקציות).

### פתיחה וסגירה

- **לחץ על קבוצה** (למשל _תמיכה_) כדי להרחיב אותה; לחץ שוב כדי לסגור.
- **החלף את כל סרגל הצד** עם `⌘ B` (macOS) או `Ctrl B` (Windows/Linux). מצב מצומצם מציג רק אייקונים — העבר את הסמן מעל אייקון כדי לראות את התווית שלו כטיפ.
- מצב סרגל הצד נשמר בין טעינות דפים (מבוסס עוגיות).

### מצב פעיל

הקטע הנוכחי מודגש בצבע ההדגשה (אדום כברירת מחדל). כשאתה בתוך קבוצה, כותרת הקבוצה גם נשארת מודגשת כדי שתמיד תדע איפה אתה.

### ספירות וסמלים

חלק מהפריטים מציגים **סמל** עם מספר — אלה ספירות של לא נקראו/ממתינים שנמשכות בזמן אמת מהודעות:

- _תמיכה → כרטיסים_ — כרטיסים ממתינים שהוקצו לך
- _תמיכה → הוכחות חניה_ — הוכחות ממתינות לבדיקה
- _נסיעות_, _רכבים_, _לקוחות_ — ספירות כשמתאימות

### הרשאות

אתה רואה רק פריטים שה-**תפקיד וההרשאות** שלך מאפשרים. אם קטע חסר לך ואחר בצוות כן רואה אותו — זו שער הרשאות, לא תקלה. שאל מנהל אם אמור להיות לך גישה.

## סרגל עליון

סרגל העליון מופיע בכל דף. במחשב שולחני יש בו את פירורי הלחם משמאל וחמישה בקרים מימין.

### פירורי לחם (משמאל)

פירורי הלחם הם הנתיב שלך חזרה דרך ההיררכיה:

`בית → רכבים → RW-001`

- **לחץ על כל מקטע** כדי לחזור לרמה ההיא (הקטע האחרון הוא הדף הנוכחי ואינו לחיץ).
- פירורי הלחם תמיד גלויים — זו הדרך הבטוחה ביותר לצאת מדף עמוק.

### בקרים (מימין, במחשב שולחני)

בסדר, משמאל לימין:

| אייקון | מה הוא עושה                                                                            |
| ------ | --------------------------------------------------------------------------------------- |
| ✨     | **שיחת AI** — פותח לוח שיחה עם עוזר שמענה על שאלות בלוח המחוונים                      |
| ?      | **עזרה** — פותח את בסיס הידע בצד, בהקשר לדף הנוכחי                                   |
| 🔔     | **התראות** — אירועי מערכת והתראות אחרונים (סמל אדום מציג ספירת לא נקראו)              |
| 👤     | **פרופיל** — הגדרות, סיסמה, יציאה, בקרות נושא (האווטאר שלך)                         |

### מובייל

במסכים צרים מ-769 פיקסלים סרגל העליון מצטמצם:

- סרגל הצד מצטמצם לכפתור המבורגר בצד שמאל הרחוק
- פירורי הלחם יושבים ליד המבורגר וגלילים אופקית אם ארוכים
- חמשת הבקרים הופכים לארבעה כפתורים מימין (AI, עזרה, התראות, אווטאר) — אותן פעולות, מטרות הקשה גדולות יותר

## גיליון פרופיל

לחיצה על האווטאר שלך פותחת לוח נגלל מימין עם:

- **פרופיל** — המידע האישי שלך
- **שנה סיסמה**
- **הגדרות** — העדפות (שפה, נושא, התראות)
- **עזרה** — קפיצה לדף הבית של העזרה
- **יציאה** (באדום)
- מתגים לנושא/שפה/סגנון מפה בתחתית

## טיפים

- **העבר את הסמן על פריטי סרגל הצד** כשהוא מצומצם — טיפים מופיעים מיד, ללא דיחוי
- **השתמש בפירורי הלחם** כדי לצאת מדפים עמוקים במקום כפתור חזור בדפדפן — זה מהיר ומונע טעינה מחדש
- **`⌘/Ctrl + B`** היא דרך מהירה לתת לעצמך יותר מקום אופקי בדפים עם נתונים כבדים (טבלאות, מפות)
- **עזרה (?)** בסרגל העליון היא **מודעת דף** — היא מנסה לפתוח את המאמר הרלוונטי ביותר למקום שבו אתה; אם אין כזה, היא חוזרת לחיפוש
