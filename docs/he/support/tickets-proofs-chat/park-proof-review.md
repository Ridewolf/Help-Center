# סקירת הוכחות חניה

דף הסקירה (`/support/park-proofs/:id/review`) הוא המקום שבו אתם מתווכים בתמונת הוכחת חניה אחת בפירוט. התמונה המלאה, כל ההקשר הרלוונטי (לקוח / נסיעה / רכב), ותפריט הפעולות המלא נמצאים כאן.

בדרך כלל מגיעים לכאן על ידי לחיצה על התמונה המוקטנת (או _הצג_ בתפריט השורה) ב[רשימת הוכחות החניה](park-proofs.md).

הרשאה נדרשת: **הוכחות חניה** (`d5e6f7`) + הרשאת משנה `review` לפעולות המתווך.

## פריסה

הדף מחולק לשלושה עמודות במסכים רחבים, ומסודר בערימה במסכים צרים יותר:

| עמודה          | רוחב  | תוכן                                               |
| -------------- | ----- | -------------------------------------------------- |
| **תמונה**      | 5/12  | תמונה בגודל מלא עם זום וגרירה                     |
| **פעולות**    | 4/12  | כפתורי מתווך, הערה אופציונלית, מחיקה למנהלים      |
| **כרטיסי מידע** | 3/12  | פרטי לקוח, נסיעה, רכב, פרטי הוכחה                 |

## תמונה (עמודה שמאלית)

**צופה תמונות עם זום** המציג את התמונה ברזולוציה מלאה:

- **לחצו וגררו** כדי להזיז את התמונה כשהיא מוגדלת
- **גלגלת העכבר** (או צביטה במובייל) כדי להגדיל/להקטין
- **לחיצה כפולה** לאיפוס הזום

חפשו:

- כל הרכב במסגרת (לא רק גלגל)
- מקום חניה חוקי (לא חוסם הולכי רגל, לא באזור ללא חניה)
- מעמד הרגלית למטה, הרכב זקוף
- כל דבר שסותר את סיפור הרוכב במקרה של מחלוקת

## פעולות (עמודה אמצעית)

ארבעת כפתורי המתווך מסודרים אנכית, לפי סדר חומרה:

| כפתור               | השפעה על הסטטוס | השתמשו בו כאשר                                                        |
| -------------------- | ---------------- | -------------------------------------------------------------------- |
| **אשר**             | _מאושר_          | התמונה טובה — הרוכב חנה נכון                                      |
| **אזהרה**            | _אזהרה_          | התמונה לא מושלמת אבל לא מספיק רעה לקנס — הרוכב מקבל התראה       |
| **דחה עם קנס**       | _מקונס_          | התמונה רעה — מחיל קנס בסכום שתזינו מתחת לכפתור                   |
| **חסום**             | _חסום_           | הפרה חמורה / חוזרת — חוסם את הרוכב מנסיעות עתידיות               |

כל פעולה דורשת הרשאת משנה `review`. פעולות שאינכם יכולים לבצע מוסתרות או מנוטרלות.

### סכום הקנס

לכפתור **דחה עם קנס** יש שדה מספרי מתחתיו להזנת **סכום הקנס** במטבע החברה. הקנס מחויב מארנק הלקוח (או משיטת התשלום המוגדרת כברירת מחדל, בהתאם להגדרות). סכום הקנס נדרש בעת לחיצה על _דחה עם קנס_ — אחרת הכפתור מנוטרל.

### הערה

שדה **הערה** נמצא מתחת לכפתורי הפעולה. כל מה שתכתבו מצורף לפעולה ונשמר ב:

- רשומת ההוכחה (לבדיקות עתידיות)
- [יומן הפעילות של הלקוח](../../operations/customers/client-detail.md#כרטיסיית-פעילות) (כדי שמי שיבדוק את הלקוח יראה את ההערה שלכם)
- ההתראה באפליקציה של הרוכב (בהתאם לפעולה — הם רואים את ההקשר מדוע קיבלו אזהרה / קנס)

כתבו את ההערה **לפני** לחיצה על הפעולה — היא נשלחת יחד עם הפעולה, לא אחריה. שמרו על דיוק: "קורקינט חוסם מדרכה, תמונה צולמה ב-22:14" עדיף על "חניה רעה".

### מחיקה (למנהלים)

כפתור **מחק** בתחתית (נראה רק עם הרשאת מנהל) מסיר את רשומת ההוכחה לחלוטין. השתמשו בזה ל:

- תמונות בדיקה / העלאות ספאם
- העלאות כפולות (אותה נסיעה, מספר תמונות זהות)
- תמונות שהועלו לנסיעה שגויה (שגיאת נתונים)

אל תשתמשו במחיקה במקום אישור / דחייה — מחיקה מיועדת ל_הסרת הרשומה מהמערכת_, לא להחלטות מתווך.

## כרטיסי מידע (עמודה ימנית)

שלושה כרטיסי "ישות קשורה" ועוד כרטיס פרטים מסודרים אנכית:

- **לקוח** — שם, טלפון, אימייל, סטטוס, קישורים ל[דף פרטי הלקוח](../../operations/customers/client-detail.md)
- **נסיעה** — מזהה נסיעה, זמני התחלה/סיום, מרחק, עלות; קישור ל[דף פרטי הנסיעה](../../operations/trips/ride-detail.md)
- **רכב** — תווית, דגם, סטטוס; קישור ל[דף פרטי הרכב](../../operations/fleet/vehicle-detail.md)
- **פרטי הוכחת חניה** — סוג (התחלה/חניה/סיום), תאריך יצירה, קואורדינטות GPS, כל פסק דין אוטומטי שכבר הוחל

השתמשו בכרטיסים האלה כדי **לבנות הקשר במהירות**:

- האם הלקוח הוא מפר ראשון או עבריין חוזר? — פתחו לקוח → פעילות
- האם סיים את הנסיעה במיקום שבתמונה? — פתחו נסיעה → מפת מסלול
- האם הרכב חונה לעיתים קרובות בצורה רעה? — פתחו רכב → הוכחות אחרונות

## תהליכי עבודה טיפוסיים

- **אישור מהיר** — תמונה ברורה וטובה → השאירו את ההערה ריקה → _אשר_ → חזרה לתור
- **אזהרה עם הקשר** — תמונה רעה אך קלה → כתבו הערה קצרה → _אזהרה_ → הרוכב מקבל התראה רכה
- **קנס לאחר שקילה** — תמונה ברורה ורעה → בדקו בכרטיס הלקוח עבירות חוזרות → כתבו הערה המסבירה את הקנס → הזינו את הסכום → _דחה עם קנס_
- **הסלמה לחסימה** — תמונה היא העבירה השלישית → בדקו בלקוח → פעילות עבור אזהרות קודמות → כתבו הערה → _חסום_
- **בדיקת החלטה קודמת** — פתחו את ההוכחה → קראו את שדה ההערה ביומן הפעילות כדי לראות מה כתב המתווך הקודם

## טיפים

- **התקרב לפני קבלת החלטה** — מיתקני עגינה, שלטי חניה ודרכי הולכי רגל קלים לפספס בתמונה המוקטנת
- **הקלד את ההערה קודם** — ברגע שאתה לוחץ על פעולה, היא נשלחת; אם תקליד את ההערה אחרי, כבר ביצעת מיון ללא הקשר
- **אישור > אזהרה > קנס > חסימה** היא הסלמה חד-כיוונית — אל תעבור ישר לחסימה בעבירה ראשונה
- **ההערה היא פומבית** (לצוות שלך ולרוכב) — שמור על עובדות; ללא מונחים פנימיים, ללא דעות על הלקוח
- **מחיקה היא בלתי הפיכה** — ברגע שההוכחה נמחקת לא ניתן לשחזר אותה; השתמש ב_דחה_ אם ברצונך לשמור תיעוד של התמונה הרעה
- **התמונה היא האמת** — כאשר הרוכב מתנגד לקנס, התמונה המקורית + ההערה שלך + ציר הזמן הם תיק המקרה
