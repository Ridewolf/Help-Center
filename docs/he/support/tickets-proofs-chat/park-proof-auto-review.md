# סקירת הוכחות חניה אוטומטית

דף סקירת האוטומט (`/support/park-proofs/auto-review`) הוא **ממשק תור פשוט** לעבור במהירות על הוכחות חניה ממתינות אחת אחרי השנייה, מבלי לחזור לרשימה בין החלטות.

למרות השם "אוטומט", ההחלטות עדיין שלך — _אוטו_ כאן מתייחס ל**התקדמות אוטומטית**: לאחר כל פעולה הדף טוען אוטומטית את ההוכחה הבאה שממתינה כדי שתוכל להמשיך במודרציה בלי ללחוץ חזרה לרשימה.

ניתן להגיע אליו דרך כפתור **סקירה אוטומטית** ב[רשימת הוכחות החניה](park-proofs.md).

הרשאה נדרשת: **הוכחות חניה** (`d5e6f7`) + הרשאת משנה `review`.

## איך זה עובד

1. הדף טוען את **תור ההוכחות הממתינות הנוכחי** כשאתה פותח אותו
2. אתה רואה את ההוכחה הראשונה — אותה תמונה + אותם כפתורי פעולה כמו ב[דף הסקירה הרגיל](park-proof-review.md)
3. בחר פעולה (אישור / אזהרה / דחייה עם קנס / חסימה) או דלג
4. הדף **מתקדם אוטומטית** להוכחה הבאה שממתינה
5. חזור על הפעולה עד שהתור ריק
6. כשהתור ריק, הדף עובר ל**מצב המתנה** — הוא מבצע בדיקות תקופתיות להוכחות חדשות ויטען אותן אוטומטית

אתה לא מאבד את המקום בטעות: אם תסגור את הלשונית ותחזור, התור ייבנה מחדש מההוכחות שעדיין ממתינות.

## פריסה

שתי עמודות שוות במסכים רחבים, ערימה במסכים צרים:

| עמודה      | רוחב | תוכן                                                          |
| ----------- | ----- | ------------------------------------------------------------- |
| **תמונה**   | 6/12  | תמונה מתקרבת + חותמת זמן יצירה מתחתיה                        |
| **פעולות** | 6/12  | אותה ערימת כפתורי אישור / אזהרה / דחייה+קנס / חסימה / הערה |

סרגל התקדמות בראש הדף מראה כמה התקדמת בתור.

## כותרת עליונה

- **כותרת** "סקירת הוכחות חניה אוטומטית"
- **כותרת משנה** עם התקדמות: `סקירת X מתוך Y · PP-12345`
- כפתור **דלג** (למעלה מימין) — מדלג על ההוכחה הנוכחית בלי לקבל החלטה ועובר להוכחה הבאה (ההוכחה נשארת _ממתינה_)
- **חץ חזרה** — חוזר ל[רשימת הוכחות החניה](park-proofs.md)

**סרגל ההתקדמות** מתחת לכותרת מתמלא ככל שאתה עובד — אפקט ברק קטן על החלק המלא.

## כפתורי פעולה

זהים ל[דף סקירת הוכחה יחידה](park-proof-review.md):

| כפתור               | השפעה                                                           |
| -------------------- | ---------------------------------------------------------------- |
| **אשר**             | סמן כ_מאושר_ → התקדמות אוטומטית                                |
| **אזהרה**            | סמן כ_אזהרה_ + שלח התראה לרוכב → התקדמות אוטומטית             |
| **דחה עם קנס**       | סמן כ_מופקד קנס_ עם סכום הקנס בשדה → התקדמות אוטומטית          |
| **חסום**             | סמן כ_חסום_ (את הרוכב, לא את ההוכחה) → התקדמות אוטומטית       |
| **דלג**              | אל תקבל החלטה; עבור להוכחה הבאה (זו נשארת _ממתינה_)            |
| **הערה**             | שדה טקסט אופציונלי — מצורף לפעולה שתבחר                       |

לאחר כל החלטה, ההוכחה הבאה מחליקה פנימה. אין "בטל" — ברגע שלחצת, הפעולה נשמרת.

## מצב המתנה

כשהתור מתרוקן, הדף מציג **מסך המתנה** במקום כרטיס פעולות ריק:

- הודעה "כל ההוכחות נסקרו"
- **טיימר נספר לאחור** עד לרענון האוטומטי הבא (בדרך כלל כמה דקות)
- כפתור **בדוק עכשיו** לדלג על הספירה ולבצע בדיקה מיידית
- כפתור **יציאה** לחזרה לרשימה

אם מגיעה הוכחה חדשה בזמן ההמתנה (הרוכב סיים נסיעה כרגע), הדף טוען אותה אוטומטית ומחדש את קצב המודרציה שלך.

## מתי להשתמש בסקירה אוטומטית לעומת הרשימה

| השתמש ברשימה (`/support/park-proofs`) כש…              | השתמש בסקירה אוטומטית כש…                          |
| -------------------------------------------------------- | --------------------------------------------------- |
| אתה מבצע בדיקות נקודתיות ללקוחות או נסיעות ספציפיות    | אתה מנקה גיבוב של הוכחות ממתינות כלליות             |
| אתה צריך רק אישור מהיר מתפריט השורה                      | אתה רוצה כל תמונה מולך בגודל מלא                   |
| אתה מבצע ביקורת על החלטות קודמות (מאושר / מופקד קנס וכו') | אתה מתמקד בתור ה_ממתין_ כרגע                        |
| אתה רוצה לסנן לפי טווח תאריכים, סוג או לקוח             | אתה רוצה מהירות: תמונה → פעולה → הבא              |

סקירה אוטומטית היא כלי **מצב זרימה** — פתח אותה בתחילת משמרת המודרציה שלך ואל תעזוב עד שהתור ריק.

## תרחישי עבודה טיפוסיים

- **תחילת משמרת** — פתח סקירה אוטומטית → עבוד על כל ההוכחות הממתינות → סיים במסך ההמתנה → קח הפסקה
- **פרץ מהיר** — פתח ל-10 דקות, נקה מה שאתה יכול, _צא_ חזרה לרשימה כשמשהו אחר דורש את תשומת לבך
- **מקרה לא ברור באמצע הזרימה** — כשאתה צריך הקשר נוסף (מפת נסיעה מלאה, היסטוריית לקוח), לחץ על הקישורים לישות הרלוונטית בתוך הסקירה הרגילה (אלה לא מוצגים כאן); ייתכן שתרצה _לדלג_ על ההוכחה ולחזור אליה מהרשימה

## טיפים

- **הקלד את ההערה קודם** — אותו כלל כמו בדף הסקירה הרגיל: לחיצה על פעולה מאשרת לפני שאתה יכול לשמור הערה מאוחרת
- **דלג הוא חברך** במקרים לא ברורים — אל תטיל קנס כי אתה "כמעט בטוח"; דלג וסקור מהרשימה עם ההקשר המלא (היסטוריית לקוח, מפת נסיעה)
- **ההתקדמות האוטומטית מהירה** — אל תמהר; אם טעית בדחייה עם קנס, הארנק של הרוכב יחויב תוך שניות
- **מסך ההמתנה בריא** — תור ריק אומר שהצוות שלך עומד בקצב. התרחק מהמקלדת כשאתה רואה אותו
- **אין כאן מסננים** — סקירה אוטומטית עוברת על תור ההוכחות הממתינות ללא סינון לפי סדר הגעה; השתמש ב[הרשימה](park-proofs.md) אם אתה צריך למקד תת-קבוצה
- **סגירת הלשונית בטוחה** — המקום שלך הוא התור ה_ממתין_ עצמו; תוכל להמשיך מהתור הנוכחי בכל פעם שתפתח מחדש
