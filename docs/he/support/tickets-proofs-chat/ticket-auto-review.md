# סקירה אוטומטית של כרטיסים

דף סקירה אוטומטית של כרטיסים (`/support/tickets/auto-review`) הוא **ממשק תור פשוט** לעבודה עם כרטיסים ממתינים אחד אחרי השני, מבלי לחזור לרשימה בין החלטות.

כמו ב-[סקירה אוטומטית של הוכחות חניה](park-proof-auto-review.md), "אוטו" כאן משמעותו **התקדמות אוטומטית**: לאחר כל פעולה הדף טוען את הכרטיס הבא שממתין כדי שתוכל להמשיך במודרציה ללא הפסקה.

ניתן להגיע אליו דרך כפתור **סקירה אוטומטית** ברשימת [כרטיסים](tickets.md).

הרשאה נדרשת: **כרטיסים** (`a8b9c1`).

## איך זה עובד

1. הדף טוען את **תור הכרטיסים הממתינים הנוכחי** כשאתה פותח אותו
2. אתה רואה את הכרטיס הראשון — תמונת הוכחה, מידע על הכרטיס וכפתורי הפעולה
3. בחר פעולה (פתור / בתהליך / ממתין למידע / דחה / כפול) או דלג
4. הדף **מתקדם אוטומטית** לכרטיס הבא שממתין
5. חזור על הפעולה עד שהתור ריק
6. כשהתור ריק, הדף עובר ל**מצב המתנה** עם ספירה לאחור שבודקת אם יש כרטיסים חדשים

המקום שלך הוא התור הממתין עצמו — סגירת הטאב ופתיחתו מחדש לא מאבדים התקדמות, פשוט ממשיכים מהכרטיס הבא שמטען.

## פריסה

שלושה עמודות במסכים רחבים, ערימות במסכים צרים:

| עמודה       | רוחב  | תוכן                                                                   |
| ----------- | ----- | ---------------------------------------------------------------------- |
| **תמונה**   | 5/12  | תמונת הוכחה עם זום + חותמת זמן                                       |
| **פעולות** | 4/12  | חמישה כפתורי שינוי סטטוס + דלג + הערה                                |
| **מידע**    | 3/12  | כרטיס מידע על הכרטיס עם סטטוס, סוג תלונה, רכב, מדווח, תאריכים       |

סרגל התקדמות בראש מראה כמה התקדמת.

## כותרת עליונה

- **כותרת** "סקירה אוטומטית של כרטיסים"
- **כותרת משנה** עם התקדמות: `Reviewing X of Y · T-12345`
- כפתור **דלג** (למעלה מימין) — עובר על הכרטיס הנוכחי בלי לקבל החלטה (הכרטיס נשאר _ממתין_)
- **חץ חזרה** — חוזר ל[רשימת הכרטיסים](tickets.md)

## כפתורי פעולה

חמישה מעברי סטטוס, בנוסף לדלג והערה אופציונלית:

| כפתור           | סטטוס חדש     | מתי להשתמש                                                                |
| ---------------- | -------------- | --------------------------------------------------------------------------- |
| **פתור**         | _נפתר_        | הבעיה תוקנה (או לא הייתה אמיתית) — סוגר את הכרטיס                         |
| **בתהליך**       | _בתהליך_      | הבעיה אמיתית, התחלת תיקון (משימת תחזוקה, מעקב)                           |
| **ממתין למידע**  | _ממתין למידע_ | צריך מידע נוסף מהרוכב לפני החלטה — הרוכב מקבל התראה                      |
| **דחה**          | _נדחה_        | לא בעיה אמיתית (דיווח באיכות נמוכה, טעות יעד, ספאם)                      |
| **כפול**         | _כפול_        | כבר קיים כרטיס אחר לאותו רכב / בעיה                                      |
| **דלג**          | (ללא שינוי)   | אל תקבל החלטה; עבור לכרטיס הבא                                           |
| **הערה**         | (כל פעולה)    | הערה אופציונלית שמצורפת לפעולה שנבחרה                                   |

כל לחיצה מתבצעת מיידית ומתקדמת לכרטיס הבא. הקלד את **ההערה קודם** אם ברצונך לצרפה.

### מתי להשתמש באיזה סטטוס סגירה

- **פתור** — התקלה תוקנה (או שהדיווח היה אי-הבנה שנפתרה בבדיקת הרכב)
- **דחה** — הדיווח היה שגוי / מזויף / לא רלוונטי; הרוכב רואה את הדחייה באפליקציה
- **כפול** — קישור למקור; המערכת מטפלת בשרשרת כך שסגירה באחד סוגרת את כולם

_פתור_, _דחה_ ו_כפול_ סוגרים את הכרטיס. _בתהליך_ ו_ממתין למידע_ משאירים אותו פתוח בקטגוריה שונה.

## עמודת מידע

כרטיס **מידע על כרטיס** מימין מציג את הנתונים המובנים מאחורי התמונה:

- **סטטוס** — כדור סטטוס נוכחי
- **סוג תלונה** — כדור צבעוני (נזק מכני, חשמלי, סוללה וכו')
- **רכב** — תווית וקישור
- **מדווח** — שם (רוכב) או תווית (מערכת / מפעיל)
- **מיקום** — כתובת / קואורדינטות
- **נוצר / עודכן** — חותמות זמן
- **SLA** — זמן שנותר (או תג "מאחר")

קרא את הכרטיס לפני ההחלטה — הוא מספר את כל הסיפור מבלי לעזוב את הדף.

## מצב המתנה

כשהתור מתרוקן, הדף מציג את מסך ההמתנה המשמש גם להוכחות חניה:

- הודעת "כל הכרטיסים נסקרו"
- **טיימר ספירה לאחור** עד הסקר הבא האוטומטי
- כפתור **בדוק עכשיו** לסקר מיידי
- כפתור **יציאה** לחזרה לרשימה

אם כרטיס חדש מגיע בזמן ההמתנה, הדף טוען אותו אוטומטית.

## מתי להשתמש בסקירה אוטומטית ומתי ברשימה

| השתמש ברשימה כש…                                         | השתמש בסקירה אוטומטית כש…                          |
| ---------------------------------------------------------- | --------------------------------------------------- |
| אתה צריך לסנן לפי סטטוס, סוג תלונה או רכב                 | אתה עובר על התור הממתין ללא סינון                    |
| אתה חוקר היסטוריה של רכב או רוכב מסוים                    | אתה מתמקד בכרטיס אחד בכל פעם, במסך מלא               |
| אתה מבצע ביקורת על החלטות קודמות (נפתר / נדחה / וכו')    | אתה רוצה מהירות: קרא → החלט → הבא                   |
| אתה צריך להעביר לצוות התחזוקה                             | אתה במצב משמרת, עובד על התור מקצה לקצה                 |

## תזרימי עבודה טיפוסיים

- **תחילת משמרת** — פתח את סקירה אוטומטית → עבוד על כל כרטיס ממתין → סיים במסך ההמתנה
- **מיון מהיר** — קרא את התמונה + סוג התלונה + המדווח → אם ברור, _פתור_ / _דחה_ עם הערה בשורה אחת; אם לא, _בעבודה_ וסמן את צוות התחזוקה בהערה
- **ממתין לרוכב** — כאשר הדיווח לא ברור, _ממתין למידע_ עם שאלה בהערה; הרוכב מקבל התראה
- **כפילות** — כאשר החיפוש מגלה שכרטיס לאותו רכב כבר פתוח, _כפול_ לקישור השרשרת
- **מקרה לא ברור** — _דלג_ ופתח מהרשימה עם הקשר מלא (היסטוריית רכב, נסיעות קשורות, התראות IoT)

## טיפים

- **הקלד את ההערה קודם** — אותו כלל כמו בהוכחות חניה: הפעולה מתבצעת לפני שהערות מאוחרות נשמרות
- **דלג ≠ החלטה** — דילוג לא סוגר כלום; הכרטיס נשאר בתור למפעיל הבא
- **פתור מול דחה זה לא אותו דבר** — _פתור_ אומר "תיקנו את זה"; _דחה_ אומר "זו לא הייתה בעיה אמיתית"; הרוכב רואה את ההבדל באפליקציה שלו
- **טיפול בכפילויות** — חפש קודם ברשימה לפי תווית רכב; אם מצאת כרטיס ראשי, לחץ על כפול, אחרת פתר את המידע ביותר וכפל את השאר
- **שעון SLA עדיין פועל** בזמן ההמתנה — אם התור ריק אבל הרשימה עדיין מכילה שורות שעברו את המועד, שורות אלו מסוננות בסקירה האוטומטית (אולי הרשאות, אולי סטטוס); חזור לרשימה כדי לראותן
- **סקירה אוטומטית מכבדת את סדר הכרטיסים מהשרת** — הכרטיסים החדשים ביותר משתנים לפי פריסה; התייחס לסדר התור כסמכותי
