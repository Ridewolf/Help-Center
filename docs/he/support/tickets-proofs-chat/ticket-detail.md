# פרטי כרטיס

דף פרטי הכרטיס (`/support/tickets/:id`) הוא המקום לחקור כרטיס תמיכה אחד. הוא נפתח כמודאל גדול מעל [רשימת הכרטיסים](tickets.md) — כתובת ה-URL משתנה כך שהכרטיס ניתן לשיתוף / קישור עמוק.

בדרך כלל מגיעים לכאן על ידי לחיצה על שורה ברשימה, או הדבקת כתובת URL ישירה בדפדפן.

הרשאה נדרשת: **כרטיסים** (`a8b9c1`). חלק מהפעולות דורשות הרשאות משנה נוספות (`edit`, `delete`).

## כיצד זה מתקשר לתצוגות כרטיס אחרות

| תצוגה                                                                     | מה היא מיועדת                                                                 |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [רשימת כרטיסים](tickets.md)                  | התור המלא — חיפוש, סינון, מיון                                              |
| [סקירה אוטומטית של כרטיס](ticket-auto-review.md) | מצב זרימה — כרטיס ממתין אחד בכל פעם, מיון מהיר באמצעות מקלדת                 |
| **פרטי כרטיס (הדף הזה)**                                              | חקירה מעמיקה של כרטיס אחד — תמונה מלאה, תיאור מלא, הקשר, עריכה / מחיקה       |

## פריסה

המודאל מסודר מלמעלה למטה:

1. **כותרת** — כותרת (תווית הכרטיס), שורת תיאור ("כרטיס #ID"), סגירה (X)
2. **מדור תמונה** — תמונת הוכחה שהרוכב העלה (גדולה, לחיצה לפתיחה)
3. **כרטיס פרטי הכרטיס** — סטטוס, סוג תלונה, תיאור, הערה
4. **כרטיס רכב ומיקום** — רכב, IMEI, קואורדינטות מיקום, אזור, מדווח
5. **כותרת תחתונה** — כפתורי _סגור_ ו-_ערוך_

## כותרת

הרצועה העליונה מזהה את הכרטיס:

- **אייקון מעגל התראה** ליד תווית הכרטיס (למשל תווית הרכב או שם כרטיס שנוצר)
- **שורת תיאור** המציגה את מזהה הכרטיס
- סגירת הדיאלוג (×) בפינה הימנית העליונה — גם נסגר באמצעות Esc או לחיצה מחוץ לחלון

סגירת הדיאלוג מסירה את `/:id` מכתובת ה-URL כך שההיסטוריה אחורה / קדימה תתאים למה שאתה רואה.

## מדור תמונה

תמונת הראיה שהרוכב הגיש, בגודל מספיק גדול לבחינה מהירה:

- **לחץ על התמונה** (או על כפתור _הצג בגודל מלא_ שמופיע בהצבעה) — פותח את התמונה ברזולוציה המקורית בכרטיסייה חדשה
- **הצבעה** — שכבת כהה + כפתור _הצג בגודל מלא_ מופיעים
- אם התמונה לא נטענת, מופיע תחליף במקומה
- אם לכרטיס אין תמונה (נדיר, למשל כרטיסים שהופעלו על ידי מפעיל), המדור מוסתר

התמונה המוקטנת ברשימה היא גרסה קטנה; זו התמונה המלאה המוכנה למודרציה.

## כרטיס פרטי הכרטיס

כרטיס שמאלי מתוך רשת של שני כרטיסים. שדות:

| שדה              | מה הוא מציג                                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **סטטוס**         | כדור הסטטוס (ממתין, בתהליך, נפתר, נדחה, כפול וכו') — באותה פלטת צבעים כמו ברשימה                                      |
| **סוג תלונה**     | כדור סוג התלונה — קידוד צבעים זהה לרשימה (אדום נזק מכני, צהוב ניקיון וכו')                                                    |
| **תיאור**        | תיאור חופשי של הרוכב, מוצג במרקדאון (שורות חדשות נשמרות, קישורים מקושרים אוטומטית) — ריק אם הרוכב השאיר ריק                 |
| **הערה**          | הערות פנימיות של מפעיל על הכרטיס — ריק עד שמפעיל הוסיף אחת                                                                   |

ראה [רשימת כרטיסים → הפניה לסטטוס / סוגי תלונות](tickets.md) למשמעות המלאה של כל צבע כדור.

## כרטיס רכב ומיקום

כרטיס ימני ברשת. שדות:

| שדה        | מה הוא מציג                                                                             |
| ------------ | ----------------------------------------------------------------------------------------- |
| **רכב**    | תווית הרכב (עם אייקון רכב) ו-IMEI המקושר של מכשיר ה-IoT שלו                             |
| **מיקום**  | קו רוחב / אורך שבו דווח הבעיה (6 ספרות עשרוניות, עם אייקון סיכה)                      |
| **אזור**   | ה[אזור](../../settings/infrastructure/zones.md) שבו נמצא המיקום, אם יש כזה              |
| **מדווח**  | הרוכב / המערכת / המפעיל שהגיש את הכרטיס, עם האימייל שלו                            |

השתמש בהפניות אלו כדי לקפוץ להקשר: לחץ על הרכב לפתיחת [פרטי הרכב](../../operations/fleet/vehicle-detail.md), לחץ על המדווח לפתיחת [פרופיל הלקוח](../../operations/customers/client-detail.md), או העתק את הקואורדינטות לכלי מפות לאישור המיקום.

## פעולות (כותרת תחתונה)

דף הפרטים מציג סט פעולות **קטן במכוון** — רוב זרימות העבודה של הכרטיס מתרחשות ברשימה או בישויות קשורות (רכב, לקוח). מה שיש כאן:

| כפתור    | מה הוא עושה                                                                                                                                                    |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **סגור** | סוגר את המודאל (מסיר את `/:id` מכתובת ה-URL)                                                                                                                  |
| **ערוך**  | פותח את הכרטיס במצב עריכה. שים לב: בבנייה הנוכחית מטפל העריכה מציג הודעת "העריכה לא מיושמת" — הוא מחובר אך הטופס עדיין לא נשלח |

### מה יש ברשימה אבל לא כאן

לתפריט השורה ברשימה יש שתי פעולות נוספות שאינן מופיעות בדף הפרטים עצמו:

| פעולה      | היכן היא נמצאת | למה                                                                                                                              |
| ---------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **ערוך**   | שורת רשימה + פרטים | אותו עריכה (כרגע מייצג מקום שמור)                                                                                                |
| **מחק**   | תפריט שורת רשימה | מחיקה היא פעולה בשורת הרשימה בלבד (עם תיבת אישור). למחוק מתוך הפרטים יש לסגור את החלון קודם, ואז להשתמש בתפריט השורה |

### מה יש בדף הרשימה

כותרת דף הרשימה כוללת _סקירה אוטומטית_ שמקפיצה לתור הזרימה — אין כפתור מקביל בדף הפרטים כי כבר ממוקדים בכרטיס יחיד.

## פעולות עם דגל תכונה (לא בבנייה הנוכחית)

קוד הבסיס כולל מקומות שמורים למערך פעולות כרטיסים עשיר יותר שהן **מושתקות** בבנייה זו:

- **הקצה** — הקצה את הכרטיס למפעיל
- **חסום רכב** — הוצא את הרכב מהשירות בלחיצה אחת
- **צור משימת תחזוקה** — פתח משימת תחזוקה עם נתוני הכרטיס ממולאים מראש
- **הענק זיכוי למשתמש** — הוסף זיכוי לארנק של המדווח
- **השב** — שלח תגובה תבניתית לרוכב
- **מזג כפילויות** — קישור כרטיס זה לכרטיס ראשי

אם הפריסה שלך מפעילה את אלה, הן מופיעות בתפריט השורה / בתפריט נפתח _פעולות_ בכותרת — לא בגוף החלון עצמו. בדוק עם המנהל אם אתה מצפה להן ואינך רואה.

## זרימות עבודה טיפוסיות

- **מיון לפי תמונה** — פתח את הכרטיס → הסתכל על התמונה → אם הנזק אמיתי, העתק את תווית הרכב → סגור את החלון → פתח את פרטי הרכב לחסימה / יצירת משימת תחזוקה
- **פתרון דיווח באיכות נמוכה** — פתח את הכרטיס → אשר שהתמונה פסולה → סגור → השתמש בתפריט שורת הרשימה למחיקה (עם אישור)
- **חקור היסטוריית רכב** — פתח כרטיס → לחץ על הרכב → ראה את כל ההתראות והנסיעות של הרכב → חזור לכרטיס להוספת הערה
- **אמת תלונת רוכב מול הנסיעה** — פתח כרטיס → העתק את המדווח → פתח את פרטי הלקוח → בדוק את נסיעותיו האחרונות להקשר
- **שתף כרטיס עם חבר צוות** — כתובת ה-URL מכילה את מזהה הכרטיס (`/support/tickets/:id`) כדי שתוכל להדביק בצ׳אט והמקבל יגיע לאותו חלון

## טיפים

- **כתובת ה-URL היא הסימנייה שלך** — העתקת הכתובת עם `:id` והדבקתה מאוחר יותר מקפיצה ישירות לאותו כרטיס, אפילו מישיבה שונה
- **Esc לסגירה** — החלון תומך ב-Esc, לחיצה מחוץ לחלון, ו-X — שלושתם מסירים את המזהה מהכתובת
- **לחץ על התמונה פעם אחת לצפייה במקור** — התמונה המוקטנת דחוסה; המקור הוא מה שהרוכב שלח בפועל
- **צלב-בדוק את IMEI** — אם רכב מתויג שוב ושוב, לרוב זו בעיית IoT, לא השלדה. ה-IMEI הוא הקישור שלך לרשומת [הגדרות IoT](../../settings/infrastructure/iot.md)
- **הערה פנימית בלבד** — הרוכבים לא רואים אותה; השתמש בה בחופשיות להערות בין מפעילים על הכרטיס
- **עריכה עדיין לא זמינה** — לחיצה על _ערוך_ היום מציגה הודעה. אם צריך לשנות סטטוס, עשה זאת מפעולות ברמת הרשימה או בסקירה האוטומטית
