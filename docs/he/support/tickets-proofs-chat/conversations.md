# שיחות

דף השיחות (`/support/conversations`) הוא **המסנג'ר של המפעיל** — ממשק צ'אט בזמן אמת בין צוות התמיכה שלך לרוכבים שלך. כל שיחה שייכת ללקוח אחד ומכילה את היסטוריית ההודעות המלאה, פעולות הצוות שלך ושינויים בסטטוס.

הרשאה נדרשת: **שיחות** (`x2y3z4`).

## איך השיחות מופיעות כאן

השיחות מגיעות ממספר זרמים:

1. **הרוכב פותח צ'אט** באפליקציה הניידת — יוצר שיחה _חדשה_, ומתווסף לתור בסטטוס _ממתין_
2. **המפעיל יוזם** — _+ חדש_ בתפריט הצד מאפשר להתחיל צ'אט עם לקוח ספציפי (למשל למעקב על קנס או בדיקת הונאה)
3. **שיחה שנפתחה מחדש** — שיחות שנסגרו יכולות להיפתח מחדש (על ידי הרוכב או המפעיל) וחוזרות לראש הרשימה

הרשימה היא **חיונית** — שיחות חדשות והודעות נכנסות זורמות דרך WebSocket ללא רענון.

## פריסה

לעמוד שני אזורים עיקריים. הפריסה מתאימה את עצמה לגודל המסך:

- **דסקטופ** — תצוגה מפוצלת, תפריט צד שמאלי (30%) ותוכן הצ'אט מימין (70%), עם ידית גרירה
- **נייד** — אזור אחד בכל פעם: רשימת התפריט הצדדי, או הצ'אט הפתוח (חץ חזרה מחזיר לרשימה)

## תפריט צדדי (שמאל)

תור השיחות ומסננים:

- **+ חדש** — פותח דיאלוג לחיפוש לקוח ולהתחלת שיחה חדשה (סטטוס _ממתין_)
- **חיפוש** — חיפוש טקסטואלי על שם הלקוח, מזהה, הודעה אחרונה
- **מסנני סטטוס** — טבליות עם מונים: `הכל` / `חדש` / `ממתין` / `פעיל` / `מושהה` / `נסגר`
- **כרטיסי שיחה** — כל אחד מציג: אווטאר, שם הלקוח, תצוגה מקדימה של ההודעה האחרונה, טבליית סטטוס, חותמת זמן, סמל הודעות לא נקראו. לחיצה לפתיחה
- **טען עוד** — דפדוף בעת גלילה

מיון ברירת המחדל מציב בראש את השיחות ללא מענה (ממתין / פעיל עם הודעות לא נקראו) — הצ'אטים הדחופים ביותר תמיד מול העיניים שלך.

### הפניה לסטטוס

| סטטוס      | משמעות                                                     |
| ----------- | ----------------------------------------------------------- |
| **חדש**     | נפתח זה עתה, אף אחד עדיין לא קרא                            |
| **ממתין**   | לא מוקצה, בתור שכל מפעיל יכול לקחת                          |
| **פעיל**    | מוקצה למפעיל, שיחה בתהליך                                   |
| **מושהה**  | המפעיל השהה את השיחה (ממתין למידע, מעקב מאוחר יותר)       |
| **נסגר**    | נפתרה ונסגרה                                              |

## תוכן הצ'אט (ימין)

כשאתה בוחר שיחה, העמודה הימנית מציגה:

### כותרת הצ'אט

- **חץ חזרה** (נייד בלבד) — חזרה לרשימת התפריט הצדדי
- **כותרת** — שם הלקוח עם טבליית סטטוס השיחה
- **מידע פתוח** — פותח את [תפריט המידע על המשתמש](#לוחות-מידע) עם הקשר מלא על הלקוח
- כפתורי **השהה / העבר / סגור** בהתאם לסטטוס

### חלון הצ'אט

- **בועות הודעות** — הודעות המפעיל מימין (בצבע הדגשה), הודעות הרוכב משמאל; עם חותמות זמן וסימני קריאה
- **סמן הקלדה** — מציג כאשר הרוכב מקליד
- כפתור **טען ישן יותר** בראש — טוען הודעות מוקדמות לפי דרישה
- כפתור **להודעות חדשות** — קיצור גלילה לתחתית כשגללת למעלה
- פעולות על הודעות בהצבעה — ערוך / מחק על ההודעות שלך

### תגובות מוכנות

שורה מעל שדה הקלט מציגה תבניות תגובה מהירה מקובצות לפי קטגוריה. לחץ על אחת כדי להכניס את הטקסט לשדה הקלט — ניתן לערוך לפני השליחה.

### תחתית הצ'אט

מה שמופיע בתחתית תלוי ב**סטטוס** השיחה ובהקצאה:

- **פעיל + מוקצה לך** → **שדה הודעה** עם תפריט קבצים מצורפים (טקסט + תמונה / קובץ)
- **כל מצב אחר** → סרגל **פעולות שיחה** עם הכפתורים הרלוונטיים למצב הנוכחי

## פעולות שיחה (לפי סטטוס)

התחתית מציגה את הכפתורים המתאימים לסטטוס הנוכחי. פעולות נפוצות:

| פעולה         | זמינה כאשר…                      | מה היא עושה                                          |
| ------------- | -------------------------------- | ----------------------------------------------------- |
| **קבל**      | ממתין / חדש (עדיין לא בבעלותך) | מקצה את השיחה אליך ומעביר לסטטוס _פעיל_             |
| **קח על עצמך** | פעיל (מפעיל אחר בבעלות)          | מקצה מחדש אליך                                      |
| **החזר**     | פעיל (מוקצה לך)                 | משחרר את השיחה חזרה לסטטוס _ממתין_                   |
| **השהה**    | פעיל                           | שם את השיחה בהשהיה → _מושהה_                         |
| **פתח מחדש** | נסגר                          | מחזיר לסטטוס _פעיל_                                |
| **סגור**    | פעיל                           | מסמן את השיחה כנפתרה → _נסגר_                         |
| **מחק**     | מוגבל בהרשאות                  | מחיקה רכה של השיחה (בסגנון מנהל)                      |
| **חדש**     | תמיד                          | מתחיל שיחה חדשה עם אותו לקוח                          |

אתה מוגן מפעולה על צ'אט שאינו בבעלותך — תקבל כפתור _קח על עצמך_ במקום שדה הודעה כאשר הצ'אט מוקצה למישהו אחר.

## לוחות מידע

שני לוחות נגללים נפתחים מפעולות בחלון הצ'אט:

- **תפריט מידע על המשתמש** — הקשר מהיר למפעיל המוקצה (אתה), ופעילות הרוכב האחרונה בשיחה זו
- **גליון מידע על הלקוח** — תמונת מצב מלאה של פרופיל הלקוח (יתרה, סטטוס, תגיות, נסיעות אחרונות) מבלי לעזוב את הצ'אט — נוח לקבלת החלטות מהירה

## מצב ריק (דסקטופ)

כשאין שיחה נבחרת בדסקטופ, הפאנל הימני מציג איור מצב ריק עם רמז לבחור שיחה. בנייד הפאנל הימני לא קיים עד לבחירת שיחה — רשימת התפריט הצדדי ממלאת את המסך.

## זרימות עבודה טיפוסיות

- **לקחת שיחה ממתינה** — `סטטוס = ממתין` → לחץ על הכרטיס העליון → _קבל_ → התחל לשוחח
- **לקחת שיחה מחבר צוות** — פתח את השיחה (תראה שהיא שייכת למישהו אחר) → _קח_ (השתמש בזה במידה; זה מופרע את רצף השיחה של הרוכב)
- **להרגיע שיחה איטית** — כשהרוכב מפסיק להגיב, _דחה_ כדי להעביר אותה מחוץ לתור הפעיל שלך; היא תחזור לתיבת הדואר הנכנס שלך כשהם יגיבו
- **לסגור שיחה** — הבעיה נפתרה → _סגור_ עם תגובה מוכנה מהירה ("הכל סודר, נסיעה טובה!")
- **לקבל את ההקשר של הרוכב במהירות** — _פתח מידע_ בכותרת → ראה יתרה / נסיעות אחרונות / תגיות לפני מענה על שאלה חשבונית
- **השתמש בתגובות מוכנות** — לתשובות חוזרות (מדיניות החזרות, תהליך פריט אבוד), בחר תבנית והתאם אישית

## טיפים

- **חי כברירת מחדל** — הודעות חדשות זורמות ללא רענון; מונה הסימונים מתעדכן אוטומטית
- **לא נענו קודם** — המיון שומר שיחות דחופות למעלה; סמוך על סדר הרשימה
- **תגובות מוכנות הן תבניות, לא תסריטים** — תמיד התאם אישית את הברכה ואת שורת הסיום; רוכבים מבחינים כשהם מקבלים טקסט סטנדרטי
- **קח שיחה בזהירות** — הרוכב לא רואה את מצב המפעיל. החלפה באמצע שיחה יכולה להרגיש מפתיעה; קח שיחה רק כשהמפעיל הנוכחי תקוע בבירור (מנותק, מחוץ למשמרת)
- **דחה > סגור במקרים לא ודאיים** — אם אתה חושב שהבעיה עשויה לחזור, _דחה_ שומר את השרשור מקושר; _סגור_ מאלץ את הרוכב לפתוח שיחה חדשה אם הוא רוצה להמשיך
- **ערוך רק את ההודעות שלך** — וערוך רק טעויות קטנות; כתיבה מחדש של הודעה ישנה אחרי שהרוכב קרא אותה עלולה לפגוע באמון
- **כתובת ה-URL כוללת את מזהה השיחה** — הדבק אותה בכרטיס או בהערת הסלמה כדי שהמפעיל הבא יוכל לקפוץ ישר לשיחה
