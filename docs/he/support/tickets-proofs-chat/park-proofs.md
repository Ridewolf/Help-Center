# הוכחות חניה — רשימה

רשימת הוכחות החניה (`/support/park-proofs`) היא תור המודרציה לתמונות שרוכבים מצלמים של הרכב שלהם ברגעים מרכזיים בנסיעה. תמונות אלו מוכיחות שהרוכב חנה כראוי (או לא), ותפקיד הצוות שלך כאן הוא **לאשר תמונות טובות, להזהיר או להעניש תמונות רעות**.

לסקירת תמונה בודדת (מסך המודרציה עם התמונה הגדולה), ראה [Park Proof Review](park-proof-review.md). לכללי האוטומציה שמטפלים במקרים ברורים ללא התערבותך, ראה [Auto Review](park-proof-auto-review.md).

הרשאה נדרשת: **הוכחות חניה** (`d5e6f7`). חלק מפעולות השורה דורשות הרשאות משנה נוספות.

## איך הוכחות מגיעות לכאן

אפליקציית הרוכב במובייל מבקשת מהמשתמש לצלם תמונה בשלושה שלבים:

1. **התחלה** — כשפותחים את הנעילה של הרכב (מוכיח שהיחידה הייתה במצב טוב כשהתחילו להשתמש בה)
2. **חניה** — במהלך עצירה באמצע הנסיעה (מוכיח שהם חנו כחוק במהלך העצירה)
3. **סיום** — כשמסיימים את הנסיעה (העיקרית — מוכיחה שהרוכב השאיר את הרכב חונה כראוי)

התמונה מועלת עם מטא-דאטה של GPS ונשלחת לתור זה במצב **ממתין**. Auto Review יכול לשנות את הסטטוס ל_מאושר_ (תמונה טובה) ללא התערבות מפעיל; כל מה ש-Auto Review לא בטוח לגביו מגיע לכאן לסקירה אנושית.

## מסננים

| מסנן      | סוג       | הערות                                                               |
| ---------- | --------- | ------------------------------------------------------------------- |
| חיפוש     | טקסט      | מחפש לפי שם הלקוח, תווית הרכב, מזהה נסיעה                         |
| טווח תאריכים | לוח שנה | בוחר מ/עד; ברירת מחדל היא "כל הזמנים"                            |
| סטטוס     | תפריט נפתח | `ממתין` / `מאושר` / `אזהרה` / `קנס` / `חסום` (או `הכל`)           |
| סוג       | תפריט נפתח | `התחלה` / `חניה` / `סיום` (או `הכל`)                              |

השתמש ב`סטטוס = ממתין` כמסנן המעקב היומי שלך — זהו תור המודרציה.

## הפניה לסטטוס

| סטטוס       | צבע    | משמעות                                                                       |
| ------------ | ------ | ----------------------------------------------------------------------------- |
| **ממתין**   | צהוב   | ממתין למודרציה (שלך או של Auto Review)                                      |
| **מאושר**   | ירוק   | התמונה טובה — הרוכב חנה כראוי                                              |
| **אזהרה**   | כתום   | התמונה לא מושלמת — הרוכב מקבל אזהרה אך ללא קנס                              |
| **קנס**     | אדום   | התמונה רעה — הרוכב קיבל קנס (או שהמערכת סימנה אותה כמועמדת לקנס)           |
| **חסום**   | אפור   | הרוכב נחסם בגלל הוכחה זו (הפרה חמורה / חוזרת)                              |

סטטוסים שנקבעים באמצעות פעולות שורה ובדף הסקירה מתועדים גם ברשומת ההוכחה וגם ב[יומן הפעילות](../../operations/customers/client-detail.md#כרטיסיית-פעילות) של הלקוח.

## פעולות שורה

לכל שורה יש **תפריט שלוש נקודות** מימין. הפעולות הזמינות תלויות בהרשאות:

| פעולה         | הרשאה       | מה היא עושה                                                                                              |
| ------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| **הצג**      | `view-detail`         | פותח את [דף הסקירה](park-proof-review.md) עם התמונה המלאה והקשר                                    |
| **אשר**      | `review`         | מסמן את ההוכחה כ_מאושרת_ (ללא קנס, ללא אזהרה) — אופייני לתמונות טובות                            |
| **הזהר**     | `review`         | מסמן כאזהרה — הרוכב מקבל הודעה אך לא מקבל קנס                                                      |
| **פתח נסיעה** | —           | קפיצה לדף פרטי הנסיעה הקשורה (מפת מסלול, ציר זמן וכו')                                            |

פעולות שאין לך הרשאה אליהן מוסתרות.

מערך הפעולות המלא (קנס, חסימת משתמש, יצירת משימת תחזוקה, בקשה לחניה מחדש) נמצא בדף ה**סקירה** — עבור לשם לכל פעולה מעבר לאישור/אזהרה מהירים.

## פעולות בדף (למעלה מימין)

- **Auto Review** — פותח את [דף הגדרות Auto Review](park-proof-auto-review.md) להגדרת כללים שמאשרים אוטומטית תמונות טובות ברורות ומסמנים אוטומטית תמונות רעות ברורות (זה מרוקן את תור הממתינים כך שתסקור רק מקרים שוליים)

## תרחישי עבודה טיפוסיים

- **תור המודרציה היומי** — `סטטוס = ממתין` → מיין לפי תאריך מהישן לחדש → עבור על כל אחד, _הצג_ להקשר, _אשר_ / _הזהר_ בהתאם למה שאתה רואה
- **חקירת תלונה** — חפש לפי מזהה נסיעה או לקוח → מצא את ההוכחה → _הצג_ → בדוק את התמונה מול טענת הרוכב
- **איתור מפרים חוזרים** — חפש לפי שם לקוח → הסתכל על מספר הוכחות כדי לזהות דפוס (יומן הפעילות בפרופיל המשתמש יספר את אותה סיפור)
- **רק סיום נסיעה** — `סוג = סיום` → סקור רק את תמונות סיום הנסיעה (החשובות ביותר; תמונות חניה באמצע הנסיעה בדרך כלל תקינות)
- **בדיקת Auto Review** — סנן `סטטוס = מאושר` ליום האחרון → בדוק דגימה לוודא שהכללים פועלים כראוי

## טיפים

- **התמונה המוקטנת מספיקה לרוב הקריאות** — ברור שהיא בתוך אזור, ממוסגרת ישר, ללא חסימה — _אשר_ בלי לפתוח. שמור את _הצג_ לתמונות לא חד-משמעיות
- **נסיעה פתוחה** היא קיצור הדרך שלך להקשר — אם הרוכב טוען שחנה כחוק, מפת הנסיעה מראה לך איפה הוא באמת סיים
- **הסטטוסים נשמרים** — ברגע שקבעת _מאושר_, הרוכב מפסיק לקבל תזכורות עבור הוכחה זו. אל תאשר תמונה גרועה כדי "לנקות את התור" כי תאבד את היכולת לעקוב
- **אזהרה היא ה"בין לבין" שלך** — השתמש בה כשהתמונה גרועה אבל לא זדונית (הרוכב היה ממהר, מזג האוויר היה גרוע וכו'). אזהרות חוזרות מחריפות לקנסות דרך חוקי סקירה אוטומטית
- **השתמש בסקירה אוטומטית באגרסיביות** — התור גדל מהר; ככל שסקרי הסקירה האוטומטית מאשרים יותר תמונות ברורות בעצמם, כך יש לך יותר אנרגיה לאלו שבאמת לא חד-משמעיות
- **ה-URL ניתן לשיתוף** — העתק תצוגה מסוננת (למשל _הוכחות שקיבלו קנסות אתמול_) ושלח לחבר צוות לבדיקה נקודתית
