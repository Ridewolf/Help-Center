# פרטי הוכחת חניה

דף פרטי הוכחת החניה (`/support/park-proofs/:id`) הוא המקום שבו בודקים לעומק הוכחת חניה אחת — ואם היא עדיין ממתינה — מנהלים אותה. הוא נפתח כדיאלוג גדול מעל [רשימת הוכחות החניה](park-proofs.md); כתובת ה-URL משתנה כך שניתן לשתף או לקשר ישירות להוכחה.

בדרך כלל מגיעים לכאן על ידי לחיצה על _הצג_ בשורה, לחיצה על אריח בתצוגת גלריה, או הדבקת כתובת URL ישירה.

הרשאה נדרשת: **הוכחות חניה** (`d5e6f7`). תת-ההרשאה `review` מאפשרת פעולות ניהול, ו-`delete` מאפשרת את כפתור מחיקה.

## כיצד זה קשור לדף הסקירה

שני `/support/park-proofs/:id` (דף זה) ו-`/support/park-proofs/:id/review` קיימים — הם נראים דומים אך משרתים תפקידים שונים:

| משטח                                                                             | מה זה                                                                                                                                     |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **פרטי הוכחת חניה (דף זה)**                                                     | **דיאלוג** שנפתח מהרשימה — תמונה מלאה עם זום, הקשר מלא, סט פעולות מלא. תצוגת רשומה יחידה. כתובת URL `/support/park-proofs/:id` |
| [סקירת הוכחת חניה](park-proof-review.md)           | **דף מסך מלא** (`/:id/review`) — משטח סקירה ייעודי להוכחה אחת                                                         |
| [סקירה אוטומטית של הוכחת חניה](park-proof-auto-review.md) | **מצב זרימה** — תור מתקדם אוטומטית של הוכחות ממתינות, אחת בכל פעם                                                                 |

ביום-יום: השתמש ב**סקירה אוטומטית** לניקוי התור, ב**דיאלוג הפרטים** (דף זה) לבדיקות נקודתיות מהרשימה, וב**דף הסקירה** לזרימת הסקירה הייעודית.

## פריסה

הדיאלוג מחולק לשתי עמודות במסכים רחבים, ומסודר בעמודה אחת במסכים צרים:

| עמודה           | רוחב | תוכן                                                                                                  |
| ---------------- | ----- | ----------------------------------------------------------------------------------------------------- |
| **תמונה (שמאל)** | 3/5   | תמונה ברזולוציה מלאה עם זום, על רקע שחור                                                               |
| **מידע (ימין)**   | 2/5   | כותרת (כותרת + תגי סטטוס / סוג), הקשר (לקוח / נסיעה / רכב), רשת פרטים, פעולות סקירה                   |

## תמונה (עמודה שמאלית)

צופה תמונות גדול עם תמונה ברזולוציה מלאה על רקע שחור:

- **לחץ על התמונה** כדי להחליף זום (1× → 2× → 3× → 4× → חזרה ל-1×)
- **גלגל גלילה** כדי להגדיל או להקטין בזום בצעדים של 0.5×
- הסמן משתנה בין הגדלה להקטנה בהתאם למצב
- **תג אחוז זום** מופיע בפינה השמאלית העליונה כשאתה בזום מעל 1×

ארבעה כפתורים מופיעים בפינה הימנית התחתונה בהצבעה (חצי שקופים על הרקע השחור):

| כפתור               | מה הוא עושה                                                                   |
| ------------------- | ------------------------------------------------------------------------------ |
| **הגדל זום**        | הגדלת זום ב-0.5× (מוגבל ל-4× מקסימום)                                         |
| **הקטן זום**        | הקטנת זום ב-0.5× (מינימום 1×)                                                 |
| **מזער**             | מאפס את הזום חזרה ל-1×                                                        |
| **פתח בכרטיסייה חדשה** | פותח את התמונה ברזולוציה המקורית בכרטיסייה חדשה בדפדפן לבחינה מקרוב           |

חפש את אותם סימנים כמו ב[דף הסקירה](park-proof-review.md): רכב שלם במסגרת, מקום חניה חוקי, מעמד קיקסטנד למטה, כל דבר שסותר את טענת הרוכב.

## כותרת (חלק עליון בעמודה הימנית)

רצועת הכותרת מזהה את ההוכחה:

- **כותרת** _"סקירת הוכחת חניה"_ עם תיאור קצר מתחת
- שני **תגים** מונחים בצד ימין:
  - **תג סטטוס** — בצבע התואם לסטטוס (צהוב ממתין, ירוק מאושר, כתום אזהרה, אדום נדחה, כהה חסום)
  - **תג סוג** — קפסולה עם קו מתאר המציגה _התחלה_ / _חניה_ / _סיום_

## קטע הקשר

שלוש שורות המקשרות לישויות קשורות. כל אחת היא קישור-נתב (router-link) (לחץ לפתיחת דף הפרטים הקשור באותו חלון):

| שורה         | מציג                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------- |
| **לקוח**     | שם הלקוח (מקושר ל[פרטי הלקוח](../../operations/customers/client-detail.md)), אימייל + טלפון (לחיצה להעתקה)           |
| **נסיעה**    | שם / מזהה הנסיעה מקושר ל[פרטי הנסיעה](../../operations/trips/ride-detail.md)                                           |
| **רכב**      | תווית הרכב מקושרת ל[פרטי הרכב](../../operations/fleet/vehicle-detail.md), סוג הרכב מתחת                              |

השתמש בהפניות הצולבות האלה כדי לבנות הקשר במהירות — האם לקוח זה הפר את הכללים בעבר, האם אכן סיים את הנסיעה כאן, האם רכב זה סומן לעיתים קרובות.

## קטע פרטים

רשת מפתח/ערך בשתי עמודות מתחת להקשר. השדות המופיעים תלויים במצב ההוכחה:

| שדה                 | מתי מוצג                  | מה הוא מציג                                                                                                                                                                                                                                   |
| ------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **נוצר**            | תמיד                      | מתי האפליקציה של הרוכב העלתה את התמונה                                                                                                                                                                                                      |
| **נבדק בתאריך**     | רק לאחר בדיקה             | מתי מפעיל (או בדיקה אוטומטית) קיבל את ההחלטה                                                                                                                                                                                               |
| **משך הבדיקה**      | רק לאחר בדיקה             | הפרש זמן בין יצירה לבדיקה (למשל "2ש 14ד") — שימושי למדידת SLA מול ההוכחה                                                                                                                                                                   |
| **נבדק על ידי**     | רק לאחר בדיקת מפעיל       | המפעיל שביצע את הבדיקה. מקושר ל[פרופיל המפעיל](../../settings/access/operators.md). אם לא ניתן לפתור את המפעיל (404, ללא הרשאה), מוצג מזהה כקישור לחיץ — דף הפרופיל מטפל באימות בעצמו |
| **מיקום**            | כאשר לנסיעה יש קואורדינטות | קו רוחב / אורך של תחילת הנסיעה (להוכחות _התחלה_) או סופה (להוכחות _חניה_/_סיום_), עד 6 ספרות עשרוניות                                                                                                                                    |

אם ההוכחה נדחתה עם קנס, מוצגת התראה אדומה _קנס_ מתחת לפרטים עם סכום הקנס במטבע החברה.

אם קיימת הערה או סיבת דחייה קודמת, היא מופיעה כסעיף _הערה_ למטה.

## פעולות בדיקה (ממתינות בלבד)

אם סטטוס ההוכחה הוא **ממתין**, מופיע בוחר פעולה בתחתית העמודה הימנית. דיאלוג הפרטים תומך ב**חמש** פעולות בקרה (אחת יותר מדף הבדיקה הייעודי):

| פעולה                    | השפעה על הסטטוס | שדות נוספים          | מתי להשתמש                                                                         |
| ------------------------ | ---------------- | --------------------- | ----------------------------------------------------------------------------------- |
| **אשר**                 | _מאושר_          | —                     | התמונה ברורה וטובה — אין צורך בהערה                                           |
| **אשר עם הערה**         | _מאושר_          | דרוש הערה             | התמונה טובה אך רוצים לתעד הערה (מקרה קצה, התייחסות עתידית, אימון ML) |
| **אזהרה**               | _אזהרה_          | מומלץ להוסיף הערה     | התמונה לא אידיאלית — הרוכב מקבל התראה רכה, ללא קנס                         |
| **דחה**                 | _נדחה_           | הערה + סכום קנס       | תמונה גרועה — קנס הוטל. הקנס מנוכה מארנק בעת השליחה                        |
| **חסום**                | _חסום_           | דרוש הערה             | עבירה חמורה / חוזרת — חוסם את הרוכב מנסיעות עתידיות                        |

כל פעולה מוצגת ככרטיס רדיו לחיץ עם תיאור; בחירת פעולה חושפת את השדות המותנים (שדה טקסט להערה ו/או שדה להזנת סכום הקנס). כפתור השליחה הראשי מקבל את צבע הפעולה (ירוק / צהוב / אדום / כהה).

לאחר השליחה, הדיאלוג נסגר, מוצגת הודעת טוסט המאשרת את הפעולה, והרשימה מתעדכנת.

### מה שונה מדף הבדיקה

דף הבדיקה הייעודי [review page](park-proof-review.md) (`/:id/review`) מציג **ארבע** פעולות ככפתורים מונחים. דיאלוג זה מציג **חמש** פעולות ככרטיסי רדיו — הפעולה הנוספת היא _אשר עם הערה_, שימושית לתיעוד הקשר בהחלטה חיובית מבלי להעלות אותה לאזהרה.

## הוכחות סגורות (כבר נבדקו)

אם ההוכחה כבר נבדקה (מאושר / אזהרה / נדחה / חסום), אזור הפעולות מוסתר — הדיאלוג הופך לקריאה בלבד. עדיין רואים את כל ההקשר (תמונה, לקוח / נסיעה / רכב, פרטים, קנס, הערה, מי בדק ומתי), וניתן עדיין:

- **מחק** את הרשומה (עם הרשאת `delete`) — רק להעלאות ספאם / בדיקה / טעויות
- **סגור** את הדיאלוג

כדי לשנות החלטה לאחר מכן, פנה למנהל שלך — הזרימה הסטנדרטית לא מאפשרת בדיקה חוזרת דרך הממשק.

## תחתית הדף

| כפתור            | מתי נראה                                    | מה הוא עושה                                                                                                                      |
| ----------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **מחק**          | תמיד, אם יש לך את תת-ההרשאה `delete` | מסיר את רשומת ההוכחה לחלוטין (עם אישור). יש להשתמש בזה רק להעלאות בדיקה / ספאם / נסיעה שגויה — לא כהחלטת פיקוח |
| **בטל**          | רק במצב ממתין                                    | סוגר את החלון מבלי לשלוח                                                                                              |
| **שלח פעולה**   | רק במצב ממתין, לאחר בחירת פעולה           | שולח את הפעולה שנבחרה (בצבע התואם לפעולה)                                                                         |
| **סגור**         | הוכחות שנבדקו                                 | סוגר את החלון                                                                                                                 |

סגירת החלון (בטל / סגור / Esc / לחיצה על שכבת הרקע) מסירה את `/:id` מה-URL כך שההיסטוריה אחורה/קדימה תתאים למה שאתה רואה.

## זרימות עבודה טיפוסיות

- **חקור הוכחה אחת מהרשימה** — מצא את ההוכחה ברשימה (סינון / חיפוש), לחץ על השורה → נפתח חלון הפרטים → גלול בהקשר → קבל החלטה
- **בדיקה מעמיקה של הוכחה עם קנס** — חפש לפי לקוח → פתח אחת מההוכחות שנדחו שלו → בדוק את "נבדק על ידי" + הערה כדי לראות מי החליט ולמה → השתמש בזה לפתרון מחלוקות
- **אישור מהיר מקישור ישיר** — קבל URL מחבר צוות → לחץ → נפתח חלון → התקרב לתמונה → אישור / אישור עם הערה
- **בדיקת היסטוריית רכב** — פתח הוכחה → לחץ על הרכב → בדוק אם אותו רכב ממשיך לקבל תמונות חניה גרועות → זה מצביע על בעיית מיקום / שילוט, לא על הרוכב
- **בדיקת שיחות של הבודק** — סנן רשימה לפי סטטוס `מאושר` → לחץ על הוכחות כדי לראות "נבדק על ידי" + הערה → כיול סטנדרטים של הצוות

## טיפים

- **התקרבות בגלגלת מהירה** — אין צורך בכפתור — פשוט גלגל למעלה מעל התמונה
- **התמונה נפתחת בכרטיסייה חדשה ברזולוציה מלאה** — כשלא מספיק להתקרב בתוך החלון (למשל לקרוא שלט בגודל לוחית רישוי), פתח בחוץ
- **"אישור עם הערה" עדיף על אישור שקט** במקרים מיוחדים — השאר שורת הערה שהבודק הבא (או אתה בעוד שלושה חודשים) יודה לך עליה
- **חסימה היא סופית** — ניתן להסיר חסימה לרוכבים דרך [פרטי הלקוח](../../operations/customers/client-detail.md) אבל עבור כל הוכחה, _חסימה_ היא ההסלמה הגבוהה ביותר. אל תשתמש בה בעבירה ראשונה
- **מחיקה לעומת דחייה** — דחייה משאירה רישום פיקוח (ומטילה קנס על הרוכב); מחיקה מוחקת את ההוכחה לחלוטין. אם אתה רוצה עקבות, לעולם אל תמחק
- **ה-URL ניתן לשיתוף** — `/support/park-proofs/:id` מוביל ישירות לכאן, ללא ניווט ברשימה
- **הוכחות סגורות הן לקריאה בלבד** — אם פתחת הוכחה שנבדקה וציפית לפעול עליה, זו הסיבה שהכפתורים נעלמו
