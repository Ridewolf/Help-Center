# כרטיסים — רשימה

רשימת הכרטיסים (`/support/tickets`) היא תור התמיכה לבעיות שהועלו לגבי רכב — נזק מכני, תקלות חשמליות, חלקים שבורים, חששות בטיחותיים ועוד. כל כרטיס מקושר לרכב ספציפי וכולל תמונה, מדווח, סוג התלונה, טיימר SLA וסטטוס.

לחקירה פרטנית של כל כרטיס (שרשור מלא, ראיות, פעולות פתרון) ראה את **דף פרטי הכרטיס** (נפתח בלחיצה על שורה).

לממשק תור פשוט יותר, ראה [Ticket Auto Review](ticket-auto-review.md).

הרשאה נדרשת: **כרטיסים** (`a8b9c1`).

## כיצד כרטיסים מופיעים כאן

כרטיסים נוצרים ממספר מקורות:

1. **דיווח רוכב** — באפליקציית Rider App יש תהליך "דווח על בעיה"; הרוכבים בוחרים סוג תלונה, מצלמים תמונה, משאירים הערה
2. **יוזמת מפעיל** — מפעיל פותח כרטיס לרכב שזיהה שיש לו בעיה (נדיר; בדרך כלל מעדיפים את תהליך [משימות התחזוקה](../../operations/fleet/vehicle-detail.md))
3. **סימון מערכת** — כללי IoT או ניתוחים יכולים להעלות כרטיסים אוטומטית (למשל אנומליה בסוללה)

כל כרטיס חדש מופיע ברשימה זו עם סטטוס (בדרך כלל _ממתין_) ומתחיל את טיימר ה-SLA שלו.

| מסנן          | סוג       | הערות                                                                                      |
| -------------- | --------- | ------------------------------------------------------------------------------------------ |

| סטטוס          | תפריט נפתח | רשימה מונעת על ידי השרת (`ממתין`, `בתהליך`, `נפתר`, `נדחה`, `כפול` וכו')               |
| סוג תלונה      | תפריט נפתח | 7 סוגים — ראה הפניה למטה                                                                  |

המסננים משולבים עם AND. שבבים מופיעים מעל הטבלה; כתובת ה-URL משקפת את המצב הנוכחי.

## סוגי תלונות

שבעה סוגים מסייעים למיון הכרטיסים במבט חטוף. כל אחד מקודד בצבע:

| סוג                   | צבע תג          | מה זה בדרך כלל אומר                                      |
| --------------------- | ---------------- | -------------------------------------------------------- |
| **נזק מכני**          | הרסני (אדום)     | תאונה, מסגרת שבורה, רכיבים מעוקלים                      |
| **תקלה חשמלית**       | אזהרה (צהוב)     | מצערת, אורות, בעיות חיישנים                              |
| **בעיה בסוללה**       | ברירת מחדל (כחול) | לא נטען, התרוקנות מהירה מהצפוי                           |
| **חלקים שבורים**      | הרסני (אדום)     | מעמד רגל חסר, רפלקטור חסר, בלמים פגומים                 |
| **חשש בטיחותי**      | הרסני (אדום)     | כל דבר שהופך את הרכב לבלתי בטוח לנסיעה                   |
| **ניקיון**            | אזהרה (צהוב)     | מלוכלך, ריח, משטחים דביקים — דחיפות נמוכה יותר          |
| **אחר**               | קווי מתאר        | לא מתאים לקטגוריות שלמעלה — קרא את התיאור               |

קטגוריות אדומות בדרך כלל מחייבות הוצאת הרכב מהשירות מיידית; צהוב/כחול יכולים בדרך כלל להמתין לחלון שירות.

## הפניה לסטטוס

רשימת הסטטוסים נמשכת מהשרת, ולכן יכולה להשתנות מעט לפי פריסה. סטטוסים טיפוסיים:

| סטטוס          | וריאנט           | משמעות                                                        |
| --------------- | ----------------- | -------------------------------------------------------------- |
| **ממתין**       | משני (אפור)       | דווח זה עתה, אף אחד עדיין לא טיפל בזה                         |
| **בתהליך**      | ברירת מחדל (כחול) | הוקצה למפעיל או נוצרה משימת תחזוקה                            |
| **נפתר**        | הצלחה (ירוק)      | הבעיה תוקנה; הכרטיס נסגר                                     |
| **נדחה**        | הרסני (אדום)      | המפעיל קבע שזו לא בעיה אמיתית                                |
| **בוטל**        | הרסני (אדום)      | נסגר ללא פתרון (לעיתים משמש לדיווחים באיכות נמוכה)          |
| **בארכיון**     | קווי מתאר         | ישן / היסטורי                                               |
| **כפול**        | (נסגר)            | מקושר לכרטיס קודם על אותו רכב                                |

סטטוסים המכילים _נפתר_, _נדחה_ או _כפול_ נחשבים ל**סגורים** — הם כבר לא נספרים בתור הפתוח.

## חומרה

פנימית, לכרטיסים יש חומרה (`critical`, `high`, `medium`, `low`) הנגזרת מסוג התלונה וכל קלט מפעיל/מערכת. דף הרשימה מציג חומרה דרך **צבע סוג התלונה** ו**צבע טיימר ה-SLA** — SLA שפג תוקפו בכרטיס קריטי הוא העדיפות העליונה שלך.

## פעולות שורה

לכל שורה יש **תפריט שלוש נקודות** עם פריט פעיל יחיד:

| פעולה            | מה היא עושה                                                            |
| ----------------- | ----------------------------------------------------------------------- |
| **הצג פרטים**   | פותח את דף פרטי הכרטיס (שרשור מלא + ראיות + פעולות פתרון)             |

מערך הפעולות המלא של המפעיל (הקצה, חסום רכב, צור משימת תחזוקה, זיכוי משתמש, השב, מיזוג כפילויות) נמצא ב**דף פרטי הכרטיס** ומופעל או מושבת באמצעות דגל תכונה בכל פריסה. תפקיד הרשימה הוא לשמש תור מיון, לא קונסולת פתרון.

## פעולות בדף

- **סקירה אוטומטית** — פותח את [תור הסקירה האוטומטית של כרטיסים](ticket-auto-review.md) — סקירה ממוקדת של כרטיס אחד בכל פעם

## זרימות עבודה טיפוסיות

- **מיון יומי** — סנן `סטטוס = ממתין` → מיין לפי SLA (הוותיק ביותר ראשון, המועד הקרוב ביותר למעלה) → עבור על כל אחד, פתח לפרטים, החלט ופעל
- **מיון רק למקרים קריטיים** — סנן `סוג תלונה = נזק מכני / חשש בטיחותי` → אלו הכרטיסים שיש להוציא משירות
- **בדיקת היסטוריית רכב** — חפש לפי תווית רכב → ראה כל כרטיס שהוגש אי פעם על יחידה זו → שימושי לפני שליחתו שוב לאחר תיקון
- **התראה על SLA** — מיין לפי SLA → הכרטיסים בראש הרשימה הם באיחור → העלה מיד לדרג גבוה יותר

## טיפים

- **התמונה היא האות הראשון שלך** — אפילו לפני פתיחת הכרטיס, התמונה המוקטנת מראה אם זו דיווח נזק אמיתי או הגשה באיכות נמוכה
- **SLA אדום = פעל עכשיו** — כשה-SLA הופך לאדום כבר פספסת את חלון החוזה; זהו תור התגובה שלך
- **השווה עם הרכב** — לחץ על עמודת הרכב → פתח את לשונית ההתראות של הרכב → בעיות IoT ודיווחים של מפעילים לעיתים חופפות
- **היזהר מכפילויות** — רוכבים רבים מדווחים לעיתים על אותו קורקינט שבור תוך שעות; השתמש ב'חיפוש לפי רכב' כדי לזהות אותם לפני הפתרון
- **ה-URL ניתן לשיתוף** — העתק תצוגה מסוננת (למשל _כרטיסים ממתינים עם נזק מכני_) ושלח לצוות התחזוקה
