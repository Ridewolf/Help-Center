# Добро пожаловать в Ridewolf Dashboard

Ridewolf Dashboard — это центр управления вашим парком shared-mobility. Самокаты, велосипеды или любой другой транспорт — здесь вы следите за активностью в реальном времени, управляете клиентами, обрабатываете обращения в поддержку и анализируете показатели.

## Для кого этот дашборд

Дашборд рассчитан на **операторов** — сотрудников, занимающихся повседневной работой с флотом:

- **Менеджеры флота** — транспорт, зоны, тарифы
- **Агенты поддержки** — тикеты, чаты, park proofs
- **Аналитики** — метрики, отчёты, производительность
- **Администраторы** — операторы, роли, системные настройки

Что именно видит каждый оператор, зависит от его **роли и прав доступа**. Ваш интерфейс может быть уже, чем на скриншотах в этом гайде, если какие-то модули для вашей роли закрыты.

## Ключевые понятия

Дашборд построен вокруг нескольких понятий, которые встречаются везде:

| Понятие        | Что означает                                                              |
| -------------- | ------------------------------------------------------------------------- |
| **Транспорт**  | Физическая единица флота (самокат, велосипед и т.д.) — GPS, заряд, статус |
| **Поездка**    | Поездка клиента на транспорте — старт/финиш, маршрут, стоимость           |
| **Клиент**     | Зарегистрированный пользователь, который может арендовать транспорт       |
| **Платёж**     | Денежная транзакция по поездке, пополнению или возврату                   |
| **Зона**       | Географическая область, где транспорт работает (или запрещён)             |
| **Тариф**      | Правила ценообразования для поездок                                       |
| **Тег**        | Метка для группировки и фильтрации клиентов или транспорта                |
| **Тикет**      | Запрос в поддержку от клиента                                             |
| **Park Proof** | Фото клиента, подтверждающее правильную парковку                          |

## Базовая навигация

### Сайдбар (слева)

Сайдбар — основная навигация. Группы раскрываются и показывают подразделы — например, **Поддержка** раскрывается в Тикеты, Park Proofs и Чаты.

### Верхний бар

Верхний бар присутствует на каждой странице и содержит:

- **Хлебные крошки** — путь обратно по иерархии (например, Главная → Транспорт → RW-001)
- **AI Chat** (иконка искры) — ассистент, отвечающий на вопросы по дашборду
- **Помощь** (знак вопроса) — открывает эту базу знаний с привязкой к текущей странице
- **Уведомления** (колокольчик) — последние системные события
- **Профиль** (аватар) — настройки, смена пароля, выход, темы

### Таблицы

Большинство страниц со списками (транспорт, поездки, клиенты и т.д.) следуют одной схеме:

1. **Поиск** сверху для полнотекстового поиска
2. **Фильтры** ниже — сужают результат по статусу, типу и пр.
3. **Сортируемые колонки** — клик по заголовку колонки сортирует
4. **Пагинация** внизу
5. **Действия над строкой** — меню из трёх точек у каждой строки

## С чего начать

Если вы впервые в дашборде, рекомендуем:

1. **Обновить профиль** — аватар → Профиль, заполните имя, фото и контакты
2. **Посмотреть свой флот** — откройте **Транспорт**, чтобы увидеть что активно сейчас
3. **Глянуть поездки за сегодня** — откройте **Поездки** с фильтром на сегодня
4. **Открыть главный дашборд** — `/dashboard` показывает дневные KPI
5. **Прочитать эту базу знаний** — открывайте релевантный раздел перед первым действием в каждом модуле

## Как получить помощь

Из дашборда есть три способа:

- **Иконка помощи (?)** в верхнем баре — открывает боковую панель с документацией для текущей страницы
- **Помощь** в сайдбаре (иконка книги) — полная база знаний с поиском
- **Формы фидбека / идей** на главной Помощи — пишите команде напрямую

## Что дальше

Когда освоитесь с базой:

- Откройте **Фишки дашборда** — горячие клавиши, трюки с фильтрами, темы
- Откройте **Операции** — практические гайды по транспорту, поездкам, клиентам
- Откройте **Настройки** если нужно настроить операторов, зоны или тарифы
