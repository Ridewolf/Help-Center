# Batch mode — очередь из нескольких транспортных средств

Batch mode (`/batch`) собирает несколько транспортных средств в одну очередь, чтобы вы видели их рядом и проходили по ним, не разыскивая каждое заново. Попасть сюда можно с домашнего экрана или по ссылке сканирования из пустого состояния [карты флота](../fleet/fleet-map.md).

**Прочитайте это в первую очередь:** batch mode — это рабочий список, а не инструмент массовых команд. Кнопки групповых действий внизу экрана **сейчас недоступны в приложении**. Вы действуете на каждый транспорт с его собственной [страницы транспорта](../fleet/vehicle-controls.md).

## Добавление транспорта

1. Откройте batch mode.
2. Отсканируйте QR-код транспорта — сканер тот же, что использует карта флота, так что действуют те же правила поиска (label, VIN или IMEI).
3. Каждое успешное сканирование добавляет транспорт в очередь в состоянии **idle**.
4. Повторите для каждого транспорта, который хотите добавить в список.

Длинные очереди остаются отзывчивыми, так что нет практической причины держать список коротким, кроме планирования собственной смены.

## Чтение очереди

Каждая строка показывает:

| Элемент                | Как читать                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------- |
| **Label**              | Код транспорта                                                                             |
| **Battery bar**        | Красный при 10% и ниже, оранжевый при 20% и ниже, янтарный при 40% и ниже, зелёный выше 40% |
| **Tracker battery**    | Собственный заряд трекера                                                                  |
| **Connectivity icon**  | Онлайн трекер или офлайн                                                                    |
| **Status**             | Текущий статус транспорта                                                                   |
| **Row state**          | idle, running, ok или failed                                                                |

Упавшая строка показывает своё сообщение об ошибке вместо телеметрии, так что вы видите, что пошло не так, не выходя из очереди.

**Тап по любой строке открывает страницу этого транспорта** — именно так вы действительно работаете с транспортом: ставьте его в очередь здесь, затем обрабатывайте по одному.

## Удаление транспорта

- **Иконка корзины на строке** убирает этот транспорт из очереди. Она ничего не отправляет на транспорт — удаление влияет только на ваш список.
- **Иконка корзины в шапке** очищает всю очередь после подтверждения. Она отключена, пока batch помечен как running.

## Групповые действия

Внизу экрана расположены пять кнопок: шестерёнка настроек, замок, колокольчик, молния и слои. **Эти групповые действия сейчас недоступны в приложении.** Нажатие на любую из них ничего не отправляет ни на один транспорт.

Чтобы разблокировать, подать сигнал, поменять батарею или отправить команду трекеру, откройте транспорт из очереди и используйте элементы управления на [странице транспорта](../fleet/vehicle-controls.md):

- Блокировка и разблокировка — **Ride Mode**
- Звук локатора — **Beep**
- [Battery Swap](battery-swap.md) — таймированная последовательность замены батареи
- Команды вендора — лист **Commands**

## Частые проблемы

| Симптом                                          | Что это значит                                                                   |
| --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Нажатие группового действия как будто ничего не делает | Верно — групповые действия сейчас недоступны. Работайте с каждым транспортом со своей страницы |
| Кнопка очистки всей очереди серая и недоступна    | Batch помечен как running                                                             |
| В строке не видно заряда или связи                | Эти значения для этого транспорта неизвестны — не ноль                                  |
| Отсканированный транспорт не появился              | Код не резолвился. Правила те же, что и на карте флота: label, VIN или IMEI            |

## Советы

- **Собирайте очередь в начале маршрута.** Отсканировать десять транспортных средств во дворе разом выгоднее, чем искать их по одному позже.
- **Используйте цвета батареи, чтобы упорядочить работу** — красные первыми, это те, о которых райдер пожалуется следующим.
- **Очередь принадлежит только вам**, так что удаление строки никогда не меняет ничего для коллег или для самого транспорта.
- **Для операций по всему флоту используйте дашборд.** Массовая смена статуса, массовые теги и массовые команды живут в [списке транспорта дашборда](../../operations/fleet/vehicles.md#bulk-действия).
