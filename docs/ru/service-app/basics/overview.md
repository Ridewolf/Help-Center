# Service App — обзор, вход и навигация

Service App — это приложение Ridewolf для операторов в поле: то, с чем техник выходит на улицу менять батареи, разблокировать самокаты, снимать неисправности и закрывать тикеты. Это отдельный продукт — не приложение райдера и не дашборд оператора: у него свой вход и своя навигация.

После входа приложение сразу открывает карту флота (`/battery-swap`), а не домашний дашборд — потому что в поле карта это стартовая точка для любой задачи.

## Вход

Экран входа (`/login`) показывается только тем, кто ещё не вошёл — если вы уже авторизованы, приложение сразу отправит на карту флота.

1. Введите свой **рабочий email**. Он должен быть полным адресом (с собакой и точкой) — иначе поле отклоняется ещё до отправки.
2. Введите **пароль** — минимум 6 символов.
3. Отправьте форму. Здесь работают только операторские аккаунты; учётные данные райдеров отклоняются.
4. Загружается ваш профиль (имя, роль, должность, отдел, компания, права), и приложение открывает карту флота.

### Вход через Google и Apple

Кнопки **Google** и **Apple** появляются только если этот способ входа включён для вашей инсталляции. Отсутствие кнопки — это не персональная настройка оператора: её не увидит никто в компании.

- **В приложении** — нажатие на кнопку открывает страницу провайдера в браузере телефона, и приложение ждёт, пока браузер не вернёт управление после входа. Ожидание истекает через 5 минут (с небольшим запасом на возврат приложения на передний план). Если приложение было закрыто, пока браузер был открыт, холодный старт всё равно завершит вход.
- **В браузере** — вход через Google вместо этого открывается во всплывающем окне.

В обоих случаях дальнейший flow такой же, как при входе по паролю.

## Навигационный drawer

На каждом экране есть кнопка меню, открывающая навигационную панель (drawer) — она выезжает слева. Содержимое сверху вниз:

| Пункт               | Открывает              | Заметки                                              |
| -------------------- | ----------------------- | ----------------------------------------------------- |
| **Your profile**    | `/profile`              | Аватар, имя и email                                  |
| **Driver App**      | `/battery-swap`         | Карта флота — «управляйте флотом на ходу» (Manage your fleet on the move) |
| **Replay Player**   | `/replay-player`        | Реплей дня одного транспорта                         |
| **Find Scooter**    | `/finder`               | «Найти самокат по Bluetooth» (Locate a scooter over Bluetooth) |
| **Rebalancing**     | `/rebalancing`          | Только для владельца, отключено, бейдж **Soon**      |
| **Support**         | `/support/tickets`      | Только для владельца                                 |
| **Conversations**   | `/support/dialogs`      | Только для владельца                                 |
| **Parking proofs**  | `/support/park-proofs`  | Только для владельца                                 |
| **Analytics**       | `/analytics`            | Только для владельца                                 |

Ещё три контрола закреплены в футере под прокручиваемым списком:

- **Settings** — открывает панель App Settings (см. ниже)
- **Map preferences** — открывает лист настроек карты, описанный в [Карта флота](../fleet/fleet-map.md#map-preferences)
- **Logout** — оформлен красным

Стоит запомнить два нюанса с названиями — именно они вызывают большинство вопросов «не могу найти»: карта флота в меню называется **Driver App**, а не «Battery Swap», а Bluetooth-радар называется **Find Scooter**, а не «Finder». У каждого пункта под названием также есть однострочное описание.

Все восемь пунктов навигации — это один плоский список, а не вложенные группы: **Support**, **Conversations** и **Parking proofs** равноправны, даже если их роуты лежат под `/support`. Пункт, соответствующий текущему экрану, получает акцентный фон.

Два правила объясняют большинство репортов «у меня меню выглядит по-другому»:

- **Пункты только для владельца полностью скрыты** для остальных операторов — они не серые и недоступные, а именно отсутствуют: нечего нажать и не о чем спрашивать.
- **Отключённые пункты** показывают бейдж **Soon** там, где обычно была бы стрелка.

## Страница профиля

Откройте `/profile` через кнопку профиля в панели навигации.

- **Шапка** — крупный аватар (ваши инициалы, если нет фото) с кнопкой камеры для загрузки. Только изображения, максимум 5 МБ. Рядом — бейдж статуса, а для владельцев ещё и owner-бейдж.
- **Account** — роль, отдел, должность, телефон, количество прав, дата регистрации и ваш user ID с кнопкой копирования (пригодится, когда саппорт его запросит).
- **Workspaces** — если вы состоите больше чем в одной компании, переключайтесь здесь. Приложение перезагрузится под выбранную компанию.
- **Security** — **App Lock**, **Change PIN**, **Change Password**, **Active Sessions**.
- **More** — **Appearance & Language**, открывает ту же панель App Settings, что и пункт **Settings** в drawer.
- **Logout** внизу.

### App Lock

**App Lock** доступен только в установленном приложении, поэтому в браузерной версии этого раздела нет. Включение запускает короткий мастер, который регистрирует PIN и биометрию устройства. После регистрации используйте **Change PIN**, чтобы заменить код.

### Change Password

1. Откройте **Change Password** в разделе Security.
2. Введите текущий пароль, затем новый — дважды.
3. Отправьте форму.

Все три поля требуют минимум 8 символов, новый пароль должен отличаться от текущего, а подтверждение — совпадать с ним. Диалог очищает поля и ошибки при каждом открытии и закрытии, так что на общем телефоне ничего введённого не остаётся.

### Active Sessions

Сессии группируются по браузеру, операционной системе и производителю устройства. Каждая группа показывает:

- Бейдж с количеством
- Локацию (страну и IP-адрес)
- Как давно сессия была активна
- Бейдж **current device** на той, которой вы пользуетесь сейчас

**Revoke** доступен для любой группы, кроме текущего устройства. **Log out other devices** отзывает разом все остальные сессии — самый быстрый способ реагировать, если телефон потерян.

## Панель App Settings

Нижний лист (sheet), который открывается из пункта **Settings** в drawer или кнопки **Appearance & Language** на странице профиля. Каждый контрол применяется сразу — кнопки Save нет.

| Настройка        | Варианты                                                    |
| ---------------- | ------------------------------------------------------------ |
| **Theme**        | Light, Dark, System                                          |
| **Map Style**    | Default, Street, Satellite, 3D, Navigation, Flat             |
| **Offline Maps** | Скачать карту вокруг текущего местоположения для оффлайн-использования |
| **Language**     | Auto, English, Română, Russian                               |
| **My Marker**    | Сетка из 6 иконок для отображения вашей собственной позиции   |

**Offline Maps** скачивает регион вокруг вашего текущего местоположения и держит его в кэше. Пока идёт загрузка, вы видите счётчик скачанных тайлов и кнопку **Cancel**. Выключение настройки отменяет текущую загрузку и очищает закэшированный регион.

Внешний вид транспорта на карте (маркеры, оверлеи, кластеризация, частота обновления) настраивается в отдельном листе **Map preferences** — см. [Карта флота](../fleet/fleet-map.md#map-preferences).

## Выход

**Logout** есть и в навигационном drawer, и внизу страницы профиля. Он отключает App Lock, выполняет выход и возвращает на экран входа, полностью очищая сессию на устройстве.

## Частые проблемы

| Симптом                                            | Причина                                                                   |
| --------------------------------------------------- | --------------------------------------------------------------------------- |
| Нет кнопки **Google** или **Apple**                | Этот способ входа не включён для вашей инсталляции                        |
| Пункт меню, который есть у коллеги, отсутствует у вас | Он доступен только владельцу                                              |
| Пункт не открывается и показывает **Soon**         | Он намеренно отключён на данный момент                                     |
| Нет раздела **App Lock** на странице профиля       | Вы используете браузерную версию; для App Lock нужно установленное приложение |
| Вход отклонён ещё до загрузки чего-либо            | Формат email или минимум в 6 символов для пароля не прошли проверку на устройстве |
| Названия в меню не совпадают с ожидаемыми          | Карта флота называется **Driver App**; Bluetooth-радар — **Find Scooter** |
