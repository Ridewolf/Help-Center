# Карта флота и поиск транспорта по QR-коду

Карта флота (`/battery-swap`) — это стартовый экран Service App после входа: полноэкранная карта вашего флота с рядом плавающих кнопок действий внизу. Любая полевая задача начинается здесь — сначала найдите транспорт, потом откройте его.

Открытие транспорта с этого экрана ведёт на [страницу транспорта](vehicle-controls.md), где находится управление. Про меню и настройки приложения см. [обзор Service App](../basics/overview.md).

## Как читать карту

Каждый транспорт на карте — это маркер. За каждым маркером приложение хранит значения, нужные вам в поле:

- Метка и статус
- Процент заряда транспорта
- Процент заряда трекера
- Позиция, курс и скорость в км/ч
- Заблокирован или разблокирован
- Качество сотового сигнала — значение от 0 до 36
- Статус GPS и онлайн ли трекер
- IMEI трекера

Тапните по маркеру, чтобы открыть этот транспорт.

### Список (List view)

Полноэкранный список выезжает поверх карты и показывает весь транспорт, подходящий под текущие фильтры. У него своя шапка с кнопками возврата на карту и открытия фильтров; нижний ряд кнопок действий скрыт, пока список открыт.

Тап по строке открывает ту же страницу транспорта, что и тап по маркеру — используйте тот вид, который быстрее для конкретной задачи.

## Фильтрация транспорта

Фильтры живут в листе фильтров (sheet) и **сохраняются на устройстве** — переживают закрытие и переоткрытие приложения. Это самая частая причина, по которой транспорт «исчезает»: фильтр, выставленный вчера, всё ещё применён сегодня.

Контролы по порядку:

| Контрол           | Что делает                                                                            |
| ------------------ | --------------------------------------------------------------------------------------- |
| **Status chips**  | Фильтр по статусу; чипы окрашены так же, как точки статуса на живой карте                |
| **Battery range** | Слайдер 0–100%                                                                          |
| **Vehicle type**  | Карусель типов — показывается только если во флоте больше одного типа транспорта         |
| **Last signal**   | Пресеты: any, 1h, 6h, 24h, 7d — скрывает транспорт, офлайн дольше выбранного окна        |
| **Tags**          | Сначала публичные теги по алфавиту, затем приватные — с иконкой замка                     |
| **Search**        | Свободный текст, ищет по метке, VIN или IMEI                                             |

Два поведения, которые стоит держать в голове:

- **Несколько тегов работают по логике И** — транспорт должен нести *каждый* выбранный тег, чтобы остаться в результатах.
- **Теги подгружаются тихо.** Если список тегов не загрузился, чипы просто не появятся, ошибка не покажется. Закройте и снова откройте лист, чтобы повторить попытку.

У низкоконтрастных цветов статуса (charging и discharged) текст на чипе темнее в светлой теме, чтобы оставаться читаемым; в тёмной теме цвет остаётся ярким.

Лист всегда открывается заново уже с применёнными сохранёнными фильтрами.

## Открытие транспорта по QR-коду

1. Нажмите кнопку действия **scanner**.
2. Наведите камеру на QR-код транспорта. Коды, которые сразу идентифицируют транспорт, открывают его немедленно; всё остальное ищется по метке, VIN или IMEI. Если совпадает несколько единиц, побеждает точное совпадение по метке.
3. Приложение открывает страницу этого транспорта.

В [batch mode](../operations/batch-mode.md) то же сканирование добавляет транспорт в очередь, вместо того чтобы открывать его.

### Когда код не сканируется

Используйте запасной вариант — ручной ввод: наберите **label**, **VIN** или **IMEI** в модальном окне. Используется точно такой же поиск, так что всё, что мог бы открыть сканер, откроет и ручной ввод.

Нераспознанный код показывает ошибку invalid-code. Сканер также сам закрывается через некоторое время, если ничего не отсканировано — просто откройте его снова.

## Панель тикетов и легенда

- Кнопка действия **tickets** открывает панель открытых support-тикетов со счётчиками. Это полевой шорткат, чтобы увидеть, что зарепортили райдеры, отдельно от полной очереди support, описанной в [Инструментах бэк-офиса](../tools/back-office-tools.md#support--тикеты).
- Модальное окно **legend** объясняет формы маркеров и цветовую кодировку статусов на карте. Открывайте его, когда цвет незнаком, вместо того чтобы гадать.

## Map preferences

Контрол в **правом верхнем углу карты** — не общая для всего приложения панель **Settings** — открывает настройки карты. Он охватывает:

- Стиль маркера (иконка, точка, авто) и размер маркера
- Оверлеи: процент заряда, метки, кольца статуса, тревоги, тикеты
- Кластеризацию
- Зоны
- Вашу собственную локацию
- Плавное движение
- Wake lock (не даёт экрану гаснуть, пока вы работаете)
- Частоту обновления

Меняйте эти настройки, когда карта слишком перегружена для чтения: отключите оверлеи для более чистой картины или включите кластеризацию в плотной зоне.

## Частые проблемы

| Симптом                                    | Что делать                                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Ожидаемый транспорт отсутствует на карте   | Всё ещё применён сохранённый фильтр — проверьте status chips, диапазон заряда и особенно окно last-signal |
| В фильтрах нет карусели типов транспорта   | Во флоте только один тип транспорта — это нормально                                              |
| Совсем нет чипов тегов                     | Список тегов не загрузился. Закройте и снова откройте лист фильтров, чтобы повторить             |
| Комбинация тегов ничего не возвращает      | Теги комбинируются по И — уберите один тег                                                       |
| Отсканированный код не распознан           | Убедитесь, что код принадлежит транспорту вашей компании, затем используйте ручной ввод по метке, VIN или IMEI |
| Сканер закрывается сам по себе             | Он закрывается по таймауту после периода бездействия — откройте снова                            |

## Советы

- **Сбрасывайте фильтры в начале смены.** Они сохраняются, а устаревшее окно last-signal скрывает именно тот транспорт, за которым вас отправили.
- **Используйте пресеты last-signal, чтобы найти мёртвые трекеры** — поставьте `7d` и смотрите, что молчит.
- **Search принимает IMEI**, так что стикер с одним только номером трекера всё равно достаточен, чтобы открыть транспорт.
- **Ручной ввод — не хуже сканера** — он резолвится точно так же, как сканер, так что используйте его сразу, как только код выглядит повреждённым.
