# Навигация

Дашборд имеет три основные поверхности навигации: **сайдбар** слева, **верхний бар** сверху и **хлебные крошки** внутри верхнего бара. Они работают одинаково на всех страницах.

## Сайдбар

Сайдбар — основная навигация. Каждый пункт это либо отдельная страница (Дашборд, Поездки, Транспорт, Клиенты, Помощь), либо **группа**, раскрывающаяся в подпункты (Платежи, Поддержка, Аналитика, Настройки, Приложения).

### Раскрытие и сворачивание

- **Клик по группе** (например, _Поддержка_) — раскрывает её; повторный клик — сворачивает.
- **Свернуть весь сайдбар** — `⌘ B` (macOS) или `Ctrl B` (Windows/Linux). В свёрнутом состоянии видны только иконки — наведите курсор на иконку, чтобы увидеть подпись.
- Состояние сайдбара сохраняется между перезагрузками страницы (cookie).

### Активный пункт

Текущий раздел подсвечен акцентным цветом (по умолчанию красный). Если вы внутри группы, заголовок группы тоже остаётся подсвеченным — вы всегда видите где находитесь.

### Счётчики и бейджи

Некоторые пункты показывают **бейдж** с числом — это live-счётчики из уведомлений:

- _Поддержка → Тикеты_ — pending-тикеты на вас
- _Поддержка → Park Proofs_ — proofs ждущие обработки
- _Поездки_, _Транспорт_, _Клиенты_ — счётчики где это уместно

### Права доступа

Вы видите только те пункты, которые разрешены вашей **ролью и правами**. Если у коллеги виден раздел, которого нет у вас — это гейтинг прав, не баг. Уточните у администратора, должны ли вы иметь доступ.

## Верхний бар

Верхний бар присутствует на каждой странице. На десктопе слева — хлебные крошки, справа — пять элементов управления.

### Хлебные крошки (слева)

Хлебные крошки — путь обратно по иерархии:

`Главная → Транспорт → RW-001`

- **Клик по любому сегменту** — переход на этот уровень (последний сегмент — текущая страница, не кликабельный).
- Хлебные крошки видны всегда — самый безопасный способ выйти из глубокой страницы.

### Элементы справа (десктоп)

По порядку, слева направо:

| Иконка | Что делает                                                                              |
| ------ | --------------------------------------------------------------------------------------- |
| ✨     | **AI Chat** — открывает чат с ассистентом, который отвечает на вопросы по дашборду      |
| ?      | **Помощь** — открывает эту базу знаний в боковой панели, привязанную к текущей странице |
| 🔔     | **Уведомления** — последние системные события (красный бейдж показывает непрочитанные)  |
| 👤     | **Профиль** — настройки, пароль, выход, темы (ваш аватар)                               |

### Мобильная версия

На экранах уже 769 px верхний бар сворачивается:

- Сайдбар превращается в кнопку-гамбургер слева
- Хлебные крошки идут рядом с гамбургером и скроллятся горизонтально если длинные
- Пять кнопок становятся четырьмя справа (AI, Помощь, Уведомления, Аватар) — те же действия, увеличенные тап-таргеты

## Панель профиля

Клик по аватару открывает выезжающую справа панель с:

- **Профиль** — личная информация
- **Сменить пароль**
- **Настройки** — предпочтения (язык, тема, уведомления)
- **Помощь** — переход на главную страницу Помощи
- **Выход** (красная)
- Переключатели темы/языка/стиля карты внизу

## Полезные приёмы

- **Наведите курсор** на иконки свёрнутого сайдбара — подсказки появляются мгновенно, без задержки
- **Используйте хлебные крошки** для выхода из глубоких страниц вместо браузерной кнопки "Назад" — быстрее и не перезагружает данные
- **`⌘/Ctrl + B`** — быстрый способ освободить горизонтальное пространство на страницах с таблицами и картами
- **Помощь (?)** в верхнем баре — **page-aware**: открывает статью наиболее релевантную текущей странице; если её нет — показывает поиск
