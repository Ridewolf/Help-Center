# Уведомления

Уведомления показывают живые события из всего дашборда — новые тикеты, IoT-алерты, активность по платежам, инциденты с транспортом, системные сообщения. Они приходят по WebSocket-соединению, поэтому обновления в реальном времени, без перезагрузки страницы.

## Колокольчик в верхнем баре

**Иконка колокольчика** в верхнем баре — точка входа. Красный бейдж показывает число непрочитанных.

- Бейджа нет → ничего непрочитанного
- Бейдж с числом → столько непрочитанных
- `99+` → больше 99 непрочитанных

Клик по колокольчику открывает **Панель уведомлений** как боковую панель справа.

## Внутри панели

### Шапка

- **Заголовок** "Уведомления"
- **Счётчик непрочитанных** показан как "N непрочитанных" или "Всё прочитано", если ничего нет
- **Ярлык настроек** (шестерёнка) открывает страницу глобальных настроек

### Переключатель браузерных уведомлений

Если ваш браузер поддерживает системные уведомления, под шапкой появляется тумблер:

- **Выкл** → уведомления только внутри дашборда
- **Вкл** → браузер показывает системное уведомление при появлении нового, даже если вкладка в фоне
- При первом включении браузер спросит разрешение

Если вы ранее запретили разрешение, тумблер заблокирован, и появляется жёлтое предупреждение с инструкцией включить обратно в настройках сайта в браузере.

### Список

Уведомления показываются от новых к старым. Каждый элемент содержит:

- **Иконка категории** — маленькая иконка, окрашенная в цвет приоритета (см. ниже)
- **Заголовок** — короткий заголовок
- **Тело** — описание события
- **Время** — например, "2 мин назад"
- **Клик** по элементу переходит к связанной странице (релевантный тикет, транспорт, платёж и т.д.)

### Пустое состояние

Когда смотреть нечего, панель показывает дружелюбное сообщение и кнопку перехода к настройкам.

## Категории и приоритет

У каждого уведомления есть **категория** (определяет иконку) и **приоритет** (определяет цвет).

### Категории

| Категория    | Иконка          | Типичные события                               |
| ------------ | --------------- | ---------------------------------------------- |
| Поддержка    | 🔔 Колокольчик  | Новые тикеты, ответы по тикетам                |
| Обслуживание | 🔧 Гаечный ключ | Назначенные задачи, срабатывания автоматизаций |
| Транспорт    | ✨ Искры        | Смена статуса, аномалии                        |
| Клиент       | 👥 Пользователи | Новые регистрации, флаги аккаунта              |
| Платёж       | 💳 Карта        | Транзакции, возвраты, события вебхуков         |
| IoT          | 🖥️ Процессор    | Устройство offline, низкий заряд, алерты       |
| Система      | 🛎️ Звонок       | Системные сообщения, деплои                    |
| Безопасность | 🛡️ Щит-алерт    | События авторизации, подозрительная активность |

### Цвета приоритета

| Приоритет | Цвет      | Использование                                        |
| --------- | --------- | ---------------------------------------------------- |
| Critical  | Красный   | Нужно действие сейчас (поломка транспорта, security) |
| High      | Оранжевый | Важно, но не блокирует                               |
| Medium    | Янтарный  | Рутинное внимание                                    |
| Low       | Синий     | Информационное                                       |

## Настройки (глубокая конфигурация)

Панель колокольчика покрывает базу. Для полной конфигурации откройте **Настройки → Alerts & Notifications** (или нажмите шестерёнку в шапке панели):

- **Звуки** — выбрать звук на каждый приоритет, или отключить
- **Провайдеры** — пересылка уведомлений во внешние каналы (Telegram и т.п.) по чату/получателю
- **Фильтрация** — какие категории слышать
- **Расписание тишины** — quiet hours (где поддерживается)

## Как работает разрешение

Браузерным уведомлениям нужно одноразовое разрешение от браузера. Тумблер в панели вызывает запрос браузера при первом включении.

- **Granted** → тумблер работает; системные попапы появляются пока дашборд открыт в любой вкладке
- **Denied** → тумблер заблокирован; нужно изменить разрешение в настройках сайта в браузере, потом вернуться и включить
- **Unsupported** → некоторые встроенные браузеры и старые версии не могут показывать системные уведомления; тумблер скрыт

Выдача разрешения браузеру никак не меняет работу внутри дашборда — in-app панель работает всегда.

## Полезные приёмы

- **Используйте браузерные уведомления в одной вкладке** — открытие дашборда в нескольких вкладках может умножить системные попапы
- **Звуки локальные** — играют только во вкладке, где у вас подключение; отключайте на общих компьютерах
- **Клик-проброс — самый быстрый рабочий процесс** — клик по уведомлению ведёт прямо на страницу события; быстрее чем навигация вручную
- **Дашборд отключился** — если WebSocket упал, маленькая точка на аватаре краснеет. Уведомления возобновятся когда соединение вернётся; вы ничего не теряете
- **Сначала Critical** — когда приходит много сразу, сканируйте цвета а не заголовки: красные иконки — в начало очереди
