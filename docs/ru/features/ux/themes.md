# Темы

В дашборде есть три независимые настройки внешнего вида:

- **Режим** — светлый, тёмный или следовать системе
- **Цвет** — акцент для кнопок, ссылок, бейджей и активных состояний
- **Стиль карты** — базовые тайлы карты (отдельный выбор для светлого и тёмного режима)

Все три живут в **панели профиля** снизу — кликните на аватар в верхнем баре чтобы открыть её.

## Режим (светлый / тёмный / системный)

Переключение между тремя режимами:

| Иконка     | Режим     | Поведение                                                          |
| ---------- | --------- | ------------------------------------------------------------------ |
| 🖥️ Монитор | Системный | Следует за настройкой ОС; переключается автоматически при смене ОС |
| ☀️ Солнце  | Светлый   | Всегда светлый, игнорирует ОС                                      |
| 🌙 Луна    | Тёмный    | Всегда тёмный, игнорирует ОС                                       |

**Системный** режим выбран по умолчанию. Если вы переключите тему ОС (например, macOS включит тёмную тему на закате), дашборд переключится сразу — без перезагрузки.

## Цвет

Акцентный цвет используется для кнопок, ссылок, бейджей, focus-обводки и активного пункта сайдбара. Доступно 12 пресетов:

| Цвет         | Превью |
| ------------ | ------ |
| Чёрный       | ⚫     |
| Красный      | 🔴     |
| Розовый-роза | 🌹     |
| Розовый      | 🩷     |
| Оранжевый    | 🟠     |
| Жёлтый       | 🟡     |
| Зелёный      | 🟢     |
| Бирюзовый    | 🟢     |
| Циан         | 🔵     |
| Синий        | 🔵     |
| Индиго       | 🟣     |
| Фиолетовый   | 🟣     |

Выберите тот, что проще всего читается на вашем режиме (некоторые цвета лучше смотрятся на светлом, другие — на тёмном).

## Стиль карты

Страницы с картами (Live Map, детали транспорта, редактор зон, маршрут поездки и т.д.) используют базовый стиль карты, который можно выбрать независимо. Дашборд хранит **два отдельных предпочтения** — один для светлого режима, другой для тёмного — чтобы карта соответствовала остальному UI при переключении.

- Переключение режима (светлый ↔ тёмный) автоматически меняет стиль карты на выбранный для этого режима
- Доступные стили зависят от провайдера карты (MapTiler или альтернатива); обычно: Streets, Satellite, Light, Dark, Outdoors

## Где живут настройки

Все три настройки хранятся в **localStorage** браузера по этим ключам:

| Настройка             | Ключ                  |
| --------------------- | --------------------- |
| Режим                 | `app-dark-mode`       |
| Цвет                  | `app-theme`           |
| Стиль карты (светлый) | `app-map-style-light` |
| Стиль карты (тёмный)  | `app-map-style-dark`  |

Это значит:

- **На устройство, на браузер** — другой компьютер = другие настройки
- **Не синхронизируется** с аккаунтом — коллеги с тем же аккаунтом видят свою тему
- **Стирается** при очистке данных браузера для сайта
- **Инкогнито**-окна стартуют с дефолтами

## Полезные приёмы

- **Начните с системного режима** — пусть OS решает по расписанию; переключайтесь на Светлый/Тёмный только если хотите отличаться от ОС
- **Сопоставляйте стиль карты с режимом** — Satellite плохо читается в тёмном режиме; выберите "Dark" или "Streets Dark"
- **Цвет влияет на контраст** — Жёлтый или Циан на светлом фоне тяжело читаются; если кнопки кажутся "тонкими", попробуйте темнее (Красный, Синий, Индиго)
- **Тема — не право доступа** — каждый оператор выбирает свою; коллеги не увидят ваших изменений
