# Таблицы и фильтры

Почти каждая страница со списком в дашборде (Транспорт, Поездки, Клиенты, Платежи, Тикеты поддержки, Park Proofs, Чаты, Аналитика, Операторы и т.д.) имеет одинаковую анатомию. Освоив паттерн, вы сможете работать с любой страницей-списком одинаково.

## Анатомия страницы со списком

Сверху вниз:

1. **Шапка страницы** — заголовок, действия страницы (например, _Создать_, _Экспорт_)
2. **Поиск** — полнотекстовый по нескольким полям
3. **Ряд фильтров** — дропдауны и пилюли для сужения результатов
4. **Чипы активных фильтров** — удаляемые чипы показывают что применено сейчас
5. **Bulk-бар** — появляется когда выделена хотя бы одна строка
6. **Таблица** — сортируемые колонки, row actions справа
7. **Пагинация** — внизу справа

## Поиск

Поиск работает по наиболее релевантным полям страницы (например, метка, ID, имя владельца).

- **Набирайте текст** — результаты фильтруются по мере ввода, с коротким debounce чтобы не спамить сервер
- **Очистить** — × в поле или клавиша `Esc`
- Поиск идёт на **сервере** по всему датасету, а не по текущей странице

## Фильтры

Фильтры сужают результат без текстового поиска. Каждый фильтр — это дропдаун (single- или multi-select в зависимости от поля).

- **Применяется сразу** — кнопки "Применить" нет
- **Несколько фильтров комбинируются по И** — чем больше, тем уже результат
- **Чипы активных фильтров** появляются над таблицей; × на чипе убирает только этот фильтр
- **Очистить всё** — если применено много фильтров, рядом с чипами появляется ссылка _Очистить всё_

Типы фильтров:

| Тип               | Поведение                                                      |
| ----------------- | -------------------------------------------------------------- |
| Статус            | Single-select дропдаун                                         |
| Тип / Модель      | Single-select дропдаун                                         |
| Теги              | Multi-select с чипами внутри дропдауна                         |
| Период            | Календарь (от / до)                                            |
| Числовой диапазон | Поля от / до (например, заряд 0–30%)                           |
| Поиск по ID       | Свободный текст в фильтр-пилюле (отдельно от основного поиска) |

## Сортировка

- **Клик по заголовку колонки** — сортировка по возрастанию
- **Повторный клик** — по убыванию
- **Третий клик** — снять сортировку (вернуть порядок по умолчанию)
- **Стрелка** (↑ / ↓) появляется рядом с именем колонки, когда сортировка по ней активна

Не все колонки сортируемые. Сортируемые подсвечиваются при наведении, остальные — нет.

## Пагинация

Внизу справа таблицы:

- **Номера страниц** — клик по номеру для перехода
- **Предыдущая / Следующая** — стрелки по бокам
- **Размер страницы** — дропдаун (обычно 10 / 20 / 50 / 100 строк)

Пагинация — серверная. Фильтры и поиск применяются ко **всему датасету**, не только к видимой странице — третья страница отфильтрованных результатов всё равно отфильтрована.

## Действия над строкой

У каждой строки справа — **меню из трёх точек**. Открывается дропдаун с действиями:

- **Открыть** — переход на детальную страницу
- **Редактировать** — открыть форму редактирования
- **Удалить** — удалить запись (с подтверждением)
- **Действия страницы** — например, _Отправить push_ на клиентах, _Разблокировать_ на транспорте, _Возврат_ на платежах, _Назначить_ на тикетах

Видимые действия зависят от ваших **прав** — действия, на которые нет прав, скрыты.

## Multi-select и bulk-действия

На страницах с поддержкой (Клиенты, Транспорт и др.):

1. **Выделите строки** — клик по чекбоксу слева от строки
2. **Выделить все на странице** — чекбокс в заголовке колонки
3. **Bulk-бар** появляется сверху со счётчиком выделенных и доступными bulk-действиями
4. **Выберите действие** — применяется ко всем выделенным
5. **Снять выделение** — × на bulk-баре или снять чекбокс заголовка

Типичные bulk-действия:

- Добавить или убрать теги
- Отправить push-уведомление
- Применить штраф или пополнить баланс (клиенты)
- Сменить статус

## Пустое состояние и загрузка

- **Загрузка** — skeleton-строки на короткое время пока данные грузятся
- **Нет результатов** — заглушка ("Совпадений не найдено") с кнопкой _Сбросить фильтры_ если применены фильтры
- **Ошибка сети** — состояние ошибки с кнопкой _Повторить_ (чаще всего при нестабильном соединении)

## Полезные приёмы

- **Дождитесь debounce** — после ввода в поиск подождите долю секунды до клика — сервер дёрнется один раз, когда вы остановитесь
- **Делитесь отфильтрованными видами** — поиск, фильтры, сортировка и страница отражены в URL. Скопируйте URL и отправьте коллеге — он увидит точно такой же вид
- **Кнопки браузера "назад/вперёд"** работают как ожидается — возвращают через состояния фильтров
- **Сочетайте поиск + фильтры** — поиск это слой свободного текста поверх фильтров. Сначала сузьте фильтрами по статусу/типу, потом ищите по имени внутри
- **Поднимите размер страницы до 100** когда нужно визуально просмотреть много записей, вместо клика по страницам
- **Права — это молчаливый фильтр** — если коллега видит строки которых нет у вас, почти всегда дело в правах, а не баге
