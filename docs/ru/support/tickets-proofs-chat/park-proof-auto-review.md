# Park Proof Auto Review

Страница Auto Review (`/support/park-proofs/auto-review`) — это **streamlined-интерфейс очереди** для прохождения pending park-proofs один за другим, без возврата к списку между решениями.

Несмотря на имя "Auto", решения по модерации всё равно ваши — _auto_ здесь значит **auto-advance**: после каждого действия страница автоматически загружает следующий pending-proof, чтобы вы могли модерировать не возвращаясь к списку.

Открывается из кнопки **Auto Review** на [странице Park Proofs](park-proofs.md).

Требуется право: **Park Proofs** (`d5e6f7`) + под-право `review`.

## Как это работает

1. Страница загружает **текущую pending-очередь** при открытии
2. Вы видите первый proof — то же изображение + те же кнопки, что и на обычной [странице review](park-proof-review.md)
3. Выбираете действие (Approve / Warn / Reject with fine / Block) или Skip
4. Страница **автоматически переходит** на следующий pending-proof
5. Повторяете пока очередь не закончится
6. Когда пусто — страница переходит в **режим ожидания**: периодически опрашивает новые proofs и автозагружает их

Своё место не теряете: закроете вкладку и вернётесь — очередь восстановится из того, что всё ещё pending.

## Структура

Две равные колонки на широких экранах, складываются на узких:

| Колонка     | Ширина | Содержимое                                                 |
| ----------- | ------ | ---------------------------------------------------------- |
| **Image**   | 6/12   | Зумируемое фото + timestamp создания под ним               |
| **Actions** | 6/12   | Тот же стек Approve / Warn / Reject+fine / Block / Comment |

Прогресс-бар сверху показывает как далеко вы в очереди.

## Шапка

- **Заголовок** "Park Proof Auto Review"
- **Подзаголовок** с прогрессом: `Reviewing X of Y · PP-12345`
- **Кнопка Skip** (вверху-справа) — пропустить текущий proof без решения, перейти к следующему (proof остаётся _Pending_)
- **Стрелка назад** — возврат к [списку Park Proofs](park-proofs.md)

**Прогресс-бар** под шапкой заполняется по мере работы — небольшой shimmer на заполненной части.

## Кнопки действий

Идентичны [странице Review одного proof](park-proof-review.md):

| Кнопка               | Эффект                                                       |
| -------------------- | ------------------------------------------------------------ |
| **Approve**          | Пометить как _Approved_ → auto-advance                       |
| **Warn**             | Пометить как _Warning_ + уведомление райдеру → auto-advance  |
| **Reject with fine** | Пометить как _Fined_ с суммой из поля → auto-advance         |
| **Block**            | Пометить как _Blocked_ (райдера, не proof) → auto-advance    |
| **Skip**             | Не решать; перейти к следующему (текущий остаётся _Pending_) |
| **Comment**          | Опциональная textarea — прикрепляется к любому клику         |

После любого решения следующий proof "въезжает". Нет "Undo" — один клик и действие committed.

## Режим ожидания

Когда очередь заканчивается, страница показывает **экран ожидания** вместо пустой Actions-карточки:

- Сообщение "All proofs reviewed"
- **Countdown** до следующего автообновления (обычно пара минут)
- Кнопка **Check now** — пропустить countdown и опросить сразу
- Кнопка **Exit** — вернуться к списку

Если новый proof приходит во время ожидания (райдер только что завершил поездку), страница автозагрузит его и возобновит ритм.

## Когда использовать Auto Review vs Список

| Используйте список (`/support/park-proofs`) когда… | Используйте Auto Review когда…                  |
| -------------------------------------------------- | ----------------------------------------------- |
| Точечно проверяете конкретных клиентов или поездки | Разгребаете backlog обычных pending proofs      |
| Нужен быстрый approve через меню строки            | Хотите видеть каждое фото в полном размере      |
| Аудит прошлых решений (Approved / Fined и т.д.)    | Сосредоточены на _Pending_-очереди прямо сейчас |
| Хотите фильтр по периоду, типу, клиенту            | Хотите скорость: фото → действие → следующий    |

Auto Review — инструмент **flow state**: открыли в начале смены модерации и не уходите пока очередь не закончится.

## Типичные сценарии

- **Старт смены** — открыть Auto Review → пройти каждый pending → закончить на экране ожидания → перерыв
- **Быстрый burst** — открыть на 10 минут, разгрести что можно, _Exit_ в список когда нужно переключиться
- **Двусмысленный случай по ходу** — когда нужен дополнительный контекст (полная карта поездки, история клиента), кликнуть по entity-ссылкам в обычном review (тут их не показывают); можете _Skip_ proof и вернуться к нему из списка

## Полезные приёмы

- **Сначала комментарий** — то же правило что и на обычной review-странице: клик commit-ит до того как успеете дописать
- **Skip — ваш друг** при двусмысленности — не штрафуйте потому что "почти уверены"; пропустите и разберите из списка с полным контекстом (история, карта)
- **Auto-advance быстрый** — не торопитесь; ошибка в Reject with fine = списание с кошелька райдера за секунды
- **Экран ожидания — это здоровое состояние** — пустая очередь = команда успевает. Отойдите от клавиатуры
- **Фильтров нет** — Auto Review идёт по неотфильтрованной pending-очереди в порядке прибытия; используйте [список](park-proofs.md) для подмножества
- **Закрыть вкладку безопасно** — ваше "место" это сама pending-очередь; вернётесь к тому что pending сейчас
