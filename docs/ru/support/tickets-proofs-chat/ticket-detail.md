# Тикет — Детали

Страница деталей тикета (`/support/tickets/:id`) — где вы разбираете один support-тикет. Открывается как большой модал поверх [списка тикетов](tickets.md) — URL меняется так что тикет можно расшарить / открыть по deep-link.

Обычно сюда приходят кликом по строке в списке или вставкой прямого URL.

Требуется право: **Tickets** (`a8b9c1`). Некоторые действия требуют доп. суб-прав (`edit`, `delete`).

## Как соотносится с другими видами тикетов

| Вид                                                                        | Для чего                                                                       |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [Список тикетов](tickets.md)                | Вся очередь — поиск, фильтр, сортировка                                        |
| [Ticket Auto Review](ticket-auto-review.md) | Streamline — один pending тикет за раз, быстрый keyboard-driven триаж          |
| **Детали тикета (эта страница)**                                           | Глубокий разбор одного тикета — полное фото, описание, контекст, edit / delete |

## Layout

Модал — сверху вниз:

1. **Header** — заголовок (label тикета), description ("Ticket #ID"), close (X)
2. **Секция фото** — evidence-фото от райдера (большое, клик → открыть)
3. **Card Ticket Details** — status, complaint type, description, comment
4. **Card Vehicle & Location** — транспорт, IMEI, координаты, зона, репортёр
5. **Footer** — кнопки _Close_ и _Edit_

## Header

Верхняя полоса идентифицирует тикет:

- **Alert-circle иконка** рядом с label тикета (label транспорта или сгенерированное имя)
- **Description-строка** показывает ID тикета
- **Close (×)** в правом верхнем углу — также закрывается на Esc или клик по фону

При закрытии диалога `/:id` дропается из URL чтобы back / forward-история совпадала с тем что вы видите.

## Секция фото

Полное evidence-фото от райдера, достаточно крупное чтобы оценить сразу:

- **Клик по фото** (или кнопка _View Full Size_ появляющаяся на hover) — открывает оригинальное разрешение в новой вкладке
- **Hover** — затемняющий оверлей + кнопка _View Full Size_
- Если фото не загружается — на его месте placeholder
- Если у тикета нет фото (редко, например operator-initiated тикеты), секция скрыта

Миниатюра в списке — это сжатая версия; здесь — полное изображение готовое для модерации.

## Card Ticket Details

Левая карточка из двух-картчёчного грида. Поля:

| Поле               | Что показывает                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **Status**         | Status-пилюля (Pending, In progress, Resolved, Dismissed, Duplicate и т.д.) — палитра как в списке               |
| **Complaint type** | Пилюля типа жалобы — цвета как в списке (красный Mechanical damage, жёлтый Cleanliness и т.д.)                   |
| **Description**    | Свободный текст от райдера, рендерится как markdown (переносы строк, авто-линки) — пусто если райдер не заполнял |
| **Comment**        | Внутренний operator-комментарий — пусто пока оператор не добавил                                                 |

Полное значение каждого цвета пилюли см. в [Список тикетов → Status reference / Complaint types](tickets.md).

## Card Vehicle & Location

Правая карточка из грида. Поля:

| Поле         | Что показывает                                                                    |
| ------------ | --------------------------------------------------------------------------------- |
| **Vehicle**  | Label транспорта (с car-иконкой) и IMEI его IoT-устройства                        |
| **Location** | Широта / долгота где зарепортили (6 знаков, с pin-иконкой)                        |
| **Zone**     | [Зона](../../settings/infrastructure/zones.md) в которую попадает локация, если есть |
| **Reporter** | Райдер / system / оператор который открыл тикет, с email                          |

Используйте эти cross-references чтобы прыгать в контекст: клик по транспорту → [детали транспорта](../../operations/fleet/vehicle-detail.md), клик по репортёру → [профиль клиента](../../operations/customers/client-detail.md), скопировать координаты в map-tool для подтверждения локации.

## Actions (footer)

На детали — **намеренно маленький** action-set. Большая часть тикет-workflow живёт в списке или в связанных сущностях (транспорт, клиент). Что здесь:

| Кнопка    | Что делает                                                                                                                                                 |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Close** | Закрывает модал (убирает `/:id` из URL)                                                                                                                    |
| **Edit**  | Открывает тикет в edit-режиме. Заметка: в текущей сборке Edit-хендлер показывает тост "Edit not implemented" — кнопка проводится, но форма ещё не выпущена |

### Что есть в списке, но нет здесь

В row-меню списка две дополнительные action которые не появляются на детали:

| Action     | Где             | Почему                                                                                                                  |
| ---------- | --------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Edit**   | Row + детали    | Тот же Edit (пока placeholder)                                                                                          |
| **Delete** | Row-меню списка | Delete — только row-action (с confirmation dialog). Чтобы удалить с детали — закройте модал, потом используйте row-меню |

### Что есть на странице списка

В header списка есть _Auto Review_ → прыжок в streamline-очередь — на детали аналога нет, потому что вы уже сфокусированы на одном тикете.

## Feature-flagged actions (не в текущей сборке)

В кодовой базе есть placeholder'ы для более богатого набора ticket-actions, **закомментированных** в текущей сборке:

- **Assign** — назначить тикет на оператора
- **Block vehicle** — в один клик вывести транспорт из эксплуатации
- **Create maintenance task** — открыть maintenance-task с предзаполненными данными тикета
- **Credit user** — выдать wallet-credit репортёру
- **Reply** — отправить templated-ответ райдеру
- **Merge duplicate** — связать тикет с master-тикетом

Если в вашем деплое они включены — появляются в row-меню / дропдауне header'а _Actions_ — не на теле модала. Если ждали и не видите, уточните у админа.

## Типовые workflow

- **Триаж по фото** — открыть тикет → посмотреть фото → если повреждение реальное, скопировать label транспорта → закрыть модал → открыть детали транспорта чтобы заблокировать / создать maintenance-task
- **Закрыть низкокачественный репорт** — открыть тикет → подтвердить что фото мусор → закрыть → row-меню списка → delete (с confirmation)
- **Расследовать историю транспорта** — открыть тикет → клик по транспорту → посмотреть всю историю alerts + поездок → вернуться в тикет добавить комментарий
- **Сверить жалобу райдера с поездкой** — открыть тикет → клик по репортёру → открыть детали клиента → проверить недавние поездки для контекста
- **Расшарить тикет** — в URL уже есть id тикета (`/support/tickets/:id`) — вставьте в чат, получатель попадёт на тот же модал

## Tips

- **URL — это закладка** — копирование URL с `:id` и вставка позже сразу открывает тот же тикет, даже из другой сессии
- **Esc закрывает** — модал поддерживает Esc, клик за пределы и X — все три убирают id из URL
- **Один клик по фото — оригинал** — миниатюра сжата; оригинал — то что райдер реально отправил
- **Cross-reference IMEI** — если транспорт регулярно тикетируется — это часто IoT глючит, а не шасси. IMEI — ваша ссылка на запись в [IoT settings](../../settings/infrastructure/iot.md)
- **Comment — internal-only** — райдеры его не видят; используйте свободно для operator-to-operator заметок
- **Edit ещё не выпущен** — клик по _Edit_ сегодня — тост. Если надо менять статус, делайте через list-level actions или Auto Review
