# Replay Player

Replay Player (`/apps/replay-player`) — forensic-инструмент, который проигрывает GPS-трек транспорта за день — или полный маршрут одной поездки — на карте. Используйте для расследования инцидентов, проверки заявлений райдеров, аудита необычных маршрутов или просто чтобы посмотреть как двигался флот.

Это **не** real-time карта (для этого см. Realtime-дашборд) — здесь проигрываются **исторические** координаты с бэка с полным скрабом таймлайна.

Требуется право: **Replay Player** (`k7m8n9`).

## Layout

Страница разделена на левый сайдбар (селекторы + информационные панели) и большую карту с панелью управления снизу:

| Зона         | Ширина | Содержимое                                                                 |
| ------------ | ------ | -------------------------------------------------------------------------- |
| **Сайдбар**  | 320px  | Tabs (By Vehicle / By Ride), инфо-карточка(и) на каждый транспорт          |
| **Карта**    | flex   | MapLibre с полилинией маршрута, маркерами Start / End, движущимся курсором |
| **Контролы** | низ    | Play / pause, дропдаун скорости, слайдер таймлайна, elapsed / total        |

## Контролы (сайдбар)

Сайдбар управляет **что** проигрывать. Две вкладки — две модели выбора.

### Вкладка By Vehicle

Проиграть трек одного или нескольких транспортов за день:

- **Vehicles** — multi-select до **5** транспортов. Поиск по тексту, фильтр списка через тэги в дропдауне ниже.
- **Date** — календарь-поповер; по дефолту сегодня. Реплей покрывает весь локально-временной день выбранной даты.
- **Tags** — ограничивает дропдаун транспортами с любым из выбранных тегов. Полезно для большого флота.
- **Load** — параллельно тянет координаты дня для всех выбранных транспортов и рендерит их.

При загрузке нескольких транспортов каждый получает свою полилинию (цвет по скорости) и свой движущийся маркер на карте, плюс отдельную инфо-карточку в сайдбаре.

### Вкладка By Ride

Проиграть координаты одной поездки вместо всего дня:

- **Vehicle** (опционально) — single-select; сужает список поездок ниже
- **Date** (опционально) — календарь-поповер; фильтрует поездки одним днём. Очистите, чтобы видеть все даты.
- **Tags** (опционально) — фильтр списка поездок по тегам транспорта
- **Список поездок** — скроллируемый, paginated список поездок под фильтрами выше. Каждая карточка показывает время старта, статус-пилюлю, длительность и дистанцию.

Клик по карточке поездки сразу автозагружает её координаты — отдельная кнопка Load не нужна.

## Таймлайн (нижняя панель)

Полоса управления тянется вдоль низа карты:

| Контрол               | Что делает                                                                         |
| --------------------- | ---------------------------------------------------------------------------------- |
| **Play / Pause**      | Запустить или поставить на паузу анимацию                                          |
| **Дропдаун скорости** | Выбрать множитель скорости (см. ниже)                                              |
| **Слайдер таймлайна** | Скрабить в любую точку реплея; карта обновляется мгновенно                         |
| **Elapsed / Total**   | `mm:ss` (или `h:mm:ss` для длинных) — прошедшее время реплея и полная длительность |

При загрузке нескольких транспортов слайдер охватывает **глобальный** start-to-end объединения всех треков. У треков которые ещё не стартовали в текущее время просто нет маркера на карте.

## Карта

Карта использует стиль вашей текущей темы (см. [Темы](../../features/ux/themes.md)). Для каждого загруженного трека:

- **Полилиния** окрашивается по скорости — зелёный для медленного, оранжевый для среднего, красный для быстрого
- **Зелёный Start-маркер** ставится в первой точке
- **Красный End-маркер** ставится в последней точке
- **Маркер транспорта** движется по линии по мере проигрывания таймлайна

Map-контролы в правом верхнем углу (вертикальный стек):

| Кнопка            | Что делает                                                                           |
| ----------------- | ------------------------------------------------------------------------------------ |
| **Zoom in / out** | Стандартный зум карты                                                                |
| **Reset bearing** | Возвращает карту к north-up если вы её повернули / наклонили                         |
| **Fit bounds**    | Подгоняет вид под полные маршрут(ы) — полезно когда камера дрейфует за долгий реплей |
| **Fullscreen**    | Карта в полный экран; полоса управления остаётся внизу                               |

## Скорость проигрывания

Дропдаун скорости предлагает 8 пресетов: **1x, 2x, 4x, 8x, 16x, 32x, 64x, 128x**.

- **1x** — реальное время; 20-минутная поездка проиграется 20 минут
- **128x** сжимает 8-часовой день примерно в 4 минуты
- Скорость можно менять во время проигрывания; анимация плавно продолжается с того же места

Используйте более высокие скорости (32x / 64x / 128x) для полнодневного реплея транспорта, низкие (1x / 2x / 4x) для forensic'а поездки когда нужно видеть где именно был райдер в каждую секунду.

## Инфо-панель на транспорт

Каждый загруженный транспорт получает маленькую карточку в сайдбаре, которая обновляется live по мере проигрывания:

| Поле            | Что показывает                                                                  |
| --------------- | ------------------------------------------------------------------------------- |
| **Speed**       | Текущая интерполированная скорость в км/ч (цветная: зелёная / жёлтая / красная) |
| **Coordinates** | Текущая lat / lng с точностью 6 знаков                                          |
| **Distance**    | Кумулятивная пройденная дистанция в км (haversine, считается на клиенте)        |
| **Point**       | Индекс текущей точки / всего точек (как далеко в датасете)                      |

Когда проигрывание не начато или данных нет — карточка показывает прочерки.

## Empty / loading состояния

- **Нет выбора** — на месте карты иконка play и подпись "Select a vehicle and date or ride to start replay"
- **Загрузка** — спиннер по центру с "Loading coordinates..." поверх карты
- **Нет данных** — если на выбранную дату / поездку нет координат, тост с warning "No coordinate data found for this selection", карта пустая
- **Не загрузился чанк карты** — карта это lazy-чанк (~1 MB); при ошибке загрузки (stale deploy, offline) — error-тост с предложением обновить страницу

## Типовые workflow

- **Расследовать жалобу** — переключитесь на By Ride, найдите поездку райдера, кликните → смотрите маршрут на 4x чтобы увидеть куда он реально ехал vs его слова
- **Аудит "потерянного" транспорта** — By Vehicle, выберите единицу, сегодняшняя дата → проигрывайте на 128x чтобы увидеть весь день за секунды; последняя точка маркера — где он сейчас
- **Сравнить два транспорта** — By Vehicle, выберите две единицы по похожим маршрутам, одна дата → обе полилинии и оба маркера рендерятся вместе для визуального сравнения
- **Найти время события** — загрузите поездку → перетащите слайдер на timestamp из тикета / лога → координаты в инфо-панели
- **Поймать превышения** — загрузите день транспорта → ищите **красные** сегменты полилинии → перетащите слайдер туда для подтверждения

## Tips

- **Макс 5 транспортов** одновременно — multi-select капнут, чтобы карта не лагала. Для большего — несколько сессий
- **Используйте Fit Bounds после долгого реплея** — проигрывание следует за маркером, камера дрейфует; один клик на Fit Bounds — и весь маршрут опять в кадре
- **Цвета скорости — не привязка к тарифу** — это чисто визуальные подсказки на основе GPS-скорости (>15 км/ч жёлтый, >30 км/ч красный). Сверьте со _speed mode_ транспорта на странице деталей для контекста
- **Слайдер скрабит в обе стороны** — тащите назад чтобы перемотать. В сочетании с низкой скоростью можно пошагово смотреть сложные сегменты
- **URL не сохраняет состояние** — выбор не сериализуется в URL, deep-link не пошлёте. Если нужно "забукмаркить" момент — скриншот
- **Парьте со страницей [деталей поездки](../../operations/trips/ride-detail.md)** — там статическая карта + timeline событий; replay добавляет временное измерение поверх неё
