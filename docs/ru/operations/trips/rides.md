# Поездки — Список

**Поездка** — это одна поездка клиента на одном из ваших транспортов. Список поездок (`/rides`) — это мастер-запись всех поездок: прошлых, текущих и предстоящих по всему флоту.

Откройте строку чтобы увидеть [страницу детали поездки](ride-detail.md) с маршрутом, таймлайном и полным набором действий.

Требуется право: **Rides** (`i1j2k3`).

## Откуда здесь берутся поездки

Поездки не создаются в дашборде — они приходят со стороны клиента:

1. Клиент **разблокирует транспорт** в мобильном приложении (Ridewolf rider app)
2. Бэкенд открывает новую запись поездки, привязанную к этому транспорту и клиенту
3. Поездка сразу появляется в списке со статусом **Active**
4. Когда клиент **блокирует / паркует** транспорт, бэкенд закрывает поездку; статус становится **Completed**, и считается итоговый breakdown (дистанция, длительность, цена)
5. Другие конечные статусы (`Cancelled` и т.п.) ставятся системными правилами или действиями оператора

Перезагрузите страницу или зайдите ещё раз чтобы получить свежий снимок — активные поездки обновляются по мере движения клиента.

## Порядок по умолчанию

По умолчанию бэкенд возвращает **активные поездки сверху**, затем завершённые в обратном хронологическом порядке (новые первыми). Клик по заголовку колонки переопределяет этот порядок.

## Фильтры

| Фильтр  | Тип          | Заметки                                                                |
| ------- | ------------ | ---------------------------------------------------------------------- |
| Поиск   | Текст        | Ищет по имени клиента, метке транспорта, ID поездки                    |
| Период  | Календарь    | От / до; по умолчанию "за всё время"                                   |
| Статус  | Дропдаун     | `Active`, `Completed`, `Cancelled` и т.д.                              |
| Рейтинг | Дропдаун     | Фильтр по звёздам рейтинга от рейдера (1–5, _Без рейтинга_)            |
| Теги    | Multi-select | Фильтр по тегам поездки (наследуются от транспорта — см. Колонки ниже) |

Все фильтры комбинируются по И. Чипы фильтров появляются над таблицей; URL отражает текущее состояние.

## Колонки

| Колонка   | Сортировка? | Содержимое                                                     |
| --------- | ----------- | -------------------------------------------------------------- |
| Клиент    | —           | Аватар, имя, ссылка на профиль клиента                         |
| Транспорт | —           | Метка, модель, ссылка на транспорт                             |
| Тариф     | —           | Название тарифа применённого к поездке                         |
| Stats     | —           | Быстрые бейджи: дистанция, длительность, итоговая стоимость    |
| Теги      | —           | Теги унаследованные от **транспорта** на момент старта поездки |
| Статус    | ✓           | Пилюля статуса (Active, Completed, Cancelled и т.д.)           |
| Рейтинг   | ✓           | Звёзды от рейдера (или "–" если нет)                           |
| Создано   | ✓           | Дата и время старта; по умолчанию сорт = новые сверху          |

Сортировка кликом по заголовку. Выбранная сортировка попадает в URL и **переопределяет** дефолтный порядок описанный выше — третий клик "восстановить дефолт" отсутствует, но можно убрать сорт-параметр из URL или перезагрузить страницу без него.

> **Теги наследуются от транспорта.** У поездок нет своего редактора тегов — теги поездки это снимок тегов транспорта на момент старта поездки. Поменяете теги транспорта позже — на существующих поездках останется их снимок; новые теги попадут только в новые поездки.

## Действия над строкой

У каждой строки справа — **меню из трёх точек**. Доступные действия зависят от статуса поездки и ваших прав:

| Действие     | Право           | Когда активно                                               |
| ------------ | --------------- | ----------------------------------------------------------- |
| **Pause**    | `pause-unpause` | Поездка **Active** (не на паузе, не завершена, не отменена) |
| **Resume**   | `pause-unpause` | Поездка на **паузе**                                        |
| **End ride** | `end-ride`      | Поездка **не** Completed и **не** Cancelled                 |

Действия без прав скрыты. Действия которые недоступны в текущем статусе (например, End на уже завершённой поездке) показаны серым — вы видите что возможно в нужном состоянии.

Полный набор действий — возврат, посмотреть маршрут на карте, отправить push, архивировать — живёт на **странице детали поездки**. Кликните по строке чтобы перейти.

## Действия страницы

В правом верхнем углу страницы списка:

- **Export** — скачать текущий отфильтрованный список файлом (фильтры и сортировка учитываются)

## Типичные сценарии на списке

- **Следить за активностью live** — откройте страницу и оставьте; активные поездки сверху
- **Найти поездки в зоне или временном окне** — сочетайте Период + Статус + Теги
- **Заметить аномалии** — отфильтруйте `Статус = Cancelled` или `Рейтинг ≤ 2` и ищите паттерны (один транспорт? одно время дня?)
- **Быстро остановить зависшую поездку** — не уходя со списка, откройте меню строки и _End ride_ (требуется право)

## Полезные приёмы

- **URL шарится** — отфильтруйте список, скопируйте URL, отправьте коллеге — он увидит ту же картину
- **Stats-бейджи в списке** — быстрый способ заметить странно короткие или длинные поездки до клика
- **Не доверяйте только рейтингу** — откройте детальную для низкорейтинговых поездок; рейтинг — один из многих сигналов
- **Права варьируются по компаниям** — некоторые операторы видят только свои поездки; если поездки нет, уточните у админа
