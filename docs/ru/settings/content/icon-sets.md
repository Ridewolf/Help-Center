# Icon Sets

Страница Icon Sets (`/settings/icon-sets`) — это **библиотека иконок на карте**, которой rider mobile app Ridewolf рендерит транспорт. Каждый набор привязан к одному типу транспорта (e-scooter, e-bike, cargo e-bike, e-moped, e-car, e-boat) и содержит три категории SVG-иконок: **Selected**, **Non-selected** и **Discount**.

Это инфраструктура контента — оператор грузит SVG здесь, rider app выбирает нужную иконку на основе типа транспорта, уровня заряда и того, тапнул ли райдер по точке. Релиз мобильного приложения не нужен.

Вместе с [FAQ Sets](faq-sets.md) и [Quick Guides](quick-guides.md) — это контент-слой дашборда.

Требуется право: **Icon Sets** (check with admin).

## Где это видно райдеру

На карте rider app каждая точка транспорта использует иконку из активного набора своего типа:

- **Non-selected** иконки — для точек, по которым райдер ещё не тапал — шесть уровней заряда (`bat10`, `bat25`, `bat40`, `bat55`, `bat90`, `bat100`), чтобы точка отражала текущий заряд
- **Selected** иконки — заменяют точку когда райдер по ней тапнул — те же 6 уровней, другой стиль
- **Discount** иконки (5%, 15%, 25%, 35%, 45%, 55% по умолчанию) — оверлей на точке когда у транспорта promo-цена

Один набор на тип транспорта можно отметить как **default** — именно его приложение загрузит когда ничего другого не настроено.

## Фильтры

| Фильтр         | Тип      | Заметки                                                                                                 |
| -------------- | -------- | ------------------------------------------------------------------------------------------------------- |
| Search         | Текст    | Поле в шапке — по title / slug                                                                          |
| Vehicle type   | Дропдаун | `E-scooter` / `E-bike` / `Cargo e-bike` / `E-moped` / `E-car` / `E-boat` (или `All`)                    |
| State coverage | Дропдаун | По заполненности: `Selected only` / `Non-selected only` / `Discount only` / `Full coverage` (или `All`) |
| Status         | Дропдаун | `Active` / `Draft` / `Incomplete` / `Archived` (или `All`)                                              |
| Tags           | Combobox | Свободный фильтр по тегам (поле показано но пока disabled — будет позже)                                |

**Clear all** сбрасывает все фильтры.

## Колонки

| Колонка                | Содержимое                                                             |
| ---------------------- | ---------------------------------------------------------------------- |
| **Set**                | Иконка пакета + title; вторая строка — slug                            |
| **Vehicle type**       | Пилюля типа (E-scooter, E-bike и т.д.)                                 |
| **Selected icons**     | Покрытие вида `6/6` (сколько уровней заряда загружено)                 |
| **Non-selected icons** | То же покрытие `n/6` для non-selected варианта                         |
| **Discount icons**     | Первые 3 процента скидки чипами (`5%`, `15%`, `25%`), `+N` для остатка |
| **Tags**               | Первые 2 чипа тегов с `+N` для остатка                                 |
| **Updated**            | Дата последнего обновления                                             |
| **Status**             | `Active` / `Draft` / `Incomplete` / `Archived`                         |

`Incomplete` значит набор не дозаполнен в одной из трёх категорий — rider app откатится на default для этого типа транспорта, пока вы не закончите загрузку.

Клик по строке открывает **Detail dialog** — визуальное превью всех иконок в наборе. Клик по меню из трёх точек — действия.

## Действия над строкой

| Действие           | Что делает                                                                             |
| ------------------ | -------------------------------------------------------------------------------------- |
| **View details**   | Открыть detail с превью всех загруженных SVG                                           |
| **Edit**           | Открыть форму с пятью табами (Details / Selected / Non-selected / Discounts / Preview) |
| **Duplicate**      | Клонировать набор как Draft                                                            |
| **Set as default** | Назначить набор дефолтом для его типа транспорта — rider app загрузит его              |
| **Download**       | Скачать набор как ZIP со всеми SVG                                                     |
| **Archive**        | Перевести в `Archived` — в истории, не используется приложением                        |
| **Delete**         | Удалить навсегда                                                                       |

В тулбаре сверху — массовые **Import** (ZIP / JSON) и **Export** (ZIP / JSON).

## Форма Create / Edit

Диалог с пятью табами:

1. **Details** — title (обязательное), slug (auto), vehicle type (обязательное), tags, status
2. **Selected** — загрузить 6 SVG, по одному на уровень заряда (`bat10` → `bat100`)
3. **Non-selected** — те же 6 слотов, для невыбранного состояния
4. **Discounts** — по одному SVG на процент скидки. Дефолтные пресеты `5, 15, 25, 35, 45, 55`, но можно добавлять/удалять строки
5. **Preview** — визуальная проверка набора перед сохранением

Набор с пустыми слотами в любом табе сохраняется как `Incomplete`.

## Типичные сценарии

- **Обновить точки самокатов под ребрендинг** — Duplicate текущего default → загрузить новые SVG во все три таба → сохранить как Draft → Preview → Set as default → rider app подхватит при следующем refresh
- **A/B-тест иконок** — оставить старый набор Active и не-default, создать новый Active + default для типа → откат через Set default старого
- **Праздничные discount-иконки** — открыть активный набор → Edit → таб Discounts → загрузить тематические SVG для актуальных процентов → save
- **Bulk import ZIP от дизайнера** — top-right _Import_ → ZIP → подтвердить маппинг → проверить в Preview → Activate

## Полезные приёмы

- **Один default на тип транспорта** — установка нового default автоматом снимает предыдущий. Статус не обязан быть `Active` для default, но желательно
- **Уровни заряда зафиксированы** — `bat10/25/40/55/90/100` — единственные buckets, которые понимает приложение; оно выбирает ближайший по реальному заряду
- **Только SVG** — аплоад ждёт SVG-файлы; PNG не отмасштабируются на retina-экранах чисто
- **`Incomplete` — полезный guardrail** — он говорит что rider app откатился на default, так что вы случайно не выкатите недозалитый набор
- **Archive перед Delete** — архивные наборы остаются в поиске, на случай если захочется откатить
