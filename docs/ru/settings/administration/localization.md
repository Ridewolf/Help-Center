# Локализация

Страница «Локализация» (`/settings/localization`) — это **рабочее место переводчика**: библиотека _коллекций_ (групп связанных ключей) которые можно редактировать, импортировать, экспортировать и публиковать. У каждой коллекции есть namespace (например, `ui`, `auth`, `rides`), базовый язык (всегда `en`), набор целевых языков и список ключей со значениями по языкам.

> _Примечание_: страница сейчас **только клиентский прототип** — коллекции приходят из `mockData.ts` и держатся в локальном состоянии. _Save_ и _Publish_ показывают toast, но эндпоинта ещё нет. Страница пригодна как спецификация для будущего API; ничего из сделанного не сохраняется.

Разрешение: на маршруте не задан `requiredPermissions` — любой авторизованный оператор может открыть страницу.

## Раскладка страницы

Одна строка-шапка с заголовком, поиском, выпадающим _Import / Export_ и кнопкой _+ Create collection_ — затем карточка фильтров и таблица коллекций.

Справочные данные (сейчас жёстко в `Localization.vue`):

- Языки: `en`, `ro`, `ru`, `de`, `fr`, `es` (база + 5 целевых)
- Namespaces: `ui`, `auth`, `rides`, `payments`, `marketing`
- Теги: `core`, `beta`, `promo`, `legacy`

## Фильтры

Карточка Filters над таблицей.

| Фильтр    | Тип            | Заметки                                                                |
| --------- | -------------- | ---------------------------------------------------------------------- |
| Language  | Dropdown       | Оставляет коллекции, содержащие этот язык. Дефолт `ro`                 |
| Namespace | Dropdown       | Один из списка namespace (или пусто = все)                             |
| Status    | Dropdown       | `all`, `active`, `draft`, `archived`                                   |
| Tags      | Toggle chips   | Чипы тегов — коллекция должна нести _все_ выбранные теги, чтобы пройти |
| Search    | Поле (toolbar) | Debounce 300 мс — матчит имя, описание, namespace                      |

Кнопка _Clear_ на карточке сбрасывает все четыре фильтра.

## Таблица коллекций

| Колонка    | Сортируется? | Содержимое                                                                                 |
| ---------- | ------------ | ------------------------------------------------------------------------------------------ |
| Collection | —            | Имя + однострочное описание                                                                |
| Namespace  | —            | Badge с namespace                                                                          |
| Languages  | —            | Badge на язык. Базовый — primary, целевые — secondary. Hover показывает _base_ vs _target_ |
| Keys       | —            | Общее число ключей. Hover — разбивка по флагам (_missing_, _changed_, _obsolete_)          |
| Status     | —            | Badge — `active` / `draft` / `archived`                                                    |
| Updated    | —            | Относительная дата. Hover — автор                                                          |
| Actions    | —            | Меню 3-точки на строке                                                                     |

Пагинация внизу: _Previous / Next_, общее число и селектор per-page (10 / 20 / 50).

### Действия в строке

| Действие  | Что делает                                                                           |
| --------- | ------------------------------------------------------------------------------------ |
| View      | Открывает Collection dialog только-чтение                                            |
| Edit      | Открывает Collection dialog в режиме _edit_                                          |
| Duplicate | Клонирует коллекцию с суффиксом « (Copy)» в начале списка                            |
| Import    | Открывает Collection dialog на вкладке _Import / Export_ в режиме импорта            |
| Export    | Toast — плейсхолдер для скачивания в выбранном формате                               |
| Archive   | Переводит статус в `archived` (строка остаётся — отфильтруйте Status, чтобы увидеть) |
| Delete    | Удаляет строку из локального списка                                                  |

## Create / Edit / View — Collection dialog

Открывается из + Create или любого пункта меню строки. Четыре вкладки внутри.

### Overview

Метаданные коллекции.

- _Name_ (обязательно) — отображаемое имя (например, «UI Labels»).
- _Namespace_ — пикер с поиском.
- _Description_ — короткое описание.
- _Base language_ — только-чтение, всегда `en`.
- _Target languages_ — toggable чипы из пяти не-английских опций. База + целевые задают набор колонок-языков во вкладке Keys.
- _Status_ — `active` / `draft` / `archived`.
- _Tags_ — toggable чипы из списка тегов.

### Keys

Сама сетка переводов.

- Toolbar: поиск (имя ключа и любое значение), фильтр статуса (например, _Missing only_), выбор языка (какая целевая колонка выделена для редактирования).
- Bulk-действия при выборе строк: _Set status_, _Clear values_, _Export selected_, _Delete_.
- Per-row: duplicate key, delete key, copy-from-English (копирует EN-значение в целевой), validate placeholders (проверяет, что плейсхолдеры вроде `{{name}}` сохранены).
- У строки бывают флаги в виде badge:

| Флаг       | Смысл                                                                     |
| ---------- | ------------------------------------------------------------------------- |
| `new`      | Ключ недавно добавлен — нужна ручная проверка                             |
| `changed`  | EN-значение изменилось после последнего перевода — целевые могут устареть |
| `missing`  | Пустое значение хотя бы в одном целевом языке                             |
| `obsolete` | Ключ больше не используется в коде — можно безопасно удалить              |

- _Add key_ и _Find & replace_ открывают отдельные мини-диалоги.
- _Autosave_ — когда включён, правки коммитятся в локальный state сразу.

### Import / Export

Import:

- _Format_ — JSON / CSV / XLSX.
- _Mode_ — replace / merge / append.
- _Keep unknown keys_ — при выключении ключи, отсутствующие в импорте, помечаются `obsolete`.
- _Simulate_ — dry-run с отчётом о том, что изменится (без записи).
- _Apply_ — применить импорт. Прогресс-бар показывается во время выполнения.

Export:

- _Format_ — JSON / CSV / XLSX.
- _Scope_ — все ключи / отфильтрованные / выбранные.
- _Download_ — плейсхолдер (пока toast).

### Publish

- Сводный блок: _N всего / M changed / K missing_.
- Список изменённых ключей с before / after.
- Список предупреждений (например, mismatch плейсхолдеров, пустой целевой).
- _Save draft_ — фиксирует рабочую копию как draft (`status = draft`).
- _Publish_ — переводит draft в `active` и тостит.

## Верхний toolbar — меню Import / Export

Два глобальных ярлыка в шапке (отдельно от per-collection):

- _Import collections_ — открывает page-level импорт-диалог (массовый импорт нескольких коллекций сразу).
- _Export all_ — экспортирует все коллекции одной пачкой (пока toast).

## Несохранённые изменения и навигационный guard

Есть глобальный флаг (`hasUnsavedGlobal`) — пока он включён, виден закреплённый footer с _Discard_ / _Save_. Также установлен `router.beforeEach`: попытка уйти со страницы при несохранённых правках вызывает нативный браузерный _confirm_.

## Сценарии

- **Перевести новый ключ на румынский** — выбрать коллекцию → Edit → Keys → язык `ro` → найти ключ (или _Add key_) → заполнить значение → _Save_ (или включить Autosave).
- **Аудит пропусков в французском** — Edit коллекции → Keys → статус _Missing only_ → язык _fr_. Можно использовать _Copy from English_ как быстрый fallback, или _Validate placeholders_ перед публикацией.
- **Массовое обновление из XLSX** — Edit → Import / Export → XLSX, mode _Merge_, сперва _Simulate_ → ревью diff → _Apply_.
- **Перевести draft в продакшн** — Edit → Publish → подтвердить changed-keys, починить warnings → _Publish_.
- **Сделать вариант для нового рынка** — Duplicate → переименовать → добавить язык в _Target languages_ → переводить.
- **Архивировать устаревший набор** — меню строки → Archive. Коллекция остаётся в таблице, но переходит в `archived`; найти позже через фильтр Status.

## Советы

- **Сейчас только клиент.** Ни один из `Save`, `Publish`, `Export`, `Delete`, `Archive` ничего не отправляет на бэк — только локальный state + toast. Не используйте для продакшн-строк, пока не появится API.
- **Базовый язык залочен.** `en` всегда базовый — не-английские коллекции должны создаваться как target к английской базе, а не самостоятельно.
- **Tags работают по AND.** Фильтр по двум чипам тегов значит, что коллекция несёт _оба_ тега. Чтобы искать по любому — снимите один из чипов.
- **Guard глобальный.** Даже если грязный только диалог, выход со страницы спрашивает подтверждение — явно save/discard, чтобы избежать prompt.
- **Валидация плейсхолдеров — ваш друг** — запуск перед Publish ловит «мы потеряли `{{name}}` в переводе»-баги, которые ломают рендер строки.
- **Не путать с вкладкой Locale в [Общих настройках](general.md)** — там задаются дефолты (какие языки _активны_, форматы даты / времени / единиц). Здесь живут сами переведённые строки.
- **Справочные данные — мок.** Языки, namespaces и теги сейчас жёстко зашиты — после появления API они придут с бэка и, возможно, станут редактируемыми.
