# Моя компания

Страница **«Моя компания»** (`/settings/my-company`) — это идентичность вашего оператора: юридические данные компании, обслуживающей флот, её брендинг и конфигурация, которую читает райдер-приложение — город карты по умолчанию, способы входа, каналы поддержки и юридические ссылки.

Страница видна только операторам, у которых есть **оба** права — просмотр и редактирование компании; без права редактирования она скрывается полностью, а не показывается в режиме только-чтения.

Как и весь дашборд, «Моя компания» подстраивается под выбранный режим интерфейса:

- **Упрощённый режим** (в переключателе режимов — _Lite_) — сводка основных данных только для чтения плюс пошаговый **мастер из пяти шагов** для их редактирования.
- **Расширенный режим** — четыре вкладки: **Профиль** (в интерфейсе — _Компания_), **Конфигурация приложения** (вкладка _Приложение_), **Платежи** и **Интеграции**.

Переключение с Упрощённого на Расширенный запрашивает подтверждение и перезагружает страницу; дашборд запоминает выбранный режим.

## Упрощённый режим

Упрощённый режим показывает главное с первого взгляда — логотип, контактные данные (email, телефон, сайт, адрес) и включённые публичные каналы поддержки — плюс раздел «Подробнее» только для чтения со всем остальным: данными юр. лица, брендингом приложения, платёжными провайдерами и подключёнными интеграциями, юридическими ссылками.

Доступны два действия:

- **Редактировать данные** открывает пошаговый мастер (ниже).
- **Переключитесь на Расширенный режим для платежей и интеграций** — ключи платёжных провайдеров и учётные данные интеграций настраиваются только в Расширенном режиме; эта кнопка ведёт туда (подтверждение → страница перезагружается).

### Мастер из пяти шагов

**Редактировать данные** проводит по основным данным шаг за шагом и сохраняет всё одним действием в конце:

1. **Название и логотип** — отображаемое название компании (обязательно) и логотип.
2. **Контактные данные** — email, телефон, сайт.
3. **Адрес** — страна, город, адрес, почтовый индекс.
4. **Каналы поддержки** — публичные каналы связи, которые райдеры видят в приложении.
5. **Обзор** — сводка всех полей с кнопками редактирования у каждой строки; **Подтвердить и сохранить** сохраняет всё разом.

## Расширенный режим

Четыре вкладки. Закреплённый нижний футер с кнопками **Отменить** и **Сохранить изменения** появляется только когда что-то действительно изменилось — если кнопки сохранения не видно, значит, изменений пока нет.

### Вкладка «Профиль» (_Компания_)

Само юридическое лицо, пять карточек:

- **Идентичность** — _Юридическое название_ (обязательно), _Отображаемое имя_ (короткое название; здесь необязательно, хотя мастер Упрощённого режима его требует), _Регистрационный номер_ (обязательно) и _Налоговый ID_ (необязательно, с подсказкой о том, что формат зависит от юрисдикции).
- **Расположение** — _Страна_, _Город_, _Адрес_ и _Почтовый индекс_ (все обязательны).
- **Контакты** — _Email_ (обязательно), _Телефон_ и _Сайт_ (необязательны).
- **Подключение трекеров** — только чтение: _Домен_ и _Порт_, назначенные вашей компании, готовая строка _Endpoint_ (выделяется одним кликом) и пошаговая инструкция, как направить на неё трекер транспортного средства. Сами устройства управляются на странице [Трекер](../infrastructure/iot.md).
- **Контент** — _Описание_ (короткий текст) и _О компании_ (длинный текст), оба в Markdown с живым предпросмотром.

**Валюты на этой вкладке нет.** Валюта компании (и производный от неё символ) — это первый шаг вкладки **«Платежи»**, см. [Платежи и интеграции](company-integrations.md).

### Вкладка «Конфигурация приложения» (_Приложение_)

Всё, что читает райдер-приложение, сверху вниз:

- **Бренд и цвета** — название приложения, короткое имя, логотип и цвета темы/акцента (hex-значения). Логотип задаётся URL-адресом с предпросмотром; прямая загрузка файла пока недоступна.
- **Карта по умолчанию** — кликните по интерактивной карте, чтобы задать город по умолчанию для райдер-приложения; сохраняются широта, долгота и зум, а точка клика превращается в название города обратным геокодированием.
- **Способы аутентификации** — переключатели _OTP по телефону_, _OTP по email_, _Email и пароль_, _Google_, _Apple_, _Telegram_ и _WhatsApp_. Социальные способы работают только после настройки и включения соответствующей карточки на вкладке **«Интеграции»** — см. [Платежи и интеграции](company-integrations.md).
- **Дополнительные шаги регистрации** — дополнительные шаги при регистрации, у каждого ID, позиция и переключатель _Обязательный_; **Добавить шаг** добавляет новую строку.
- **Коммуникации** — переключатель _live-чата_ и **Telegram-бот для OTP**: вставьте токен бота, нажмите **Проверить чаты** и выберите из списка чат, который бот должен использовать. Это отдельная настройка, не связанная с карточкой Telegram на вкладке «Интеграции» — настройка одной не настраивает другую.
- **Каналы поддержки** — _Email_, _Телефон_, _Сайт_, _Telegram_ и _WhatsApp_, у каждого переключатель и поле значения; райдерам показываются только включённые каналы.
- **Юридическое** — URL-адреса _Условий обслуживания_, _Политики конфиденциальности_ и _Лицензий_, отображаемые в приложении.

### Вкладки «Платежи» и «Интеграции»

Платёжным шлюзам (валюта, карточки провайдеров maib / mia / Stripe, провайдер по умолчанию) и сервисным интеграциям (Telegram, WhatsApp, Google, Apple, OpenAI) посвящена отдельная статья: **[Платежи и интеграции](company-integrations.md)**. Главное, что нужно помнить: эти карточки **сохраняются по отдельности**, независимо от футера «Сохранить изменения» этой страницы.

## Сценарии

- **Быстро поправить телефон или адрес** — Упрощённый режим → **Редактировать данные** → перейти к нужному шагу → **Обзор** → **Подтвердить и сохранить**.
- **Обновить юридический адрес (Расширенный)** — вкладка «Профиль» → карточка «Расположение» → отредактировать поля → **Сохранить изменения**.
- **Ребрендинг райдер-приложения** — вкладка «Конфигурация приложения» → бренд → обновить название, цвета и URL логотипа → **Сохранить изменения**.
- **Перенести город карты по умолчанию** — вкладка «Конфигурация приложения» → карта по умолчанию → кликнуть по новому месту → **Сохранить изменения**.
- **Разрешить райдерам вход через Google** — сначала настроить и включить карточку Google на вкладке «Интеграции», затем включить _Google_ в способах аутентификации → **Сохранить изменения**.
- **Добавить обязательный шаг загрузки ID при регистрации** — вкладка «Конфигурация приложения» → дополнительные шаги регистрации → **Добавить шаг** → задать ID и позицию, включить _Обязательный_ → **Сохранить изменения**.
- **Направить трекер на вашу компанию** — вкладка «Профиль» → «Подключение трекеров» → скопировать строку _Endpoint_ в конфигурацию устройства.
- **Опубликовать обновлённые юридические документы** — вкладка «Конфигурация приложения» → «Юридическое» → вставить новые публичные URL → **Сохранить изменения**.

## Частые вопросы

- **Я вообще не вижу эту страницу.** Нужны оба права — просмотр и редактирование компании; обратитесь к администратору.
- **В Расширенном режиме нет кнопки сохранения.** Футер появляется только после того, как что-то изменилось.
- **Где валюта?** На вкладке **«Платежи»**, а не на вкладке «Профиль» — см. [Платежи и интеграции](company-integrations.md).
- **Социальный способ входа не работает у райдеров.** Сначала настройте и включите соответствующую карточку на «Интеграциях», затем включайте способ аутентификации.
- **Логотип не загружается.** Сегодня можно указать только URL; прямая загрузка файла появится позже.
- **Клик по карте не подставляет название города.** Координаты и зум всё равно сохраняются — название города приходит из обратного геокодирования и иногда может быть недоступно.
- **Где требования к фото поездок?** Не здесь — подтверждения начала/окончания поездки настраиваются для каждой модели транспорта в [Настройках транспорта](../infrastructure/vehicle-settings.md).
