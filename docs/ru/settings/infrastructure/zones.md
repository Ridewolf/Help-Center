# Зоны

Страница Зоны (`/zones`) — место где вы рисуете **невидимые правила вашей зоны обслуживания**: парковки, no-go, low-speed, charge и другие полигоны, которые меняют поведение машин и клиентов при пересечении границы. Каждая зона — это один полигон на карте плюс тип, статус, опциональные параметры (скорость, цена, лимит машин) и теги.

Зоны управляют рантайм-поведением [Машин](../../operations/fleet/vehicles.md) — заехал в no-ride полигон, и машина отрубается; припарковался в paid-parking, и срабатывает тариф.

Требуется право: **Zones** (`u7v8w9`). Под-права `create` / `edit` / `delete` гейтят соответствующие действия.

## Что такое зона

Зона состоит из четырёх несущих частей:

1. **Тип** — определяет цвет и правило в рантайме (см. таблицу ниже)
2. **Полигон** — ровно один полигон, нарисованный на карте; вогнутые формы можно, дырки нельзя
3. **Параметры** — зависят от типа: скорость (low-speed), цена (paid-parking), сумма (charge), лимит машин (parking, paid-parking, rebalance)
4. **Статус** — `Active` (применяется), `Inactive` (сохранён, но игнорируется), `Archived` (скрыт из большинства списков)

### Типы зон

| Тип              | Цвет          | Что делает                                                          |
| ---------------- | ------------- | ------------------------------------------------------------------- |
| **No-go**        | Чёрный        | Машины не могут заезжать и работать здесь                           |
| **No-parking**   | Красный       | Райдер не может завершить поездку здесь                             |
| **No-ride**      | Фиолетовый    | Машины отрубаются / отказываются стартовать внутри                  |
| **Low-speed**    | Синий         | Максимальная скорость ограничена значением `speed` (км/ч)           |
| **Parking**      | Зелёный       | Зона парковки; опциональный лимит машин                             |
| **Paid-parking** | Оранжевый     | Парковка с ценой и опциональным лимитом                             |
| **Charge**       | Тёмно-зелёный | Reward-зона — `amount` начисляется райдеру за финиш здесь           |
| **Maintenance**  | Тёмно-красный | Внутренний маркер для ops; машины внутри исключаются из райдер-флоу |
| **Rebalance**    | Тёмно-синий   | Целевая зона для ребалансировки; опциональный лимит машин           |

## Режимы просмотра

Toggle-группа в шапке переключает три вида — те же данные, разный угол.

| Режим     | Лучше всего для                                                        |
| --------- | ---------------------------------------------------------------------- |
| **Table** | Bulk-операции, сортировка по name/type/status, пагинированный просмотр |
| **Cards** | Визуальный скан с мини-картой на каждой зоне; infinite scroll          |
| **Map**   | Все зоны на реальной карте — удобно для аудита покрытия                |

## Фильтры

| Фильтр | Тип      | Заметки                           |
| ------ | -------- | --------------------------------- |
| Search | Текст    | Ищет по имени зоны и описанию     |
| Status | Дропдаун | `Active` / `Inactive` (или `All`) |
| Type   | Дропдаун | Один из 9 типов (или `All`)       |

Фильтры действуют во всех трёх режимах. Map-вид грузит **все** подходящие зоны (без пагинации); Table и Cards пагинируют.

## Колонки (Table view)

| Колонка         | Сортировка? | Содержимое                                        |
| --------------- | ----------- | ------------------------------------------------- |
| **Zone name**   | ✓           | Label + цветной свотч типа; ссылка на деталь зоны |
| **Description** | —           | Опциональное описание                             |
| **Type**        | ✓           | Цветная пилюля типа (см. таблицу типов выше)      |
| **Status**      | ✓           | `Active` / `Inactive` / `Archived`                |
| **Tags**        | —           | Теги навешенные на зону                           |

## Действия над строкой

Меню из трёх точек. Доступные действия зависят от прав:

| Действие         | Право    | Что делает                                          |
| ---------------- | -------- | --------------------------------------------------- |
| **View details** | —        | Открыть детальную (карта + метаданные)              |
| **Edit**         | `edit`   | Открыть форму редактирования (геометрия и свойства) |
| **Delete**       | `delete` | Удаление навсегда — требуется 3-секундное удержание |

## Bulk-действия

Выделите строки в Table-виде — появится bar bulk-действий. Все мутирующие требуют права `edit`:

- **Change type** — перекрасить много зон в новый тип сразу (параметры сбросятся)
- **Change vehicle limit** — выставить `allowedVehicles` по выборке (parking / paid-parking / rebalance)
- **Change value** — выставить тип-специфичное число (speed / price / amount)
- **Change status** — переключить Active ↔ Inactive массово
- **Change tags** — добавить или заменить теги по выборке
- **Export selected** — скачать только выделенные зоны как JSON (право не нужно; client-side)

## Создание — 5-шаговый визард

`+ Create` открывает направляющую форму. Назад можно прыгать свободно; вперёд — только если текущий шаг валиден.

1. **Name & description** — `Label` (обязательное) и опциональный `Description`
2. **Classify** — `Type` (обязательное, определяет цвет и форму параметров), `Status` (Active / Inactive / Archived), `Tags`
3. **Parameters** — тип-специфичные числовые поля со слайдером 0–100 для быстрого ввода: скорость (км/ч), цена, сумма или лимит машин. Типы без параметров показывают "no params" и пропускают шаг
4. **Geometry** — нарисовать ровно **1 полигон** на карте. Существующие зоны можно включить как пунктирный оверлей чтобы не пересекаться. Контролы карты: draw, edit, add points, undo (до 20 шагов), delete, zoom, fit-bounds, locate-me, fullscreen
5. **Review** — финальная read-only сводка всех полей плюс количество точек полигона

При сохранении создаётся зона и происходит переход на её деталь.

## Форма Edit

`Edit` использует ту же оболочку, но в виде одной страницы (без степпера) — поменяйте label, тип, статус, параметры, теги или перерисуйте полигон → Save. Unsaved-changes guard спросит перед уходом со страницы.

## Import / Export

Две outline-кнопки рядом с **+ Create**:

- **Import** — выбрать `.json` файл, экспортированный ранее; дашборд валидирует payload и создаёт зоны на сервере. Требует право `create`
- **Export** — открывает диалог с выбором: текущая страница, все страницы с фильтрами или всё. Bar bulk-действий тоже даёт "Export selected" для выделенных

## Детальная страница

Клик по строке (или _View details_) открывает деталь зоны:

- Live-предпросмотр полигона на карте
- Карточка Basic info (label, description, type, status, color)
- Карточка Parameters (speed / price / amount / allowed vehicles, когда применимо)
- Tags
- Created / updated timestamps
- Кнопки Edit и Delete в шапке (gated правами)

## Типичные сценарии

- **Запуск нового города** — Import JSON-пака если есть, иначе сначала нарисовать no-go-кольцо, потом parking-полигоны внутри
- **Подкрутка slow-speed зоны** — Edit → шаг 3 → поднять speed → Save. Применяется сразу
- **Закрыть парковку на день** — Edit → Status = Inactive → Save. Вернуть Active когда откроют
- **Перезонирование после городских изменений** — bulk-выбор → Change type → confirm. Старые тип-специфичные параметры очистятся автоматически
- **Аудит покрытия** — переключиться в Map-вид, фильтр Status = Active, глазами найти дыры и пересечения

## Полезные приёмы

- **Тип определяет всё** — цвет, форму параметров, рантайм-правило. Неправильный тип — самая частая причина переделок
- **Один полигон на зону** — сложные области режьте на несколько зон; редактор принудительно ограничивает одним полигоном
- **Пересечения зон разрешены** — самое строгое правило выигрывает (no-go > no-ride > low-speed), не бойтесь класть low-speed внутрь parking
- **Пунктирный оверлей** — включайте "Show existing zones on map" в редакторе чтобы не залезть на соседнюю зону
- **Inactive ≠ Deleted** — флипайте Status когда нужна временная пауза; Delete навсегда (3-секундное удержание — страховка)
- **Тегайте зоны** — теги это единственный multi-select фильтр, переживающий смену вида. Используйте для группировки по району, кампании или владельцу
- **Экспорт перед bulk-операцией** — один клик в диалоге экспорта = бэкап всего набора, и провальный bulk откатывается одним Import-ом
