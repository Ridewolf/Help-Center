# Райдер-приложение — Статистика райдера

**Статистика, обращённая к райдеру, сейчас недоступна в приложении.** Нет экрана с графиками, нет итогов и нет сводки трат, которую райдер мог бы открыть.

Вместо этого отправляйте райдеров в [Историю](history.md) — это единственное место с их собственными данными.

## Что видит райдер

- **Точки входа нет.** Боковое меню перечисляет Wallet, History, Support, Privacy, Settings и Profile — и больше ничего. Райдер, который говорит, что не может найти экран статистики, прав; не советуйте ему искать в меню и не присылайте ссылку на такой экран.
- Если открыть экран `/analytics` напрямую, он показывает только заголовок и пустое пространство. **Ничего не сломано** — ни в аккаунте райдера, ни на его устройстве, ни в установке приложения; переустановка ничего не изменит.

## Где реально живут цифры райдера

В [Истории](history.md) есть настоящие данные по каждому райдеру:

- Вкладка **Rides** перечисляет каждую прошлую поездку с расстоянием, длительностью и стоимостью
- Вкладка **Payments** перечисляет пополнения, возвраты, списания и бонусы с суммами и статусами
- Тап по поездке открывает её деталь с полной [разбивкой стоимости](../riding/rides.md#разбивка-стоимости), таймлайном активности и маршрутом, нарисованным на карте

**Баннера с общими итогами нигде нет** в райдер-приложении — ни на каком экране статистики, ни наверху Истории. Итоги за всё время приходится складывать из списка поездок вручную, либо брать из вашей собственной отчётности.

## Как отвечать на вопросы о цифрах со стороны дашборда

Когда райдеру действительно нужны итоги, получите их на стороне оператора:

| Что хочет райдер                | Где это взять                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------- |
| Общие траты за период             | [Аналитика — Платежи](../../analytics/reports/payments.md)                             |
| Экспортированный список своих поездок | [Поездки — Список](../../operations/trips/rides.md), отфильтрованный по этому клиенту |
| Свои платёжные записи             | [Платежи — История](../../operations/payments/payments.md)                             |
| Быстрая сводка по клиенту         | [Деталь клиента](../../operations/customers/client-detail.md) — количество поездок за всё время, баланс, рейтинг |

## FAQ

| Райдер спрашивает…                    | Ответ                                                                          |
| ---------------------------------------- | --------------------------------------------------------------------------- |
| «Где моя статистика?»                    | Сейчас недоступно в приложении. Используйте [Историю](history.md)             |
| «Не могу найти Analytics в меню»         | Для этого нет пункта меню                                                     |
| «Страница Analytics пустая»              | Ожидаемо — экран сейчас недоступен. Ничего не сломано                          |
| «Можно экспортировать данные моих поездок?» | Не из приложения. Экспортируйте это из дашборда от имени райдера            |
| «Сколько всего я потратил?»              | В райдер-приложении нет такого итога. Прочитайте его в Истории либо возьмите из дашборда |

## Полезные приёмы

- **Не присылайте райдерам ссылки на аналитику.** Там нет экрана, на который стоило бы попасть, а пустая страница читается как сломанное приложение.
- **Отвечайте на вопросы об итогах сами.** Взять цифру из дашборда занимает минуту и закрывает разговор.
- **История — честный ответ**, и она по-настоящему полная по каждой поездке и каждому платежу — подавайте это так, а не извиняйтесь за отсутствующий экран.
