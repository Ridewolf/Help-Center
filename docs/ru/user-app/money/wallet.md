# Райдер-приложение — Кошелёк и пополнения

Кошелёк (`/wallet`) — это денежный экран райдера, который открывается из строки баланса кошелька в боковом меню. Здесь текущий баланс, бонусы, точка входа для пополнения, переключатель автопополнения и путь к сохранённым картам.

Всё, что касается самих карт — добавление, удаление, выбор карты по умолчанию и три способа завершить пополнение — живёт в [Способах оплаты](payment-methods.md). Прошлые пополнения, возвраты, списания и бонусы — в [Истории](history.md).

## Что на экране

| Элемент                        | Что это                                                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Real Balance** (Реальный баланс) | Баланс райдера, доступный к трате. Иконка обновления рядом с ним заново читает баланс с сервера                    |
| **Bonuses** (Бонусы)            | Отдельный бонусный баланс, показывается только там, где бонусы включены                                            |
| Пресеты **Top-Up Amount** (Сумма пополнения) | Четыре кнопки: **50**, **100**, **200**, **400**. Поля для произвольной суммы на этом экране нет                    |
| **Auto Top-Up** (Автопополнение) | Один переключатель с описанием собственного порога и суммы                                                        |
| **Manage Payment Methods** (Управление способами оплаты) | Открывает [Способы оплаты](payment-methods.md) (`/wallet/payment-methods`)                          |

Если райдер настаивает, что его баланс неверный или устаревший, **сначала попросите его тапнуть по иконке обновления** — она очищает закешированное значение и читает актуальное. Это решает большинство жалоб «моё пополнение не отображается».

## Как райдер пополняет баланс

1. Открыть Кошелёк.
2. Выбрать одну из предустановленных сумм — 50, 100, 200 или 400.
3. Подтвердить пополнение.

Что происходит дальше, целиком зависит от используемого платёжного провайдера, и есть ровно **три** варианта:

| Сценарий провайдера                | Что видит райдер                                                                             | Покидает приложение? |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- | ---------------------- |
| **Подтверждение внутри приложения** (Stripe) | Платёж подтверждается прямо в приложении по сохранённой карте                        | Нет                   |
| **Редирект** (MAIB и подобные)      | Открывается внешний браузер, райдер платит на странице банка, приложение ждёт подтверждения      | Да                    |
| **QR-оплата** (MIA и подобные)      | Чекаут по QR / банковскому приложению с обратным отсчётом, приложение ждёт подтверждения          | Да                    |

**Только сценарий подтверждения внутри приложения завершается без выхода из приложения.** Для сценариев с редиректом и QR никогда не говорите райдеру, что деньги придут мгновенно — сначала ему нужно закончить оплату снаружи. Пошаговые инструкции для всех трёх — в [Способах оплаты](payment-methods.md#три-сценария-пополнения).

## Что происходит сразу после пополнения

Баланс обновляется в приложении немедленно, затем приложение сверяет его с сервером, повторяя попытки с растущей задержкой (примерно полсекунды, затем 1, 2, 4 и 8 секунд). Если подтверждение так и не приходит, показанный баланс **откатывается** к исходному значению.

Значит, баланс, который ненадолго появился и затем исчез, означает одно: **платёж так и не был подтверждён.** Проверьте список незавершённых пополнений на экране [Способы оплаты](payment-methods.md#незавершённые-пополнения).

## Автопополнение

- Один переключатель, с диалогом подтверждения, когда райдер включает его.
- Он **отключён**, если текущий провайдер не может подтверждать платежи внутри приложения. Именно поэтому райдер на провайдере, работающем только через редирект или только через QR, вообще не может его включить.
- Порог и сумма описаны прямо на экране. Смотрите их на экране — не называйте цифры по памяти и не заявляйте лимиты, которых экран не заявляет.

## Где живёт история платежей

Не здесь. Пополнения, возвраты, списания и бонусы перечислены на вкладке **Payments** в [Истории](history.md#вкладка-payments), с цветовой кодировкой суммы и статуса. Ваш собственный операторский журнал — [Платежи — История](../../operations/payments/payments.md).

## Решение проблем

| Райдер говорит…                     | Что проверить                                                                                                                             |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| «Мой баланс неверный / устаревший»    | Тапнуть по иконке обновления рядом с **Real Balance**                                                                                       |
| «Платёж отклонён»                     | Отказ со стороны карты или банка. Код ошибки — в записи платежа в [Истории → Payments](history.md#вкладка-payments)                          |
| «Недостаточно средств»                | Баланс ниже нужного для действия. Сначала пополните — и учтите, что у старта поездки свой собственный [минимальный стартовый баланс](../riding/rides.md#почему-райдер-не-может-начать-поездку) для райдеров без карты |
| «Не могу включить автопополнение»     | Активный провайдер не умеет подтверждать платежи внутри приложения                                                                          |
| «Моё пополнение ушло в никуда»        | Проверьте список незавершённых пополнений в [Способах оплаты](payment-methods.md#незавершённые-пополнения). Редирект- или QR-платёж, который так и не был завершён, лежит там же, и его можно отменить |
| «Когда придёт мой возврат?»           | Не называйте число дней — сроки возврата в приложении нигде не определены. Возвращённые платежи появляются на вкладке Payments со статусом «возвращено» |

## Полезные приёмы

- **Сначала обновите, потом расследуйте.** Половина тикетов «деньги пропали» — это закешированный баланс.
- **Знайте сценарий своего провайдера прежде, чем отвечать.** «Мгновенно» верно только для подтверждения внутри приложения; в двух других случаях райдеру нужно закончить оплату на стороне банка.
- **Исчезнувший баланс — это неподтверждённый платёж**, а не потерянный. Сразу идите в незавершённые пополнения.
- **Привязка карты полностью снимает проверку по балансу при старте поездки** — для райдеров, которые постоянно пополняют небольшими суммами, это лучший совет.
