# Райдер-приложение — Подписки и промокоды

**Подписки и промокоды сейчас недоступны в приложении.** Райдер не может купить план, не может активировать промокод, и ему нечего отменять.

Если вы хотите дать райдеру скидку, оформите её на стороне дашборда — см. [Как дать скидку райдеру сегодня](#как-дать-скидку-райдеру-сегодня).

## Что реально видит райдер

- Боковое меню на [Карте](../riding/map.md#меню-навигации) **не содержит ни пункта Promotions, ни пункта Subscriptions**.
- Ссылка `/subscriptions` не открывает экран. Райдер, который наберёт её или перейдёт по ней, попадает на экран приложения **Not Found**. Это ожидаемое поведение, а не проблема с его аккаунтом или устройством.
- Старая ссылка `/promo` просто перенаправляет в [Кошелёк](wallet.md).
- **В дашборде нет настройки**, которая включала бы подписки или промокоды для вашей компании.

Не обещайте райдеру, что код заработает «как только мы включим», и не называйте имена планов или цены — они сейчас не действуют.

## Как дать скидку райдеру сегодня

Доступны три механизма, все — на стороне оператора:

| Механизм                        | Где                                                                                                                  | Хорошо подходит для                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **Discount tiers тарифа**         | [Тарифы транспорта](../../settings/infrastructure/vehicle-tariffs.md)                                                | Постепенного удешевления долгих поездок для всех               |
| **Отдельный тариф плюс теги**     | [Тарифы транспорта](../../settings/infrastructure/vehicle-tariffs.md) + [Tags](../../settings/infrastructure/tags.md) | Более дешёвых цен для конкретной группы (корпоративные клиенты, сотрудники, VIP) |
| **Ручное пополнение баланса**     | [Деталь клиента](../../operations/customers/client-detail.md#действия) → **Top up balance**                          | Разовой компенсации после жалобы или неудачной поездки          |

Для разовой компенсации ручное пополнение баланса — самый быстрый вариант, и оно оставляет запись в журнале активности клиента. Для чего-то повторяющегося — закладывайте это в тариф.

## FAQ

| Вопрос                                          | Ответ                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| «Как мне купить подписку?»                       | Сейчас недоступно в приложении                                                                                  |
| «На странице подписок пишет Not Found»           | Верно и ожидаемо                                                                                                 |
| «Можно включить подписки для нашей компании?»    | Нет — для этого нет настройки в дашборде                                                                        |
| «Мой промокод не применяется»                    | Промокоды сейчас недоступны в приложении                                                                         |
| «Сканирование QR-кода с промокодом ничего не делает» | То же самое — сейчас недоступно                                                                              |
| «Как отменить мой план?»                         | Отменять нечего — плана нет                                                                                     |
| «А какая тогда цена действует для меня?»         | Тариф, привязанный к транспорту, на котором едет райдер. См. [Тарифы транспорта](../../settings/infrastructure/vehicle-tariffs.md) и [разбивку стоимости поездки](../riding/rides.md#разбивка-стоимости) |

## Полезные приёмы

- **Сначала скажите «сейчас недоступно», затем — что вы _можете_ сделать.** Райдер, который спрашивает про промокод, обычно на самом деле спрашивает про скидку; ручное пополнение баланса отвечает на настоящий вопрос.
- **Держите логику скидок в тарифах.** Всё, что вы там зададите, применяется последовательно и корректно отображается в разбивке стоимости поездки у райдера.
- **Следите за промокодами сторонних сервисов.** Если райдеры приходят с кодами из какой-то кампании, убедитесь, что маркетинг знает — приложение не умеет их активировать.
