# Сессии — устройства, вошедшие в аккаунт

Экран **Sessions** (`/settings/sessions`) перечисляет каждое место, где сейчас выполнен вход в аккаунт райдера, и позволяет разлогинить эти места. Это тот экран, к которому нужно обращаться всякий раз, когда райдер подозревает, что кто-то ещё получил доступ к его аккаунту.

Две точки входа, обе ведут сюда:

- **Profile → Manage Sessions**
- **Settings → карточка Privacy → Manage Sessions**

## Как организован список

Сессии **сгруппированы по устройству** — браузер и версия, операционная система и версия, тип устройства, производитель и модель — так что один и тот же телефон появляется один раз, а не десяток.

Группы отсортированы намеренно:

1. Сначала текущее устройство райдера
2. Затем по статусу: **active**, потом **inactive**, потом **old**
3. Затем по последней активности, сначала новые

Каждая группа сворачивается. Разворачивание показывает каждую отдельную сессию, принадлежащую этому устройству.

## Как читать группу устройства

| Что вы видите                              | Значение                                                                    |
| --------------------------------------------- | -------------------------------------------------------------------------- |
| **Device label** (метка устройства)           | Производитель и модель, если известны, иначе операционная система и её версия |
| Иконка типа устройства                        | Телефон, планшет или монитор                                                |
| **Browser label** (метка браузера)            | Браузер и версия, на которых работает сессия                                |
| Бейдж **Session status** (статус сессии)      | См. таблицу ниже                                                            |
| **Last activity** (последняя активность)      | Относительное время — «только что», N минут / часов / дней назад, и абсолютная дата, когда прошло больше недели |
| **Session count** (количество сессий)         | Сколько сессий у этого устройства                                          |
| **Location** (местоположение)                 | Город, страна и IP-адрес                                                   |
| **Created** (создана)                         | Когда началась эта сессия                                                  |
| **Current Device** / **Current Session**      | Выделенный бейдж на устройстве и сессии, которыми райдер пользуется прямо сейчас |

### Бейджи статуса

| Бейдж        | Значение                                   |
| ------------ | ------------------------------------------- |
| **active**   | Последняя активность менее часа назад       |
| **inactive** | Последняя активность менее 24 часов назад   |
| **old**      | Последняя активность 24 часа назад или больше |

Бейдж измеряет **только давность** — он не говорит, действительна ли ещё сессия. Бейдж «old» не означает, что сессия истекла.

## Выход из одной сессии

У текущей сессии нет элемента удаления — по замыслу её нельзя убрать из этого списка. Любую другую сессию можно:

1. Развернуть группу устройства
2. Тапнуть по иконке **корзины** на сессии
3. Подтвердить в диалоге

Список перезагружается, и сессия исчезает.

## Массовые действия

| Действие                     | Что оно делает                                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Logout Other Sessions** (завершить другие сессии) | Выходит из каждой сессии, кроме той, что на устройстве в руках у райдера. Это правильное действие, когда райдер подозревает, что кто-то ещё имеет доступ |
| **Logout All Sessions** (завершить все сессии)  | Выходит отовсюду, **включая текущее устройство**, так что райдера возвращает на экран входа и ему нужно войти заново. Поэтому оформлена как разрушительное действие |
| **Revoke Device** (отозвать устройство) | Предлагается на развёрнутой группе устройства, которая не является текущей — выходит из каждой сессии на этом устройстве |

Пока запрос на выход выполняется, кнопки отключены. Ошибка показывает короткое сообщение; успех показывает подтверждение и перезагружает список.

## Типичные сценарии

- **Райдер думает, что в его аккаунте кто-то ещё** — **Logout Other Sessions**, затем смена пароля из **Profile**. Учтите, что успешная смена пароля тоже выходит из аккаунта самого райдера, так что ему придётся войти ещё раз после этого ([Профиль](profile.md))
- **Забытый вход на чужом телефоне** — разверните группу этого устройства, **Revoke Device**
- **Чистый старт везде** — **Logout All Sessions**, затем вход заново ([Вход в приложение](registration-login.md))

## FAQ

- **Почему райдер не может удалить свою текущую сессию?** Для неё не показан элемент удаления. Чтобы завершить текущую сессию, используйте **Logout All Sessions** или обычную кнопку **Log Out** на Profile.
- **Что на самом деле значит «active»?** Активность за последний час — и ничего больше.
- **Почему на одном телефоне показано несколько сессий?** Сессии создаются на каждый вход. Экран группирует их под одним устройством и показывает счётчик.
- **Кнопка Manage Sessions серая.** У аккаунта запланировано удаление, что отключает управление сессиями вместе с редактированием профиля — см. [Профиль](profile.md).
