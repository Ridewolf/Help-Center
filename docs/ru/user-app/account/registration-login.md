# Вход в приложение — коды, пароли и вход через мессенджер

Всё, через что проходит райдер прежде, чем попасть на карту: выбор способа входа, подтверждение одноразового кода, заполнение минимального профиля, восстановление пароля или переход из бота в Telegram или Viber.

Используйте эту статью, когда райдер не может попасть в приложение. Что происходит *после* первого успешного входа — описано в [Онбординге и верификации](onboarding-verification.md).

## Какие способы входа видит райдер

Вкладки на экране входа (`/auth/login`) собираются из **Authentication Methods**, которые вы включаете в **Settings → My Company → App**. Не каждый райдер видит каждый способ. Возможные способы:

- Одноразовый код по **телефону**
- Одноразовый код по **email**
- Одноразовый код через **WhatsApp**
- **Email и пароль**
- **Google**
- **Apple**
- **Telegram**
- **Viber**

Если райдер говорит, что какого-то способа не хватает — значит, он не включён для этой компании. Включите его в [Моя компания](../../settings/administration/my-company.md) — со стороны райдера сделать ничего нельзя.

## Поля на каждой вкладке

| Вкладка                       | Поля                                                                                             |
| ------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Phone** (телефон)             | Номер телефона (минимум 6 символов) плюс выбор способа доставки — отправить код по **телефону** или через **WhatsApp** |
| **Email**                       | Адрес email                                                                                          |
| **Password** — вход             | Email и пароль                                                                                       |
| **Password** — регистрация      | **First Name** (обязательно, минимум 2 символа), **Last Name** (опционально), email, пароль          |

Телефон и WhatsApp — это **разные маршруты доставки**. Райдер, ждущий SMS, пока выбор доставки стоит на WhatsApp, будет ждать вечно.

Кнопки **Google** и **Apple** появляются, если эти способы включены. Если райдер закрывает окно провайдера, ничего не происходит и ошибка не показывается — это ожидаемое поведение, он просто отменил вход.

## Новый райдер или уже существующий

Прежде чем отправить код, приложение проверяет, принадлежит ли контакт уже существующему аккаунту.

- **Уже существующий райдер** — код отправляется сразу
- **Новый райдер** — сначала появляется короткий диалог регистрации, который собирает **First Name**, **Last Name** и тот контакт, которого не хватает: email, если код идёт на телефон, или телефон, если код идёт на email

## Проверка безопасности

Прежде чем можно будет запросить одноразовый код, на экране входа должна загрузиться CAPTCHA. Если она не загружается — заблокированная сеть, очень старый движок браузера, блокировщик рекламы во встроенном браузере — запрос кода отправить вообще нельзя. Попросите райдера открыть приложение заново при нормальном соединении.

## Ввод одноразового кода — `/auth/otp`

1. Райдер вводит код — ровно **6 цифр**, только цифры
2. **Resend** (отправить повторно) становится доступен, когда обратный отсчёт на экране доходит до нуля
3. На телефонном канале поддерживаемые телефоны подставляют код автоматически и сами его отправляют

Что происходит дальше:

- **Новый райдер** переходит на экран **Complete Profile**
- **Уже существующий райдер** попадает прямо в приложение

## Complete Profile (завершение профиля) — `/auth/complete-profile`

Показывается только новым райдерам. Запрашивает:

- **First Name** — обязательно, минимум 2 символа
- **Last Name** — опционально
- Тот контакт, которого ещё не хватает — email, если код пришёл по телефону, телефон, если код пришёл по email

Уже собранные значения подставляются заранее, и форма отправляется сама, если и имя, и контакт уже есть. Доступна кнопка **Skip** (пропустить).

Если позже выясняется, что у райдера не хватает номера телефона, попросите его проверить экран **Profile**, а не считать, что этот шаг его сохранил — см. [Профиль](profile.md).

## Райдеры, которые никогда не выбирали пароль

Райдер, создавший аккаунт через онбординг, никогда не выбирал пароль. Если позже он хочет войти на вкладке **Password**, ему сначала нужно задать пароль через **Forgot password**. Не говорите райдеру «просто попробуйте свой обычный пароль».

## Forgot password (забыли пароль) — `/auth/forgot-password`

Одно поле: email аккаунта. После отправки экран показывает один из трёх исходов, и они означают разное:

| Что видит райдер          | Значение                                              |
| ---------------------------- | -------------------------------------------------------- |
| **Зелёное сообщение**        | Письмо для сброса пароля отправлено успешно               |
| **Янтарный отсчёт**          | Слишком много попыток с этого устройства — дождитесь окончания таймера |
| **Красная ошибка**           | Сам запрос не прошёл — попробуйте снова                  |

Янтарный отсчёт хранится на конкретном устройстве райдера, поэтому не переносится на другой телефон.

## Reset password (сброс пароля) — `/auth/reset-password`

Райдер должен открыть этот экран по ссылке из письма для сброса. Если открыть его без действительной ссылки, райдера отправит обратно на **Forgot password** с уведомлением «ссылка истекла» — нужно запросить новое письмо.

На экране райдер вводит новый пароль и подтверждение. Правила пароля показываются вживую по мере ввода, и оба поля должны совпасть прежде, чем форму можно будет отправить.

## Вход через мессенджер (Telegram / Viber) — `/auth/messenger-callback`

Когда райдер стартует из вашего бота в Telegram или Viber, ссылка бота открывает промежуточную страницу, та открывает приложение, которое входит от имени райдера и переносит его в приложение.

Для двух ошибок есть отдельные сообщения:

- **Account blocked** (аккаунт заблокирован) — райдера переносит на экран **Account Blocked**, см. [Онбординг и верификация](onboarding-verification.md)
- **Rider access required** (нужен доступ райдера) — аккаунт существует, но не является райдер-аккаунтом у этой компании

Всё остальное показывает общее сообщение «неверный вход»; попросите райдера начать заново из бота по свежей ссылке.

## Лимиты частоты запросов

Лимиты на одноразовые коды устанавливает сервер, а не приложение. Экран показывает обратный отсчёт, построенный из того ожидания, которое вернул сервер. **Озвучивайте райдеру именно этот отсчёт — никогда не называйте фиксированное число минут**, потому что оно не фиксировано.

## Диагностика проблем

| Симптом                                   | Что это значит и что делать                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Не хватает способа входа                     | Он не включён в ваших **Authentication Methods**. Включите его в [Моя компания](../../settings/administration/my-company.md) |
| Код так и не пришёл                          | Дождитесь отсчёта, затем **Resend**. Проверьте, что способ доставки на вкладке **Phone** — тот, которого ждёт райдер: телефон и WhatsApp — разные маршруты |
| «Слишком много попыток»                      | Смотрите отсчёт на экране; длительность ожидания задаёт сервер                                    |
| Запрос кода не отправляется                  | Скорее всего, не загрузилась CAPTCHA на экране входа                                              |
| Райдер не знает свой пароль                  | Скорее всего, он никогда его не задавал. Отправьте через **Forgot password**                       |
| Ссылка сброса истекла                        | Райдера отбрасывает обратно на **Forgot password**; запросите новую ссылку                        |
| Экран **Account Blocked**                    | См. раздел про заблокированный аккаунт в [Онбординге и верификации](onboarding-verification.md)   |
| Вход выполнен, но ничего не грузится         | Проверьте [Сессии](sessions.md) — если у аккаунта есть отложенное удаление, часть приложения ограничена; см. [Профиль](profile.md) |
