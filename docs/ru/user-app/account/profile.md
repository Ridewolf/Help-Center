# Профиль — данные аккаунта, пароль и удаление

Экран **Profile** (`/profile`) — это собственный экран аккаунта райдера: то, что о нём знает ваша компания, плюс все действия уровня аккаунта — фото, имя, пароль, сессии, выход и удаление.

Именно здесь на самом деле происходит удаление аккаунта. Экран Privacy — информационный, кнопки удаления на нём нет, см. [Privacy](privacy.md).

## Что показывает экран

| Поле                    | Редактируется? | Примечания                                                |
| ------------------------- | ---------------- | ------------------------------------------------------------ |
| **Photo** (фото)          | Да                | Аватар 96 × 96 с оверлеем камеры для смены                    |
| **Full Name** (полное имя) | Да              | Показывается здесь, редактируется в шторке редактирования    |
| Бейдж статуса             | Нет               | Читайте лейбл так, как он показан                             |
| **Email**                 | Нет               | Только отображение                                            |
| **Phone** (телефон)       | Нет               | Только отображение                                            |
| **Account Status** (статус аккаунта) | Нет   | Только отображение                                            |
| **Member Since** (дата регистрации) | Нет    | Дата создания аккаунта                                        |

Даты рождения на этом экране **нет**. Она собирается при онбординге, но здесь не показывается и не редактируется, так что не отправляйте райдера сюда, чтобы её поменять.

## Редактирование имени

1. Тап по иконке **карандаша**
2. Открывается шторка редактирования с **First Name** и **Last Name** — и больше ничего. Оба поля обязательны
3. Сохранить

Email и телефон здесь не редактируются, и флоу их смены внутри приложения нет. Если райдеру нужен другой email или телефон, вашей команде нужно обработать это из дашборда — см. [Клиент — Создание и редактирование](../../operations/customers/client-create-edit.md).

Приятная деталь: райдера, вошедшего через Apple или Google, могут попросить ввести настоящее имя — имя, которое возвращают эти сервисы, не всегда пригодно.

## Смена фото

Тап по аватару открывает шторку фото с тремя источниками:

- **Take Photo** — камера телефона
- **Choose Gallery** — выбрать из галереи
- **Choose File** — выбрать файл

Ограничения: **JPEG, JPG, PNG или WEBP, максимум 10 МБ**. Шага обрезки нет — фото используется как снято, так что предупреждайте райдеров кадрировать его заранее. Как только загрузка завершится, новое фото заменяет старое везде в приложении.

## Смена пароля

Шторка **Change Password** запрашивает три поля:

| Поле                              | Правило                                      |
| ------------------------------------ | ----------------------------------------------- |
| **Current Password** (текущий пароль) | Обязательно                                    |
| **New Password** (новый пароль)      | Должен соответствовать показанным правилам пароля |
| **Confirm Password** (подтверждение пароля) | Должен совпадать с новым паролем         |

Предупредите райдера заранее: **успешная смена пароля выходит из аккаунта** и возвращает на экран входа с сообщением-подтверждением. Это ожидаемое поведение, а не сбой — райдеру просто нужно войти заново с новым паролем.

Неверный текущий пароль показывает встроенную ошибку прямо у этого поля. Любая другая ошибка появляется как короткое сообщение вверху экрана.

## Управление сессиями

**Manage Sessions** открывает `/settings/sessions` — список всех устройств, вошедших в аккаунт. См. [Сессии](sessions.md) — список устройств и действия по выходу отовсюду.

## Выход из аккаунта

Кнопка **Log Out** завершает сессию на этом устройстве и возвращает райдера к началу приложения. На другие устройства она не влияет — для них используйте [Сессии](sessions.md).

## Удаление аккаунта — рабочий сценарий

1. **Delete Account** появляется только тогда, когда удаление ещё не запланировано
2. Тап по ней открывает диалог подтверждения
3. При подтверждении удаление ставится в расписание
4. Кнопка заменяется блоком ожидания: иконка часов, **Scheduled for {дата}** и кнопка **Cancel**, пока отмена ещё возможна

Чтобы отменить, райдер жмёт **Cancel**, подтверждает в диалоге, и обычная кнопка **Delete Account** возвращается.

У этого флоу нет требования по балансу — райдер с деньгами в кошельке всё равно может запланировать удаление, так что напомните ему потратить или вернуть баланс заранее, если это важно. См. [Кошелёк](../money/wallet.md).

## Пока удаление ожидает выполнения

Редактирование профиля, смена пароля, загрузка фото и управление сессиями **все отключены**, пока запланировано удаление.

Это ответ на любую жалобу райдера, что кнопки на экране Profile серые: у него запланировано удаление. Отмена восстанавливает всё.

## FAQ

- **Почему райдер не может отредактировать здесь email или телефон?** Шторка редактирования содержит только имя и фамилию; оба контактных поля только для отображения, и флоу их смены внутри приложения нет.
- **Почему все кнопки отключены?** Запланировано удаление аккаунта. Отмените его.
- **Райдера разлогинило сразу после смены пароля.** Ожидаемо — успешная смена пароля вынуждает заново войти.
- **Что означают значения статуса?** Читайте лейбл **Account Status** так, как он показан; не сопоставляйте его с фиксированным списком значений.
- **Райдер спрашивает, как запросить удаление аккаунта с экрана Privacy.** На экране Privacy кнопки удаления нет — он информационный. Используйте **Profile → Delete Account** — см. [Privacy](privacy.md).
