# Райдер-приложение — Настройки

Настройки (`/settings`) хранят все пользовательские настройки приложения: уведомления, что рисует карта, переключатели приватности, язык, тему и производительность.

**Кнопки Save здесь нет.** Экран мгновенно показывает закешированные настройки, обновляет их в фоне и пушит каждое изменение автоматически через мгновение после того, как оно сделано. Райдер, который что-то поменял и сразу закрыл экран, почти наверняка уже сохранил изменение — это и есть ответ на «применилось ли моё изменение?».

Несколько из этих переключателей меняют то, что рисует [Карта](../riding/map.md), так что это первый экран, куда стоит заглянуть по жалобам «карта тормозит» и «не вижу уровень заряда».

## Уведомления

Пять независимых переключателей:

- **Ride Notifications** (Уведомления о поездках)
- **Promotion Notifications** (Уведомления об акциях)
- **App Updates** (Обновления приложения)
- **Push Notifications** (Push-уведомления)
- **Email Notifications** (Уведомления на почту) — один переключатель; под ним нет отдельных настроек по типам

В том же разделе:

| Элемент                        | Заметки                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------- |
| **Sound** (Звук)                | Переключатель                                                                     |
| **Sound Volume** (Громкость звука) | Слайдер — появляется, только пока включён **Sound**                            |
| **Vibration** (Вибрация)        | Переключатель                                                                     |
| **Radar Settings** (Настройки радара) | Карточка, которая появляется только в сборках приложения, где включены настройки радара |

## Карта и отображение

Переключатели:

- **Show Battery Level** (Показывать уровень заряда)
- **Show Promotional Vehicles** (Показывать промо-транспорт)
- **Show Pricing** (Показывать цены)
- **Auto Zoom** (Автозум)
- **Map 3D** (3D-карта) — применяется на карте сразу
- **Reduced Animations** (Меньше анимаций)

Плюс **Data Mode** (Режим данных) — селектор с вариантами **balanced**, **low** и **high**. Он управляет качеством тайлов карты и тем, сколько деталей карта рендерит, и это **первое, что стоит попробовать, когда райдер жалуется на медленную или тяжёлую карту** — опустите его до _low_ и заодно включите **Reduced Animations**.

**Offline Maps** (офлайн-карты) сейчас недоступны в приложении.

## Приватность

- Переключатель **Geolocation Sharing** (Геолокация)
- Переключатель **Data Sharing** (Обмен данными)
- **Privacy Policy** (Политика конфиденциальности) — открывает внешний URL, который вы настроили в [Моей компании](../../settings/administration/my-company.md); ссылка появляется, только если URL задан
- **Manage Sessions** (Управление сеансами) — открывает экран вошедших устройств (`/settings/sessions`), тот же самый, что доступен с Profile

Полный экран политики конфиденциальности и рекомендаций по безопасности — отдельный маршрут (`/privacy`). **Удаления аккаунта здесь нет** — рабочий сценарий удаления находится на экране Profile.

## Регион и внешний вид

| Элемент                    | Варианты             | Заметки                                                                                                 |
| ---------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Language** (Язык)         | **en**, **ru**, **ro** | Применяется сразу, без перезагрузки. На этом экране предлагаются только эти три                              |
| **Units** (единицы измерения) | —                     | Селектор единиц измерения сейчас недоступен в приложении                                                     |
| **Theme** (Тема)            | Light, Dark, System   | Применяется сразу                                                                                             |
| **Map Style** (Стиль карты) | Auto, Light, Dark     | **Отключён и принудительно выставлен в Auto, пока Theme стоит на System.** Переключите Theme на Light или Dark, чтобы разблокировать |

На этом экране показаны только три языка приложения выше, хотя в других местах продукта есть и другие локали — см. [Локализация](../../settings/administration/localization.md) для операторской стороны.

## Riding Mode

**Riding Mode (режим катания) сейчас недоступен в приложении.** Райдер, который спрашивает, где находится управление режимом катания, не потерял право доступа — этого раздела просто нет в приложении, и в дашборде нет настройки, которая бы его добавляла.

## FAQ

| Райдер спрашивает…                    | Ответ                                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------------------------- |
| «Где кнопка Save?»                       | Её нет — изменения сохраняются автоматически                                                   |
| «Где Riding Mode?»                       | Сейчас недоступно в приложении                                                                 |
| «Почему Map Style серый и недоступен?»   | **Theme** стоит на **System**. Сначала переключите на Light или Dark                           |
| «Почему в списке нет моего языка?»       | На этом экране предлагаются только **en**, **ru** и **ro**                                     |
| «Где настройка Units?»                   | Сейчас недоступна в приложении                                                                 |
| «Где переключатель Offline Maps?»        | Сейчас недоступен в приложении                                                                 |
| «Как удалить аккаунт?»                   | С экрана Profile, а не из Settings                                                             |
| «Как посмотреть свои вошедшие устройства?» | **Manage Sessions** — здесь, либо та же кнопка на Profile                                    |
| «Карта тормозит»                         | **Data Mode → low**, затем включить **Reduced Animations**. См. [Карта](../riding/map.md#решение-проблем) |

## Полезные приёмы

- **Data Mode — ваш регулятор производительности.** Прежде чем винить телефон райдера или свои тайлы, попросите его попробовать _low_.
- **«Не сохранилось» почти никогда не бывает правдой.** Попросите переоткрыть экран — значение будет на месте.
- **Жалобы на карту часто живут здесь, а не на самой карте.** Пропавшие проценты заряда, пропавшие цены и пропавший промо-транспорт — это всё переключатели на этом экране.
- **Theme блокирует Map Style.** Запомните эту пару — иначе это еженедельный тикет.
