# Райдер-приложение — Поддержка, FAQ и живой чат

Поддержка (`/support`) — это место, куда райдер идёт за помощью. У неё две вкладки — **FAQ** и **Contact** — а живой чат открывается на отдельном экране (`/support/messenger`).

Две вещи стоит знать прежде, чем отвечать на любой вопрос о самой поддержке:

- **Каждый канал связи — это ваша собственная настройка.** Нигде в приложении нет глобального email, телефона или часов работы поддержки Ridewolf — никогда их не называйте.
- **В приложении есть чат, а не форма тикета.** Райдеры не получают номера тикетов. Вид вашей команды на те же переписки — [Чаты](../../support/tickets-proofs-chat/conversations.md); [Тикеты](../../support/tickets-proofs-chat/tickets.md) — это операторское понятие.

## Вкладка FAQ

Аккордеон-секции, построенные из вашего опубликованного контента вопросов-ответов, плюс пункты **Ride Guide** (Гид по поездке), разбитые на группы **Before Start** (До старта) и **Before End** (До завершения).

Вы управляете всем этим без релиза приложения:

- Вопросы и ответы — [FAQ Sets](../../settings/content/faq-sets.md)
- Прохождения Ride Guide — [Quick Guides](../../settings/content/quick-guides.md)

Отдельные пункты FAQ **доступны по прямой ссылке**: ссылка на конкретный пункт открывает Support с этим пунктом уже развёрнутым и прокрученным в видимую область. Это правильный способ отправить райдера прямо к одному ответу вместо «посмотрите в FAQ».

## Вкладка Contact

Каждый канал здесь рендерится, только если вы включили его в [Моя компания → App → каналы поддержки](../../settings/administration/my-company.md).

| Канал                  | Что делает                                                        |
| ------------------------ | -------------------------------------------------------------------- |
| **Live Chat** (Живой чат) | Открывает мессенджер (`/support/messenger`)                          |
| **Email**               | Открывает почтовое приложение райдера с вашим адресом                |
| **Website** (Сайт)      | Открывает настроенный вами URL во встроенном браузере                |
| **Telegram**            | Открывает ваш контакт в Telegram во внешнем приложении                |
| **WhatsApp**            | Открывает ваш контакт в WhatsApp во внешнем приложении                |
| **Phone** (Телефон)     | Начинает звонок на настроенный вами номер                            |

Если **ни один** канал не включён, вкладка показывает иллюстрацию «нет контактов». Райдер, который жалуется «нет способа связаться с поддержкой», почти всегда находится в компании, где все каналы выключены, — проверьте сначала свою собственную конфигурацию.

## Живой чат

Мессенджер устроен как список переписок:

- Райдер видит **свой список переписок**, у каждой — статус, назначенный оператор, последнее сообщение с временем и счётчик непрочитанных.
- **New Chat** (Новый чат) предлагается **только когда у райдера нет открытой переписки.** Райдер с открытым тредом не видит способа начать второй — так и задумано. Он продолжает существующий тред.
- Открытие переписки загружает её историю сообщений по 50 за раз, подгружая более старые по мере прокрутки вверх.

| Статус переписки | Значение                              |
| ------------------- | ---------------------------------------- |
| **New**             | Только открыта, ещё никто не взял в работу |
| **Waiting**         | Ждёт свободного оператора                |
| **Active**          | В работе у оператора                     |
| **Delayed**         | Отложена оператором                      |
| **Closed**          | Закрыта оператором                       |

**Типы сообщений, которые рендерит приложение:** текст, изображение, файл, геолокация, контакт, поездка, ссылка на приложение и системные сообщения.

**Иконки статуса сообщения:** отправляется, отправлено, доставлено, прочитано и ошибка.

### Отправка сообщения

Райдер может прикрепить:

- До **5 изображений на сообщение**
- **Метку геолокации** (широта, долгота и подпись)
- **Файл**

Отправленное сообщение сразу появляется со статусом _sending_, затем обновляется до реального статуса по мере подтверждения сервером. То же самое живое соединение управляет обновлениями новых сообщений и прочтений, уведомлениями о закрытии и переназначении переписки и индикатором «_{имя} печатает…_».

После потери соединения приложение перезагружает список переписок и открытый чат, дедублицируя по сообщению — так что райдер, который выпал из сети, не увидит одно и то же сообщение дважды.

Когда оператор **закрывает** переписку, ввод у райдера отключается, и вместо него появляется уведомление «переписка закрыта».

## Решение проблем

| Райдер говорит…                          | Что это                                                                                                          |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| «Нет вариантов связи»                     | Для вашей компании не включён ни один канал — почините это в [Моей компании](../../settings/administration/my-company.md) |
| «Нет кнопки New Chat»                     | У райдера уже есть открытая переписка; ему стоит продолжить этот тред                                             |
| «Больше не могу печатать»                 | Оператор закрыл переписку. Новую можно начать, как только не останется открытого треда                           |
| «Моё сообщение показывает failed»         | Оно так и не ушло с устройства — отправьте повторно                                                              |
| «Мои сообщения задвоились после переподключения» | На самом деле нет; перезагрузка дедублицирует. Попросите скриншот, если райдер настаивает                  |
| «Как быстро вы отвечаете?»                | Время ответа нигде в приложении не определено. **Не обещайте конкретный срок** — называйте свои собственные опубликованные обязательства по сервису |
| «Куда сообщать о чрезвычайной ситуации?»  | Через любой из включённых вами каналов. В приложении не определена горячая линия для экстренных случаев, и её номер не должен цитироваться из приложения |

## Полезные приёмы

- **Проверяйте свою вкладку Contact.** Открывайте райдер-приложение сами после любого изменения в Моей компании — полностью пустая вкладка Contact незаметна вам и очень раздражает райдеров.
- **Давайте прямые ссылки на пункты FAQ** в ответах чата вместо того, чтобы перепечатывать их. Это учит райдеров, где живёт ответ.
- **Правило — одна открытая переписка за раз.** Когда райдеру нужно поднять что-то не связанное с текущим, сначала закройте старый тред.
- **Держите FAQ Sets и Quick Guides актуальными** — каждый вопрос, на который они отвечают, — это чат, которого у вас не будет.
- **Закрытие переписки лишает райдера возможности отвечать.** Убедитесь, что ответ полный, прежде чем закрывать.
