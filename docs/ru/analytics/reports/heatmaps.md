# Аналитика — Heatmaps

Страница Heatmaps (`/analytics/heatmaps`) — **визуализатор географической плотности**: выберите источник данных, период и режим отображения — карта покажет где концентрируется активность в зоне работы.

Используйте для **поиска спроса** (где райдеры хотят стартовать? где заканчивают?) и **планирования покрытия** (где смотрели, но транспорта не было?).

## Источники данных

Три сигнальных источника, по одному за раз:

| Источник        | Что показывает                                                           |
| --------------- | ------------------------------------------------------------------------ |
| **Scans**       | Где райдеры **открыли приложение и искали транспорт** — намерение спроса |
| **Ride starts** | Где поездки **фактически начались** — конвертированный спрос             |
| **Ride ends**   | Где поездки **завершились** — естественные drop-off локации              |

Сравните _Scans_ vs _Ride starts_ чтобы найти **неудовлетворённый спрос**: места где искали, но транспорта не было.

## Режимы визуализации

Четыре способа отрисовать одни и те же данные:

| Режим        | Что рисует                                                                     |
| ------------ | ------------------------------------------------------------------------------ |
| **Heatmap**  | Классический smooth heat-blur — для **пиков** одним взглядом                   |
| **Hexagons** | Гексагональные bins — для **сравнения зон** с консистентной геометрией         |
| **Clusters** | Кластеры точек, раскрывающиеся на зуме — для **drill-down в конкретные точки** |
| **Grid**     | Регулярная квадратная сетка — для **выравнивания с планируемыми зонами**       |

Одни данные рассказывают разные истории в разных режимах — переключайтесь во время расследования.

## Цветовые схемы

Ряд маленьких swatch-ей даёт выбрать цветовую схему — полезно для color-blind операторов или для совпадения с brand palette. Имя схемы появляется в tooltip на hover.

## Слайдер points

Слайдер в toolbar контролирует сколько точек сэмплировать (1k / 10k / 100k). Больше точек = точнее картина плотности но медленнее рендер. Стартуйте с мало, увеличивайте когда сузили область / период.

## Период

Стандартный date-range bar сверху. Шире период — более агрегированная картина; для "что было сегодня утром" выберите несколько часов.

## Карта

Карта на всю страницу. Стандартные контролы (pan, zoom, layer toggle). Heatmap-overlay сверху map base.

**Легенда** в углу объясняет цветовую шкалу активного режима — от низкой плотности к высокой.

## Типичные сценарии

- **Найти неудовлетворённый спрос** — Source = Scans, Mode = Heatmap → найти hot-зону → переключить на Ride starts → если та же зона холодная = неудовлетворённый спрос → ребаланс или расширение зоны
- **Планирование новой зоны** — Source = Ride ends, Mode = Hexagons → искать естественные drop-off-концентрации вне текущих зон → предложить operations
- **Drill в hot spot** — Mode = Clusters → zoom в hot-зону → индивидуальные точки показывают точные lat/long; сверка с [Vehicle Search](vehicles.md) для ride-level детали
- **Сравнение окон** — загрузить morning Scans → скриншот → переключить на evening Scans → сравнить side by side (дашборд пока не делает dual-period; manual export)
- **Coverage аудит** — Source = Scans за прошлую неделю → найти hot spots далеко от любой зоны → пересмотреть границы зон

## Полезные приёмы

- **Scans ≠ rides** — много сканов не конвертируются (райдер не видит транспорт, видит цену, отказывается). Gap между Scans и Ride starts = самый actionable сигнал
- **Heatmap-режим прячет масштаб** — цвета относительны на видимой карте; zoom меняет картину. Hexagons-режим честнее на фиксированных zoom-уровнях
- **Стартуйте с мало точек, заканчивайте с многих** — исследовать с 1k быстро; до 100k только когда знаете что ищете
- **Grid-режим для планирования** — если зоны прямоугольные, Grid выравнивается с ними; иначе предпочитайте Hexagons
- **Color-blind?** — попробуйте альтернативные схемы; данные те же
- **Карта не обновляется по смене даты автоматически** — зависит от конфигурации, может потребоваться нажать _Apply_ / _Refresh_
- **Легенда важна** — что выглядит "красно и драматично" может быть маленьким absolute-числом; всегда смотрите на легенду до интерпретации
