# Главная дашборда

Главная страница (`/dashboard`) — это ваш дневной обзор. Показывает ключевые метрики флота на выбранный день, их сравнение с 30-дневным средним и почасовое распределение активности. Откройте чтобы оценить пульс операций за один экран.

## Шапка

Сверху:

- **Приветствие** — "Привет, _{ваше имя}_! Добро пожаловать в дашборд _{вашей компании}_!"
- **Подзаголовок** — "Обзор производительности компании"
- **Date picker** — показывает за какой день метрики

## Date picker

По умолчанию страница загружает данные **сегодняшнего** дня. Селектор даты позволяет ходить по истории.

- **Today** — кнопка возврата на сегодня
- **Previous day** (‹) / **Next day** (›) — шаг на один день
- **Иконка календаря** — открывает попап календаря для перехода к конкретной дате

Выбранная дата сохраняется на сессию — перейдёте на другую страницу и обратно — выбор останется.

## Stat-карточки (KPI)

Восемь карточек метрик располагаются в двух рядах. Каждая показывает:

- **Заголовок** — что измеряется (например, _Поездки_)
- **Значение** — цифра за выбранный день
- **Описание** — короткое уточнение ("Completed rides", "Total distance" и т.п.)
- **Сравнение** — изменение vs 30-дневное скользящее среднее, со стрелкой вверх/вниз
- **Tooltip** — наведите на заголовок чтобы увидеть полное определение

### Восемь карточек

| Карточка             | Что показывает                                   |
| -------------------- | ------------------------------------------------ |
| **Rides**            | Количество завершённых поездок за выбранный день |
| **Distance**         | Общий километраж всех поездок                    |
| **Duration**         | Общее время поездок по флоту                     |
| **Revenue**          | Общая выручка от поездок за день                 |
| **Top-ups**          | Сумма пополнений кошелька клиентами в этот день  |
| **Avg. price**       | Средняя цена за поездку                          |
| **Avg. price / km**  | Средняя цена за километр                         |
| **Avg. price / min** | Средняя цена за минуту                           |

Сравнение читается как "**vs 30-day average**":

- ↑ Зелёная — выше среднего за последние 30 дней
- ↓ Красная — ниже среднего
- (без стрелки) — слишком близко к среднему чтобы флажить

## Weather-карточка

Виджет погоды стоит в сетке stat-карточек и показывает условия в зоне работы:

- **Текущая температура** и состояние (Clear, Cloudy, Rain и т.д.)
- **Ветер** и **осадки**
- **3-day forecast** — на 2 следующих дня плюс завтра
- Источник местоположения — _from GPS_ или _by IP_ (что доступно)

Полезно для прогноза спроса: дождь и ветер часто коррелируют с объёмом поездок.

## Почасовые графики

Под stat-карточками четыре area-графика показывают как активность распределилась по 24 часам выбранного дня, сгруппированы в две секции:

### Активность

- **Rides per hour** — количество поездок начатых в каждый час
- **Distance per hour** — общий километраж за час
- **Duration per hour** — общие минуты поездок за час

### Выручка

- **Revenue per hour** — валюта заработанная за час

Каждый график показывает кривую дня; наведите на точку чтобы увидеть точное значение для часа.

## Загрузка и ошибки

- **Загрузка** — stat-карточки показывают skeleton-состояние пока аналитика-эндпоинт отвечает
- **Ошибка** — маленький баннер сверху со словами "Failed to load analytics"; остальная страница остаётся доступной

## Права доступа

Главная страница защищена правом **View Dashboard Analytics** (`q4r5t6`). Без него вас перенаправит на другую landing-страницу при входе.

Если доступ есть, но страница пуста:

- Проверьте выбранную дату — пустые дни валидны (поездок не было)
- Проверьте сеть — посмотрите баннер "Failed to load analytics"
- Иначе обратитесь к администратору

## Полезные приёмы

- **Быстрое сравнение дней** — стрелки `‹` и `›` шагают по дням, наблюдайте как KPI меняются
- **Tooltips на заголовках карточек** — у каждой карточки точное определение; полагайтесь на него, а не угадывайте что исключено в "Avg. price / km"
- **Смотрите на бейдж сравнения первым** — цветная стрелка одним взглядом говорит — день выше или ниже нормы, до того как смотрите абсолютное число
- **Почасовые графики раскрывают паттерны** — утренние vs вечерние пики, кривые выходных, эффекты погоды; они говорят больше чем totals
