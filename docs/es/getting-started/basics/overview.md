# Bienvenido al Panel de control de Ridewolf

El Panel de control de Ridewolf es el centro de control para gestionar una flota de movilidad compartida. Ya sea que operes scooters, bicicletas u otro tipo de vehículo, aquí es donde monitoreas la actividad en tiempo real, gestionas clientes, manejas soporte y analizas el rendimiento.

## Para quién es este panel de control

El panel está diseñado para **operadores** — el personal que trabaja día a día con la flota:

- **Gerentes de flota** — vehículos, zonas, tarifas
- **Agentes de soporte** — tickets, conversaciones, pruebas de estacionamiento
- **Analistas** — métricas, informes, rendimiento
- **Administradores** — operadores, roles, configuración del sistema

Lo que cada operador ve depende de su **rol y permisos**. Tu vista puede ser más limitada que las capturas de pantalla en esta guía si algunos módulos están restringidos para tu rol.

## Conceptos básicos

El panel está organizado alrededor de algunos conceptos que encontrarás en todas partes:

| Concepto      | Qué significa                                                                 |
| -------------- | ----------------------------------------------------------------------------- |
| **Vehículo**   | Una unidad física en la flota (scooter, bicicleta, etc.) — tiene GPS, batería, estado |
| **Viaje**      | Un trayecto realizado por un cliente en un vehículo — tiene hora de inicio/fin, ruta, costo |
| **Cliente**    | Un cliente registrado que puede alquilar vehículos                            |
| **Pago**      | Transacciones monetarias vinculadas a viajes, recargas o reembolsos          |
| **Zona**       | Un área geográfica donde operan los vehículos (o donde están restringidos)   |
| **Tarifa**     | Reglas de precios que determinan cuánto cuestan los viajes                   |
| **Etiqueta**   | Una etiqueta adjunta a clientes o vehículos para agrupar y filtrar          |
| **Ticket**     | Una solicitud de soporte al cliente                                          |
| **Prueba de estacionamiento** | Una foto que un cliente envía para confirmar el estacionamiento correcto |

## Navegación básica

### Barra lateral (izquierda)

La barra lateral es la navegación principal. Los grupos se expanden para mostrar subpáginas — por ejemplo, **Soporte** se expande en Tickets, Pruebas de estacionamiento y Conversaciones.

### Barra superior

La barra superior aparece en cada página y contiene:

- **Miga de pan** — la ruta de regreso a través de la jerarquía (p. ej. Inicio → Vehículos → RW-001)
- **Chat AI** (icono de chispa) — un asistente que puede responder preguntas sobre el panel
- **Ayuda** (icono de signo de interrogación) — abre esta base de conocimientos, contextual a la página actual
- **Notificaciones** (icono de campana) — eventos y alertas recientes del sistema
- **Perfil** (avatar) — configuración, cambio de contraseña, cerrar sesión, controles de tema

### Tablas

La mayoría de las páginas de listas (vehículos, viajes, clientes, etc.) siguen el mismo diseño:

1. **Barra de búsqueda** arriba para búsqueda de texto completo
2. **Filtros en pastillas** debajo para acotar por estado, tipo, etc.
3. **Columnas ordenables** — haz clic en el encabezado de una columna para ordenar
4. **Paginación** en la parte inferior
5. **Acciones en fila** — un menú de tres puntos en cada fila para acciones rápidas

## Qué hacer primero

Si es tu primera vez en el panel, recomendamos:

1. **Actualiza tu perfil** — avatar → Perfil, completa nombre, foto, datos de contacto
2. **Explora la flota** — abre **Vehículos** para ver qué está activo actualmente
3. **Revisa los viajes de hoy** — abre **Viajes** filtrado para hoy para observar la actividad en tiempo real
4. **Abre el panel de inicio** — la página principal `/dashboard` resume los KPIs diarios
5. **Lee esta base de conocimientos** — abre la sección relevante antes de hacer tu primera acción en cada módulo

## Cómo obtener ayuda

Hay tres formas de obtener ayuda desde dentro del panel:

- **Icono de ayuda (?)** en la barra superior — abre un panel lateral con documentación relevante para la página en la que estás
- **Ayuda** en la barra lateral (icono de libro) — la base de conocimientos completa y buscable
- **Formularios de comentarios / sugerencias** en la página de inicio de Ayuda — escribe directamente al equipo
