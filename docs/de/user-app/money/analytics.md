# Rider App — Fahrerstatistiken

**Fahrerbezogene Statistiken sind in der App derzeit nicht verfügbar.** Es gibt keinen Diagrammbildschirm, keine Gesamtsummen und keine Ausgabenübersicht, die ein Fahrer öffnen könnte.

Leiten Sie Fahrer stattdessen zu [History](history.md) weiter — dies ist der einzige Ort mit ihren eigenen Daten.

## Was ein Fahrer sieht

- **Es gibt keinen Einstiegspunkt.** Die Seitenleiste listet Wallet, History, Support, Privacy, Settings und Profile — und nichts weiter. Ein Fahrer, der sagt, er könne keinen Analysebildschirm finden, hat recht; sagen Sie ihm nicht, er solle im Menü nachsehen, und schicken Sie ihm keinen Link dazu.
- Wenn der Bildschirm `/analytics` direkt geöffnet wird, zeigt er nur eine Überschrift und leeren Raum. **Mit dem Konto des Fahrers, seinem Gerät oder der App-Installation ist nichts falsch** — eine Neuinstallation ändert nichts.

## Wo die Zahlen des Fahrers tatsächlich zu finden sind

[History](history.md) enthält echte Daten pro Fahrer:

- Der Tab **Fahrten** listet jede vergangene Fahrt mit Distanz, Dauer und Kosten auf
- Der Tab **Zahlungen** listet Aufladungen, Rückerstattungen, Abbuchungen und Boni mit Beträgen und Status auf
- Ein Tippen auf eine Fahrt öffnet deren Details mit der vollständigen [Kostenaufstellung](../riding/rides.md#kostenaufstellung), der Aktivitätszeitleiste und der Route auf einer Karte

Es gibt **nirgendwo in der Rider App ein Banner mit aggregierten Gesamtsummen** — weder auf einem Statistikbildschirm noch oben in History. Lebenszeit-Gesamtsummen müssen aus der Fahrtenliste addiert oder aus Ihren eigenen Berichten gezogen werden.

## Beantwortung der Zahlenfragen vom Dashboard

Wenn ein Fahrer wirklich Gesamtsummen benötigt, erstellen Sie diese auf der Betreiberseite:

| Fahrer möchte                   | Wo Sie es bekommen                                                              |
| ------------------------------- | -------------------------------------------------------------------------------- |
| Gesamtausgaben über einen Zeitraum | [Analysen — Zahlungen](../../analytics/reports/payments.md)                    |
| Eigene Fahrtenliste, exportiert  | [Fahrten — Liste](../../operations/trips/rides.md), gefiltert auf diesen Kunden  |
| Eigene Zahlungsaufzeichnungen    | [Zahlungen — Zahlungsverlauf](../../operations/payments/payments.md)             |
| Eine schnelle Zusammenfassung pro Kunde | [Kundendetails](../../operations/customers/client-detail.md) — Lebenszeit-Fahrtenanzahl, Saldo, Bewertung |

## FAQ

| Fahrer fragt…                   | Antwort                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------- |
| „Wo sind meine Statistiken?“     | Derzeit nicht in der App verfügbar. Verwenden Sie [History](history.md)          |
| „Ich finde Analytics nicht im Menü“ | Es gibt keinen Menüeintrag dafür                                            |
| „Die Analytics-Seite ist leer“  | Erwartet — der Bildschirm ist derzeit nicht verfügbar. Es ist nichts kaputt     |
| „Kann ich meine Fahrtdaten exportieren?“ | Nicht aus der App. Exportieren Sie sie im Auftrag des Fahrers vom Dashboard    |
| „Wie viel habe ich insgesamt ausgegeben?“ | In der Rider App gibt es keine Gesamtsumme. Lesen Sie sie aus History ab oder ziehen Sie sie aus dem Dashboard |

## Tipps

- **Senden Sie Fahrern keine Analytics-Links.** Es gibt keinen lohnenden Bildschirm, und eine leere Seite wirkt wie eine defekte App.
- **Beantworten Sie Fragen zu Gesamtsummen selbst.** Die Zahl vom Dashboard zu holen dauert eine Minute und beendet das Gespräch.
- **History ist die ehrliche Antwort** und enthält wirklich vollständige Daten pro Fahrt und pro Zahlung — formulieren Sie es so, anstatt sich für einen fehlenden Bildschirm zu entschuldigen.
