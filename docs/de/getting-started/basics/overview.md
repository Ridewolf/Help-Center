# Willkommen im Ridewolf Dashboard

Das Ridewolf Dashboard ist das Kontrollzentrum zur Verwaltung einer Shared-Mobility-Flotte. Egal, ob Sie Scooter, Fahrräder oder andere Fahrzeugtypen betreiben, hier überwachen Sie die Echtzeitaktivität, verwalten Kunden, bearbeiten Supportanfragen und analysieren die Leistung.

## Für wen dieses Dashboard gedacht ist

Das Dashboard ist für **Betreiber** konzipiert – Mitarbeiter, die täglich mit der Flotte arbeiten:

- **Flottenmanager** — Fahrzeuge, Zonen, Tarife
- **Support-Mitarbeiter** — Tickets, Unterhaltungen, Parknachweise
- **Analysten** — Kennzahlen, Berichte, Leistung
- **Administratoren** — Betreiber, Rollen, Systemeinstellungen

Was jeder Betreiber sieht, hängt von seiner **Rolle und den Berechtigungen** ab. Ihre Ansicht kann eingeschränkter sein als die Screenshots in dieser Anleitung, wenn einige Module für Ihre Rolle gesperrt sind.

## Grundlegende Konzepte

Das Dashboard ist um einige Konzepte herum organisiert, denen Sie überall begegnen werden:

| Konzept       | Bedeutung                                                                    |
| ------------- | ---------------------------------------------------------------------------- |
| **Fahrzeug**  | Eine physische Einheit in der Flotte (Scooter, Fahrrad usw.) — mit GPS, Akku, Status |
| **Fahrt**     | Eine vom Kunden unternommene Fahrt mit einem Fahrzeug — mit Start-/Endzeit, Route, Kosten |
| **Kunde**     | Ein registrierter Kunde, der Fahrzeuge mieten kann                           |
| **Zahlung**   | Geldtransaktionen, die mit Fahrten, Aufladungen oder Rückerstattungen verbunden sind |
| **Zone**      | Ein geografisches Gebiet, in dem Fahrzeuge betrieben werden (oder ausgeschlossen sind) |
| **Tarif**     | Preisregeln, die festlegen, wie viel Fahrten kosten                          |
| **Tag**       | Ein Label, das Kunden oder Fahrzeugen zur Gruppierung und Filterung zugeordnet wird |
| **Ticket**    | Eine Supportanfrage eines Kunden                                             |
| **Parknachweis** | Ein Foto, das ein Kunde zur Bestätigung des korrekten Parkens einreicht    |

## Grundnavigation

### Seitenleiste (links)

Die Seitenleiste ist die Hauptnavigation. Gruppen lassen sich aufklappen, um Unterseiten anzuzeigen – zum Beispiel öffnet sich **Support** zu Tickets, Parknachweisen und Unterhaltungen.

### obere Leiste

Die obere Leiste erscheint auf jeder Seite und enthält:

- **Breadcrumb** — der Pfad zurück durch die Hierarchie (z. B. Startseite → Fahrzeuge → RW-001)
- **KI-Chat** (Funkel-Symbol) — ein Assistent, der Fragen zum Dashboard beantworten kann
- **Hilfe** (Fragezeichen-Symbol) — öffnet diese Wissensdatenbank, kontextbezogen zur aktuellen Seite
- **Benachrichtigungen** (Glocken-Symbol) — aktuelle Systemereignisse und Alarme
- **Profil** (Avatar) — Einstellungen, Passwort ändern, Abmelden, Design-Steuerung

### Tabellen

Die meisten Listen-Seiten (Fahrzeuge, Fahrten, Kunden usw.) folgen dem gleichen Layout:

1. **Suchleiste** oben für Volltextsuche
2. **Filter-Pills** darunter zum Eingrenzen nach Status, Typ usw.
3. **Sortierbare Spalten** — klicken Sie auf eine Spaltenüberschrift zum Sortieren
4. **Seitennavigation** unten
5. **Zeilenaktionen** — ein Drei-Punkte-Menü in jeder Zeile für Schnellaktionen

## Was Sie zuerst tun sollten

Wenn Sie das Dashboard zum ersten Mal nutzen, empfehlen wir:

1. **Profil aktualisieren** — Avatar → Profil, Name, Foto, Kontaktdaten ausfüllen
2. **Flotte durchsuchen** — öffnen Sie **Fahrzeuge**, um zu sehen, was aktuell aktiv ist
3. **Heutige Fahrten prüfen** — öffnen Sie **Fahrten** mit Filter auf heute, um die Echtzeitaktivität zu beobachten
4. **Startseite des Dashboards öffnen** — die Hauptseite `/dashboard` fasst die täglichen KPIs zusammen
5. **Diese Wissensdatenbank lesen** — öffnen Sie den relevanten Abschnitt, bevor Sie Ihre erste Aktion in jedem Modul durchführen

## Hilfe erhalten

Es gibt drei Möglichkeiten, im Dashboard Hilfe zu bekommen:

- **Hilfesymbol (?)** in der oberen Leiste — öffnet eine Seitenleiste mit Dokumentation, die zur aktuellen Seite passt
- **Hilfe** in der Seitenleiste (Buch-Symbol) — die vollständige, durchsuchbare Wissensdatenbank
- **Feedback-/Vorschlagsformulare** auf der Hilfeseite — schreiben Sie direkt an das Team

## Nächste Schritte

Wenn Sie mit den Grundlagen vertraut sind:

- Sehen Sie **Dashboard-Funktionen**, um Tastenkürzel, Filtertricks und Designs kennenzulernen
- Sehen Sie **Betrieb** für praktische Anleitungen zu Fahrzeugen, Fahrten und Kunden
- Sehen Sie **Einstellungen**, wenn Sie Betreiber, Zonen oder Tarife konfigurieren müssen
