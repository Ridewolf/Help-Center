# Bun venit în Ridewolf Dashboard

Dashboard-ul Ridewolf este centrul de control pentru gestionarea flotei tale de shared-mobility. Fie că operezi trotinete, biciclete sau orice alt tip de vehicul, aici monitorizezi activitatea în timp real, gestionezi clienții, te ocupi de suport și analizezi performanța.

## Cui se adresează acest dashboard

Dashboard-ul este conceput pentru **operatori** — membri ai personalului care lucrează zilnic cu flota:

- **Manageri de flotă** — vehicule, zone, tarife
- **Agenți de suport** — tickete, conversații, park proofs
- **Analiști** — metrici, rapoarte, performanță
- **Administratori** — operatori, roluri, setări de sistem

Ce vede fiecare operator depinde de **rolul și permisiunile** lui. Vizualizarea ta poate fi mai restrânsă decât în capturile de ecran din acest ghid, dacă unele module sunt restricționate pentru rolul tău.

## Concepte cheie

Dashboard-ul este organizat în jurul câtorva concepte pe care le vei întâlni peste tot:

| Concept        | Ce înseamnă                                                                     |
| -------------- | ------------------------------------------------------------------------------- |
| **Vehicul**    | O unitate fizică din flotă (trotinetă, bicicletă etc.) — GPS, baterie, status   |
| **Cursă**      | O călătorie făcută de un client pe un vehicul — start/sfârșit, traseu, cost     |
| **Client**     | Un utilizator înregistrat care poate închiria vehicule                          |
| **Plată**      | Tranzacții monetare legate de curse, reîncărcări sau rambursări                 |
| **Zonă**       | O zonă geografică în care operează vehiculele (sau în care sunt restricționate) |
| **Tarif**      | Reguli de prețuri care determină costul curselor                                |
| **Etichetă**   | O etichetă atașată clienților sau vehiculelor pentru grupare și filtrare        |
| **Ticket**     | O cerere de suport de la un client                                              |
| **Park Proof** | O fotografie trimisă de client pentru a confirma parcarea corectă               |

## Navigare de bază

### Sidebar (stânga)

Sidebar-ul este navigarea principală. Grupurile se extind pentru a dezvălui sub-pagini — de exemplu, **Suport** se extinde în Tickete, Park Proofs și Conversații.

### Bara de sus

Bara de sus apare pe fiecare pagină și conține:

- **Breadcrumb** — traseul înapoi prin ierarhie (de ex. Acasă → Vehicule → RW-001)
- **AI Chat** (iconiță scânteie) — un asistent care răspunde la întrebări despre dashboard
- **Ajutor** (semn de întrebare) — deschide această bază de cunoștințe, contextual la pagina curentă
- **Notificări** (clopoțel) — evenimente recente și alerte
- **Profil** (avatar) — setări, schimbare parolă, deconectare, controale de temă

### Tabele

Majoritatea paginilor cu liste (vehicule, curse, clienți etc.) urmează același aspect:

1. **Bară de căutare** sus pentru căutare full-text
2. **Filtre** dedesubt pentru restrângerea rezultatelor după status, tip etc.
3. **Coloane sortabile** — click pe header pentru a sorta
4. **Paginare** jos
5. **Acțiuni pe rând** — meniu cu trei puncte pe fiecare rând pentru acțiuni rapide

## Ce să faci mai întâi

Dacă este prima dată când folosești dashboard-ul, recomandăm:

1. **Actualizează-ți profilul** — avatar → Profil, completează numele, fotografia și datele de contact
2. **Răsfoiește flota** — deschide **Vehicule** pentru a vedea ce este activ în prezent
3. **Verifică cursele de azi** — deschide **Curse** filtrat pe azi pentru a vedea activitatea în timp real
4. **Deschide dashboard-ul principal** — pagina `/dashboard` rezumă KPI-urile zilnice
5. **Citește această bază de cunoștințe** — deschide secțiunea relevantă înainte de prima acțiune în fiecare modul

## Cum obții ajutor

Există trei modalități de a obține ajutor din interiorul dashboard-ului:

- **Iconița de ajutor (?)** în bara de sus — deschide un panou lateral cu documentație relevantă pentru pagina curentă
- **Ajutor** în sidebar (iconița carte) — baza de cunoștințe completă, cu căutare
- **Formulare de feedback / sugestii** pe pagina principală Ajutor — scrie echipei direct

## Pași următori

Odată ce te-ai familiarizat cu elementele de bază:

- Vezi **Funcționalități Dashboard** pentru comenzi rapide, trucuri de filtrare și teme
- Vezi **Operațiuni** pentru ghiduri practice despre vehicule, curse și clienți
- Vezi **Setări** dacă trebuie să configurezi operatori, zone sau tarife
