# Bienvenue sur le Tableau de bord Ridewolf

Le Tableau de bord Ridewolf est le centre de contrôle pour gérer une flotte de mobilité partagée. Que vous exploitiez des trottinettes, des vélos ou tout autre type de véhicule, c'est ici que vous surveillez l'activité en temps réel, gérez les clients, traitez l'assistance et analysez les performances.

## À qui s'adresse ce tableau de bord

Le tableau de bord est conçu pour les **opérateurs** — le personnel qui travaille au quotidien avec la flotte :

- **Gestionnaires de flotte** — véhicules, zones, tarifs
- **Agents d'assistance** — tickets, conversations, preuves de stationnement
- **Analystes** — métriques, rapports, performances
- **Administrateurs** — opérateurs, rôles, paramètres système

Ce que chaque opérateur voit dépend de son **rôle et de ses permissions**. Votre vue peut être plus restreinte que les captures d'écran de ce guide si certains modules sont limités pour votre rôle.

## Concepts clés

Le tableau de bord est organisé autour de quelques concepts que vous rencontrerez partout :

| Concept        | Ce que cela signifie                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| **Véhicule**   | Une unité physique dans la flotte (trottinette, vélo, etc.) — possède GPS, batterie, statut |
| **Trajet**     | Un déplacement effectué par un client sur un véhicule — a une heure de début/fin, un itinéraire, un coût |
| **Client**     | Un client enregistré pouvant louer des véhicules                              |
| **Paiement**   | Transactions monétaires liées aux trajets, recharges ou remboursements       |
| **Zone**       | Une zone géographique où les véhicules opèrent (ou sont restreints)           |
| **Tarif**      | Règles de tarification qui déterminent le coût des trajets                    |
| **Étiquette**  | Un label attaché aux clients ou véhicules pour le regroupement et le filtrage |
| **Ticket**     | Une demande d'assistance client                                              |
| **Preuve de stationnement** | Une photo soumise par un client pour confirmer un stationnement correct |

## Navigation de base

### Barre latérale (gauche)

La barre latérale est la navigation principale. Les groupes s'ouvrent pour révéler des sous-pages — par exemple, **Assistance** s'étend en Tickets, Preuves de stationnement et Conversations.

### Barre supérieure

La barre supérieure apparaît sur chaque page et contient :

- **Fil d'Ariane** — le chemin de retour dans la hiérarchie (ex. Accueil → Véhicules → RW-001)
- **Chat IA** (icône étincelle) — un assistant pouvant répondre aux questions sur le tableau de bord
- **Aide** (icône point d'interrogation) — ouvre cette base de connaissances, contextuelle à la page actuelle
- **Notifications** (icône cloche) — événements système récents et alertes
- **Profil** (avatar) — paramètres, changement de mot de passe, déconnexion, contrôle du thème

### Tableaux

La plupart des pages de liste (véhicules, trajets, clients, etc.) suivent la même disposition :

1. **Barre de recherche** en haut pour la recherche en texte intégral
2. **Filtres** en dessous pour affiner par statut, type, etc.
3. **Colonnes triables** — cliquez sur un en-tête de colonne pour trier
4. **Pagination** en bas
5. **Actions sur la ligne** — un menu à trois points sur chaque ligne pour des actions rapides

## Que faire en premier

Si c'est votre première fois sur le tableau de bord, nous recommandons :

1. **Mettre à jour votre profil** — avatar → Profil, remplissez nom, photo, coordonnées
2. **Parcourir la flotte** — ouvrez **Véhicules** pour voir ce qui est actif
3. **Vérifier les trajets du jour** — ouvrez **Trajets** filtré sur aujourd'hui pour suivre l'activité en temps réel
4. **Ouvrir le tableau de bord d'accueil** — la page principale `/dashboard` résume les indicateurs clés quotidiens
5. **Lire cette base de connaissances** — ouvrez la section pertinente avant de faire votre première action dans chaque module

## Obtenir de l'aide

Il y a trois façons d'obtenir de l'aide depuis le tableau de bord :

- **Icône Aide (?)** dans la barre supérieure — ouvre un tiroir latéral avec la documentation pertinente à la page en cours
- **Aide** dans la barre latérale (icône livre) — la base de connaissances complète et consultable
- **Formulaires de retour / suggestion** sur la page d'accueil de l'Aide — écrivez directement à l'équipe

## Étapes suivantes

Une fois que vous maîtrisez les bases :

- Consultez **Fonctionnalités du Tableau de bord** pour apprendre les raccourcis clavier, astuces de filtres et thèmes
- Consultez **Opérations** pour des guides pratiques sur les véhicules, trajets et clients
- Consultez **Paramètres** si vous devez configurer les opérateurs, zones ou tarifs
