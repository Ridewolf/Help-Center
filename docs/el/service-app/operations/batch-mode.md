# Λειτουργία Παρτίδας — Ουρά Πολλών Οχημάτων

Η λειτουργία παρτίδας (`/batch`) συγκεντρώνει πολλά οχήματα σε μία ουρά ώστε να τα βλέπετε δίπλα-δίπλα και να τα επεξεργάζεστε χωρίς να χρειάζεται να τα αναζητάτε ξανά. Πρόσβαση από την αρχική οθόνη ή από τον σύνδεσμο σάρωσης στην κενή κατάσταση του [χάρτη στόλου](../fleet/fleet-map.md).

**Διαβάστε πρώτα αυτό:** η λειτουργία παρτίδας είναι λίστα εργασιών, όχι εργαλείο μαζικών εντολών. Τα κουμπιά ομαδικών ενεργειών στο κάτω μέρος της οθόνης **δεν είναι διαθέσιμα στην εφαρμογή**. Δραστηριοποιείστε σε κάθε όχημα από τη δική του [σελίδα οχήματος](../fleet/vehicle-controls.md).

## Προσθήκη οχημάτων

1. Ανοίξτε τη λειτουργία παρτίδας.
2. Σαρώστε τον κωδικό QR ενός οχήματος — ο σαρωτής είναι ο ίδιος με αυτόν του χάρτη στόλου, οπότε ισχύουν οι ίδιες κανόνες αναζήτησης (ετικέτα, VIN ή IMEI).
3. Κάθε επιτυχημένη σάρωση προσθέτει το όχημα στην ουρά σε κατάσταση **ανενεργό**.
4. Επαναλάβετε για κάθε όχημα που θέλετε στη λίστα.

Οι μεγάλες ουρές παραμένουν γρήγορες, οπότε δεν υπάρχει πρακτικός λόγος να κρατάτε τη λίστα σύντομη πέρα από το δικό σας πρόγραμμα βάρδιας.

## Ανάγνωση της ουράς

Κάθε γραμμή δείχνει:

| Στοιχείο             | Πώς να το διαβάσετε                                                                    |
| -------------------- | -------------------------------------------------------------------------------------- |
| **Ετικέτα**          | Ο κωδικός του οχήματος                                                                 |
| **Μπάρα μπαταρίας**  | Κόκκινο στο 10% ή λιγότερο, πορτοκαλί στο 20% ή λιγότερο, κεχριμπαρί στο 40% ή λιγότερο, πράσινο πάνω από 40% |
| **Μπαταρία εντοπιστή**| Η φόρτιση του ίδιου του εντοπιστή                                                      |
| **Εικονίδιο σύνδεσης**| Αν ο εντοπιστής είναι σε σύνδεση ή εκτός σύνδεσης                                     |
| **Κατάσταση**        | Η τρέχουσα κατάσταση του οχήματος                                                    |
| **Κατάσταση γραμμής** | ανενεργό, σε εξέλιξη, εντάξει ή αποτυχία                                             |

Μια γραμμή με αποτυχία δείχνει το μήνυμα σφάλματος στη θέση των τηλεμετρικών, ώστε να βλέπετε τι πήγε λάθος χωρίς να φύγετε από την ουρά.

**Πατώντας οποιαδήποτε γραμμή ανοίγει τη σελίδα του οχήματος** — έτσι ενεργείτε πραγματικά σε ένα όχημα: το τοποθετείτε στην ουρά εδώ και το επεξεργάζεστε ένα-ένα.

## Αφαίρεση οχημάτων

- **Το εικονίδιο κάδου σε μια γραμμή** αφαιρεί το όχημα από την ουρά. Δεν στέλνει τίποτα στο όχημα — η αφαίρεση επηρεάζει μόνο τη δική σας λίστα.
- **Το εικονίδιο κάδου στην κεφαλίδα** καθαρίζει ολόκληρη την ουρά μετά από επιβεβαίωση. Είναι απενεργοποιημένο όταν η παρτίδα είναι σε εξέλιξη.

## Ομαδικές ενέργειες

Πέντε κουμπιά βρίσκονται στο κάτω μέρος της οθόνης: γρανάζι ρυθμίσεων, ξεκλείδωμα, καμπάνα, αστραπή και στρώματα. **Αυτές οι ομαδικές ενέργειες δεν είναι διαθέσιμες στην εφαρμογή.** Το πάτημα δεν στέλνει τίποτα σε κανένα όχημα.

Για να ξεκλειδώσετε, να ηχήσετε, να αλλάξετε μπαταρία ή να στείλετε εντολή εντοπιστή, ανοίξτε το όχημα από την ουρά και χρησιμοποιήστε τους ελέγχους στη [σελίδα οχήματος](../fleet/vehicle-controls.md):

- Κλείδωμα και ξεκλείδωμα — **Λειτουργία οδήγησης**
- Ήχος εντοπιστή — **Ήχος**
- [Αλλαγή μπαταρίας](battery-swap.md) — η ακολουθία χρονισμένης αλλαγής
- Εντολές προμηθευτή — το φύλλο **Εντολές**

## Συνηθισμένα προβλήματα

| Σύμπτωμα                                      | Τι σημαίνει                                                                       |
| ---------------------------------------------- | --------------------------------------------------------------------------------- |
| Το πάτημα ομαδικής ενέργειας δεν κάνει τίποτα  | Σωστό — οι ομαδικές ενέργειες δεν είναι διαθέσιμες. Επεξεργαστείτε κάθε όχημα από τη σελίδα του |
| Το κουμπί καθαρισμού όλων είναι γκρι           | Η παρτίδα είναι σε εξέλιξη                                                        |
| Μια γραμμή δεν δείχνει μπαταρία ή σύνδεση      | Αυτές οι τιμές είναι άγνωστες για το όχημα — όχι μηδέν                            |
| Ένα σαρωμένο όχημα δεν εμφανίστηκε               | Ο κωδικός δεν αναγνωρίστηκε. Οι κανόνες είναι οι ίδιοι με τον χάρτη στόλου: ετικέτα, VIN ή IMEI |

## Συμβουλές

- **Δημιουργήστε την ουρά στην αρχή μιας διαδρομής.** Η σάρωση δέκα οχημάτων σε μια αυλή μια φορά είναι καλύτερη από το να τα ψάχνετε ένα-ένα αργότερα.
- **Χρησιμοποιήστε τα χρώματα της μπαταρίας για να οργανώσετε τη δουλειά σας** — πρώτα τα κόκκινα, αυτά που θα αναφέρει ο αναβάτης επόμενα.
- **Η ουρά είναι μόνο δική σας**, οπότε η αφαίρεση μιας γραμμής δεν αλλάζει τίποτα για συναδέλφους ή για το όχημα.
- **Για λειτουργίες σε όλο τον στόλο, χρησιμοποιήστε τον Πίνακα ελέγχου.** Μαζικές αλλαγές κατάστασης, μαζικές ετικέτες και μαζικές εντολές βρίσκονται στη [λίστα Οχημάτων του Πίνακα ελέγχου](../../operations/fleet/vehicles.md#μαζικές-ενέργειες).
