# Αναπαραγωγέας Replay

Ο Αναπαραγωγέας Replay (`/apps/replay-player`) είναι ένα διερευνητικό εργαλείο που αναπαριστά το GPS ίχνος ενός οχήματος κατά τη διάρκεια μιας ημέρας — ή ολόκληρη τη διαδρομή μιας μεμονωμένης διαδρομής — σε έναν χάρτη. Χρησιμοποιήστε το για να διερευνήσετε περιστατικά, να επαληθεύσετε ισχυρισμούς αναβατών, να ελέγξετε ασυνήθιστες διαδρομές ή απλώς να παρακολουθήσετε την κίνηση του στόλου.

Δεν είναι χάρτης σε πραγματικό χρόνο (για αυτό δείτε τον Πίνακα ελέγχου Realtime) — αναπαράγει **ιστορικές** συντεταγμένες από το backend με πλήρη έλεγχο χρονογραμμής.

Απαιτούμενη άδεια: **Replay Player** (`k7m8n9`).

## Διάταξη

Η σελίδα χωρίζεται σε αριστερή πλαϊνή μπάρα (επιλογείς + πάνελ πληροφοριών) και μια μεγάλη περιοχή χάρτη με γραμμή ελέγχου στο κάτω μέρος:

| Περιοχή      | Πλάτος | Περιεχόμενα                                                            |
| ------------ | ------ | --------------------------------------------------------------------- |
| **Πλαϊνή μπάρα** | 320 px | Κάρτες επιλογής (Κατά όχημα / Κατά διαδρομή), πάνελ πληροφοριών ανά όχημα |
| **Χάρτης**   | flex   | Χάρτης MapLibre με την πολυγραμμή διαδρομής, δείκτες έναρξης / λήξης, ζωντανός δείκτης |
| **Έλεγχοι**  | κάτω   | Αναπαραγωγή / παύση, αναδυόμενο μενού ταχύτητας, ρυθμιστικό χρονογραμμής, ένδειξη χρόνου |

## Έλεγχοι (πλαϊνή μπάρα)

Η πλαϊνή μπάρα καθορίζει **τι** αναπαράγεται. Διαθέτει δύο καρτέλες που αλλάζουν το μοντέλο επιλογής.

### Καρτέλα Κατά Όχημα

Αναπαραγωγή της πλήρους διαδρομής μιας ή περισσότερων οχημάτων για όλη την ημέρα (ή οποιαδήποτε ημερομηνία επιλέξετε):

- **Οχήματα** — πολλαπλή επιλογή έως **5** οχήματα. Πληκτρολογήστε για αναζήτηση, φιλτράρετε τη λίστα με ετικέτες από το αναδυόμενο μενού παρακάτω.
- **Ημερομηνία** — αναδυόμενο ημερολόγιο; προεπιλογή η σημερινή ημέρα. Η αναπαραγωγή καλύπτει ολόκληρη την τοπική ημέρα της επιλεγμένης ημερομηνίας.
- **Ετικέτες** — περιορίζει το αναδυόμενο μενού οχημάτων σε οχήματα που φέρουν οποιαδήποτε από τις επιλεγμένες ετικέτες. Χρήσιμο όταν έχετε μεγάλο στόλο.
- **Φόρτωση** — ανακτά τις συντεταγμένες της ημέρας για όλα τα επιλεγμένα οχήματα παράλληλα και τις αποδίδει.

Όταν φορτώνετε πολλαπλά οχήματα, το καθένα έχει τη δική του πολυγραμμή (χρωματισμένη ανά ταχύτητα) και το δικό του κινούμενο δείκτη στον χάρτη, καθώς και μια αφιερωμένη κάρτα πληροφοριών στην πλαϊνή μπάρα.

### Καρτέλα Κατά Διαδρομή

Αναπαραγωγή των συντεταγμένων μιας μεμονωμένης διαδρομής αντί για ολόκληρη ημέρα:

- **Όχημα** (προαιρετικό) — μονή επιλογή· περιορίζει τη λίστα διαδρομών παρακάτω
- **Ημερομηνία** (προαιρετικό) — αναδυόμενο ημερολόγιο· φιλτράρει τις διαδρομές σε μία ημέρα. Καθαρίστε για να δείτε όλες τις ημερομηνίες.
- **Ετικέτες** (προαιρετικό) — φιλτράρει τη λίστα διαδρομών με βάση τις ετικέτες οχημάτων
- **Λίστα διαδρομών** — κύλιση, σελίδωση λίστας διαδρομών που ταιριάζουν με τα παραπάνω φίλτρα. Κάθε κάρτα δείχνει ώρα έναρξης, κατάσταση, διάρκεια και απόσταση.

Το κλικ σε κάρτα διαδρομής φορτώνει αυτόματα τις συντεταγμένες της αμέσως — δεν χρειάζεται ξεχωριστό κουμπί Φόρτωσης.

## Χρονογραμμή (κάτω γραμμή)

Η γραμμή ελέγχου εκτείνεται κατά μήκος του κάτω μέρους του χάρτη:

| Έλεγχος           | Λειτουργία                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------ |
| **Αναπαραγωγή / Παύση** | Ξεκινά ή παύει την αναπαραγωγή                                                            |
| **Αναδυόμενο μενού ταχύτητας** | Επιλογή πολλαπλασιαστή ταχύτητας αναπαραγωγής (βλέπε παρακάτω)                              |
| **Ρυθμιστικό χρονογραμμής** | Μετακίνηση σε οποιοδήποτε σημείο της αναπαραγωγής· ο χάρτης ενημερώνεται αμέσως           |
| **Περασμένος / Συνολικός χρόνος** | `μμ:δδ` (ή `ω:μμ:δδ` αν είναι πάνω από μία ώρα) — χρόνος αναπαραγωγής που πέρασε και συνολική διάρκεια |

Όταν φορτώνονται πολλαπλά οχήματα, το ρυθμιστικό καλύπτει το **παγκόσμιο** διάστημα από την αρχή έως το τέλος της ένωσης όλων των διαδρομών. Οι διαδρομές που δεν έχουν ξεκινήσει ακόμα την τρέχουσα στιγμή απλώς δεν έχουν δείκτη στον χάρτη.

## Χάρτης

Ο χάρτης χρησιμοποιεί το τρέχον στυλ χάρτη του θέματος σας (βλέπε [Themes](../../features/ux/themes.md)). Για κάθε φορτωμένη διαδρομή:

- Σχεδιάζεται μια **πολυγραμμή** χρωματισμένη ανά ταχύτητα — πράσινο για αργή, πορτοκαλί για μέτρια, κόκκινο για γρήγορη
- Τοποθετείται ένας **πράσινος δείκτης Έναρξης** στο πρώτο σημείο
- Τοποθετείται ένας **κόκκινος δείκτης Λήξης** στο τελευταίο σημείο
- Ένας **δείκτης οχήματος** κινείται κατά μήκος της γραμμής καθώς παίζει η χρονογραμμή

Οι έλεγχοι του χάρτη βρίσκονται στην πάνω δεξιά γωνία (κατακόρυφη στοίβα):

| Κουμπί            | Λειτουργία                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------- |
| **Μεγέθυνση / Σμίκρυνση** | Τυπική μεγέθυνση χάρτη                                                                     |
| **Επαναφορά προσανατολισμού** | Περιστρέφει τον χάρτη ώστε να δείχνει βόρεια αν τον είχατε κλίση ή περιστροφή               |
| **Προσαρμογή ορίων** | Μεγέθυνση / μετακίνηση για να χωρέσει ολόκληρη τη διαδρομή(ές) στην προβολή — χρήσιμο μετά από μεγάλη αναπαραγωγή που μετακινεί την κάμερα |
| **Πλήρης οθόνη**   | Μετατρέπει τον χάρτη σε πλήρη οθόνη· η γραμμή ελέγχου παραμένει στο κάτω μέρος               |

## Ταχύτητα αναπαραγωγής

Το αναδυόμενο μενού ταχύτητας προσφέρει οκτώ προκαθορισμένες τιμές: **1x, 2x, 4x, 8x, 16x, 32x, 64x, 128x**.

- **1x** αναπαράγει την αναπαραγωγή σε πραγματικό χρόνο — μια διαδρομή 20 λεπτών διαρκεί 20 λεπτά
- **128x** συμπιέζει μια 8ωρη ημέρα σε περίπου 4 λεπτά
- Η ταχύτητα μπορεί να αλλάξει κατά τη διάρκεια της αναπαραγωγής· η κίνηση συνεχίζεται ομαλά από το σημείο που βρισκόταν

Χρησιμοποιήστε υψηλότερες ταχύτητες (32x / 64x / 128x) για αναπαραγωγές ολόκληρης ημέρας οχημάτων, χαμηλότερες ταχύτητες (1x / 2x / 4x) για διερεύνηση διαδρομών όπου θέλετε να δείτε ακριβώς πού βρισκόταν ο αναβάτης κάθε δευτερόλεπτο.

## Πάνελ πληροφοριών ανά όχημα

Κάθε φορτωμένο όχημα έχει μια μικρή κάρτα στην πλαϊνή μπάρα που ενημερώνεται ζωντανά καθώς παίζει η αναπαραγωγή:

| Πεδίο           | Τι εμφανίζει                                                              |
| --------------- | ------------------------------------------------------------------------ |
| **Ταχύτητα**    | Τρέχουσα παρεμβαλλόμενη ταχύτητα σε χλμ/ώρα (χρωματικά κωδικοποιημένη πράσινο / κίτρινο / κόκκινο) |
| **Συντεταγμένες** | Τρέχουσα γεωγραφικό πλάτος / μήκος με ακρίβεια 6 δεκαδικών              |
| **Απόσταση**    | Συνολική απόσταση που έχει διανυθεί μέχρι στιγμής σε χλμ (haversine, υπολογίζεται στην πλευρά του πελάτη) |
| **Σημείο**     | Τρέχων δείκτης σημείου / συνολικά σημεία (πόσο προχωρημένο είναι το σύνολο δεδομένων) |

Όταν η αναπαραγωγή δεν έχει ξεκινήσει ή δεν έχουν φορτωθεί δεδομένα, η κάρτα εμφανίζει παύλες em-dash.

## Κενές / καταστάσεις φόρτωσης

- **Καμία επιλογή** — η περιοχή του χάρτη εμφανίζει ένα εικονίδιο αναπαραγωγής και το μήνυμα «Επιλέξτε όχημα και ημερομηνία ή διαδρομή για να ξεκινήσετε την αναπαραγωγή»
- **Φόρτωση** — ένας κεντραρισμένος δείκτης φόρτωσης με το μήνυμα «Φόρτωση συντεταγμένων...» καλύπτει τον χάρτη
- **Χωρίς δεδομένα** — αν η επιλεγμένη ημερομηνία / διαδρομή δεν έχει σημεία συντεταγμένων, εμφανίζεται προειδοποιητικό μήνυμα toast «Δεν βρέθηκαν δεδομένα συντεταγμένων για αυτήν την επιλογή» και ο χάρτης παραμένει κενός
- **Αποτυχία φόρτωσης τμήματος χάρτη** — ο χάρτης φορτώνεται τμηματικά (~1 MB); αν η φόρτωση αποτύχει (παρωχημένη έκδοση, εκτός σύνδεσης), θα δείτε μήνυμα σφάλματος που σας προτρέπει να ανανεώσετε

## Τυπικά σενάρια εργασίας

- **Διερεύνηση παραπόνου** — μεταβείτε σε By Ride, αναζητήστε τη διαδρομή του αναβάτη, κάντε κλικ → παρακολουθήστε τη διαδρομή σε 4x ταχύτητα για να δείτε πού πήγε πραγματικά σε σχέση με όσα ισχυρίστηκε
- **Έλεγχος "χαμένου" οχήματος** — By Vehicle, επιλέξτε τη μονάδα, ορίστε την ημερομηνία σήμερα → αναπαραγωγή σε 128x για να δείτε όλη την ημέρα σε δευτερόλεπτα· η τελευταία θέση του δείκτη είναι όπου βρίσκεται τώρα
- **Σύγκριση δύο οχημάτων** — By Vehicle, επιλέξτε δύο μονάδες που έκαναν παρόμοιες διαδρομές, ίδια ημερομηνία → και οι δύο πολυγραμμές και οι δείκτες εμφανίζονται μαζί για οπτική σύγκριση
- **Εντοπισμός ώρας συμβάντος** — φορτώστε μια διαδρομή → σύρετε τον ρυθμιστή στην ώρα από ένα εισιτήριο / καταγραφή → διαβάστε τις συντεταγμένες από τον πίνακα πληροφοριών
- **Εντοπισμός υπερβολικής ταχύτητας** — φορτώστε την ημέρα ενός οχήματος → αναζητήστε **κόκκινα** τμήματα πολυγραμμής → σύρετε τον ρυθμιστή σε εκείνη την περιοχή για επιβεβαίωση

## Συμβουλές

- **Μέγιστο 5 οχήματα** ταυτόχρονα — το UI περιορίζει την πολλαπλή επιλογή για να διατηρεί την απόδοση του χάρτη σε λογικά επίπεδα. Για περισσότερα, κάντε ξεχωριστές συνεδρίες.
- **Χρησιμοποιήστε το Fit Bounds μετά από μεγάλη αναπαραγωγή** — η αναπαραγωγή ακολουθεί τον δείκτη, που μετακινεί την κάμερα· ένα κλικ στο Fit Bounds επαναπλαισιώνει ολόκληρη τη διαδρομή.
- **Τα χρώματα ταχύτητας δεν συνδέονται με τιμολόγια** — είναι καθαρά οπτικά σήματα βασισμένα στην παρατηρούμενη ταχύτητα GPS (>15 χλμ/ώρα κίτρινο, >30 χλμ/ώρα κόκκινο). Συγκρίνετε με το _speed mode_ του οχήματος στη σελίδα λεπτομερειών για πλαίσιο.
- **Ο ρυθμιστής κινείται και προς τις δύο κατευθύνσεις** — σύρετε προς τα πίσω για επαναφορά. Συνδυάστε με χαμηλή ταχύτητα για να περάσετε δύσκολα τμήματα βήμα-βήμα.
- **Καμία κατάσταση URL** — οι επιλογές δεν αποθηκεύονται στο URL, οπότε δεν μπορείτε να μοιραστείτε σύνδεσμο με συγκεκριμένη κατάσταση. Αποθηκεύστε στιγμιότυπα οθόνης αν θέλετε να κρατήσετε στιγμές.
- **Συνδυάστε με τη σελίδα [Ride Detail](../../operations/trips/ride-detail.md)** — η σελίδα λεπτομερειών διαδρομής έχει στατικό χάρτη διαδρομής με χρονικές εκδηλώσεις· ο παίκτης αναπαραγωγής προσθέτει τη διάσταση του χρόνου πάνω σε αυτόν.
