# Αναλυτικά στοιχεία — Οχήματα

Η σελίδα αναλυτικών στοιχείων Οχημάτων (`/analytics/vehicles`) είναι ο **πίνακας ελέγχου υγείας στόλου**: πόσα οχήματα έχετε, πώς αποδίδουν, κατάσταση μπαταρίας, προβλήματα και βλάβες ανά τύπο και ζώνη.

Διαφέρει από τη [Λίστα Οχημάτων](../../operations/fleet/vehicles.md) — που είναι η λειτουργική προβολή ανά μονάδα· εδώ είναι **συγκεντρωτικά μετρικά στόλου** για μια επιλεγμένη περίοδο.

## Χρονικό διάστημα

Μια **γραμμή εύρους ημερομηνιών** βρίσκεται στην κορυφή. Τα διαγράμματα τάσεων χρησιμοποιούν ολόκληρο το εύρος· οι μετρήσεις επισκόπησης / κατάστασης αντανακλούν την **τρέχουσα κατάσταση** (τέλος εύρους).

## Ενότητες

Επτά ενότητες, από πάνω προς τα κάτω:

### 1. Επισκόπηση

Σύνθεση στόλου σε υψηλό επίπεδο.

| KPI               | Τι δείχνει                                                      |
| ----------------- | ------------------------------------------------------------------ |
| **Σύνολο**         | Όλα τα καταγεγραμμένα οχήματα                                    |
| **Ενεργά**        | Διαθέσιμα για ενοικίαση από αναβάτες αυτή τη στιγμή              |
| **Αδρανή**          | Ακίνητα, μη σε χρήση (μπορεί να είναι Διαθέσιμα ή χαμηλής χρήσης) |
| **Εκτός υπηρεσίας**   | Σε Συντήρηση / Αποθήκευση / Μη έτοιμα — δεν αποφέρουν έσοδα       |
| **Χαμένα / Κλεμμένα** | Κατάσταση = Κλεμμένο, ή εκτός δικτύου για μεγαλύτερο διάστημα     |

Χρησιμοποιήστε αυτή την ενότητα ως την κύρια επισκόπηση του στόλου σας.

### 2. Απόδοση

Πόσο καλά ο στόλος σας **κερδίζει** για εσάς.

| KPI                   | Τι δείχνει                                              |
| --------------------- | ---------------------------------------------------------- |
| **Οχήματα με έσοδα**  | Οχήματα που ολοκλήρωσαν τουλάχιστον μία διαδρομή στην περίοδο |
| **Αδρανή οχήματα**  | Ενεργά οχήματα με μηδενικές διαδρομές (σπατάλη)          |
| **Διαδρομές ανά όχημα** | Μέσος όρος διαδρομών ανά όχημα στο εύρος                   |
| **Χρήση**       | Ώρες ενοικίασης / ώρες διαθεσιμότητας (βιομηχανικό πρότυπο: 5-15%) |

Τα αδρανή επί ενεργών είναι το χειρότερο είδος — κοστίζουν λειτουργικά έξοδα χωρίς να παράγουν τίποτα.

### 3. Μπαταρία

Κατάσταση μπαταρίας σε όλο τον στόλο.

| KPI / Διάγραμμα      | Τι δείχνει                                                                   |
| ---------------- | ------------------------------------------------------------------------------- |
| **Μέσο επίπεδο**    | Μέσο ποσοστό μπαταρίας σε όλα τα οχήματα αυτή τη στιγμή                                    |
| **Κρίσιμα**     | Αριθμός κάτω από το κρίσιμο όριο (10-20%)                                     |
| **Μέση τάση**    | Μέσος όρος μπαταρίας στο εύρος — πτώση = οι αλλαγές δεν προλαβαίνουν                 |
| **Κατανομή** | Ιστόγραμμα οχημάτων ανά κατηγορία μπαταρίας (0-20 / 20-40 / 40-60 / 60-80 / 80-100) |
| **Αλλαγές**        | Αριθμός λειτουργιών αλλαγής μπαταρίας στο εύρος                                   |

Αν το Μέσο επίπεδο πέφτει ενώ τα Κρίσιμα αυξάνονται, η ομάδα πεδίου υστερεί — προγραμματίστε περισσότερες αλλαγές.

### 4. Προβλήματα

Ειδοποιήσεις και λειτουργικά ζητήματα που έχουν αναφερθεί για τον στόλο.

| KPI             | Τι δείχνει                                                  |
| --------------- | -------------------------------------------------------------- |
| **Ειδοποιήσεις**      | Συνολικές ειδοποιήσεις στην περίοδο                               |
| **Τύποι ειδοποιήσεων** | Κατανομή ανά τύπο (μπαταρία / συνδεσιμότητα / μηχανικά / κ.ά.) |
| **Κρίσιμες**    | Ειδοποιήσεις κρίσιμης σοβαρότητας                                       |
| **Συντήρηση** | Οχήματα που βρίσκονται σε κατάσταση Συντήρησης                       |
| **Εκτός σύνδεσης**     | Οχήματα των οποίων το IoT δεν έχει αναφέρει για μεγαλύτερο διάστημα   |

Συνδυάστε αυτή την ενότητα με τα [Αναλυτικά στοιχεία πρόσφατων εκδηλώσεων](events.md) για προβολή ανά εκδήλωση.

### 5. Τάσεις

Διάγραμμα χρονικής σειράς που δείχνει πώς μεταβλήθηκε ο αριθμός των **Ενεργών** στο εύρος. Μια πτώση συνήθως σημαίνει μαζική αλλαγή κατάστασης (μεταφορά σε συντήρηση, καιρικά, ανάκληση).

### 6. Ανά Τύπο

Κατανομή ανά **τύπο οχήματος** (σκούτερ / ποδήλατο / ηλεκτρικό ποδήλατο / κ.ά.). Για κάθε τύπο: αριθμός, ποσοστό εσόδων, χρήση, ποσοστό ειδοποιήσεων.

Αν ένας τύπος κυριαρχεί στο ποσοστό ειδοποιήσεων, το **μοντέλο** έχει πρόβλημα — όχι η ομάδα λειτουργιών.

### 7. Ανά Ζώνη

Κατανομή ανά **ζώνη**. Για κάθε ζώνη: αριθμός οχημάτων, χρήση, ποσοστό προβλημάτων.

Ζώνες με χαμηλή χρήση και υψηλό απόθεμα = **ευκαιρία επαναζυγοστάθμισης** (βλ. επίσης [Αναλυτικά στοιχεία επαναζυγοστάθμισης](../../operations/rebalance/runs.md)).

## Τυπικά ροή εργασιών

- **Εβδομαδιαία ανασκόπηση στόλου** — Επισκόπηση → Απόδοση (τάση χρήσης) → Μπαταρία (υπάρχει αύξηση κρίσιμων;) → Προβλήματα (αυξήσεις ειδοποιήσεων) → Τάσεις (υπάρχει ανεξήγητη πτώση στα Ενεργά;)
- **Καθαρισμός αδρανών** — Απόδοση → Αριθμός αδρανών → αν αυξάνεται, εντοπίστε τα οχήματα μέσω της [Λίστας Οχημάτων](../../operations/fleet/vehicles.md) και ελέγξτε κατάσταση / τοποθεσία
- **Έκτακτη ανάγκη μπαταρίας** — Ενότητα Μπαταρίας → Αύξηση κρίσιμων + πτώση μέσου → πιέστε την ομάδα πεδίου
- **Ανίχνευση κακού μοντέλου** — Ενότητα Ανά Τύπο → ποιος τύπος έχει το χειρότερο ποσοστό ειδοποιήσεων → σκεφτείτε απόσυρση / διαπραγμάτευση με κατασκευαστή
- **Επαναζυγοστάθμιση** — Ενότητα Ανά Ζώνη → ζώνες με χαμηλή χρήση + υψηλό απόθεμα → προγραμματίστε ανακατανομή
- **Προγραμματισμός πριν τη βάρδια** — Τάσεις + Πρότυπα από [Εκδηλώσεις](events.md) → ποιες μέρες / ώρες χρειάζονται περισσότερους υπαλλήλους πεδίου;

## Συμβουλές

- **Ενεργό + Ανενεργό + Εκτός υπηρεσίας + Χαμένο/Κλεμμένο = Σύνολο** — όταν τα μαθηματικά δεν βγαίνουν, οι καταστάσεις βρίσκονται σε μετάβαση· ανανεώστε ή επιλέξτε μια σταθερή ημερομηνία
- **Ενεργό ≠ κερδοφόρο** — ένα όχημα είναι «Ενεργό» αν θα μπορούσε να ενοικιαστεί· «Κερδοφόρο» σημαίνει ότι πράγματι ενοικιάστηκε. Συγκρίνετε αυτά τα δύο
- **Η χρήση πάνω από 25% είναι ανθυγιεινή** — οι αναβάτες δεν βρίσκουν οχήματα όταν τα θέλουν· σκεφτείτε να αυξήσετε το απόθεμα σε αυτή τη ζώνη
- **Η χρήση κάτω από 5% είναι βάρος** — το κόστος διατήρησης αυτού του οχήματος σε υπηρεσία υπερβαίνει τα κέρδη του· ανακατανείμετε ή αποσύρετε
- **Κρίσιμη μπαταρία + Μέση τάση** — μαζί αποτελούν το σύστημα πρώιμης προειδοποίησης· το ένα μόνο είναι θόρυβος
- **Χαμένο / Κλεμμένο είναι επίμονο** — απαιτεί χειροκίνητη αλλαγή κατάστασης για να διαγραφεί· ανακτήστε ένα «Κλεμμένο» πριν το γιορτάσετε
- **Κατά τύπο και κατά ζώνη μαζί** — μερικές φορές ένας τύπος αποτυγχάνει μόνο σε μία ζώνη (ασυμφωνία εδάφους)· η διασταύρωση το αποκαλύπτει
