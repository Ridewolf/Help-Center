# Αναλυτικά στοιχεία — Θερμικοί χάρτες

Η σελίδα Θερμικοί χάρτες (`/analytics/heatmaps`) είναι ένας **οπτικοποιητής γεωγραφικής πυκνότητας**: επιλέξτε μια πηγή δεδομένων, ένα εύρος ημερομηνιών και έναν τρόπο οπτικοποίησης — ο χάρτης δείχνει πού συγκεντρώνεται η δραστηριότητα στην περιοχή λειτουργίας σας.

Χρησιμοποιήστε το για **ανίχνευση ζήτησης** (πού θέλουν να ξεκινήσουν οι αναβάτες; πού τελειώνουν;) και **σχεδιασμό κάλυψης** (πού ψάχνουν οι αναβάτες, αλλά δεν έχουμε οχήματα;).

## Πηγές δεδομένων

Τρεις πηγές σήματος, μία κάθε φορά:

| Πηγή           | Τι δείχνει                                                               |
| -------------- | ----------------------------------------------------------------------- |
| **Σαρώσεις**   | Πού οι αναβάτες **άνοιξαν την εφαρμογή και σάρωσαν για οχήματα** — πρόθεση ζήτησης |
| **Έναρξη διαδρομών** | Πού οι διαδρομές **ξεκίνησαν πραγματικά** — μετατρεπόμενη ζήτηση          |
| **Λήξη διαδρομών**   | Πού οι διαδρομές **τελείωσαν** — φυσικές τοποθεσίες αποβίβασης            |

Συγκρίνετε τις _Σαρώσεις_ με τις _Έναρξη διαδρομών_ για να βρείτε **ανικανοποίητη ζήτηση**: μέρη όπου οι αναβάτες κοίταξαν αλλά δεν βρήκαν όχημα.

## Τρόποι οπτικοποίησης

Τέσσερις τρόποι απόδοσης των ίδιων δεδομένων:

| Τρόπος       | Τι σχεδιάζει                                                                    |
| ------------ | ------------------------------------------------------------------------------ |
| **Θερμικός χάρτης** | Κλασικός ομαλός θερμο-θολός — καλύτερος για **άμεση θέαση κορυφών**           |
| **Εξάγωνα**  | Εξαγωνικά κελιά — καλύτερα για **σύγκριση ζωνών** με συνεπή γεωμετρία          |
| **Συστάδες** | Συστάδες σημείων που επεκτείνονται με ζουμ — καλύτερες για **εμβάθυνση σε μεμονωμένα σημεία** |
| **Πλέγμα**  | Κανονικό τετράγωνο πλέγμα — καλύτερο για **ευθυγράμμιση με ζώνες σχεδιασμού**  |

Τα ίδια δεδομένα πηγής μπορούν να πουν διαφορετικές ιστορίες σε διαφορετικούς τρόπους — αλλάξτε καθώς διερευνάτε.

## Χρωματικά σχήματα

Μια σειρά μικρών δειγμάτων σας επιτρέπει να επιλέξετε το χρωματικό σχήμα — χρήσιμο για χειριστές με δυσχρωματοψία ή για να ταιριάξετε με παλέτα μάρκας. Το όνομα του σχήματος εμφανίζεται ως υπόδειξη όταν περνάτε το ποντίκι.

## Ρυθμιστικό σημείων

Ένα ρυθμιστικό στη γραμμή εργαλείων σας επιτρέπει να ελέγχετε πόσα σημεία δεδομένων θα δειγματοληπτήσετε (π.χ. 1k / 10k / 100k). Περισσότερα σημεία = πιο ακριβής εικόνα πυκνότητας αλλά πιο αργή απόδοση. Ξεκινήστε χαμηλά ενώ εξερευνάτε, αυξήστε όταν έχετε περιορίσει την περιοχή / το εύρος.

## Εύρος ημερομηνιών

Μια τυπική γραμμή εύρους ημερομηνιών στην κορυφή. Όσο πιο ευρύ το εύρος, τόσο πιο συγκεντρωμένη η εικόνα· για το «τι συνέβη σήμερα το πρωί» επιλέξτε λίγες ώρες.

## Χάρτης

Ο χάρτης γεμίζει τη σελίδα. Τυπικοί έλεγχοι χάρτη (μετακίνηση, ζουμ, εναλλαγή στρώματος). Η επικάλυψη θερμικού χάρτη κάθεται πάνω στη βάση του χάρτη.

Ένα **υπόμνημα** σε μια γωνία εξηγεί την κλίμακα χρωμάτων της ενεργής λειτουργίας — από χαμηλή σε υψηλή πυκνότητα.

## Τυπικά σενάρια εργασίας

- **Βρείτε ανικανοποίητη ζήτηση** — Πηγή = Σαρώσεις, Τρόπος = Θερμικός χάρτης → εντοπίστε μια «καυτή» περιοχή → αλλάξτε Πηγή σε Έναρξη διαδρομών → αν η ίδια περιοχή είναι «κρύα» = ανικανοποίητη ζήτηση → σκεφτείτε επανακατανομή ή επέκταση σε αυτήν την περιοχή
- **Σχεδιάστε νέα ζώνη** — Πηγή = Λήξη διαδρομών, Τρόπος = Εξάγωνα → αναζητήστε συγκεντρώσεις φυσικών αποβιβάσεων εκτός των τρεχουσών ζωνών → προτείνετε στις λειτουργίες
- **Εμβαθύνετε σε «καυτό» σημείο** — Τρόπος = Συστάδες → ζουμάρετε στην «καυτή» περιοχή → τα μεμονωμένα σημεία δείχνουν ακριβές γεωγραφικό πλάτος/μήκος· διασταυρώστε με [Vehicle Search](vehicles.md) για λεπτομέρειες διαδρομής
- **Συγκρίνετε χρονικά παράθυρα** — φορτώστε πρωινές Σαρώσεις → στιγμιότυπο οθόνης → αλλάξτε σε απογευματινές Σαρώσεις → συγκρίνετε τα στιγμιότυπα δίπλα-δίπλα (ο Πίνακας ελέγχου δεν υποστηρίζει ακόμα προβολή διπλής περιόδου· απαιτείται χειροκίνητη εξαγωγή)
- **Έλεγχος κάλυψης** — Πηγή = Σαρώσεις της τελευταίας εβδομάδας → αναζητήστε «καυτά» σημεία μακριά από οποιαδήποτε προγραμματισμένη ζώνη → σκεφτείτε να ξανασχεδιάσετε τα όρια ζώνης

## Συμβουλές

- **Σαρώσεις ≠ διαδρομές** — πολλές σαρώσεις δεν μετατρέπονται (ο αναβάτης δεν βλέπει όχημα, βλέπει τιμή, εγκαταλείπει). Το κενό μεταξύ Σαρώσεων και Έναρξης διαδρομών είναι το πιο χρήσιμο σήμα
- **Η λειτουργία θερμικού χάρτη κρύβει την κλίμακα** — τα χρώματα είναι σχετικά εντός του ορατού χάρτη· το ζουμ αλλάζει την εικόνα. Η λειτουργία Εξάγωνα είναι πιο ειλικρινής σε σταθερά επίπεδα ζουμ
- **Ξεκινήστε με λίγα σημεία, τελειώστε με πολλά** — η εξερεύνηση με 1k σημεία είναι γρήγορη· ανεβάστε σε 100k μόνο όταν ξέρετε τι ψάχνετε
- **Λειτουργία Πλέγματος για σχεδιασμό** — αν οι ζώνες σας είναι σχεδόν ορθογώνιες, το Πλέγμα ευθυγραμμίζεται με αυτές και διευκολύνει τα μαθηματικά· αλλιώς προτιμήστε Εξάγωνα
- **Δυσχρωματοψία;** — δοκιμάστε τα εναλλακτικά σχήματα· τα υποκείμενα δεδομένα είναι τα ίδια
- **Ο χάρτης δεν ανανεώνεται αυτόματα με αλλαγή ημερομηνίας** — ανάλογα με τη ρύθμιση ίσως χρειαστεί να ξαναπατήσετε _Εφαρμογή_ / _Ανανέωση_ μετά την αλλαγή εύρους ημερομηνιών
- **Το υπόμνημα μετράει** — αυτό που φαίνεται «κόκκινο και δραματικό» μπορεί να είναι μικρός απόλυτος αριθμός· ρίξτε πάντα μια ματιά στο υπόμνημα πριν ερμηνεύσετε
