# Αναλυτικά στοιχεία — Πληρωμές

Η σελίδα αναλυτικών στοιχείων Πληρωμών (`/analytics/payments`) είναι ο **οικονομικός σας πίνακας ελέγχου**: βασικοί δείκτες απόδοσης και διαγράμματα σχετικά με τα χρήματα που εισρέουν (φορτίσεις), τα χρήματα που εκρέουν (επιστροφές), τα χρήματα που χρεώνονται (χρεώσεις) και την υγεία του συστήματος πληρωμών σας.

Διαφορετική από το [Ιστορικό Πληρωμών](../../operations/payments/payments.md), που είναι ένα καθολικό ανά συναλλαγή — αυτή η σελίδα είναι **συγκεντρωτική** σε εύρος ημερομηνιών ώστε να μπορείτε να εντοπίζετε τάσεις, διαρροές και ανωμαλίες.

Απαραίτητη άδεια: **Προβολή Αναλυτικών Πληρωμών** (`w7x8y9`).

## Χρονικό πλαίσιο

Μια **γραμμή εύρους ημερομηνιών** βρίσκεται στην κορυφή της σελίδας. Κάθε μέτρηση και διάγραμμα σέβεται αυτό το εύρος:

- Επιλέξτε μια προκαθορισμένη επιλογή (Σήμερα, Τελευταίες 7 / 30 / 90 ημέρες, Αυτός / Ο προηγούμενος μήνας) ή ένα προσαρμοσμένο εύρος
- Η ετικέτα σύγκρισης κάτω από τις κάρτες μετρήσεων γράφει «σε σύγκριση με την προηγούμενη περίοδο» — όταν επιλέγετε _Τελευταίες 7 ημέρες_, η σύγκριση είναι οι 7 ημέρες πριν από αυτές
- Το εύρος παραμένει σταθερό για τη συνεδρία: πλοηγηθείτε αλλού και επιστρέψτε, το εύρος σας διατηρείται

## Ενότητες

Η σελίδα οργανώνεται σε **έξι ενότητες**, καθεμία εστιασμένη σε διαφορετική πτυχή των πληρωμών:

### 1. Ροή

Η συνολική εικόνα — χρήματα που εισέρχονται έναντι χρημάτων που εξέρχονται.

| KPI            | Τι μετράει                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Φορτίσεις**  | Χρήματα που πιστώθηκαν σε πορτοφόλια εντός αυτού του εύρους (χειροκίνητα + πάροχος)                                       |
| **Επιστροφές** | Χρήματα που επιστράφηκαν σε πελάτες· φέρει ετικέτα _Ποσοστό επιστροφών_ (επιστροφές / χρεώσεις)                          |
| **Χρεώσεις**   | Χρήματα που χρεώθηκαν σε πελάτες (διαδρομές, πρόστιμα). Περιλαμβάνει **φίλτρο ετικετών** για να περιορίσετε σε συγκεκριμένη ετικέτα πελάτη (π.χ. _VIP_) |
| **Καθαρή ροή** | Φορτίσεις − Επιστροφές· θετικό = το υπόλοιπο του πορτοφολιού σας αυξάνεται                                              |

### 2. Ποιότητα

Πόσο υγιής είναι η ενσωμάτωση του παρόχου πληρωμών σας.

| KPI                 | Τι μετράει                                                                                                               |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Ποσοστό επιτυχίας** | Ολοκληρωμένες συναλλαγές / όλες οι προσπάθειες — ο βασικός σας αριθμός αξιοπιστίας                                      |
| **Απέτυχε**          | Αριθμός αποτυχημένων συναλλαγών εντός του εύρους                                                                         |
| **Σε εκκρεμότητα**   | Αριθμός συναλλαγών που εκκρεμούν (σταυροαναφορά με [Εκκρεμείς Webhooks](../../operations/payments/pending-webhooks.md)) |
| **Επιστραφέντα**    | Αριθμός χρεώσεων που τελικά επιστράφηκαν                                                                                 |
| **Αιτίες αποτυχίας** | Διάγραμμα που αναλύει τις αποτυχίες κατά αιτία (απόρριψη / 3DS / δίκτυο / κ.ά.)                                         |

Μια αιχμή στα _Απέτυχε_ + μια συγκεκριμένη αιτία που κυριαρχεί στο διάγραμμα = διακοπή λειτουργίας ή πρόβλημα ενσωμάτωσης που πρέπει να αναφερθεί.

### 3. Υπόλοιπο

Η κατάσταση των κεφαλαίων που κατέχει ο χειριστής (πορτοφόλια αναβατών) στο τέλος του εύρους.

| KPI               | Τι δείχνει                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------------- |
| **Υπόλοιπο**      | Άθροισμα όλων των θετικών υπολοίπων — χρήματα που κρατάτε ουσιαστικά για τους αναβάτες       |
| **Χρέος**         | Άθροισμα όλων των αρνητικών υπολοίπων — χρήματα που σας οφείλουν οι αναβάτες                  |
| **Μέσο υπόλοιπο** | Μέσο υπόλοιπο ανά ενεργό πελάτη                                                              |
| **Χρήστες**       | Αριθμός πελατών με μη μηδενικό υπόλοιπο                                                     |
| **Διάγραμμα κάδων** | Ιστόγραμμα πελατών ανά μέγεθος υπολοίπου (π.χ. 0–10 / 10–50 / 50–100 / 100+)                |

Χρησιμοποιήστε το _Χρέος_ ως ένδειξη εκκρεμοτήτων είσπραξης — μεγάλο χρέος υποδηλώνει πολλά πρόστιμα ή αποτυχημένες χρεώσεις που χρειάζονται παρακολούθηση.

### 4. Πρότυπα

Συμπεριφορικά πρότυπα φορτίσεων των αναβατών — χρήσιμα για μάρκετινγκ / προϊόν.

- **Ιστόγραμμα μεγέθους φόρτισης** — πώς οι αναβάτες κατανέμουν τις φορτίσεις τους ανά ποσά. Η επικρατούσα τιμή του ιστογράμματος (η πιο συχνή τιμή) είναι η προεπιλογή για τις ειδοποιήσεις σας
- **Φορτίσεις ανά ώρα** — πότε μέσα στην ημέρα φορτίζουν οι αναβάτες. Οι κορυφές συνήθως συμπίπτουν με τις κορυφές διαδρομών (μετακινήσεις, βραδιές Σαββατοκύριακου)

### 5. Μέθοδοι

Ανάλυση σε πίνακα ανά **μέθοδο πληρωμής / πάροχο**.

- Στήλες: Μέθοδος (κάρτα / υπόλοιπο / πορτοφόλι / κ.ά.), Συνολικό ποσό, Αριθμός, Μέση συναλλαγή, Ποσοστό επιτυχίας
- Χρήσιμο για τον εντοπισμό υποαποδίδοντων παρόχων (μια μέθοδος με χαμηλό ποσοστό επιτυχίας είναι το αδύναμο σημείο σας)

### 6. Χρήστες

Προβολή κοόρτης πελατών — ποιοι σας πληρώνουν.

| KPI               | Τι μετράει                                                                                     |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| **Μοναδικοί πληρωτές** | Διακεκριμένοι πελάτες που πλήρωσαν εντός του εύρους                                            |
| **Νέοι πληρωτές**      | Πελάτες που πλήρωσαν για πρώτη φορά σε αυτό το εύρος                                          |
| **Επαναλαμβανόμενοι πληρωτές** | Πελάτες που πλήρωσαν περισσότερες από μία φορές σε αυτό το εύρος                        |
| **Κορυφαίοι πληρωτές** | Πίνακας με τους πελάτες που πληρώνουν τα περισσότερα, με όνομα, ποσό, αριθμό διαδρομών, σύνδεσμο στο προφίλ |

## Τυπικά ροή εργασίας

- **Εβδομαδιαία ανασκόπηση** — προκαθορισμένο _Τελευταίες 7 ημέρες_ → περιηγηθείτε σε κάθε ενότητα μία φορά. Οτιδήποτε εκτός της γραμμής σύγκρισης (μεγάλο ▲ ή ▼) απαιτεί βαθύτερη ανάλυση
- **Ανασκόπηση διακοπής λειτουργίας** — ορίστε το εύρος ημερομηνιών στην ημέρα του συμβάντος → Ενότητα Ποιότητας → Διάγραμμα λόγων αποτυχίας → διασταυρώστε με το [Ιστορικό πληρωμών](../../operations/payments/payments.md) για τις πραγματικές συναλλαγές
- **Εμβάθυνση σε ετικέτα** — Κάρτα Χρεώσεων → Φίλτρο ετικέτας → επιλέξτε μια ετικέτα όπως _VIP_ → το μέτρο Χρεώσεων δείχνει μόνο αυτή την ομάδα· συγκρίνετε με τον συνολικό αριθμό χρεώσεων για γρήγορο μερίδιο
- **Προώθηση εισπράξεων** — Ενότητα Υπολοίπου → _Χρέος_ → αν έχει αυξηθεί, εξετάστε μεμονωμένους πελάτες μέσω της λίστας Πελατών φιλτραρισμένης κατά αρνητικό υπόλοιπο
- **Τιμολόγηση μάρκετινγκ** — Πρότυπα → Ιστόγραμμα μεγέθους επαναφόρτισης → ορίστε την προτεινόμενη επαναφόρτιση στην εφαρμογή σας στο πιο δημοφιλές εύρος

## Συμβουλές

- **Η γραμμή σύγκρισης είναι πιο χρήσιμη από τον απόλυτο αριθμό** — το απόλυτο ποσό εσόδων εξαρτάται από το μέγεθος της εταιρείας· η ποσοστιαία αλλαγή δείχνει αν τα πράγματα βελτιώνονται
- **Επίμονο εύρος ημερομηνιών** — το τελευταίο επιλεγμένο εύρος διατηρείται κατά την πλοήγηση· αν ένας συνάδελφος μοιραστεί ένα URL με διαφορετικό εύρος, αυτό υπερισχύει
- **Το φίλτρο ετικέτας εφαρμόζεται μόνο στις Χρεώσεις** — για να δείτε επαναφορτίσεις ανά ετικέτα πρέπει να διασταυρώσετε με τη λίστα Πελατών
- **Το διάγραμμα λόγων αποτυχίας είναι ο πίνακας αξιολόγησης του παρόχου σας** — η ξαφνική εμφάνιση νέας κατηγορίας λόγου συνήθως σημαίνει αλλαγή ρύθμισης παρόχου
- **Θετική καθαρή εισροή ≠ κέρδος** — αυτό είναι το υπόλοιπο πορτοφολιού, όχι τα έσοδα· δεν λαμβάνει υπόψη επιστροφές που μπορεί να εκδώσετε αργότερα ή εκκρεμή υπόλοιπα
- **Μέσο υπόλοιπο × Χρήστες ≠ Υπόλοιπο πορτοφολιού** — το Υπόλοιπο πορτοφολιού είναι το άθροισμα των θετικών· αν πολλοί αναβάτες έχουν χρέος, το Μέσο μπορεί να είναι χαμηλότερο από το Υπόλοιπο πορτοφολιού / Χρήστες
