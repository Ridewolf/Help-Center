# Αναλυτικά στοιχεία — Πρόσφατες Εκδηλώσεις

Η σελίδα αναλυτικών στοιχείων Εκδηλώσεων (`/analytics/events`) είναι ο **πίνακας ελέγχου συμβάντων** σας: κάθε αξιοσημείωτο σύστημα, όχημα, χρήστης και ζώνη συμβάντος σε μια επιλεγμένη περίοδο, με μετρητές KPI, μοτίβα με την πάροδο του χρόνου και μια αναζητήσιμη ροή στο κάτω μέρος.

Διαφορετική από τον [Πίνακα ειδοποιήσεων](../../features/ux/notifications.md) (σε πραγματικό χρόνο, ανά συμβάν) — αυτή η σελίδα είναι **συγκεντρωτική και ιστορική**, χρήσιμη για την ανίχνευση τάσεων και την ανασκόπηση μετά από συμβάν.

Απαιτούμενη άδεια: **Προβολή Πρόσφατων Εκδηλώσεων** (`s1t2u3`).

## Χρονικό πλαίσιο & φίλτρα

Μια **γραμμή εύρους ημερομηνιών** βρίσκεται στην κορυφή — κάθε μέτρηση και γράφημα την σέβεται. Τέσσερα επιπλέον φίλτρα περιορίζουν την προβολή:

| Φίλτρο         | Επιλογές                                                                 |
| --------------- | ----------------------------------------------------------------------- |
| **Σοβαρότητα**  | `critical` / `warning` / `info` (πολλαπλή επιλογή)                      |
| **Τύπος**       | `error` / `offline` / `battery` / `payment` / `support` / `maintenance` |
| **Τύπος πηγής** | `vehicle` / `user` / `zone` / `system`                                  |
| **Κατάσταση**   | `open` / `resolved` / `dismissed`                                       |

Όλα τα φίλτρα συνδυάζονται με ΚΑΙ. Το URL αντικατοπτρίζει κάθε ρύθμιση — μοιραστείτε έναν σύνδεσμο και ο συνεργάτης σας βλέπει ακριβώς το ίδιο τμήμα.

## Ενότητες

Η σελίδα έχει **πέντε ενότητες**:

### 1. Περίληψη

Τέσσερις κάρτες μετρήσεων συνοψίζουν τους αριθμούς συμβάντων:

| KPI           | Τι εμφανίζει                                               |
| ------------- | ---------------------------------------------------------- |
| **Σύνολο**    | Συνολικά συμβάντα στο εύρος                              |
| **Κρίσιμα**   | Αριθμός με `severity = critical` — ο αριθμός που πρέπει να προσέξετε |
| **Προειδοποίηση** | Αριθμός με `severity = warning`                          |
| **Πληροφορία** | Αριθμός με `severity = info` — συνήθως θόρυβος εκτός αν υπάρχει αιχμή |

Κάθε κάρτα φέρει ένα σήμα σύγκρισης «σε σχέση με την προηγούμενη περίοδο».

### 2. Ανά Τύπο

Ένα γράφημα που διαχωρίζει τα συμβάντα κατά **τύπο**:

- **Σφάλμα** — αποτυχίες συστήματος / ενσωμάτωσης
- **Εκτός σύνδεσης** — συσκευές IoT που σβήνουν
- **Μπαταρία** — συναγερμοί χαμηλής / εξαντλημένης / ανωμαλίας
- **Πληρωμή** — απορρίψεις, προβλήματα πύλης
- **Υποστήριξη** — αιχμές εισιτηρίων / συνομιλιών
- **Συντήρηση** — συμβάντα σχετιζόμενα με υπηρεσίες

Οι αιχμές σε έναν μόνο τύπο είναι συνήθως το σημείο εκκίνησης για διερεύνηση.

### 3. Μοτίβα

Δύο γραφήματα χρονοσειρών:

- **Ανά ημέρα** — συμβάντα ανά ημέρα σε όλο το εύρος (απεικονίζει εβδομαδιαίους κύκλους)
- **Ανά ώρα** — συμβάντα ανά ώρα της ημέρας σε όλο το εύρος (απεικονίζει ημερήσιες αιχμές)

### 4. Κορυφαίες Πηγές

Μια λίστα με τις **κορυφαίες πηγές** που δημιουργούν συμβάντα — συνήθως μεμονωμένα οχήματα ή ζώνες με δυσανάλογα πολλά συμβάντα.

Κάθε εγγραφή περιλαμβάνει την πηγή (συνδεδεμένη στη σελίδα λεπτομερειών της), τον αριθμό συμβάντων και τη κυρίαρχη σοβαρότητα / τύπο.

Εδώ βρίσκετε το **όχημα που έχει συναγερμούς όλη την εβδομάδα** ή τη **ζώνη με προβλήματα μπαταρίας**.

### 5. Ροή

Μια κύλιση ροής με μεμονωμένα συμβάντα που ταιριάζουν με τα τρέχοντα φίλτρα. Κάθε σειρά δείχνει:

- Εικονίδιο σοβαρότητας (χρωματισμένο)
- Τύπος συμβάντος + ετικέτα πηγής
- Σύντομη περιγραφή
- Χρονική σήμανση
- Ετικέτα κατάστασης

Κάντε κλικ σε ένα στοιχείο ροής για να μεταβείτε στη σχετική οντότητα (όχημα, πελάτης, διαδρομή, εισιτήριο) όπου ισχύει.

## Τυπικά ροή εργασιών

- **Καθημερινή πρωινή ανασκόπηση** — προκαθορισμένο _Τελευταίες 24 ώρες_ → Σοβαρότητα = Κρίσιμη → σάρωση· όλα τα κόκκινα λαμβάνουν προσοχή πριν ανοίξετε το υπόλοιπο του πίνακα ελέγχου
- **Διαλογή κορυφαίων πηγών** — Ενότητα κορυφαίων πηγών → κλικ σε όχημα που εμφανίζεται συνεχώς → επιδιόρθωση ή κλιμάκωση στην πηγή
- **Ανίχνευση μοτίβων** — γραφήματα μοτίβων· μια ασυνήθιστη ημέρα ή ώρα δείχνει ότι κάτι άλλαξε (ανάπτυξη, καιρός, διακοπή)
- **Ανασκόπηση μετά το συμβάν** — επιλέξτε την ημέρα → σοβαρότητα = κρίσιμη → διασταυρώστε τη Ροή με την καρτέλα Ειδοποιήσεων [Οχήματος](../../operations/fleet/vehicle-detail.md) ή την ενότητα Ποιότητας [Αναλυτικών Πληρωμών](payments.md) ανάλογα με τον τύπο
- **Πέρασμα καθαρισμού** — Κατάσταση = Ανοιχτό → μαζική επίλυση παλαιών στοιχείων (το κάνετε από τις σελίδες πηγής, όχι εδώ, αλλά τα βρίσκετε εδώ)

## Συμβουλές

- **Πρώτα τα κρίσιμα** — ξεκινήστε με `severity = critical`; οι προειδοποιήσεις και οι πληροφορίες συχνά επιλύονται μόνες τους
- **Ο τύπος είναι ο ντετέκτιβ σας** — μόλις έχετε μια αιχμή, φιλτράρετε με τον κυρίαρχο τύπο για να περιορίσετε τον θόρυβο
- **Οι κορυφαίες πηγές είναι χρυσός** — ένα όχημα στην κορυφή της λίστας πηγών συνήθως εξηγεί το 30-50% όλων των συμβάντων
- **Συγκεντρώσεις έναντι ακατέργαστων** — αυτή η σελίδα συγκεντρώνει· για τις πραγματικές συναλλαγές / ειδοποιήσεις πηγαίνετε στη σελίδα τομέα πηγής
- **Επίμονα φίλτρα** — οι ρυθμίσεις σας επιβιώνουν την πλοήγηση· καθαρίστε τα όταν δίνετε το URL σε κάποιον άλλο
- **Κατάσταση `open` ≠ ανεπίλυτος συναγερμός IoT** — η Κατάσταση εδώ είναι η _κατάσταση εγγραφής συμβάντος_; ο υποκείμενος συναγερμός μπορεί να έχει εκκαθαριστεί στη συσκευή ενώ το συμβάν παραμένει ανοιχτό στο σύστημα
