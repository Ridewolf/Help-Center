# Συνεδρίες — Συσκευές Συνδεδεμένες στον Λογαριασμό

Η οθόνη **Συνεδρίες** (`/settings/sessions`) εμφανίζει κάθε σημείο όπου ο λογαριασμός ενός αναβάτη είναι αυτή τη στιγμή συνδεδεμένος και επιτρέπει την αποσύνδεση από αυτά τα σημεία. Είναι η οθόνη που πρέπει να επισκεφτεί ο αναβάτης όποτε υποψιάζεται ότι κάποιος άλλος έχει πρόσβαση στον λογαριασμό του.

Δύο σημεία εισόδου, και τα δύο οδηγούν εδώ:

- **Προφίλ → Διαχείριση Συνεδριών**
- **Ρυθμίσεις → Κάρτα Απόρρητου → Διαχείριση Συνεδριών**

## Πώς οργανώνεται η λίστα

Οι συνεδρίες **ομαδοποιούνται ανά συσκευή** — πρόγραμμα περιήγησης και έκδοση, λειτουργικό σύστημα και έκδοση, τύπος συσκευής, κατασκευαστής και μοντέλο — ώστε το ίδιο τηλέφωνο να εμφανίζεται μία φορά αντί για δώδεκα.

Οι ομάδες ταξινομούνται σκόπιμα ως εξής:

1. Πρώτα η τρέχουσα συσκευή του αναβάτη
2. Έπειτα κατά κατάσταση: **ενεργό**, μετά **ανενεργό**, μετά **παλιό**
3. Τέλος κατά τελευταία δραστηριότητα, από την πιο πρόσφατη

Κάθε ομάδα είναι συμπτυσσόμενη. Η επέκτασή της αποκαλύπτει κάθε μεμονωμένη συνεδρία που ανήκει σε αυτή τη συσκευή.

## Ανάγνωση μιας ομάδας συσκευής

| Τι βλέπετε                         | Σημασία                                                                    |
| --------------------------------- | -------------------------------------------------------------------------- |
| **Ετικέτα συσκευής**              | Κατασκευαστής και μοντέλο όταν είναι γνωστά, αλλιώς το λειτουργικό σύστημα και η έκδοσή του |
| Εικονίδιο τύπου συσκευής          | Τηλέφωνο, tablet ή οθόνη                                                   |
| **Ετικέτα προγράμματος περιήγησης** | Το πρόγραμμα περιήγησης και η έκδοση πίσω από τη συνεδρία                   |
| **Σήμα κατάστασης συνεδρίας**     | Δείτε τον παρακάτω πίνακα                                                 |
| **Τελευταία δραστηριότητα**       | Σχετικός χρόνος — «μόλις τώρα», πριν N λεπτά / ώρες / ημέρες, και απόλυτη ημερομηνία όταν είναι πάνω από μία εβδομάδα παλιά |
| **Πλήθος συνεδριών**              | Πόσες συνεδρίες έχει αυτή η συσκευή                                       |
| **Τοποθεσία**                     | Πόλη, χώρα και διεύθυνση IP                                                |
| **Δημιουργήθηκε**                 | Πότε ξεκίνησε αυτή η συνεδρία                                              |
| **Τρέχουσα Συσκευή** / **Τρέχουσα Συνεδρία** | Επισημασμένο σήμα στη συσκευή και στη συνεδρία που χρησιμοποιεί ο αναβάτης αυτή τη στιγμή |

### Σήματα κατάστασης

| Σήμα        | Σημασία                              |
| ------------ | ------------------------------------ |
| **ενεργό**   | Τελευταία δραστηριότητα πριν από λιγότερο από μία ώρα  |
| **ανενεργό** | Τελευταία δραστηριότητα πριν από λιγότερο από 24 ώρες |
| **παλιό**    | Τελευταία δραστηριότητα πριν από 24 ώρες ή περισσότερο |

Το σήμα μετράει **μόνο την πρόσφατη δραστηριότητα** — δεν δηλώνει αν μια συνεδρία είναι ακόμα έγκυρη. Ένα σήμα «παλιό» δεν σημαίνει ότι η συνεδρία έχει λήξει.

## Αποσύνδεση μιας συνεδρίας

Η τρέχουσα συνεδρία δεν έχει επιλογή διαγραφής — εκ προθέσεως, δεν μπορεί να αφαιρεθεί από αυτή τη λίστα. Κάθε άλλη συνεδρία μπορεί:

1. Επεκτείνετε την ομάδα συσκευής
2. Πατήστε το εικονίδιο **κάδου** στη συνεδρία
3. Επιβεβαιώστε στο παράθυρο διαλόγου

Η λίστα ανανεώνεται και η συνεδρία έχει αφαιρεθεί.

## Μαζικές ενέργειες

| Ενέργεια                   | Τι κάνει                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Αποσύνδεση άλλων συνεδριών**  | Αποσυνδέει κάθε συνεδρία εκτός από αυτή στη συσκευή που κρατά ο αναβάτης. Αυτή είναι η σωστή ενέργεια όταν ο αναβάτης υποψιάζεται ότι κάποιος άλλος έχει πρόσβαση |
| **Αποσύνδεση όλων των συνεδριών** | Αποσυνδέει τα πάντα **συμπεριλαμβανομένης της τρέχουσας συσκευής**, οπότε ο αναβάτης επιστρέφει στην οθόνη σύνδεσης και πρέπει να συνδεθεί ξανά. Σχεδιασμένο ως καταστροφική ενέργεια γι' αυτόν τον λόγο |
| **Ανάκληση συσκευής**          | Διατίθεται σε επεκταμένη ομάδα συσκευής που δεν είναι η τρέχουσα — αποσυνδέει κάθε συνεδρία σε αυτή τη συσκευή |

Ενώ εκτελείται το αίτημα αποσύνδεσης, τα κουμπιά είναι απενεργοποιημένα. Σε αποτυχία εμφανίζεται σύντομο μήνυμα σφάλματος· σε επιτυχία εμφανίζεται επιβεβαίωση και η λίστα ανανεώνεται.

## Τυπικά σενάρια εργασίας

- **Ο αναβάτης νομίζει ότι κάποιος άλλος είναι στον λογαριασμό του** — **Αποσύνδεση άλλων συνεδριών**, μετά αλλαγή κωδικού από το **Προφίλ**. Σημειώστε ότι μια επιτυχημένη αλλαγή κωδικού αποσυνδέει επίσης τον αναβάτη, οπότε θα συνδεθεί ξανά μετά ([Προφίλ](profile.md))
- **Ξεχασμένη σύνδεση σε δανεικό τηλέφωνο** — επεκτείνετε την ομάδα αυτής της συσκευής, **Ανάκληση συσκευής**
- **Καθαρισμός παντού** — **Αποσύνδεση όλων των συνεδριών**, μετά σύνδεση ξανά ([Σύνδεση](registration-login.md))

## Συχνές ερωτήσεις

- **Γιατί ο αναβάτης δεν μπορεί να διαγράψει την τρέχουσα συνεδρία του;** Δεν εμφανίζεται επιλογή διαγραφής για αυτήν. Για να τερματίσετε την τρέχουσα συνεδρία, χρησιμοποιήστε **Αποσύνδεση όλων των συνεδριών** ή το κανονικό κουμπί **Αποσύνδεση** στο Προφίλ.
- **Τι σημαίνει πραγματικά «ενεργό»;** Δραστηριότητα μέσα στην τελευταία ώρα — τίποτα παραπάνω.
- **Γιατί ένα τηλέφωνο εμφανίζει πολλές συνεδρίες;** Οι συνεδρίες δημιουργούνται ανά σύνδεση. Η οθόνη τις ομαδοποιεί κάτω από μία συσκευή και δείχνει το πλήθος.
- **Το κουμπί Διαχείριση Συνεδριών είναι γκριζαρισμένο.** Ο λογαριασμός έχει εκκρεμή διαγραφή, που απενεργοποιεί τη διαχείριση συνεδριών μαζί με την επεξεργασία προφίλ — δείτε [Προφίλ](profile.md).
