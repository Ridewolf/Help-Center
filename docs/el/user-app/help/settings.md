# Rider App — Ρυθμίσεις

Οι Ρυθμίσεις (`/settings`) περιλαμβάνουν κάθε προτίμηση της εφαρμογής που βλέπει ο αναβάτης: ειδοποιήσεις, τι εμφανίζει ο χάρτης, διακόπτες απορρήτου, γλώσσα, θέμα και απόδοση.

**Δεν υπάρχει κουμπί Αποθήκευσης.** Η οθόνη εμφανίζει αμέσως τις αποθηκευμένες ρυθμίσεις, τις ανανεώνει στο παρασκήνιο και στέλνει κάθε αλλαγή αυτόματα λίγο μετά την εκτέλεσή της. Ένας αναβάτης που άλλαξε κάτι και έκλεισε αμέσως την οθόνη έχει σχεδόν σίγουρα αποθηκεύσει την αλλαγή — αυτή είναι η απάντηση στο «εφαρμόστηκε η αλλαγή μου;».

Πολλοί από αυτούς τους διακόπτες αλλάζουν το τι εμφανίζει ο [Χάρτης](../riding/map.md), οπότε αυτή είναι η πρώτη οθόνη που πρέπει να επισκεφτείτε για «ο χάρτης είναι αργός» και «δεν βλέπω τα επίπεδα μπαταρίας».

## Ειδοποιήσεις

Πέντε ανεξάρτητοι διακόπτες:

- **Ειδοποιήσεις Διαδρομών**
- **Ειδοποιήσεις Προωθήσεων**
- **Ενημερώσεις Εφαρμογής**
- **Push Ειδοποιήσεις**
- **Email Ειδοποιήσεις** — ένας μόνο διακόπτης· δεν υπάρχουν υποεπιλογές ανά τύπο κάτω από αυτόν

Στην ίδια περιοχή:

| Έλεγχος           | Σημειώσεις                                                                   |
| ------------------ | ---------------------------------------------------------------------------- |
| **Ήχος**           | Διακόπτης                                                                    |
| **Ένταση Ήχου**    | Ρυθμιστικό — εμφανίζεται μόνο όταν ο **Ήχος** είναι ενεργός                  |
| **Δόνηση**         | Διακόπτης                                                                    |
| **Ρυθμίσεις Ραντάρ** | Κάρτα που εμφανίζεται μόνο σε εκδόσεις της εφαρμογής όπου οι ρυθμίσεις ραντάρ είναι ενεργοποιημένες |

## Χάρτης και εμφάνιση

Διακόπτες:

- **Εμφάνιση Επιπέδου Μπαταρίας**
- **Εμφάνιση Προωθητικών Οχημάτων**
- **Εμφάνιση Τιμολόγησης**
- **Αυτόματο Ζουμ**
- **Χάρτης 3D** — εφαρμόζεται αμέσως στον χάρτη
- **Μειωμένες Κινήσεις**

Επιπλέον, **Λειτουργία Δεδομένων**, επιλογή με **ισορροπημένη**, **χαμηλή** και **υψηλή**. Ελέγχει την ποιότητα των πλακιδίων του χάρτη και πόσες λεπτομέρειες εμφανίζει ο χάρτης, και είναι **το πρώτο που πρέπει να δοκιμάσετε όταν ένας αναβάτης αναφέρει αργό ή βαρύ χάρτη** — μειώστε το σε _χαμηλή_ και ενεργοποιήστε επίσης τις **Μειωμένες Κινήσεις**.

Οι **Χάρτες εκτός σύνδεσης** δεν είναι προς το παρόν διαθέσιμοι στην εφαρμογή.

## Έλεγχοι απορρήτου

- Διακόπτης **Κοινή χρήση γεωτοποθεσίας**
- Διακόπτης **Κοινή χρήση δεδομένων**
- **Πολιτική Απορρήτου** — ανοίγει το εξωτερικό URL που έχετε ρυθμίσει στο [Η εταιρεία μου](../../settings/administration/my-company.md)· ο σύνδεσμος εμφανίζεται μόνο όταν έχει οριστεί URL
- **Διαχείριση Συνεδριών** — ανοίγει την οθόνη συσκευών με σύνδεση (`/settings/sessions`), την ίδια που είναι προσβάσιμη από το Προφίλ

Η πλήρης οθόνη οδηγιών απορρήτου και ασφάλειας είναι ξεχωριστή διαδρομή (`/privacy`). **Η διαγραφή λογαριασμού δεν είναι εδώ** — η λειτουργική ροή διαγραφής είναι στην οθόνη Προφίλ.

## Περιοχή και εμφάνιση

| Έλεγχος        | Επιλογές                          | Σημειώσεις                                                                                              |
| -------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Γλώσσα**     | **en**, **ru**, **ro**           | Εφαρμόζεται αμέσως, χωρίς επαναφόρτωση. Μόνο αυτές οι τρεις προσφέρονται σε αυτήν την οθόνη              |
| **Μονάδες**    | —                                | Επιλογέας μονάδων δεν είναι προς το παρόν διαθέσιμος στην εφαρμογή                                      |
| **Θέμα**       | Φωτεινό, Σκούρο, Σύστημα         | Εφαρμόζεται αμέσως                                                                                       |
| **Στυλ Χάρτη** | Αυτόματο, Φωτεινό, Σκούρο        | **Απενεργοποιημένο και αναγκαστικά στο Αυτόματο όταν το Θέμα είναι ρυθμισμένο σε Σύστημα.** Αλλάξτε το Θέμα σε Φωτεινό ή Σκούρο για να το ξεκλειδώσετε |

Εδώ εμφανίζονται μόνο οι τρεις παραπάνω γλώσσες της εφαρμογής, παρόλο που υπάρχουν άλλες τοπικές ρυθμίσεις αλλού στο προϊόν — δείτε το [Localization](../../settings/administration/localization.md) για το μέρος του Πίνακα ελέγχου.

## Λειτουργία οδήγησης

**Η Λειτουργία οδήγησης δεν είναι προς το παρόν διαθέσιμη στην εφαρμογή.** Ένας αναβάτης που ρωτάει πού είναι ο έλεγχος λειτουργίας οδήγησης δεν έχει χάσει δικαίωμα — η ενότητα δεν υπάρχει στην εφαρμογή και δεν υπάρχει ρύθμιση στον Πίνακα ελέγχου που να την προσθέτει.

## Συχνές Ερωτήσεις

| Ο αναβάτης ρωτά…                     | Απάντηση                                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------------------------- |
| «Πού είναι το κουμπί Αποθήκευσης;»  | Δεν υπάρχει — οι αλλαγές αποθηκεύονται αυτόματα                                            |
| «Πού είναι η Λειτουργία Οδήγησης;»   | Δεν είναι προς το παρόν διαθέσιμη στην εφαρμογή                                             |
| «Γιατί το Στυλ Χάρτη είναι γκριζαρισμένο;» | Το **Θέμα** είναι ρυθμισμένο σε **Σύστημα**. Αλλάξτε το πρώτα σε Φωτεινό ή Σκούρο           |
| «Γιατί δεν εμφανίζεται η γλώσσα μου;» | Αυτή η οθόνη προσφέρει μόνο **en**, **ru** και **ro**                                      |
| «Πού είναι η ρύθμιση Μονάδων;»      | Δεν είναι προς το παρόν διαθέσιμη στην εφαρμογή                                             |
| «Πού είναι ο διακόπτης Χαρτών εκτός σύνδεσης;» | Δεν είναι προς το παρόν διαθέσιμη στην εφαρμογή                                             |
| «Πώς διαγράφω τον λογαριασμό μου;»  | Από την οθόνη Προφίλ, όχι από τις Ρυθμίσεις                                                |
| «Πώς βλέπω τις συσκευές που έχω συνδεθεί;» | **Διαχείριση Συνεδριών** — εδώ, ή το ίδιο κουμπί στο Προφίλ                                |
| «Ο χάρτης είναι αργός»                | **Λειτουργία Δεδομένων → χαμηλή**, μετά **Μειωμένες Κινήσεις** ενεργοποιημένες. Δείτε [Χάρτης](../riding/map.md#επίλυση-προβλημάτων) |

## Συμβουλές

- **Η λειτουργία Δεδομένων είναι ο ρυθμιστής απόδοσής σας.** Πριν κατηγορήσετε το τηλέφωνο του αναβάτη ή τα πλακίδια σας, ζητήστε τους να δοκιμάσουν _χαμηλή_.
- **Το "Δεν αποθηκεύτηκε" σχεδόν ποτέ δεν ισχύει.** Ζητήστε τους να ξανανοίξουν την οθόνη — η τιμή θα είναι εκεί.
- **Τα παράπονα για τον χάρτη συχνά βρίσκονται εδώ, όχι στον χάρτη.** Τα ποσοστά μπαταρίας που λείπουν, οι τιμές που λείπουν και τα προωθητικά οχήματα που λείπουν είναι όλα επιλογές σε αυτήν την οθόνη.
- **Το θέμα κλειδώνει το Στυλ Χάρτη.** Απομνημονεύστε αυτό το ζευγάρι· διαφορετικά είναι εβδομαδιαίο εισιτήριο.
