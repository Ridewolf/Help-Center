# Rider App — Υποστήριξη, FAQ & Ζωντανή Συνομιλία

Η **Υποστήριξη** (`/support`) είναι το σημείο όπου απευθύνεται ο αναβάτης για βοήθεια. Περιλαμβάνει δύο καρτέλες — **FAQ** και **Επικοινωνία** — και η ζωντανή συνομιλία ανοίγει σε ξεχωριστή οθόνη (`/support/messenger`).

Δύο πράγματα που πρέπει να γνωρίζετε πριν απαντήσετε σε οποιαδήποτε ερώτηση σχετικά με την υποστήριξη:

- **Κάθε κανάλι επικοινωνίας είναι δικό σας για διαμόρφωση.** Δεν υπάρχει παγκόσμιο email υποστήριξης Ridewolf, αριθμός τηλεφώνου ή ώρες λειτουργίας στην εφαρμογή — μην αναφέρετε ποτέ κάποιο.
- **Η εφαρμογή διαθέτει συνομιλία, όχι φόρμα εισιτηρίου.** Οι αναβάτες δεν λαμβάνουν αριθμούς εισιτηρίων. Η προβολή της ομάδας σας για τις ίδιες συνομιλίες είναι τα [Συνομιλίες](../../support/tickets-proofs-chat/conversations.md). Τα [Εισιτήρια](../../support/tickets-proofs-chat/tickets.md) είναι έννοια για τον χειριστή.

## Καρτέλα FAQ

Τμήματα ακορντεόν που δημιουργούνται από το δημοσιευμένο περιεχόμενο ερωτήσεων-απαντήσεων, μαζί με στοιχεία **Οδηγού Διαδρομής** χωρισμένα σε ομάδες **Πριν την Έναρξη** και **Πριν το Τέλος**.

Ελέγχετε όλο αυτό χωρίς να χρειάζεται νέα έκδοση της εφαρμογής:

- Ερωτήσεις και απαντήσεις — [Σετ FAQ](../../settings/content/faq-sets.md)
- Οδηγοί διαδρομής — [Γρήγοροι οδηγοί](../../settings/content/quick-guides.md)

Μεμονωμένα στοιχεία FAQ είναι **σύνδεσμοι με άμεση πρόσβαση**: ένας σύνδεσμος σε συγκεκριμένο στοιχείο ανοίγει την Υποστήριξη με το στοιχείο ήδη επεκταμένο και ορατό. Αυτός είναι ο σωστός τρόπος να στείλετε έναν αναβάτη απευθείας σε μια απάντηση αντί για "κοιτάξτε στο FAQ".

## Καρτέλα Επικοινωνία

Κάθε κανάλι εδώ εμφανίζεται μόνο όταν το έχετε ενεργοποιήσει στο [Η εταιρεία μου → Εφαρμογή → κανάλια υποστήριξης](../../settings/administration/my-company.md).

| Κανάλι       | Τι κάνει                                                        |
| ------------- | ------------------------------------------------------------------- |
| **Ζωντανή Συνομιλία** | Ανοίγει τον messenger (`/support/messenger`)                          |
| **Email**     | Ανοίγει την εφαρμογή email του αναβάτη με τη δική σας διεύθυνση                        |
| **Ιστοσελίδα**   | Ανοίγει το ρυθμισμένο URL σας στον ενσωματωμένο περιηγητή της εφαρμογής                     |
| **Telegram**  | Ανοίγει εξωτερικά την επαφή σας στο Telegram                              |
| **WhatsApp**  | Ανοίγει εξωτερικά την επαφή σας στο WhatsApp                              |
| **Τηλέφωνο**     | Ξεκινά κλήση στον ρυθμισμένο αριθμό σας                             |

Αν **κανένα** δεν είναι ενεργοποιημένο, η καρτέλα εμφανίζει εικόνα χωρίς επαφές. Ένας αναβάτης που αναφέρει "δεν υπάρχει τρόπος να επικοινωνήσω με την υποστήριξη" βρίσκεται σχεδόν πάντα σε εταιρεία με όλα τα κανάλια απενεργοποιημένα — ελέγξτε τη δική σας διαμόρφωση πριν κοιτάξετε αλλού.

## Ζωντανή συνομιλία

Ο messenger βασίζεται σε συνομιλίες:

- Ο αναβάτης βλέπει τη **λίστα των συνομιλιών του**, κάθε μία με κατάσταση, τον ανατεθειμένο χειριστή, το τελευταίο μήνυμα και την ώρα του, και τον αριθμό μη αναγνωσμένων.
- Η επιλογή **Νέα Συνομιλία** προσφέρεται **μόνο όταν ο αναβάτης δεν έχει ανοιχτή συνομιλία.** Ένας αναβάτης με ανοιχτή συνομιλία δεν βλέπει τρόπο να ξεκινήσει δεύτερη — εκ προθέσεως. Συνεχίζει την υπάρχουσα συνομιλία.
- Το άνοιγμα συνομιλίας φορτώνει το ιστορικό μηνυμάτων, 50 μηνύματα κάθε φορά, φέρνοντας παλαιότερα καθώς ο αναβάτης κάνει scroll προς τα πάνω.

| Κατάσταση συνομιλίας | Σημασία                              |
| ------------------- | ------------------------------------ |
| **Νέο**             | Μόλις άνοιξε, δεν έχει αναληφθεί ακόμα       |
| **Αναμονή**         | Αναμονή από την ομάδα σας                 |
| **Ενεργό**          | Σε επεξεργασία                        |
| **Καθυστερημένο**         | Αναβλήθηκε                             |
| **Κλειστό**          | Κλειστό από χειριστή                |

**Τύποι μηνυμάτων που εμφανίζει η εφαρμογή:** κείμενο, εικόνα, αρχείο, τοποθεσία, επαφή, διαδρομή, σύνδεσμος εφαρμογής και συστημικά μηνύματα.

**Εικονίδια κατάστασης μηνυμάτων:** αποστολή, αποστάλθηκε, παραδόθηκε, διαβασμένο και απέτυχε.

### Αποστολή μηνύματος

Ένας αναβάτης μπορεί να επισυνάψει:

- Έως **5 εικόνες ανά μήνυμα**
- Μια **σημείωση τοποθεσίας** (γεωγραφικό πλάτος, μήκος και ετικέτα)
- Ένα **αρχείο**

Ένα αποσταλμένο μήνυμα εμφανίζεται αμέσως ως _αποστολή_, μετά ενημερώνεται στην πραγματική του κατάσταση όταν το επιβεβαιώνει ο διακομιστής. Η ίδια ζωντανή σύνδεση χειρίζεται ενημερώσεις νέων μηνυμάτων και ανάγνωσης, ειδοποιήσεις κλεισίματος και ανάθεσης συνομιλίας, και τον δείκτη "_{όνομα} πληκτρολογεί…_".

Μετά από απώλεια σύνδεσης, η εφαρμογή ξαναφορτώνει τη λίστα συνομιλιών και την ανοιχτή συνομιλία, αποφεύγοντας διπλοεγγραφές μηνυμάτων — έτσι ένας αναβάτης που αποσυνδέθηκε δεν θα δει το ίδιο μήνυμα δύο φορές.

Όταν ένας χειριστής **κλείνει** τη συνομιλία, η εισαγωγή του αναβάτη απενεργοποιείται και εμφανίζεται ειδοποίηση "η συνομιλία έκλεισε" στη θέση της.

## Αντιμετώπιση προβλημάτων

| Ο αναβάτης λέει…                              | Τι σημαίνει                                                                                                    |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| "Δεν υπάρχουν επιλογές επικοινωνίας"           | Κανένα κανάλι δεν είναι ενεργοποιημένο για την εταιρεία σας — διορθώστε το στο [Η εταιρεία μου](../../settings/administration/my-company.md)  |
| "Δεν υπάρχει κουμπί Νέας Συνομιλίας"            | Ο αναβάτης έχει ήδη ανοιχτή συνομιλία· πρέπει να συνεχίσει αυτή τη συνομιλία                                     |
| "Δεν μπορώ να πληκτρολογήσω άλλο"                  | Ένας χειριστής έκλεισε τη συνομιλία. Μπορεί να ξεκινήσει νέα μόνο όταν δεν υπάρχει ανοιχτή συνομιλία                        |
| "Το μήνυμά μου εμφανίζεται ως απέτυχε"                | Δεν έφυγε ποτέ από τη συσκευή — δοκιμάστε ξανά                                                                             |
| "Τα μηνύματά μου εμφανίστηκαν διπλά μετά την επανασύνδεση" | Δεν εμφανίστηκαν· η επαναφόρτωση αποφεύγει διπλοεγγραφές. Ζητήστε screenshot αν επιμένουν                                     |
| "Πόσο γρήγορα θα απαντήσετε;"               | Δεν ορίζεται χρόνος απόκρισης στην εφαρμογή. **Μην υποσχεθείτε** — αναφέρετε τη δική σας δημοσιευμένη δέσμευση υπηρεσίας    |
| "Πού αναφέρω έκτακτη ανάγκη;"        | Μέσω των καναλιών που έχετε ενεργοποιήσει. Η εφαρμογή δεν ορίζει κανένα τηλεφωνικό αριθμό έκτακτης ανάγκης και δεν πρέπει να αναφέρεται κανένας |

## Συμβουλές

- **Ελέγξτε την καρτέλα Επαφής σας.** Ανοίξτε μόνοι σας την εφαρμογή Rider μετά από οποιαδήποτε αλλαγή στην Εταιρεία μου — μια εντελώς κενή καρτέλα Επαφής είναι αόρατη για εσάς και εξοργιστική για τους αναβάτες.
- **Χρησιμοποιήστε απευθείας συνδέσμους σε απαντήσεις FAQ** στις απαντήσεις συνομιλίας αντί να τις ξαναγράφετε. Διδάσκει στους αναβάτες πού βρίσκεται η απάντηση.
- **Ο κανόνας είναι μία ανοιχτή συνομιλία τη φορά.** Όταν ένας αναβάτης χρειάζεται να θέσει κάτι άσχετο, κλείστε πρώτα το παλιό νήμα.
- **Κρατήστε τα Σετ Συχνών Ερωτήσεων και τους Γρήγορους οδηγούς ενημερωμένους** — κάθε ερώτηση που απαντούν είναι μια συνομιλία που δεν χρειάζεται να κάνετε.
- **Το κλείσιμο μιας συνομιλίας τερματίζει τη δυνατότητα απάντησης του αναβάτη.** Βεβαιωθείτε ότι η απάντηση είναι πλήρης πριν κλείσετε.
