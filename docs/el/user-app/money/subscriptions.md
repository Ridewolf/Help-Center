# Rider App — Συνδρομές & Κωδικοί Προώθησης

**Οι συνδρομές και οι κωδικοί προώθησης δεν είναι διαθέσιμοι στην εφαρμογή αυτή τη στιγμή.** Ένας αναβάτης δεν μπορεί να αγοράσει σχέδιο, δεν μπορεί να εξαργυρώσει κωδικό προώθησης και δεν έχει κάτι να ακυρώσει.

Αν θέλετε να δώσετε έκπτωση σε έναν αναβάτη, ρυθμίστε το από τον πίνακα ελέγχου — δείτε [Giving a rider a discount today](#πώς-να-δώσετε-έκπτωση-σε-έναν-αναβάτη-σήμερα).

## Τι βλέπει πραγματικά ο αναβάτης

- Το πλευρικό μενού στο [Χάρτη](../riding/map.md#κέλυφος-πλοήγησης) **δεν έχει καταχώρηση Προωθήσεων ούτε Συνδρομών**.
- Ένας σύνδεσμος `/subscriptions` δεν ανοίγει οθόνη. Ένας αναβάτης που τον πληκτρολογεί ή ακολουθεί σύνδεσμο σε αυτόν, προσγειώνεται στην οθόνη **Not Found** της εφαρμογής. Αυτή είναι η αναμενόμενη συμπεριφορά, όχι σφάλμα στον λογαριασμό ή τη συσκευή του.
- Ο παλαιότερος σύνδεσμος `/promo` απλώς ανακατευθύνει στο [Πορτοφόλι](wallet.md).
- Δεν υπάρχει **καμία ρύθμιση στον πίνακα ελέγχου** που να ενεργοποιεί τις συνδρομές ή τους κωδικούς προώθησης για την εταιρεία σας.

Μην υποσχεθείτε σε έναν αναβάτη ότι ένας κωδικός θα λειτουργήσει «όταν τον ενεργοποιήσουμε», και μην αναφέρετε ονόματα σχεδίων ή τιμές — κανένα δεν ισχύει.

## Πώς να δώσετε έκπτωση σε έναν αναβάτη σήμερα

Υπάρχουν τρεις μηχανισμοί, όλοι από την πλευρά του χειριστή:

| Μηχανισμός                 | Πού                                                                        | Κατάλληλο για                                                     |
| ------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **Επίπεδα έκπτωσης τιμολογίου** | [Τιμολόγια οχημάτων](../../settings/infrastructure/vehicle-tariffs.md)           | Να γίνονται οι μεγαλύτερες διαδρομές προοδευτικά φθηνότερες για όλους       |
| **Ξεχωριστό τιμολόγιο συν ετικέτες** | [Τιμολόγια οχημάτων](../../settings/infrastructure/vehicle-tariffs.md) + [Ετικέτες](../../settings/infrastructure/tags.md) | Φθηνότερη τιμολόγηση για ορισμένη ομάδα (εταιρικοί, προσωπικό, VIP)   |
| **Χειροκίνητη πίστωση υπολοίπου** | [Λεπτομέρειες πελάτη](../../operations/customers/client-detail.md#ενέργειες) → **Επαναφόρτιση υπολοίπου** | Μοναδική ευγενική χειρονομία μετά από παράπονο ή αποτυχημένη διαδρομή           |

Για μία μοναδική αποζημίωση, η χειροκίνητη πίστωση υπολοίπου είναι η ταχύτερη και αφήνει καταχώρηση στο αρχείο δραστηριοτήτων του πελάτη. Για οτιδήποτε επαναλαμβανόμενο, ενσωματώστε το σε τιμολόγιο.

## Συχνές Ερωτήσεις

| Ερώτηση                                        | Απάντηση                                                                                                        |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| "Πώς αγοράζω συνδρομή;"                  | Δεν είναι διαθέσιμο στην εφαρμογή αυτή τη στιγμή                                                                             |
| "Η σελίδα συνδρομών δείχνει Not Found"        | Σωστό και αναμενόμενο                                                                                           |
| "Μπορούμε να ενεργοποιήσουμε τις συνδρομές για την εταιρεία μας;"  | Όχι — δεν υπάρχει ρύθμιση στον πίνακα ελέγχου για αυτό                                                                       |
| "Ο κωδικός προώθησής μου δεν εφαρμόζεται"                     | Οι κωδικοί προώθησης δεν είναι διαθέσιμοι στην εφαρμογή αυτή τη στιγμή                                                              |
| "Η σάρωση κωδικού QR προώθησης δεν κάνει τίποτα"         | Το ίδιο — δεν είναι διαθέσιμο αυτή τη στιγμή                                                                                  |
| "Πώς ακυρώνω το σχέδιό μου;"                      | Δεν υπάρχει σχέδιο για ακύρωση                                                                                      |
| "Ποια τιμολόγηση ισχύει για μένα τότε;"              | Το τιμολόγιο που συνδέεται με το όχημα που χρησιμοποιείται. Δείτε [Τιμολόγια οχημάτων](../../settings/infrastructure/vehicle-tariffs.md) και την [ανάλυση κόστους διαδρομής](../riding/rides.md#ανάλυση-κόστους) |

## Συμβουλές

- **Πείτε "δεν είναι διαθέσιμο αυτή τη στιγμή", και μετά πείτε τι _μπορείτε_ να κάνετε.** Ένας αναβάτης που ρωτά για κωδικούς προώθησης συνήθως ζητά έκπτωση· μια χειροκίνητη πίστωση υπολοίπου απαντά στην πραγματική ερώτηση.
- **Κρατήστε τη λογική έκπτωσης στα τιμολόγια.** Οτιδήποτε ορίσετε εκεί εφαρμόζεται συνεπώς και εμφανίζεται σωστά στην ανάλυση κόστους διαδρομής του αναβάτη.
- **Προσέξτε για κωδικούς προώθησης τρίτων.** Αν οι αναβάτες έρχονται με κωδικούς από καμπάνια, βεβαιωθείτε ότι το μάρκετινγκ γνωρίζει πως η εφαρμογή δεν μπορεί να τους εξαργυρώσει.
