# Εφαρμογή Χρήστη — Επισκόπηση

Η εφαρμογή χρήστη (η εφαρμογή rider) είναι η κινητή εφαρμογή που χρησιμοποιούν οι πελάτες σας για να βρουν και να χρησιμοποιήσουν κοινόχρηστα οχήματα, να διατηρούν το υπόλοιπο του πορτοφολιού τους ενημερωμένο, να αναθεωρούν προηγούμενες διαδρομές και να επικοινωνούν με την ομάδα υποστήριξής σας.

Αυτό το άρθρο είναι ο χάρτης αυτής της εφαρμογής: τι κάνει, πού βρίσκεται κάθε οθόνη και ποιος οδηγός απαντά σε ποια ερώτηση. Χρησιμοποιήστε το ως σημείο εκκίνησης όταν ένας rider επικοινωνεί και χρειάζεστε το ακριβές όνομα οθόνης και τα ακριβή βήματα.

Για μια περιήγηση για τον rider κατά την πρώτη εκκίνηση, δείτε το [Getting started](getting-started.md). Για την εφαρμογή προσωπικού πεδίου, δείτε το [Service app — Overview](../../service-app/basics/overview.md).

## Τι μπορεί να κάνει η εφαρμογή

- Ζωντανός χάρτης οχημάτων ως αρχική οθόνη
- Υπόλοιπο πορτοφολιού με πολλούς παρόχους ανανέωσης
- Ιστορικό διαδρομών με ανάλυση κόστους ανά διαδρομή και χάρτη διαδρομής
- Ζωντανή συνομιλία με υποστήριξη, συν τα κανάλια επικοινωνίας που ενεργοποιείτε
- Πολλές γλώσσες διεπαφής, φωτεινά και σκοτεινά θέματα
- Διαχείριση συνεδριών ανά συσκευή

## Πώς κινούνται οι riders στην εφαρμογή

Ο **χάρτης** είναι η αρχική οθόνη. Όλα τα άλλα ανοίγουν από το **Μενού**, το οποίο ο rider τραβάει από τον χάρτη — αυτό το συρτάρι είναι το μοναδικό κέλυφος πλοήγησης της εφαρμογής. Δεν υπάρχει κάτω γραμμή καρτελών πουθενά στην εφαρμογή, οπότε μην στέλνετε ποτέ έναν rider να ψάχνει για κάτι τέτοιο.

Τα μηνύματα συνομιλίας του χειριστή μπορούν επίσης να περιέχουν συνδέσμους εφαρμογής που πηγαίνουν τον rider απευθείας σε μια οθόνη (για παράδειγμα στην οθόνη Απόρρητο).

## Δεν είναι διαθέσιμο στην εφαρμογή αυτή τη στιγμή

Μην υποσχεθείτε αυτά σε αναβάτη — δεν είναι διαθέσιμα στην εφαρμογή αυτή τη στιγμή:

- **Συνδρομές** και **κωδικοί προσφοράς** — η οθόνη δεν μπορεί να ανοίξει
- **Αναλυτικά στοιχεία** — στείλτε τους αναβάτες στο **Ιστορικό** για συνολικά
- **Ανέβασμα εγγράφων κατά την εγγραφή** — μην πείτε ποτέ σε αναβάτη ότι το έγγραφό του ελήφθη
- **Λειτουργία οδήγησης**, **Μονάδες μέτρησης**, **Χάρτες εκτός σύνδεσης**, **κωδικοί πρόσκλησης**, **Λήψη των δεδομένων μου** και το κουμπί **Αίτηση διαγραφής λογαριασμού** στην οθόνη Απόρρητο

Η διαγραφή λογαριασμού λειτουργεί — από το **Προφίλ**, δείτε [Προφίλ](../account/profile.md).

## Τι αλλάζουν οι ρυθμίσεις της εταιρείας σας

Μερικά μέρη της εφαρμογής διαφέρουν ανάμεσα στους χειριστές επειδή τα ρυθμίζετε στον πίνακα ελέγχου, στις **Ρυθμίσεις → Η εταιρεία μου → Εφαρμογή**:

- **Μέθοδοι πιστοποίησης** — ποιες καρτέλες βλέπει ο αναβάτης στην οθόνη σύνδεσης
- **Επιπλέον βήματα εγγραφής** — αν η εισαγωγή ζητά επιπλέον έγγραφα
- **Κανάλια υποστήριξης** — ποια κανάλια επικοινωνίας εμφανίζονται στις οθόνες Υποστήριξης και Αποκλεισμού λογαριασμού
- **Νομικά & συμμόρφωση** — οι σύνδεσμοι Όροι Υπηρεσίας και Πολιτική Απορρήτου που εμφανίζονται στην εφαρμογή

Δείτε [Η εταιρεία μου](../../settings/administration/my-company.md) για την πλευρά του χειριστή αυτών των ρυθμίσεων.
