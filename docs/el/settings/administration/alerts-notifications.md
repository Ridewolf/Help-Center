# Ειδοποιήσεις & Ανακοινώσεις

Η σελίδα Ειδοποιήσεων & Ανακοινώσεων (`/settings/alerts-notifications`) είναι η **κονσόλα ειδοποιήσεων χειριστή** — ο τρόπος με τον οποίο η πλατφόρμα ενημερώνει το _προσωπικό_ ότι κάτι χρειάζεται προσοχή. Καλύπτει τα κανάλια (push / εντός εφαρμογής / email / SMS), τους εξωτερικούς παρόχους (SendGrid, Twilio, Telegram, Slack, Discord, webhooks), τους κανόνες που ενεργοποιούν τις ειδοποιήσεις, τα πρότυπα μηνυμάτων, τις πολιτικές κλιμάκωσης, ποιος είναι συνδρομητής και το αρχείο παράδοσης.

Αυτή η σελίδα αφορά **ειδοποιήσεις για την ομάδα που διαχειρίζεται την πλατφόρμα**. Για το κείμενο ειδοποιήσεων που βλέπει ο αναβάτης (Η διαδρομή ξεκίνησε, Επιβλήθηκε ποινή, κ.λπ.), δείτε την καρτέλα _Notifications_ στο [General](general.md).

> _Σημείωση_: αυτή η σελίδα είναι προς το παρόν **πρωτότυπο μόνο για το frontend** — οι ρυθμίσεις καναλιών, οι κανόνες, οι συνδρομές και το αρχείο παράδοσης διατηρούνται σε τοπική κατάσταση (ή φορτώνονται από το `mockData.ts`). Η _Αποθήκευση αλλαγών_ εμφανίζει μια επιβεβαίωση toast αλλά δεν καλεί ακόμα κάποιο backend endpoint. Η δομή της σελίδας αντιστοιχεί στο πραγματικό μοντέλο και είναι ασφαλής για χρήση ως προδιαγραφή για την ανάπτυξη του API.

Απαιτούμενη άδεια: δεν ορίζονται συγκεκριμένα `requiredPermissions` στη διαδρομή — οποιοσδήποτε συνδεδεμένος χειριστής μπορεί να την ανοίξει.

## Επάνω γραμμή εργαλείων

Η κεφαλίδα της σελίδας έχει τέσσερα κουμπιά:

| Ενέργεια     | Τι κάνει                                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Αυτόματη ανανέωση | Το κοινό `AutoRefresh` widget — χωρίς λειτουργία εδώ, υπάρχει για ομοιομορφία με άλλες σελίδες                              |
| Δοκιμή όλων  | Εμφανίζει toast _"Testing all"_ — θέση κράτησης για "αποστολή δοκιμής σε κάθε ενεργοποιημένο κανάλι"                      |
| Σίγαση 1ω    | Toast _"Muted for 1h"_ — θέση κράτησης για παγκόσμια σίγαση 1 ώρας                                                       |
| Συντήρηση   | Καταστροφικό κόκκινο κουμπί — ανοίγει AlertDialog που ζητά επιβεβαίωση; η επιβεβαίωση εμφανίζει toast ότι η συντήρηση είναι ενεργοποιημένη |

## Καρτέλες

Επτά καρτέλες στην κορυφή. Κάθε μία είναι ξεχωριστό υποσυστατικό.

| Καρτέλα       | Σκοπός                                                                             |
| ------------- | ---------------------------------------------------------------------------------- |
| Κανάλια       | Ενσωματωμένα κανάλια (push / εντός εφαρμογής / email / SMS) + δρομολόγηση σοβαρότητας + συνοπτικές αναφορές |
| Πάροχοι       | Διαπιστευτήρια εξωτερικών παρόχων (Email / SMS / Telegram / Slack / Discord / Webhook) |
| Κανόνες       | Κανόνες ειδοποίησης ανά οικογένεια συμβάντων                                      |
| Πρότυπα       | Κείμενο ειδοποίησης ανά οικογένεια συμβάντος × γλώσσα                            |
| Πολιτικές     | Αλυσίδα κλιμάκωσης, αυτόματη σίγαση, ασφάλεια κοινού, απόκρυψη προσωπικών δεδομένων |
| Συνδρομές     | Ποιος (ρόλος ή χρήστης) λαμβάνει ποιες οικογένειες συμβάντων σε ποια κανάλια      |
| Αρχεία        | Μόνο ανάγνωση αρχείο παράδοσης (απεσταλμένα / επιβεβαιωμένα / αποτυχημένα)         |

### Κανάλια

Τρεις κάρτες στοιβαγμένες.

**Ενσωματωμένα κανάλια**

- _Push_ — πλήρης ρύθμιση (διακόπτης ενεργοποίησης, όριο ρυθμού, επαναλήψεις, ώρες ησυχίας από/έως, κουμπί δοκιμής).
- _Εντός εφαρμογής_ — ενεργοποιημένο, όριο ρυθμού, δευτερόλεπτα αυτόματης απόρριψης.
- _Email_ — εξαρτάται από τον πάροχο Email στην καρτέλα Πάροχοι. Ενεργοποιημένο, όριο ρυθμού, επαναλήψεις.
- _SMS_ — εξαρτάται από τον πάροχο SMS. Ενεργοποιημένο, όριο ρυθμού, επαναλήψεις, ώρες ησυχίας.

**Χαρτογράφηση σοβαρότητας** — τρία αναδυόμενα μενού που αντιστοιχούν `info` → `inApp` (προεπιλογή), `warning` → `push`, `critical` → `push+email`. Αυτά είναι τα κανάλια που χρησιμοποιούνται όταν ένας κανόνας έχει αυτή τη σοβαρότητα αλλά δεν ορίζει συγκεκριμένα κανάλια.

**Συνοπτική αναφορά (Digest)** — συχνότητα (απενεργοποιημένη / ανά ώρα / καθημερινά / εβδομαδιαία) + ώρα αποστολής (επιλογέας ώρας HH:00).

### Πάροχοι

Έξι μπλοκ παρόχων, το καθένα με διακόπτη ενεργοποίησης και διαπιστευτήρια.

- _Email_ — αναδυόμενο μενού τύπου παρόχου (SMTP / SendGrid / Mailgun), API key ή SMTP διαπιστευτήρια (κρυφά), από domain.
- _SMS_ — Account SID, Auth token (κρυφό), από αριθμό — μορφή Twilio.
- _Telegram_ — Bot token (κρυφό) + επιλογέας chat ID (λίστα τριών demo chats: `@ridewolf_alerts`, `@support_team`, `@management`; το κουμπί **Test** είναι θέση κράτησης).
- _Slack_ — URL webhook + κανάλι.
- _Discord_ — URL webhook.
- _Webhook_ — γενικό URL webhook + μυστικό υπογραφής.

Κάθε μπλοκ παρόχου εμφανίζει μια ετικέτα _Ενεργοποιημένο_ δίπλα στον τίτλο μόλις ο διακόπτης είναι ενεργός. Τα κουμπιά _Test_ εμφανίζουν toast.

### Κανόνες

Πίνακας κανόνων ειδοποίησης. Στήλες: Όνομα / Οικογένεια συμβάντων / Σοβαρότητα / Κανάλια / Κατάσταση / Ενέργειες (μενού 3 τελείες: Επεξεργασία / Αντιγραφή / Ενεργοποίηση-Απενεργοποίηση / Διαγραφή). Κάντε κλικ στο **+ Δημιουργία κανόνα** για να ανοίξετε το Rule Dialog — επιλέξτε όνομα, πεδίο εφαρμογής (παγκόσμιο / ζώνη / ρόλος), μία ή περισσότερες οικογένειες συμβάντων, σοβαρότητα (info / warning / critical), κανάλια και τη σημαία ενεργοποίησης.

Προκαθορισμένοι κανόνες: _Αποτυχίες πληρωμών_ (critical, οικογένεια πληρωμών, push+email+telegram) και _Όχημα εκτός σύνδεσης_ (warning, οικογένεια οχημάτων, push+email).

### Πρότυπα

Επιλέξτε οικογένεια συμβάντων + γλώσσα + κανάλι, στη συνέχεια επεξεργαστείτε τον τίτλο και το σώμα. Το σώμα υποστηρίζει θέσεις κράτησης (π.χ. `{{ride.id}}`, `{{amount}}`) που το μπλοκ **Προεπισκόπησης** επεκτείνει με ένα δείγμα συμβάντος. Το _Αποστολή δοκιμής_ εμφανίζει toast ότι μια δοκιμή αποστέλλεται στο επιλεγμένο κανάλι.

### Πολιτικές

Τέσσερα μπλοκ:

- _Κρίσιμη κλιμάκωση_ — αναδυόμενο μενού αλυσίδας (π.χ. push → email → telegram → SMS), χρονικό όριο επιβεβαίωσης σε λεπτά, διακόπτης απαίτησης απόδειξης ανάγνωσης.
- _Αυτόματη σίγαση_ — σίγαση επαναλήψεων: αν το ίδιο συμβάν ενεργοποιηθεί _Ν_ φορές σε _Μ_ λεπτά, σίγαση για _Κ_ λεπτά (τρεις αριθμητικές εισόδους). Μια συνοπτική φράση παρακάτω επαναλαμβάνει τον κανόνα.
- _Ασφάλεια κοινού_ — διακόπτης _Αποκλεισμός SMS εκτός ωρών ησυχίας_ (αντικαθιστά τις ώρες ησυχίας ανά κανάλι ειδικά για SMS).
- _Απόκρυψη δεδομένων_ — διακόπτης _Απόκρυψη προσωπικών δεδομένων σε εξωτερικά μηνύματα_; μια υπόδειξη εξηγεί τι αποκρύπτεται (τηλέφωνο, email, τελευταία 4 ψηφία καρτών κ.λπ.).

### Συνδρομές

Ένας πίνακας εγγραφών συνδρομής. Κάθε γραμμή συνδέει έναν στόχο (ένα Ρόλο ή έναν συγκεκριμένο Χρήστη) με μία ή περισσότερες οικογένειες εκδηλώσεων και κανάλια — π.χ. _Ρόλος: Διαχειριστής → σύστημα + πληρωμές → push + email_. Το κουμπί **+ Δημιουργία** ανοίγει διάλογο συνδρομής· το μενού της γραμμής έχει Επεξεργασία / Διαγραφή.

Χρησιμοποιήστε τις Συνδρομές για να παραδίδετε ειδοποιήσεις σε άτομα που δεν ταιριάζουν με κανένα καρφιτσωμένο κανάλι σε έναν Κανόνα — οι Κανόνες ορίζουν _τι_ να ειδοποιηθεί, οι Συνδρομές ορίζουν _ποιος_ το ακούει.

### Καταγραφές

Πίνακας μόνο για ανάγνωση με προσπάθειες παράδοσης. Στήλες: Ώρα / Εκδήλωση / Διαδρομή / Κανάλι / Παραλήπτης / Κατάσταση (απεστάλη / επιβεβαιώθηκε / απέτυχε) / Καθυστέρηση. Κάντε κλικ σε μια γραμμή για να ανοίξετε μια λεπτομερή ειδοποίηση (πρόχειρο για πλήρη πίνακα λεπτομερειών). Χρησιμοποιήστε το για να επιβεβαιώσετε ότι μια ειδοποίηση όντως στάλθηκε ή για να εντοπίσετε σφάλμα παρόχου.

## Οικογένειες εκδηλώσεων

Οι Κανόνες, τα Πρότυπα και οι Συνδρομές βασίζονται στην ίδια σταθερή λίστα οικογενειών εκδηλώσεων (ορισμένη στο `models/channels.ts`):

`authProfile` · `dashboard` · `vehicles` · `rides` · `payments` · `marketing` · `rebalance` · `support` · `maintenance` · `settings` · `system`

Αυτές αντιστοιχούν περίπου στους τομείς του Πίνακα ελέγχου — επιλέξτε την οικογένεια που ταιριάζει με τον τύπο της εκδήλωσης για την οποία θέλετε να ειδοποιήσετε.

## Ροές εργασίας

- **Ρυθμίστε ειδοποιήσεις email** — Καρτέλα Παρόχων → ενεργοποιήστε Email → επιλέξτε τύπο παρόχου → επικολλήστε το κλειδί API → αποθήκευση → επιστροφή στην καρτέλα Κανάλια → ενεργοποιήστε το κανάλι Email → ολοκληρώθηκε.
- **Λάβετε ειδοποίηση όταν αποτυγχάνουν πληρωμές** — Καρτέλα Κανόνων → επεξεργασία _Αποτυχίες πληρωμών_ → βεβαιωθείτε ότι η σοβαρότητα είναι `critical` και τα κανάλια περιλαμβάνουν αυτά που παρακολουθείτε → αποθήκευση.
- **Αποφύγετε spam SMS τη νύχτα** — Καρτέλα Πολιτικών → ενεργοποιήστε _Αποκλεισμός SMS εκτός ωρών ησυχίας_ → ορίστε τις ώρες ησυχίας ανά κανάλι στην καρτέλα Κανάλια.
- **Στείλτε ημερήσια περίληψη αντί για ειδοποιήσεις** — Καρτέλα Κανάλια → κάρτα Περίληψη → ορίστε συχνότητα σε _καθημερινά_, ώρα π.χ. 09:00.
- **Προσθέστε νέο ρόλο εφημερίας** — Καρτέλα Συνδρομών → + Δημιουργία → επιλέξτε ρόλο → οικογένειες εκδηλώσεων → κανάλια → αποθήκευση. Θα λαμβάνουν μελλοντικές ειδοποιήσεις που ταιριάζουν.
- **Εντοπίστε χαμένη ειδοποίηση** — Καρτέλα Καταγραφών → βρείτε την εκδήλωση με βάση διαδρομή ή ώρα → αν η κατάσταση είναι `failed`, πηγαίνετε στους Παρόχους για έλεγχο διαπιστευτηρίων· αν `sent` αλλά ο χρήστης δεν την είδε, ελέγξτε Συνδρομές / ώρες ησυχίας / κατάσταση σίγασης.

## Συμβουλές

- **Μόνο για front-end προς το παρόν.** Η αποθήκευση εμφανίζει ειδοποίηση αλλά το API δεν υπάρχει ακόμα — θεωρήστε αυτή τη σελίδα ως προδιαγραφή, όχι ως πηγή αλήθειας.
- **Τα κουμπιά δοκιμής είναι υποκατάστατα.** _Δοκιμή όλων_, _Σίγαση 1 ώρα_, ανά κανάλι _Δοκιμή_ και η επιβεβαίωση _Συντήρησης_ απλώς εμφανίζουν ειδοποίηση — δεν στέλνουν πραγματικά δοκιμαστικά μηνύματα ή δεν σιγάζουν τίποτα.
- **Ο χάρτης σοβαρότητας είναι η εναλλακτική.** Η λίστα _Κανάλια_ ενός Κανόνα υπερισχύει όταν οριστεί· μόνο αν είναι κενή ή μη ορισμένη χρησιμοποιείται ο χάρτης σοβαρότητας.
- **Η Περίληψη είναι ξεχωριστή από τις ειδοποιήσεις ανά εκδήλωση.** Η ενεργοποίηση της περίληψης δεν σιγάζει τις μεμονωμένες ειδοποιήσεις — απλώς προσθέτει την περιοδική σύνοψη.
- **Οι Συνδρομές μπορούν να στοχεύουν χρήστη**, όχι μόνο ρόλο. Χρησιμοποιήστε το για μεμονωμένες κλιμακώσεις (π.χ. _ο υπεύθυνος νυχτερινής βάρδιας λαμβάνει όλες τις ειδοποιήσεις `rides` μέσω push_) χωρίς να δημιουργήσετε ρόλο.
- **Η διάταξη για κινητά είναι σκόπιμα μόνο για ανάγνωση.** Όλες οι καρτέλες σε κινητά λένε _Χρησιμοποιήστε επιτραπέζιο για πλήρη ρύθμιση_ — η ειδοποίηση είναι διοικητική εργασία που απαιτεί επιτραπέζιο.
- **Η απόκρυψη προσωπικών δεδομένων είναι σημαντική για SMS/email.** Αν είναι απενεργοποιημένη, το περιεχόμενο των ειδοποιήσεων μπορεί να διαρρεύσει αριθμούς τηλεφώνου ή αποσπάσματα καρτών σε εξωτερικούς παρόχους — αφήστε την ενεργοποιημένη εκτός αν έχετε συγκεκριμένο λόγο.
