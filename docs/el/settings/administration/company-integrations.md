# Πληρωμές & Ενσωματώσεις

Οι καρτέλες **Πληρωμές** και **Ενσωματώσεις** στη σελίδα [Η εταιρεία μου](my-company.md) (`/settings/my-company`, **Λειτουργία για προχωρημένους**) είναι όπου αποθηκεύονται τα διαπιστευτήρια τρίτων: οι πύλες πληρωμών που χρεώνουν τους αναβάτες σας και οι ενσωματώσεις υπηρεσιών που υποστηρίζουν τις συνδέσεις, τα μηνύματα και τον βοηθό AI.

Στη Λειτουργία για προχωρημένους, η Η εταιρεία μου έχει τέσσερις καρτέλες — Προφίλ, Ρυθμίσεις Εφαρμογής, **Πληρωμές**, **Ενσωματώσεις**. Αυτό το άρθρο καλύπτει τις δύο τελευταίες.

## Καρτέλα Πληρωμές

1. **Επιλέξτε το νόμισμα της εταιρείας** — εδώ γίνεται η επεξεργασία του νομίσματος (και του σχετικού συμβόλου), **όχι στην καρτέλα Προφίλ**. Το αναπτυσσόμενο μενού προσφέρει 16 κωδικούς: USD, EUR, GBP, CHF, RON, MDL, GEL, UAH, RUB, TRY, PLN, CZK, HUF, BGN, ILS, AED.
2. **Διαμορφώστε μία κάρτα ανά πάροχο πληρωμών** — **maib**, **mia**, **Stripe**.
3. Κάθε κάρτα έχει ένα διακόπτη **ενεργοποιημένο**, τα δικά της πεδία διαπιστευτηρίων και ένα πλαίσιο επιλογής **προεπιλογής**.

Ακριβώς **ένας πάροχος λειτουργεί ως προεπιλογή** για νέες χρεώσεις, και πρέπει να είναι ένας από τους ενεργοποιημένους/υποστηριζόμενους παρόχους.

## Καρτέλα Ενσωματώσεις

Πέντε κάρτες, καθεμία με το δικό της διακόπτη ενεργοποίησης και διαπιστευτήρια:

| Κάρτα         | Διαπιστευτήρια                                    | Υποστηρίζει                  |
| ------------ | ------------------------------------------------ | ---------------------------- |
| **Telegram** | token bot, όνομα χρήστη bot                       | Σύνδεση / μηνύματα Telegram  |
| **WhatsApp** | αναγνωριστικό επιχειρηματικού λογαριασμού, αναγνωριστικό αριθμού τηλεφώνου, access token | Σύνδεση / μηνύματα WhatsApp  |
| **Google**   | client ID, client secret                          | Σύνδεση Google για αναβάτες  |
| **Apple**    | client ID, team ID, key ID, ιδιωτικό κλειδί      | Σύνδεση Apple για αναβάτες   |
| **OpenAI**   | API key                                           | Ο βοηθός AI του Πίνακα ελέγχου |

## Κάθε κάρτα αποθηκεύεται ξεχωριστά

Κάθε κάρτα παρόχου πληρωμών και ενσωμάτωσης **αποθηκεύεται ανεξάρτητα** — καμία δεν αποτελεί μέρος της αποθήκευσης ολόκληρης της σελίδας. Η αποθήκευση της καρτέλας Προφίλ ή Ρυθμίσεων Εφαρμογής δεν αποθηκεύει αυτές τις κάρτες, και το αντίστροφο. **Αποθηκεύστε κάθε κάρτα που αλλάξατε.**

## Σχέση με τις μεθόδους σύνδεσης αναβατών

Οι μέθοδοι αυθεντικοποίησης στην καρτέλα Ρυθμίσεις Εφαρμογής για Google, Apple, Telegram και WhatsApp λειτουργούν μόνο αφού η **αντίστοιχη κάρτα Ενσωματώσεων είναι ενεργοποιημένη και διαμορφωμένη**. Διαμορφώστε πρώτα την ενσωμάτωση και μετά ενεργοποιήστε τη μέθοδο σύνδεσης.

## Μυστικά

- Τα πεδία μυστικών είναι **οπτικά κρυμμένα** με τρόπο που αποτρέπει επίσης τους διαχειριστές κωδικών του προγράμματος περιήγησης από το να προσπαθήσουν να τα καταγράψουν ή να τα συμπληρώσουν αυτόματα.
- **Κατά την αλλαγή ενός μυστικού, επανεισάγετε ολόκληρη την τιμή σκόπιμα** αντί να βασίζεστε στο κρυμμένο δείγμα.

## Telegram: δύο διαφορετικές ρυθμίσεις

Ξεχωριστά από την κάρτα Ενσωματώσεων Telegram, υπάρχει μια ροή **ανακάλυψης Telegram OTP-bot**: εισάγετε ένα token bot, κάντε κλικ στο **Έλεγχος Συνομιλιών** και επιλέξτε μια συνομιλία από το αναπτυσσόμενο μενού που γεμίζει. Αυτή η ροή εξυπηρετεί την παράδοση κωδικού μίας χρήσης και είναι μια **διαφορετική ρύθμιση** από την κάρτα Ενσωματώσεων Telegram — η διαμόρφωση της μίας δεν διαμορφώνει την άλλη.

## Συχνές ερωτήσεις

- **Άλλαξα ένα διαπιστευτήριο αλλά δεν έγινε καμία αλλαγή.** Κάθε κάρτα αποθηκεύεται ξεχωριστά — επιβεβαιώστε ότι αποθηκεύσατε αυτήν την συγκεκριμένη κάρτα, όχι μόνο τη σελίδα.
- **Η κοινωνική σύνδεση δεν είναι διαθέσιμη στους αναβάτες.** Η κάρτα παρόχου πρέπει να είναι ενεργοποιημένη και διαμορφωμένη εδώ πριν λειτουργήσει η αντίστοιχη μέθοδος σύνδεσης στις Ρυθμίσεις Εφαρμογής.
- **Δεν μπορώ να επιλέξω προεπιλεγμένο πάροχο πληρωμών.** Η προεπιλογή μπορεί να επιλεγεί μόνο από τους παρόχους που είναι πραγματικά διαμορφωμένοι ως υποστηριζόμενοι.
- **Πού είναι το πεδίο νομίσματος;** Στην καρτέλα Πληρωμές — όχι στην καρτέλα Προφίλ.
- **Το "Έλεγχος Συνομιλιών" αποτυγχάνει με έγκυρο token.** Θεωρήστε το αρχικά ως πρόβλημα περιβάλλοντος/σύνδεσης αντί να υποθέσετε ότι το token είναι λάθος.
