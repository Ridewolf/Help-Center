# Τοπικοποίηση

Η σελίδα Τοπικοποίησης (`/settings/localization`) είναι το **εργαστήριο μετάφρασης** — μια βιβλιοθήκη _Συλλογών_ (ομάδες σχετικών κλειδιών μετάφρασης) που επεξεργάζεστε, εισάγετε, εξάγετε και δημοσιεύετε. Κάθε συλλογή έχει ένα namespace (π.χ. `ui`, `auth`, `rides`), μια βασική γλώσσα (πάντα `en`), ένα σύνολο γλωσσών-στόχων και μια λίστα κλειδιών με τιμές ανά γλώσσα.

> _Σημείωση_: αυτή η σελίδα είναι προς το παρόν **πρωτότυπο μόνο για το front-end** — οι συλλογές φορτώνονται από το `mockData.ts` και διατηρούνται στην τοπική κατάσταση. Οι ενέργειες _Αποθήκευσης_ και _Δημοσίευσης_ εμφανίζουν επιβεβαιωτικά μηνύματα αλλά δεν υπάρχει ακόμα backend endpoint. Η σελίδα είναι ασφαλής για χρήση ως προδιαγραφή για το API· τίποτα από όσα κάνετε εδώ δεν αποθηκεύεται.

Απαιτούμενη άδεια: δεν ορίζονται συγκεκριμένα `requiredPermissions` στη διαδρομή — οποιοσδήποτε συνδεδεμένος χειριστής μπορεί να την ανοίξει.

## Διάταξη σελίδας

Μια ενιαία γραμμή κεφαλίδας με τον τίτλο της σελίδας, ένα πλαίσιο αναζήτησης, ένα αναδυόμενο μενού _Εισαγωγή / Εξαγωγή_ και ένα κουμπί _+ Δημιουργία συλλογής_ — ακολουθεί μια κάρτα Φίλτρων και ο πίνακας Συλλογών.

Αναφορικά δεδομένα (προς το παρόν σκληροκωδικοποιημένα στο `Localization.vue`):

- Γλώσσες: `en`, `ro`, `ru`, `de`, `fr`, `es` (βασική + 5 στόχοι)
- Namespaces: `ui`, `auth`, `rides`, `payments`, `marketing`
- Ετικέτες: `core`, `beta`, `promo`, `legacy`

## Φίλτρα

Μια κάρτα Φίλτρων βρίσκεται πάνω από τον πίνακα.

| Φίλτρο   | Τύπος          | Σημειώσεις                                                                                 |
| -------- | -------------- | ----------------------------------------------------------------------------------------- |
| Γλώσσα   | Αναδυόμενο     | Φιλτράρει συλλογές που περιλαμβάνουν αυτή τη γλώσσα. Προεπιλογή `ro`                      |
| Namespace| Αναδυόμενο     | Ένα από τη λίστα namespace (ή κενό για όλες)                                            |
| Κατάσταση| Αναδυόμενο     | `all`, `active`, `draft`, `archived`                                                     |
| Ετικέτες | Επιλογείς      | Επιλογή πολλαπλών ετικετών — μια συλλογή πρέπει να έχει _όλες_ τις επιλεγμένες ετικέτες   |
| Αναζήτηση| Κείμενο (γραμμή εργαλείων) | Καθυστέρηση 300 ms — ταιριάζει με όνομα, περιγραφή, namespace                      |

Ένα κουμπί _Καθαρισμός_ στην κάρτα Φίλτρων επαναφέρει και τα τέσσερα φίλτρα.

## Πίνακας Συλλογών

| Στήλη     | Ταξινομήσιμη; | Περιεχόμενο                                                                                                         |
| --------- | ------------- | ------------------------------------------------------------------------------------------------------------------ |
| Συλλογή   | —             | Όνομα + περιγραφή μιας γραμμής                                                                                      |
| Namespace | —             | Σήμα με το string του namespace                                                                                     |
| Γλώσσες   | —             | Σήμα ανά γλώσσα. Η βασική γλώσσα έχει την πρωτεύουσα παραλλαγή· οι στόχοι είναι δευτερεύουσες. Το hover δείχνει _base_ vs _target_ |
| Κλειδιά   | —             | Συνολικός αριθμός κλειδιών. Το hover δείχνει ανάλυση ανά σημαία (_missing_, _changed_, _obsolete_)                   |
| Κατάσταση | —             | Σήμα — `active` / `draft` / `archived`                                                                             |
| Ενημερώθηκε | —           | Σχετική ημερομηνία. Το hover δείχνει τον δημιουργό                                                                    |
| Ενέργειες | —             | Μενού με τρεις τελείες ανά γραμμή                                                                                   |

Σελιδοποίηση στο κάτω μέρος: _Προηγούμενο / Επόμενο_, συνολικός αριθμός και επιλογέας ανά σελίδα (10 / 20 / 50).

### Ενέργειες γραμμής

| Ενέργεια  | Τι κάνει                                                                                  |
| --------- | ----------------------------------------------------------------------------------------- |
| Προβολή  | Ανοίγει το παράθυρο Συλλογής σε λειτουργία μόνο-ανάγνωσης _view_                         |
| Επεξεργασία | Ανοίγει το παράθυρο Συλλογής σε λειτουργία _edit_                                      |
| Διπλότυπο | Κλωνοποιεί τη συλλογή με κατάληξη " (Copy)" στην κορυφή της λίστας                     |
| Εισαγωγή | Ανοίγει το παράθυρο Συλλογής εστιάζοντας στην καρτέλα _Εισαγωγή / Εξαγωγή_ σε λειτουργία εισαγωγής |
| Εξαγωγή | Εμφανίζει μήνυμα — κράτημα θέσης για λήψη της συλλογής σε επιλεγμένη μορφή                |
| Αρχειοθέτηση | Αλλάζει την κατάσταση σε `archived` (η γραμμή παραμένει — φιλτράρετε με Κατάσταση για να δείτε τα αρχειοθετημένα) |
| Διαγραφή | Αφαιρεί τη γραμμή από τη τοπική λίστα                                                  |

## Δημιουργία / Επεξεργασία / Προβολή — το παράθυρο Συλλογής

Ανοίγει από το + Δημιουργία ή από οποιαδήποτε ενέργεια γραμμής. Τέσσερις καρτέλες μέσα στο παράθυρο.

### Καρτέλα Επισκόπησης

Επεξεργαστείτε τα μεταδεδομένα της συλλογής.

- _Όνομα_ (απαραίτητο) — εμφανιζόμενο όνομα (π.χ. "UI Labels").
- _Namespace_ — επιλογέας με πεδίο αναζήτησης.
- _Περιγραφή_ — σύντομη περιγραφή.
- _Βασική γλώσσα_ — μόνο για ανάγνωση, πάντα `en`.
- _Γλώσσες στόχοι_ — εναλλασσόμενες ετικέτες από τις πέντε μη αγγλικές επιλογές. Η βασική + οι στόχοι μαζί αποτελούν τις στήλες γλωσσών στην καρτέλα Κλειδιά.
- _Κατάσταση_ — `active` / `draft` / `archived`.
- _Ετικέτες_ — εναλλασσόμενες ετικέτες από τη λίστα ετικετών.

### Καρτέλα Κλειδιών

Το πραγματικό πλέγμα μετάφρασης.

- Γραμμή εργαλείων: πλαίσιο αναζήτησης (ταιριάζει με όνομα κλειδιού και οποιαδήποτε τιμή), φίλτρο κατάστασης (π.χ. _Μόνο ελλείποντα_), επιλογέας γλώσσας (ποια στήλη στόχου επισημαίνεται ως εστία επεξεργασίας).
- Μαζικές ενέργειες όταν επιλέγονται κλειδιά: _Ορισμός κατάστασης_, _Καθαρισμός τιμών_, _Εξαγωγή επιλεγμένων_, _Διαγραφή_.
- Ενέργειες ανά γραμμή: διπλότυπο κλειδί, διαγραφή κλειδιού, αντιγραφή από Αγγλικά (γεμίζει τον τρέχοντα στόχο με την τιμή EN), επικύρωση θέσεων κράτησης (ελέγχει ότι στοιχεία όπως `{{name}}` στα EN διατηρούνται στον στόχο).
- Κάθε γραμμή φέρει προαιρετικές σημαίες που εμφανίζονται ως σήματα:

| Σημαία     | Σημασία                                                        |
| ---------- | -------------------------------------------------------------- |
| `new`      | Κλειδί προστέθηκε πρόσφατα — χρειάζεται ανθρώπινη ανασκόπηση    |
| `changed`  | Η τιμή EN άλλαξε από την τελευταία μετάφραση — οι στόχοι μπορεί να είναι παρωχημένοι |
| `missing`  | Κενή τιμή σε τουλάχιστον μία γλώσσα στόχο                      |
| `obsolete` | Το κλειδί δεν χρησιμοποιείται πλέον στον κώδικα — ασφαλές για διαγραφή |

- _Προσθήκη κλειδιού_ και _Εύρεση & αντικατάσταση_ ανοίγουν αφιερωμένα μικρά παράθυρα διαλόγου.
- Διακόπτης _Αυτόματη αποθήκευση_ — όταν είναι ενεργός, οι αλλαγές σε μια τιμή δεσμεύονται αμέσως στην τοπική κατάσταση.

### Καρτέλα Εισαγωγής / Εξαγωγής

Εισαγωγή:

- _Μορφή_ — JSON / CSV / XLSX.
- _Λειτουργία_ — αντικατάσταση υπαρχουσών τιμών / συγχώνευση / προσθήκη.
- Διακόπτης _Διατήρηση άγνωστων κλειδιών_ — όταν είναι απενεργοποιημένος, τα κλειδιά που δεν υπάρχουν στο εισαγόμενο αρχείο σημαίνονται ως `obsolete`.
- _Προσομοίωση_ — δοκιμαστική εκτέλεση που αναφέρει τι θα άλλαζε (χωρίς εγγραφές).
- _Εφαρμογή_ — δεσμεύει την εισαγωγή. Εμφανίζεται μπάρα προόδου κατά την εκτέλεση.

Εξαγωγή:

- _Μορφή_ — JSON / CSV / XLSX.
- _Εύρος_ — όλα τα κλειδιά / φιλτραρισμένα κλειδιά / επιλεγμένα κλειδιά.
- _Λήψη_ — προσωρινή ενέργεια (προς το παρόν ειδοποίηση).

### Καρτέλα Δημοσίευσης

- Ένα συνοπτικό μπλοκ: _Σύνολο N κλειδιών / M αλλαγμένα / K λείπουν_.
- Λίστα με τα αλλαγμένα κλειδιά με τιμές πριν / μετά.
- Λίστα προειδοποιήσεων (π.χ. ασυμφωνία placeholder, λείπει στόχος).
- _Αποθήκευση πρόχειρου_ — αποθηκεύει το τρέχον αντίγραφο ως πρόχειρο (`status = draft`).
- _Δημοσίευση_ — προωθεί το πρόχειρο σε `active` και εμφανίζει ειδοποίηση.

## Επάνω γραμμή εργαλείων — Μενού Εισαγωγής / Εξαγωγής

Δύο παγκόσμιες συντομεύσεις στην κεφαλίδα της σελίδας (ξεχωριστές από τις ενέργειες ανά συλλογή):

- _Εισαγωγή συλλογών_ — ανοίγει το παράθυρο εισαγωγής σε επίπεδο σελίδας (μαζική εισαγωγή πολλαπλών συλλογών ταυτόχρονα).
- _Εξαγωγή όλων_ — συντόμευση για εξαγωγή κάθε συλλογής σε ένα πακέτο (προς το παρόν ειδοποίηση).

## Μη αποθηκευμένες αλλαγές & προστασία πλοήγησης

Υπάρχει μια παγκόσμια σημαία "μη αποθηκευμένων αλλαγών" (`hasUnsavedGlobal`) — όταν είναι ενεργή, εμφανίζεται ένα σταθερό υποσέλιδο με _Απόρριψη_ / _Αποθήκευση_. Η σελίδα εγκαθιστά επίσης έναν `router.beforeEach` φρουρό: η προσπάθεια πλοήγησης με μη αποθηκευμένες αλλαγές ενεργοποιεί το εγγενές παράθυρο _επιβεβαίωσης_ του προγράμματος περιήγησης.

## Ροές εργασίας

- **Μετάφραση νέου κλειδιού στα Ρουμανικά** — Επιλέξτε τη συλλογή από τον πίνακα → Επεξεργασία → Καρτέλα Κλειδιών → ορίστε τον επιλογέα γλώσσας σε `ro` → βρείτε το κλειδί (ή _Προσθήκη κλειδιού_) → συμπληρώστε την τιμή → _Αποθήκευση_ (ή ενεργοποιήστε την Αυτόματη αποθήκευση).
- **Έλεγχος τι λείπει στα Γαλλικά** — Επεξεργασία συλλογής → Καρτέλα Κλειδιών → φίλτρο κατάστασης _Μόνο λείποντα_ → γλώσσα _fr_. Χρησιμοποιήστε _Αντιγραφή από Αγγλικά_ ως γρήγορη λύση, ή _Επικύρωση placeholder_ πριν τη δημοσίευση.
- **Μαζική ενημέρωση από XLSX** — Επεξεργασία συλλογής → Καρτέλα Εισαγωγής / Εξαγωγής → επιλέξτε XLSX, λειτουργία _Συγχώνευση_, πρώτα _Προσομοίωση_ → ελέγξτε τη διαφορά → _Εφαρμογή_.
- **Προώθηση πρόχειρων κειμένων σε παραγωγή** — Επεξεργασία συλλογής → Καρτέλα Δημοσίευσης → επιβεβαιώστε τη λίστα αλλαγμένων κλειδιών, διορθώστε τυχόν προειδοποιήσεις → _Δημοσίευση_.
- **Δημιουργία παραλλαγής για νέα αγορά** — Αντιγραφή συλλογής → μετονομασία → προσθήκη νέας γλώσσας στα _Γλώσσες στόχου_ → μετάφραση.
- **Αρχειοθέτηση παρωχημένου σετ** — Μενού γραμμής → Αρχειοθέτηση. Η συλλογή παραμένει στον πίνακα αλλά μετακινείται σε κατάσταση `archived`; φιλτράρετε κατά Κατάσταση για να τη βρείτε αργότερα.

## Συμβουλές

- **Μόνο front-end προς το παρόν.** Τίποτα εδώ δεν φτάνει ακόμα στο backend — οι ενέργειες `Αποθήκευση`, `Δημοσίευση`, `Εξαγωγή`, `Διαγραφή`, `Αρχειοθέτηση` είναι όλες μεταβολές τοπικής κατάστασης + ειδοποιήσεις. Μην βασίζεστε σε αυτό για πραγματικά κείμενα παραγωγής μέχρι να κυκλοφορήσει το API.
- **Η βασική γλώσσα είναι κλειδωμένη.** Το `en` είναι πάντα η βάση — οι μη αγγλικές συλλογές πρέπει να δημιουργούνται ως γλώσσες στόχου μιας συλλογής με βάση τα Αγγλικά, όχι ανεξάρτητα.
- **Οι ετικέτες χρησιμοποιούν λογική ΚΑΙ.** Φιλτράρισμα με δύο ετικέτες σημαίνει ότι η συλλογή πρέπει να έχει _και τις δύο_ ετικέτες. Για αναζήτηση με οποιαδήποτε, καθαρίστε μία από τις ετικέτες.
- **Ο φρουρός πλοήγησης είναι παγκόσμιος.** Ακόμα και όταν μόνο ένα παράθυρο διαλόγου είναι βρώμικο, η έξοδος από τη σελίδα ζητά επιβεβαίωση — αποθηκεύστε ή απορρίψτε ρητά για να παραλείψετε την προτροπή.
- **Η επικύρωση placeholder είναι φίλος σας** — η εκτέλεσή της πριν τη Δημοσίευση εντοπίζει λάθη τύπου "χάσαμε το `{{name}}` στη μετάφραση" που σπάνε το εμφανιζόμενο κείμενο κατά την εκτέλεση.
- **Μην το συγχέετε με την καρτέλα Locale στο [General](general.md)** — εκείνη η καρτέλα ορίζει προεπιλογές (ποιες γλώσσες είναι _ενεργοποιημένες_, μορφές ημερομηνίας / ώρας / μονάδων). Αυτή η σελίδα είναι όπου ζουν τα πραγματικά μεταφρασμένα κείμενα.
- **Τα δεδομένα αναφοράς είναι ψεύτικα.** Γλώσσες, namespaces και ετικέτες είναι προς το παρόν σκληροκωδικοποιημένα — όταν κυκλοφορήσει το backend, αναμένετε να προέρχονται από το API και πιθανώς να είναι επεξεργάσιμα.
