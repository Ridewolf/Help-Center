# Γενικά

Η σελίδα Γενικά (`/settings/general`) είναι ο **πίνακας ελέγχου σε επίπεδο συστήματος** — ένα σημείο για να ορίσετε τις προεπιλογές που διέπουν την εφαρμογή rider, τον στόλο, τις τιμές, τις διαδρομές, τις ειδοποιήσεις και τις ρυθμίσεις επιπέδου προγραμματιστή. Όλα εδώ εφαρμόζονται παγκοσμίως σε ολόκληρη την εταιρεία· οι παρακάμψεις ανά όχημα ή ανά τιμολόγιο βρίσκονται στις [Ρυθμίσεις Οχήματος](../infrastructure/vehicle-settings.md) και [Τιμολόγια Οχημάτων](../infrastructure/vehicle-tariffs.md).

> _Σημείωση_: αυτή η σελίδα είναι προς το παρόν **μόνο οθόνη frontend** — κάθε τιμή κρατιέται σε τοπική κατάσταση και το κουμπί **Αποθήκευση** απλώς εμφανίζει μια επιβεβαίωση toast. Δεν αποστέλλονται δεδομένα στο backend ακόμα. Θεωρήστε το ως το UI προδιαγραφής / staging για το επερχόμενο API.

Η διαδρομή `/settings/general-settings` είναι ένα ξεχωριστό, σχεδόν κενό **placeholder** με μια μόνο εικόνα και επικεφαλίδα. Η πραγματική οθόνη ρύθμισης είναι το `/settings/general` (αυτό το άρθρο) — εκεί ζουν όλες οι έξι καρτέλες.

Απαιτούμενη άδεια: δεν έχουν οριστεί συγκεκριμένα `requiredPermissions` στον δρομολογητή — οποιοσδήποτε συνδεδεμένος χειριστής μπορεί να ανοίξει τη σελίδα.

## Καρτέλες

Η σελίδα έχει έξι καρτέλες στην κορυφή (επιτραπέζιος υπολογιστής). Σε κινητό, οι ίδιες καρτέλες συμπτύσσονται σε ένα ακκορντεόν που λέει απλώς _Χρησιμοποιήστε επιτραπέζιο υπολογιστή για πλήρη ρύθμιση_ — αυτές οι ρυθμίσεις προορίζονται μόνο για διαχειριστές.

| Καρτέλα       | Εικονίδιο   | Τι καλύπτει                                                                                           |
| ------------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| Εφαρμογή      | sliders     | Έλεγχος ενημερώσεων εφαρμογής, προεπιλεγμένη ορατότητα μονάδων, σημαίες λειτουργιών, όρια ρυθμού, προεπιλογές οχημάτων |
| Τοπικοποίηση  | globe       | Προεπιλεγμένη γλώσσα, ζώνη ώρας, ενεργοποιημένες γλώσσες, μορφές ημερομηνίας / ώρας / μονάδων, πάροχος χάρτη + στυλ ζώνης |
| Τιμολόγηση   | dollar sign | Προεπιλογές τιμολόγησης, πρότυπα τιμολογίων, πολιτική εκπτώσεων/προωθήσεων, προεπιλογές συνδρομών    |
| Διαδρομές    | car         | Κανόνες κράτησης + διαδρομής, αυτόματη παύση/στάση, ποινές, επεξεργασία πληρωμών                      |
| Ειδοποιήσεις | bell        | Εναλλαγές καναλιών (push / email / SMS) και πρότυπα μηνυμάτων για γεγονότα rider                      |
| Για προχωρημένους | code    | Ενσωματώσεις, ασφάλεια, διατήρηση απορρήτου, νομικές σελίδες, σημαίες προγραμματιστή, συντήρηση συστήματος |

Ένα σταθερό υποσέλιδο με **Απόρριψη** και **Αποθήκευση αλλαγών** εμφανίζεται στο κάτω μέρος μόνο αφού αλλάξετε πραγματικά κάποιο πεδίο — η σελίδα χρησιμοποιεί `useFormState` για να συγκρίνει με το φορτωμένο στιγμιότυπο.

## Ενότητες ανά καρτέλα

### Εφαρμογή

Δύο κάρτες στοιβαγμένες.

**Προεπιλογές εφαρμογής**

- _Απαίτηση ενημέρωσης εφαρμογής_ — διακόπτης + πεδίο κειμένου για ελάχιστη έκδοση (απενεργοποιημένο μέχρι να ενεργοποιηθεί ο διακόπτης). Αν είναι ενεργό, η εφαρμογή rider θα μπλοκάρει χρήστες με παλαιότερη έκδοση.
- _Προεπιλεγμένη ορατότητα μονάδων_ — τέσσερις διακόπτες (Μάρκετινγκ, Εξισορρόπηση, Υποστήριξη, Αναλυτικά στοιχεία) που ορίζουν ποιες μονάδες βλέπουν οι νέοι χειριστές.
- _Σημαίες λειτουργιών_ — τέσσερις διακόπτες (Ζωντανή παρακολούθηση, Προχωρημένα στατιστικά, Πολλαπλά νομίσματα, White-label).
- _Όριο ρυθμού API_ / _Όριο ρυθμού UI_ — αριθμητικά πεδία (προεπιλογές 1000 / 100 αιτ./λεπτό).

**Προεπιλογές οχήματος**

- _Προεπιλεγμένο σετ εικονιδίων_ — αναζητήσιμο αναπτυσσόμενο με ονόματα σετ εικονιδίων (προς το παρόν τέσσερα σκληροκωδικοποιημένα mock: Προεπιλεγμένα Εικονίδια / Σύγχρονο Σετ / Μινιμαλιστικό / Έντονο Χρώμα· η πραγματική λίστα θα προέρχεται από [Σετ Εικονιδίων](../content/icon-sets.md)).
- _Όρια μπαταρίας_ — δύο αριθμητικά πεδία (Χαμηλό %, Κρίσιμο %). Η επικύρωση γίνεται κατά την Αποθήκευση: το κρίσιμο πρέπει να είναι χαμηλότερο από το χαμηλό αλλιώς θα λάβετε σφάλμα toast.
- _Βάρη βαθμολογίας υγείας_ — τρία ποσοστά (σήμα / σφάλματα / μπαταρία). Επικυρώνονται να αθροίζουν 100 κατά την Αποθήκευση.
- _Αυτόματες ετικέτες_ — συμβολοσειρά με κόμματα από ετικέτες που εφαρμόζονται αυτόματα σε ολοκαίνουργια οχήματα.

### Τοπικοποίηση

- _Προεπιλεγμένη γλώσσα_ / _Ζώνη ώρας_ — επιλογή.
- _Ενεργοποιημένες γλώσσες_ — πολλαπλές επιλογές με chip· X για αφαίρεση.
- _Έναρξη εβδομάδας_ — Δευτέρα / Κυριακή.
- _Μορφή ημερομηνίας_ — DD/MM/YYYY, MM/DD/YYYY, ISO, κ.ά.
- _Μορφή ώρας_ — 12ωρη / 24ωρη.
- _Μονάδα θερμοκρασίας_ — Κελσίου / Φαρενάιτ.
- _Μονάδα απόστασης_ — χλμ / μίλια.
- _Νόμισμα εμφάνισης_ — προεπιλογή EUR (TODO στον κώδικα: φόρτωση από API εταιρείας).
- _Στρογγυλοποίηση τιμής_ — καμία / πλησιέστερο 0,05 / κ.ά.

**Χάρτες** (ξεχωριστή κάρτα στην ίδια καρτέλα)

- _Πάροχος_ (προεπιλογή MapTiler) και _Στυλ_ (φωτεινό / σκοτεινό / δορυφορικό).
- _Κλειδί API_ — πεδίο κειμένου για το κλειδί του παρόχου.
- _Προεπιλεγμένο ζουμ_ + _Προεπιλεγμένο κέντρο_ — χρησιμοποιούνται όταν δεν υπάρχει GPS πλαίσιο.
- _Στυλ ζώνης_ — χρώμα + πλάτος περιγράμματος για πολύγωνα Στάθμευσης / Απαγορευμένης / Χαμηλής ταχύτητας / Πληρωμένης στάθμευσης. Οι επιλογείς χρησιμοποιούν παλέτα 12 χρωμάτων.
- _Όριο χαμηλής ταχύτητας_ — αριθμητικό (χλμ/ώρα).

### Τιμολόγηση

Τέσσερις κάρτες: _Προεπιλογές τιμολόγησης_, _Πρότυπα τιμολογίων_, _Εκπτώσεις & Προωθήσεις_, _Συνδρομές_. Αυτές ορίζουν **τιμές εφεδρείας** — η πραγματική τιμολόγηση διαδρομής παρακάμπτεται ανά όχημα μέσω των [Τιμολογίων Οχημάτων](../infrastructure/vehicle-tariffs.md).

- Προεπιλογές τιμολόγησης: τέλος ξεκλειδώματος, τιμή/λεπτό, τιμή/χλμ, πληρωμένη αναμονή, δωρεάν λεπτά κράτησης, έκπτωση δύο επιπέδων βάσει αριθμού διαδρομών.
- Πρότυπα τιμολογίων: ανά περίοδο (λεπτό / ώρα / ημέρα / εβδομάδα / μήνας / έτος) — τιμή, μέγιστη διάρκεια, διακόπτης δωρεάν στάθμευσης, διακόπτης ενεργοποίησης. Συν _επιτρέπεται η στοίβαξη_.
- Εκπτώσεις & Προωθήσεις: μέγιστο ποσοστό έκπτωσης %, πρόθεμα προώθησης (προεπιλογή `WOLF`), προεπιλεγμένες ημέρες ισχύος και κανόνες στοίβαξης.
- Συνδρομές: προεπιλεγμένο ποσοστό έκπτωσης, ημέρες δοκιμής, αυτόματη ανανέωση, επιτρεπτοί κωδικοί προώθησης.

### Διαδρομές

- Κανόνες κράτησης + διαδρομής: δωρεάν λεπτά κράτησης, μέγιστες ενεργές κρατήσεις ανά πελάτη, ελάχιστο υπόλοιπο για εκκίνηση, αυτόματη παύση + αυτόματη στάση (καθένα με ενεργοποίηση + όριο).
- Ποινές: δύο τύποι ποινών (Εκτός ζώνης, Ακατάλληλη στάθμευση) — κάθε μία με ποσό τέλους και μήνυμα προειδοποίησης.
- _Προεπιλεγμένος γρήγορος οδηγός_ — αναπτυσσόμενο από λίστα placeholder· θα προέρχεται από [Γρήγορους Οδηγούς](../content/quick-guides.md).
- _Προεπιλεγμένο σετ FAQ_ — αναπτυσσόμενο από [Σετ Συχνών Ερωτήσεων](../content/faq-sets.md).
- Κάρτα πληρωμών: 3-D Secure, τρόπος κράτησης (άμεσο / προέγκριση), ποσό προέγκρισης, διάρκεια κράτησης (ώρες), πολιτική επιστροφής, μέγιστο παράθυρο επιστροφής (ημέρες).

### Ειδοποιήσεις

- _Κανάλια_ — τρεις διακόπτες (Push / Email / SMS) — ελέγχει ποια κανάλια είναι διαθέσιμα στην εφαρμογή Rider.
- _Πρότυπα_ — τίτλος + κείμενο σώματος για τα τρία βασικά γεγονότα: Έναρξη διαδρομής, Ολοκλήρωση διαδρομής, Επιβολή ποινής. Μεταβλητές όπως `{{amount}}` / `{{reason}}` αντικαθίστανται από το backend.
- Ένα κουμπί **Δοκιμαστική ειδοποίηση** εμφανίζει ένα ενημερωτικό μήνυμα (χωρίς πραγματική αποστολή ακόμα).

Για τη **διαδικασία ειδοποίησης** που βλέπει ο χειριστής δείτε [Alerts & Notifications](alerts-notifications.md) — αυτή η καρτέλα εδώ αφορά την πλευρά της εφαρμογής Rider.

### Για προχωρημένους

Πέντε κάρτες.

- _Ενσωματώσεις_ — webhook endpoint + μυστικό, Google Analytics ID, Sentry DSN, συμβολοσειρές bot Telegram και Slack. Ένα κουμπί **Δοκιμή webhook** εμφανίζει μήνυμα.
- _Ασφάλεια_ — διακόπτης απαιτούμενου 2FA, χρονικό όριο συνεδρίας (λεπτά), πολιτική κωδικού (ελάχιστο μήκος + κεφαλαία/αριθμοί/ειδικοί χαρακτήρες), κλειδιά reCAPTCHA, λίστα επιτρεπόμενων IP, αναδυόμενο μενού περιορισμών εξαγωγής.
- _Απόρρητο_ — διατήρηση δεδομένων σε ημέρες (τηλεμετρία / μέσα / αρχεία καταγραφής), διακόπτης ανωνυμοποίησης GPS, SLA εξαγωγής και SLA διαγραφής σε ημέρες.
- _Νομικά_ — Όροι Υπηρεσίας + Πολιτική Απορρήτου ως πεδία κειμένου Markdown, συν συμβολοσειρά έκδοσης και ημερομηνία δημοσίευσης.
- _Προγραμματιστής / Για προχωρημένους_ — sandbox mode, επίπεδο καταγραφής, URLs παραγωγής + staging endpoints, διακόπτες πειραμάτων (AI δρομολόγηση, προγνωστική συντήρηση, δυναμική τιμολόγηση).
- _Σύστημα / Συντήρηση_ — διακόπτης λειτουργίας συντήρησης + κείμενο πανό + διακόπτης λειτουργίας μόνο για ανάγνωση.
- _Έλεγχος & Αντίγραφα ασφαλείας_ — κουμπιά _Δημιουργία αντιγράφου_ και _Διαγραφή όλων των δεδομένων_ (και τα δύο εμφανίζουν μηνύματα· το κουμπί διαγραφής λέει ότι _απαιτεί επιβεβαίωση διαχειριστή_ — δεν έχει υλοποιηθεί ακόμα).

## Ροές εργασίας

- **Κλείδωμα νέας έκδοσης** — Καρτέλα App → ενεργοποίηση _Απαιτείται ενημέρωση εφαρμογής_ → ορισμός ελάχιστης έκδοσης → Αποθήκευση. Οι χρήστες με παλαιότερες εκδόσεις λαμβάνουν ειδοποίηση ενημέρωσης.
- **Προσθήκη γλώσσας** — Καρτέλα Locale → _Ενεργές γλώσσες_ → επιλέξτε το chip γλώσσας → Αποθήκευση. Οι συμβολοσειρές πρέπει ακόμα να μεταφραστούν μέσω [Localization](localization.md).
- **Ρύθμιση της εμπειρίας ποινής χρήστη** — Καρτέλα Rides → ρυθμίστε το τέλος εκτός ζώνης + κείμενο προειδοποίησης → Αποθήκευση.
- **Παύση πλατφόρμας για συντήρηση** — Για προχωρημένους → _Σύστημα / Συντήρηση_ → ενεργοποιήστε το διακόπτη, επεξεργαστείτε το κείμενο πανό, προαιρετικά ορίστε λειτουργία μόνο για ανάγνωση → Αποθήκευση.
- **Εφαρμογή νέου στυλ χάρτη** — Locale → κάρτα _Χάρτες_ → επιλέξτε στυλ → ρυθμίστε τα χρώματα ζωνών → Αποθήκευση (οι αλλαγές εφαρμόζονται παγκοσμίως μόλις συνδεθεί το API).

## Συμβουλές

- **Μόνο front-end προς το παρόν.** Η αποθήκευση καταγράφει τοπικό στιγμιότυπο αλλά δεν καλεί κανένα backend endpoint — μην βασίζεστε σε αυτή τη σελίδα για να αποθηκεύσετε οτιδήποτε μέχρι να υλοποιηθεί το API.
- **Η επικύρωση γίνεται κατά την Αποθήκευση.** Τα όρια μπαταρίας (κρίσιμο < χαμηλό) και τα βάρη βαθμολογίας υγείας (άθροισμα 100) ελέγχονται όταν πατάτε Αποθήκευση, όχι κατά την πληκτρολόγηση — διορθώστε το σφάλμα που εμφανίζεται και δοκιμάστε ξανά.
- **Μην το μπερδεύετε με το `/settings/general-settings`.** Αυτή η διαδρομή υπάρχει αλλά εμφανίζει μόνο μια κενή κάρτα placeholder — ανοίξτε το `/settings/general` για την πραγματική οθόνη.
- **Το Απόρριψη είναι το δίχτυ ασφαλείας σας** — το υποσέλιδο εμφανίζεται μόνο όταν υπάρχουν μη αποθηκευμένες αλλαγές· κάντε κλικ στο _Απόρριψη_ για να επαναφέρετε το φορτωμένο στιγμιότυπο χωρίς να φύγετε από τη σελίδα.
- **Το κινητό είναι σκόπιμα περιορισμένο.** Μόνο η αναδίπλωση App είναι συνδεδεμένη· οι υπόλοιπες απλώς σας προτρέπουν να χρησιμοποιήσετε την έκδοση desktop.
- **Προτεραιότητα ανά όχημα.** Οτιδήποτε ορίσετε στα Τιμολόγια / Διαδρομές είναι προεπιλογή· το πραγματικό τιμολόγιο που πληρώνει ο χρήστης προέρχεται από το Τιμολόγιο Οχήματος που συνδέεται με το μοντέλο — δείτε [Vehicle Tariffs](../infrastructure/vehicle-tariffs.md).
