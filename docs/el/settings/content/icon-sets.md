# Σετ Εικονιδίων

Η σελίδα Σετ Εικονιδίων (`/settings/icon-sets`) είναι η **βιβλιοθήκη εικονιδίων χάρτη** που χρησιμοποιεί η εφαρμογή Ridewolf rider για κινητά για την απόδοση των οχημάτων. Κάθε σετ συνδέεται με έναν τύπο οχήματος (ηλεκτρικό πατίνι, ηλεκτρικό ποδήλατο, ηλεκτρικό ποδήλατο φορτίου, ηλεκτρικό μοτοποδήλατο, ηλεκτρικό αυτοκίνητο, ηλεκτρικό σκάφος) και παρέχει τρεις κατηγορίες εικονιδίων SVG: **Επιλεγμένα**, **Μη επιλεγμένα** και **Έκπτωση**.

Αυτή είναι υποδομή περιεχομένου — οι χειριστές ανεβάζουν SVG εδώ, η εφαρμογή rider επιλέγει το σωστό εικονίδιο βάσει τύπου οχήματος, επιπέδου μπαταρίας και αν ο αναβάτης έχει πατήσει το όχημα στο χάρτη. Δεν απαιτείται νέα έκδοση της εφαρμογής για να αλλάξει η εικόνα.

Μαζί με τα [FAQ Sets](faq-sets.md) και τους [Quick Guides](quick-guides.md), αυτό είναι το επίπεδο περιεχομένου του Πίνακα ελέγχου.

Απαιτούμενη άδεια: **Σετ Εικονιδίων** (ελέγξτε με τον διαχειριστή).

## Πού εμφανίζεται στον αναβάτη

Στον χάρτη της εφαρμογής rider, κάθε καρφίτσα οχήματος χρησιμοποιεί ένα εικονίδιο από το ενεργό σετ για τον τύπο οχήματος:

- Τα **Μη επιλεγμένα** εικονίδια χρησιμοποιούνται για καρφίτσες που ο αναβάτης δεν έχει πατήσει — έξι επίπεδα μπαταρίας (`bat10`, `bat25`, `bat40`, `bat55`, `bat90`, `bat100`) ώστε η καρφίτσα να αντανακλά την τρέχουσα φόρτιση
- Τα **Επιλεγμένα** εικονίδια αντικαθιστούν την καρφίτσα όταν ο αναβάτης την πατά — ίδια έξι επίπεδα μπαταρίας, διαφορετικό στυλ
- Τα **Εικονίδια έκπτωσης** (5%, 15%, 25%, 35%, 45%, 55% από προεπιλογή) επικαλύπτονται στην καρφίτσα όταν το όχημα έχει προωθητική τιμή

Ένα σετ ανά τύπο οχήματος μπορεί να οριστεί ως **προεπιλεγμένο** — αυτό φορτώνει η εφαρμογή όταν δεν έχει ρυθμιστεί κάτι άλλο.

## Φίλτρα

| Φίλτρο          | Τύπος    | Σημειώσεις                                                                                                         |
| --------------- | -------- | ----------------------------------------------------------------------------------------------------------------- |
| Αναζήτηση       | Κείμενο  | Πλαίσιο αναζήτησης στην κεφαλίδα — αναζητά τίτλο / slug                                                          |
| Τύπος οχήματος  | Αναπτυσσόμενο | `Ηλεκτρικό πατίνι` / `Ηλεκτρικό ποδήλατο` / `Ηλεκτρικό ποδήλατο φορτίου` / `Ηλεκτρικό μοτοποδήλατο` / `Ηλεκτρικό αυτοκίνητο` / `Ηλεκτρικό σκάφος` (ή `Όλα`) |
| Κάλυψη κατάστασης | Αναπτυσσόμενο | Φιλτράρισμα ανά βάση συμπληρωμένων: `Μόνο επιλεγμένα` / `Μόνο μη επιλεγμένα` / `Μόνο έκπτωση` / `Πλήρης κάλυψη` (ή `Όλα`) |
| Κατάσταση       | Αναπτυσσόμενο | `Ενεργό` / `Πρόχειρο` / `Ατελές` / `Αρχειοθετημένο` (ή `Όλα`)                                                    |
| Ετικέτες        | Συνδυαστικό πλαίσιο | Φίλτρο ετικετών ελεύθερης μορφής (εμφανίζεται πεδίο αλλά είναι απενεργοποιημένο — έρχεται σύντομα)                  |

Το **Καθαρισμός όλων** επαναφέρει όλα τα φίλτρα.

## Στήλες

| Στήλη                  | Περιεχόμενο                                                               |
| ---------------------- | ------------------------------------------------------------------------- |
| **Σετ**                | Εικονίδιο πακέτου + τίτλος; δευτερεύουσα γραμμή δείχνει slug              |
| **Τύπος οχήματος**     | Ετικέτα (Ηλεκτρικό πατίνι, Ηλεκτρικό ποδήλατο, κ.λπ.)                    |
| **Επιλεγμένα εικονίδια** | Κάλυψη όπως `6/6` (πόσα επίπεδα μπαταρίας έχουν ανέβει)                  |
| **Μη επιλεγμένα εικονίδια** | Ίδια κάλυψη `n/6` για μη επιλεγμένες παραλλαγές                         |
| **Εικονίδια έκπτωσης** | Πρώτα 3 ποσοστά έκπτωσης ως ετικέτες (`5%`, `15%`, `25%`), `+N` υπερχείλιση |
| **Ετικέτες**           | Πρώτες 2 ετικέτες με `+N` υπερχείλιση                                    |
| **Ενημερώθηκε**        | Ημερομηνία τελευταίας ενημέρωσης                                         |
| **Κατάσταση**          | `Ενεργό` / `Πρόχειρο` / `Ατελές` / `Αρχειοθετημένο`                      |

`Ατελές` σημαίνει ότι το σετ λείπουν εικονίδια για μία από τις τρεις κατηγορίες — η εφαρμογή rider επιστρέφει στο προεπιλεγμένο για τον τύπο οχήματος μέχρι να ολοκληρώσετε το ανέβασμα.

Κάντε κλικ σε μια γραμμή για να ανοίξετε το **Παράθυρο λεπτομερειών** — μια οπτική προεπισκόπηση κάθε εικονιδίου στο σετ. Κάντε κλικ στο μενού με τις τρεις τελείες για ενέργειες.

## Ενέργειες γραμμής

| Ενέργεια            | Τι κάνει                                                                         |
| ------------------- | -------------------------------------------------------------------------------- |
| **Προβολή λεπτομερειών** | Ανοίγει το παράθυρο λεπτομερειών με προεπισκοπήσεις κάθε ανεβασμένου SVG         |
| **Επεξεργασία**      | Ανοίγει τη φόρμα με πολλές καρτέλες (Λεπτομέρειες / Επιλεγμένα / Μη επιλεγμένα / Εκπτώσεις / Προεπισκόπηση) |
| **Αντιγραφή**       | Κλωνοποιεί το σετ ως Πρόχειρο                                                    |
| **Ορισμός ως προεπιλεγμένο** | Ορίζει αυτό το σετ ως προεπιλεγμένο για τον τύπο οχήματος — η εφαρμογή rider θα το φορτώνει |
| **Λήψη**            | Κατεβάζει το σετ ως αρχείο ZIP με όλα τα SVG                                    |
| **Αρχειοθέτηση**    | Μεταφέρει σε `Αρχειοθετημένο` — διατηρείται για ιστορικό, δεν χρησιμοποιείται από την εφαρμογή |
| **Διαγραφή**        | Αφαιρεί οριστικά                                                               |

Τα κουμπιά **Εισαγωγή** (ZIP / JSON) και **Εξαγωγή** (ZIP / JSON) στην κορυφή λειτουργούν μαζικά.

## Φόρμα Δημιουργίας / Επεξεργασίας

Η φόρμα είναι ένα παράθυρο με πέντε καρτέλες:

1. **Λεπτομέρειες** — τίτλος (υποχρεωτικό), slug (παράγεται αυτόματα), τύπος οχήματος (υποχρεωτικό), ετικέτες, κατάσταση
2. **Επιλεγμένα** — ανέβασμα 6 SVG, ένα ανά επίπεδο μπαταρίας (`bat10` → `bat100`)
3. **Μη επιλεγμένα** — ίδια 6 θέσεις, για την κατάσταση μη επιλεγμένου στο χάρτη
4. **Εκπτώσεις** — ένα SVG ανά ποσοστό έκπτωσης. Οι προεπιλογές είναι `5, 15, 25, 35, 45, 55` αλλά μπορείτε να προσθέσετε/αφαιρέσετε γραμμές
5. **Προεπισκόπηση** — οπτικός έλεγχος ορθότητας όλου του σετ πριν την αποθήκευση

Ένα σετ με κενές θέσεις σε οποιαδήποτε καρτέλα αποθηκεύεται ως `Ατελές`.

## Τυπικές ροές εργασίας

- **Ανανέωση των εικονιδίων των ηλεκτρικών πατινιών για επανασχεδιασμό** — Αντιγράψτε το τρέχον προεπιλεγμένο → ανεβάστε νέα SVG σε όλες τις τρεις καρτέλες → αποθηκεύστε ως Πρόχειρο → προεπισκόπηση → Ορισμός ως προεπιλεγμένο → η εφαρμογή rider το αναγνωρίζει στην επόμενη ανανέωση
- **Εκτέλεση A/B δοκιμής στα εικονίδια** — κρατήστε το παλιό σετ Ενεργό και μη προεπιλεγμένο, δημιουργήστε νέο σετ ως Ενεργό + προεπιλεγμένο για τύπο οχήματος → επαναφέρετε ορίζοντας το παλιό ως προεπιλεγμένο αν χρειαστεί
- **Εικαστικά έκπτωσης διακοπών** — ανοίξτε το ενεργό σετ → Επεξεργασία → καρτέλα Εκπτώσεις → ανεβάστε θεματικά SVG για τα ποσοστά που χρησιμοποιούνται → αποθήκευση
- **Μαζική εισαγωγή ZIP σχεδιαστή** — επάνω δεξιά _Εισαγωγή_ → ZIP → επιβεβαίωση αντιστοίχισης αρχείων → ανασκόπηση στην Προεπισκόπηση → Ενεργοποίηση

## Συμβουλές

- **Ένα προεπιλεγμένο ανά τύπο οχήματος** — η ρύθμιση νέου προεπιλεγμένου απενεργοποιεί αυτόματα το προηγούμενο. Το σήμα Κατάστασης δεν χρειάζεται να είναι `Ενεργό` για να είναι ένα σετ προεπιλεγμένο, αλλά καλό είναι
- **Τα επίπεδα μπαταρίας είναι σταθερά** — τα `bat10/25/40/55/90/100` είναι οι μόνες κατηγορίες που καταλαβαίνει η εφαρμογή· επιλέγει το πιο κοντινό με βάση τη ζωντανή φόρτιση οχήματος
- **Μόνο SVG** — οι μεταφορτώσεις αναμένουν αρχεία SVG· τα PNG δεν κλιμακώνονται καθαρά σε οθόνες retina
- **Το `Incomplete` είναι χρήσιμο όριο ασφαλείας** — δείχνει ότι η εφαρμογή rider επιστρέφει στο προεπιλεγμένο, ώστε να μην στείλετε κατά λάθος ημιτελές σετ
- **Αρχειοθετήστε πριν διαγράψετε** — τα αρχειοθετημένα σετ παραμένουν αναζητήσιμα σε περίπτωση που θέλετε να επαναφέρετε
