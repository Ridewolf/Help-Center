# Σετ Συχνών Ερωτήσεων

Η σελίδα Σετ Συχνών Ερωτήσεων (`/settings/faq-sets`) είναι η **βιβλιοθήκη ερωτήσεων και απαντήσεων** που εμφανίζεται μέσα στις εφαρμογές Ridewolf — κυρίως στην εφαρμογή κινητού για αναβάτες, αλλά και σε επιφάνειες που βλέπουν οι χειριστές. Κάθε σετ είναι ένα πακέτο καταχωρήσεων Ε/Α προσανατολισμένο σε ένα συγκεκριμένο κοινό (εφαρμογή αναβάτη, εφαρμογή πελάτη, μηχανικός, διαχειριστής ή γενικό).

Μαζί με τους [Γρήγορους οδηγούς](quick-guides.md) και τα [Σετ Εικονιδίων](icon-sets.md), αυτή η σελίδα αποτελεί μέρος του επιπέδου περιεχομένου — ό,τι αλλάζει ένας χειριστής εδώ είναι αυτό που βλέπει ο αναβάτης στο τηλέφωνό του, χωρίς να χρειάζεται νέα έκδοση της εφαρμογής κινητού.

Απαιτούμενη άδεια: **Σετ Συχνών Ερωτήσεων** (ελέγξτε με τον διαχειριστή).

## Πού εμφανίζεται στον αναβάτη

Στην εφαρμογή κινητού για αναβάτες, τα Σετ Συχνών Ερωτήσεων υποστηρίζουν την ενότητα Βοήθεια / FAQ μέσα στην εφαρμογή. Κάθε σετ με τύπο **rider-app** και κατάσταση `active` φορτώνεται στην εφαρμογή· οι καταχωρήσεις που έχουν επισημανθεί ως `visible` εμφανίζονται, ταξινομημένες με βάση το πεδίο `order`. Τα σετ με τύπο `client-app`, `mechanic`, `admin`, `general` προορίζονται για τις αντίστοιχες εφαρμογές / επιφάνειες.

Ένα σετ με κατάσταση `draft` ή `archived` δεν εμφανίζεται ποτέ — χρήσιμο για προετοιμασία αλλαγών πριν τη δημοσίευση.

## Φίλτρα

| Φίλτρο | Τύπος        | Σημειώσεις                                                               |
| ------ | ------------ | ------------------------------------------------------------------------ |
| Αναζήτηση | Κείμενο      | Πλαίσιο αναζήτησης στην κεφαλίδα — αναζητά τίτλο / περιγραφή / slug      |
| Ετικέτες | Πολλαπλή επιλογή | Φιλτράρισμα με βάση τις ετικέτες που εφαρμόζονται στο σετ (onboarding, payments, technical, …) |
| Κατάσταση | Αναπτυσσόμενο | `Ενεργό` / `Πρόχειρο` / `Αρχειοθετημένο` (ή `Όλα`)                      |
| Τύπος   | Αναπτυσσόμενο | `Εφαρμογή πελάτη` / `Εφαρμογή αναβάτη` / `Μηχανικός` / `Διαχειριστής` / `Γενικό` (ή `Όλα`) |

Το **Καθαρισμός όλων** επαναφέρει όλα τα φίλτρα ταυτόχρονα.

## Στήλες

| Στήλη       | Περιεχόμενο                                                        |
| ----------- | ----------------------------------------------------------------- |
| **Σετ**     | Εικονίδιο + τίτλος· η δευτερεύουσα γραμμή δείχνει περιγραφή ή slug |
| **Τύπος**   | Ετικέτα κοινού — Εφαρμογή πελάτη / Εφαρμογή αναβάτη / Μηχανικός / Διαχειριστής / Γενικό |
| **Ετικέτες**| Πρώτα 3 chip ετικέτες, με `+N` για υπερχείλιση                      |
| **Είδη**    | Αριθμός πεδίων Ε/Α στο σετ                                       |
| **Κατάσταση**| `Ενεργό` (πράσινο) / `Πρόχειρο` (γκρι) / `Αρχειοθετημένο` (αχνό)    |
| **Ενημερώθηκε**| Σχετική ημερομηνία· δείτε πλήρη χρονική σήμανση + δημιουργό με hover |

Κάντε κλικ σε μια γραμμή για να ανοίξετε το παράθυρο διαλόγου **Προβολή** (προεπισκόπηση μόνο για ανάγνωση). Κάντε κλικ στο μενού με τις τρεις τελείες για ενέργειες.

## Ενέργειες γραμμής

| Ενέργεια          | Τι κάνει                                                            |
| ----------------- | ------------------------------------------------------------------ |
| **Προβολή λεπτομερειών** | Προεπισκόπηση μόνο για ανάγνωση με κάθε πεδίο Ε/Α αποδοσμένο       |
| **Επεξεργασία**    | Άνοιγμα του παραθύρου διαλόγου φόρμας (ίδιο με Δημιουργία, προγεμισμένο) |
| **Αντιγραφή**     | Κλωνοποίηση του σετ με κατάληξη slug `-copy` και επαναφορά κατάστασης σε `Draft` |
| **Εξαγωγή**       | Λήψη του σετ ως ZIP ή JSON                                         |
| **Αρχειοθέτηση**  | Μεταφορά σε `Archived` — κρυφό από την εφαρμογή αναβάτη, διατηρείται για ιστορικό |
| **Διαγραφή**      | Μόνιμη αφαίρεση (καταστροφική — μόνο αν είστε σίγουροι ότι δεν χρειάζεται) |

Η κορυφαία γραμμή εργαλείων έχει επίσης ομαδική **Εισαγωγή** (ZIP / JSON) και **Εξαγωγή** (ZIP / JSON της ορατής λίστας).

## Φόρμα Δημιουργίας / Επεξεργασίας

Το παράθυρο διαλόγου φόρμας έχει τρεις επιλογείς κορυφαίου επιπέδου και μια λίστα πεδίων Ε/Α:

- **Τύπος** — υποχρεωτικό, ορίζει ποιος βλέπει το σετ (Εφαρμογή πελάτη / Εφαρμογή αναβάτη / Μηχανικός / Διαχειριστής / Γενικό)
- **Κατάσταση** — `Πρόχειρο` (προεπιλογή για νέα) / `Ενεργό` / `Αρχειοθετημένο`
- **Ετικέτες** — πολλαπλή επιλογή, χρησιμοποιείται για φιλτράρισμα και ομαδοποίηση
- **Τίτλος** — υποχρεωτικό, εμφανίζεται ως όνομα σετ
- **Περιγραφή** — προαιρετικό, δευτερεύουσα γραμμή στη λίστα
- **Πεδία** — οι καταχωρήσεις Ε/Α. Κάθε πεδίο έχει:
  - **Ετικέτα** (η ερώτηση)
  - **Τιμή** (η απάντηση)
  - **Τύπος** — `text` / `markdown` / `link` / `list`
  - **Εμφανές** toggle (απόκρυψη μεμονωμένων στοιχείων χωρίς διαγραφή)
  - **Σειρά** (σύρετε για αναδιάταξη)

Το slug προέρχεται από τον τίτλο και χρησιμοποιείται στο URL του API — αλλάξτε το μέσω Επεξεργασίας αν χρειάζεται.

## Τυπικά ροή εργασίας

- **Δημοσίευση νέου FAQ για αναβάτες** — `+ Δημιουργία σετ` → Τύπος = Εφαρμογή αναβάτη, Κατάσταση = Πρόχειρο → συμπληρώστε τίτλο + περιγραφή → προσθέστε πεδία Ε/Α → αποθηκεύστε → προεπισκόπηση μέσω Προβολής λεπτομερειών → Επεξεργασία, αλλάξτε Κατάσταση σε Ενεργό → εμφανίζεται στην εφαρμογή αναβάτη στην επόμενη ενημέρωση
- **Προετοιμασία εποχιακού κειμένου** — Αντιγράψτε ένα υπάρχον σετ → επεξεργαστείτε το αντίγραφο ως Πρόχειρο → προγραμματίστε την αλλαγή αρχειοθετώντας το παλιό σετ και ενεργοποιώντας το νέο ταυτόχρονα
- **Επαναφορά κακής απάντησης** — ανοίξτε το προβληματικό σετ → Επεξεργασία → διορθώστε το πεδίο (ή απενεργοποιήστε το `Εμφανές`) → αποθηκεύστε· ή Αρχειοθετήστε ολόκληρο το σετ και επαναφέρετε σε προηγούμενη διπλοτυπημένη έκδοση
- **Μαζική εισαγωγή από JSON dump** — πάνω δεξιά _Εισαγωγή_ → επιλέξτε το αρχείο → επιβεβαιώστε τη δομή που αναλύθηκε → εισαγωγή ως Πρόχειρο, μετά ελέγξτε και ενεργοποιήστε

## Συμβουλές

- **Ο Τύπος ελέγχει ποιος βλέπει το περιεχόμενο** — μην βάζετε κείμενο για αναβάτες σε σετ `mechanic`, δεν θα φτάσει ποτέ στην εφαρμογή αναβάτη
- **Το Πρόχειρο είναι φίλος σας** — τα νέα σετ είναι από προεπιλογή Πρόχειρα ώστε η εφαρμογή αναβάτη να μην δείχνει ημιτελές περιεχόμενο. Αλλάξτε σε Ενεργό μόνο αφού ελέγξετε τα πάντα
- **Τα πεδία Markdown αποδίδουν μορφοποίηση** — χρησιμοποιήστε τα για απαντήσεις που χρειάζονται λίστες ή έντονα γράμματα· επιλέξτε `text` όταν θέλετε απλό κείμενο
- **Οι Ετικέτες μοιράζονται με το φίλτρο** — χρησιμοποιήστε συνεπή λεξιλόγιο ετικετών (π.χ. `onboarding`, `payments`, `troubleshooting`) ώστε το μελλοντικό φιλτράρισμα να παραμένει χρήσιμο
- **Αρχειοθετήστε αντί να Διαγράψετε** όταν είναι δυνατόν — τα διαγραμμένα σετ χάνονται οριστικά, τα αρχειοθετημένα μπορούν να επανενεργοποιηθούν και χρησιμεύουν ως ιστορικό
