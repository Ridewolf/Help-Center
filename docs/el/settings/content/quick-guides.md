# Γρήγοροι Οδηγοί

Η σελίδα Γρήγοροι Οδηγοί (`/settings/quick-guides`) περιέχει τις **οδηγίες βήμα προς βήμα** που εμφανίζει η εφαρμογή Ridewolf rider για θέματα όπως «Πώς να νοικιάσετε ένα σκούτερ» ή «Λίστα ελέγχου ασφάλειας». Κάθε οδηγός είναι μια ταξινομημένη λίστα με στοιχεία που περιλαμβάνουν ένα εικονίδιο, χρώμα, τίτλο και κείμενο σώματος — δημοσιευμένη ανά κοινό (rider app, client app, μηχανικός, διαχειριστής, γενικά).

Μαζί με τα [Σετ Συχνών Ερωτήσεων](faq-sets.md) (μπλοκ ερωτήσεων/απαντήσεων) και τα [Σετ Εικονιδίων](icon-sets.md) (γραφικά χάρτη), οι Γρήγοροι Οδηγοί αποτελούν τον τρίτο πυλώνα του επιπέδου περιεχομένου. Επεξεργαστείτε έναν οδηγό εδώ, η rider app θα ανανεώσει την αλλαγή στην επόμενη λήψη — δεν απαιτείται νέα έκδοση της εφαρμογής.

Απαραίτητη άδεια: **Γρήγοροι Οδηγοί** (ελέγξτε με τον διαχειριστή).

## Πού εμφανίζεται στον αναβάτη

Στην εφαρμογή rider, οι Γρήγοροι Οδηγοί τροφοδοτούν τα εκπαιδευτικά προγράμματα εισαγωγής και τις οθόνες συμβουλών κατά τη διάρκεια της διαδρομής. Κάθε οδηγός με τύπο **rider-app** και κατάσταση `active` φορτώνεται· τα στοιχεία που έχουν επισημανθεί ως `visible` εμφανίζονται με τη σειρά `order`, με το ρυθμισμένο `icon` και `color` στα αριστερά, και το κείμενο `body` επεκτείνεται αν το `expandByDefault` είναι αληθές.

Οι οδηγοί με τύπους `client-app`, `mechanic`, `admin`, `general` συνδέονται με τις αντίστοιχες επιφάνειες τους.

## Φίλτρα

| Φίλτρο | Τύπος        | Σημειώσεις                                                               |
| ------ | ------------ | ----------------------------------------------------------------------- |
| Αναζήτηση | Κείμενο      | Πλαίσιο αναζήτησης στην κεφαλίδα — αναζητά τίτλο / περιγραφή / slug     |
| Ετικέτες | Πολλαπλή επιλογή | Φιλτράρισμα κατά ετικέτες (onboarding, basics, technical, payments, …) |
| Κατάσταση | Αναπτυσσόμενο | `Ενεργό` / `Πρόχειρο` / `Αρχειοθετημένο` (ή `Όλα`)                      |
| Τύπος    | Αναπτυσσόμενο | `Client app` / `Rider app` / `Mechanic` / `Admin` / `General` (ή `Όλα`) |

Το **Καθαρισμός όλων** επαναφέρει κάθε φίλτρο.

## Στήλες

| Στήλη       | Περιεχόμενο                                                        |
| ----------- | ----------------------------------------------------------------- |
| **Σετ**     | Εικονίδιο βιβλίου + τίτλος; η δευτερεύουσα γραμμή δείχνει περιγραφή ή slug |
| **Τύπος**   | Ετικέτα κοινού — Client app / Rider app / Mechanic / Admin / General |
| **Ετικέτες**| Πρώτα 3 τσιπ ετικετών, με υπερχείλιση `+N`                        |
| **Στοιχεία**| Αριθμός βημάτων στον οδηγό                                       |
| **Κατάσταση**| `Ενεργό` (πράσινο) / `Πρόχειρο` (γκρι) / `Αρχειοθετημένο` (αχνό)  |
| **Ενημερώθηκε**| Σχετική ημερομηνία; δείτε πλήρη χρονική σήμανση + δημιουργό με hover |

Κάντε κλικ σε μια γραμμή για να ανοίξετε το διάλογο **Προβολή** (προεπισκόπηση κάθε βήματος). Κάντε κλικ στο μενού με τις τρεις τελείες για ενέργειες.

## Ενέργειες γραμμής

| Ενέργεια         | Τι κάνει                                                           |
| ---------------- | ----------------------------------------------------------------- |
| **Προβολή λεπτομερειών** | Προεπισκόπηση με κάθε στοιχείο όπως θα το έβλεπε ο αναβάτης       |
| **Επεξεργασία**   | Άνοιγμα διαλόγου φόρμας (ίδιο με Δημιουργία, προ-συμπληρωμένο)    |
| **Αντιγραφή**    | Κλωνοποίηση του οδηγού με κατάληξη slug `-copy` και επαναφορά κατάστασης σε `Πρόχειρο` |
| **Εξαγωγή**      | Λήψη ως ZIP ή JSON                                               |
| **Αρχειοθέτηση** | Μεταφορά σε `Αρχειοθετημένο` — κρυφό από την rider app, διατηρείται για ιστορικό |
| **Διαγραφή**     | Μόνιμη αφαίρεση                                                 |

Τα κουμπιά **Εισαγωγή** (ZIP / JSON) και **Εξαγωγή** (ZIP / JSON) στην κορυφή λειτουργούν μαζικά.

## Φόρμα Δημιουργίας / Επεξεργασίας

Η φόρμα έχει τους ίδιους βασικούς επιλογείς με τα Σετ Συχνών Ερωτήσεων, συν έναν πιο πλούσιο επεξεργαστή ανά στοιχείο:

- **Τύπος** — υποχρεωτικό, ορίζει ποιος βλέπει τον οδηγό
- **Κατάσταση** — `Πρόχειρο` / `Ενεργό` / `Αρχειοθετημένο`
- **Ετικέτες** — πολλαπλή επιλογή
- **Τίτλος / Περιγραφή** — απαιτείται τίτλος, περιγραφή προαιρετική
- **Στοιχεία** — η λίστα βημάτων. Κάθε στοιχείο έχει:
  - **Τίτλος** — ο τίτλος του βήματος
  - **Κείμενο** — το περιεχόμενο του βήματος (εκτενές, απλό κείμενο)
  - **Εικονίδιο** — όνομα εικονιδίου Lucide (π.χ. `MapPin`, `QrCode`, `Shield`)
  - **Χρώμα** — χρώμα hex με προκαθορισμένα brand (Primary `#6366f1`, Success `#22c55e`, Warning `#eab308`, Danger `#ef4444`, κ.ά.)
  - **Ανάπτυξη από προεπιλογή** — αν είναι ενεργό, το στοιχείο ανοίγει επεκταμένο στην εφαρμογή
  - **Ορατό** — εναλλαγή για απόκρυψη στοιχείου χωρίς διαγραφή
  - **Σειρά** — σύρετε για αναδιάταξη

Το slug προέρχεται από τον τίτλο και χρησιμοποιείται στο URL του API.

## Τυπικές ροές εργασίας

- **Γράψτε έναν νέο οδηγό εισαγωγής** — `+ Δημιουργία οδηγού` → Τύπος = Rider app, Κατάσταση = Πρόχειρο → προσθέστε 5–7 ταξινομημένα στοιχεία με εικονίδια + χρώματα → προεπισκόπηση μέσω Προβολή λεπτομερειών → αλλάξτε σε Ενεργό → εμφανίζεται στην rider app στην επόμενη λήψη
- **Κάντε ένα βήμα προαιρετικό / αποκρύψτε το** — Επεξεργασία → απενεργοποιήστε το `Ορατό` στο στοιχείο → αποθήκευση (το στοιχείο παραμένει στα δεδομένα, απλώς δεν εμφανίζεται)
- **Κάντε A/B δοκιμή νέου οδηγού** — Αντιγράψτε τον ενεργό οδηγό → επεξεργαστείτε το αντίγραφο → αρχειοθετήστε τον παλιό και ενεργοποιήστε τον νέο μαζί
- **Μαζική εισαγωγή σχεδίου σχεδιαστή** — πάνω δεξιά _Εισαγωγή_ → ZIP/JSON → επιβεβαιώστε τη δομή → εισαγωγή ως Πρόχειρο → ελέγξτε και ενεργοποιήστε

## Συμβουλές

- **Τα εικονίδια είναι ονόματα Lucide** — επιλέξτε από το [lucide.dev](https://lucide.dev) ώστε να εμφανίζονται στην εφαρμογή· τα λανθασμένα ονόματα εικονιδίων αντικαθίστανται με κράτημα θέσης
- **Χρωματίστε τα βήματα για ευκολία σάρωσης** — οι αναβάτες διαβάζουν γρήγορα τους οδηγούς. Χρησιμοποιήστε Warning για βήματα "προσοχής" και Success για "ολοκληρωμένα" στάδια
- **Το `expandByDefault` ισχύει συνήθως μόνο για το πρώτο βήμα** — το να ανοίγουν όλα τα στοιχεία από προεπιλογή ακυρώνει το νόημα του ακορντεόν. Αφήστε τα υπόλοιπα κλειστά
- **Το κείμενο σώματος είναι απλή πρόζα, όχι markdown** — κρατήστε τις παραγράφους σύντομες· η εφαρμογή ρυθμίζει την τυπογραφία
- **Αρχειοθετήστε αντί να διαγράψετε** όταν αποσύρετε έναν οδηγό — μπορείτε πάντα να τον επανενεργοποιήσετε ή να τον αντιγράψετε αργότερα
- **Χρησιμοποιήστε τις ετικέτες συνεπώς με τα [Σετ Συχνών Ερωτήσεων](faq-sets.md)** — `onboarding`, `troubleshooting` κ.ά. είναι κοινό λεξιλόγιο στο επίπεδο περιεχομένου
