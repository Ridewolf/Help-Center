# Ετικέτες

Η σελίδα Ετικέτες (`/settings/tags`) είναι η **κοινή βιβλιοθήκη ετικετών** για την εταιρεία σας. Μια ετικέτα είναι μια ονομαστική ετικέτα που μπορείτε να επισυνάψετε σε οχήματα, πελάτες, χειριστές, διαδρομές και πληρωμές για να τα φιλτράρετε, ομαδοποιήσετε και αναφέρετε. Η λίστα εδώ είναι η μοναδική πηγή αλήθειας — όταν προσθέτετε μια ετικέτα, γίνεται διαθέσιμη παντού όπου υποστηρίζεται.

Απαιτούμενη άδεια: **Ετικέτες** (`d1e2f3`). Υπο-άδειες ελέγχουν τη δημιουργία, επεξεργασία και διαγραφή.

## Πού χρησιμοποιούνται οι ετικέτες

Οι ετικέτες είναι μια **ενιαία παγκόσμια δεξαμενή** — δεν υπάρχει πεδίο ανά οντότητα. Η ίδια ετικέτα μπορεί να επισυναφθεί σε διαφορετικούς τύπους εγγραφών:

- **[Οχήματα](../../operations/fleet/vehicles.md)** — π.χ. «Χρειάζεται καθαρισμό», «Προτεραιότητα συντήρησης», «Δοκιμαστικός στόλος»
- **[Πελάτες](../../operations/customers/clients.md)** — π.χ. «VIP», «Εταιρικός», «Μαύρη λίστα»
- **[Χειριστές](../access/operators.md)** — π.χ. «Νυχτερινή βάρδια», «Εκπαιδευτής», «Σε ετοιμότητα»
- **Διαδρομές** — επισημασμένες για ανασκόπηση, διαφωνία ή παρακολούθηση καμπάνιας
- **Πληρωμές** — επισημασμένες για συμφωνία ή παρακολούθηση

Κάθε εγγραφή μπορεί να φέρει πολλαπλές ετικέτες· το φιλτράρισμα με ετικέτα είναι διαθέσιμο σε κάθε λίστα που τις υποστηρίζει.

## Φίλτρα

| Φίλτρο | Τύπος | Σημειώσεις                                     |
| ------ | ---- | --------------------------------------------- |
| Αναζήτηση | Κείμενο | Αναζητά το όνομα ετικέτας (ετικέτα) και την περιγραφή |

Η λίστα έχει προεπιλογή 50 γραμμές ανά σελίδα και καθαρίζει τα φίλτρα με την ενέργεια **Καθαρισμός**.

## Στήλες

| Στήλη          | Ταξινομήσιμη; | Περιεχόμενο                                                        |
| --------------- | ------------ | ------------------------------------------------------------------ |
| **Όνομα ετικέτας**    | ΝΑΙ          | Εικονίδιο ετικέτας + ετικέτα; σύνδεσμος στη σελίδα λεπτομερειών της ετικέτας                |
| **Κατάσταση**      | ΝΑΙ          | `Public` ή `Private` (βλέπε παρακάτω)                              |
| **Περιγραφή** | ΟΧΙ          | Περιγραφή ελεύθερου κειμένου; θέση κράτησης «Χωρίς περιγραφή» όταν είναι κενό |
| **Ημερομηνίες**       | ΝΑΙ          | Ημερομηνία δημιουργίας πάνω, ημερομηνία ενημέρωσης από κάτω                   |

Η κεφαλίδα της σελίδας εμφανίζει επίσης **Αυτόματη ανανέωση**, **+ Δημιουργία**, **Εισαγωγή** (έρχεται σύντομα) και **Εξαγωγή** (λήψη JSON — τρέχουσα σελίδα, όλα τα φιλτραρισμένα ή συγκεκριμένες σελίδες).

## Ενέργειες γραμμής

Μενού με τρεις τελείες ανά γραμμή. Οι διαθέσιμες ενέργειες εξαρτώνται από τα δικαιώματα:

| Ενέργεια           | Άδεια | Τι κάνει                                                                                    |
| ---------------- | ---------- | ----------------------------------------------------------------------------------------------- |
| **Προβολή λεπτομερειών** | —          | Ανοίγει τη σελίδα λεπτομερειών της ετικέτας                                                                      |
| **Επεξεργασία**         | `edit`     | Ανοίγει τη φόρμα επεξεργασίας (ετικέτα, κατάσταση, περιγραφή)                                                 |
| **Διαγραφή**       | `delete`   | Αφαιρεί την ετικέτα από την εταιρεία. **Οι εγγραφές που είχαν την ετικέτα χάνουν τον σύνδεσμο** — χρησιμοποιήστε με προσοχή |

Η διαγραφή απαιτεί επιβεβαίωση με κράτημα 3 δευτερολέπτων για αποφυγή ατυχημάτων.

## Σελίδα λεπτομερειών

Το κλικ σε μια γραμμή (ή _Προβολή λεπτομερειών_) ανοίγει τη σελίδα λεπτομερειών της ετικέτας με:

- **Πληροφορίες ετικέτας** — ετικέτα, κατάσταση, περιγραφή (αποδίδεται με υποστήριξη Markdown)
- **Μεταδεδομένα** — εσωτερικό ID, χρονικές σφραγίδες δημιουργίας / ενημέρωσης

Η Επεξεργασία και η Διαγραφή είναι διαθέσιμες και από τις ενέργειες κεφαλίδας στη σελίδα λεπτομερειών.

## Φόρμα Δημιουργίας / Επεξεργασίας

Η **φόρμα ετικέτας** (`+ Δημιουργία` ή _Επεξεργασία_) έχει τρία πεδία:

- **Ετικέτα** (απαραίτητο) — το ορατό όνομα της ετικέτας· πρέπει να είναι αρκετά μοναδικό για να αναγνωρίζεται με μια ματιά
- **Κατάσταση** (απαραίτητο) — `Public` ή `Private`
  - **Public** — ορατό και επιλέξιμο από όλους τους χειριστές σε όλη την εταιρεία
  - **Private** — περιορισμένη ορατότητα· χρήσιμο για εσωτερικές/διαχειριστικές ροές εργασίας με ετικέτες
- **Περιγραφή** (προαιρετικό) — ελεύθερο κείμενο που εξηγεί πότε να χρησιμοποιείται η ετικέτα· εμφανίζεται στη σελίδα λεπτομερειών

Μια ζωντανή **προεπισκόπηση** στην πλαϊνή μπάρα δείχνει πώς θα φαίνεται η ετικέτα και η περιγραφή καθώς πληκτρολογείτε. Η αποθήκευση ελέγχει ότι η ετικέτα δεν είναι κενή, γράφει στη δεξαμενή ετικετών της εταιρείας και ανανεώνει την κοινή προσωρινή μνήμη ετικετών ώστε άλλες σελίδες να ανανεωθούν στην επόμενη φόρτωση.

## Τυπικές ροές εργασίας

- **Προσθήκη νέας ετικέτας** — `+ Δημιουργία` → πληκτρολογήστε ετικέτα → επιλέξτε Public/Private → προαιρετικά περιγράψτε πότε να χρησιμοποιείται → Αποθήκευση → η ετικέτα είναι άμεσα διαθέσιμη στα φίλτρα και τις φόρμες επεξεργασίας Οχημάτων / Πελατών / Χειριστών
- **Μετονομασία ετικέτας** — Επεξεργασία → αλλαγή Ετικέτας → Αποθήκευση (κάθε εγγραφή που είχε ήδη την ετικέτα διατηρεί τον σύνδεσμο· το νέο όνομα εμφανίζεται παντού)
- **Απόσυρση ετικέτας** — Διαγραφή από το μενού γραμμής, ή πρώτα ορίστε την Κατάσταση σε Private για να την κρύψετε από νέες επισημάνσεις ενώ διατηρείτε τους ιστορικούς συνδέσμους (θα την επανασυνδέσετε μόνο μέσω άμεσης επεξεργασίας)
- **Καθαρισμός διπλοτύπων** — αναζητήστε τη λίστα για να εντοπίσετε σχεδόν διπλότυπα («vip» έναντι «VIP») → επεξεργαστείτε ένα για συγχώνευση ονομάτων, μετά διαγράψτε το άλλο (σημείωση: οι εγγραφές κάτω από την διαγραμμένη ετικέτα θα χάσουν τον σύνδεσμο — επισημάνετέ τις ξανά πρώτα)
- **Μαζική εξαγωγή** — Εξαγωγή → Όλα τα φιλτραρισμένα → λήψη JSON για κοινή χρήση με την ομάδα σας ή για δημιουργία αντιγράφου ασφαλείας της ταξινομίας

## Συμβουλές

- **Οι ετικέτες είναι παγκόσμιες** — δεν υπάρχει ξεχωριστός χώρος ονομάτων για «ετικέτες πελατών» έναντι «ετικετών οχημάτων». Ονομάστε τις αρκετά καθαρά ώστε μια ετικέτα όπως «VIP» να έχει νόημα σε όποια οντότητα επισυνάπτεται, ή χρησιμοποιήστε προθέματα («client:vip», «vehicle:maintenance») για να διατηρείτε τα πράγματα τακτοποιημένα
- **Το Public είναι η προεπιλογή** — αφήστε το Public εκτός αν έχετε συγκεκριμένο λόγο να περιορίσετε την ορατότητα
- **Η Διαγραφή είναι καταστροφική** — κάθε εγγραφή που φέρει την ετικέτα χάνει αμέσως τον σύνδεσμο· δεν υπάρχει μαλακή διαγραφή. Προτιμήστε τη μετονομασία ή τη μετάβαση σε Private αν δεν είστε σίγουροι
- **Η Περιγραφή υποστηρίζει Markdown** στη σελίδα λεπτομερειών — χρησιμοποιήστε την για να τεκμηριώσετε ποιος πρέπει να εφαρμόζει την ετικέτα και πότε
- **Η κοινή προσωρινή μνήμη ανανεώνεται σε κάθε αποθήκευση / διαγραφή** — άλλες ανοιχτές καρτέλες θα πάρουν τις αλλαγές σας στην επόμενη πλοήγηση, χωρίς πλήρη επαναφόρτωση
- **Τα ονόματα ετικετών εμφανίζονται στα συμφραζόμενα φίλτρα του Ridewolf παντού** — κρατήστε τα σύντομα και φιλικά προς πεζά για την καλύτερη εμπειρία χρήστη σε πυκνούς πίνακες
