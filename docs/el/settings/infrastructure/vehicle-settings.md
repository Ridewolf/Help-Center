# Κανόνες Οχημάτων

Η σελίδα Κανόνες Οχημάτων (`/settings/vehicle-rules`) είναι ο **κατάλογος μοντέλων οχημάτων** που γνωρίζει να χειρίζεται το Ridewolf — _Xiaomi M365_, _Ninebot Max G30_, _Segway F40_ κ.ο.κ. Κάθε γραμμή εδώ είναι ένα **πρότυπο μοντέλου**: ένα επαναχρησιμοποιήσιμο πακέτο τιμολόγησης, τεχνικών ορίων, κανόνων απόδειξης με φωτογραφία και ετικετών που συνδέεται με μεμονωμένα φυσικά [οχήματα](../../operations/fleet/vehicles.md) μέσω της [φόρμας οχήματος](../../operations/fleet/vehicle-create-edit.md).

Απαραίτητη άδεια: **Κανόνες Οχημάτων** (`e7f8g9`). Υπο-άδειες για `create` / `edit` / `delete`.

## Μοντέλο έναντι παραδείγματος οχήματος

Αυτή είναι η πιο σημαντική διάκριση σε αυτή τη σελίδα:

- Ένα **Μοντέλο Οχήματος** (αυτή η σελίδα) — ένας ορισμός. _"Κάθε Xiaomi M365 στο στόλο μας συμπεριφέρεται έτσι"_. Μία γραμμή ανά κατασκευή/διαμόρφωση.
- Ένα **Όχημα** (η [λίστα Οχημάτων](../../operations/fleet/vehicles.md)) — μια φυσική μονάδα με αυτοκόλλητη ετικέτα όπως `RW-007`, συνδεδεμένη με μία συσκευή IoT, σταθμευμένη κάπου. Εκατοντάδες από αυτά δείχνουν σε ένα μοντέλο.

Όταν αλλάζετε ένα μοντέλο εδώ, κάθε όχημα που δείχνει σε αυτό κληρονομεί τις νέες προεπιλογές — τα τιμολόγια ενεργοποιούνται, τα όρια ταχύτητας ενημερώνονται, οι απαιτήσεις απόδειξης με φωτογραφία τίθενται σε ισχύ. Θεωρήστε αυτή τη σελίδα ως **στρώμα πολιτικής** που εξαπλώνεται σε πολλές μονάδες ταυτόχρονα.

## Φίλτρα

Η κορυφαία γραμμή φίλτρων έχει τρεις ελέγχους:

| Φίλτρο      | Τύπος    | Σημειώσεις                                                                                  |
| ----------- | -------- | ------------------------------------------------------------------------------------------ |
| **Αναζήτηση** | Κείμενο  | Αναζητά την ετικέτα μοντέλου                                                               |
| **Κατάσταση** | Αναπτυσσόμενο | `Όλα` / `Ενεργό` / `Ανενεργό` / `Αρχειοθετημένο`                                         |
| **Τύπος**    | Αναπτυσσόμενο | `Όλα` / `Ηλεκτρικό Πατίνι` / `Ηλεκτρικό Ποδήλατο` / `Φορτηγό Ηλεκτρικό Ποδήλατο` / `Ηλεκτρικό Μοτοποδήλατο` / `Ηλεκτρικό Αυτοκίνητο` / `Ηλεκτρικό Σκάφος` |

Η αλλαγή οποιουδήποτε φίλτρου επαναφέρει την σελιδοποίηση στην σελίδα 1 και φορτώνει ξανά από τον διακομιστή.

## Στήλες

| Στήλη           | Ταξινομήσιμη; | Περιεχόμενο                                                                                   |
| --------------- | ------------- | -------------------------------------------------------------------------------------------- |
| **Εικόνα**      | —             | Μικρογραφία 64×64; εμφανίζει ένα γενικό εικονίδιο αυτοκινήτου αν δεν έχει μεταφορτωθεί εικόνα  |
| **Όνομα**       | ✓             | Η ετικέτα μοντέλου (π.χ. _Xiaomi M365 Pro_)                                                  |
| **Τύπος**       | ✓             | Ετικέτα τύπου οχήματος (ηλεκτρικό πατίνι, ηλεκτρικό ποδήλατο, …)                             |
| **Περιγραφή**   | ✓             | Πρώτοι 36 χαρακτήρες της περιγραφής markdown, χωρίς μορφοποίηση                               |
| **Ετικέτες**    | —             | Μέχρι 2 ετικέτες + ένα τσιπ υπερχείλισης `+N` — **κλικ για γρήγορη επεξεργασία** σε διάλογο  |
| **Κατάσταση**   | ✓             | Έγχρωμη ετικέτα: Ενεργό (πράσινο) / Ανενεργό (γκρι) / Αρχειοθετημένο (μπλε) — **κλικ για γρήγορη επεξεργασία** |
| **Δημιουργήθηκε** | ✓           | Ημερομηνία δημιουργίας του μοντέλου                                                         |
| **Ενημερώθηκε** | ✓             | Ημερομηνία τελευταίας αλλαγής                                                               |

Τα κλικ για γρήγορη επεξεργασία ανοίγουν έναν μικρό διάλογο με πολλαπλή επιλογή ετικετών ή αναπτυσσόμενο μενού κατάστασης — χρήσιμο για μαζικές αλλαγές κατάστασης χωρίς να φύγετε από τη λίστα.

## Ενέργειες στη γραμμή εργαλείων

Κουμπιά πάνω δεξιά (η ορατότητα εξαρτάται από τις άδειες):

| Κουμπί           | Άδεια      | Τι κάνει                                                                                                                    |
| ----------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Αυτόματη ανανέωση** | —        | Ενημερώνει τη λίστα σε σταθερό διάστημα· ενεργοποίηση/απενεργοποίηση· το εικονίδιο περιστρέφεται κατά τη φόρτωση           |
| **Εισαγωγή**      | `create`   | Επιλέξτε αρχείο JSON (μορφή εξαγωγής). Κάθε στοιχείο γίνεται κλήση `create`; οι ετικέτες και τα τιμολόγια αφαιρούνται — επανασυνδέστε χειροκίνητα μετά |
| **Εξαγωγή**       | —          | Ανοίγει διάλογο για εξαγωγή τρέχουσας σελίδας / όλων των φιλτραρισμένων / συγκεκριμένων σελίδων ως `vehicle-models-export.json` |
| **+ Δημιουργία**  | `create`   | Πηγαίνει στο `/settings/vehicle-rules/create`                                                                                |

## Ενέργειες στη γραμμή

Μενού με τρεις τελείες ανά γραμμή:

| Ενέργεια          | Άδεια      | Τι κάνει                                                                                                                   |
| ----------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Προβολή λεπτομερειών** | —    | Ανοίγει τις λεπτομέρειες μοντέλου στο `/settings/vehicle-rules/:id` (Γενικά / Τεχνικά / Ιστορικό καρτέλες)                 |
| **Επεξεργασία**    | `edit`     | Ανοίγει τη φόρμα επεξεργασίας (`/settings/vehicle-rules/:id/edit`) με πλήρες σύνολο πεδίων                                   |
| **Διαγραφή**      | `delete`   | Επιβεβαίωση καταστροφικής ενέργειας με καθυστέρηση 3 δευτερολέπτων πριν ενεργοποιηθεί το κουμπί επιβεβαίωσης. Η γραμμή μοντέλου εξαφανίζεται από τη λίστα |

Το κλικ στη γραμμή (οπουδήποτε εκτός των τσιπ γρήγορης επεξεργασίας) πηγαίνει σε **Προβολή λεπτομερειών**.

## Φόρμα Δημιουργίας / Επεξεργασίας

Το `+ Δημιουργία` (`/settings/vehicle-rules/create`) και το _Επεξεργασία_ (`/settings/vehicle-rules/:id/edit`) μοιράζονται την ίδια διάταξη: μια κάρτα φόρμας αριστερά, μια πλαϊνή μπάρα **Οδηγού Πεδίου** δεξιά με ζωντανή προεπισκόπηση του μοντέλου.

Η φόρμα είναι ομαδοποιημένη σε ενότητες — η Δημιουργία δείχνει μόνο τα βασικά επτά πεδία· η Επεξεργασία προσθέτει τρεις επιπλέον υποενότητες (Τεχνικά Χαρακτηριστικά, Αυτόματες Πολιτικές, Απαιτήσεις Εγγράφων) για προχωρημένες ρυθμίσεις.

### Βασικά πεδία

| Πεδίο            | Απαιτείται | Σημειώσεις                                                                                                                             |
| ---------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Ετικέτα**      | ✓          | Ανθρώπινο όνομα που εμφανίζεται παντού (π.χ. _Xiaomi M365 Pro_). Ελεύθερο κείμενο                                                      |
| **Περιγραφή**    | —          | Επεξεργαστής Markdown· χρησιμοποιείται στις λεπτομέρειες μοντέλου και στις συμβουλές προς τον χειριστή                                |
| **Τύπος Οχήματος** | ✓          | Ένα από: e-scooter / e-bike / cargo-e-bike / e-moped / e-car / e-boat. Καθορίζει το εικονίδιο οδήγησης και τη λογική κατηγορίας       |
| **Κατάσταση**    | ✓          | Ενεργό / Ανενεργό / Αρχειοθετημένο. Το Ανενεργό αφαιρεί το μοντέλο από τον επιλογέα δημιουργίας οχήματος                              |
| **Εικόνα**       | —          | Μεταφορά και απόθεση ή κλικ για μεταφόρτωση. PNG/JPEG/JPG, μέγιστο 10 MB. Εμφανίζεται στη μικρογραφία λίστας και στις λεπτομέρειες οχήματος |
| **Τιμολόγια**    | ✓          | Πολλαπλή επιλογή από [Τιμολόγια οχημάτων](vehicle-tariffs.md). Όλες οι διαδρομές με αυτό το μοντέλο τιμολογούνται με βάση αυτά τα τιμολόγια |
| **Ετικέτες**     | ✓          | Πολλαπλή επιλογή ετικετών σε επίπεδο μοντέλου. Κληρονομούνται από κάθε όχημα αυτού του μοντέλου                                         |

### Τεχνικές Προδιαγραφές (μόνο σε λειτουργία επεξεργασίας)

| Πεδίο                             | Σημειώσεις                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| **Βασικό όριο ταχύτητας (km/h)** | Σκληρό όριο που επιβάλλεται από το firmware IoT σε κάθε διαδρομή                      |
| **Εφεδρική μπαταρία (%)**        | Επίπεδο φόρτισης κάτω από το οποίο το όχημα θεωρείται με χαμηλή μπαταρία             |
| **Εφεδρική αυτονομία (km)**      | Εκτιμώμενη υπολειπόμενη αυτονομία κάτω από την οποία η μονάδα σηματοδοτείται για αντικατάσταση |
| **Ελάχιστη / Μέγιστη τάση μπαταρίας (V)** | Όρια για έγκυρες μετρήσεις κύριας μπαταρίας — οτιδήποτε εκτός σηματοδοτεί _Χρειάζεται διερεύνηση_ |
| **Ελάχιστη / Μέγιστη τάση IoT (V)** | Το ίδιο, για την μπαταρία του tracker του IoT module                                |

### Αυτόματες Πολιτικές (μόνο σε λειτουργία επεξεργασίας)

Εναλλαγή πακέτου: **Διακοπή λόγω χαμηλής μπαταρίας**, **Διακοπή λόγω χαμηλού υπολοίπου**, **Πολλαπλές διαδρομές**, **Αυτόματο κλείδωμα**, καθώς και **Αυτόματη επιστροφή χρημάτων** και **Αυτόματη έκπτωση** με τα δικά τους όρια (απόσταση / χρόνος / ποσό).

### Απαιτήσεις Εγγράφων (μόνο σε λειτουργία επεξεργασίας)

Καθορίζει ποιες φωτογραφίες / έγγραφα πρέπει να υποβάλει ο αναβάτης:

- **Αποδείξεις εκκίνησης** — φωτογραφίες οχήματος στην έναρξη της διαδρομής (εναλλαγή + απαιτείται + πλήθος) και selfie αναβάτη
- **Αποδείξεις στάθμευσης** — φωτογραφίες στάθμευσης στο τέλος της διαδρομής (εναλλαγή + απαιτείται + πλήθος)
- **Επιπλέον έγγραφα** — άδεια οδήγησης / διαβατήριο / ταυτότητα / selfie / άλλα

Αυτοί οι κανόνες διαβάζονται από την εφαρμογή Rider App κατά την έναρξη / λήξη διαδρομής σε όχημα που ανήκει σε αυτό το μοντέλο.

## Σχέση με άλλες οντότητες

- **[Τιμολόγια οχημάτων](vehicle-tariffs.md)** — οι γραμμές τιμολόγησης που επιλέγετε στο πεδίο **Τιμολόγια**. Ένα μοντέλο χωρίς τιμολόγια δεν μπορεί να τιμολογήσει διαδρομή
- **[Οχήματα](../../operations/fleet/vehicles.md)** — φυσικές μονάδες που δείχνουν σε αυτό το μοντέλο μέσω του πεδίου _Vehicle Model_ της [φόρμας οχήματος](../../operations/fleet/vehicle-create-edit.md). Το μοντέλο ορίζει την πολιτική· το όχημα έχει το IoT, την ετικέτα και την τοποθεσία
- **Ετικέτες** — ετικέτες σε επίπεδο μοντέλου που κληρονομούνται από κάθε όχημα αυτού του μοντέλου, επιπλέον των ετικετών σε επίπεδο οχήματος που εφαρμόζονται απευθείας στη μονάδα. Οι διαδρομές κληρονομούν και τα δύο στην έναρξη της διαδρομής

## Τυπικές ροές εργασίας

- **Εγκατάσταση νέου μοντέλου** — `+ Δημιουργία` → συμπληρώστε Ετικέτα / Τύπο / Κατάσταση / Εικόνα → επιλέξτε τα τιμολόγια που ισχύουν → αποθήκευση → ανοίξτε το νέο μοντέλο από τη λίστα και κάντε κλικ στο _Επεξεργασία_ για να ορίσετε Τεχνικές Προδιαγραφές και πολιτικές
- **Απόσυρση μοντέλου** — ανοίξτε το μοντέλο → _Επεξεργασία_ → ορίστε Κατάσταση = _Αρχειοθετημένο_ → αποθήκευση. Τα υπάρχοντα οχήματα συνεχίζουν να λειτουργούν· το μοντέλο απλώς δεν εμφανίζεται πλέον στον επιλογέα δημιουργίας οχήματος
- **Αλλαγή τιμολογίου σε όλο το στόλο** — επεξεργαστείτε το μοντέλο → αλλάξτε τιμολόγια → αποθήκευση. Όλα τα οχήματα αυτού του μοντέλου αρχίζουν να τιμολογούνται με τα νέα τιμολόγια από την επόμενη διαδρομή
- **Μαζική εισαγωγή μετά από μετεγκατάσταση** — Εξαγωγή από το staging → Εισαγωγή του αρχείου JSON εδώ → επανασύνδεση τιμολογίων και ετικετών χειροκίνητα σε κάθε νέο μοντέλο (η εισαγωγή αφαιρεί σκόπιμα αυτές τις αναφορές)
- **Προσαρμογή απαιτήσεων φωτογραφιών** — Επεξεργασία → Απαιτήσεις Εγγράφων → εναλλαγή Αποδείξεων εκκίνησης / στάθμευσης → αποθήκευση. Η εφαρμογή Rider App αναλαμβάνει τους νέους κανόνες στην επόμενη έναρξη διαδρομής

## Συμβουλές

- **Ορίστε τα τιμολόγια πριν ενεργοποιήσετε το Ενεργό** — ένα μοντέλο χωρίς τιμολόγια θα απορρίψει αιτήματα τιμολόγησης διαδρομής
- **Χρησιμοποιήστε το Ανενεργό, όχι τη Διαγραφή, για απόσυρση** — το Ανενεργό κρύβει το μοντέλο από τη δημιουργία νέου οχήματος αλλά διατηρεί το ιστορικό ανέπαφο. Η Διαγραφή είναι μη αναστρέψιμη και μπλοκάρεται από την καθυστέρηση επιβεβαίωσης 3 δευτερολέπτων για λόγο
- **Η εικόνα έχει σημασία** — η μικρογραφία λίστας και οι επιλογείς οχημάτων του χειριστή χρησιμοποιούν αυτή την εικόνα. Κόψτε σε τετράγωνο με διαφανές φόντο για την καθαρότερη εμφάνιση
- **Οι ετικέτες εδώ είναι σε επίπεδο μοντέλου, όχι οχήματος** — η εφαρμογή ετικέτας εδώ την τοποθετεί σε κάθε όχημα αυτού του μοντέλου. Για ετικέτες συγκεκριμένης μονάδας, επεξεργαστείτε το μεμονωμένο όχημα
- **Οι ειδοποιήσεις τεχνικών προδιαγραφών** — η εφεδρική μπαταρία και τα όρια τάσης τροφοδοτούν τον ενεργοποιητή _Χρειάζεται διερεύνηση_; ο πολύ αυστηρός ορισμός τους πλημμυρίζει την ουρά ειδοποιήσεων
- **Η πλαϊνή μπάρα Οδηγού Πεδίου ενημερώνεται καθώς εστιάζετε σε πεδίο** — διαβάστε την την πρώτη φορά που δημιουργείτε μοντέλο, είναι πιο ενημερωμένη από αυτό το άρθρο
