# Ζώνες

Η σελίδα Ζώνες (`/zones`) είναι όπου σχεδιάζετε τους **αόρατους κανόνες της περιοχής υπηρεσίας σας** — ζώνες στάθμευσης, απαγορευμένες, χαμηλής ταχύτητας, φόρτισης και άλλες πολύγωνες περιοχές που αλλάζουν τη συμπεριφορά οχημάτων και πελατών όταν διασχίζουν ένα όριο. Κάθε ζώνη είναι ένα μόνο πολύγωνο στον χάρτη συν έναν τύπο, μια κατάσταση, προαιρετικές παραμέτρους (ταχύτητα, τιμή, χωρητικότητα οχήματος) και ετικέτες.

Οι ζώνες καθορίζουν τη συμπεριφορά εκτέλεσης για τα [Οχήματα](../../operations/fleet/vehicles.md) — εισέρχεστε σε πολύγωνο απαγόρευσης οδήγησης και το όχημα απενεργοποιείται· σταθμεύετε μέσα σε πολύγωνο με πληρωμένη στάθμευση και εφαρμόζεται ο αντίστοιχος τιμοκατάλογος.

Απαιτούμενη άδεια: **Ζώνες** (`u7v8w9`). Οι υπο-άδειες `create` / `edit` / `delete` ελέγχουν τις αντίστοιχες ενέργειες.

## Τι είναι μια ζώνη

Μια ζώνη έχει τέσσερα βασικά μέρη:

1. **Τύπος** — επιλέγει το χρώμα και τον κανόνα που εφαρμόζεται κατά την εκτέλεση (βλ. τον πίνακα παρακάτω)
2. **Πολύγωνο** — ακριβώς ένα πολύγωνο, σχεδιασμένο στον χάρτη· επιτρέπονται κοίλα σχήματα, όχι κενά
3. **Παράμετροι** — εξαρτώνται από τον τύπο: ταχύτητα (χαμηλής ταχύτητας), τιμή (πληρωμένη στάθμευση), ποσό (φόρτιση), επιτρεπόμενα οχήματα (στάθμευση, πληρωμένη στάθμευση, επαναζύγιση)
4. **Κατάσταση** — `Ενεργό` (εφαρμόζεται), `Ανενεργό` (αποθηκευμένο αλλά αγνοείται), `Αρχειοθετημένο` (κρυφό από τις περισσότερες λίστες)

### Τύποι ζωνών

| Τύπος            | Χρώμα      | Τι κάνει                                                           |
| ---------------- | ---------- | ----------------------------------------------------------------- |
| **Απαγορευμένη** | Μαύρο      | Τα οχήματα δεν μπορούν να εισέλθουν ή να λειτουργήσουν εδώ        |
| **Απαγορευμένη στάθμευση** | Κόκκινο    | Οι αναβάτες δεν μπορούν να τερματίσουν διαδρομή εδώ               |
| **Απαγορευμένη οδήγηση** | Μωβ        | Τα οχήματα απενεργοποιούνται / αρνούνται να ξεκινήσουν μέσα σε αυτό το πολύγωνο |
| **Χαμηλής ταχύτητας** | Μπλε       | Η μέγιστη ταχύτητα περιορίζεται στην ρυθμισμένη τιμή `speed` (χλμ/ώρα) |
| **Στάθμευση**    | Πράσινο    | Ορισμένη στάθμευση; προαιρετική χωρητικότητα οχημάτων             |
| **Πληρωμένη στάθμευση** | Πορτοκαλί | Στάθμευση με τιμή και προαιρετική χωρητικότητα                     |
| **Φόρτιση**      | Σκούρο πράσινο | Ζώνη ανταμοιβής — εφαρμόζεται `amount` όταν οι αναβάτες τερματίζουν εδώ |
| **Συντήρηση**    | Σκούρο κόκκινο | Εσωτερική ένδειξη για λειτουργίες· τα οχήματα μέσα εξαιρούνται από τη ροή αναβατών |
| **Επαναζύγιση**  | Σκούρο μπλε | Περιοχή στόχος για επαναζύγιση στόλου; προαιρετική χωρητικότητα οχημάτων |

## Τρόποι προβολής

Μια ομάδα επιλογής στην κεφαλίδα της σελίδας εναλλάσσει μεταξύ τριών προβολών — ίδια δεδομένα, διαφορετική οπτική.

| Τρόπος     | Κατάλληλο για                                                      |
| ---------- | ----------------------------------------------------------------- |
| **Πίνακας** | Μαζικές επεξεργασίες, ταξινόμηση κατά όνομα/τύπο/κατάσταση, σελιδοποιημένη περιήγηση |
| **Κάρτες** | Οπτική σάρωση με μικρό χάρτη ανά ζώνη· απεριόριστο κύλιση          |
| **Χάρτης** | Εμφάνιση κάθε ζώνης επάνω στον πραγματικό χάρτη — χρήσιμο για ελέγχους κάλυψης |

## Φίλτρα

| Φίλτρο  | Τύπος     | Σημειώσεις                              |
| ------- | --------- | -------------------------------------- |
| Αναζήτηση | Κείμενο   | Αναζητά το όνομα και την περιγραφή της ζώνης |
| Κατάσταση | Αναπτυσσόμενο | `Ενεργό` / `Ανενεργό` (ή `Όλα`)         |
| Τύπος   | Αναπτυσσόμενο | Ένας από τους 9 τύπους (ή `Όλα`)          |

Τα φίλτρα εφαρμόζονται σε όλους τους τρόπους προβολής. Η προβολή Χάρτη φορτώνει **όλες** τις αντίστοιχες ζώνες (χωρίς σελιδοποίηση)· οι Πίνακας και Κάρτες σελιδοποιούν.

## Στήλες (Προβολή Πίνακα)

| Στήλη           | Ταξινομήσιμη; | Περιεχόμενο                                               |
| --------------- | ------------- | --------------------------------------------------------- |
| **Όνομα ζώνης** | ✓             | Ετικέτα + έγχρωμο δείγμα τύπου; σύνδεσμος στη σελίδα λεπτομερειών ζώνης |
| **Περιγραφή**   | —             | Προαιρετική ελεύθερη περιγραφή                            |
| **Τύπος**       | ✓             | Έγχρωμη ετικέτα τύπου (βλ. πίνακα τύπων παραπάνω)        |
| **Κατάσταση**   | ✓             | `Ενεργό` / `Ανενεργό` / `Αρχειοθετημένο`                  |
| **Ετικέτες**    | —             | Ετικέτες που εφαρμόζονται στη ζώνη                         |

## Ενέργειες γραμμής

Μενού με τρεις τελείες ανά γραμμή. Οι διαθέσιμες ενέργειες εξαρτώνται από τα δικαιώματα:

| Ενέργεια          | Άδεια      | Τι κάνει                                                  |
| ----------------- | ---------- | --------------------------------------------------------- |
| **Προβολή λεπτομερειών** | —          | Άνοιγμα της σελίδας λεπτομερειών ζώνης (χάρτης + μεταδεδομένα) |
| **Επεξεργασία**    | `edit`     | Άνοιγμα της φόρμας επεξεργασίας για τη γεωμετρία/ιδιότητες |
| **Διαγραφή**      | `delete`   | Μόνιμη αφαίρεση — απαιτεί κράτημα 3 δευτερολέπτων για επιβεβαίωση |

## Μαζικές ενέργειες

Επιλέξτε γραμμές στην προβολή Πίνακα για να εμφανιστεί η γραμμή μαζικών ενεργειών. Όλες οι μαζικές ενέργειες που τροποποιούν απαιτούν την ικανότητα `edit`:

- **Αλλαγή τύπου** — βάψτε πολλές ζώνες σε νέο τύπο ταυτόχρονα (οι παράμετροι επαναρυθμίζονται ανάλογα)
- **Αλλαγή ορίου οχημάτων** — ορίστε το `allowedVehicles` σε όλη την επιλογή (σχετικό για στάθμευση / πληρωμένη στάθμευση / επαναζύγιση)
- **Αλλαγή τιμής** — ορίστε την αριθμητική τιμή ειδική για τον τύπο (ταχύτητα / τιμή / ποσό)
- **Αλλαγή κατάστασης** — εναλλαγή Ενεργό ↔ Ανενεργό μαζικά
- **Αλλαγή ετικετών** — προσθήκη ή αντικατάσταση ετικετών σε όλη την επιλογή
- **Εξαγωγή επιλεγμένων** — κατεβάστε μόνο τις επιλεγμένες ζώνες ως JSON (δεν απαιτείται άδεια· γίνεται στον πελάτη)

## Δημιουργία — ο οδηγός 5 βημάτων

Το `+ Δημιουργία` ανοίγει μια καθοδηγούμενη φόρμα. Μπορείτε να πηδήξετε ελεύθερα προς τα πίσω· τα άλματα προς τα εμπρός ξεκλειδώνονται μόνο όταν το τρέχον βήμα είναι έγκυρο.

1. **Όνομα & περιγραφή** — `Label` (απαραίτητο) και προαιρετικό `Description`
2. **Κατηγοριοποίηση** — `Type` (απαραίτητο, επιλέγει το χρώμα και το σχήμα παραμέτρου), `Status` (Ενεργό / Ανενεργό / Αρχειοθετημένο), `Tags`
3. **Παράμετροι** — αριθμητικές είσοδοι ειδικές για τον τύπο με ρυθμιστικό 0–100 για γρήγορη εισαγωγή: ταχύτητα (km/h), τιμή, ποσότητα ή επιτρεπόμενα οχήματα. Οι τύποι χωρίς παραμέτρους εμφανίζουν ειδοποίηση "χωρίς παραμέτρους" και επιτρέπουν την προώθηση
4. **Γεωμετρία** — σχεδιάστε ακριβώς **1 πολύγωνο** στον χάρτη. Οι υπάρχουσες ζώνες μπορούν να ενεργοποιηθούν ως διακεκομμένη επικάλυψη για να αποφύγετε την επικάλυψη. Έλεγχοι χάρτη: σχεδίαση, επεξεργασία, προσθήκη σημείων, αναίρεση (έως 20 βήματα), διαγραφή, ζουμ, προσαρμογή ορίων, εντοπισμός θέσης, πλήρης οθόνη
5. **Ανασκόπηση** — τελικό αναγνώσιμο σύνοψη κάθε πεδίου συν τον αριθμό σημείων του πολυγώνου

Η αποθήκευση δημιουργεί τη ζώνη και σας μεταφέρει στη σελίδα λεπτομερειών της.

## Φόρμα επεξεργασίας

Το `Edit` επαναχρησιμοποιεί το ίδιο πλαίσιο αλλά σε φόρμα μίας σελίδας (χωρίς βηματιστή) — αλλάξτε το label, τον τύπο, την κατάσταση, τις παραμέτρους, τις ετικέτες ή ξανασχεδιάστε το πολύγωνο, και μετά Αποθήκευση. Η προστασία μη αποθηκευμένων αλλαγών προειδοποιεί πριν φύγετε από τη σελίδα.

## Εισαγωγή / Εξαγωγή

Δύο κουμπιά περιγράμματος δίπλα στο **+ Δημιουργία**:

- **Εισαγωγή** — επιλέξτε ένα αρχείο `.json` που εξήχθη νωρίτερα· ο Πίνακας ελέγχου επικυρώνει το περιεχόμενο και δημιουργεί ζώνες στον διακομιστή. Απαιτεί την ικανότητα `create`
- **Εξαγωγή** — ανοίγει διάλογο όπου επιλέγετε τι θα κατεβάσετε: την τρέχουσα σελίδα, όλες τις σελίδες με τα τρέχοντα φίλτρα ή τα πάντα. Η γραμμή μαζικών ενεργειών προσφέρει επίσης "Εξαγωγή επιλεγμένων" για τις επισημασμένες γραμμές

## Σελίδα λεπτομερειών

Κάνοντας κλικ σε μια γραμμή (ή _Προβολή λεπτομερειών_) ανοίγει η σελίδα λεπτομερειών της ζώνης με:

- Ζωντανή προεπισκόπηση του πολυγώνου στον χάρτη
- Κάρτα βασικών πληροφοριών (label, περιγραφή, τύπος, κατάσταση, χρώμα)
- Κάρτα παραμέτρων (ταχύτητα / τιμή / ποσότητα / επιτρεπόμενα οχήματα, όταν ισχύει)
- Ετικέτες
- Χρονικές σφραγίδες δημιουργίας / ενημέρωσης
- Κουμπιά Επεξεργασία και Διαγραφή στην κεφαλίδα (με δικαιώματα)

## Τυπικές ροές εργασίας

- **Εκκίνηση νέας πόλης** — Εισαγωγή πακέτου JSON ζωνών αν υπάρχει, αλλιώς σχεδιάστε πρώτα το δακτύλιο απαγόρευσης, μετά πολύγωνα στάθμευσης μέσα σε αυτόν
- **Προσαρμογή περιοχής χαμηλής ταχύτητας** — Επεξεργασία → βήμα 3 → αυξήστε την τιμή ταχύτητας → Αποθήκευση. Ενεργό αμέσως
- **Κλείσιμο χώρου στάθμευσης για μια μέρα** — Επεξεργασία → Κατάσταση = Ανενεργό → Αποθήκευση. Επαναφέρετε όταν ανοίξει ξανά ο χώρος
- **Επαναζωνοποίηση μετά από αλλαγή πόλης** — μαζική επιλογή επηρεαζόμενων ζωνών → Αλλαγή τύπου → επιβεβαίωση. Οι παλιές παράμετροι ειδικές για τύπο διαγράφονται αυτόματα
- **Έλεγχος κάλυψης** — μεταβείτε σε προβολή Χάρτη, φιλτράρετε με Κατάσταση = Ενεργό, ελέγξτε για κενά και επικαλύψεις

## Συμβουλές

- **Ο τύπος καθορίζει τα πάντα** — χρώμα, σχήμα παραμέτρου, κανόνα χρόνου εκτέλεσης. Η επιλογή λάθος τύπου είναι ο πιο συνηθισμένος λόγος επανεπεξεργασίας
- **Ένα πολύγωνο ανά ζώνη** — χωρίστε πολύπλοκες περιοχές σε πολλαπλές ζώνες· ο επεξεργαστής επιβάλλει ένα μόνο πολύγωνο
- **Επιτρέπονται επικαλυπτόμενες ζώνες** — κερδίζει ο πιο περιοριστικός κανόνας (απαγόρευση > απαγόρευση οδήγησης > χαμηλή ταχύτητα), οπότε μη διστάζετε να τοποθετήσετε χαμηλή ταχύτητα μέσα σε πολύγωνο στάθμευσης
- **Χρησιμοποιήστε την διακεκομμένη επικάλυψη** — ενεργοποιήστε "Εμφάνιση υπαρχουσών ζωνών στον χάρτη" στον επεξεργαστή για να αποφύγετε τυχαία επικάλυψη με γειτονικές ζώνες
- **Ανενεργό ≠ Διαγραμμένο** — αλλάξτε την Κατάσταση όταν θέλετε να παύσετε προσωρινά μια ζώνη· η Διαγραφή είναι μόνιμη (η επιβεβαίωση με κράτημα 3 δευτερολέπτων είναι το δίχτυ ασφαλείας)
- **Ετικετοποιήστε τις ζώνες σας** — οι ετικέτες είναι το μόνο φίλτρο πολλαπλής επιλογής που διατηρείται ανάμεσα σε λειτουργίες προβολής. Χρησιμοποιήστε τις για ομαδοποίηση κατά περιοχή, καμπάνια ή ιδιοκτησία
- **Εξαγωγή πριν από μαζικές επεξεργασίες** — ένα κλικ στον διάλογο εξαγωγής δημιουργεί αντίγραφο ασφαλείας ολόκληρου του συνόλου, ώστε μια αποτυχημένη μαζική αλλαγή να αναιρεθεί με μια Εισαγωγή
