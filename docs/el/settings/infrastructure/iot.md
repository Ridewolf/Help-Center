# Συσκευές IoT

Η σελίδα IoT (`/iot`) είναι το **απόθεμα υλικού** — κάθε μονάδα ιχνηλάτη / κλειδώματος που ανήκει στον στόλο σας, ανεξάρτητα από το αν είναι αυτή τη στιγμή προσαρτημένη σε όχημα. Κάθε γραμμή αντιστοιχεί σε μία φυσική συσκευή που αναγνωρίζεται από το **IMEI** της, με ζωντανή τηλεμετρία (κατάσταση σύνδεσης, GPS, σήμα GSM, μπαταρία) που ανανεώνεται από το τελευταίο ping.

Αυτή είναι η πλευρά της συσκευής που αντικατοπτρίζει τα [Οχήματα](../../operations/fleet/vehicles.md): ένα όχημα χωρίς IoT δεν μπορεί να παρακολουθηθεί ή να ελεγχθεί· ένα IoT χωρίς όχημα είναι απλώς μη δεσμευμένο υλικό που κάθεται στο ράφι.

Απαραίτητη άδεια: **Συσκευές IoT** (`n8p9q9`). Οι υπο-άδειες ελέγχουν το `edit` / `send-command` / `delete` και η μαζική ενέργεια _Δημιουργία οχήματος_ δανείζεται από το `operations.vehicles.create`.

## Πώς φτάνουν οι συσκευές εδώ

Οι συσκευές δεν ανιχνεύονται αυτόματα — τις καταχωρείτε καθώς λαμβάνετε αποστολές:

1. **Προμήθεια** — αγοράζετε μονάδες IoT από προμηθευτή (Omni, Segway, Okai κ.ά.). Κάθε μονάδα έχει μοναδικό **IMEI** τυπωμένο στο κουτί / αυτοκόλλητο
2. **+ Δημιουργία** εδώ — εισάγετε Όνομα, IMEI, Προμηθευτή, Κατάσταση. Η συσκευή είναι τώρα στο απόθεμα αλλά μη δεσμευμένη
3. **Δέσιμο με όχημα** — γίνεται από το [Δημιουργία / Επεξεργασία Οχήματος](../../operations/fleet/vehicle-create-edit.md) επιλέγοντας αυτό το IoT στον επιλογέα συσκευής. Ένα IoT ανά όχημα, ένα όχημα ανά IoT
4. **Η τηλεμετρία αρχίζει να ρέει** μόλις η συσκευή ενεργοποιηθεί με SIM και συνδεθεί στον MQTT broker του Ridewolf. Η λίστα δείχνει το πιο πρόσφατο στιγμιότυπο — ανανεώστε ή περιμένετε το AutoRefresh

Εναλλακτικά, χρησιμοποιήστε τη μαζική ενέργεια **Δημιουργία οχήματος** παρακάτω για να δημιουργήσετε ένα νέο όχημα για κάθε επιλεγμένο IoT σε μία κίνηση (π.χ. μετά την εισαγωγή παρτίδας νέων σκούτερ).

## Φίλτρα

| Φίλτρο | Τύπος    | Σημειώσεις                                  |
| ------ | -------- | ------------------------------------------ |
| Αναζήτηση | Κείμενο  | Ταιριάζει με όνομα και IMEI                 |
| Κατάσταση | Αναπτυσσόμενο | `Όλα` / `Ενεργό` / `Ανενεργό` / `Αρχειοθετημένο` |

Τα φίλτρα συγχρονίζονται με το URL (η ανανέωση διατηρεί την προβολή σας) και επανέρχονται στις προεπιλογές μέσω του συνδέσμου Καθαρισμός στη γραμμή φίλτρων.

## Στήλες

| Στήλη           | Ταξινομήσιμη; | Περιεχόμενο                                                                 |
| --------------- | ------------- | -------------------------------------------------------------------------- |
| **Όνομα**       | ναι           | Όνομα συσκευής + σύντομο ID· κάντε κλικ στη γραμμή για να ανοίξετε τη σελίδα λεπτομερειών | 
| **Κλείδωμα**    | —             | Κατάσταση κλειδώματος (Κλειδωμένο / Ξεκλειδωμένο) από την τελευταία εντολή MQTT | 
| **Σε σύνδεση**  | —             | Πράσινη κουκκίδα αν το τελευταίο ping είναι εντός παραθύρου φρεσκάδας· κόκκινη αν παλιό | 
| **GPS**         | —             | Έγκυρη / Μη έγκυρη ένδειξη σήματος GPS                                   |
| **GSM**         | —             | Ισχύς σήματος (κλίμακα 0-32, κόκκινο ≤10, κίτρινο ≤20, πράσινο ≤32)      |
| **Μπαταρία**    | ναι           | Ποσοστό μπαταρίας με έγχρωμη μπάρα                                        |
| **Κατάσταση**   | ναι           | Ετικέτα `Ενεργό` / `Ανενεργό` / `Αρχειοθετημένο`                          |
| **Τελευταίο Σήμα** | ναι         | Χρόνος από το τελευταίο πακέτο τηλεμετρίας (σχετικός, π.χ. "πριν 5λ")    |

## Ενέργειες γραμμής

Μενού με τρεις τελείες ανά γραμμή. Οι διαθέσιμες ενέργειες εξαρτώνται από τις άδειες:

| Ενέργεια           | Άδεια       | Τι κάνει                                                                   |
| ------------------ | ----------- | -------------------------------------------------------------------------- |
| **Προβολή λεπτομερειών** | —           | Ανοίγει τη σελίδα λεπτομερειών συσκευής (Καρτέλες: Λεπτομέρειες / Δραστηριότητα / Εντολές / Ιστορικό) |
| **Προβολή τοποθεσίας** | —           | Ανοίγει τις τελευταίες γνωστές συντεταγμένες GPS στο Google Maps (νέα καρτέλα) |
| **Επεξεργασία**    | `edit`      | Ανοίγει τη φόρμα επεξεργασίας (Όνομα / IMEI / Προμηθευτής / Κατάσταση)     |
| **Διαγραφή**       | `delete`    | Αφαιρεί την εγγραφή της συσκευής. Η επιβεβαίωση έχει καθυστέρηση 3 δευτερολέπτων πριν το ξεκλείδωμα |

## Μαζικές ενέργειες

Επιλέξτε πολλαπλές γραμμές (κουτάκι στην κεφαλίδα ή ανά γραμμή) για να εμφανιστεί η γραμμή μαζικών ενεργειών. Οι ενέργειες ελέγχονται επίσης από άδειες — αυτές που δεν μπορείτε να εκτελέσετε είναι κρυφές, όχι γκριζαρισμένες:

| Ενέργεια                    | Άδεια             | Τι κάνει                                                                                                         |
| --------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Δημιουργία οχήματος**     | `vehicles.create`  | Δημιουργεί ένα νέο όχημα για κάθε επιλεγμένο IoT, με αυτόματο όνομα με πρόθεμα της εταιρείας σας· επιλέξτε μοντέλο οχήματος + προαιρετικές ετικέτες |
| **Αλλαγή κατάστασης**       | `edit`            | Ορίζει Ενεργό / Ανενεργό / Αρχειοθετημένο για όλα τα επιλεγμένα                                                        |
| **Δοκιμή σύνδεσης (Beep)** | `send-command`    | Στέλνει εντολή `Beep` σε κάθε συσκευή — χρήσιμο για φυσικό εντοπισμό μονάδων σε αποθήκη                                |
| **Αποστολή εντολής**         | `send-command`    | Επιλέξτε εντολή από τον προμηθευτή της πρώτης επιλογής (προεπιλεγμένη ή σύνθετη διαδικασία πολλαπλών βημάτων) και στείλτε σε όλες |
| **Διαγραφή**                | `delete`          | Μαζική διαγραφή με παράθυρο επιβεβαίωσης (καθυστέρηση 3 δευτερολέπτων)                                              |

Οι μαζικές λειτουργίες εκτελούνται διαδοχικά με πρόοδο (`επεξεργασμένα / σύνολο`) και πίνακα αποτυχημένων — μερική επιτυχία είναι φυσιολογική, οι αποτυχημένες συσκευές παραμένουν επιλεγμένες για να δοκιμάσετε ξανά ή να ελέγξετε.

## Σελίδα λεπτομερειών

Κάνοντας κλικ σε μια γραμμή (ή _Προβολή λεπτομερειών_) ανοίγει η σελίδα λεπτομερειών συσκευής. Τέσσερις καρτέλες:

- **Λεπτομέρειες** — IMEI / Κατασκευαστής / Κατάσταση / συντεταγμένες με ενσωματωμένη προεπισκόπηση Google Maps· πλήρες μπλοκ τηλεμετρίας (λειτουργία ταχύτητας, εγκυρότητα GPS, ακατέργαστη τιμή GSM, μπαταρία, κατάσταση κλειδώματος)
- **Δραστηριότητα** — γενικό αρχείο δραστηριότητας για αυτή τη συσκευή (`entity-type=iot`)
- **Εντολές** — αποστολέας εντολών με γνώση κατασκευαστή. Ο ίδιος μηχανισμός χρησιμοποιείται στην καρτέλα Εντολές του [Vehicle Detail](../../operations/fleet/vehicle-detail.md) — δείτε το άρθρο για τη διαδικασία / προχωρημένη ροή
- **Ιστορικό** — ιστορικό τηλεμετρίας / αρχείο πακέτων

Η κεφαλίδα εμφανίζει το συνδεδεμένο Όχημα (αν υπάρχει) ως chip — κάντε κλικ για να μεταβείτε στη σελίδα λεπτομερειών του οχήματος. Ένα αναδυόμενο μενού **Ενέργειες** στην κεφαλίδα προσφέρει Επεξεργασία / Προβολή στο Google Maps / Διαγραφή.

## Φόρμα Δημιουργίας / Επεξεργασίας

Η φόρμα IoT (`+ Δημιουργία` ή _Επεξεργασία_) έχει τέσσερα πεδία, όλα υποχρεωτικά:

- **Όνομα** — σύντομη ετικέτα που θα βλέπετε στις λίστες (π.χ. `SCOOTER-014`). Ελεύθερο κείμενο
- **IMEI** — το μοναδικό αναγνωριστικό υλικού της συσκευής (χρησιμοποιείται για τη σύνδεση με όχημα και για τη λήψη κίνησης MQTT). Μόλις οριστεί, θεωρείται αμετάβλητο — η αλλαγή του σε αναπτυγμένη συσκευή θα διακόψει την τηλεμετρία μέχρι να ενημερωθεί η σύνδεση οχήματος
- **Κατασκευαστής** — η συμβολοσειρά κατασκευαστή (π.χ. `omni`, `segway`). Καθορίζει το σύνολο εντολών που καταλαβαίνει η συσκευή — να είστε ακριβείς, η αναζήτηση κατασκευαστή είναι ευαίσθητη σε πεζά-κεφαλαία
- **Κατάσταση** — `Ενεργό` (προεπιλογή) / `Ανενεργό` (κρυφό από επιλογέα για σύνδεση οχήματος) / `Αρχειοθετημένο` (αποσυρμένο υλικό)

Δεν υπάρχει ενσωματωμένη φόρμα για σύνδεση με όχημα εδώ — αυτή η λειτουργία ανήκει στη φόρμα Δημιουργίας / Επεξεργασίας Οχήματος.

## Τυπικές ροές εργασίας

- **Εγκατάσταση αποστολής 50 ιχνηλατών** — Δημιουργήστε κάθε ένα (ή εισαγάγετε μέσω CSV, αν έχετε) → επιλέξτε όλα → _Δημιουργία οχήματος_ με το σωστό μοντέλο οχήματος → ολοκληρώθηκε· κάθε IoT έχει τώρα συνδεδεμένο όχημα σε κατάσταση `needs_investigation` έτοιμο για QA
- **Εύρεση χαμένης μονάδας στην αποθήκη** — Φιλτράρετε με όνομα/IMEI → ενέργεια γραμμής _Δοκιμή σύνδεσης (Beep)_ ή ομαδικό Beep → περπατήστε ακούγοντας
- **Απόσυρση κατεστραμμένης συσκευής** — Επεξεργασία → ορίστε Κατάσταση = Αρχειοθετημένο (μη Διαγραφή — διατηρείται το αρχείο δραστηριότητας). Αν υπήρχε σύνδεση με όχημα, αποσυνδέστε πρώτα από τη φόρμα επεξεργασίας οχήματος
- **Εκτεταμένη αποστολή εντολών ανά κατασκευαστή** (π.χ. ρύθμιση firmware) — Φιλτράρετε με πρότυπο ονόματος ή τηλεμετρία, επιλέξτε όλα τα ταιριαστά → _Αποστολή εντολής_ → επιλέξτε την εντολή κατασκευαστή και αφήστε την να εκτελεστεί με πρόοδο
- **Διερεύνηση "φανταστικού" οχήματος** (σε σύνδεση αλλά χαμένο) — Προβολή τοποθεσίας → αν το GPS είναι Άκυρο, δοκιμάστε Beep· αν παραμένει σιωπηλό, υποψιαστείτε SIM / μπαταρία
- **Διασταύρωση τηλεμετρίας με εκδηλώσεις** — ανοίξτε την αναφορά [Events report](../../analytics/reports/events.md) φιλτραρισμένη με το όχημα αυτού του IoT για συσχέτιση κατάστασης υλικού με δραστηριότητα πλατφόρμας

## Συμβουλές

- **Το IMEI είναι το κλειδί σύνδεσης** παντού — σύνδεση οχήματος, δρομολόγηση MQTT, εισιτήρια υποστήριξης. Πληκτρολογήστε το μία φορά, αντιγράψτε το για πάντα
- **Το πεδίο Κατασκευαστής είναι δομικό, όχι διακοσμητικό** — καθοδηγεί τον κατάλογο εντολών στην καρτέλα Εντολές. Λάθος ορθογραφία `omni` ως `Omni` μπορεί να δώσει κενή λίστα εντολών
- **Σε σύνδεση ≠ Ενεργό** — Σε σύνδεση σημαίνει ζωντανό σήμα τηλεμετρίας· η Κατάσταση είναι σημαία διαχειριστή. Μια Ενεργή συσκευή μπορεί να είναι Εκτός σύνδεσης (νεκρή μπαταρία, χωρίς GSM)· μια Αρχειοθετημένη μπορεί ακόμα να στέλνει σήματα μέχρι να απενεργοποιηθεί
- **Η ομαδική αποστολή εντολής χρησιμοποιεί τον κατασκευαστή της πρώτης γραμμής** — αν η επιλογή σας περιλαμβάνει πολλούς κατασκευαστές, χωρίστε τα σε παρτίδες ανά κατασκευαστή ή θα λάβετε συγκεχυμένη λίστα εντολών
- **Η Δημιουργία οχήματος δημιουργεί σκόπιμα οχήματα `needs_investigation`** — χρειάζονται ανθρώπινη επιβεβαίωση ότι η σύνδεση είναι σωστή πριν ενεργοποιηθούν. Η ομαδική επισήμανση κατά τη δημιουργία διευκολύνει τον επόμενο έλεγχο QA
- **Δεν υπάρχει κουμπί "αναγκαστικής επανασύνδεσης"** — αν η τηλεμετρία σταματήσει μετά από αλλαγή, ελέγξτε τη σύνδεση Vehicle → IoT (επεξεργασία οχήματος) και τη SIM / τροφοδοσία της συσκευής, όχι αυτή τη σελίδα
- **Οι αρχειοθετημένες συσκευές παραμένουν αναζητήσιμες** με IMEI — χρήσιμο όταν μια παλιά μονάδα επιστρέφει από επισκευή και πρέπει να την επαναφέρετε (επιστροφή σε Ενεργό)
- **Το Τελευταίο Σήμα είναι ο ταχύτερος έλεγχος υγείας** — ταξινομήστε φθίνουσα για να βρείτε πρώτα τις παλιές συσκευές· οτιδήποτε > 24ωρο σε Ενεργή γραμμή αξίζει έλεγχο
