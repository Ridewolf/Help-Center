# Ρόλοι

Η σελίδα Ρόλοι (`/settings/roles`) είναι όπου ορίζετε **τι μπορούν να κάνουν οι χειριστές** στον Πίνακα ελέγχου. Ένας ρόλος είναι ένα ονομασμένο πακέτο δικαιωμάτων· κάθε χειριστής έχει ακριβώς έναν ρόλο· τα δικαιώματα καθορίζουν ποιες σελίδες βλέπουν και ποιες ενέργειες μπορούν να εκτελέσουν.

Συνδυάστε αυτή τη σελίδα με τους [Χειριστές](operators.md) — Οι Χειριστές αναθέτουν ρόλους σε άτομα, οι Ρόλοι ορίζουν τι μπορεί να κάνει κάθε ρόλος στην πράξη.

Απαιτούμενο δικαίωμα: **Ρόλοι** (`d4e5f6`).

## Πώς λειτουργούν τα δικαιώματα

Κάθε σελίδα και ενέργεια στον Πίνακα ελέγχου προστατεύεται από ένα **αναγνωριστικό δικαιώματος** (π.χ. `k7m8n9` για Οχήματα, `e4f5h6` για Πελάτες). Ένας ρόλος είναι ουσιαστικά μια λίστα ελέγχου αυτών των αναγνωριστικών δικαιωμάτων:

- Ένας χειριστής μπορεί να δει μια σελίδα μόνο αν ο ρόλος του έχει το δικαίωμα της σελίδας
- Μια ενέργεια σε γραμμή (Επεξεργασία, Διαγραφή κ.λπ.) κρύβεται όταν ο ρόλος δεν έχει το αντίστοιχο υπο-δικαίωμα
- Τα δικαιώματα αξιολογούνται **ανά αίτημα** — αλλάζετε έναν ρόλο και ο χειριστής βλέπει την αλλαγή στην επόμενη φόρτωση σελίδας (ή νωρίτερα)

Δεν υπάρχει **κληρονομικότητα** μεταξύ ρόλων — κάθε ρόλος είναι ανεξάρτητος. Οι ρόλοι με μεγαλύτερη εμπιστοσύνη απλώς έχουν μεγαλύτερη λίστα δικαιωμάτων.

## Προεπιλεγμένοι έναντι προσαρμοσμένων ρόλων

Οι ρόλοι διακρίνονται σε δύο κατηγορίες:

| Τύπος       | Επεξεργάσιμος | Σκοπός                                                                 |
| ----------- | ------------ | --------------------------------------------------------------------- |
| **Προεπιλεγμένος** | Όχι          | Συνοδεύει την πλατφόρμα (π.χ. Ιδιοκτήτης, Διαχειριστής). Εγγυάται ασφαλή βάση |
| **Προσαρμοσμένος** | Ναι          | Δημιουργείται από εσάς — ταιριάζει στη δομή της ομάδας σας             |

Οι προεπιλεγμένοι ρόλοι **Ιδιοκτήτης / Διαχειριστής** δεν μπορούν να επεξεργαστούν ή να διαγραφούν — είναι το δίχτυ ασφαλείας. Οι προσαρμοσμένοι ρόλοι είναι όπου ρυθμίζετε τα δικαιώματα ώστε να ταιριάζουν στις πραγματικές ευθύνες.

## Φίλτρα

| Φίλτρο  | Τύπος     | Σημειώσεις                              |
| ------- | --------- | ------------------------------------- |
| Αναζήτηση | Κείμενο   | Αναζητά όνομα ρόλου και περιγραφή      |
| Κατάσταση | Αναπτυσσόμενο | `Ενεργό` / `Ανενεργό` (ή `Όλα`)         |

## Στήλες

| Στήλη           | Ταξινομήσιμο; | Περιεχόμενο                                                                |
| --------------- | ------------- | -------------------------------------------------------------------------- |
| **Όνομα ρόλου** | ✓             | Η ετικέτα του ρόλου                                                        |
| **Περιγραφή**   | —             | Σύντομο κείμενο που εξηγεί τον σκοπό του ρόλου                             |
| **Τύπος**       | —             | Ετικέτα Προεπιλεγμένου / Προσαρμοσμένου                                   |
| **Δικαιώματα**  | —             | Αριθμός δικαιωμάτων που έχουν δοθεί (π.χ. "23 / 84")                      |
| **Βαθμολογία εμπιστοσύνης** | ✓   | Αριθμητική βαθμολογία που δείχνει πόσα μπορεί να κάνει ο ρόλος (υψηλότερο = πιο ισχυρός) |
| **Δημιουργήθηκε** | ✓           | Πότε δημιουργήθηκε ο ρόλος                                                  |

### Βαθμολογία εμπιστοσύνης

Η βαθμολογία εμπιστοσύνης είναι μια αδρή αριθμητική ένδειξη του "πόσο επικίνδυνο είναι το σύνολο δικαιωμάτων αυτού του ρόλου" — χρησιμοποιείται για ταξινόμηση και οπτικά σήματα. Ένας ρόλος με δικαιώματα διαγραφής + μαζικής ενημέρωσης + διαχείρισης δικαιωμάτων έχει υψηλότερη βαθμολογία από έναν ρόλο μόνο για προβολή. Δεν υπάρχει σταθερή κλίμακα· θεωρήστε το ως σχετική μέτρηση μέσα στη λίστα των δικών σας ρόλων.

## Ενέργειες γραμμής

Μενού με τρεις τελείες ανά γραμμή.

| Ενέργεια          | Δικαίωμα  | Τι κάνει                                                                                         |
| ----------------- | --------- | ------------------------------------------------------------------------------------------------ |
| **Προβολή λεπτομερειών** | —         | Ανοίγει τη σελίδα λεπτομερειών του ρόλου με πλήρη ανάλυση δικαιωμάτων                            |
| **Επεξεργασία**    | `edit`    | Ανοίγει τη φόρμα επεξεργασίας (απενεργοποιημένη με ειδοποίηση για Προεπιλεγμένους ρόλους)         |
| **Διαγραφή**      | `delete`  | Μαλακή διαγραφή του ρόλου (με επιβεβαίωση· μόνο για Προσαρμοσμένους ρόλους· μόνο αν κανένας χειριστής δεν τον έχει) |

Αν ένας ρόλος χρησιμοποιείται, το σύστημα θα αρνηθεί τη Διαγραφή και θα σας ενημερώσει πόσοι χειριστές τον έχουν — αναθέστε τους άλλους ρόλους πρώτα.

## Φόρμα Δημιουργίας / Επεξεργασίας

Η φόρμα ρόλου εμφανίζει κάθε δικαίωμα ομαδοποιημένο κατά τομέα (Λειτουργίες, Υποστήριξη, Αναλυτικά στοιχεία, Ρυθμίσεις κ.λπ.) με πλαίσια επιλογής.

Βασικά πεδία:

- **Όνομα** (απαραίτητο, μοναδικό)
- **Περιγραφή** (προαιρετικό αλλά συνιστάται)
- **Κατάσταση** (Ενεργό / Ανενεργό)
- **Δέντρο δικαιωμάτων** — δικαιώματα σελίδας και υπο-δικαιώματα, ομαδοποιημένα κατά τομέα

Όταν απενεργοποιείτε ένα δικαίωμα σελίδας ανώτατου επιπέδου, όλα τα υπο-δικαιώματα απενεργοποιούνται (ο χειριστής χάνει εντελώς τη σελίδα). Η ενεργοποίηση ενός δικαιώματος σελίδας δίνει από προεπιλογή μόνο προβολή — στη συνέχεια επιλέγετε ξεχωριστά υπο-δικαιώματα _δημιουργίας_, _επεξεργασίας_, _διαγραφής_ κ.λπ.

Ένας μικρός δείκτης **Βαθμολογίας εμπιστοσύνης** ενημερώνεται καθώς επιλέγετε πλαίσια — χρήσιμος για διασταύρωση με παρόμοιους ρόλους.

## Σελίδα λεπτομερειών ρόλου

Το κλικ σε μια γραμμή ανοίγει τη σελίδα λεπτομερειών του ρόλου που εμφανίζει:

- Όνομα, περιγραφή, τύπο, κατάσταση
- Βαθμολογία εμπιστοσύνης
- Πλήρη λίστα δικαιωμάτων (μόνο για ανάγνωση, ομαδοποιημένη κατά τομέα)
- Καταγραφή δραστηριότητας: πότε δημιουργήθηκε, τελευταία επεξεργασία, από ποιον
- Λίστα χειριστών που έχουν ανατεθεί (με συνδέσμους στα προφίλ τους)

## Τυπικά ροή εργασίας

- **Ορισμός νέας ομάδας** — `+ Δημιουργία` → όνομα (π.χ. "Υπεύθυνος πεδίου") → επιλέξτε τα δικαιώματα που χρειάζονται → Αποθήκευση → αναθέστε τον ρόλο στους σχετικούς [χειριστές](operators.md)
- **Περιορισμός υπάρχοντος ρόλου** — βρείτε τον ρόλο στη λίστα → Επεξεργασία → αποεπιλέξτε δικαιώματα που δεν θέλετε πια → Αποθήκευση (οι χειριστές με αυτόν τον ρόλο χάνουν πρόσβαση στο επόμενο αίτημα)
- **Προαγωγή μέλους ομάδας** — πηγαίνετε στους [Χειριστές](operators.md) → Επεξεργασία → αλλάξτε Ρόλο → Αποθήκευση (δεν γίνεται από αυτή τη σελίδα)
- **Έλεγχος ποιος μπορεί να διαγράψει οχήματα** — ανοίξτε αυτή τη λίστα → ταξινομήστε κατά Βαθμολογία εμπιστοσύνης → ελέγξτε τις υπο-δικαιώματα Επεξεργασίας / Διαγραφής σε Οχήματα για κάθε ρόλο
- **Απόσυρση ρόλου** — βεβαιωθείτε ότι κανένας χειριστής δεν τον έχει ([Χειριστές](operators.md) φίλτρο κατά ρόλο) → Διαγραφή

## Συμβουλές

- **Λιγότερο είναι περισσότερο** — ξεκινήστε με προβολή μόνο και προσθέστε συγκεκριμένες ενέργειες· αποφύγετε την αντιγραφή ενός ανώτερου ρόλου και τη μείωση
- **Δοκιμάστε με προσωποποίηση** (όπου υποστηρίζεται) — πριν αναπτύξετε έναν ρόλο, συνδεθείτε ως δοκιμαστικός χειριστής με τον ρόλο και δοκιμάστε τις ροές εργασίας
- **Οι προεπιλεγμένοι ρόλοι είναι η εφεδρεία σας** — Ο Ιδιοκτήτης / Διαχειριστής υπάρχουν πάντα· αν κλειδωθείτε κατά λάθος εκτός ενός Προσαρμοσμένου ρόλου, ένας Διαχειριστής μπορεί να αποκαταστήσει την πρόσβαση
- **Ο δείκτης εμπιστοσύνης είναι υπόδειξη, όχι κανόνας** — δύο ρόλοι με τον ίδιο δείκτη εμπιστοσύνης μπορούν να κάνουν πολύ διαφορετικά πράγματα· ελέγξτε πάντα το πραγματικό δέντρο δικαιωμάτων
- **Τα δικαιώματα αξιολογούνται στην πλευρά του διακομιστή** — η απενεργοποίησή τους στον ρόλο δεν αφαιρεί την τρέχουσα συνεδρία του χειριστή, αλλά το αμέσως επόμενο αίτημα απορρίπτεται
- **Τεκμηριώστε κάθε Προσαρμοσμένο ρόλο** στο πεδίο Περιγραφή — έξι μήνες μετά, το «Διαχειριστής στόλου (ανάγνωση + επεξεργασία, χωρίς διαγραφή)» σώζει ζωές
