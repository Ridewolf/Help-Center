# Χειριστές

Η σελίδα Χειριστές (`/settings/operators`) είναι ο **κατάλογος προσωπικού** — κάθε υπάλληλος που έχει πρόσβαση στον Πίνακα ελέγχου. Κάθε χειριστής έχει έναν ρόλο (δείτε [Ρόλοι](roles.md)), προαιρετικά μεταδεδομένα τμήματος / θέσης, ετικέτες για φιλτράρισμα και κατάσταση (Ενεργό / Ανενεργό).

Διαφορετικοί από τους [Πελάτες](../../operations/customers/clients.md) (τους πελάτες σας) — οι Χειριστές είναι η **εσωτερική ομάδα** που διαχειρίζεται την πλατφόρμα.

Απαιτούμενη άδεια: **Χειριστές** (`t4u5v6`). Οι υπο-άδειες ελέγχουν τις ενέργειες επεξεργασίας.

## Πώς φτάνουν οι χειριστές εδώ

Οι χειριστές δημιουργούνται από εσάς (διαχειριστή) μέσω του κουμπιού **+ Δημιουργία** — δεν υπάρχει αυτοεγγραφή:

1. Το **+ Δημιουργία** ανοίγει τη φόρμα χειριστή — όνομα, email, ρόλος, προαιρετικά τμήμα / θέση / ετικέτες
2. Ο νέος χειριστής λαμβάνει email με οδηγίες σύνδεσης και προσωρινό κωδικό
3. Συνδέεται, συμπληρώνει το προφίλ του (`/profile`) και μπορεί να ξεκινήσει να εργάζεται βάσει των αδειών του ρόλου του
4. Οι ανενεργοί χειριστές δεν μπορούν να συνδεθούν — αλλάξτε την κατάσταση σε ανενεργό όταν ένας υπάλληλος αποχωρεί

## Φίλτρα

| Φίλτρο | Τύπος        | Σημειώσεις                                               |
| ------ | ------------ | -------------------------------------------------------- |
| Αναζήτηση | Κείμενο      | Αναζητά σε όνομα, email, θέση, τμήμα                     |
| Κατάσταση | Αναπτυσσόμενο | `Ενεργό` / `Ανενεργό` (ή `Όλα`)                         |
| Ετικέτες | Πολλαπλή επιλογή | Φιλτράρισμα με ετικέτες που έχουν εφαρμοστεί στους χειριστές (π.χ. "Νυχτερινή βάρδια") |

## Στήλες

| Στήλη          | Ταξινομήσιμη; | Περιεχόμενο                                                             |
| -------------- | ------------- | ----------------------------------------------------------------------- |
| **Χρήστης**    | ✓             | Άβαταρ + όνομα + επώνυμο + email; σύνδεσμος στη σελίδα λεπτομερειών χειριστή |
| **Ρόλος**      | —             | Ετικέτα ρόλου χειριστή (σύνδεσμος σε [Ρόλοι](roles.md)) |
| **Τμήμα**      | —             | Προαιρετική ετικέτα τμήματος                                           |
| **Θέση**       | —             | Προαιρετική ετικέτα θέσης                                             |
| **Ετικέτες**   | —             | Ετικέτες που έχουν εφαρμοστεί στον χειριστή                           |
| **Κατάσταση**  | ✓             | `Ενεργό` (πράσινο) / `Ανενεργό` (γκρι)                               |

## Ενέργειες γραμμής

Μενού με τρεις τελείες ανά γραμμή. Οι διαθέσιμες ενέργειες εξαρτώνται από τις άδειες:

| Ενέργεια          | Άδεια      | Τι κάνει                                         |
| ----------------- | ---------- | ------------------------------------------------ |
| **Προβολή λεπτομερειών** | —          | Ανοίγει τη σελίδα λεπτομερειών χειριστή          |
| **Επεξεργασία**    | `edit`     | Ανοίγει τη φόρμα επεξεργασίας (όνομα, ρόλος, τμήμα κ.λπ.) |

Δεν υπάρχει **ενέργεια Διαγραφής** — τα αρχεία χειριστών διατηρούνται για λόγους ελέγχου. Για να αποτρέψετε τη σύνδεση, αλλάξτε την κατάσταση του χειριστή σε _Ανενεργό_ μέσω της Επεξεργασίας.

## Σελίδα λεπτομερειών

Κάνοντας κλικ σε μια γραμμή (ή _Προβολή λεπτομερειών_) ανοίγει η σελίδα λεπτομερειών χειριστή με:

- Προσωπικά στοιχεία (όνομα, email, τηλέφωνο, φωτογραφία)
- Στιγμιότυπο ρόλου + αδειών
- Τμήμα / θέση / ετικέτες
- Κατάσταση
- Καταγραφή δραστηριότητας (συνδέσεις, αλλαγές ρόλου)

Επεξεργασία από εκεί ή από το μενού γραμμής — και οι δύο οδηγούν στην ίδια φόρμα.

## Φόρμα Δημιουργίας / Επεξεργασίας

Η **φόρμα χειριστή** (`+ Δημιουργία` ή _Επεξεργασία_) είναι απλή:

- **Όνομα / Επώνυμο** (υποχρεωτικό)
- **Email** (υποχρεωτικό, μοναδικό ανά χειριστή)
- **Ρόλος** (υποχρεωτικό, αναπτυσσόμενο με διαθέσιμους ρόλους — δείτε [Ρόλοι](roles.md))
- **Τμήμα / Θέση** (προαιρετικό)
- **Ετικέτες** (προαιρετική πολλαπλή επιλογή)
- **Κατάσταση** (Ενεργό / Ανενεργό)
- Μόνο στη Δημιουργία: πεδίο **αρχικού κωδικού** ή αυτόματη αποστολή κωδικού με email στον χειριστή

Η αποθήκευση επικυρώνει και καταγράφει στο αρχείο ελέγχου. Οι νεοδημιουργημένοι χειριστές λαμβάνουν αυτόματα email καλωσορίσματος.

## Τυπικά ροή εργασίας

- **Εισαγωγή νέου υπαλλήλου** — `+ Δημιουργία` → συμπλήρωση ονόματος/email/ρόλου → Αποθήκευση → επιβεβαίωση λήψης email καλωσορίσματος → ζήτηση σύνδεσης και ολοκλήρωσης προφίλ
- **Αλλαγή ρόλου μετά από προαγωγή** — Επεξεργασία → αλλαγή Ρόλου → Αποθήκευση (οι νέες άδειες ισχύουν στο επόμενο αίτημα του χειριστή, όχι αναδρομικά)
- **Αποχώρηση** — Επεξεργασία → ορισμός Κατάστασης = Ανενεργό → Αποθήκευση (το αρχείο διατηρείται για έλεγχο· η σύνδεση αποκλείεται)
- **Σχεδιασμός βάρδιας με βάση ετικέτες** — εφαρμόστε ετικέτες όπως "Νυχτερινή βάρδια" → φιλτράρετε τη λίστα με την ετικέτα για να δείτε ποιος είναι προγραμματισμένος

## Συμβουλές

- **Ο ρόλος είναι το πιο ισχυρό πεδίο** — να είστε προσεκτικοί όταν τον αλλάζετε. Η υποβάθμιση από Admin σε Support αφαιρεί αμέσως τα δικαιώματα εγγραφής
- **Ανενεργό ≠ Διαγραμμένο** — το ιστορικό του χειριστή διατηρείται· αλλάξτε ξανά σε Ενεργό για να επαναφέρετε την πρόσβαση
- **Η λίστα ταξινομείται κατά όνομα από προεπιλογή** — αν έχετε πολλούς χειριστές, αναζητήστε με email ή τμήμα αντί να κάνετε κύλιση
- **Οι ετικέτες εδώ διαφέρουν από τις ετικέτες πελατών** — είναι ειδικές για χειριστές (π.χ. "Νυχτερινή βάρδια", "Εκπαιδευτής") και δεν μοιράζονται το ίδιο namespace
- **Περιορισμοί αυτοεπεξεργασίας** — δεν μπορείτε να αλλάξετε τον δικό σας ρόλο από το μενού γραμμής· χρησιμοποιήστε το Προφίλ για προσωπικές αλλαγές
