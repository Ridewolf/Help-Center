# Πίνακες & Φίλτρα

Σχεδόν κάθε σελίδα λίστας στον Πίνακα ελέγχου (Οχήματα, Διαδρομές, Πελάτες, Πληρωμές, Εισιτήρια Υποστήριξης, Αποδείξεις στάθμευσης, Συνομιλίες, Αναλυτικά στοιχεία, Χειριστές κ.ά.) έχει την ίδια δομή. Μόλις μάθετε το μοτίβο, κάθε σελίδα λίστας λειτουργεί με τον ίδιο τρόπο.

## Δομή μιας σελίδας λίστας

Από πάνω προς τα κάτω:

1. **Επικεφαλίδα σελίδας** — τίτλος, ενέργειες σε επίπεδο σελίδας (π.χ. _Δημιουργία_, _Εξαγωγή_)
2. **Μπάρα αναζήτησης** — αναζήτηση πλήρους κειμένου σε πολλαπλά πεδία
3. **Γραμμή φίλτρων** — αναδυόμενα μενού και ετικέτες για περιορισμό αποτελεσμάτων
4. **Ενεργά φίλτρα σε μορφή ετικετών** — αφαιρούμενες ετικέτες που δείχνουν τι εφαρμόζεται
5. **Μπάρα μαζικών ενεργειών** — εμφανίζεται όταν επιλέγεται μία ή περισσότερες γραμμές
6. **Πίνακας** — ταξινομήσιμες στήλες, ενέργειες γραμμής δεξιά
7. **Σελιδοποίηση** — κάτω δεξιά

## Αναζήτηση

Η μπάρα αναζήτησης ψάχνει στα πιο σχετικά πεδία για τη σελίδα (π.χ. ετικέτα, αναγνωριστικό, όνομα ιδιοκτήτη).

- **Πληκτρολογήστε για αναζήτηση** — τα αποτελέσματα φιλτράρονται καθώς πληκτρολογείτε, με μικρή καθυστέρηση για να μην υπερφορτώνεται ο διακομιστής
- **Καθαρισμός** — κάντε κλικ στο × στο πεδίο ή πατήστε `Esc`
- Η αναζήτηση εκτελείται **από τον διακομιστή** σε ολόκληρο το σύνολο δεδομένων, όχι μόνο στη σελίδα που βλέπετε

## Φίλτρα

Τα φίλτρα περιορίζουν το σύνολο αποτελεσμάτων χωρίς αναζήτηση κειμένου. Κάθε φίλτρο είναι αναδυόμενο μενού (επιλογή μίας ή πολλαπλών τιμών ανάλογα με το πεδίο).

- **Εφαρμογή κατά την αλλαγή** — τα φίλτρα εφαρμόζονται αμέσως, χωρίς κουμπί Εφαρμογή
- **Πολλαπλά φίλτρα συνδυάζονται με AND** — όσο περισσότερα προσθέτετε, τόσο πιο περιορισμένα τα αποτελέσματα
- **Ενεργά φίλτρα σε μορφή ετικετών** εμφανίζονται πάνω από τον πίνακα· κάντε κλικ στο × σε μια ετικέτα για να αφαιρέσετε μόνο αυτό το φίλτρο
- **Καθαρισμός όλων** — όταν υπάρχουν πολλά φίλτρα, εμφανίζεται κουμπί _Καθαρισμός όλων_ δίπλα στις ετικέτες

Συνηθισμένοι τύποι φίλτρων:

| Τύπος        | Συμπεριφορά                                                  |
| ------------ | ------------------------------------------------------------ |
| Κατάσταση    | Αναδυόμενο μενού μονής επιλογής                              |
| Τύπος / Μοντέλο | Αναδυόμενο μενού μονής επιλογής                              |
| Ετικέτες    | Πολλαπλής επιλογής με ετικέτες μέσα στο αναδυόμενο μενού     |
| Περίοδος ημερομηνιών | Ημερολόγιο (από / έως)                                      |
| Αριθμητικό εύρος | Είσοδοι από / έως αριθμητικές (π.χ. μπαταρία 0–30%)          |
| Αναζήτηση με ID | Ελεύθερο κείμενο μέσα σε ετικέτα φίλτρου (ξεχωριστό από την κύρια αναζήτηση) |

## Ταξινόμηση

- **Κάντε κλικ στην κεφαλίδα στήλης** — ταξινόμηση αύξουσα
- **Κάντε ξανά κλικ** — ταξινόμηση φθίνουσα
- **Κάντε τρίτο κλικ** — καθαρισμός ταξινόμησης (επιστροφή στην προεπιλεγμένη σειρά)
- Εμφανίζεται **εικονίδιο βέλους** (↑ / ↓) δίπλα στο όνομα της στήλης όταν είναι ενεργή η ταξινόμηση

Δεν είναι όλες οι στήλες ταξινομήσιμες. Οι ταξινομήσιμες στήλες δείχνουν διακριτική κατάσταση hover στην κεφαλίδα· οι μη ταξινομήσιμες όχι.

## Σελιδοποίηση

Κάτω δεξιά του πίνακα:

- **Αριθμοί σελίδων** — κάντε κλικ σε αριθμό για άλμα
- **Βέλη Προηγούμενο / Επόμενο** στα πλάγια
- **Επιλογέας μεγέθους σελίδας** — αναδυόμενο μενού (συνήθως 10 / 20 / 50 / 100 γραμμές ανά σελίδα)

Η σελιδοποίηση γίνεται από τον διακομιστή. Τα φίλτρα και η αναζήτηση εφαρμόζονται στο **ολόκληρο σύνολο δεδομένων**, όχι μόνο στη σελίδα που βλέπετε — η σελίδα 3 των φιλτραρισμένων αποτελεσμάτων παραμένει φιλτραρισμένη.

## Ενέργειες γραμμής

Κάθε γραμμή έχει **μενού με τρεις τελείες** στα δεξιά. Το μενού ανοίγει αναδυόμενο με ενέργειες σε επίπεδο γραμμής:

- **Προβολή** — άνοιγμα σελίδας λεπτομερειών
- **Επεξεργασία** — άνοιγμα φόρμας επεξεργασίας
- **Διαγραφή** — αφαίρεση εγγραφής (με παράθυρο επιβεβαίωσης)
- **Ενέργειες ειδικές για τη σελίδα** — π.χ. _Αποστολή push_ σε πελάτες, _Ξεκλείδωμα_ σε οχήματα, _Επιστροφή_ σε πληρωμές, _Ανάθεση_ σε εισιτήρια

Οι ενέργειες που βλέπετε εξαρτώνται από τα **δικαιώματά** σας — οι ενέργειες για τις οποίες δεν έχετε δικαίωμα είναι κρυφές.

## Πολλαπλή επιλογή και μαζικές ενέργειες

Σε σελίδες που το υποστηρίζουν (Πελάτες, Οχήματα κ.ά.):

1. **Επιλογή γραμμών** — κάντε κλικ στο πλαίσιο ελέγχου αριστερά σε κάθε γραμμή
2. **Επιλογή όλων στη σελίδα** — κάντε κλικ στο πλαίσιο ελέγχου στην κεφαλίδα της στήλης
3. Εμφανίζεται **μπάρα μαζικών ενεργειών** στην κορυφή που δείχνει τον αριθμό επιλεγμένων και τις διαθέσιμες μαζικές ενέργειες
4. **Επιλέξτε ενέργεια** — εφαρμόζεται σε όλες τις επιλεγμένες γραμμές
5. **Καθαρισμός επιλογής** — × στη μπάρα μαζικών ενεργειών ή αποεπιλογή του πλαισίου στην κεφαλίδα

Συνηθισμένες μαζικές ενέργειες:

- Προσθήκη ή αφαίρεση ετικετών
- Αποστολή ειδοποίησης push
- Επιβολή προστίμου ή φόρτιση υπολοίπου (σε πελάτες)
- Αλλαγή κατάστασης

## Κενές και καταστάσεις φόρτωσης

- **Φόρτωση** — εμφανίζονται προσωρινά σκελετοειδείς γραμμές κατά τη φόρτωση δεδομένων
- **Χωρίς αποτελέσματα** — φιλικό μήνυμα ("Δεν βρέθηκαν αποτελέσματα") με κουμπί _Καθαρισμός φίλτρων_ όταν υπάρχουν ενεργά φίλτρα
- **Σφάλμα δικτύου** — κατάσταση σφάλματος με κουμπί _Προσπάθησε ξανά_ (συχνά σε ασταθή σύνδεση)

## Συμβουλές

- **Περιμένετε την καθυστέρηση** — μετά την πληκτρολόγηση στην αναζήτηση, περιμένετε ένα κλάσμα δευτερολέπτου πριν κάνετε κλικ — ο διακομιστής εκτελεί αναζήτηση μία φορά όταν σταματήσετε να πληκτρολογείτε
- **Μοιραστείτε φιλτραρισμένες προβολές** — η αναζήτηση, τα φίλτρα, η ταξινόμηση και η σελίδα αντανακλώνται στο URL. Αντιγράψτε το URL και στείλτε το σε συνεργάτη· θα δει ακριβώς την ίδια προβολή
- **Το πίσω/επόμενο του προγράμματος περιήγησης λειτουργεί κανονικά** — επιστρέφει στις αλλαγές φίλτρων που κάνατε
- **Συνδυάστε αναζήτηση + φίλτρα** — η αναζήτηση είναι ελεύθερο κείμενο πάνω από τα φίλτρα. Χρησιμοποιήστε φίλτρα για περιορισμό κατά κατάσταση/τύπο, μετά αναζητήστε όνομα μέσα σε αυτό το υποσύνολο
- **Αυξήστε το μέγεθος σελίδας** σε 100 όταν θέλετε να δείτε πολλά αρχεία οπτικά αντί να κάνετε κλικ σε πολλές σελίδες
- **Τα δικαιώματα είναι το αθόρυβο φίλτρο** — αν ένας συνεργάτης βλέπει γραμμές που εσείς όχι, σχεδόν πάντα οφείλεται σε διαφορά δικαιωμάτων, όχι σε σφάλμα
