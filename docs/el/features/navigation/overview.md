# Πλοήγηση

Ο πίνακας ελέγχου πλοηγείται μέσα από τρεις βασικές επιφάνειες: η **πλευρική γραμμή** στα αριστερά, η **γραμμή κορυφής** στο πάνω μέρος και το **breadcrumb** μέσα στη γραμμή κορυφής. Συμπεριφέρονται με συνέπεια σε κάθε σελίδα.

## Πλευρική γραμμή

Η πλευρική γραμμή είναι η κύρια πλοήγησή σας. Κάθε στοιχείο είναι είτε μια μεμονωμένη σελίδα (Πίνακας ελέγχου, Διαδρομές, Οχήματα, Πελάτες, Υποστήριξη) είτε μια **ομάδα** που επεκτείνεται σε υποστοιχεία (Πληρωμές, Υποστήριξη, Αναλυτικά στοιχεία, Ρυθμίσεις, Εφαρμογές).

### Επέκταση και σύμπτυξη

- **Κάντε κλικ σε μια ομάδα** (π.χ. _Υποστήριξη_) για να την επεκτείνετε· κάντε ξανά κλικ για να τη συμπτύξετε.
- **Εναλλαγή ολόκληρης της πλευρικής γραμμής** με `⌘ B` (macOS) ή `Ctrl B` (Windows/Linux). Η συμπτυγμένη κατάσταση δείχνει μόνο το εικονίδιο — περάστε τον κέρσορα πάνω από ένα εικονίδιο για να δείτε την ετικέτα του ως υπόδειξη.
- Η κατάσταση της πλευρικής γραμμής διατηρείται μεταξύ των φορτώσεων σελίδων (υποστηρίζεται από cookie).

### Ενεργή κατάσταση

Η τρέχουσα ενότητα επισημαίνεται με το χρώμα έμφασης (κόκκινο από προεπιλογή). Όταν βρίσκεστε μέσα σε μια ομάδα, η κεφαλίδα της ομάδας παραμένει επίσης επισημασμένη ώστε να γνωρίζετε πάντα πού βρίσκεστε.

### Μετρήσεις και σήματα

Ορισμένα στοιχεία εμφανίζουν **σήμα** με αριθμό — αυτοί είναι οι μετρητές μη αναγνωσμένων/εκκρεμών ειδοποιήσεων που ενημερώνονται ζωντανά:

- _Υποστήριξη → Εισιτήρια_ — εκκρεμή εισιτήρια που σας έχουν ανατεθεί
- _Υποστήριξη → Αποδείξεις στάθμευσης_ — εκκρεμείς αποδείξεις που περιμένουν έλεγχο
- _Διαδρομές_, _Οχήματα_, _Πελάτες_ — μετρήσεις όταν είναι σχετικές

### Δικαιώματα

Βλέπετε μόνο τα στοιχεία που επιτρέπουν ο **ρόλος και τα δικαιώματά** σας. Αν μια ενότητα λείπει για εσάς αλλά την έχει κάποιος άλλος συνάδελφος — είναι θέμα δικαιωμάτων, όχι σφάλμα. Ρωτήστε έναν διαχειριστή αν πρέπει να έχετε πρόσβαση.

## Γραμμή κορυφής

Η γραμμή κορυφής εμφανίζεται σε κάθε σελίδα. Σε επιτραπέζιους υπολογιστές έχει το breadcrumb στα αριστερά και πέντε χειριστήρια στα δεξιά.

### Breadcrumb (αριστερά)

Το breadcrumb είναι η διαδρομή σας πίσω στην ιεραρχία:

`Αρχική → Οχήματα → RW-001`

- **Κάντε κλικ σε οποιοδήποτε τμήμα** για να επιστρέψετε σε εκείνο το επίπεδο (το τελευταίο τμήμα είναι η τρέχουσα σελίδα και δεν είναι κλικαριστό).
- Το breadcrumb είναι πάντα ορατό — είναι ο ασφαλέστερος τρόπος να βγείτε από μια βαθιά σελίδα.

### Χειριστήρια (δεξιά, επιτραπέζιος)

Με τη σειρά, από αριστερά προς τα δεξιά:

| Εικονίδιο | Τι κάνει                                                                                  |
| --------- | ---------------------------------------------------------------------------------------- |
| ✨       | **AI Chat** — ανοίγει πάνελ συνομιλίας με βοηθό που απαντά σε ερωτήσεις του πίνακα ελέγχου |
| ?        | **Βοήθεια** — ανοίγει αυτή τη βάση γνώσεων σε πλαϊνό παράθυρο, σχετικό με την τρέχουσα σελίδα |
| 🔔       | **Ειδοποιήσεις** — πρόσφατα συστήματα και συναγερμοί (κόκκινο σήμα δείχνει μη αναγνωσμένα)  |
| 👤       | **Προφίλ** — ρυθμίσεις, κωδικός, αποσύνδεση, έλεγχοι θέματος (το avatar σας)               |

### Κινητό

Σε οθόνες μικρότερες από 769 px η γραμμή κορυφής συμπτύσσεται:

- Η πλευρική γραμμή συμπτύσσεται σε ένα κουμπί χάμπουργκερ αριστερά
- Το breadcrumb κάθεται δίπλα στο χάμπουργκερ και κυλά οριζόντια αν είναι μεγάλο
- Τα πέντε χειριστήρια γίνονται τέσσερα κουμπιά στα δεξιά (AI, Βοήθεια, Ειδοποιήσεις, Avatar) — ίδιες ενέργειες, μεγαλύτεροι στόχοι για πάτημα

## Φύλλο προφίλ

Κάνοντας κλικ στο avatar σας ανοίγει ένα πλαϊνό πάνελ στα δεξιά με:

- **Προφίλ** — τα προσωπικά σας στοιχεία
- **Αλλαγή κωδικού**
- **Ρυθμίσεις** — προτιμήσεις (γλώσσα, θέμα, ειδοποιήσεις)
- **Βοήθεια** — πηγαίνει στην αρχική σελίδα Βοήθειας
- **Αποσύνδεση** (κόκκινο)
- Διακόπτες θέματος/γλώσσας/στυλ χάρτη στο κάτω μέρος

## Συμβουλές

- **Περάστε τον κέρσορα πάνω από τα στοιχεία της πλευρικής γραμμής** όταν είναι συμπτυγμένη — οι υπόδειξεις εμφανίζονται αμέσως, χωρίς καθυστέρηση
- **Χρησιμοποιήστε το breadcrumb** για να βγείτε από βαθιές σελίδες αντί του κουμπιού πίσω του προγράμματος περιήγησης — είναι πιο γρήγορο και αποφεύγει την επαναφόρτωση
- **`⌘/Ctrl + B`** είναι ένας γρήγορος τρόπος να κερδίσετε περισσότερο οριζόντιο χώρο σε σελίδες με πολλά δεδομένα (πίνακες, χάρτες)
- Η **Βοήθεια (?)** στη γραμμή κορυφής είναι **ενημερωμένη για τη σελίδα** — προσπαθεί να ανοίξει το πιο σχετικό άρθρο για το σημείο που βρίσκεστε· αν δεν υπάρχει, επιστρέφει στην αναζήτηση
