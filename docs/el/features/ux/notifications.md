# Ειδοποιήσεις

Οι ειδοποιήσεις εμφανίζουν ζωντανά γεγονότα από όλο τον πίνακα ελέγχου — νέα εισιτήρια, ειδοποιήσεις IoT, δραστηριότητα πληρωμών, προβλήματα οχημάτων, μηνύματα συστήματος. Φτάνουν μέσω σύνδεσης WebSocket, έτσι οι ενημερώσεις είναι σε πραγματικό χρόνο χωρίς επαναφόρτωση της σελίδας.

## Καμπάνα στη γραμμή κορυφής

Το **εικονίδιο καμπάνας** στη γραμμή κορυφής είναι το σημείο εισόδου σας. Μια κόκκινη ένδειξη δείχνει τον αριθμό των μη αναγνωσμένων ειδοποιήσεων.

- Χωρίς ένδειξη → τίποτα μη αναγνωσμένο
- Αριθμητική ένδειξη → τόσες μη αναγνωσμένες
- `99+` → περισσότερες από 99 μη αναγνωσμένες

Κάντε κλικ στην καμπάνα για να ανοίξετε το **Πλαίσιο Ειδοποιήσεων** ως πλαϊνό φύλλο στα δεξιά.

## Μέσα στο πλαίσιο

### Επικεφαλίδα

- **Τίτλος** "Ειδοποιήσεις"
- **Αριθμός μη αναγνωσμένων** εμφανίζεται είτε ως "N μη αναγνωσμένα" είτε ως "Όλα διαβασμένα" όταν δεν υπάρχουν
- **Συντόμευση ρυθμίσεων** (εικονίδιο γραναζιού) ανοίγει τη σελίδα παγκόσμιων ρυθμίσεων ειδοποιήσεων

### Διακόπτης ειδοποιήσεων προγράμματος περιήγησης

Αν το πρόγραμμα περιήγησής σας υποστηρίζει συστημικές ειδοποιήσεις, εμφανίζεται ένας διακόπτης κάτω από την επικεφαλίδα:

- **Απενεργοποιημένο** → οι ειδοποιήσεις ζουν μόνο μέσα στον πίνακα ελέγχου
- **Ενεργοποιημένο** → το πρόγραμμα περιήγησης εμφανίζει συστημική ειδοποίηση όταν φτάνει κάτι νέο, ακόμα και όταν η καρτέλα είναι στο παρασκήνιο
- Την πρώτη φορά που ενεργοποιείται, το πρόγραμμα περιήγησης ζητά άδεια

Αν αρνηθήκατε την άδεια νωρίτερα, ο διακόπτης είναι απενεργοποιημένος και εμφανίζεται μια κίτρινη ειδοποίηση με οδηγίες για να την ενεργοποιήσετε ξανά στις ρυθμίσεις του προγράμματος περιήγησης για τον ιστότοπο.

### Λίστα

Οι ειδοποιήσεις εμφανίζονται με τις πιο πρόσφατες πρώτες. Κάθε στοιχείο δείχνει:

- **Εικονίδιο κατηγορίας** — ένα μικρό εικονίδιο με χρώμα προτεραιότητας (βλέπε παρακάτω)
- **Τίτλος** — μια σύντομη επικεφαλίδα
- **Κείμενο** — η περιγραφή του γεγονότος
- **Πόσος χρόνος πριν** — π.χ. "πριν 2 λεπτά"
- **Κλικ** στο στοιχείο για να μεταβείτε στη σχετική σελίδα (το αντίστοιχο εισιτήριο, όχημα, πληρωμή κ.λπ.)

### Κενή κατάσταση

Όταν δεν υπάρχει κάτι να δείτε, το πλαίσιο εμφανίζει ένα φιλικό μήνυμα και ένα κουμπί για να ανοίξετε τη σελίδα ρυθμίσεων.

## Κατηγορίες και προτεραιότητα

Κάθε ειδοποίηση έχει μια **κατηγορία** (καθορίζει το εικονίδιο) και μια **προτεραιότητα** (καθορίζει το χρώμα).

### Κατηγορίες

| Κατηγορία   | Εικονίδιο      | Τυπικά γεγονότα                             |
| ----------- | -------------- | ------------------------------------------- |
| Υποστήριξη  | 🔔 Καμπάνα     | Νέα εισιτήρια, απαντήσεις σε εισιτήρια      |
| Συντήρηση   | 🔧 Κλειδί      | Ανατεθειμένες εργασίες συντήρησης, ενεργοποιήσεις αυτοματοποίησης |
| Όχημα       | ✨ Αστραφτερό  | Αλλαγές κατάστασης, ανωμαλίες               |
| Πελάτης     | 👥 Χρήστες     | Νέες εγγραφές, σημαίες λογαριασμού          |
| Πληρωμή     | 💳 Κάρτα      | Συναλλαγές, επιστροφές, γεγονότα webhook    |
| IoT         | 🖥️ Κεντρική μονάδα | Συσκευή εκτός σύνδεσης, χαμηλή μπαταρία, ειδοποιήσεις αισθητήρων |
| Σύστημα     | 🛎️ Κουδούνι   | Μηνύματα συστήματος, αναπτύξεις              |
| Ασφάλεια    | 🛡️ Συναγερμός | Γεγονότα πιστοποίησης, ύποπτη δραστηριότητα  |

### Χρώματα προτεραιότητας

| Προτεραιότητα | Χρώμα  | Χρήση                                               |
| ------------ | ------ | -------------------------------------------------- |
| Κρίσιμο      | Κόκκινο| Απαιτεί άμεση ενέργεια (διακοπή οχήματος, συναγερμός ασφάλειας) |
| Υψηλό        | Πορτοκαλί | Σημαντικό αλλά όχι αποκλειστικό                   |
| Μεσαίο       | Κίτρινο | Ρουτίνα προσοχής                                  |
| Χαμηλό       | Μπλε    | Πληροφοριακό                                     |

## Ρυθμίσεις (προχωρημένη διαμόρφωση)

Το πλαίσιο καμπάνας καλύπτει τα βασικά. Για πλήρη διαμόρφωση, ανοίξτε **Ρυθμίσεις → Ειδοποιήσεις & Συναγερμοί** (ή κάντε κλικ στο γρανάζι στην επικεφαλίδα του πλαισίου):

- **Ήχοι** — επιλέξτε ήχο ανά προτεραιότητα ή απενεργοποιήστε τους ήχους
- **Πάροχοι** — προωθήστε ειδοποιήσεις σε εξωτερικά κανάλια (Telegram κ.ά.) ρυθμισμένα ανά συνομιλία/παραλήπτη
- **Φιλτράρισμα** — ποιες κατηγορίες θέλετε να λαμβάνετε
- **Προγράμματα σίγασης** — ώρες ησυχίας (όπου υποστηρίζεται)

## Πώς λειτουργεί η άδεια

Οι ειδοποιήσεις προγράμματος περιήγησης χρειάζονται μια εφάπαξ άδεια από το πρόγραμμα περιήγησης. Ο διακόπτης στο πλαίσιο ενεργοποιεί το αίτημα άδειας την πρώτη φορά που τον ενεργοποιείτε.

- **Επιτράπηκε** → ο διακόπτης λειτουργεί· λαμβάνετε συστημικές ειδοποιήσεις όσο ο πίνακας ελέγχου είναι ανοιχτός σε οποιαδήποτε καρτέλα
- **Αρνηθήκατε** → ο διακόπτης είναι κλειδωμένος απενεργοποιημένος· πρέπει να αλλάξετε την άδεια στις ρυθμίσεις ιστότοπου του προγράμματος περιήγησης, μετά να επιστρέψετε και να ενεργοποιήσετε τον διακόπτη
- **Μη υποστηριζόμενο** → ορισμένα ενσωματωμένα προγράμματα περιήγησης και παλαιότερες εκδόσεις δεν μπορούν να εμφανίσουν συστημικές ειδοποιήσεις· ο διακόπτης κρύβεται

Η παροχή άδειας στο πρόγραμμα περιήγησης δεν αλλάζει τίποτα μέσα στον πίνακα ελέγχου — το ενσωματωμένο πλαίσιο λειτουργεί ανεξάρτητα.

## Συμβουλές

- **Χρησιμοποιήστε τις ειδοποιήσεις προγράμματος περιήγησης σε μία μόνο καρτέλα** — το άνοιγμα του πίνακα ελέγχου σε πολλές καρτέλες μπορεί να πολλαπλασιάσει τις συστημικές ειδοποιήσεις
- **Οι ήχοι είναι τοπικοί** — παίζουν μόνο στην καρτέλα όπου είστε συνδεδεμένοι· σιγήστε τους σε κοινόχρηστους υπολογιστές
- **Το κλικ είναι η ταχύτερη ροή εργασίας** — το κλικ σε μια ειδοποίηση σας μεταφέρει απευθείας στη σελίδα που την προκάλεσε· πιο γρήγορο από το να πλοηγηθείτε χειροκίνητα
- **Αποσυνδεδεμένος πίνακας ελέγχου** — αν η σύνδεση WebSocket πέσει, η μικρή κουκκίδα κατάστασης στο avatar γίνεται κόκκινη. Οι ειδοποιήσεις συνεχίζονται μόλις επανέλθει η σύνδεση· δεν χάνετε τίποτα εν τω μεταξύ
- **Πρώτα τα κρίσιμα** — όταν φτάνουν πολλές μαζί, ελέγξτε πρώτα τα χρώματα πριν τους τίτλους: τα κόκκινα εικονίδια πάνε στην κορυφή της ουράς σας
