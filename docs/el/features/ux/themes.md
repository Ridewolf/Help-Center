# Θέματα

Ο Πίνακας ελέγχου διαθέτει τρεις ανεξάρτητες ρυθμίσεις εμφάνισης:

- **Λειτουργία** — φωτεινή, σκοτεινή ή ακολουθεί το λειτουργικό σύστημα
- **Χρώμα** — το χρώμα έμφασης που χρησιμοποιείται για κουμπιά, συνδέσμους, σήματα και ενεργές καταστάσεις
- **Στυλ χάρτη** — τα βασικά πλακίδια χάρτη (ξεχωριστή επιλογή για φωτεινή και σκοτεινή λειτουργία)

Οι τρεις ρυθμίσεις βρίσκονται στο **Φύλλο προφίλ** στο κάτω μέρος — κάντε κλικ στο avatar σας στη γραμμή επάνω για να το ανοίξετε.

## Λειτουργία (φωτεινή / σκοτεινή / σύστημα)

Εναλλαγή μεταξύ τριών λειτουργιών:

| Εικονίδιο  | Λειτουργία | Συμπεριφορά                                                      |
| ---------- | ---------- | ---------------------------------------------------------------- |
| 🖥️ Οθόνη  | Σύστημα    | Ακολουθεί την προτίμηση του λειτουργικού σας συστήματος· αλλάζει αυτόματα με την αλλαγή του λειτουργικού |
| ☀️ Ήλιος  | Φωτεινή    | Πάντα φωτεινή, αγνοεί το λειτουργικό σύστημα                    |
| 🌙 Φεγγάρι | Σκοτεινή   | Πάντα σκοτεινή, αγνοεί το λειτουργικό σύστημα                   |

Η λειτουργία **Σύστημα** είναι η προεπιλογή. Αν αλλάξετε το θέμα του λειτουργικού σας (π.χ. προγραμματισμένη σκοτεινή λειτουργία macOS στο ηλιοβασίλεμα), ο Πίνακας ελέγχου ακολουθεί αμέσως — χωρίς επαναφόρτωση.

## Χρώμα

Το χρώμα έμφασης καθορίζει τα κουμπιά, τους συνδέσμους, τα σήματα, τα πλαίσια εστίασης και το ενεργό στοιχείο της πλαϊνής γραμμής. Διατίθενται δώδεκα προκαθορισμένες παλέτες:

| Χρώμα  | Προεπισκόπηση |
| ------ | ------------ |
| Μαύρο  | ⚫           |
| Κόκκινο| 🔴           |
| Τριαντάφυλλο | 🌹      |
| Ροζ    | 🩷           |
| Πορτοκαλί | 🟠         |
| Κίτρινο| 🟡           |
| Πράσινο| 🟢           |
| Τιρκουάζ | 🟢          |
| Κυανό  | 🔵           |
| Μπλε   | 🔵           |
| Ινδικό | 🟣           |
| Μωβ    | 🟣           |

Επιλέξτε αυτό που σας φαίνεται πιο εύκολο στην ανάγνωση σε συνδυασμό με τη λειτουργία που έχετε επιλέξει (κάποια χρώματα φαίνονται καλύτερα σε φωτεινή, άλλα σε σκοτεινή λειτουργία).

## Στυλ χάρτη

Οι σελίδες που εμφανίζουν χάρτες (Live Map, λεπτομέρειες οχήματος, επεξεργαστής ζώνης, διαδρομή διαδρομής κ.ά.) χρησιμοποιούν ένα βασικό στυλ χάρτη που μπορείτε να επιλέξετε ανεξάρτητα. Ο Πίνακας ελέγχου διατηρεί **δύο ξεχωριστές προτιμήσεις στυλ χάρτη** — μία για τη φωτεινή λειτουργία και μία για τη σκοτεινή — ώστε ο χάρτης να ταιριάζει με το υπόλοιπο UI όταν αλλάζετε λειτουργίες.

- Η αλλαγή λειτουργίας (φωτεινή ↔ σκοτεινή) αλλάζει αυτόματα στο επιλεγμένο στυλ χάρτη για αυτή τη λειτουργία
- Τα διαθέσιμα στυλ εξαρτώνται από τον πάροχο χαρτών σας (MapTiler ή εναλλακτικό)· συνήθως: Streets, Satellite, Light, Dark, Outdoors

## Πού αποθηκεύονται οι προτιμήσεις

Οι τρεις ρυθμίσεις αποθηκεύονται στο **localStorage** του προγράμματος περιήγησής σας με τα εξής κλειδιά:

| Ρύθμιση          | Κλειδί αποθήκευσης     |
| ----------------- | --------------------- |
| Λειτουργία        | `app-dark-mode`       |
| Χρώμα             | `app-theme`           |
| Στυλ χάρτη (φωτεινή) | `app-map-style-light` |
| Στυλ χάρτη (σκοτεινή) | `app-map-style-dark`  |

Αυτό σημαίνει:

- **Ανά συσκευή, ανά πρόγραμμα περιήγησης** — διαφορετικός υπολογιστής = διαφορετικές προτιμήσεις
- **Δεν συγχρονίζονται** με τον λογαριασμό σας — οι συνάδελφοι που χρησιμοποιούν τον ίδιο λογαριασμό βλέπουν το δικό τους θέμα
- **Διαγράφονται με το "Καθαρισμό δεδομένων περιήγησης"** για αυτήν την ιστοσελίδα
- **Τα παράθυρα ανώνυμης περιήγησης** ξεκινούν με τις προεπιλογές

## Συμβουλές

- **Ξεκινήστε με τη λειτουργία Σύστημα** — αφήστε το λειτουργικό να αποφασίσει για εσάς· αλλάξτε σε Φωτεινή/Σκοτεινή μόνο αν έχετε προτίμηση διαφορετική από το λειτουργικό
- **Ταιριάξτε το στυλ χάρτη με τη λειτουργία** — το Satellite είναι δύσκολο στην ανάγνωση σε σκοτεινή λειτουργία· προτιμήστε στυλ "Dark" ή "Streets Dark"
- **Το χρώμα επηρεάζει την αντίθεση** — το Κίτρινο ή το Κυανό σε φωτεινό φόντο μπορεί να είναι δύσκολο στην ανάγνωση· αν τα κουμπιά φαίνονται "λεπτά", δοκιμάστε πιο σκούρο χρώμα (Κόκκινο, Μπλε, Ινδικό)
- **Ένα θέμα δεν είναι δικαίωμα** — κάθε χειριστής μπορεί να επιλέξει το δικό του· οι συνάδελφοι δεν θα δουν τις αλλαγές σας
