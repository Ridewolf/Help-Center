# Εξισορρόπηση — Διαδρομές

Η σελίδα Διαδρομές Εξισορρόπησης (`/rebalance/runs`) είναι το **λειτουργικό αρχείο καταγραφής κάθε διαδρομής εξισορρόπησης**: ποιος οδήγησε ποιο βαν, από ποιο αμαξοστάσιο ξεκίνησε, πόσα πατίνια και μπαταρίες έχει στο όχημα, αν είναι στην ώρα τους και πού παρουσιάστηκαν προβλήματα.

Μια **διαδρομή** είναι η εργασία ενός βάρδιας — ένας οδηγός, ένα βαν, ένα αμαξοστάσιο προέλευσης, μια διατεταγμένη λίστα στάσεων και ένα προγραμματισμένο παράθυρο εκτιμώμενης ώρας άφιξης (ETA). Η σελίδα επιτρέπει στους διαχειριστές να παρακολουθούν ενεργές διαδρομές και να ελέγχουν τις ολοκληρωμένες.

Αυτή η σελίδα είναι η λεπτομερής προβολή ανά διαδρομή που συμπληρώνει την ανώτερου επιπέδου περίληψη [Analytics — Rebalance](runs.md) και τον πίνακα βάσει τοποθεσίας [Rebalance — Dead Zones](dead-zones.md).

Απαιτούμενη άδεια: συνδεδεμένος χειριστής (η διαδρομή επιβάλλει μόνο _requiresAuth_, χωρίς συγκεκριμένο αναγνωριστικό άδειας).

> Σημείωση — κατά τη στιγμή της συγγραφής, τα endpoints CRUD του `/rebalance/runs` δεν είναι ακόμη ενεργά. Η σελίδα εμφανίζει το μπλοκ φίλτρων, τη σειρά KPI και τη διάταξη πίνακα με ψεύτικα KPI και κενή λίστα. Οι λειτουργίες _Δημιουργία διαδρομής_, _Αναζήτηση_, _Αυτόματη ανανέωση_ και το μενού ενεργειών ανά γραμμή (_Αποστολή_, _Επανακατανομή_, _Επαναβέλτιστη_, _Εκτύπωση φύλλου_, _Εξαγωγή_, _Επεξεργασία_, _Ακύρωση_) είναι υλοποιημένες στον κώδικα αλλά σχολιασμένες μέχρι να ενεργοποιηθεί το backend. Το κλικ σε μια γραμμή πλοηγεί στο `/rebalance/runs/:id` αλλά η σελίδα λεπτομερειών δεν περιλαμβάνεται σε αυτή την έκδοση.

## Σειρά KPI (επάνω)

Μια σειρά από πέντε κάρτες KPI συνοψίζει τις σημερινές διαδρομές.

| KPI                | Τι εμφανίζει                                                                                  |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **Ενεργές διαδρομές** | Διαδρομές που βρίσκονται σε _Απεσταλμένες_ / _Σε εξέλιξη_ / _Παύση_                          |
| **Ποσοστό στην ώρα του** | Ποσοστό διαδρομών που φτάνουν εντός του προγραμματισμένου παραθύρου ETA· πράσινη ανοδική τάση ≥ 90%, κόκκινη καθοδική κάτω από αυτό |
| **Καθυστερημένες διαδρομές** | Αριθμός διαδρομών με σημαία _Καθυστερημένες_ στο SLA — ο δείκτης "τι χρειάζεται βοήθεια" του διαχειριστή |
| **Συνολικά χλμ σήμερα** | Συνολική απόσταση που διένυσαν όλα τα βαν εξισορρόπησης σήμερα                                |
| **Ανταλλαγές μπαταριών** | Συνολικές ανταλλαγές μπαταριών που έγιναν από την ομάδα πεδίου σήμερα                         |

Οι πέντε μαζί δίνουν μια συνοπτική εικόνα για το πώς εξελίσσεται η σημερινή λειτουργία πεδίου σε σχέση με το σχέδιο.

## Φίλτρα

Τέσσερα φίλτρα βρίσκονται στην κάρτα _Φίλτρα_, όλα συνδυάζονται με λογική ΚΑΙ. Ένα κουμπί _Καθαρισμός όλων_ στα δεξιά επαναφέρει το μπλοκ.

| Φίλτρο            | Τύπος    | Επιλογές                                                                                 |
| ----------------- | -------- | --------------------------------------------------------------------------------------- |
| **Κατάσταση**     | Αναπτυσσόμενο | _Όλα_ / _Προγραμματισμένες_ / _Απεσταλμένες_ / _Σε εξέλιξη_ / _Παύση_ / _Ολοκληρωμένες_ / _Ακυρωμένες_ |
| **Κίνδυνος SLA**  | Αναπτυσσόμενο | _Όλα_ / _Στο σωστό δρόμο_ / _Σε κίνδυνο_ / _Καθυστερημένες_ — σημαία καθυστέρησης διαδρομής |
| **Πόλη**          | Αναπτυσσόμενο | _Όλες οι πόλεις_ / _Μόσχα_ / _Άγιος Πετρούπολη_                                        |
| **Έχει περιστατικά** | Αναπτυσσόμενο | _Όλα_ / _Ναι_ / _Όχι_ — καταγεγραμμένα περιστατικά στη διαδρομή                          |

Έλεγχος ελεύθερου κειμένου _Αναζήτηση_ (κατά αριθμό διαδρομής, οδηγό ή βαν) είναι υλοποιημένος αλλά προς το παρόν κρυφός μαζί με το _Αυτόματη ανανέωση_ και τη _Δημιουργία διαδρομής_ μέχρι να ενεργοποιηθεί το endpoint.

## Στήλες

Ο πίνακας έχει εννέα ορατές στήλες. Οι γραμμές είναι κλικαριστές — πλοηγούν στο `/rebalance/runs/:id` (η λεπτομερής προβολή δεν περιλαμβάνεται σε αυτή την έκδοση).

| Στήλη                 | Περιεχόμενο                                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Αριθμός διαδρομής** | Αναγνωριστικό διαδρομής αναγνώσιμο από άνθρωπο (π.χ. `RUN-2026-0517-001`)                                                |
| **Οδηγός / Βαν**      | Άβαταρ οδηγού + όνομα + τηλέφωνο; κάτω το μοντέλο βαν + αριθμός πινακίδας                                            |
| **Αμαξοστάσιο / Πόλη** | Όνομα αμαξοστασίου προέλευσης και η πόλη του                                                                           |
| **Κατάσταση**         | Ετικέτα κατάστασης — γκρι _Προγραμματισμένη_, μπλε _Απεσταλμένη_, πράσινη _Σε εξέλιξη_, κίτρινη _Παύση_, τιρκουάζ _Ολοκληρωμένη_, κόκκινη _Ακυρωμένη_ |
| **Στάσεις**           | Πρόοδος ως `ολοκληρωμένες / σύνολο`, με _Απέτυχε: N_ από κάτω με κόκκινο όταν κάποια στάση απέτυχε                      |
| **Φορτίο**            | Φορτωμένα πατίνια (`🛴 μέσα / χωρητικότητα`) και φορτωμένες μπαταρίες (`🔋 φορτισμένες + εκφορτισμένες / χωρητικότητα`) |
| **Προγραμματισμένο**  | Ώρα έναρξης–λήξης ETA + προγραμματισμένη απόσταση (χλμ) και διάρκεια (λεπτά)                                            |
| **Κίνδυνος SLA**      | Ετικέτα κινδύνου — πράσινη _Στο σωστό δρόμο_, κεχριμπαρένια _Σε κίνδυνο_, κόκκινη _Καθυστερημένη_                      |
| **Δημιουργήθηκε / Ενημερώθηκε** | Ημερομηνία δημιουργίας επάνω, ημερομηνία τελευταίας ενημέρωσης από κάτω                                              |

Η στήλη ενεργειών (μενού τριών σημείων) είναι υλοποιημένη αλλά σχολιασμένη μέχρι να ενεργοποιηθούν τα endpoints CRUD· δείτε τις _Ενέργειες γραμμής_ παρακάτω για το προγραμματισμένο σύνολο.

## Αναφορά κατάστασης

Μια διαδρομή βρίσκεται ακριβώς σε μία κατάσταση· η κατάσταση καθορίζει ποιες ενέργειες αποστολής είναι διαθέσιμες:

| Κατάσταση      | Σημασία                                               |
| -------------- | ----------------------------------------------------- |
| **Προγραμματισμένο** | Δημιουργήθηκε και προγραμματίστηκε αλλά δεν έχει σταλεί ακόμα στον οδηγό |
| **Απεσταλμένο** | Στάλθηκε στον οδηγό / βαν — αναμονή αναχώρησης        |
| **Σε εξέλιξη**  | Το βαν κινείται και / ή κάνει στάσεις                   |
| **Παύση**      | Ο οδηγός έκανε παύση στη διαδρομή (διάλειμμα, περιστατικό κ.λπ.) |
| **Ολοκληρωμένο**| Όλες οι στάσεις επιχειρήθηκαν, η διαδρομή έκλεισε       |
| **Ακυρωμένο**  | Διακόπηκε πριν την ολοκλήρωση                          |

## Αναφορά κινδύνου SLA

Ένα σήμα σε πραγματικό χρόνο για το αν η διαδρομή θα φτάσει στο προγραμματισμένο παράθυρο:

| Κίνδυνος      | Σημασία                                               |
| ------------- | ----------------------------------------------------- |
| **Στο σωστό δρόμο** | Ο τρέχων ρυθμός ταιριάζει με την προγραμματισμένη ETA |
| **Σε κίνδυνο** | Τάση καθυστέρησης, αλλά ακόμα εντός ανακτήσιμης απόστασης |
| **Καθυστέρηση**| Το σχέδιο έχει ήδη χαθεί — χρειάζεται προσοχή από τον διαχειριστή |

Χρησιμοποιήστε _Κίνδυνος SLA = Καθυστέρηση_ ως το πρώτο φίλτρο του διαχειριστή το πρωί.

## Ενέργειες γραμμής (προγραμματισμένες)

Κάθε γραμμή θα έχει ένα μενού με τρεις τελείες στα δεξιά με τις παρακάτω ενέργειες· σήμερα η στήλη είναι κρυφή μέχρι να είναι διαθέσιμο το API.

| Ενέργεια       | Τι θα κάνει                                              |
| -------------- | -------------------------------------------------------- |
| **Προβολή**    | Ανοίγει τη σελίδα λεπτομερειών διαδρομής στο `/rebalance/runs/:id` |
| **Αποστολή**   | Μεταφέρει μια _Προγραμματισμένη_ διαδρομή σε _Απεσταλμένη_, ειδοποιώντας τον οδηγό |
| **Επανακατανομή** | Αλλάζει οδηγό και / ή βαν στη διαδρομή                  |
| **Επαναβελτιστοποίηση** | Επανατρέχει τον βελτιστοποιητή διαδρομής για τις υπόλοιπες στάσεις |
| **Εκτύπωση φύλλου** | Δημιουργεί ένα εκτυπώσιμο φύλλο διαδρομής (περίληψη για τον οδηγό) |
| **Εξαγωγή**    | Εξάγει τα δεδομένα διαδρομής ως αρχείο (σεβόμενη φίλτρα / ταξινόμηση) |
| **Επεξεργασία**| Ανοίγει τον επεξεργαστή διαδρομής                        |
| **Ακύρωση**    | Ακυρώνει τη διαδρομή — ανοίγει παράθυρο επιβεβαίωσης    |

## Κενές / καταστάσεις φόρτωσης

- **Φόρτωση** — ένας περιστρεφόμενος δείκτης με το μήνυμα "Φόρτωση διαδρομών…" ενώ γίνεται ερώτημα στο backend
- **Σφάλμα** — μια μπάντα _Συναγερμού_ με κουμπί _Προσπαθήστε ξανά_ αν η αίτηση αποτύχει
- **Κενό** — ένα εικονίδιο _Φορτηγού_ στο κέντρο με το μήνυμα "Δεν βρέθηκαν διαδρομές"· αυτή είναι η **αναμενόμενη κατάσταση σήμερα** καθώς το endpoint δεν επιστρέφει στοιχεία

## Τυπικές ροές εργασίας

- **Πρωινός έλεγχος αποστολών** — Φιλτράρισμα _Κατάσταση = Προγραμματισμένο_, ταξινόμηση κατά ημερομηνία δημιουργίας, αποστολή κάθε διαδρομής με τη σειρά
- **Ζωντανή παρακολούθηση** — Φιλτράρισμα _Κατάσταση = Σε εξέλιξη_, μετά _Κίνδυνος SLA = Καθυστέρηση_ για εμφάνιση οδηγών που χρειάζονται βοήθεια· μόλις ενεργοποιηθεί, το _Αυτόματο ανανέωση_ κρατά την προβολή φρέσκια
- **Ανασκόπηση τέλους ημέρας** — Φιλτράρισμα _Κατάσταση = Ολοκληρωμένο_, σάρωση της στήλης _Στάσεις_ για διαδρομές με αποτυχημένες στάσεις, κλικ σε κάθε μία για ανάλυση περιστατικού
- **Πόλη-πόλη** — Φιλτράρισμα _Πόλη_ κατά τη λειτουργία σε πολλές πόλεις· διασταύρωση μετρήσεων με τη σελίδα [Analytics — Rebalance](runs.md)
- **Διαλογή περιστατικών** — Φιλτράρισμα _Έχει περιστατικά = Ναι_ για εμφάνιση κάθε διαδρομής με πρόβλημα σήμερα
- **Έλεγχος χωρητικότητας** — Επισκόπηση της στήλης _Φορτίο_ στις γραμμές _Σε εξέλιξη_; τα βαν κοντά στη χωρητικότητα μπορεί να χρειαστεί να επιστρέψουν σύντομα στο ντεπό

## Συμβουλές

- **Οι αριθμοί διαδρομών είναι σταθεροί αναγνωριστικοί** — μοιραστείτε τους με την ομάδα πεδίου για σαφή συντονισμό ("κοιτάξτε το RUN-2026-0517-003")
- **Η στήλη στάσεων δείχνει την αλήθεια με μια ματιά** — `4/7` σημαίνει τέσσερις ολοκληρωμένες, τρεις απομένουν· ένα κόκκινο _Απέτυχε: N_ από κάτω = χρειάζεται παρακολούθηση
- **Το "εξαντλημένο" φορτίο έχει σημασία** — ένας υψηλός αριθμός εξαντλημένων μπαταριών σημαίνει ότι το βαν είναι γεμάτο με νεκρές μπαταρίες και πρέπει να περάσει από φορτιστή
- **Δημιουργήθηκε vs Ενημερώθηκε** — το _Ενημερώθηκε_ τικάρεται κάθε φορά που ο οδηγός ενεργεί στη διαδρομή· ένα παλιό _Ενημερώθηκε_ σε μια γραμμή _Σε εξέλιξη_ = ο οδηγός δεν έχει κάνει check-in για καιρό
- **Η κατάσταση _Παύση_ δεν είναι σφάλμα** — οι οδηγοί κάνουν παύσεις για διαλείμματα, περιστατικά και αλληλεπιδράσεις με αναβάτες· οι διαδρομές με μεγάλη παύση αξίζουν τηλεφώνημα
- **Μέχρι να κυκλοφορήσει το endpoint, θεωρήστε αυτή τη σελίδα ως προεπισκόπηση διάταξης / UX** — η δομή, τα φίλτρα και η οπτική γλώσσα είναι τελικά· τα δεδομένα πίσω τους όχι
