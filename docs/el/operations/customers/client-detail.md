# Λεπτομέρειες Πελάτη

Η σελίδα λεπτομερειών πελάτη (`/clients/:id`) είναι ο πάγκος εργασίας για έναν μεμονωμένο πελάτη. Χρησιμοποιήστε την για να ελέγξετε προσωπικές πληροφορίες, να κάνετε ενέργειες στο υπόλοιπο (φόρτιση, πρόστιμο), να αποκλείσετε / ξεμπλοκάρετε, να στείλετε μηνύματα και να ελέγξετε το ιστορικό διαδρομών και τη δραστηριότητα λογαριασμού του πελάτη.

Συνήθως φτάνετε εδώ κάνοντας κλικ σε μια γραμμή στη [λίστα Πελατών](clients.md) ή από τη σελίδα λεπτομερειών μιας διαδρομής (ο σύνδεσμος πελάτη στην κεφαλίδα).

Απαιτούμενη άδεια: **Clients** (`e4f5h6`). Συγκεκριμένες ενέργειες απαιτούν υπο-άδειες (σημειώνονται παρακάτω).

## Διάταξη

Από πάνω προς τα κάτω:

1. **Κεφαλίδα** — πίσω, όνομα, κατάσταση, κουμπί _Ενέργειες_
2. **Κάρτες επισκόπησης** — υπόλοιπο, διαδρομές, αξιολόγηση, κατάσταση (4 πλακίδια KPI)
3. **Καρτέλες** — Λεπτομέρειες / Δραστηριότητα / Ιστορικό

## Κεφαλίδα

Η κορυφαία γραμμή αναγνωρίζει τον πελάτη:

- **Κουμπί πίσω** (`←`) επιστρέφει στη λίστα
- **Όνομα** (όνομα + επώνυμο) και **κάψουλα κατάστασης** (Ενεργό / Αποκλεισμένο / Παγωμένο / Εγγραφή)
- Κουμπί **Ενέργειες** στα δεξιά — ανοίγει το παράθυρο ενεργειών

## Ενέργειες

Το πάτημα στο **Ενέργειες** ανοίγει ένα παράθυρο διαλόγου με κάθε διαθέσιμη ενέργεια χειριστή για αυτόν τον πελάτη. Κάθε ενέργεια ελέγχεται με άδεια:

| Ενέργεια            | Άδεια              | Τι κάνει                                                                   |
| ------------------- | ------------------- | -------------------------------------------------------------------------- |
| **Φόρτιση υπολοίπου** | `topup-manual`      | Ανοίγει το παράθυρο υπολοίπου — πιστώνει χρήματα στο πορτοφόλι του πελάτη  |
| **Επιβολή προστίμου** | `fine`              | Ανοίγει το παράθυρο προστίμου — χρεώνει χρήματα από το πορτοφόλι (ζημιά, στάθμευση κ.ά.) |
| **Αποστολή push**    | —                   | Ανοίγει παράθυρο για αποστολή ειδοποίησης push στην εφαρμογή του πελάτη    |
| **Αποκλεισμός / Ξεμπλοκάρισμα** | `block` / `unblock` | Εναλλαγή κατάστασης αποκλεισμού με προαιρετικό λόγο                        |
| **Επεξεργασία πελάτη** | `edit`              | Ανοίγει τη [φόρμα επεξεργασίας](client-create-edit.md)                    |
| **Διαγραφή πελάτη**  | `delete`            | Μαλακή διαγραφή με παράθυρο επιβεβαίωσης (κόκκινο καταστροφικό στοιχείο)   |

Οι ενέργειες για τις οποίες δεν έχετε άδεια είναι κρυφές.

## Κάρτες επισκόπησης

Μια σειρά από τέσσερις κάρτες κάτω από την κεφαλίδα συνοψίζουν τον πελάτη με μια ματιά:

| Κάρτα        | Τι δείχνει                                                                       |
| ----------- | ----------------------------------------------------------------------------------- |
| **Υπόλοιπο** | Υπόλοιπο πορτοφολιού στο νόμισμα της εταιρείας (κόκκινο αν αρνητικό)               |
| **Διαδρομές** | Συνολικός αριθμός διαδρομών                                                       |
| **Αξιολόγηση** | Μέση αξιολόγηση που έχουν αφήσει οι αναβάτες για αυτόν τον πελάτη                 |
| **Κατάσταση** | Τρέχουσα κατάσταση με υπότιτλο μιας γραμμής ("Ενεργό / Αποκλεισμένο / Παγωμένο / Εγγραφή") |

## Καρτέλες

Τρεις καρτέλες:

| Καρτέλα      | Περιεχόμενο                                                                                           |
| ------------ | --------------------------------------------------------------------------------------------------- |
| **Λεπτομέρειες** | Προσωπικά στοιχεία (όνομα, email, τηλέφωνο, κατάσταση, υπόλοιπο, ετικέτες) και το πάνελ **Συσκευές** (συσκευές που έχουν συνδεθεί) |
| **Δραστηριότητα** | Ενέργειες χειριστή και συστήματος στον λογαριασμό του πελάτη (αλλαγές κατάστασης, επεξεργασίες υπολοίπου κ.ά.)                |
| **Ιστορικό**  | Το ιστορικό διαδρομών του πελάτη — μια εστιασμένη τομή της παγκόσμιας λίστας Διαδρομών, περιορισμένη σε αυτόν τον πελάτη             |

### Καρτέλα Λεπτομερειών

Η πιο λεπτομερής προβολή της κατάστασης του λογαριασμού του πελάτη. Δύο περιοχές:

**Προσωπικά στοιχεία (πίνακας):**

- Όνομα
- Επώνυμο
- Email (δείκτης επαλήθευσης)
- Τηλέφωνο (δείκτης επαλήθευσης)
- Κατάσταση (με την κάψουλα κατάστασης)
- Υπόλοιπο (μορφοποιημένο στο νόμισμα της εταιρείας)
- Ετικέτες (τα chips που έχουν εφαρμοστεί σε αυτόν τον πελάτη)

**Πάνελ Συσκευών:**

Λίστα με κάθε συσκευή που έχει συνδεθεί στην εφαρμογή Rider App με αυτόν τον λογαριασμό, με χρονικές σημάνσεις τελευταίας εμφάνισης και επιλογή αποστολής push (όταν επιτρέπεται) ή αποσύνδεσης συσκευής. Χρήσιμο για έρευνες ασφαλείας και υποστήριξη "Δεν μπορώ να συνδεθώ".

### Καρτέλα Δραστηριότητας

Το χρονολογικό **ημερολόγιο δραστηριότητας** για αυτόν τον πελάτη: κάθε ενέργεια χειριστή (φόρτιση, πρόστιμο, αλλαγή κατάστασης, επεξεργασία, αποστολή SMS/email/push) και κάθε σύστημα συμβάν (ορόσημα εγγραφής, αλλαγές κατάστασης επαλήθευσης, προσαρμογές υπολοίπου από επιστροφές).

Χρήσιμο για συμμόρφωση, επίλυση διαφορών και λογοδοσία.

### Καρτέλα Ιστορικού

Το **ιστορικό διαδρομών** του πελάτη ως πίνακας — ίδια μορφή γραμμής με τη γενική λίστα Διαδρομών, προφιλτραρισμένη σε αυτόν τον πελάτη. Κάντε κλικ σε οποιαδήποτε γραμμή για να ανοίξετε τις λεπτομέρειες της διαδρομής.

Αυτή η καρτέλα είναι το σημείο εκκίνησής σας για περιπτώσεις "ο πελάτης λέει ότι η διαδρομή X ήταν λάθος".

## Τυπικά ροή εργασίας

- **Ο πελάτης λέει ότι το υπόλοιπο είναι λάθος** — ανοίξτε τις Λεπτομέρειες (τρέχον υπόλοιπο), μετά τη Δραστηριότητα (αναζητήστε την τελευταία αλλαγή υπολοίπου), μετά το Ιστορικό (επιβεβαιώστε τη διαδρομή που προκάλεσε τη χρέωση). Αν κάτι ήταν λάθος, _Ενέργειες → Φόρτιση υπολοίπου_ με αιτιολογία
- **Ο πελάτης αναφέρει χαμένο τηλέφωνο** — Λεπτομέρειες → Συσκευές → αποσυνδέστε τη χαμένη συσκευή (όταν υποστηρίζεται); προαιρετικά κλειδώστε το πορτοφόλι μέσω _Ενέργειες → Αποκλεισμός πελάτη_ μέχρι να ανακτήσουν πρόσβαση
- **Απάτη ή κατάχρηση** — Δραστηριότητα για τη χρονογραμμή, Ιστορικό για τις ύποπτες διαδρομές· μετά _Ενέργειες → Αποκλεισμός πελάτη_ με αιτιολογία· η αιτιολογία αποθηκεύεται στο ημερολόγιο δραστηριότητας
- **Επιστροφή καλής θέλησης** — _Ενέργειες → Φόρτιση υπολοίπου_ με περιγραφή όπως "Επιστροφή καλής θέλησης — εισιτήριο #12345"· η περιγραφή είναι ορατή στη Δραστηριότητα για το ιστορικό ελέγχου
- **Καλωσόρισμα / εισαγωγική επικοινωνία** — _Ενέργειες → Αποστολή push_ με μήνυμα καλωσορίσματος· ελέγξτε πρώτα τις Συσκευές για να βεβαιωθείτε ότι έχουν ενεργή συνεδρία

## Συμβουλές

- **Παρακολουθήστε την κάρτα Κατάστασης** — ακόμα κι αν όλα τα άλλα φαίνονται εντάξει, μια κατάσταση _Αποκλεισμένο_ ή _Παγωμένο_ εξηγεί γιατί ο πελάτης δεν μπορεί να κάνει διαδρομή
- **Το πάνελ Συσκευές είναι η αφετηρία για αποσφαλμάτωση** — οι περισσότερες περιπτώσεις "Δεν μπορώ να συνδεθώ" οφείλονται σε παρωχημένη συνεδρία συσκευής
- **Οι περιγραφές αναπλήρωσης και προστίμων εμφανίζονται στη Δραστηριότητα** — γράψτε κάτι που οι χειριστές μπορούν να αναζητήσουν αργότερα ("εισιτήριο #X", "επιστροφή για διαδρομή Y") αντί για απλώς έναν αριθμό
- **Η Επεξεργασία αφορά τα μεταδεδομένα** — όνομα, email, τηλέφωνο — όχι το υπόλοιπο. Χρησιμοποιήστε τα ειδικά παράθυρα διαλόγου υπολοίπου (με ιστορικό ελέγχου) για χρηματικές συναλλαγές
- **Η Βαθμολογία είναι η βαθμολογία _οδηγού_ του πελάτη** — χαμηλή βαθμολογία σε συνδυασμό με αυξήσεις σε αποδείξεις στάθμευσης / εισιτήρια συνήθως υποδεικνύει προβληματικό αναβάτη
- **Το URL περιέχει το αναγνωριστικό πελάτη** — επικολλήστε το σε συνομιλία υποστήριξης για να μοιραστείτε το ακριβές προφίλ
