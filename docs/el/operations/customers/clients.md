# Πελάτες — Λίστα

Η λίστα Πελατών (`/clients`) είναι η βάση δεδομένων πελατών σας: κάθε άτομο που έχει εγγραφεί στην υπηρεσία σας, με το υπόλοιπό του, τις ετικέτες, την περίληψη ιστορικού διαδρομών και τα κανάλια επικοινωνίας.

Για εργασία ανά πελάτη (πλήρες ιστορικό, ενέργειες υπολοίπου, συσκευές, σχόλια) ανοίξτε τη [Σελίδα λεπτομερειών πελάτη](client-detail.md).

Απαιτούμενη άδεια: **Πελάτες** (`e4f5h6`). Πρόσθετες υπο-άδειες ελέγχουν συγκεκριμένες ενέργειες σε γραμμές και μαζικές ενέργειες.

## Πώς εμφανίζονται οι πελάτες εδώ

Συνήθως δεν δημιουργείτε πελάτες στον πίνακα ελέγχου — εγγράφονται μέσω της εφαρμογής Rider App:

1. Ένα άτομο εγκαθιστά την **Ridewolf rider app** και εγγράφεται (τηλέφωνο ή email)
2. Το backend δημιουργεί εγγραφή πελάτη· η γραμμή εμφανίζεται εδώ με κατάσταση **Εγγραφή** ενώ η επαλήθευση (SMS, ταυτότητα, μέθοδος πληρωμής) είναι σε εξέλιξη
3. Μετά την ολοκλήρωση της επαλήθευσης, η κατάσταση αλλάζει σε **Ενεργό** — ο πελάτης μπορεί να κάνει διαδρομές
4. Οι χειριστές μπορούν να δημιουργήσουν πελάτες χειροκίνητα (π.χ. για VIP ή δοκιμαστικούς λογαριασμούς) μέσω `+ Δημιουργία` — καλύπτεται στο άρθρο _Δημιουργία_

Η λίστα ανανεώνεται όταν φορτώνετε ξανά ή αλλάζετε φίλτρα.

## Φίλτρα

| Φίλτρο     | Τύπος         | Σημειώσεις                                                  |
| ---------- | ------------ | ---------------------------------------------------------- |
| Αναζήτηση  | Κείμενο       | Αναζητά σε όνομα, τηλέφωνο, email, αναγνωριστικό πελάτη    |
| Περίοδος   | Ημερολόγιο    | Φιλτράρει κατά **ημερομηνία εγγραφής**· από / έως          |
| Κατάσταση  | Αναπτυσσόμενο | `Ενεργό` / `Αποκλεισμένο` / `Παγωμένο` / `Εγγραφή` (ή `Όλα`) |
| Ετικέτες  | Πολλαπλή επιλογή | Φιλτράρει με βάση τις ετικέτες που έχουν εφαρμοστεί στον πελάτη |

Όλα τα φίλτρα συνδυάζονται με AND. Τα φίλτρα εμφανίζονται πάνω από τον πίνακα· το URL αντανακλά την τρέχουσα κατάσταση.

## Στήλες

| Στήλη         | Ταξινομήσιμη; | Περιεχόμενο                                                                    |
| ------------- | ------------- | ------------------------------------------------------------------------------ |
| **Πελάτης**   | ✓             | Άβαταρ + όνομα/επώνυμο + τηλέφωνο ή email· σύνδεσμος στη σελίδα λεπτομερειών  |
| **Κανάλια**   | —             | Εικονίδια για τα κανάλια επικοινωνίας που έχει επαληθεύσει ο πελάτης (τηλέφωνο, email, κοινωνικά) |
| **Υπόλοιπο**  | ✓             | Υπόλοιπο πορτοφολιού στο νόμισμα της εταιρείας, με κόκκινο χρώμα αν είναι αρνητικό |
| **Ετικέτες**  | —             | Ετικέτες που έχουν εφαρμοστεί σε αυτόν τον πελάτη                             |
| **Κατάσταση** | ✓             | Ετικέτα κατάστασης (βλέπε αναφορά παρακάτω)                                  |
| **Βαθμολογία**| ✓             | Μέση βαθμολογία που έχουν αφήσει οι αναβάτες για αυτόν τον πελάτη (βαθμολογία οδηγού) |
| **Διαδρομές** | ✓             | Συνολικός αριθμός διαδρομών                                                  |
| **Τελευταία διαδρομή** | ✓      | Πότε ο πελάτης έκανε την τελευταία του διαδρομή                               |
| **Πληρωμή**  | —             | Εικονίδιο προεπιλεγμένης μεθόδου πληρωμής (κάρτα, πορτοφόλι κ.ά.)             |

Ταξινομήστε κάνοντας κλικ σε μια επικεφαλίδα που υποστηρίζει ταξινόμηση. Η ταξινόμηση αποτελεί μέρος του URL.

## Αναφορά καταστάσεων

| Κατάσταση       | Σημασία                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------- |
| **Ενεργό**      | Πλήρως επαληθευμένο, μπορεί να κάνει διαδρομές, μπορεί να χρεωθεί                        |
| **Αποκλεισμένο**| Δεν μπορεί να κάνει διαδρομές· αποκλεισμός από χειριστή (απάτη, κατάχρηση, χρέος) ή από το σύστημα |
| **Παγωμένο**    | Ο λογαριασμός είναι σε παύση (π.χ. ενώ διερευνάται διαφωνία ή κατόπιν αιτήματος πελάτη) |
| **Εγγραφή**    | Η εγγραφή είναι σε εξέλιξη — τηλέφωνο / email / ταυτότητα / μέθοδος πληρωμής δεν έχουν επαληθευτεί ακόμα |

## Ενέργειες γραμμής

Κάθε γραμμή έχει **μενού τριών σημείων** στα δεξιά. Οι διαθέσιμες ενέργειες εξαρτώνται από τις άδειές σας:

| Ενέργεια           | Άδεια               | Τι κάνει                                                                         |
| ------------------ | ------------------- | ------------------------------------------------------------------------------- |
| **Προβολή προφίλ** | —                   | Ανοίγει τη [σελίδα λεπτομερειών πελάτη](client-detail.md)                       |
| **Ιστορικό διαδρομών** | —                | Ανοίγει την προβολή διαδρομών του πελάτη (εστιασμένο τμήμα της παγκόσμιας λίστας διαδρομών) |
| **Αποστολή SMS**   | —                   | Ανοίγει διάλογο για αποστολή SMS στο επαληθευμένο τηλέφωνο του πελάτη           |
| **Αποστολή email** | —                   | Ανοίγει διάλογο για αποστολή email στη επαληθευμένη διεύθυνση του πελάτη        |
| **Αποστολή push**  | —                   | Ανοίγει διάλογο για αποστολή push ειδοποίησης στην εφαρμογή του πελάτη          |
| **Φόρτιση υπολοίπου** | `topup-manual`    | Ανοίγει διάλογο υπολοίπου — πιστώνει χρήματα στο πορτοφόλι του πελάτη           |
| **Επιβολή προστίμου** | `fine`            | Ανοίγει διάλογο προστίμου — χρεώνει χρήματα από το πορτοφόλι (για ζημιά, στάθμευση κ.ά.) |
| **Αποκλεισμός / Άρση αποκλεισμού** | `block` / `unblock` | Ανοίγει διάλογο αποκλεισμού — εναλλαγή κατάστασης αποκλεισμού με προαιρετικό λόγο |
| **Επεξεργασία**    | `edit`              | Ανοίγει τη [φόρμα επεξεργασίας](client-create-edit.md)                          |
| **Διαγραφή**       | `delete`            | Μαλακή διαγραφή εγγραφής πελάτη (με επιβεβαίωση· κόκκινο καταστροφικό στοιχείο)  |

Οι ενέργειες για τις οποίες δεν έχετε άδεια είναι κρυφές από το μενού.

## Μαζικές ενέργειες

Επιλέξτε έναν ή περισσότερους πελάτες με τα πλαίσια ελέγχου στα αριστερά. Εμφανίζεται μια **γραμμή μαζικών ενεργειών** στην κορυφή με τον αριθμό επιλεγμένων και τις ενέργειες:

| Μαζική ενέργεια   | Δικαίωμα           | Τι κάνει                                                                |
| ----------------- | ------------------ | ---------------------------------------------------------------------- |
| **Προσθήκη υπολοίπου** | `topup-manual`     | Πιστώνει ένα ενιαίο ποσό σε κάθε επιλεγμένο πορτοφόλι (με επιβεβαίωση) |
| **Χρέωση ποσού**  | `fine`             | Χρεώνει ένα ενιαίο ποσό από κάθε επιλεγμένο πορτοφόλι (π.χ. πρόστιμο εκδήλωσης) |
| **Αλλαγή κατάστασης** | `block` / `unblock` | Ορίζει την ίδια κατάσταση σε κάθε επιλεγμένο πελάτη (Ενεργό / Αποκλεισμένο / Παγωμένο) |
| **Αποστολή push** | —                  | Αποστέλλει ειδοποίηση push σε κάθε επιλεγμένο πελάτη ταυτόχρονα         |

Οι διάλογοι μαζικών ενεργειών σας καθοδηγούν στο ποσό / μήνυμα / κατάσταση και στη συνέχεια εφαρμόζουν σε όλες τις επιλεγμένες γραμμές με μία τελική επιβεβαίωση.

## Ενέργειες σελίδας (πάνω δεξιά)

- **+ Δημιουργία** — ανοίγει τη [φόρμα δημιουργίας πελάτη](client-create-edit.md) (ξεχωριστό άρθρο)

## Τυπικά ροή εργασιών

- **Διερεύνηση παραπόνου πληρωμής** — αναζήτηση με τηλέφωνο ή email → άνοιγμα λεπτομερειών → έλεγχος υπολοίπου και ιστορικού διαδρομών
- **Φόρτιση πορτοφολιού κατόπιν αιτήματος χειριστή** — βρείτε τον πελάτη, _Προσθήκη υπολοίπου_ στο μενού γραμμής, συμπληρώστε το ποσό, επιβεβαιώστε
- **Αποκλεισμός απατεώνα** — αναζήτηση πελάτη → _Αποκλεισμός / Άρση αποκλεισμού_ → ορισμός σε Αποκλεισμένο με αιτιολογία· η κατάσταση αλλάζει σε _Αποκλεισμένο_, δεν επιτρέπονται άλλες διαδρομές
- **Αποστολή SMS διακοπής λειτουργίας** — φιλτράρισμα με ετικέτα ζώνης → _Επιλογή όλων_ → _Αποστολή push_ (ή χρήση Marketing → SMS για μη επείγουσες ανακοινώσεις)
- **Έλεγχος κατόχων ετικέτας** — φιλτράρισμα με ετικέτα, έλεγχος υπολοίπου και αριθμού διαδρομών για ανωμαλίες

## Συμβουλές

- **Η κατάσταση είναι ο σιωπηλός φρουρός** — πελάτες σε _Εγγραφή_ / _Παγωμένο_ / _Αποκλεισμένο_ δεν μπορούν να κάνουν διαδρομές· μην περιμένετε να τους δείτε στη λίστα Διαδρομών
- **Τα εικονίδια καναλιών δείχνουν τι έχει επαληθευτεί** — η απουσία εικονιδίου email σημαίνει ότι το SMS είναι το μόνο κανάλι αποστολής για αυτόν τον πελάτη
- **Η βαθμολογία είναι η αξιολόγηση του αναβάτη για τον πελάτη** (όχι της διαδρομής) — χαμηλές βαθμολογίες συχνά σημαίνουν προβλήματα στάθμευσης ή αγενή συμπεριφορά· ελέγξτε με αποδείξεις στάθμευσης και εισιτήρια
- **Το υπόλοιπο που γίνεται κόκκινο** = αρνητικό πορτοφόλι. Ο πελάτης δεν μπορεί να ξεκινήσει νέες διαδρομές μέχρι να φορτιστεί ή να επιστραφεί
- **Τα δικαιώματα είναι στρωματοποιημένα** — μπορεί να μπορείτε να _Αποστείλετε SMS_ αλλά όχι να _Προσθέσετε υπόλοιπο_ στον ίδιο πελάτη· το μενού δείχνει τι μπορείτε να κάνετε
- **Το URL είναι κοινοποιήσιμο** — αντιγράψτε μια φιλτραρισμένη προβολή (π.χ. _Αποκλεισμένοι πελάτες με διαδρομές > 0_) και στείλτε την σε συνάδελφο
