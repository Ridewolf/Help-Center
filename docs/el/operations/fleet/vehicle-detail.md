# Λεπτομέρειες Οχήματος

Η σελίδα λεπτομερειών οχήματος (`/vehicles/:id`) είναι ο πάγκος εργασίας για μια μονάδα. Χρησιμοποιήστε την για να δείτε ζωντανά δεδομένα IoT, να στείλετε εντολές, να ελέγξετε το ιστορικό διαδρομών, να διερευνήσετε ειδοποιήσεις και να εκτελέσετε ενέργειες χειριστή (επεξεργασία, αλλαγή τοποθεσίας, σήμανση για συντήρηση, δημιουργία QR, διαγραφή).

Συνήθως φτάνετε εδώ κάνοντας κλικ σε μια γραμμή στη [λίστα Οχημάτων](vehicles.md).

Απαιτούμενη άδεια: **Οχήματα** (`k7m8n9`). Ορισμένες καρτέλες και ενέργειες χρειάζονται επιπλέον άδειες (σημειώνονται παρακάτω).

## Διάταξη

Από πάνω προς τα κάτω:

1. **Επικεφαλίδα** — πίσω, ετικέτα, κατάσταση, κουμπί _Ενέργειες_
2. **Κάρτες επισκόπησης** — μπαταρία, τελευταία σήμα, σύνοψη υγείας IoT, μοντέλο κ.ά.
3. **Κάρτα τοποθεσίας** — ένας μικρός χάρτης που δείχνει την τρέχουσα θέση GPS
4. **Καρτέλες** — Λεπτομέρειες / Διαδρομές / Δραστηριότητα / Ειδοποιήσεις / Εντολές

## Επικεφαλίδα

Η κορυφαία γραμμή αναγνωρίζει το όχημα:

- **Κουμπί πίσω** (`←`) επιστρέφει στη λίστα
- **Ετικέτα οχήματος** (π.χ. _RW-001_) και **κάψουλα κατάστασης** (Διαθέσιμο, Σε χρήση κ.ά.)
- **Κουμπί Ενέργειες** στα δεξιά — ανοίγει το παράθυρο ενεργειών

## Ενέργειες

Το κλικ στο **Ενέργειες** ανοίγει ένα παράθυρο διαλόγου με κάθε διαθέσιμη ενέργεια χειριστή για αυτό το όχημα. Ορισμένες απαιτούν άδεια:

| Ενέργεια                  | Άδεια      | Τι κάνει                                                                                                                               |
| ------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Επεξεργασία οχήματος**  | `edit`     | Ανοίγει τη [φόρμα επεξεργασίας](vehicle-create-edit.md)                                                                                 |
| **Προβολή ιστορικού διαδρομών** | —          | Ανοίγει παράθυρο με συντεταγμένες της πρόσφατης διαδρομής GPS                                                                           |
| **Σήμανση για συντήρηση** | —          | Γρήγορη αλλαγή κατάστασης σε _Συντήρηση_                                                                                              |
| **Αλλαγή τοποθεσίας**     | —          | Ανοίγει χάρτη για χειροκίνητη ενημέρωση συντεταγμένων GPS (χρήσιμο όταν η συσκευή IoT δεν στέλνει σήματα και ο χειριστής γνωρίζει την τοποθεσία) |
| **Δημιουργία QR κώδικα**  | —          | Ανοίγει τον δημιουργό QR για αυτό το όχημα (ετικέτα για εκτύπωση)                                                                       |
| **Διαγραφή οχήματος**     | `delete`   | Απαλή διαγραφή με παράθυρο επιβεβαίωσης                                                                                                |

Οι ενέργειες για τις οποίες δεν έχετε άδεια είναι κρυφές από το παράθυρο διαλόγου.

## Κάρτες επισκόπησης

Ένα πλέγμα μικρών καρτών κάτω από την επικεφαλίδα συνοψίζει το όχημα με μια ματιά:

- **Μπαταρία** — ποσοστό μπαταρίας σκούτερ (και μπαταρία πλακέτας IoT αν αναφέρεται ξεχωριστά)
- **Τελευταίο σήμα** — πότε η συσκευή IoT έστειλε τελευταία φορά, με κάψουλα κατάστασης (Σε σύνδεση / Εκτός σύνδεσης / Παρωχημένο)
- **Κλείδωμα** — κλειδωμένο / ξεκλειδωμένο
- **Μοντέλο** — όνομα μοντέλου, κατάσταση, εικόνα
- **GSM / GPS** — κατάσταση δικτύου κινητής και GPS
- **Λειτουργία ταχύτητας** — τρέχουσα λειτουργία οδήγησης (οικονομική, κανονική, σπορ κ.ά., αν υποστηρίζεται από το μοντέλο)
- **Τάση** — τάση πλακέτας IoT (τεχνικό πεδίο)

## Κάρτα τοποθεσίας

Ένας μικρός χάρτης δείχνει το όχημα ως ένα σημείο στην τελευταία γνωστή συντεταγμένη GPS, με προεπιλεγμένη ζουμ προσαρμοσμένη στο σημείο. Χρησιμοποιήστε το για γρήγορο «πού βρίσκεται τώρα;» χωρίς να ανοίξετε το ιστορικό διαδρομών.

## Καρτέλες

Η λεπτομέρεια εναλλάσσεται μεταξύ έως πέντε καρτελών (μερικές απαιτούν άδεια):

| Καρτέλα       | Άδεια         | Περιεχόμενο                                                                    |
| ------------- | ------------- | ------------------------------------------------------------------------------ |
| **Λεπτομέρειες** | —             | Πλήρη δεδομένα οχήματος — πεδία IoT, μοντέλο + τιμολόγια, ετικέτες, ζώνες, GSM/GPS, λειτουργία ταχύτητας |
| **Διαδρομές**  | view-rides    | Πρόσφατες διαδρομές με αυτό το όχημα (εστιασμένο υποσύνολο της παγκόσμιας λίστας Διαδρομών) |
| **Δραστηριότητα** | —             | Καταγραφή δραστηριότητας περιορισμένη σε αυτό το όχημα (ενέργειες χειριστή και συστήματος) |
| **Ειδοποιήσεις** | —             | Ομαδοποιημένα σφάλματα και συναγερμοί IoT με σελιδοποίηση (ιστορικό «τι πήγε στραβά») |
| **Εντολές**    | `iot-command` | Αποστολή εντολών IoT απευθείας στη συσκευή (κλείδωμα, ξεκλείδωμα, συναγερμός, επανεκκίνηση κ.ά.) |

### Καρτέλα Λεπτομερειών

Η προεπιλεγμένη καρτέλα και η πιο λεπτομερής προβολή της κατάστασης του οχήματος:

- **Πίνακας IoT** — μπαταρία, τάση, κλείδωμα, σήμα GSM, εγκυρότητα GPS, τελευταίο σήμα, λειτουργία ταχύτητας
- **Πίνακας μοντέλου** — όνομα και εικόνα μοντέλου, κατάσταση, ετικέτες κληρονομημένες από το μοντέλο
- **Πίνακας τιμολογίων** — τιμολόγια που έχουν ανατεθεί στο μοντέλο του οχήματος (αυτά καθορίζουν την τιμολόγηση διαδρομών)
- **Πίνακας ετικετών** — ετικέτες που εφαρμόζονται σε αυτό το συγκεκριμένο όχημα (επεξεργάσιμες από τον χειριστή μέσω _Επεξεργασία_)
- **Πίνακας ζωνών** — ζώνες στις οποίες ανήκει το όχημα αυτή τη στιγμή

Αν τα δεδομένα IoT αποτύχουν να φορτώσουν, εμφανίζεται μια μπάντα σφάλματος σε αυτή την καρτέλα· η υπόλοιπη σελίδα λειτουργεί κανονικά.

### Καρτέλα Διαδρομών

Λίστα με τις πρόσφατες διαδρομές που έγιναν με αυτό το όχημα — ίδια μορφή γραμμής με τη γενική λίστα Διαδρομών, φιλτραρισμένη μόνο για αυτό το όχημα. Κάντε κλικ σε οποιαδήποτε γραμμή για να ανοίξετε τη λεπτομέρεια διαδρομής.

Αυτή η καρτέλα είναι κρυφή εκτός αν έχετε την άδεια `view-rides` για αυτό το όχημα.

### Καρτέλα Δραστηριότητας

Χρονολογική **καταγραφή δραστηριότητας** για αυτό το όχημα: κάθε ενέργεια χειριστή (επεξεργασία, αλλαγή κατάστασης, διαγραφή, ενημέρωση ετικετών) και κάθε σύστημα (μεταβάσεις κατάστασης από ενεργοποιητές IoT, εκτελέσεις αυτοματισμών).

Χρήσιμο για συμμόρφωση, λογοδοσία και αποσφαλμάτωση απρόβλεπτων αλλαγών κατάστασης.

### Καρτέλα Ειδοποιήσεων

Ομαδοποιημένες **ειδοποιήσεις και σφάλματα IoT** που έχει αναφέρει η συσκευή, με σελιδοποίηση. Κάθε καταχώρηση περιλαμβάνει:

- Κωδικό και τίτλο κατανοητό από τον άνθρωπο
- Χρονικές σφραγίδες πρώτης / τελευταίας εμφάνισης
- Συχνότητα (πόσες φορές έχει εμφανιστεί αυτός ο κωδικός)
- Κατάσταση (ενεργό / επιλυμένο)

Ένα κουμπί _Καθαρισμός_ (όπου υποστηρίζεται) σας επιτρέπει να επισημάνετε μια ομάδα ως επιλυμένη. Η σελιδοποίηση σας επιτρέπει να περιηγηθείτε σε ιστορικές ειδοποιήσεις.

### Καρτέλα Εντολές

Άμεσες **εντολές IoT** προς τη συσκευή, ομαδοποιημένες κατά κατηγορία (π.χ. _Κλείδωμα & ξεκλείδωμα_, _Συναγερμός_, _Φώτα_, _Σύστημα_). Περιορίζεται με δικαίωμα `iot-command`.

- Επιλέξτε μια εντολή και κάντε κλικ στο _Αποστολή_
- Η εντολή αποστέλλεται στη συσκευή IoT· ο χρόνος απόκρισης εξαρτάται από το σήμα κινητής
- Το πρόσφατο ιστορικό εντολών εμφανίζεται παρακάτω με κατάσταση (απεσταλμένη / παραδοθείσα / αποτυχημένη)

Χρησιμοποιήστε το όταν χρειάζεται να κάνετε κάτι που δεν καλύπτει η μαζική διαδρομή _Αποστολή εντολής_ — διαγνωστικά, μεμονωμένες επανεκκινήσεις, χειροκίνητα ξεκλειδώματα για περιπτώσεις υποστήριξης.

## Τυπικές ροές εργασίας

- **Διερεύνηση παραπόνου** — ανοίξτε το Activity για να δείτε ποιοι χειριστές / συστήματα αλληλεπίδρασαν με αυτό το όχημα σήμερα· μετά Alerts για σφάλματα IoT· μετά Rides για τη συγκεκριμένη διαδρομή
- **Εξαναγκασμός κλειδώματος ή ξεκλειδώματος** — Καρτέλα Εντολές → _Αποστολή Κλειδώματος_ ή _Αποστολή Ξεκλειδώματος_ (απαιτεί `iot-command`)
- **Ανάκληση μονάδας για συντήρηση** — _Ενέργειες → Σήμανση για συντήρηση_ (ορίζει κατάσταση)· στείλτε την ομάδα πεδίου
- **Χειροκίνητη διόρθωση GPS** — _Ενέργειες → Αλλαγή τοποθεσίας_ (όταν η συσκευή IoT δεν ανταποκρίνεται και γνωρίζετε πού βρίσκεται)
- **Εκτύπωση νέας ετικέτας** — _Ενέργειες → Δημιουργία κωδικού QR_

## Συμβουλές

- **Παρακολουθήστε την καρτέλα Alerts** — συχνά σφάλματα είναι πρώιμες προειδοποιήσεις για προβλήματα υλικού· αντιμετωπίστε τα πριν γίνουν περιστατικά
- **Το Activity είναι το αρχείο ελέγχου σας** — κάθε αλλαγή χειριστή καταγράφεται εδώ με όνομα και χρονική σήμανση
- **Οι εντολές είναι μονόδρομες, αποστολή και λήθη μέσω κινητής** — αν δεν δείτε απάντηση μέσα σε ένα λεπτό, η συσκευή μπορεί να είναι εκτός σύνδεσης· ελέγξτε το Τελευταίο σήμα στην επισκόπηση πριν ξαναδοκιμάσετε
- **Οι ετικέτες και τα τιμολόγια προέρχονται από δύο μέρη** — οι ετικέτες σε επίπεδο οχήματος (πάνελ Ετικέτες, επεξεργάσιμες στην Επεξεργασία) υπερισχύουν / συμπληρώνουν τις ετικέτες σε επίπεδο μοντέλου (μόνο για ανάγνωση εδώ, ορίζονται στις Ρυθμίσεις οχήματος)
- **Η κάρτα Χάρτης δείχνει μόνο την τελευταία καρφίτσα** — για το ιστορικό διαδρομής χρησιμοποιήστε _Ενέργειες → Προβολή ιστορικού διαδρομής_
