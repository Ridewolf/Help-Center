# Όχημα — Δημιουργία & Επεξεργασία

Δύο διευθύνσεις URL μοιράζονται την ίδια διάταξη φόρμας:

- **Δημιουργία** — `/vehicles/create` — καταχωρεί μια νέα φυσική μονάδα
- **Επεξεργασία** — `/vehicles/:id/edit` — ενημερώνει τα μεταδεδομένα ενός υπάρχοντος οχήματος

Και οι δύο προσπελαύνονται από τη [Λίστα Οχημάτων](vehicles.md) (κουμπί `+ Δημιουργία` πάνω δεξιά) ή από τη [Λεπτομέρεια Οχήματος](vehicle-detail.md) (`Ενέργειες → Επεξεργασία οχήματος`).

Δικαιώματα:

- **Δημιουργία** — `Οχήματα` (`k7m8n9`) + υπο-δικαίωμα σχετικό με τη δημιουργία
- **Επεξεργασία** — `Οχήματα` (`k7m8n9`) + το υπο-δικαίωμα `edit`

## Διάταξη

Η σελίδα χωρίζεται σε δύο στήλες σε επιτραπέζιους υπολογιστές, στοιβάζεται σε κινητές συσκευές:

- **Αριστερά (8/12)** — η ίδια η φόρμα, μέσα σε κάρτα _Πληροφορίες Οχήματος_
- **Δεξιά (4/12)** — η πλαϊνή μπάρα **Οδηγού Πεδίου** με συμφραζόμενη βοήθεια για το πεδίο που έχει εστιαστεί, συν ζωντανή προεπισκόπηση όσων έχετε συμπληρώσει

## Πεδία

Συνολικά πέντε πεδία. Τα υποχρεωτικά πεδία σημειώνονται με κόκκινο αστερίσκο (`*`).

### 1. Ετικέτα (υποχρεωτικό)

Ο ανθρώπινα αναγνώσιμος κωδικός που εκτυπώνεται στο αυτοκόλλητο του οχήματος (π.χ. _RW-001_).

- Πρέπει να είναι μοναδική σε όλο τον στόλο σας
- Ελεύθερο κείμενο — η τυπική σύμβαση είναι _ΠΡΟΘΕΜΑ-ΑΑΑ_ (το πρόθεμα της εταιρείας σας + διαδοχικός αριθμός)
- Κάντε κλικ στο **Δημιουργία** (εικονίδιο αστραφτερής λάμψης) για αυτόματη συμπλήρωση — το σύστημα διαβάζει το πρόθεμα της εταιρείας σας και τις υπάρχουσες ετικέτες, υπολογίζει την επόμενη ακολουθία και τη γράφει στο πεδίο. Εμφανίζεται δείκτης φόρτωσης κατά το ερώτημα.

### 2. Κατάσταση (υποχρεωτικό)

Η αρχική / τρέχουσα κατάσταση του οχήματος. Δώδεκα επιλογές — η ίδια λίστα όπως στο [Φίλτρο λίστας Οχημάτων](vehicles.md#αναφορά-κατάστασης).

Συνηθισμένες αρχικές τιμές κατά τη δημιουργία:

- **Μη Έτοιμο** — δημιουργήθηκε αλλά δεν έχει δοθεί ακόμα στους αναβάτες (ασφαλής προεπιλογή)
- **Διαθέσιμο** — έτοιμο για ενοικίαση αμέσως (χρησιμοποιήστε μόνο αφού επαληθευτούν IoT και στάθμευση)
- **Αποθήκευση** — για απόθεμα που δεν είναι ακόμα σε υπηρεσία

Κατά την επεξεργασία, αλλάξτε την κατάσταση με προσοχή — αυτό μπορεί να αφαιρέσει το όχημα από τη ροή ενοικίασης ή να το επαναφέρει.

### 3. Συσκευή IoT (προαιρετικό)

Το IoT module που συνδέεται με αυτό το όχημα (το κυψελοειδές κουτί που χειρίζεται το κλείδωμα/ξεκλείδωμα και αναφέρει μπαταρία/GPS).

- Αναζητήσιμο αναπτυσσόμενο μενού — πληκτρολογήστε για φιλτράρισμα κατά IMEI ή ετικέτα
- Προαιρετικό — μπορείτε να δημιουργήσετε όχημα χωρίς IoT τώρα και να το συνδέσετε αργότερα (στη _Επεξεργασία_)
- Μια συσκευή IoT μπορεί να συνδεθεί μόνο με ένα όχημα κάθε φορά

Κατά την επεξεργασία, η αλλαγή της συσκευής IoT επιτρέπεται αλλά δίνει αίσθηση μη αναστρεψιμότητας — η νέα συσκευή αρχίζει να αναφέρει υπό αυτό το όχημα, η παλιά αποσυνδέεται. Χρησιμοποιήστε το όταν μια πλακέτα αντικαθίσταται φυσικά.

### 4. Μοντέλο Οχήματος (προαιρετικό)

Η εγγραφή μοντέλου (Ρυθμίσεις → Ρυθμίσεις Οχήματος) που ορίζει τα τιμολόγια της μονάδας, τις προεπιλεγμένες ρυθμίσεις και την κατηγορία.

- Αναζητήσιμο αναπτυσσόμενο μενού — πληκτρολογήστε για φιλτράρισμα κατά ετικέτα μοντέλου
- Προαιρετικό κατά τη δημιουργία, συνιστάται να οριστεί μόλις γνωρίζετε το μοντέλο — τα τιμολόγια και οι συμπεριφορές προέρχονται από αυτό
- Η αλλαγή του μοντέλου αργότερα ενημερώνει τα ενεργά τιμολόγια και τους κανόνες συμπεριφοράς — επιβεβαιώστε με τις λειτουργίες πριν την αλλαγή σε ζωντανή μονάδα

### 5. Ετικέτες (προαιρετικό)

Ετικέτες που εφαρμόζονται από τον χειριστή και αφορούν συγκεκριμένα αυτό το όχημα.

- Πολλαπλή επιλογή — επιλέξτε μία ή περισσότερες
- Αναζητήσιμες
- Αυτές είναι _ετικέτες επιπέδου οχήματος_, ξεχωριστές από τις _ετικέτες επιπέδου μοντέλου_ που κληρονομούνται από το επιλεγμένο Μοντέλο Οχήματος
- Οι διαδρομές με αυτό το όχημα θα κληρονομήσουν αυτές τις ετικέτες επιπέδου οχήματος κατά την έναρξη της διαδρομής (δείτε τη [Λίστα Διαδρομών](../trips/rides.md) για το πώς λειτουργεί η κληρονομιά ετικετών)

## Πλαϊνή μπάρα Οδηγού Πεδίου

Η δεξιά στήλη είναι ένας **συμφραζόμενος οδηγός**, όχι αντίγραφο της φόρμας:

- **Ζωντανή προεπισκόπηση** των τιμών που έχετε πληκτρολογήσει/επιλέξει (για να επαληθεύετε πριν αποθηκεύσετε)
- **Συμβουλή εντός γραμμής** που ενημερώνεται καθώς εστιάζετε σε πεδίο — εξηγεί τι σημαίνει το πεδίο, κοινές παγίδες, προεπιλογές
- **Αυτόματα πεδία** που εμφανίζονται: τρέχουσα ετικέτα, ετικέτα κατάστασης, ετικέτα συσκευής IoT, ετικέτα μοντέλου, πλήθος ετικετών

Χρησιμοποιήστε το ως δεύτερο ζευγάρι ματιών. Σε ευρεία οθόνη παραμένει ορατό ενώ κάνετε κύλιση στη φόρμα.

## Αποθήκευση / Πίσω

- **Πίσω** (`←`) — απορρίπτει μη αποθηκευμένες αλλαγές και επιστρέφει στην προηγούμενη σελίδα (τη λίστα ή τη λεπτομέρεια σε περίπτωση επεξεργασίας)
- **Αποθήκευση** — επικυρώνει τη φόρμα και δημιουργεί / ενημερώνει το όχημα. Εμφανίζεται μήνυμα επιτυχίας· τα σφάλματα πεδίων επισημαίνονται κάτω από το πεδίο με κόκκινο μήνυμα

Αν η επικύρωση αποτύχει (λείπει ετικέτα, λείπει κατάσταση, διπλή ετικέτα) η σελίδα παραμένει ανοιχτή με το προβληματικό πεδίο περιγραμμένο με κόκκινο.

## Δημιουργία vs Επεξεργασία — διαφορές

| Χαρακτηριστικό     | Δημιουργία                          | Επεξεργασία                                             |
| ------------------ | ---------------------------------- | ------------------------------------------------------- |
| Ετικέτα            | Κενό ή _Δημιουργία_                | Προ-συμπληρωμένο με την τρέχουσα ετικέτα               |
| Κατάσταση          | Κενό (πρέπει να επιλέξετε)         | Προ-συμπληρωμένο με την τρέχουσα κατάσταση             |
| Συσκευή IoT        | Κενό ή επιλογή από μη συνδεδεμένες | Προ-συμπληρωμένο; η αλλαγή αποσυνδέει την προηγούμενη  |
| Μοντέλο Οχήματος   | Κενό                               | Προ-συμπληρωμένο                                        |
| Ετικέτες           | Κενό                               | Προ-συμπληρωμένο με τις τρέχουσες ετικέτες επιπέδου οχήματος |
| Μετά την αποθήκευση | Ανακατεύθυνση στη νέα λεπτομέρεια οχήματος | Παραμένει στη φόρμα / ανακατεύθυνση στη λεπτομέρεια (ανάλογα με τη ροή) |
| Καταγραφή δραστηριότητας | "Όχημα δημιουργήθηκε από _όνομα χειριστή_" | "Όχημα επεξεργάστηκε από _όνομα χειριστή_" με διαφορές σε επίπεδο πεδίου |

Και οι δύο ροές γράφουν στο [Καταγραφή ενεργειών](vehicle-detail.md#καρτέλα-δραστηριότητας) του οχήματος.

## Τυπικές ροές εργασίας

- **Εγκατάσταση νέας παρτίδας** — δημιουργήστε ετικέτα → κατάσταση _Μη έτοιμο_ → συνδέστε IoT → ορίστε Μοντέλο → αποθήκευση. Μόλις η μονάδα είναι στο πεδίο και δοκιμαστεί, επεξεργαστείτε σε _Διαθέσιμο_
- **Αντικατάσταση κατεστραμμένης πλακέτας IoT** — επεξεργασία → αποσύνδεση / επιλογή νέου IoT → αποθήκευση → αναμονή για πρώτο σήμα (Τελευταίο σήμα στις λεπτομέρειες)
- **Επανακατηγοριοποίηση** — αλλαγή Μοντέλου κατά τη μεταφορά μονάδων μεταξύ στόλων/κατηγοριών
- **Προσθήκη προσωρινής ετικέτας** — επεξεργασία → Ετικέτες → αποθήκευση (π.χ. "Event 2026-05", "Δανεικό")

## Συμβουλές

- **Χρησιμοποιήστε το Generate** για ετικέτες — διατηρεί την αρίθμησή σας τακτοποιημένη και αποφεύγει διπλότυπα
- **Ορίστε το Μοντέλο νωρίς** — τα τιμολόγια προέρχονται από το μοντέλο· ένα μη ορισμένο μοντέλο σημαίνει ότι οι διαδρομές σε αυτό το όχημα θα υπαχθούν σε κανόνες τιμολόγησης χωρίς μοντέλο
- **Μην αλλάζετε την Κατάσταση σε _Διαθέσιμο_ μέχρι να επαληθεύσετε φυσικά το IoT** — οι αναβάτες θα μπορούν να το ξεκλειδώσουν αμέσως
- **Παρακολουθήστε τη συμβουλή Field Guide** όταν έχετε αμφιβολίες για ένα πεδίο — η ενσωματωμένη βοήθεια είναι πιο ενημερωμένη από αυτό το άρθρο
- **Το αρχείο δραστηριότητας είναι το δίχτυ ασφαλείας σας** — κάθε αποθήκευση καταγράφεται με όνομα χειριστή και χρονική σήμανση στις [λεπτομέρειες οχήματος](vehicle-detail.md#καρτέλα-δραστηριότητας)
