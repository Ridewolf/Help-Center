# Οχήματα — Λίστα

Η λίστα Οχημάτων (`/vehicles`) είναι το απόθεμα ολόκληρου του στόλου σας — κάθε πατίνι, ποδήλατο ή άλλη μονάδα, με την τρέχουσα κατάσταση, τοποθεσία, μπαταρία, σύνδεση IoT, ετικέτες και ζώνη. Αυτή είναι η πιο χρησιμοποιούμενη σελίδα στον Πίνακα ελέγχου: ξεκινάτε από εδώ για σχεδόν κάθε λειτουργία στόλου.

Για εργασία ανά όχημα (πλήρης κατάσταση, ιστορικό, εντολές IoT, αναπαραγωγή διαδρομής) ανοίξτε τη [Σελίδα λεπτομερειών οχήματος](vehicle-detail.md).

Απαιτούμενη άδεια: **Οχήματα** (`k7m8n9`).

## Πώς εμφανίζονται τα οχήματα εδώ

Τα οχήματα δεν εμφανίζονται από μόνα τους — δημιουργούνται και διαχειρίζονται από εσάς:

1. Ο χειριστής **δημιουργεί ένα όχημα** μέσω του κουμπιού _Δημιουργία_ (ορίζει ετικέτα, μοντέλο, συσκευή IoT, αρχική κατάσταση)
2. Το όχημα καταχωρείται σε μια συσκευή IoT· αυτή η συσκευή αρχίζει να αναφέρει **μπαταρία, κατάσταση κλειδώματος, τελευταία σήμανση, συντεταγμένες GPS** συνεχώς
3. Μόλις η συσκευή IoT στείλει τον πρώτο παλμό ζωής, η γραμμή σε αυτή τη λίστα γεμίζει με ζωντανά δεδομένα — ποσοστό μπαταρίας, ώρα σήματος, ένδειξη κλειδώματος
4. Οι χειριστές (και οι μαζικές ενέργειες) **ενημερώνουν κατάσταση, ετικέτες, ζώνη, ρυθμίσεις** κατά τη διάρκεια ζωής του οχήματος
5. Όταν το όχημα αποσύρεται, αλλάζετε την κατάστασή του σε _Αποθήκευση_ / _Συντήρηση_ / κ.ά., ή το διαγράφετε

Η λίστα ανανεώνεται όταν φορτώνετε ξανά ή αλλάζετε φίλτρα· ζωντανές ενημερώσεις IoT που στέλνονται από το backend μπορούν επίσης να ανανεώσουν γραμμές επιτόπου.

## Τρόποι προβολής — Πίνακας vs Χάρτης

Η σελίδα έχει δύο προβολές, εναλλασσόμενες από ένα χειριστήριο στο επάνω μέρος:

- **Πίνακας** — ο πλήρης πίνακας δεδομένων με όλα τα φίλτρα, ταξινόμηση και δυνατότητες μαζικής επιλογής
- **Χάρτης** — ο ίδιος στόλος απεικονισμένος σε χάρτη της περιοχής λειτουργίας σας· τα οχήματα είναι σημεία χρωματισμένα ανά κατάσταση με σήματα μπαταρίας

Τα φίλτρα εφαρμόζονται και στις δύο προβολές. Η προβολή Χάρτη είναι ιδανική για να εντοπίζετε συστάδες, κενά και ευκαιρίες ανακατανομής· ο Πίνακας είναι για εργασία με δεδομένα.

## Φίλτρα

| Φίλτρο   | Τύπος           | Σημειώσεις                                                                    |
| -------- | --------------- | ----------------------------------------------------------------------------- |
| Αναζήτηση | Κείμενο πλήρους πλάτους | Αναζητά ετικέτα οχήματος, ID, σειριακό IoT — η εισαγωγή κειμένου είναι **καθυστερημένη ~300ms** |
| Οδόμετρο | Αναπτυσσόμενο   | Κουτιά συνολικής απόστασης: `<1k`, `1k–10k`, `10k–50k`, `50k–100k`, `>100k` χλμ |
| Κατάσταση | Αναπτυσσόμενο   | Φιλτράρισμα κατά κατάσταση οχήματος (δείτε την αναφορά κατάστασης παρακάτω)  |
| Ετικέτες | Πολλαπλή επιλογή | Φιλτράρισμα κατά ετικέτες που έχουν εφαρμοστεί στο όχημα                      |

Όλα τα φίλτρα συνδυάζονται με AND. Τα chips φίλτρων εμφανίζονται πάνω από τον πίνακα· το URL ενημερώνεται καθώς προχωράτε.

## Στήλες

| Στήλη           | Μπορεί να ταξινομηθεί; | Περιεχόμενο                                                                                  |
| --------------- | --------------------- | -------------------------------------------------------------------------------------------- |
| **Υγεία**       | —                     | Συμπαγείς ενδείξεις υγείας IoT (περιφερειακά) — μικρά εικονίδια που συνοψίζουν την κατάσταση υποσυστημάτων IoT |
| **Κωδικός**     | ✓                     | Ετικέτα οχήματος (ο αναγνώσιμος κωδικός στο αυτοκόλλητο), με σύνδεσμο στη σελίδα λεπτομερειών οχήματος |
| **Κατάσταση**   | ✓                     | Ετικέτα κατάστασης (Διαθέσιμο, Σε χρήση, Φόρτιση κ.ά. — δείτε την αναφορά παρακάτω)          |
| **Μοντέλο**     | —                     | Όνομα μοντέλου και μικρογραφία (π.χ. Xiaomi M365)                                           |
| **Κλείδωμα**    | —                     | Εικονίδιο κλειδώματος — κλειστό (κλειδωμένο) / ανοιχτό (ξεκλείδωτο) βάσει της τελευταίας αναφοράς IoT |
| **Μπαταρία**    | ✓                     | Ποσοστό μπαταρίας με έγχρωμη μπάρα (πράσινο ≥ 60%, πορτοκαλί 30–60%, κόκκινο < 30%)         |
| **Ετικέτες**    | —                     | Ετικέτες που έχουν εφαρμοστεί σε αυτό το όχημα (οι χειριστές μπορούν να επεξεργαστούν)        |
| **Ζώνη**        | —                     | Ζώνη στην οποία βρίσκεται το όχημα αυτή τη στιγμή, ή "Εκτός ζώνης"                         |
| **Τελευταία διαδρομή** | ✓               | Ημερομηνία / ώρα που το όχημα ξεκλειδώθηκε τελευταία φορά για διαδρομή                       |
| **Τελευταίο σήμα** | ✓                   | Πότε η συσκευή IoT έκανε τελευταία αναφορά (ένα παλιό σήμα = πιθανώς η συσκευή είναι εκτός σύνδεσης) |

Οι στήλες που μπορούν να ταξινομηθούν σημειώνονται με ✓ — κάντε κλικ στην κεφαλίδα. Η ταξινόμηση αντικατοπτρίζεται στο URL.

## Αναφορά κατάστασης

Κάθε όχημα βρίσκεται ακριβώς σε μία κατάσταση. Η κατάσταση καθορίζει τη συμπεριφορά (αν οι αναβάτες μπορούν να το νοικιάσουν, αν ενεργοποιούνται ειδοποιήσεις IoT κ.ά.):

| Κατάσταση               | Σημασία                                               |
| ----------------------- | ----------------------------------------------------- |
| **Διαθέσιμο**           | Αδρανές, ενοικιάσιμο, σταθμευμένο σωστά               |
| **Σε χρήση**            | Επί διαδρομή                                          |
| **Φόρτιση**             | Σε σταθμό φόρτισης                                    |
| **Εκφορτισμένο**        | Μπαταρία πολύ χαμηλή για ενοικίαση                    |
| **Χρειάζεται διερεύνηση** | Επισημασμένο από σύστημα ή χειριστή — απαιτεί χειροκίνητη ανασκόπηση |
| **Συντήρηση**           | Στο συνεργείο / εκτός στόλου για επισκευή              |
| **Μη έτοιμο**           | Δημιουργήθηκε αλλά δεν έχει δοθεί ακόμα στους αναβάτες |
| **Κρατημένο**           | Κρατημένο για συγκεκριμένο αναβάτη/κράτηση            |
| **Μεταφορά**            | Μετακινείται (ανακατανομή, παραλαβή από πεδίο)         |
| **Αποθήκευση**          | Σε μακροχρόνια αποθήκευση, εκτός λειτουργίας          |
| **Κλεμμένο**            | Αναφέρθηκε κλεμμένο / αγνοούμενο                       |
| **Συναγερμός**          | Κρίσιμη ειδοποίηση από IoT ή σύστημα                   |

## Ενέργειες γραμμής

Κάθε γραμμή έχει **μενού με τρεις τελείες** στα δεξιά. Οι διαθέσιμες ενέργειες εξαρτώνται από τα δικαιώματά σας:

| Ενέργεια                | Δικαίωμα             | Τι κάνει                                                             |
| ----------------------- | -------------------- | ------------------------------------------------------------------- |
| **Προβολή λεπτομερειών**| —                    | Ανοίγει τη [σελίδα λεπτομερειών οχήματος](vehicle-detail.md)       |
| **Προβολή ιστορικού διαδρομής** | `coordinates-history` | Ανοίγει έναν χάρτη που αναπαράγει την πρόσφατη διαδρομή GPS του οχήματος |
| **Άνοιγμα στο Google Maps** | —                 | Ανοίγει τις τελευταίες γνωστές συντεταγμένες του οχήματος στο Google Maps (νέα καρτέλα) |
| **Επεξεργασία**          | `edit`               | Ανοίγει τη φόρμα επεξεργασίας                                       |
| **Αλλαγή κατάστασης**    | `edit`               | Ανοίγει ένα μικρό παράθυρο διαλόγου για αλλαγή κατάστασης χωρίς να φύγετε από τη λίστα |
| **Διαγραφή**             | `delete`             | Μαλακή διαγραφή του οχήματος (με παράθυρο επιβεβαίωσης)             |

Οι ενέργειες για τις οποίες δεν έχετε δικαιώματα είναι κρυφές.

## Μαζικές ενέργειες

Επιλέξτε ένα ή περισσότερα οχήματα με τα πλαίσια ελέγχου στα αριστερά κάθε γραμμής. Εμφανίζεται μια **γραμμή μαζικών ενεργειών** στην κορυφή με τον αριθμό των επιλεγμένων και τις διαθέσιμες ενέργειες:

| Μαζική ενέργεια      | Δικαίωμα       | Τι κάνει                                                        |
| -------------------- | -------------- | -------------------------------------------------------------- |
| **Αλλαγή κατάστασης** | `bulk-update`  | Ανοίγει παράθυρο διαλόγου και εφαρμόζει μία κατάσταση σε όλα τα επιλεγμένα οχήματα |
| **Αλλαγή ετικετών**   | `bulk-update`  | Προσθέτει ή αφαιρεί ετικέτες σε όλα τα επιλεγμένα              |
| **Αλλαγή ρυθμίσεων**  | `bulk-update`  | Εφαρμόζει ρυθμίσεις οχήματος (π.χ. μέγιστη ταχύτητα, συναγερμοί) σε όλα τα επιλεγμένα |
| **Αποστολή εντολής**  | `iot-command`  | Στέλνει εντολή IoT (κλείδωμα, ξεκλείδωμα, ενεργοποίηση/απενεργοποίηση συναγερμού, επανεκκίνηση) σε όλα |
| **Μαζικό QR**         | —              | Δημιουργεί εκτυπώσιμο φύλλο με QR κωδικούς για τα επιλεγμένα οχήματα |
| **Διαγραφή επιλεγμένων** | `delete`    | Μαλακή διαγραφή όλων των επιλεγμένων οχημάτων (με παράθυρο επιβεβαίωσης) |

## Ενέργειες σελίδας (πάνω δεξιά)

- **+ Δημιουργία** — ανοίγει τη [φόρμα δημιουργίας οχήματος](vehicle-create-edit.md) (ξεχωριστό άρθρο)
- **Εξαγωγή** — κατεβάζει την τρέχουσα φιλτραρισμένη λίστα ως αρχείο (σεβόμενη φίλτρα και ταξινόμηση)
- **Μαζικό QR** (διαθέσιμο και ως μαζική ενέργεια) — ανοίγει τον οδηγό μαζικής δημιουργίας QR κωδικών για εκτύπωση

## Προβολή χάρτη

Όταν αλλάζετε σε Προβολή χάρτη:

- Τα οχήματα εμφανίζονται ως **σημεία** χρωματισμένα ανά κατάσταση (πράσινο = Διαθέσιμο, μπλε = Σε χρήση, κ.ά.)
- Δίπλα σε κάθε σημείο υπάρχει ένα μικρό **σήμα μπαταρίας**
- Κάντε κλικ σε ένα σημείο για να ανοίξει ένα αναδυόμενο με την ετικέτα οχήματος, κατάσταση, μπαταρία και σύνδεσμο _Προβολή λεπτομερειών_
- **Τα φίλτρα εξακολουθούν να ισχύουν** — περιορίστε κατά κατάσταση, ετικέτες κ.ά. και ο χάρτης ενημερώνεται
- Μετακινήστε / ζουμάρετε με το ποντίκι ή με χειρονομίες δύο δακτύλων

Ο χάρτης τροφοδοτείται από τα ίδια δεδομένα με τον πίνακα — είναι ένας διαφορετικός φακός, όχι διαφορετικό σύνολο δεδομένων.

## Τυπικά ροή εργασιών

- **Μαζική επαναφορά ισορροπίας** — φιλτράρετε με `Status = Discharged` + ζώνη, επιλέξτε όλα, _Αποστολή εντολής → Κλείδωμα_ (ή _Αλλαγή κατάστασης → Μεταφορά_) πριν από την παραλαβή
- **Εντοπισμός κολλημένου οχήματος** — ταξινομήστε κατά _Τελευταίο σήμα_ αύξουσα για να δείτε τα παλαιότερα σήματα στην κορυφή
- **Εντοπισμός χαμηλής μπαταρίας πριν γίνει πρόβλημα** — ταξινομήστε κατά _Μπαταρία_ αύξουσα; το κάτω μέρος του στόλου είναι η ουρά συντήρησης του κοντινού μέλλοντος
- **Έλεγχος ετικέτας** — φιλτράρετε κατά ετικέτα και ελέγξτε τις γραμμές
- **Προετοιμασία προσωπικού πεδίου** — φιλτράρετε στους στόχους της ημέρας, _Μαζικό QR_ για εκτύπωση ετικετών για νέες μονάδες

## Συμβουλές

- **Η αναζήτηση έχει καθυστέρηση** — σταματήστε να πληκτρολογείτε για να απαντήσει ο διακομιστής μία φορά
- **Το URL = η προβολή** — αντιγράψτε και μοιραστείτε φιλτραρισμένους συνδέσμους με συναδέλφους
- **Η στήλη υγείας με μια ματιά** — τα μικρά εικονίδια συνοψίζουν υποσυστήματα IoT; περάστε τον δείκτη πάνω από οποιοδήποτε για να δείτε τι αντιπροσωπεύει (π.χ. σήμα κινητής, κατάσταση κλειδώματος, μέτρηση αισθητήρα)
- **Το χρώμα μπαταρίας είναι ο κωδικός σας** — μια κόκκινη μπάρα στη λίστα = χρειάζεται φορτιστή ή παραλαβή σύντομα
- **Ο δείκτης κλειδώματος είναι η τελευταία αναφορά IoT** — μπορεί να έχει καθυστέρηση μερικών δευτερολέπτων; χρησιμοποιήστε _Αποστολή εντολής → Κλείδωμα_ αν χρειάζεται να διασφαλίσετε την κατάσταση στη συσκευή
