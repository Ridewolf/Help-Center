# Διαδρομές — Λίστα

Μια **διαδρομή** είναι ένα μεμονωμένο ταξίδι που πραγματοποιείται από έναν πελάτη με ένα από τα οχήματά σας. Η λίστα Διαδρομών (`/rides`) είναι το κύριο αρχείο κάθε ταξιδιού — παρελθόντος, τρέχοντος και μελλοντικού — σε ολόκληρο τον στόλο.

Ανοίξτε μια σειρά για να δείτε τη [σελίδα λεπτομερειών διαδρομής](ride-detail.md) με τη διαδρομή, το χρονοδιάγραμμα και όλες τις ενέργειες.

Απαιτούμενη άδεια: **Διαδρομές** (`i1j2k3`).

## Πώς εμφανίζονται οι διαδρομές εδώ

Δεν δημιουργείτε διαδρομές στον πίνακα ελέγχου — προέρχονται από την πλευρά του πελάτη:

1. Ένας πελάτης **ξεκλειδώνει ένα όχημα** στην εφαρμογή για κινητά (Ridewolf rider app)
2. Το backend ανοίγει μια νέα εγγραφή διαδρομής συνδεδεμένη με το όχημα και τον πελάτη
3. Η διαδρομή εμφανίζεται αμέσως σε αυτή τη λίστα με κατάσταση **Ενεργό**
4. Όταν ο πελάτης **κλειδώνει / παρκάρει** το όχημα, το backend κλείνει τη διαδρομή· η κατάσταση αλλάζει σε **Ολοκληρωμένο** και υπολογίζεται η τελική ανάλυση (απόσταση, διάρκεια, τιμή)
5. Άλλες τελικές καταστάσεις (`Ακυρωμένο`, κ.ά.) προέρχονται από κανόνες συστήματος ή ενέργειες χειριστή

Ανανέωση ή επανεπίσκεψη της σελίδας για να τραβήξετε την πιο πρόσφατη εικόνα — οι ενεργές διαδρομές ενημερώνονται καθώς ο πελάτης κινείται.

## Προεπιλεγμένη σειρά

Κατά προεπιλογή, το backend επιστρέφει **πρώτα τις ενεργές διαδρομές**, μετά τις ολοκληρωμένες σε αντίστροφη χρονολογική σειρά (πρώτα οι πιο πρόσφατες). Εφαρμόστε ταξινόμηση στη στήλη για να παρακάμψετε αυτήν την προεπιλογή.

## Φίλτρα

| Φίλτρο    | Τύπος        | Σημειώσεις                                                          |
| ---------- | ------------ | ------------------------------------------------------------------ |
| Αναζήτηση | Κείμενο      | Αναζητά όνομα πελάτη, ετικέτα οχήματος, αναγνωριστικό διαδρομής   |
| Περίοδος  | Ημερολόγιο   | Επιλογή από / έως; προεπιλογή "όλο το διάστημα"                   |
| Κατάσταση | Αναπτυσσόμενο| `Ενεργό`, `Ολοκληρωμένο`, `Ακυρωμένο`, κ.ά.                       |
| Αξιολόγηση| Αναπτυσσόμενο| Φιλτράρισμα με βάση την αξιολόγηση με αστέρια από τον αναβάτη (1–5, _Χωρίς αξιολόγηση_) |
| Ετικέτες | Πολλαπλή επιλογή | Φιλτράρισμα με βάση ετικέτες διαδρομής (κληρονομημένες από το όχημα — δείτε τις Στήλες παρακάτω) |

Όλα τα φίλτρα συνδυάζονται με ΚΑΙ. Τα φίλτρα εμφανίζονται πάνω από τον πίνακα· το URL αντικατοπτρίζει την τρέχουσα κατάσταση φίλτρου.

## Στήλες

| Στήλη   | Ταξινομήσιμη; | Περιεχόμενο                                                      |
| ------- | ------------- | ----------------------------------------------------------------|
| Πελάτης | —             | Εικόνα προφίλ, όνομα, σύνδεσμος στο προφίλ του πελάτη          |
| Όχημα   | —             | Ετικέτα, μοντέλο, σύνδεσμος στο όχημα                           |
| Τιμολόγιο | —           | Όνομα τιμολογίου που εφαρμόστηκε στη διαδρομή                    |
| Στατιστικά | —           | Γρήγορες ενδείξεις: απόσταση, διάρκεια, συνολικό κόστος         |
| Ετικέτες | —            | Ετικέτες κληρονομημένες από το **όχημα** τη στιγμή που ξεκίνησε η διαδρομή |
| Κατάσταση | ✓           | Ετικέτα κατάστασης (Ενεργό, Ολοκληρωμένο, Ακυρωμένο, κ.ά.)      |
| Αξιολόγηση | ✓          | Αξιολόγηση με αστέρια από τον αναβάτη (ή "–" αν δεν υπάρχει)    |
| Δημιουργήθηκε | ✓       | Ημερομηνία & ώρα έναρξης διαδρομής; προεπιλεγμένη ταξινόμηση = πιο πρόσφατο πρώτο |

Ταξινομήστε κάνοντας κλικ σε μια κεφαλίδα που υποστηρίζει ταξινόμηση. Η επιλεγμένη ταξινόμηση αποτελεί μέρος του URL και **αντικαθιστά** την προεπιλεγμένη σειρά που περιγράφεται παραπάνω — δεν υπάρχει τρίτο κλικ για "επαναφορά προεπιλογής", αλλά μπορείτε να καθαρίσετε την ταξινόμηση επεξεργάζοντας το URL ή ανανεώνοντας χωρίς παράμετρο ταξινόμησης.

> **Οι ετικέτες κληρονομούνται από το όχημα.** Οι διαδρομές δεν έχουν δικό τους επεξεργαστή ετικετών — οι ετικέτες μιας διαδρομής είναι ένα στιγμιότυπο των ετικετών που υπήρχαν στο όχημα όταν ξεκίνησε η διαδρομή. Επεξεργαστείτε τις ετικέτες του οχήματος αργότερα και οι υπάρχουσες διαδρομές διατηρούν το αρχικό τους στιγμιότυπο· μόνο οι νέες διαδρομές παίρνουν τις νέες ετικέτες.

## Ενέργειες σειράς

Κάθε σειρά έχει ένα **μενού με τρεις τελείες** στα δεξιά. Οι διαθέσιμες ενέργειες εξαρτώνται από την κατάσταση της διαδρομής και τα δικαιώματά σας:

| Ενέργεια     | Άδεια          | Όταν είναι ενεργή                                            |
| ------------ | -------------- | ------------------------------------------------------------ |
| **Παύση**   | `pause-unpause` | Η διαδρομή είναι **Ενεργή** (όχι ήδη σε παύση, ολοκληρωμένη, ακυρωμένη) |
| **Συνέχεια**| `pause-unpause` | Η διαδρομή είναι **Σε παύση**                                |
| **Τερματισμός διαδρομής** | `end-ride` | Η διαδρομή **δεν** είναι Ολοκληρωμένη ή Ακυρωμένη          |

Οι ενέργειες για τις οποίες δεν έχετε άδεια είναι κρυφές. Οι απενεργοποιημένες ενέργειες (π.χ. Τερματισμός σε ήδη ολοκληρωμένη διαδρομή) εμφανίζονται με γκριζαρισμένο χρώμα ώστε να βλέπετε τι είναι δυνατό στη σωστή κατάσταση.

Το πλήρες σύνολο ενεργειών — επιστροφή χρημάτων, προβολή διαδρομής στον χάρτη, αποστολή ειδοποίησης, αρχειοθέτηση — βρίσκεται στη **σελίδα λεπτομερειών διαδρομής**. Κάντε κλικ στη σειρά για να τις αποκτήσετε.

## Ενέργειες σελίδας

Στο πάνω δεξιά μέρος της σελίδας λίστας:

- **Εξαγωγή** — κατεβάστε τη λίστα με τα τρέχοντα φίλτρα ως αρχείο (τα φίλτρα και η ταξινόμηση τηρούνται)

## Τυπικά ροή εργασιών στη λίστα

- **Παρακολούθηση ζωντανής δραστηριότητας** — ανοίξτε τη σελίδα και μείνετε σε αυτήν· στην κορυφή της λίστας εμφανίζονται οι ενεργές διαδρομές
- **Εύρεση διαδρομών σε ζώνη ή χρονικό παράθυρο** — συνδυάστε περίοδο + κατάσταση + ετικέτες
- **Εντοπισμός ανωμαλιών** — φιλτράρετε με `Κατάσταση = Ακυρωμένο` ή `Αξιολόγηση ≤ 2` και ψάξτε για μοτίβα (ίδιο όχημα; ίδια ώρα της ημέρας;)
- **Γρήγορος τερματισμός κολλημένης διαδρομής** — χωρίς να φύγετε από τη λίστα, ανοίξτε το μενού σειράς και _Τερματισμός διαδρομής_ (απαιτείται άδεια)

## Συμβουλές

- **Το URL είναι κοινοποιήσιμο** — φιλτράρετε τη λίστα, αντιγράψτε το URL, στείλτε το σε συνάδελφο — βλέπει την ίδια προβολή
- **Οι ενδείξεις στατιστικών στη λίστα** είναι ένας γρήγορος τρόπος να εντοπίσετε ασυνήθιστα σύντομες ή μακρές διαδρομές πριν κάνετε κλικ
- **Μην εμπιστεύεστε μόνο την αξιολόγηση** — ανοίξτε τη σελίδα λεπτομερειών για διαδρομές με χαμηλή αξιολόγηση· η αξιολόγηση είναι ένα από πολλά σήματα
- **Οι άδειες διαφέρουν ανά εταιρεία** — κάποιοι χειριστές βλέπουν μόνο διαδρομές για οχήματα που διαχειρίζονται· αν λείπει μια διαδρομή για εσάς, ελέγξτε με έναν διαχειριστή
