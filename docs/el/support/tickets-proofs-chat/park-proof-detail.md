# Λεπτομέρειες Απόδειξης Στάθμευσης

Η σελίδα λεπτομερειών απόδειξης στάθμευσης (`/support/park-proofs/:id`) είναι όπου εξετάζετε μία απόδειξη στάθμευσης σε βάθος και — αν είναι ακόμα σε εκκρεμότητα — τη διαχειρίζεστε. Ανοίγει ως μεγάλο παράθυρο διαλόγου πάνω από τη [λίστα Αποδείξεων Στάθμευσης](park-proofs.md)· η διεύθυνση URL αλλάζει ώστε η απόδειξη να μπορεί να κοινοποιηθεί / να συνδεθεί απευθείας.

Συνήθως φτάνετε εδώ κάνοντας κλικ στο _Προβολή_ σε μια γραμμή, κάνοντας κλικ σε πλακίδιο σε προβολή γκαλερί ή επικολλώντας μια απευθείας διεύθυνση URL.

Απαιτούμενη άδεια: **Αποδείξεις στάθμευσης** (`d5e6f7`). Η υπο-άδεια `review` ενεργοποιεί τις ενέργειες διαχείρισης, η `delete` ενεργοποιεί το κουμπί Διαγραφή.

## Πώς σχετίζεται με τη σελίδα αναθεώρησης

Υπάρχουν και οι δύο `/support/park-proofs/:id` (αυτή η σελίδα) και `/support/park-proofs/:id/review` — μοιάζουν αλλά εξυπηρετούν διαφορετικές λειτουργίες:

| Επιφάνεια                                                                          | Τι είναι                                                                                                                                    |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Λεπτομέρειες Απόδειξης Στάθμευσης (αυτή η σελίδα)**                            | **Παράθυρο διαλόγου** που ανοίγει από τη λίστα — πλήρης εικόνα με ζουμ, πλήρες πλαίσιο, πλήρες σύνολο ενεργειών. Μονή προβολή εγγραφής. URL `/support/park-proofs/:id` |
| [Αναθεώρηση Απόδειξης Στάθμευσης](park-proof-review.md)                           | **Πλήρης σελίδα** (`/:id/review`) — η αφιερωμένη επιφάνεια αναθεώρησης για μία απόδειξη                                                      |
| [Αυτόματη Αναθεώρηση Απόδειξης Στάθμευσης](park-proof-auto-review.md)             | **Λειτουργία απλοποίησης** — αυτόματη προώθηση ουράς εκκρεμών αποδείξεων, μία κάθε φορά                                                        |

Καθημερινά: χρησιμοποιήστε την **Αυτόματη Αναθεώρηση** για εκκαθάριση ουράς, το **παράθυρο διαλόγου λεπτομερειών** (αυτή η σελίδα) για μεμονωμένη επιθεώρηση από τη λίστα, και τη **σελίδα αναθεώρησης** για την αφιερωμένη ροή αναθεωρητή.

## Διάταξη

Το παράθυρο διαλόγου χωρίζεται σε δύο στήλες σε ευρείες οθόνες, στοιβάζεται σε στενές:

| Στήλη            | Πλάτος | Περιεχόμενα                                                                                           |
| ---------------- | ------ | --------------------------------------------------------------------------------------------------- |
| **Εικόνα (αριστερά)** | 3/5    | Η φωτογραφία πλήρους ανάλυσης με ζουμ, σε μαύρο φόντο                                              |
| **Πληροφορίες (δεξιά)** | 2/5    | Επικεφαλίδα (τίτλος + σήματα κατάστασης / τύπου), πλαίσιο (πελάτης / διαδρομή / όχημα), πλέγμα λεπτομερειών, ενέργειες αναθεώρησης |

## Εικόνα (αριστερή στήλη)

Μεγάλος προβολέας εικόνας με τη φωτογραφία πλήρους ανάλυσης σε μαύρο φόντο:

- **Κάντε κλικ στην εικόνα** για εναλλαγή ζουμ (1× → 2× → 3× → 4× → πίσω στο 1×)
- **Κύλινδρος κύλισης** για ζουμ μέσα ή έξω σε βήματα 0,5×
- Ο δείκτης αλλάζει μεταξύ ζουμ-μέσα / ζουμ-έξω ανάλογα με την κατάσταση
- Εμφανίζεται **σήμα ποσοστού ζουμ** πάνω αριστερά όταν είστε πάνω από 1× ζουμ

Τέσσερα κουμπιά εμφανίζονται κάτω δεξιά όταν περνάτε το ποντίκι (ημιδιαφανή στο μαύρο φόντο):

| Κουμπί              | Τι κάνει                                                                       |
| ------------------- | ------------------------------------------------------------------------------ |
| **Ζουμ μέσα**        | Βήμα ζουμ +0,5× (μέγιστο 4×)                                                  |
| **Ζουμ έξω**         | Βήμα ζουμ -0,5× (ελάχιστο 1×)                                                  |
| **Ελαχιστοποίηση**   | Επαναφέρει το ζουμ στο 1×                                                      |
| **Άνοιγμα σε νέα καρτέλα** | Ανοίγει την εικόνα πλήρους ανάλυσης σε νέα καρτέλα του προγράμματος περιήγησης για πιο προσεκτική εξέταση |

Αναζητήστε τα ίδια σημάδια όπως στη [σελίδα αναθεώρησης](park-proof-review.md): ολόκληρο το όχημα στο κάδρο, νόμιμη θέση στάθμευσης, κατεβασμένο σταντ, οτιδήποτε αντιφάσκει με τον ισχυρισμό του αναβάτη.

## Επικεφαλίδα (πάνω δεξιά στήλη)

Η γραμμή επικεφαλίδας ταυτοποιεί την απόδειξη:

- **Τίτλος** _"Αναθεώρηση Απόδειξης Στάθμευσης"_ με σύντομη περιγραφή από κάτω
- Δύο **σήματα** στοιβαγμένα δεξιά:
  - **Σήμα κατάστασης** — χρωματισμένο ανάλογα με την κατάσταση (κίτρινο Σε εκκρεμότητα, πράσινο Εγκρίθηκε, πορτοκαλί Προειδοποίηση, κόκκινο Απορρίφθηκε, σκούρο Αποκλεισμένο)
  - **Σήμα τύπου** — περίγραμμα σε σχήμα κάψουλας που δείχνει _Έναρξη_ / _Στάθμευση_ / _Λήξη_

## Ενότητα πλαισίου

Τρεις γραμμές που συνδέουν με σχετικές οντότητες. Κάθε μία είναι router-link (κλικ για άνοιγμα της σχετικής σελίδας λεπτομερειών στο ίδιο παράθυρο):

| Γραμμή       | Εμφανίζει                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------- |
| **Πελάτης**  | Όνομα πελάτη (σύνδεσμος στη [λεπτομέρεια πελάτη](../../operations/customers/client-detail.md)), email + τηλέφωνο (κλικ για αντιγραφή) |
| **Διαδρομή** | Όνομα / αναγνωριστικό διαδρομής συνδεδεμένο με τη [λεπτομέρεια διαδρομής](../../operations/trips/ride-detail.md)          |
| **Όχημα**    | Ετικέτα οχήματος συνδεδεμένη με τη [λεπτομέρεια οχήματος](../../operations/fleet/vehicle-detail.md), τύπος οχήματος από κάτω |

Χρησιμοποιήστε αυτές τις διασταυρούμενες αναφορές για γρήγορη δημιουργία πλαισίου — έχει παραβιάσει ξανά αυτός ο πελάτης, ολοκλήρωσε πραγματικά τη διαδρομή εδώ, έχει σηματοδοτηθεί συχνά αυτό το όχημα;

## Ενότητα λεπτομερειών

Ένα πλέγμα δύο στηλών κλειδιού/τιμής κάτω από το πλαίσιο. Τα πεδία που εμφανίζονται εξαρτώνται από την κατάσταση της απόδειξης:

| Πεδίο               | Πότε εμφανίζεται           | Τι εμφανίζει                                                                                                                                                                                                                                  |
| ------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Δημιουργήθηκε**   | Πάντα                      | Όταν η εφαρμογή του αναβάτη ανέβασε τη φωτογραφία                                                                                                                                                                                             |
| **Εξετάστηκε στις**  | Μόνο μετά την εξέταση      | Όταν ένας χειριστής (ή η Αυτόματη Εξέταση) πήρε την απόφαση                                                                                                                                                                                  |
| **Διάρκεια εξέτασης**| Μόνο μετά την εξέταση      | Χρόνος από Δημιουργία → Εξέταση (π.χ. "2ω 14λ") — χρήσιμο για μέτρηση SLA σε σχέση με την απόδειξη                                                                                                                                            |
| **Εξετάστηκε από**   | Μόνο μετά από χειριστή     | Ο χειριστής που την εξέτασε. Συνδέεται με το [προφίλ χειριστή](../../settings/access/operators.md). Αν ο χειριστής δεν βρεθεί (404, χωρίς δικαιώματα), εμφανίζεται το αναγνωριστικό ως κλικαριστός σύνδεσμος — η σελίδα προφίλ διαχειρίζεται την αυθεντικοποίηση |
| **Τοποθεσία**       | Όταν η διαδρομή έχει συντεταγμένες | Γεωγραφικό πλάτος / μήκος της εκκίνησης της διαδρομής (για αποδείξεις _Έναρξης_) ή του τέλους (για αποδείξεις _Στάθμευσης_/_Τέλους_), με ακρίβεια 6 δεκαδικών ψηφίων                                                                                 |

Αν η απόδειξη απορρίφθηκε με πρόστιμο, εμφανίζεται κόκκινη ειδοποίηση _Πρόστιμο_ κάτω από τις λεπτομέρειες με το ποσό του προστίμου σε νόμισμα της εταιρείας.

Αν υπάρχει προηγούμενο σχόλιο ή λόγος απόρριψης, εμφανίζεται ως ενότητα _Σχόλιο_ παρακάτω.

## Ενέργειες εξέτασης (μόνο σε εκκρεμότητα)

Αν η κατάσταση της απόδειξης είναι **Σε εκκρεμότητα**, εμφανίζεται επιλογέας ενέργειας στο κάτω μέρος της δεξιάς στήλης. Το παράθυρο λεπτομερειών υποστηρίζει **πέντε** ενέργειες διαχείρισης (μία παραπάνω από τη σελίδα αφιερωμένης εξέτασης):

| Ενέργεια                 | Επίδραση στην κατάσταση | Επιπλέον πεδία         | Πότε να χρησιμοποιηθεί                                                            |
| ------------------------ | ----------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| **Εγκρίνω**              | _Εγκεκριμένο_            | —                      | Η φωτογραφία είναι σαφώς καλή — δεν απαιτείται σχόλιο                            |
| **Εγκρίνω με σχόλιο**    | _Εγκεκριμένο_            | Απαιτείται σχόλιο       | Η φωτογραφία είναι καλή αλλά θέλετε να καταγράψετε σημείωση (ειδική περίπτωση, μελλοντική αναφορά, εκπαίδευση ML) |
| **Προειδοποιώ**          | _Προειδοποίηση_          | Συνιστάται σχόλιο       | Η φωτογραφία δεν είναι ιδανική — ο αναβάτης λαμβάνει ήπια ειδοποίηση, χωρίς πρόστιμο |
| **Απορρίπτω**            | _Απορριφθέν_             | Σχόλιο + Ποσό προστίμου | Κακή φωτογραφία — επιβάλλεται πρόστιμο. Το πρόστιμο χρεώνεται από το πορτοφόλι κατά την υποβολή |
| **Αποκλείω**             | _Αποκλεισμένο_           | Απαιτείται σχόλιο       | Σοβαρή / επαναλαμβανόμενη παράβαση — αποκλείει τον αναβάτη από μελλοντικές διαδρομές |


Κάθε ενέργεια εμφανίζεται ως κλικαριστή ραδιοκάρτα με περιγραφή· η επιλογή μιας αποκαλύπτει τα προαιρετικά πεδία (περιοχή κειμένου σχολίου και / ή πεδίο ποσού προστίμου). Το βασικό κουμπί υποβολής παίρνει το χρώμα της ενέργειας (πράσινο / κίτρινο / κόκκινο / σκούρο).

Μόλις υποβάλετε, το παράθυρο κλείνει, εμφανίζεται ειδοποίηση επιβεβαίωσης και η λίστα ανανεώνεται.

### Τι διαφέρει από τη σελίδα εξέτασης

Η αφιερωμένη [σελίδα εξέτασης](park-proof-review.md) (`/:id/review`) εμφανίζει **τέσσερις** ενέργειες ως κουμπιά στοιβαγμένα. Αυτό το παράθυρο εμφανίζει **πέντε** ενέργειες ως ραδιοκάρτες — η επιπλέον είναι το _Εγκρίνω με σχόλιο_, χρήσιμο για καταγραφή πλαισίου σε θετική απόφαση χωρίς να κλιμακωθεί σε προειδοποίηση.

## Κλειστές αποδείξεις (ήδη εξετασμένες)

Αν η απόδειξη έχει ήδη εξεταστεί (Εγκεκριμένη / Προειδοποίηση / Απορριφθείσα / Αποκλεισμένη), η ενότητα ενεργειών κρύβεται — το παράθυρο γίνεται μόνο για ανάγνωση. Βλέπετε ακόμα όλο το πλαίσιο (εικόνα, πελάτη / διαδρομή / όχημα, λεπτομέρειες, πρόστιμο, σχόλιο, ποιος εξέτασε και πότε), και μπορείτε ακόμα:

- **Διαγράψτε** την εγγραφή (με δικαίωμα `delete`) — μόνο για ανεπιθύμητα / δοκιμαστικά / λάθος ανεβάσματα διαδρομής
- **Κλείστε** το παράθυρο

Για να αλλάξετε μια απόφαση εκ των υστέρων, επικοινωνήστε με τον διαχειριστή σας — η τυπική ροή δεν επιτρέπει επανεξέταση μέσω της διεπαφής χρήστη.

## Υποσέλιδο

| Κουμπί            | Όταν είναι ορατό                               | Τι κάνει                                                                                                                          |
| ----------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Διαγραφή**      | Πάντα, αν έχετε την υπο-άδεια `delete`          | Αφαιρεί πλήρως την εγγραφή απόδειξης (με επιβεβαίωση). Χρησιμοποιήστε μόνο για δοκιμές / ανεπιθύμητα / λανθασμένες διαδρομές — όχι ως επιλογή μετριασμού |
| **Ακύρωση**       | Μόνο σε εκκρεμότητα                            | Κλείνει το παράθυρο διαλόγου χωρίς υποβολή                                                                                        |
| **Υποβολή ενέργειας** | Μόνο σε εκκρεμότητα, μετά την επιλογή ενέργειας | Υποβάλλει την επιλεγμένη ενέργεια (με χρώμα που ταιριάζει στην ενέργεια)                                                          |
| **Κλείσιμο**      | Ελεγμένες αποδείξεις                            | Κλείνει το παράθυρο διαλόγου                                                                                                     |

Το κλείσιμο του παραθύρου διαλόγου (Ακύρωση / Κλείσιμο / Esc / κλικ στο overlay) αφαιρεί το `/:id` από το URL ώστε το ιστορικό πίσω / μπροστά να ταιριάζει με αυτό που βλέπετε.

## Τυπικές ροές εργασίας

- **Έρευνα μιας απόδειξης από τη λίστα** — βρείτε την απόδειξη στη λίστα (φιλτράρισμα / αναζήτηση), κάντε κλικ στη σειρά → ανοίγει το παράθυρο λεπτομερειών → μετακινηθείτε στο περιεχόμενο → αποφασίστε
- **Εμβάθυνση σε μια επιβαρυμένη απόδειξη** — αναζητήστε ανά πελάτη → ανοίξτε μια από τις απορριφθείσες αποδείξεις τους → ελέγξτε το Reviewed by + σχόλιο για να δείτε ποιος αποφάσισε και γιατί → χρησιμοποιήστε το για επίλυση διαφορών
- **Γρήγορη έγκριση από σύνδεσμο** — λάβετε ένα URL από συνάδελφο → κάντε κλικ → ανοίγει το παράθυρο → κάντε ζουμ στη φωτογραφία → Εγκρίνετε / Εγκρίνετε με σχόλιο
- **Διασταύρωση ιστορικού οχήματος** — ανοίξτε μια απόδειξη → κάντε κλικ στο όχημα → δείτε αν το ίδιο όχημα έχει συνεχώς κακές φωτογραφίες στάθμευσης → αυτό δείχνει πρόβλημα τοποθέτησης / σήμανσης, όχι του αναβάτη
- **Έλεγχος κλήσεων αξιολογητή** — φιλτράρετε τη λίστα με Κατάσταση `Εγκρίθηκε` → κάντε κλικ στις αποδείξεις για να δείτε το Reviewed by + σχόλιο → βαθμονομήστε τα πρότυπα της ομάδας

## Συμβουλές

- **Το ζουμ με τον τροχό κύλισης είναι γρήγορο** — δεν χρειάζεστε το κουμπί — απλώς γυρίστε τον τροχό πάνω από την εικόνα
- **Η εικόνα ανοίγει σε νέα καρτέλα σε πλήρη ανάλυση** — όταν το ζουμ μέσα στο παράθυρο δεν αρκεί (π.χ. για ανάγνωση πινακίδας μεγέθους πινακίδας), ανοίξτε εξωτερικά
- **Το "Εγκρίνετε με σχόλιο" υπερτερεί της σιωπηρής έγκρισης** για ακραίες περιπτώσεις — αφήστε μια σύντομη σημείωση που ο επόμενος αξιολογητής (ή εσείς σε τρεις μήνες) θα εκτιμήσει
- **Το Μπλοκάρισμα είναι οριστικό** — οι αναβάτες μπορούν να ξεμπλοκαριστούν μέσω της [λεπτομέρειας πελάτη](../../operations/customers/client-detail.md) αλλά για οποιαδήποτε απόδειξη, το _Μπλοκάρισμα_ είναι η μέγιστη κλιμάκωση. Μην το χρησιμοποιείτε για πρώτη παράβαση
- **Διαγραφή έναντι Απόρριψης** — η Απόρριψη αφήνει εγγραφή μετριασμού (και επιβάλλει πρόστιμο στον αναβάτη); η Διαγραφή σβήνει εντελώς την απόδειξη. Αν θέλετε ίχνος, μην διαγράφετε ποτέ
- **Το URL είναι κοινοποιήσιμο** — `/support/park-proofs/:id` οδηγεί απευθείας εδώ, χωρίς πλοήγηση στη λίστα
- **Οι κλειστές αποδείξεις είναι μόνο για ανάγνωση** — αν ανοίξατε μια ελεγμένη απόδειξη περιμένοντας να ενεργήσετε, γι' αυτό τα κουμπιά έχουν εξαφανιστεί
