# Λεπτομέρειες Εισιτηρίου

Η σελίδα λεπτομερειών εισιτηρίου (`/support/tickets/:id`) είναι όπου διερευνάτε ένα υποστηρικτικό εισιτήριο. Ανοίγει ως μεγάλο παράθυρο πάνω από τη [λίστα Εισιτηρίων](tickets.md) — η διεύθυνση URL αλλάζει ώστε το εισιτήριο να μπορεί να κοινοποιηθεί / να συνδεθεί απευθείας.

Συνήθως φτάνετε εδώ κάνοντας κλικ σε μια γραμμή της λίστας ή επικολλώντας μια απευθείας διεύθυνση URL στον περιηγητή.

Απαραίτητη άδεια: **Εισιτήρια** (`a8b9c1`). Ορισμένες ενέργειες απαιτούν επιπλέον υπο-άδειες (`edit`, `delete`).

## Πώς σχετίζεται με άλλες προβολές εισιτηρίων

| Προβολή                                                                    | Για τι προορίζεται                                                             |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [Λίστα Εισιτηρίων](tickets.md)                  | Ολόκληρη η ουρά — αναζήτηση, φιλτράρισμα, ταξινόμηση                          |
| [Αυτόματη Ανασκόπηση Εισιτηρίου](ticket-auto-review.md) | Λειτουργία ροής — ένα εκκρεμές εισιτήριο τη φορά, γρήγορη διαλογή με πληκτρολόγιο |
| **Λεπτομέρειες εισιτηρίου (αυτή η σελίδα)**                              | Βαθιά ανάλυση ενός εισιτηρίου — πλήρης εικόνα, πλήρης περιγραφή, πλαίσιο, επεξεργασία / διαγραφή |

## Διάταξη

Το παράθυρο στοιβάζεται από πάνω προς τα κάτω:

1. **Επικεφαλίδα** — τίτλος (ετικέτα εισιτηρίου), γραμμή περιγραφής ("Εισιτήριο #ID"), κλείσιμο (X)
2. **Ενότητα εικόνας** — φωτογραφία αποδεικτικού στοιχείου του αναβάτη (μεγάλη, κλικ για άνοιγμα)
3. **Κάρτα λεπτομερειών εισιτηρίου** — κατάσταση, τύπος παραπόνου, περιγραφή, σχόλιο
4. **Κάρτα οχήματος & τοποθεσίας** — όχημα, IMEI, συντεταγμένες τοποθεσίας, ζώνη, αναφέρων
5. **Υποσέλιδο** — κουμπιά _Κλείσιμο_ και _Επεξεργασία_

## Επικεφαλίδα

Η κορυφαία λωρίδα ταυτοποιεί το εισιτήριο:

- Ένα **εικονίδιο alert-circle** δίπλα στην ετικέτα του εισιτηρίου (π.χ. η ετικέτα του οχήματος ή ένα δημιουργημένο όνομα εισιτηρίου)
- Μια **γραμμή περιγραφής** που δείχνει το ID του εισιτηρίου
- Το κουμπί κλεισίματος διαλόγου (×) πάνω δεξιά — κλείνει επίσης με Esc ή κλικ εκτός παραθύρου

Το κλείσιμο του διαλόγου αφαιρεί το `/:id` από τη διεύθυνση URL ώστε το ιστορικό πίσω / εμπρός να ταιριάζει με αυτό που βλέπετε.

## Ενότητα εικόνας

Η πλήρης φωτογραφία αποδεικτικού στοιχείου που υπέβαλε ο αναβάτης, αρκετά μεγάλη για γρήγορη επιθεώρηση:

- **Κάντε κλικ στην εικόνα** (ή στο κουμπί _Προβολή σε Πλήρες Μέγεθος_ που εμφανίζεται με το πέρασμα του ποντικιού) — ανοίγει η φωτογραφία σε αρχική ανάλυση σε νέα καρτέλα
- **Πέρασμα ποντικιού** — εμφανίζεται μια σκουρότερη επικάλυψη + το κουμπί _Προβολή σε Πλήρες Μέγεθος_
- Αν η εικόνα δεν φορτώσει, εμφανίζεται μια εικόνα κράτησης θέσης
- Αν το εισιτήριο δεν έχει εικόνα (σπάνιο, π.χ. εισιτήρια που ξεκίνησε ο χειριστής), η ενότητα κρύβεται

Το μικρογραφικό στη λίστα είναι μια μικρή έκδοση· αυτή είναι η πλήρης εικόνα έτοιμη για αξιολόγηση.

## Κάρτα λεπτομερειών εισιτηρίου

Αριστερή κάρτα του πλέγματος δύο καρτών. Πεδία:

| Πεδίο             | Τι εμφανίζει                                                                                                                        |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Κατάσταση**      | Το εικονίδιο κατάστασης (Σε εκκρεμότητα, Σε εξέλιξη, Επιλυμένο, Απορρίφθηκε, Διπλότυπο, κ.ά.) — ίδια παλέτα χρωμάτων με τη λίστα    |
| **Τύπος παραπόνου**| Το εικονίδιο τύπου παραπόνου — ίδια κωδικοποίηση χρωμάτων με τη λίστα (κόκκινο Μηχανική βλάβη, κίτρινο Καθαριότητα, κ.ά.)             |
| **Περιγραφή**      | Η ελεύθερη περιγραφή του αναβάτη, αποδοσμένη ως markdown (σεβασμός αλλαγών γραμμής, αυτόματοι σύνδεσμοι) — κενό αν ο αναβάτης δεν έγραψε τίποτα |
| **Σχόλιο**         | Εσωτερικό σχόλιο / σημειώσεις χειριστή για το εισιτήριο — κενό μέχρι να προστεθεί από χειριστή                                    |

Δείτε [Λίστα Εισιτηρίων → Αναφορά Κατάστασης / Τύποι Παραπόνων](tickets.md) για την πλήρη σημασία κάθε χρώματος εικονιδίου.

## Κάρτα Οχήματος & Τοποθεσίας

Δεξιά κάρτα του πλέγματος. Πεδία:

| Πεδίο        | Τι εμφανίζει                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------- |
| **Όχημα**    | Ετικέτα οχήματος (με εικονίδιο αυτοκινήτου) και το συνδεδεμένο IMEI της συσκευής IoT        |
| **Τοποθεσία**| Το γεωγραφικό πλάτος / μήκος όπου αναφέρθηκε το πρόβλημα (6 δεκαδικά ψηφία, με εικονίδιο καρφίτσας) |
| **Ζώνη**     | Η [ζώνη](../../settings/infrastructure/zones.md) στην οποία ανήκει η τοποθεσία, αν υπάρχει   |
| **Αναφέρων** | Ο αναβάτης / σύστημα / χειριστής που ανέφερε το εισιτήριο, με το email του                  |

Χρησιμοποιήστε αυτές τις διασταυρούμενες αναφορές για να μεταβείτε στο πλαίσιο: κάντε κλικ στο όχημα για να ανοίξετε τις [λεπτομέρειες οχήματος](../../operations/fleet/vehicle-detail.md), κάντε κλικ στον αναφέροντα για να ανοίξετε το [προφίλ πελάτη](../../operations/customers/client-detail.md) ή αντιγράψτε τις συντεταγμένες σε εργαλείο χάρτη για επιβεβαίωση της τοποθεσίας.

## Ενέργειες (υποσέλιδο)

Η σελίδα λεπτομερειών παρέχει ένα **σκόπιμα μικρό** σύνολο ενεργειών — οι περισσότερες ροές εργασίας εισιτηρίων γίνονται στη λίστα ή σε σχετικές οντότητες (όχημα, πελάτης). Τι υπάρχει εδώ:

| Κουμπί    | Τι κάνει                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Κλείσιμο** | Κλείνει το παράθυρο (αφαιρεί το `/:id` από τη διεύθυνση URL)                                                                                              |
| **Επεξεργασία**  | Ανοίγει το εισιτήριο σε λειτουργία επεξεργασίας. Σημείωση: στην τρέχουσα έκδοση ο χειριστής Επεξεργασίας εμφανίζει μήνυμα "Η επεξεργασία δεν έχει υλοποιηθεί" — είναι συνδεδεμένος αλλά η φόρμα δεν έχει παραδοθεί ακόμα |

### Τι υπάρχει στη λίστα αλλά όχι εδώ

Το μενού γραμμής της λίστας έχει δύο επιπλέον ενέργειες που δεν εμφανίζονται στη σελίδα λεπτομερειών αυτή καθαυτή:

| Ενέργεια   | Πού βρίσκεται    | Γιατί                                                                                                                              |
| ---------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Επεξεργασία** | Γραμμή λίστας + λεπτομέρεια | Ίδια Επεξεργασία (προς το παρόν κράτημα θέσης)                                                                                   |
| **Διαγραφή** | Μενού γραμμής λίστας | Η Διαγραφή είναι ενέργεια μόνο στη γραμμή (με παράθυρο επιβεβαίωσης). Για να διαγράψετε από τη λεπτομέρεια κλείνετε πρώτα το παράθυρο, μετά χρησιμοποιείτε το μενού της γραμμής |

### Τι υπάρχει στη σελίδα λίστας

Η κεφαλίδα της σελίδας λίστας έχει _Αυτόματη Ανασκόπηση_ που πηγαίνει στην ουρά ροής — δεν υπάρχει αντίστοιχο κουμπί στη λεπτομέρεια γιατί ήδη εστιάζετε σε ένα μόνο εισιτήριο.

## Ενέργειες με ενεργοποιημένη σημαία λειτουργίας (δεν υπάρχουν στην τρέχουσα έκδοση)

Η βάση κώδικα έχει κρατήματα θέσης για ένα πλουσιότερο σύνολο ενεργειών εισιτηρίων που είναι **σχολιασμένες** στην παρούσα έκδοση:

- **Ανάθεση** — ανάθεση του εισιτηρίου σε χειριστή
- **Αποκλεισμός οχήματος** — βγάλτε το όχημα εκτός υπηρεσίας με ένα κλικ
- **Δημιουργία εργασίας συντήρησης** — ανοίξτε μια εργασία συντήρησης προ-συμπληρωμένη με τα δεδομένα αυτού του εισιτηρίου
- **Πίστωση χρήστη** — εκδώστε πίστωση πορτοφολιού στον αναφέρων
- **Απάντηση** — στείλτε μια προτυπωμένη απάντηση στον αναβάτη
- **Συγχώνευση διπλοτύπου** — συνδέστε αυτό το εισιτήριο με ένα κύριο εισιτήριο

Αν η εγκατάστασή σας τα έχει ενεργοποιημένα, εμφανίζονται στο μενού γραμμής / στο αναπτυσσόμενο _Ενέργειες_ της κεφαλίδας — όχι στο σώμα του παραθύρου. Ελέγξτε με τον διαχειριστή σας αν τα περιμένετε και δεν τα βλέπετε.

## Τυπικές ροές εργασίας

- **Διαλογή με φωτογραφία** — ανοίξτε το εισιτήριο → δείτε την εικόνα → αν η ζημιά είναι πραγματική, αντιγράψτε την ετικέτα οχήματος → κλείστε το παράθυρο → ανοίξτε τη λεπτομέρεια οχήματος για να το αποκλείσετε / να δημιουργήσετε εργασία συντήρησης
- **Επίλυση αναφοράς χαμηλής ποιότητας** — ανοίξτε το εισιτήριο → επιβεβαιώστε ότι η φωτογραφία είναι άχρηστη → κλείστε → χρησιμοποιήστε το μενού γραμμής λίστας για διαγραφή (με επιβεβαίωση)
- **Διερεύνηση ιστορικού οχήματος** — ανοίξτε ένα εισιτήριο → κάντε κλικ στο όχημα → δείτε το πλήρες ιστορικό συναγερμών + διαδρομών του οχήματος → επιστρέψτε στο εισιτήριο για να προσθέσετε σχόλιο
- **Επαλήθευση παραπόνου αναβάτη έναντι της διαδρομής** — ανοίξτε το εισιτήριο → αντιγράψτε τον αναφέρων → ανοίξτε τη λεπτομέρεια πελάτη → ελέγξτε τις πρόσφατες διαδρομές για το πλαίσιο
- **Κοινοποίηση εισιτηρίου σε συνάδελφο** — το URL περιέχει το αναγνωριστικό εισιτηρίου (`/support/tickets/:id`) ώστε να το επικολλήσετε σε συνομιλία και ο παραλήπτης να ανοίξει το ίδιο παράθυρο

## Συμβουλές

- **Το URL είναι το σελιδοδείκτης σας** — η αντιγραφή του URL με `:id` και η επικόλληση αργότερα πηγαίνει απευθείας στο ίδιο εισιτήριο, ακόμα και από διαφορετική συνεδρία
- **Esc για κλείσιμο** — το παράθυρο υποστηρίζει Esc, κλικ εκτός και το X — και τα τρία αφαιρούν το id από το URL
- **Κάντε κλικ στην εικόνα μία φορά για να δείτε το πρωτότυπο** — η μικρογραφία είναι συμπιεσμένη· το πρωτότυπο είναι αυτό που έστειλε ο αναβάτης
- **Διασταυρώστε το IMEI** — αν ένα όχημα λαμβάνει επανειλημμένα εισιτήρια, συχνά φταίει το IoT και όχι το πλαίσιο. Το IMEI είναι ο σύνδεσμός σας με τις [ρυθμίσεις IoT](../../settings/infrastructure/iot.md)
- **Το σχόλιο είναι μόνο για εσωτερική χρήση** — οι αναβάτες δεν το βλέπουν· χρησιμοποιήστε το ελεύθερα για σημειώσεις χειριστή προς χειριστή στο εισιτήριο
- **Η επεξεργασία δεν έχει κυκλοφορήσει ακόμα** — το πάτημα στο _Επεξεργασία_ σήμερα εμφανίζει ειδοποίηση. Αν χρειάζεται να αλλάξετε κατάσταση, κάντε το από τις ενέργειες σε επίπεδο λίστας ή την Αυτόματη Ανασκόπηση
