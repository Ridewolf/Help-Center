# Εισιτήρια — Λίστα

Η λίστα Εισιτηρίων (`/support/tickets`) είναι η ουρά υποστήριξης για ζητήματα που αναφέρονται σχετικά με ένα όχημα — μηχανικές βλάβες, ηλεκτρικά προβλήματα, σπασμένα μέρη, θέματα ασφάλειας κ.ά. Κάθε εισιτήριο συνδέεται με συγκεκριμένο όχημα και περιέχει μια φωτογραφία, τον αναφέρων, τον τύπο παραπόνου, έναν χρονομετρητή SLA και μια κατάσταση.

Για διερεύνηση ανά εισιτήριο (πλήρες νήμα, αποδείξεις, ενέργειες επίλυσης) δείτε τη **σελίδα λεπτομερειών εισιτηρίου** (ανοίγει με κλικ σε μια γραμμή).

Για την απλοποιημένη διεπαφή ουράς, δείτε το [Ticket Auto Review](ticket-auto-review.md).

Απαιτούμενη άδεια: **Εισιτήρια** (`a8b9c1`).

## Πώς εμφανίζονται τα εισιτήρια εδώ

Τα εισιτήρια δημιουργούνται από μερικές πηγές:

1. **Αναφορά αναβάτη** — η εφαρμογή Rider App έχει ροή "αναφορά προβλήματος"· οι αναβάτες επιλέγουν τύπο παραπόνου, τραβούν φωτογραφία, αφήνουν σημείωμα
2. **Πρωτοβουλία χειριστή** — ένας χειριστής ανοίγει εισιτήριο για όχημα που παρατήρησε ότι έχει πρόβλημα (σπάνιο· συνήθως προτιμάται η ροή [εργασιών συντήρησης](../../operations/fleet/vehicle-detail.md))
3. **Σηματοδότηση συστήματος** — κανόνες IoT ή αναλυτικών μπορούν να δημιουργήσουν εισιτήρια αυτόματα (π.χ. ανωμαλία μπαταρίας)

Κάθε νέο εισιτήριο προστίθεται σε αυτή τη λίστα με κατάσταση (τυπικά _Σε εκκρεμότητα_) και ξεκινά ο χρονομετρητής SLA.

## Φίλτρα

| Φίλτρο        | Τύπος    | Σημειώσεις                                                                                  |
| ------------- | -------- | ------------------------------------------------------------------------------------------ |
| Αναζήτηση     | Κείμενο  | Αναζητά ID εισιτηρίου, ετικέτα οχήματος, αναφέρων, τοποθεσία                               |
| Κατάσταση     | Αναπτυσσόμενο | Λίστα από backend (`Σε εκκρεμότητα`, `Σε εξέλιξη`, `Επιλυμένο`, `Απορρίφθηκε`, `Διπλότυπο` κ.ά.) |
| Τύπος παραπόνου | Αναπτυσσόμενο | 7 τύποι — δείτε την αναφορά παρακάτω                                                        |

Τα φίλτρα συνδυάζονται με ΚΑΙ. Τα chips εμφανίζονται πάνω από τον πίνακα· το URL αντανακλά την τρέχουσα κατάσταση.

## Στήλες

| Στήλη        | Ταξινομήσιμη; | Περιεχόμενο                                                    |
| ------------ | ------------- | -------------------------------------------------------------- |
| **Φωτογραφία** | —           | Μικρογραφία της φωτογραφίας αποδείξεων του αναβάτη (κλικ για μεγέθυνση) |
| **Όχημα**    | —             | Ετικέτα και μοντέλο οχήματος· κλικ για άνοιγμα λεπτομερειών οχήματος |
| **SLA**      | —             | Χρόνος που απομένει μέχρι την προθεσμία SLA (γίνεται κόκκινο όταν λήξει) |
| **Τοποθεσία** | —            | Πού αναφέρθηκε το πρόβλημα — συντεταγμένες και/ή διεύθυνση    |
| **Αναφέρων** | —             | Ποιος ανέφερε το πρόβλημα (όνομα αναβάτη ή ετικέτα συστήματος/χειριστή) |
| **Κατάσταση** | —             | Ετικέτα κατάστασης με χρώμα (δείτε την αναφορά παρακάτω)       |
| **Ημερομηνίες** | —           | Χρονοσφραγίδες δημιουργίας / ενημέρωσης                         |

## Τύποι παραπόνων

Επτά τύποι βοηθούν στην άμεση διαλογή των εισιτηρίων. Κάθε τύπος έχει χρωματική κωδικοποίηση:

| Τύπος                 | Χρώμα σήματος    | Τι συνήθως σημαίνει                                      |
| --------------------- | ---------------- | -------------------------------------------------------- |
| **Μηχανική βλάβη**    | Καταστροφικό (κόκκινο) | Σύγκρουση, σπασμένο πλαίσιο, στραβωμένα μέρη            |
| **Ηλεκτρικό πρόβλημα** | Προειδοποίηση (κίτρινο) | Θρόμπα, φώτα, προβλήματα αισθητήρα                        |
| **Πρόβλημα μπαταρίας** | Προεπιλογή (μπλε) | Δεν φορτίζει, εξαντλείται πιο γρήγορα από το αναμενόμενο  |
| **Σπασμένα μέρη**     | Καταστροφικό (κόκκινο) | Λείπει σταντ, λείπει ανακλαστήρας, φθαρμένα φρένα         |
| **Θέμα ασφάλειας**    | Καταστροφικό (κόκκινο) | Οτιδήποτε καθιστά το όχημα μη ασφαλές για οδήγηση         |
| **Καθαριότητα**       | Προειδοποίηση (κίτρινο) | Βρώμικο, οσμή, κολλώδεις επιφάνειες — χαμηλότερη προτεραιότητα |
| **Άλλο**              | Περίγραμμα        | Δεν εμπίπτει στις παραπάνω κατηγορίες — διαβάστε την περιγραφή |

Οι κόκκινες κατηγορίες συνήθως απαιτούν άμεση αφαίρεση του οχήματος από την υπηρεσία· οι κίτρινες/μπλε μπορούν συνήθως να περιμένουν παράθυρο συντήρησης.

## Αναφορά καταστάσεων

Η λίστα καταστάσεων λαμβάνεται από το backend, οπότε μπορεί να διαφέρει ελαφρώς ανά εγκατάσταση. Τυπικές καταστάσεις:

| Κατάσταση       | Παραλλαγή         | Σημασία                                                        |
| --------------- | ----------------- | -------------------------------------------------------------- |
| **Σε εκκρεμότητα** | Δευτερεύουσα (γκρι) | Μόλις αναφέρθηκε, κανείς δεν έχει ασχοληθεί ακόμα               |
| **Σε εξέλιξη**   | Προεπιλογή (μπλε) | Ανατέθηκε σε χειριστή ή δημιουργήθηκε εργασία συντήρησης        |
| **Επιλυμένο**    | Επιτυχία (πράσινο) | Το πρόβλημα διορθώθηκε· το εισιτήριο έκλεισε                   |
| **Απορρίφθηκε**  | Καταστροφικό (κόκκινο) | Ο χειριστής αποφάσισε ότι δεν είναι πραγματικό πρόβλημα        |
| **Ακυρώθηκε**    | Καταστροφικό (κόκκινο) | Κλείστηκε χωρίς επίλυση (συχνά για αναφορές χαμηλής ποιότητας) |
| **Αρχειοθετημένο** | Περίγραμμα        | Παλιό / ιστορικό                                               |
| **Διπλότυπο**    | (κλειστό)          | Συνδεδεμένο με προηγούμενο εισιτήριο για το ίδιο όχημα         |

Οι καταστάσεις που περιέχουν _επιλυμένο_, _απορρίφθηκε_ ή _διπλότυπο_ θεωρούνται **κλειστές** — δεν υπολογίζονται πλέον στην ανοιχτή ουρά.

## Βαθμός σοβαρότητας

Εσωτερικά, τα εισιτήρια φέρουν βαθμό σοβαρότητας (`critical`, `high`, `medium`, `low`) που προκύπτει από τον τύπο παραπόνου και τυχόν εισροές χειριστή/συστήματος. Η σελίδα λίστας εμφανίζει τη σοβαρότητα μέσω του **χρώματος τύπου παραπόνου** και του **χρώματος χρονομετρητή SLA** — η εκπρόθεσμη SLA σε κρίσιμο εισιτήριο είναι η κορυφαία προτεραιότητά σας.

## Ενέργειες γραμμής

Κάθε γραμμή έχει **μενού τριών σημείων** με ένα μόνο ενεργό στοιχείο:

| Ενέργεια         | Τι κάνει                                                                |
| ---------------- | ----------------------------------------------------------------------- |
| **Προβολή λεπτομερειών** | Ανοίγει τη σελίδα λεπτομερειών εισιτηρίου (πλήρες νήμα + αποδείξεις + ενέργειες επίλυσης) |

Το πλήρες σύνολο ενεργειών χειριστή (Ανάθεση, Αποκλεισμός οχήματος, Δημιουργία εργασίας συντήρησης, Πίστωση χρήστη, Απάντηση, Συγχώνευση διπλοτύπων) βρίσκεται στη **σελίδα λεπτομερειών εισιτηρίου** και ενεργοποιείται/απενεργοποιείται ανά ανάπτυξη με σημαία λειτουργίας. Ο ρόλος της λίστας είναι να λειτουργεί ως ουρά διαλογής, όχι ως κονσόλα επίλυσης.

## Ενέργειες σελίδας

- **Αυτόματη Ανασκόπηση** — ανοίγει την [Ουρά Αυτόματης Ανασκόπησης Εισιτηρίων](ticket-auto-review.md) — απλοποιημένη ανασκόπηση ενός εισιτηρίου τη φορά

## Τυπικές ροές εργασίας

- **Ημερήσια διαλογή** — φιλτράρισμα `Κατάσταση = Σε εκκρεμότητα` → ταξινόμηση κατά SLA (παλαιότερα πρώτα, προθεσμία επάνω) → επεξεργασία, άνοιγμα κάθε εισιτηρίου σε λεπτομέρειες, απόφαση και ενέργεια
- **Διαλογή μόνο κρίσιμων** — φιλτράρισμα `Τύπος παραπόνου = Μηχανική βλάβη / Ζήτημα ασφάλειας` → αυτά είναι τα εισιτήρια για αφαίρεση από υπηρεσία
- **Έλεγχος ιστορικού οχήματος** — αναζήτηση με ετικέτα οχήματος → προβολή όλων των εισιτηρίων που έχουν καταχωρηθεί για αυτή τη μονάδα → χρήσιμο πριν την επανεκκίνηση μετά από επισκευή
- **Συναγερμός SLA** — ταξινόμηση κατά SLA → τα εισιτήρια στην κορυφή της λίστας έχουν καθυστερήσει → άμεση κλιμάκωση

## Συμβουλές

- **Η φωτογραφία είναι το πρώτο σας σήμα** — ακόμα και πριν ανοίξετε το εισιτήριο, η μικρογραφία δείχνει αν είναι πραγματική αναφορά βλάβης ή υποβολή χαμηλής ποιότητας
- **Κόκκινο SLA == δράση τώρα** — όταν το SLA γίνεται κόκκινο, έχετε ήδη χάσει το συμβατικό παράθυρο· αυτή είναι η αντιδραστική σας ουρά
- **Διασταύρωση με το όχημα** — κάντε κλικ στη στήλη οχήματος → ανοίξτε την καρτέλα Ειδοποιήσεων του οχήματος → τα προβλήματα IoT και οι αναφορές χειριστών συχνά επικαλύπτονται
- **Προσοχή στα διπλότυπα** — πολλοί αναβάτες συχνά αναφέρουν το ίδιο σπασμένο πατίνι μέσα σε ώρες· χρησιμοποιήστε την Αναζήτηση οχήματος για να τα εντοπίσετε πριν την επίλυση
- **Το URL είναι κοινοποιήσιμο** — αντιγράψτε μια φιλτραρισμένη προβολή (π.χ. _εισιτήρια μηχανικής βλάβης σε εκκρεμότητα_) και στείλτε την στην ομάδα συντήρησης
