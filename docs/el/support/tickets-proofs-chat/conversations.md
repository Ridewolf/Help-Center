# Συνομιλίες

Η σελίδα Συνομιλίες (`/support/conversations`) είναι ο **messenger χειριστή** — μια διεπαφή συνομιλίας σε πραγματικό χρόνο μεταξύ της ομάδας υποστήριξής σας και των αναβατών σας. Κάθε συνομιλία ανήκει σε έναν πελάτη και περιέχει το πλήρες ιστορικό μηνυμάτων, τις ενέργειες της ομάδας σας και τις αλλαγές κατάστασης.

Απαιτούμενη άδεια: **Συνομιλίες** (`x2y3z4`).

## Πώς εμφανίζονται οι συνομιλίες εδώ

Οι συνομιλίες προέρχονται από μερικές ροές:

1. **Ο αναβάτης ανοίγει μια συνομιλία** στην εφαρμογή για κινητά — δημιουργεί μια _Νέα_ συνομιλία, μπαίνει σε ουρά _Αναμονής_
2. **Ο χειριστής ξεκινά** — το _+ Νέο_ στο πλαϊνό μενού σας επιτρέπει να ξεκινήσετε συνομιλία με συγκεκριμένο πελάτη (π.χ. για παρακολούθηση προστίμου ή έλεγχο απάτης)
3. **Επανεμφανιζόμενη** — κλειστές συνομιλίες μπορούν να ξανανοίξουν (από αναβάτη ή χειριστή) και επιστρέφουν στην κορυφή της λίστας

Η λίστα είναι **ζωντανή** — νέες συνομιλίες και εισερχόμενα μηνύματα ρέουν μέσω WebSocket χωρίς ανανέωση.

## Διάταξη

Η σελίδα έχει δύο βασικές περιοχές. Η διάταξη προσαρμόζεται στο μέγεθος οθόνης:

- **Επιτραπέζιος υπολογιστής** — διαχωρισμένη προβολή, πλαϊνό μενού αριστερά (30%) και περιεχόμενο συνομιλίας δεξιά (70%), με λαβή μεταφοράς
- **Κινητό** — μία περιοχή τη φορά: η λίστα στο πλαϊνό μενού ή η ανοιχτή συνομιλία (το βέλος πίσω επιστρέφει στη λίστα)

## Πλαϊνό μενού (αριστερά)

Η ουρά συνομιλιών και τα φίλτρα:

- **+ Νέο** — ανοίγει διάλογο για αναζήτηση πελάτη και έναρξη νέας συνομιλίας (κατάσταση _Αναμονής_)
- **Αναζήτηση** — αναζήτηση κειμένου σε όνομα πελάτη, ID, τελευταίο μήνυμα
- **Φίλτρα κατάστασης** — ετικέτες με μετρητές: `Όλα` / `Νέο` / `Αναμονή` / `Ενεργό` / `Καθυστερημένο` / `Κλειστό`
- **Κάρτες συνομιλιών** — κάθε μία δείχνει: avatar, όνομα πελάτη, προεπισκόπηση τελευταίου μηνύματος, ετικέτα κατάστασης, χρονική σήμανση, σήμα μη αναγνωσμένων. Κλικ για άνοιγμα
- **Φόρτωση περισσότερων** — σελιδοποίηση καθώς κάνετε κύλιση

Η προεπιλεγμένη ταξινόμηση βάζει τις αναπάντητες (Αναμονή / Ενεργό με μη αναγνωσμένα) στην κορυφή — οι πιο επείγουσες συνομιλίες είναι πάντα στο οπτικό σας πεδίο.

### Αναφορά κατάστασης

| Κατάσταση   | Σημασία                                                    |
| ----------- | ---------------------------------------------------------- |
| **Νέο**     | Μόλις άνοιξε, κανείς δεν το έχει διαβάσει ακόμα            |
| **Αναμονή** | Μη ανατεθειμένο, σε ουρά για να το αναλάβει οποιοσδήποτε χειριστής |
| **Ενεργό**  | Ανατεθειμένο σε χειριστή, συνομιλία σε εξέλιξη             |
| **Καθυστερημένο** | Ο χειριστής το έχει θέσει σε αναμονή (αναμονή για πληροφορίες, παρακολούθηση αργότερα) |
| **Κλειστό** | Επιλυμένο και κλειστό                                     |

## Περιεχόμενο συνομιλίας (δεξιά)

Όταν επιλέγετε μια συνομιλία, η δεξιά στήλη δείχνει:

### Κεφαλίδα συνομιλίας

- **Βέλος πίσω** (μόνο κινητό) — επιστροφή στη λίστα στο πλαϊνό μενού
- **Τίτλος** — όνομα πελάτη με ετικέτα κατάστασης συνομιλίας
- **Άνοιγμα πληροφοριών** — ανοίγει το [πλαϊνό μενού Πληροφοριών Χρήστη](#πλαίσια-πληροφοριών) με πλήρες πλαίσιο πελάτη
- **Κουμπιά Αναβολής / Μεταφοράς / Κλεισίματος** ανάλογα με την κατάσταση

### Παράθυρο συνομιλίας

- **Φυσαλίδες μηνυμάτων** — μηνύματα χειριστή δεξιά (χρώμα έμφασης), μηνύματα αναβάτη αριστερά· με χρονικές σφραγίδες και δείκτες ανάγνωσης
- **Δείκτης πληκτρολόγησης** — εμφανίζεται όταν ο αναβάτης πληκτρολογεί
- **Κουμπί Φόρτωσης παλαιότερων** στην κορυφή — φέρνει παλαιότερα μηνύματα κατόπιν ζήτησης
- **Κουμπί Προς νέα μηνύματα** — συντόμευση κύλισης στο κάτω μέρος όταν έχετε κάνει κύλιση προς τα πάνω
- **Ενέργειες μηνυμάτων** με αιώρηση — Επεξεργασία / Διαγραφή στα δικά σας μηνύματα

### Προκαθορισμένες απαντήσεις

Μια σειρά πάνω από το πεδίο εισαγωγής δείχνει πρότυπα γρήγορης απάντησης ομαδοποιημένα κατά κατηγορία. Κάντε κλικ σε ένα για να εισαχθεί το κείμενο στο πεδίο — μπορείτε να το επεξεργαστείτε πριν την αποστολή.

### Υποσέλιδο συνομιλίας

Το τι εμφανίζεται στο υποσέλιδο εξαρτάται από την **κατάσταση** και την ανάθεση της συνομιλίας:

- **Ενεργό + ανατεθειμένο σε εσάς** → **Πεδίο εισαγωγής μηνύματος** με μενού συνημμένων (κείμενο + εικόνα / αρχείο)
- **Οτιδήποτε άλλο** → **Μπάρα Ενεργειών Συνομιλίας** με τα κουμπιά που σχετίζονται με την τρέχουσα κατάσταση

## Ενέργειες συνομιλίας (ανά κατάσταση)

Το υποσέλιδο δείχνει τα σωστά κουμπιά για την τρέχουσα κατάσταση. Κοινές ενέργειες:

| Ενέργεια      | Διαθέσιμη όταν…                     | Τι κάνει                                              |
| ------------- | ---------------------------------- | ---------------------------------------------------- |
| **Αποδοχή**   | Αναμονή / Νέο (δεν σας ανήκει ακόμα) | Αναθέτει τη συνομιλία σε εσάς και την μετατρέπει σε _Ενεργό_ |
| **Ανάληψη**   | Ενεργό (άλλος χειριστής την έχει)  | Αναθέτει ξανά σε εσάς                               |
| **Επιστροφή** | Ενεργό (ανατεθειμένη σε εσάς)      | Απελευθερώνει τη συνομιλία πίσω σε _Αναμονή_         |
| **Αναβολή**  | Ενεργό                             | Θέτει τη συνομιλία σε αναμονή → _Καθυστερημένο_      |
| **Επανέναρξη** | Κλειστό                           | Επαναφέρει τη συνομιλία σε _Ενεργό_                   |
| **Κλείσιμο** | Ενεργό                             | Σηματοδοτεί τη συνομιλία ως επιλυμένη → _Κλειστό_     |
| **Διαγραφή** | Με περιορισμό άδειας               | Μαλακή διαγραφή της συνομιλίας (σε επίπεδο διαχειριστή) |
| **Νέο**     | Πάντα                             | Ξεκινά νέα συνομιλία με τον ίδιο πελάτη               |

Είστε προστατευμένοι από ενέργειες σε συνομιλία που δεν σας ανήκει — θα δείτε κουμπί _Ανάληψη_ αντί για πεδίο εισαγωγής όταν η συνομιλία είναι ανατεθειμένη σε άλλον.

## Πλαίσια πληροφοριών

Δύο πλαίσια που εμφανίζονται με ολίσθηση από ενέργειες στο παράθυρο συνομιλίας:

- **Πλαϊνό μενού Πληροφοριών Χρήστη** — γρήγορο πλαίσιο για τον ανατεθειμένο χειριστή (εσάς) και τη πρόσφατη δραστηριότητα του αναβάτη σε αυτή τη συνομιλία
- **Φύλλο Πληροφοριών Πελάτη** — πλήρες στιγμιότυπο προφίλ πελάτη (υπόλοιπο, κατάσταση, ετικέτες, πρόσφατες διαδρομές) χωρίς να φύγετε από τη συνομιλία — χρήσιμο για γρήγορες αποφάσεις

## Κενή κατάσταση (επιτραπέζιος υπολογιστής)

Όταν δεν έχει επιλεγεί συνομιλία σε επιτραπέζιο υπολογιστή, το δεξί πάνελ δείχνει μια εικόνα κενής κατάστασης με υπόδειξη να επιλέξετε συνομιλία. Σε κινητό το δεξί πάνελ δεν υπάρχει μέχρι να επιλέξετε μία — η λίστα στο πλαϊνό μενού γεμίζει την οθόνη.

## Τυπικές ροές εργασίας

- **Αποδοχή μιας αναμονής συνομιλίας** — `Status = Waiting` → κάντε κλικ στην κορυφαία κάρτα → _Αποδοχή_ → ξεκινήστε τη συνομιλία
- **Ανάληψη συνομιλίας από συνάδελφο** — ανοίξτε τη συνομιλία (θα δείτε ότι ανήκει σε κάποιον άλλον) → _Ανάληψη_ (χρησιμοποιήστε με φειδώ· διακόπτει τη συνέχεια του αναβάτη)
- **Αναστολή αργής συνομιλίας** — όταν ο αναβάτης σταματά να απαντά, _Καθυστέρηση_ για να την αφαιρέσετε από την ενεργή ουρά σας· επιστρέφει στα εισερχόμενά σας όταν απαντήσει
- **Κλείσιμο συνομιλίας** — το ζήτημα επιλύθηκε → _Κλείσιμο_ με μια γρήγορη προκαθορισμένη απάντηση ("Όλα εντάξει, καλή διαδρομή!")
- **Λάβετε γρήγορα το πλαίσιο του αναβάτη** — _Άνοιγμα πληροφοριών_ στην κεφαλίδα → δείτε υπόλοιπο / πρόσφατες διαδρομές / ετικέτες πριν απαντήσετε σε ερώτηση χρέωσης
- **Χρησιμοποιήστε προκαθορισμένες απαντήσεις** — για επαναλαμβανόμενες απαντήσεις (πολιτική επιστροφών, διαδικασία για χαμένα αντικείμενα), επιλέξτε ένα πρότυπο και προσωποποιήστε το

## Συμβουλές

- **Ζωντανά από προεπιλογή** — νέα μηνύματα εμφανίζονται χωρίς ανανέωση· ο μετρητής ενημερώνεται αυτόματα
- **Πρώτα τα αναπάντητα** — η ταξινόμηση κρατά τις επείγουσες συνομιλίες στην κορυφή· εμπιστευτείτε τη σειρά της λίστας
- **Οι προκαθορισμένες απαντήσεις είναι πρότυπα, όχι σενάρια** — πάντα προσωποποιήστε τον χαιρετισμό και τη γραμμή κλεισίματος· οι αναβάτες καταλαβαίνουν πότε λαμβάνουν τυποποιημένες απαντήσεις
- **Αναλάβετε με προσοχή** — ο αναβάτης δεν βλέπει την κατάσταση του χειριστή. Η αλλαγή στη μέση της συνομιλίας μπορεί να φανεί απότομη· αναλάβετε μόνο όταν ο τρέχων χειριστής είναι ξεκάθαρα κολλημένος (εκτός σύνδεσης, εκτός βάρδιας)
- **Καθυστέρηση > Κλείσιμο σε αβέβαιες περιπτώσεις** — αν νομίζετε ότι το ζήτημα μπορεί να επανέλθει, η _Καθυστέρηση_ κρατά τη συνομιλία συνδεδεμένη· το _Κλείσιμο_ αναγκάζει τον αναβάτη να ανοίξει νέα συνομιλία αν θέλει να συνεχίσει
- **Επεξεργαστείτε μόνο τα δικά σας μηνύματα** — και μόνο μικρά ορθογραφικά λάθη· η επανεγγραφή παλιού μηνύματος αφού το διαβάσει ο αναβάτης μπορεί να βλάψει την εμπιστοσύνη
- **Το URL περιέχει το αναγνωριστικό συνομιλίας** — επικολλήστε το σε εισιτήριο ή σημείωση κλιμάκωσης ώστε ο επόμενος χειριστής να μπει απευθείας
