# Αυτόματη Ανασκόπηση Αποδείξεων Στάθμευσης

Η σελίδα Αυτόματης Ανασκόπησης (`/support/park-proofs/auto-review`) είναι μια **απλοποιημένη διεπαφή ουράς** για να επεξεργάζεστε τις εκκρεμείς αποδείξεις στάθμευσης μία προς μία, χωρίς να επιστρέφετε στη λίστα μεταξύ των αποφάσεων.

Παρά το όνομα "Auto", οι αποφάσεις διαχείρισης εξακολουθούν να είναι δικές σας — _auto_ εδώ σημαίνει **αυτόματη προώθηση**: μετά από κάθε ενέργεια, η σελίδα φορτώνει αυτόματα την επόμενη εκκρεμή απόδειξη ώστε να συνεχίσετε τη διαχείριση χωρίς να κάνετε κλικ για επιστροφή στη λίστα.

Πρόσβαση από το κουμπί **Αυτόματη Ανασκόπηση** στη [λίστα Αποδείξεων Στάθμευσης](park-proofs.md).

Απαιτούμενη άδεια: **Αποδείξεις Στάθμευσης** (`d5e6f7`) + υπο-άδεια `review`.

## Πώς λειτουργεί

1. Η σελίδα φορτώνει την **τρέχουσα εκκρεμή ουρά** όταν την ανοίγετε
2. Βλέπετε την πρώτη απόδειξη — ίδια εικόνα + ίδια κουμπιά ενέργειας όπως στη συνηθισμένη [σελίδα ανασκόπησης](park-proof-review.md)
3. Επιλέγετε ενέργεια (Έγκριση / Προειδοποίηση / Απόρριψη με πρόστιμο / Αποκλεισμός) ή Παράλειψη
4. Η σελίδα **προωθείται αυτόματα** στην επόμενη εκκρεμή απόδειξη
5. Επαναλαμβάνετε μέχρι να αδειάσει η ουρά
6. Όταν αδειάσει, η σελίδα μεταβαίνει σε **κατάσταση αναμονής** — ελέγχει περιοδικά για νέες αποδείξεις και τις φορτώνει αυτόματα

Δεν χάνετε τη θέση σας κατά λάθος: αν κλείσετε την καρτέλα και επιστρέψετε, η ουρά αναδημιουργείται από ό,τι εκκρεμεί ακόμα.

## Διάταξη

Δύο ίσες στήλες σε ευρείες οθόνες, στοιβάζονται σε στενές οθόνες:

| Στήλη       | Πλάτος | Περιεχόμενο                                                  |
| ----------- | ------ | ------------------------------------------------------------ |
| **Εικόνα**  | 6/12   | Μεγεθυνόμενη φωτογραφία + χρονική σήμανση δημιουργίας από κάτω |
| **Ενέργειες** | 6/12   | Ίδια στοίβα κουμπιών Έγκριση / Προειδοποίηση / Απόρριψη+πρόστιμο / Αποκλεισμός / Σχόλιο |

Μια γραμμή προόδου στο πάνω μέρος δείχνει πόσο προχωρήσατε στην ουρά.

## Κεφαλίδα

- **Τίτλος** "Αυτόματη Ανασκόπηση Αποδείξεων Στάθμευσης"
- **Υπότιτλος** με πρόοδο: `Ανασκόπηση X από Y · PP-12345`
- κουμπί **Παράλειψη** (πάνω δεξιά) — παραλείπει την τρέχουσα απόδειξη χωρίς απόφαση και προχωρά στην επόμενη (η απόδειξη παραμένει _Σε εκκρεμότητα_)
- **Βέλος επιστροφής** — επιστρέφει στη [λίστα Αποδείξεων Στάθμευσης](park-proofs.md)

Η **γραμμή προόδου** κάτω από την κεφαλίδα γεμίζει καθώς εργάζεστε — με μικρό εφέ λάμψης στο γεμάτο τμήμα.

## Κουμπιά ενέργειας

Ταυτόσημα με τη [σελίδα ανασκόπησης μεμονωμένης απόδειξης](park-proof-review.md):

| Κουμπί               | Επίδραση                                                        |
| -------------------- | --------------------------------------------------------------- |
| **Έγκριση**          | Σημειώνει ως _Εγκεκριμένο_ → αυτόματη προώθηση                  |
| **Προειδοποίηση**     | Σημειώνει ως _Προειδοποίηση_ + αποστέλλει ειδοποίηση στον αναβάτη → αυτόματη προώθηση |
| **Απόρριψη με πρόστιμο** | Σημειώνει ως _Πρόστιμο_ με το ποσό πρόστιμου στην είσοδο → αυτόματη προώθηση |
| **Αποκλεισμός**      | Σημειώνει ως _Αποκλεισμένο_ (τον αναβάτη, όχι την απόδειξη) → αυτόματη προώθηση |
| **Παράλειψη**         | Δεν αποφασίζει· προχωρά στην επόμενη απόδειξη (η τρέχουσα παραμένει _Σε εκκρεμότητα_) |
| **Σχόλιο**           | Προαιρετικό πεδίο κειμένου — επισυνάπτεται στην ενέργεια που επιλέγετε |

Μετά από οποιαδήποτε απόφαση, η επόμενη απόδειξη εμφανίζεται ομαλά. Δεν υπάρχει "Αναίρεση" — μόλις κάνετε κλικ, η ενέργεια εκτελείται.

## Κατάσταση αναμονής

Όταν η ουρά αδειάσει, η σελίδα εμφανίζει **οθόνη αναμονής** αντί για κενή κάρτα Ενεργειών:

- Μήνυμα "Όλες οι αποδείξεις έχουν ανασκοπηθεί"
- **Χρονόμετρο αντίστροφης μέτρησης** μέχρι την επόμενη αυτόματη ανανέωση (συνήθως λίγα λεπτά)
- κουμπί **Έλεγχος τώρα** για παράκαμψη της αντίστροφης μέτρησης και άμεσο έλεγχο
- κουμπί **Έξοδος** για επιστροφή στη λίστα

Αν φτάσει νέα απόδειξη κατά την αναμονή (ο αναβάτης μόλις τελείωσε μια διαδρομή), η σελίδα τη φορτώνει αυτόματα και συνεχίζει τον ρυθμό διαχείρισης.

## Πότε να χρησιμοποιείτε την Αυτόματη Ανασκόπηση αντί για τη λίστα

| Χρησιμοποιήστε τη λίστα (`/support/park-proofs`) όταν…          | Χρησιμοποιήστε την Αυτόματη Ανασκόπηση όταν…               |
| --------------------------------------------------------------- | ---------------------------------------------------------- |
| Ελέγχετε συγκεκριμένους πελάτες ή διαδρομές τυχαία              | Καθαρίζετε συσσωρευμένες γενικές εκκρεμείς αποδείξεις       |
| Χρειάζεστε μόνο γρήγορη έγκριση από το μενού γραμμής            | Θέλετε κάθε φωτογραφία σε πλήρες μέγεθος μπροστά σας        |
| Ελέγχετε παλιές αποφάσεις (Εγκεκριμένα / Πρόστιμα / κ.ά.)      | Εστιάζετε στην ουρά _Σε εκκρεμότητα_ αυτή τη στιγμή          |
| Θέλετε να φιλτράρετε κατά ημερομηνία, τύπο ή πελάτη              | Θέλετε ταχύτητα: εικόνα → ενέργεια → επόμενο                |

Η Αυτόματη Ανασκόπηση είναι το εργαλείο **κατάστασης ροής** — ανοίξτε το στην αρχή της βάρδιάς σας και μην φύγετε μέχρι να αδειάσει η ουρά.

## Τυπικά ροή εργασίας

- **Έναρξη βάρδιας** — ανοίξτε την Αυτόματη Ανασκόπηση → επεξεργαστείτε κάθε εκκρεμή απόδειξη → τελειώστε στην οθόνη αναμονής → κάντε διάλειμμα
- **Γρήγορη έκρηξη** — ανοίξτε το για 10 λεπτά, καθαρίστε ό,τι μπορείτε, _Έξοδος_ πίσω στη λίστα όταν κάτι άλλο χρειάζεται την προσοχή σας
- **Ασαφής περίπτωση στη μέση της ροής** — όταν χρειάζεστε επιπλέον πληροφορίες (πλήρης χάρτης διαδρομής, ιστορικό πελάτη), κάντε κλικ στους σχετικούς συνδέσμους οντοτήτων στη συνηθισμένη ανασκόπηση (δεν εμφανίζονται εδώ); ίσως θέλετε να _Παραλείψετε_ την απόδειξη και να επιστρέψετε από τη λίστα

## Συμβουλές

- **Πληκτρολογήστε πρώτα το σχόλιο** — ίδιος κανόνας με τη συνηθισμένη σελίδα ανασκόπησης: το κλικ σε ενέργεια εκτελείται πριν προλάβετε να αποθηκεύσετε ένα αργοπορημένο σχόλιο
- **Η Παράλειψη είναι φίλος σας** για ασαφείς περιπτώσεις — μην επιβάλλετε πρόστιμο επειδή "είστε σχεδόν σίγουροι"· παραλείψτε και ανασκοπήστε από τη λίστα με πλήρες πλαίσιο (ιστορικό πελάτη, χάρτης διαδρομής)
- **Η αυτόματη προώθηση είναι γρήγορη** — μην βιάζεστε· αν κάνετε λάθος στην Απόρριψη με πρόστιμο, το πορτοφόλι του αναβάτη χρεώνεται μέσα σε δευτερόλεπτα
- **Η οθόνη αναμονής είναι υγιής** — μια άδεια ουρά σημαίνει ότι η ομάδα σας προλαβαίνει. Απομακρυνθείτε από το πληκτρολόγιο όταν τη δείτε
- **Εδώ δεν υπάρχουν φίλτρα** — η Αυτόματη Ανασκόπηση περπατάει την ανεπεξέργαστη ουρά σε σειρά άφιξης· χρησιμοποιήστε τη [λίστα](park-proofs.md) αν χρειάζεστε στόχευση υποσυνόλου
- **Το κλείσιμο της καρτέλας είναι ασφαλές** — η θέση σας είναι η ίδια η ουρά _Σε εκκρεμότητα_; μπορείτε να συνεχίσετε από εκεί που είναι η ουρά όποτε ξανανοίξετε
