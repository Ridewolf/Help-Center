# Αποδείξεις στάθμευσης — Λίστα

Η λίστα Αποδείξεων στάθμευσης (`/support/park-proofs`) είναι η ουρά διαχείρισης για τις φωτογραφίες που τραβούν οι αναβάτες του οχήματος σε κρίσιμες στιγμές της διαδρομής. Αυτές οι φωτογραφίες αποδεικνύουν ότι ο αναβάτης στάθμευσε σωστά (ή όχι), και η δουλειά της ομάδας σας εδώ είναι να **εγκρίνετε τις καλές φωτογραφίες, να προειδοποιείτε ή να επιβάλλετε ποινές στις κακές**.

Για ανασκόπηση ανά φωτογραφία (η οθόνη διαχείρισης με τη μεγάλη εικόνα), δείτε το [Park Proof Review](park-proof-review.md). Για τους κανόνες αυτοματοποίησης που χειρίζονται προφανείς περιπτώσεις χωρίς εσάς, δείτε το [Auto Review](park-proof-auto-review.md).

Απαραίτητη άδεια: **Αποδείξεις στάθμευσης** (`d5e6f7`). Ορισμένες ενέργειες σε γραμμές απαιτούν επιπλέον υπο-άδειες.

## Πώς φτάνουν οι αποδείξεις εδώ

Η εφαρμογή κινητού του αναβάτη ζητά από τον χρήστη να τραβήξει φωτογραφία σε τρία σημεία:

1. **Έναρξη** — όταν ξεκλειδώνει το όχημα (αποδεικνύει ότι η μονάδα ήταν σε καλή κατάσταση όταν το παρέλαβε)
2. **Στάθμευση** — κατά τη διάρκεια μιας παύσης στη μέση της διαδρομής (αποδεικνύει ότι στάθμευσε νόμιμα κατά τη στάση)
3. **Τέλος** — όταν ολοκληρώνει τη διαδρομή (η **κύρια** — αποδεικνύει ότι άφησε το όχημα σταθμευμένο σωστά)

Η φωτογραφία ανεβαίνει με μεταδεδομένα GPS και δημοσιεύεται σε αυτήν την ουρά με κατάσταση **Σε εκκρεμότητα**. Η Auto Review μπορεί να την αλλάξει σε _Εγκεκριμένη_ (καλή φωτογραφία) χωρίς παρέμβαση χειριστή· οτιδήποτε η Auto Review δεν είναι σίγουρη προσγειώνεται εδώ για ανθρώπινη ανασκόπηση.

## Φίλτρα

| Φίλτρο    | Τύπος     | Σημειώσεις                                                        |
| ---------- | -------- | ---------------------------------------------------------------- |
| Αναζήτηση | Κείμενο  | Αναζητά με βάση το όνομα πελάτη, την ετικέτα οχήματος, το ID διαδρομής |
| Περίοδος  | Ημερολόγιο | Επιλογή από/έως; προεπιλογή σε "όλο το διάστημα"                |
| Κατάσταση | Αναπτυσσόμενο | `Σε εκκρεμότητα` / `Εγκεκριμένο` / `Προειδοποίηση` / `Πρόστιμο` / `Αποκλεισμένο` (ή `Όλα`) |
| Τύπος     | Αναπτυσσόμενο | `Έναρξη` / `Στάθμευση` / `Τέλος` (ή `Όλα`)                      |

Χρησιμοποιήστε `Κατάσταση = Σε εκκρεμότητα` ως το καθημερινό φίλτρο παρακολούθησης — είναι η ουρά διαχείρισης.

## Στήλες

| Στήλη       | Ταξινομήσιμη; | Περιεχόμενο                                               |
| ----------- | ------------- | --------------------------------------------------------- |
| **Εικόνα**  | —             | Μικρογραφία της φωτογραφίας (κλικ για άνοιγμα της σελίδας ανασκόπησης) |
| **Χρήστης** | —             | Όνομα πελάτη και avatar; κλικ για άνοιγμα προφίλ πελάτη  |
| **Όχημα**   | —             | Ετικέτα και μοντέλο οχήματος; κλικ για λεπτομέρειες οχήματος |
| **Διαδρομή**| —             | ID διαδρομής; κλικ για λεπτομέρειες διαδρομής             |
| **Τύπος**   | ✓             | Φάση της διαδρομής (`Έναρξη` / `Στάθμευση` / `Τέλος`)      |
| **Κατάσταση**| ✓            | Ετικέτα κατάστασης (δείτε αναφορά παρακάτω)                |
| **Ημερομηνία**| ✓           | Πότε τραβήχτηκε η φωτογραφία; προεπιλεγμένη ταξινόμηση = νεότερα πρώτα |

## Αναφορά καταστάσεων

| Κατάσταση    | Χρώμα  | Σημασία                                                                       |
| ------------ | ------ | ----------------------------------------------------------------------------- |
| **Σε εκκρεμότητα** | Κίτρινο | Αναμονή διαχείρισης (δική σας ή της Auto Review)                            |
| **Εγκεκριμένο** | Πράσινο | Η φωτογραφία είναι καλή — ο αναβάτης στάθμευσε σωστά                        |
| **Προειδοποίηση** | Πορτοκαλί | Η φωτογραφία δεν είναι καλή — ο αναβάτης λαμβάνει προειδοποίηση αλλά όχι πρόστιμο |
| **Πρόστιμο** | Κόκκινο | Η φωτογραφία είναι κακή — ο αναβάτης τιμωρήθηκε (ή το σύστημα την σήμανε ως υποψήφια για πρόστιμο) |
| **Αποκλεισμένο** | Γκρι | Ο αναβάτης αποκλείστηκε λόγω αυτής της απόδειξης (σοβαρή / επαναλαμβανόμενη παράβαση) |

Οι καταστάσεις που ορίζονται με ενέργειες σε γραμμές και στη σελίδα ανασκόπησης καταγράφονται τόσο στο αρχείο της απόδειξης όσο και στο [Καταγραφή ενεργειών](../../operations/customers/client-detail.md#καρτέλα-δραστηριότητας) του πελάτη.

## Ενέργειες γραμμής

Κάθε γραμμή έχει ένα **μενού με τρεις τελείες** στα δεξιά. Οι διαθέσιμες ενέργειες εξαρτώνται από τις άδειες:

| Ενέργεια      | Άδεια          | Τι κάνει                                                                                                  |
| ------------- | -------------- | --------------------------------------------------------------------------------------------------------- |
| **Προβολή**   | `view-detail`  | Ανοίγει τη [σελίδα ανασκόπησης](park-proof-review.md) με την πλήρη εικόνα και το πλαίσιο                     |
| **Έγκριση**  | `review`       | Σημειώνει την απόδειξη ως _Εγκεκριμένη_ (χωρίς πρόστιμο, χωρίς προειδοποίηση) — τυπικό για καλές φωτογραφίες |
| **Προειδοποίηση** | `review`    | Σημειώνει ως _Προειδοποίηση_ — ο αναβάτης ειδοποιείται αλλά δεν τιμωρείται                                   |
| **Άνοιγμα διαδρομής** | —       | Μεταβαίνει στη σελίδα λεπτομερειών της σχετικής διαδρομής (χάρτης διαδρομής, χρονοδιάγραμμα κ.ά.)          |

Οι ενέργειες για τις οποίες δεν έχετε άδεια είναι κρυφές.

Το πλήρες σύνολο ενεργειών (Πρόστιμο, Αποκλεισμός χρήστη, Δημιουργία εργασίας συντήρησης, Αίτημα επαναστάθμευσης) βρίσκεται στη **σελίδα ανασκόπησης** — πηγαίνετε εκεί για οτιδήποτε πέρα από γρήγορη έγκριση/προειδοποίηση.

## Ενέργειες σελίδας (πάνω δεξιά)

- **Auto Review** — ανοίγει τη [σελίδα ρυθμίσεων Auto Review](park-proof-auto-review.md) για να διαμορφώσετε κανόνες που εγκρίνουν αυτόματα προφανείς καλές φωτογραφίες και σημαίνουν αυτόματα προφανείς κακές (αυτό αδειάζει την ουρά Σε εκκρεμότητα ώστε να αναθεωρείτε μόνο τις αμφίβολες περιπτώσεις)

## Τυπικά ροή εργασίας

- **Καθημερινή ουρά διαχείρισης** — `Κατάσταση = Σε εκκρεμότητα` → ταξινόμηση κατά ημερομηνία παλαιότερα πρώτα → περνάτε κάθε μία, _Προβολή_ για πλαίσιο, _Έγκριση_ / _Προειδοποίηση_ ανάλογα με το τι βλέπετε
- **Διερεύνηση παραπόνου** — αναζήτηση με ID διαδρομής ή πελάτη → βρείτε την απόδειξη → _Προβολή_ → ελέγξτε τη φωτογραφία με την καταγγελία του αναβάτη
- **Εντοπισμός επαναλαμβανόμενων παραβατών** — αναζήτηση με όνομα πελάτη → δείτε πολλαπλές αποδείξεις για να εντοπίσετε μοτίβο (το αρχείο δραστηριοτήτων του προφίλ χρήστη θα πει την ίδια ιστορία)
- **Μόνο τέλος διαδρομής** — `Τύπος = Τέλος` → ανασκόπηση μόνο των φωτογραφιών τέλους διαδρομής (οι πιο σημαντικές· οι φωτογραφίες στάθμευσης στη μέση της διαδρομής συνήθως είναι εντάξει)
- **Έλεγχος Auto Review** — φιλτράρισμα `Κατάσταση = Εγκεκριμένο` για την τελευταία μέρα → τυχαίος έλεγχος δείγματος για να βεβαιωθείτε ότι οι κανόνες λειτουργούν σωστά

## Συμβουλές

- **Η μικρογραφία αρκεί για τις περισσότερες κλήσεις** — σαφώς εντός ζώνης, ευθυγραμμισμένη, χωρίς εμπόδια — _Εγκρίνετε_ χωρίς να ανοίξετε. Αποθηκεύστε το _Προβολή_ για ασαφείς φωτογραφίες
- **Η ανοιχτή διαδρομή** είναι η συντόμευσή σας για το πλαίσιο — αν ο αναβάτης ισχυρίζεται ότι στάθμευσε νόμιμα, ο χάρτης της διαδρομής σας δείχνει πού κατέληξε πραγματικά
- **Οι καταστάσεις είναι σταθερές** — μόλις ορίσετε _Εγκρίθηκε_, ο αναβάτης σταματά να λαμβάνει υπενθυμίσεις για αυτήν την απόδειξη. Μην εγκρίνετε κακή φωτογραφία για να "καθαρίσετε την ουρά" γιατί χάνετε τη δυνατότητα να ακολουθήσετε
- **Η προειδοποίηση είναι το "ενδιάμεσο" σας** — χρησιμοποιήστε την όταν η φωτογραφία είναι κακή αλλά όχι κακόβουλη (ο αναβάτης βιαζόταν, ο καιρός ήταν κακός κ.λπ.). Επαναλαμβανόμενες προειδοποιήσεις κλιμακώνονται σε πρόστιμα μέσω κανόνων Auto Review
- **Χρησιμοποιήστε το Auto Review επιθετικά** — η ουρά μεγαλώνει γρήγορα· όσο περισσότερες προφανώς καλές φωτογραφίες εγκρίνει το Auto Review αυτόματα, τόση περισσότερη ενέργεια έχετε για τις πραγματικά ασαφείς
- **Το URL είναι κοινοποιήσιμο** — αντιγράψτε μια φιλτραρισμένη προβολή (π.χ. _οι αποδείξεις με πρόστιμο του χθες_) και στείλτε την σε έναν συνεργάτη για τυχαίο έλεγχο
