# Καλώς ήρθατε στον Πίνακα ελέγχου Ridewolf

Ο Πίνακας ελέγχου Ridewolf είναι το κέντρο ελέγχου για τη διαχείριση ενός στόλου κοινόχρηστης κινητικότητας. Είτε χειρίζεστε πατίνια, ποδήλατα ή οποιονδήποτε άλλο τύπο οχήματος, εδώ παρακολουθείτε τη δραστηριότητα σε πραγματικό χρόνο, διαχειρίζεστε πελάτες, χειρίζεστε την υποστήριξη και αναλύετε την απόδοση.

## Για ποιον προορίζεται αυτός ο πίνακας ελέγχου

Ο πίνακας ελέγχου έχει σχεδιαστεί για **χειριστές** — το προσωπικό που εργάζεται καθημερινά με τον στόλο:

- **Διαχειριστές στόλου** — οχήματα, ζώνες, τιμολόγια
- **Υπάλληλοι υποστήριξης** — εισιτήρια, συνομιλίες, αποδείξεις στάθμευσης
- **Αναλυτές** — μετρήσεις, αναφορές, απόδοση
- **Διαχειριστές** — χειριστές, ρόλοι, ρυθμίσεις συστήματος

Το τι βλέπει κάθε χειριστής εξαρτάται από τον **ρόλο και τα δικαιώματά** του. Η προβολή σας μπορεί να είναι πιο περιορισμένη από τις εικόνες οθόνης σε αυτόν τον οδηγό αν ορισμένα τμήματα είναι περιορισμένα για τον ρόλο σας.

## Βασικές έννοιες

Ο πίνακας ελέγχου οργανώνεται γύρω από μερικές έννοιες που θα συναντήσετε παντού:

| Έννοια        | Τι σημαίνει                                                                 |
| -------------- | ----------------------------------------------------------------------------- |
| **Όχημα**    | Μια φυσική μονάδα στον στόλο (πατίνι, ποδήλατο κ.λπ.) — διαθέτει GPS, μπαταρία, κατάσταση |
| **Διαδρομή**       | Μια διαδρομή που πραγματοποιεί πελάτης με όχημα — έχει ώρα έναρξης/λήξης, διαδρομή, κόστος     |
| **Πελάτης**     | Ένας εγγεγραμμένος πελάτης που μπορεί να νοικιάσει οχήματα                                   |
| **Πληρωμή**    | Χρηματικές συναλλαγές συνδεδεμένες με διαδρομές, ανανεώσεις υπολοίπου ή επιστροφές                         |
| **Ζώνη**       | Μια γεωγραφική περιοχή όπου λειτουργούν τα οχήματα (ή από την οποία απαγορεύεται η χρήση τους)             |
| **Τιμολόγιο**     | Κανόνες τιμολόγησης που καθορίζουν πόσο κοστίζουν οι διαδρομές                                 |
| **Ετικέτα**        | Μια ετικέτα που επισυνάπτεται σε πελάτες ή οχήματα για ομαδοποίηση και φιλτράρισμα            |
| **Εισιτήριο**     | Αίτημα υποστήριξης πελάτη                                                    |
| **Απόδειξη στάθμευσης** | Μια φωτογραφία που υποβάλλει πελάτης για να επιβεβαιώσει τη σωστή στάθμευση                         |

## Βασική πλοήγηση

### Πλευρική μπάρα (αριστερά)

Η πλευρική μπάρα είναι η κύρια πλοήγηση. Οι ομάδες επεκτείνονται για να αποκαλύψουν υποσελίδες — για παράδειγμα, το **Υποστήριξη** επεκτείνεται σε Εισιτήρια, Αποδείξεις στάθμευσης και Συνομιλίες.

### Επάνω μπάρα

Η επάνω μπάρα εμφανίζεται σε κάθε σελίδα και περιέχει:

- **Breadcrumb** — η διαδρομή πίσω στην ιεραρχία (π.χ. Αρχική → Οχήματα → RW-001)
- **AI Chat** (εικονίδιο αστραφτερής λάμψης) — ένας βοηθός που μπορεί να απαντήσει σε ερωτήσεις σχετικά με τον πίνακα ελέγχου
- **Βοήθεια** (εικονίδιο ερωτηματικού) — ανοίγει αυτή τη βάση γνώσεων, σχετική με την τρέχουσα σελίδα
- **Ειδοποιήσεις** (εικονίδιο καμπάνας) — πρόσφατα συμβάντα και συναγερμοί συστήματος
- **Προφίλ** (avatar) — ρυθμίσεις, αλλαγή κωδικού, αποσύνδεση, έλεγχοι θέματος

### Πίνακες

Οι περισσότερες σελίδες λίστας (οχήματα, διαδρομές, πελάτες κ.λπ.) ακολουθούν την ίδια διάταξη:

1. **Μπάρα αναζήτησης** στην κορυφή για αναζήτηση πλήρους κειμένου
2. **Φίλτρα** από κάτω για περιορισμό κατά κατάσταση, τύπο κ.λπ.
3. **Στήλες με δυνατότητα ταξινόμησης** — κάντε κλικ στην κεφαλίδα στήλης για ταξινόμηση
4. **Σελιδοποίηση** στο κάτω μέρος
5. **Ενέργειες γραμμής** — μενού με τρεις τελείες σε κάθε γραμμή για γρήγορες ενέργειες

## Τι να κάνετε πρώτα

Αν είναι η πρώτη φορά που χρησιμοποιείτε τον πίνακα ελέγχου, προτείνουμε:

1. **Ενημερώστε το προφίλ σας** — avatar → Προφίλ, συμπληρώστε όνομα, φωτογραφία, στοιχεία επικοινωνίας
2. **Περιηγηθείτε στον στόλο** — ανοίξτε **Οχήματα** για να δείτε τι είναι ενεργό αυτή τη στιγμή
3. **Ελέγξτε τις σημερινές διαδρομές** — ανοίξτε **Διαδρομές** φιλτραρισμένες για σήμερα για να παρακολουθήσετε τη δραστηριότητα σε πραγματικό χρόνο
4. **Ανοίξτε τον αρχικό πίνακα ελέγχου** — η κύρια σελίδα `/dashboard` συνοψίζει τα καθημερινά KPIs
5. **Διαβάστε αυτή τη βάση γνώσεων** — ανοίξτε το σχετικό τμήμα πριν κάνετε την πρώτη σας ενέργεια σε κάθε ενότητα

## Λήψη βοήθειας

Υπάρχουν τρεις τρόποι να λάβετε βοήθεια μέσα από τον πίνακα ελέγχου:

- **Εικονίδιο βοήθειας (?)** στην επάνω μπάρα — ανοίγει ένα πλαϊνό παράθυρο με τεκμηρίωση σχετική με τη σελίδα που βρίσκεστε
- **Βοήθεια** στην πλευρική μπάρα (εικονίδιο βιβλίου) — η πλήρης, αναζητήσιμη βάση γνώσεων
- **Φόρμες ανατροφοδότησης / προτάσεων** στην αρχική σελίδα της Βοήθειας — γράψτε απευθείας στην ομάδα

## Επόμενα βήματα

Μόλις εξοικειωθείτε με τα βασικά:

- Δείτε τα **Χαρακτηριστικά Πίνακα ελέγχου** για να μάθετε συντομεύσεις πληκτρολογίου, κόλπα φίλτρων και θέματα
- Δείτε τις **Λειτουργίες** για πρακτικούς οδηγούς σχετικά με οχήματα, διαδρομές και πελάτες
- Δείτε τις **Ρυθμίσεις** αν χρειάζεται να διαμορφώσετε χειριστές, ζώνες ή τιμολόγια
