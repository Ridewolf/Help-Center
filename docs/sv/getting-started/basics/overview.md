# Välkommen till Ridewolf Instrumentpanel

Ridewolf Instrumentpanel är kontrollcentret för att hantera en delad mobilitetsflotta. Oavsett om du driver elscootrar, cyklar eller någon annan fordonstyp är detta platsen där du övervakar aktivitet i realtid, hanterar kunder, sköter support och analyserar prestanda.

## Vem denna instrumentpanel är för

Instrumentpanelen är byggd för **operatörer** — personal som arbetar dagligen med flottan:

- **Flottchefer** — fordon, zoner, avgifter
- **Supportagenter** — biljetter, konversationer, parkeringsbevis
- **Analytiker** — mätvärden, rapporter, prestanda
- **Administratörer** — operatörer, roller, systeminställningar

Vad varje operatör ser beror på deras **roll och behörigheter**. Din vy kan vara mer begränsad än skärmbilderna i denna guide om vissa moduler är begränsade för din roll.

## Kärnbegrepp

Instrumentpanelen är organiserad kring några begrepp som du kommer att möta överallt:

| Begrepp        | Vad det betyder                                                              |
| -------------- | ----------------------------------------------------------------------------- |
| **Fordon**     | En fysisk enhet i flottan (scooter, cykel, etc.) — har GPS, batteri, status   |
| **Resa**       | En tur som en kund gör på ett fordon — har start-/sluttid, rutt, kostnad      |
| **Kund**       | En registrerad kund som kan hyra fordon                                      |
| **Betalning**  | Pengatransaktioner kopplade till resor, påfyllningar eller återbetalningar   |
| **Zon**        | Ett geografiskt område där fordon är verksamma (eller är begränsade från)     |
| **Avgift**     | Prissättningsregler som styr hur mycket resor kostar                         |
| **Tagg**       | En etikett kopplad till kunder eller fordon för gruppering och filtrering    |
| **Biljett**    | En kundsupportförfrågan                                                      |
| **Parkeringsbevis** | Ett foto som en kund skickar in för att bekräfta korrekt parkering       |

## Grundläggande navigering

### Sidofält (vänster)

Sidofältet är huvudnavigeringen. Grupper expanderar för att visa undersidor — till exempel expanderar **Support** till Biljetter, Parkeringsbevis och Konversationer.

### Övre fältet

Det övre fältet visas på varje sida och innehåller:

- **Brödsmulor** — vägen tillbaka genom hierarkin (t.ex. Hem → Fordon → RW-001)
- **AI-chatt** (glittrande ikon) — en assistent som kan svara på frågor om instrumentpanelen
- **Hjälp** (frågeteckenikon) — öppnar denna kunskapsbas, kontextuell till aktuell sida
- **Aviseringar** (klockikon) — senaste systemhändelser och varningar
- **Profil** (avatar) — inställningar, lösenordsbyte, logga ut, temakontroller

### Tabeller

De flesta listvyer (fordon, resor, kunder, etc.) följer samma layout:

1. **Sökfält** högst upp för fulltextsökning
2. **Filterknappar** nedanför för att begränsa efter status, typ, etc.
3. **Sorterbara kolumner** — klicka på en kolumnrubrik för att sortera
4. **Sidindelning** längst ner
5. **Radåtgärder** — en meny med tre prickar på varje rad för snabba åtgärder

## Vad du ska göra först

Om detta är första gången du använder instrumentpanelen rekommenderar vi:

1. **Uppdatera din profil** — avatar → Profil, fyll i namn, foto, kontaktuppgifter
2. **Bläddra i flottan** — öppna **Fordon** för att se vad som är aktivt just nu
3. **Kolla dagens resor** — öppna **Resor** filtrerat till idag för att följa aktivitet i realtid
4. **Öppna startsidan för instrumentpanelen** — huvudsidan `/dashboard` sammanfattar dagliga KPI:er
5. **Läs denna kunskapsbas** — öppna relevant avsnitt innan du gör din första åtgärd i varje modul

## Få hjälp

Det finns tre sätt att få hjälp inifrån instrumentpanelen:

- **Hjälpikon (?)** i övre fältet — öppnar en sidopanel med dokumentation relevant för sidan du är på
- **Hjälp** i sidofältet (bokikon) — hela, sökbara kunskapsbasen
- **Feedback-/förslagsformulär** på hjälpsidan — skriv direkt till teamet

## Nästa steg

När du är bekväm med grunderna:

- Se **Dashboard features** för att lära dig tangentbordsgenvägar, filterknep och teman
- Se **Operations** för praktiska guider om fordon, resor och kunder
- Se **Settings** om du behöver konfigurera operatörer, zoner eller avgifter
